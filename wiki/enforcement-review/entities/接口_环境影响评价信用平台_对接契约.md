# 接口_环境影响评价信用平台_对接契约

> 数据中台接口契约

## 接口描述

本接口用于数据中台与环境影响评价信用平台之间的数据对接，实现环评机构信用信息、环评报告信息等数据的自动采集，支撑环评合规审查和环评机构资质评估。

## 对接系统

环境影响评价信用平台

## 关联资源

- [[排污许可制]]
## 数据字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| institution_info | JSON | 环评机构信息（名称、资质等级、从业人数） |
| credit_score | Number | 信用评分（0-100） |
| violation_records | Array | 违规记录（违规类型、处罚机关、处罚日期） |
| project_records | Array | 承担项目清单（项目名称、环评类型、审批状态） |

## 接口规范

- 协议：HTTPS RESTful API
- 认证方式：OAuth 2.0 + IP白名单
- 数据格式：JSON
- 调用频率：按需查询 + 每周增量同步
