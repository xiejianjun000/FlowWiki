# 接口_全国人大法律数据库_对接契约

> 数据中台接口契约

## 接口描述

本接口用于数据中台与全国人大法律数据库之间的数据对接，实现法律法规文本的自动采集与更新，支撑知识库法规条目的及时同步和版本管理。

## 对接系统

全国人大法律数据库（国家法律法规数据库）

## 数据字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| law_fulltext | String | 法律法规全文（结构化HTML） |
| amendment_history | Array | 修订历史（修订时间、修订内容摘要） |
| effective_date | Date | 施行日期 |
| relevance_tags | Array | 关联标签（行业、污染物、管理手段） |

## 接口规范

- 协议：HTTPS RESTful API
- 认证方式：IP白名单 + API Key
- 数据格式：JSON / XML
- 调用频率：每日增量同步 + 按需查询
