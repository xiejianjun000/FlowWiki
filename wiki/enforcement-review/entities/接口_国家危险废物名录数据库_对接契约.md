# 接口_国家危险废物名录数据库_对接契约

> 数据中台接口契约

## 接口描述

本接口用于数据中台与国家危险废物名录数据库之间的数据对接，实现危险废物分类代码、特性描述、处置要求等危废基础数据的自动采集与同步，支撑企业危险废物规范化管理。

## 对接系统

国家危险废物名录数据库

## 关联资源

- [[排污许可制]]
## 数据字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| waste_code | String | 危废代码（8位HW编号） |
| waste_name | String | 危废名称 |
| category | String | 废物类别 |
| hazard_characteristics | Array | 危险特性（毒性、腐蚀性、易燃性等） |
| disposal_methods | Array | 推荐处置方式（填埋、焚烧、综合利用等） |

## 接口规范

- 协议：HTTPS RESTful API
- 认证方式：API Key
- 数据格式：JSON
- 调用频率：按需查询 + 月度全量同步
