# 全国人民代表大会

## 机构概况

中华人民共和国全国人民代表大会（简称全国人大，National People's Congress, NPC）是最高国家权力机关，行使国家立法权。在生态环境领域，全国人大及其常务委员会负责：

- **环境立法**：制定、修改和解释生态环境法律
- **规划审批**：审查和批准国民经济和社会发展规划（含生态环境保护内容）
- **预算审议**：审议中央生态环保财政预算和决算
- **监督权**：执法检查、专题询问、听取专项工作报告
- **重大事项决定**：批准生态相关国际条约，决定机构改革
- **人事任免**：决定生态环境部部长等国务院组成人员任命

### 五、进入法典时代（2026年及以后）

2026年3月12日，全国人民代表大会通过《中华人民共和国生态环境法典》，这是中国首部生态环境领域法典。法典整合了污染防治、生态保护、绿色低碳发展等领域的法律制度，标志着生态环境立法从分散单行法阶段进入法典化整合的新阶段。

法典通过后，原《环境保护法》、《大气污染防治法》、《水污染防治法》、《土壤污染防治法》、《固体废物污染环境防治法》、《噪声污染防治法》、《环境影响评价法》等单行法中的核心制度被吸收整合。

## 重大生态监督行动

全国人大及其常委会在生态环境领域行使监督权的主要方式：

- **执法检查**：定期对《环境保护法》《大气污染防治法》《水污染防治法》等法律实施情况开展执法检查
- **专题询问**：就生态环境保护问题对国务院及其部门进行专题询问
- **听取报告**：每年审议国务院年度环境状况和环境保护目标完成情况报告
- **备案审查**：对行政法规、地方性法规的生态环境条款进行合宪性和合法性审查
- **重点督办建议**：将生态环境相关代表建议列为重点督办事项

## 与国务院的关系

全国人大与国务院在生态环境领域的互动关系：

```
全国人民代表大会（立法权）
    │ 制定法律 ✓
    │ 批准规划 ✓
    │ 审查预算 ✓
    │ 执法检查 ✓
    ▼
国务院（行政权）
    │ 制定行政法规
    │ 编制执行规划
    │ 实施法律
    │ 管理日常事务
    ▼
生态环境部（执行部门）
    │ 部门规章
    │ 标准制定
    │ 执法监管
    ▼
地方政府生态环境部门
```
