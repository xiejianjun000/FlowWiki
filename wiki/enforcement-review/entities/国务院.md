# 国务院

## 机构概况

中华人民共和国国务院，即中央人民政府，是最高国家权力机关（全国人民代表大会）的执行机关，是最高国家行政机关。在生态环境领域，国务院承担以下核心职能：

- **行政法规制定**：根据宪法和法律制定生态环境相关行政法规
- **政策规划审批**：批准全国生态环境规划、国家行动方案
- **重大事项决定**：批准生态保护区设立、重大工程审批
- **机构设置管理**：决定生态环境部的设立、职能配置
- **国际条约缔约**：代表国家签署批准多边环境协定
- **跨部门协调**：协调跨部门、跨区域的生态环境事务

## 在生态环境领域的角色与职能

### 一、行政法规制定

国务院发布的生态环境行政法规是仅次于法律的第二大法源层级。截至2026年，现行有效的生态环境相关行政法规约40余部。代表性法规包括：

| 自然保护区条例.md | 1994（2017修订） | 自然保护区设立与管理 |
| 建设项目环境保护管理条例.md | 1998（2017修订） | 项目环评与环保验收 |
| 排污许可管理条例.md | 2021 | 排污许可制度法治化 |
| 碳排放权交易管理暂行条例.md | 2024 | 碳市场法治基础 |

### 三、审批权与重大事项决定

国务院在生态环境领域的审批事项包括：

- **国家级自然保护区**的设立、调整和撤销
- **国家生态工业示范园区**的批准命名
- **重大建设项目**环评审批（部分需国务院核准）
- **核电厂**选址和建造许可的最终核准
- **生态环境标准**中强制性国家标准的批准发布
- **国家生态文明建设示范区**命名

### 四、机构设置与改革

国务院历次机构改革中与生态环境相关的重大调整：

| 年份 | 改革内容 |
|------|---------|
| 1982 | 城乡建设环境保护部成立（内设环境保护局） |
| 1988 | 国家环境保护局（副部级）从建设部独立 |
| 1998 | 国家环境保护总局（正部级）设立 |
| 2008 | 环境保护部（国务院组成部门）组建 |
| 2018 | 生态环境部组建，整合8部门生态环保职责 |
| 2023 | 生态环境部职责进一步优化（碳排放纳入管理） |

### 五、国务院办公厅文件

国务院办公厅（国办）在生态环境领域的主要发文类型：

- **国办发**：国务院办公厅印发的政策通知（如美丽中国先行区建设实施意见）
- **国办函**：对各部门或地方政府请示的批复
- **国办发明电**：紧急部署通知
- **转发性通知**：转发生态环境部等部门政策意见

代表性国办生态环境文件：

- 国务院办公厅转发生态环境部《关于建设美丽中国先行区的实施意见》（2025）
- 国务院办公厅关于严格规范涉企行政检查的意见（2025）
- 国务院办公厅关于印发"高效办成一件事"2026年度第一批重点事项清单的通知（2026）

### 六、国务院组成部门统筹

国务院通过其组成部门统筹生态环境管理。与生态环境紧密相关的部门包括：

- **生态环境部**：生态环境保护和监管的主管部门
- **国家发展和改革委员会**：应对气候变化、循环经济、能源政策
- **自然资源部**：国土空间规划、生态保护修复
- **水利部**：水资源保护、水土保持
- **农业农村部**：农业面源污染防治、农村人居环境
- **国家林业和草原局**：森林、草原、湿地、荒漠化防治
- **住房和城乡建设部**：城市环境卫生、污水处理
- **国家能源局**：能源结构调整、新能源发展

## 政策影响力评估

国务院在生态环境领域的核心影响力体现为：

1. **顶层设计能力**：通过国家行动计划和行政法规确立中长期政策方向
2. **跨部门协调能力**：生态环境问题涉及多部门，国务院是最高协调层级
3. **资源调配能力**：中央财政生态环保资金、转移支付、专项资金
4. **绩效考核权**：将生态环境指标纳入地方政府绩效考核体系
5. **立法提案权**：向全国人大提交生态环境法律草案
6. **国际承诺**：代表国家作出气候变化、生物多样性等国际承诺
