# 接口_全国排污许可证管理信息平台_对接契约

> 数据中台接口契约

## 接口描述

本接口用于数据中台与全国排污许可证管理信息平台之间的数据对接，实现排污许可证信息、许可证执行报告、自行监测数据等关键信息的自动采集与同步，支撑企业排污许可合规管理的数据需求。

## 对接系统

全国排污许可证管理信息平台

## 关联资源

- [[排污许可制]]
## 数据字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| permit_info | JSON | 排污许可证信息（证书编号、有效期、许可排放量） |
| compliance_records | Array | 合规执行记录（监测数据、执行报告提交状态） |
| violation_records | Array | 违规记录（超标排放、未按时提交报告等） |
| permit_changes | Array | 许可证变更记录（变更时间、变更内容） |

## 接口规范

- 协议：HTTPS RESTful API
- 认证方式：OAuth 2.0 + 电子证照认证
- 数据格式：JSON
- 调用频率：每日增量同步
