# 接口_生态环境部法规库_对接契约

> 数据中台接口契约

## 接口描述

本接口用于数据中台与生态环境部法规库之间的数据对接，实现生态环境部门规章、规范性文件、标准等法规文本的自动采集与更新，支撑知识库中部门规章和标准条目的及时同步。

## 对接系统

生态环境部法规库

## 关联资源

- [[排污许可制]]
## 数据字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| regulation_fulltext | String | 法规全文（结构化文本） |
| issuance_info | Object | 发布信息（发布机关、发布日期、文号） |
| status | String | 现行有效/已废止/即将施行 |
| related_regulations | Array | 关联法规列表（上位法、下位法、配套规章） |

## 接口规范

- 协议：HTTPS RESTful API
- 认证方式：API Key + IP白名单
- 数据格式：JSON
- 调用频率：每日增量同步
