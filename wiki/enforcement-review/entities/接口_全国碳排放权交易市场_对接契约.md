# 接口_全国碳排放权交易市场_对接契约

> 数据中台接口契约

## 接口描述

本接口用于数据中台与全国碳排放权交易市场之间的数据对接，实现碳排放配额、交易行情、履约信息等碳市场数据的自动采集，支撑企业碳排放管理和碳合规分析。

## 对接系统

全国碳排放权交易市场

## 关联资源

- [[排污许可制]]
## 数据字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| allowance_balance | Number | 企业碳排放配额余量（吨CO2） |
| trade_records | Array | 交易记录（时间、价格、数量、对手方） |
| compliance_status | String | 履约状态（已履约/未履约/待核查） |
| market_price | Number | 最新市场成交价（元/吨） |

## 接口规范

- 协议：HTTPS RESTful API
- 认证方式：API Key + 数字签名
- 数据格式：JSON
- 调用频率：每日批量同步
