# 排污许可证执行报告编制技术规范解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规范排污许可证执行报告编制技术要求。明确执行报告分类（季度报告、年度报告）、编制内容（排污单位基本情况、污染防治设施运行情况、自行监测情况、台账记录情况、实际排放情况、合规判定、整改措施等）、提交频次、提交方式等。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 报告分类 | 季度报告、年度报告 |
| 编制内容 | 基本情况、设施运行、监测、排放等 |
| 提交频次 | 季度报告每季度末提交、年度报告次年3月底前 |
| 提交方式 | 全国排污许可证管理信息平台 |
| 公开要求 | 依法向社会公开 |

## 四、合规要点
1. 按时编制和提交季度、年度执行报告
2. 报告内容真实、完整、准确
3. 通过信息平台在线提交
4. 依法向社会公开执行报告
5. 报告中如实反映合规判定和整改情况
