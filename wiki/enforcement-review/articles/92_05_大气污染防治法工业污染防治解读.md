# 大气污染防治法工业污染防治解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章针对钢铁、建材、有色、化工、石化等重点工业行业大气污染防治作出专门规定。明确工业炉窑治理、挥发性有机物管控、有毒有害气体治理、粉尘无组织排放控制、泄漏检测与修复（LDAR）等要求，鼓励采用清洁生产工艺，推行源头替代和过程控制。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第43条 | 工业炉窑大气污染物治理 |
| 第45条 | 挥发性有机物管控 |
| 第47条 | 石化行业LDAR |
| 第48条 | 有毒有害气体治理 |
| 第49条 | 粉尘无组织排放控制 |

## 四、合规要点
1. 重点行业执行大气污染物特别排放限值
2. 涉VOCs行业落实源头替代、过程控制、末端治理
3. 石化行业建立LDAR制度并定期检测
4. 工业炉窑实施深度治理和燃料清洁化
5. 粉尘排放企业落实密闭、收集、除尘措施
