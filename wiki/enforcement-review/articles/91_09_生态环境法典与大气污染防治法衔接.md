# 生态环境法典与大气污染防治法衔接

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人民代表大会 |

## 二、主要内容
法典整合吸收《大气污染防治法》，将其核心制度纳入污染防治编大气污染防治章节。法典保留燃煤、工业、机动车船、扬尘、VOCs、恶臭等专项防治规则，强化重污染天气应对、区域联防联控、总量控制和排污权交易制度，明确按日连续处罚、查封扣押等强制措施在大气违法案件中的适用。

## 三、关键条款/案例要点
| 衔接要点 | 内容 |
|---------|------|
| 燃煤控制 | 煤炭消费总量控制、燃煤锅炉整治 |
| 工业治理 | 重点行业大气污染物特别排放限值 |
| VOCs管控 | 工业涂装、包装印刷等行业源头替代 |
| 机动车 | 在用车排放检测、油品质量监管 |
| 重污染应对 | 应急减排措施、限产停产 |

## 四、合规要点
1. 重点行业企业执行大气污染物特别排放限值
2. 涉VOCs行业落实源头替代和过程控制
3. 燃煤锅炉实施超低排放改造
4. 重污染天气应急期间落实减排措施
5. 不得通过暗管、渗坑等方式逃避监管排放大气污染物
