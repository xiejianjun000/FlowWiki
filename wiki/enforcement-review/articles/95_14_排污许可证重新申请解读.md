# 排污许可证重新申请解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 国务院 |

## 二、主要内容
排污单位发生重大变化时，应当重新申请排污许可证。重新申请情形包括：新建、改建、扩建项目环评批复后、生产工艺或原辅材料发生重大变化、污染物排放种类或排放量大幅增加、排放口位置或数量发生重大变化等。重新申请程序与首次申请相同。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 重新申请情形 | 新改扩建项目、重大变动 |
| 申请程序 | 与首次申请相同 |
| 申请材料 | 申请表、自行监测方案等 |
| 审批时限 | 30个工作日 |
| 临时排污 | 重新申请期间不得违法排污 |

## 四、合规要点
1. 新改扩建项目环评批复后及时申请重新申请
2. 重大变动发生前完成重新申请
3. 重新申请期间不得超许可排放
4. 申请材料应真实、完整、准确
5. 关注审批进度，及时取得新许可证
