# 排污许可证自行监测技术指南解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
指南规范排污单位自行监测技术要求。明确自行监测方案编制、监测点位布设、监测指标确定、监测频次、监测方法、质量保证与质量控制、监测数据记录和报告、信息公开等要求，为排污单位开展自行监测提供技术依据。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 方案编制 | 监测点位、指标、频次、方法 |
| 监测点位 | 排放口、厂界、内控 |
| 监测指标 | 许可污染物、特征污染物 |
| 监测频次 | 自动监测、手工监测 |
| 质量保证 | 资质、标准、记录 |

## 四、合规要点
1. 制定可行的自行监测方案
2. 按方案开展监测，保存原始监测记录
3. 监测数据真实、完整、准确
4. 重点排污单位安装自动监测设备并联网
5. 依法公开自行监测信息
