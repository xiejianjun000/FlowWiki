# 生态环境法典与气候变化应对衔接

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人民代表大会 |

## 二、主要内容
法典在绿色低碳发展编设立气候变化应对专章，将碳达峰碳中和目标纳入法治轨道。法典构建减缓与适应并重的气候治理体系，明确温室气体排放管控、碳排放权交易、碳捕集利用与封存、气候投融资、气候适应型城市建设等制度，强化甲烷等非二氧化碳温室气体管控，推动国际气候合作。

## 三、关键条款/案例要点
| 衔接要点 | 内容 |
|---------|------|
| 双碳目标 | 碳达峰、碳中和时间表 |
| 碳交易 | 全国碳排放权交易市场 |
| 非二氧化碳 | 甲烷、HFCs管控 |
| 碳捕集 | CCUS技术规范 |
| 气候适应 | 适应气候变化行动 |

## 四、合规要点
1. 重点排放单位纳入碳交易并按期履约
2. 开展温室气体排放核算与报告，确保数据真实
3. 关注甲烷等非二氧化碳温室气体管控
4. 高排放行业探索CCUS技术应用
5. 参与气候适应型城市建设，提升适应能力
