# 土壤污染防治法风险管控和修复解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章规定土壤污染风险管控和修复制度。明确农用地土壤污染风险管控（安全利用、严格管控）、建设用地土壤污染风险管控（风险筛查、详查评估、风险管控、修复）、土壤污染责任人认定和责任追溯、土壤污染状况调查评估、风险管控和修复方案编制、效果评估等要求。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第35条 | 农用地风险管控 |
| 第40条 | 建设用地风险筛查 |
| 第42条 | 风险评估 |
| 第45条 | 风险管控和修复 |
| 第48条 | 责任人认定 |

## 四、合规要点
1. 农用地安全利用类落实农艺调控、替代种植
2. 严格管控类禁止种植食用农产品
3. 工业企业搬迁地块依法开展土壤污染状况调查
4. 风险管控和修复方案科学可行
5. 修复完成后开展效果评估
