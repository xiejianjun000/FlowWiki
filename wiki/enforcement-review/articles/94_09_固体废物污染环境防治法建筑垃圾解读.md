# 固体废物污染环境防治法建筑垃圾解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章规定建筑垃圾污染防治制度。明确建筑垃圾减量化、资源化、无害化原则，建立建筑垃圾全过程管理制度；施工单位编制建筑垃圾处理方案，报备案；运输建筑垃圾应取得核准，密闭运输；建筑垃圾处置设施应建立台账，分类处置，资源化利用。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第60条 | 减量化资源化 |
| 第61条 | 处理方案 |
| 第62条 | 运输核准 |
| 第63条 | 处置设施 |
| 第64条 | 台账记录 |

## 四、合规要点
1. 施工单位编制建筑垃圾处理方案并备案
2. 运输建筑垃圾取得核准，密闭运输
3. 不得擅自倾倒、抛撒、堆放建筑垃圾
4. 处置设施建立台账，依法分类处置
5. 推动建筑垃圾资源化利用
