# 排污许可管理条例按日连续处罚适用

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 国务院 |

## 二、主要内容
按日连续处罚是排污许可管理条例核心强制措施，针对未取得排污许可证排污、超过许可浓度或排放量排放污染物、逃避监管方式排放、未按规定运行污染防治设施等违法行为适用。启动条件为责令改正决定后复查仍拒不改正，计罚天数为责令改正决定之日的次日起至复查之日止。

## 三、关键条款/案例要点
| 适用要点 | 内容 |
|---------|------|
| 适用情形 | 无证排污、超许可排放、逃避监管排放 |
| 启动条件 | 责令改正后复查仍拒不改正 |
| 计罚天数 | 责令改正决定之次日起至复查之日 |
| 计罚基数 | 原罚款数额 |
| 计罚上限 | 法律未明确上限 |

## 四、合规要点
1. 收到责令改正决定后立即整改
2. 建立内部环境合规自查和整改跟踪机制
3. 整改完成后主动申请复查
4. 复查合格后保留整改证据
5. 关注按日连续处罚复议诉讼救济途径
