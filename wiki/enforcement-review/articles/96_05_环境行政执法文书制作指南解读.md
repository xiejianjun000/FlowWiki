# 环境行政执法文书制作指南解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
指南规范环境行政执法文书制作要求。明确文书种类（立案审批表、调查询问笔录、现场检查笔录、案件调查报告、事先告知书、听证告知书、处罚决定书、送达回证等）、文书格式（统一格式、必备要素）、文书制作要求（真实、准确、完整、规范）、文书送达、文书归档等。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 文书种类 | 立案、调查、决定、送达等 |
| 文书格式 | 统一格式、必备要素 |
| 制作要求 | 真实、准确、完整、规范 |
| 文书送达 | 直接送达、留置送达、邮寄送达、公告送达 |
| 文书归档 | 立卷归档、保管期限 |

## 四、合规要点
1. 关注执法文书格式和内容完整性
2. 对文书错误及时提出更正
3. 依法签收执法文书，留存副本
4. 不服处罚决定可申请复议或诉讼
5. 关注文书送达方式，确保送达效力
