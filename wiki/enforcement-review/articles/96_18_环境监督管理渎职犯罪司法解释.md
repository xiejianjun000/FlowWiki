# 环境监督管理渎职犯罪司法解释

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 最高人民法院、最高人民检察院 |

## 二、主要内容
司法解释规范环境监督管理渎职犯罪案件审理。明确环境监管失职罪（《刑法》第408条）追诉标准（"严重不负责任，导致发生重大环境污染事故"的具体情形）、滥用职权罪、玩忽职守罪、徇私舞弊罪、环境监测数据造假罪等环境监管渎职犯罪的认定、共犯、单位犯罪、量刑标准。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第1条 | 环境监管失职罪追诉标准 |
| 第3条 | "严重不负责任"情形 |
| 第5条 | 滥用职权罪 |
| 第8条 | 玩忽职守罪 |
| 第10条 | 量刑标准 |

## 四、合规要点
1. 监管部门依法履职，避免渎职风险
2. 关注"严重不负责任"的认定标准
3. 监测数据不得造假，关注数据真实性
4. 配合监管的同时关注监管合法性
5. 关注徇私舞弊对量刑的影响
