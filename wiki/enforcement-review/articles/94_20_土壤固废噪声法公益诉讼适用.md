# 土壤固废噪声法公益诉讼适用

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
土壤、固废、噪声污染防治法对破坏土壤环境、固废污染环境、声环境、损害社会公共利益的行为，建立环境公益诉讼制度。符合条件的社会组织可提起民事公益诉讼；检察机关在无适格社会组织或社会组织不提起时，可提起民事公益诉讼，也可对违法行使职权或不作为的行政机关提起行政公益诉讼。

## 三、关键条款/案例要点
| 法律 | 公益诉讼条款 |
|------|---------|
| 土壤污染防治法 | 第97条 |
| 固废法 | 第122条 |
| 噪声法 | 第85条 |
| 共同规则 | 社会组织前置、检察机关补位 |
| 衔接规则 | 生态损害赔偿优先 |

## 四、合规要点
1. 关注社会组织环境公益诉讼风险
2. 检察机关公告30日内可启动生态损害赔偿磋商
3. 主动整改可减轻或免除公益诉讼追责
4. 关注行政公益诉讼对监管部门履职的督促
5. 公益诉讼赔偿金专项用于生态修复
