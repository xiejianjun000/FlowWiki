# 排污许可管理条例申请与审批解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 国务院 |

## 二、主要内容
本章规定排污许可证申请与审批程序。明确申请材料（排污许可证申请表、自行监测方案、承诺书等）、审批时限（30个工作日内）、审批条件、不予许可情形、信息公开要求；首次申请、变更、延续、重新申请的具体程序；生态环境部门依法核发排污许可证。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第7条 | 申请材料 |
| 第9条 | 审批时限 |
| 第11条 | 审批条件 |
| 第12条 | 不予许可情形 |
| 第14条 | 信息公开 |

## 四、合规要点
1. 排污单位首次申请排污许可证，应提前准备完整材料
2. 申请材料应真实、完整、准确
3. 关注审批时限，及时跟进审批进度
4. 不予许可情形包括不符合法律法规、不符合环境质量改善目标等
5. 排污许可证核发前依法公开信息
