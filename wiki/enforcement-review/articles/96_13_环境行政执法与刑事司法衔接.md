# 环境行政执法与刑事司法衔接

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部、公安部、最高检 |

## 二、主要内容
本文规范环境行政执法与刑事司法衔接工作。明确移送情形（涉及污染环境罪、非法处置进口固体废物罪、环境监管失职罪等）、移送程序（移送材料、移送时限、移送监督）、证据转换（行政执法证据向刑事证据转换）、案件会商、信息共享、监督机制。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 移送情形 | 涉嫌环境犯罪案件 |
| 移送程序 | 移送材料、时限、监督 |
| 证据转换 | 行政证据向刑事证据转换 |
| 案件会商 | 重大疑难案件会商 |
| 信息共享 | 信息共享平台 |

## 四、合规要点
1. 涉嫌环境犯罪案件依法移送公安机关
2. 关注移送程序合法性，及时咨询律师
3. 行政执法证据可作为刑事证据使用
4. 配合刑事侦查，争取从宽处理
5. 关注案件会商对案件定性的影响
