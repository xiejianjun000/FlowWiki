# 排污许可证注销撤销解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 国务院 |

## 二、主要内容
排污许可证注销、撤销是许可证终止的两种情形。注销适用于排污单位终止、不再排污、许可证到期未延续、依法被吊销等情形；撤销适用于排污单位以欺骗、贿赂等不正当手段取得许可证的情形。注销撤销后，排污单位不得继续排放污染物。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 注销情形 | 终止、不排污、到期未延续、吊销 |
| 撤销情形 | 欺骗、贿赂等不正当手段取得 |
| 实施 | 生态环境部门依法注销或撤销 |
| 后续义务 | 不得继续排污 |
| 救济途径 | 申请行政复议或行政诉讼 |

## 四、合规要点
1. 排污单位终止前依法办理许可证注销
2. 不得以欺骗、贿赂等手段取得许可证
3. 许可证到期前30日申请延续
4. 被注销撤销后不得继续排放污染物
5. 不服注销撤销决定可依法申请复议或诉讼
