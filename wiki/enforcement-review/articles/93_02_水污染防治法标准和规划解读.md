# 水污染防治法标准和规划解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章规定水环境质量标准、水污染物排放标准体系，建立流域水污染防治规划制度。国务院生态环境主管部门制定国家水环境质量标准和水污染物排放标准，省级政府可制定地方标准并报备；重点流域、海域编制水污染防治规划；江河湖泊流域按一河一策编制规划。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第11条 | 水环境质量标准 |
| 第12条 | 水污染物排放标准 |
| 第14条 | 重点流域规划 |
| 第15条 | 一河一策 |
| 第16条 | 规划实施评估 |

## 四、合规要点
1. 重点流域企业执行水污染物特别排放限值
2. 关注地方标准严于国家标准的情况
3. 配合流域水污染防治规划实施
4. 跟踪标准修订动态，及时更新治理设施
5. 关注流域水质目标考核
