# 排污许可证后监管执法指南解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
指南规范排污许可证后监管执法工作。明确监管执法方式（现场检查、台账核查、监测比对、数据审核、随机抽查等）、检查重点（许可证有效性、按证排污情况、自行监测合规性、台账报告合规性、信息公开合规性等）、违法情形识别、处罚措施适用。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 监管方式 | 现场检查、台账核查、监测比对 |
| 检查重点 | 按证排污、自行监测、台账报告 |
| 违法情形 | 无证排污、超许可排放、未自行监测 |
| 处罚措施 | 罚款、按日连续处罚、查封扣押 |
| 信用监管 | 信用评级、联合惩戒 |

## 四、合规要点
1. 配合生态环境部门许可证后监管检查
2. 保存完整台账和监测记录，备查
3. 及时整改监管发现的问题
4. 关注信用监管对企业经营影响
5. 严重违法面临按日连续处罚、查封扣押、拘留
