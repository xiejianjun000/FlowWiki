# 固体废物污染环境防治法工业固废解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章规定工业固废污染防治制度。明确产生工业固废单位的污染防治责任、台账记录、分类贮存、综合利用、处置要求；建立工业固废申报登记、转移联单制度；推动工业固废综合利用，加强工业固废贮存、处置设施建设。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第36条 | 产生者责任 |
| 第37条 | 台账记录 |
| 第38条 | 贮存设施 |
| 第39条 | 综合利用 |
| 第40条 | 申报登记 |

## 四、合规要点
1. 产生工业固废的单位建立台账，如实记录
2. 依法分类贮存，不得混堆
3. 贮存设施符合国家标准
4. 推动综合利用，减少处置量
5. 按时申报登记固废产生、利用、处置情况
