# 大气污染防治法大气污染防治监督管理解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章建立大气污染防治监督管理核心制度：建设项目环评、排污许可、总量控制、排污收费（环境保护税）、监测、信息公开等。明确排污单位自行监测、台账记录、执行报告义务，建立重点排污单位名录，强化自动监测设备安装和联网，推行环境信息公开和信用评价制度。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第18条 | 建设项目环评和三同时 |
| 第19条 | 排污许可制度 |
| 第21条 | 重点排污单位名录 |
| 第24条 | 自动监测设备安装联网 |
| 第25条 | 环境信息公开 |

## 四、合规要点
1. 重点排污单位依法安装自动监测设备并联网
2. 建立自行监测制度，保存原始监测记录
3. 如实公开污染物排放信息，接受社会监督
4. 依法缴纳环境保护税
5. 配合总量控制和排污权交易管理
