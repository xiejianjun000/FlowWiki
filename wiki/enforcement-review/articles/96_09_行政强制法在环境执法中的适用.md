# 行政强制法在环境执法中的适用

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
《行政强制法》规范环境执法中行政强制措施和行政强制执行。明确强制措施种类（查封、扣押、冻结等）、强制执行方式（代履行、加处罚款、滞纳金、划拨存款等）、强制程序（实施、催告、陈述申辩、决定、执行、解除）、强制措施期限、救济途径。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第9条 | 强制措施种类 |
| 第12条 | 强制执行方式 |
| 第18条 | 强制措施程序 |
| 第35条 | 催告程序 |
| 第45条 | 加处罚款 |

## 四、合规要点
1. 不得拒绝、阻挠行政强制措施实施
2. 依法享有陈述、申辩权利
3. 关注强制措施期限，及时申请解除
4. 不服强制决定可申请复议或诉讼
5. 强制执行前依法催告，给予合理期限
