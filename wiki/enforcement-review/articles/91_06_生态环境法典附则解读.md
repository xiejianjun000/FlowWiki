# 生态环境法典附则解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人民代表大会 |

## 二、主要内容
附则编主要规定法律术语定义、法律衔接、过渡条款和施行日期等事项。法典明确整合吸收的现行法律清单（含大气污染防治法、水污染防治法、土壤污染防治法、固废法、噪声法等十余部），规定法典施行后上述法律同时废止，并对正在办理的案件、已生效行政许可的过渡处理作出安排。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第200条 | 术语定义 |
| 第205条 | 整合吸收的现行法律 |
| 第206条 | 法律废止 |
| 第208条 | 过渡条款 |
| 第210条 | 施行日期 |

## 四、合规要点
1. 关注法典整合吸收范围，及时更新内部合规依据
2. 注意法典施行日（2026年相关规定），做好衔接准备
3. 正在办理的环境案件适用新旧法衔接规则
4. 已取得的排污许可等行政许可效力延续
5. 关注术语定义条款，准确理解法律概念
