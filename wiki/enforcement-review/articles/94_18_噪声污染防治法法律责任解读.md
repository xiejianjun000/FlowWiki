# 噪声污染防治法法律责任解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章对超标排放工业噪声、违法夜间施工、高音喇叭扰民、商业经营噪声超标、公共场所活动噪声超标、室内装修违法等行为设定法律责任。明确罚款幅度、责令改正、查封扣押（针对工业噪声）、按日连续处罚、行政拘留等强制措施，强化"双罚制"和第三方机构责任。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第75条 | 工业噪声超标处罚 |
| 第77条 | 夜间施工违法处罚 |
| 第80条 | 高音喇叭扰民处罚 |
| 第82条 | 商业经营噪声处罚 |
| 第84条 | 按日连续处罚 |

## 四、合规要点
1. 工业噪声排放不得超标
2. 夜间施工依法取得许可
3. 不得使用高音喇叭扰民
4. 商业经营落实噪声管控
5. 关注按日连续处罚风险
