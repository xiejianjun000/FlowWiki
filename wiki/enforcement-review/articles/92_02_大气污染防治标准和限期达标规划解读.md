# 大气污染防治标准和限期达标规划解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章规定大气环境质量标准、大气污染物排放标准体系，建立未达标城市限期达标规划制度。国务院生态环境主管部门制定国家大气环境质量标准，省级政府可制定地方标准并报备；重点区域和未达标地区执行特别排放限值；未达标城市政府应编制限期达标规划，明确阶段性目标和措施，并向社会公开。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第8条 | 大气环境质量标准 |
| 第9条 | 大气污染物排放标准 |
| 第11条 | 重点区域特别排放限值 |
| 第13条 | 未达标城市限期达标规划 |
| 第14条 | 规划实施评估 |

## 四、合规要点
1. 重点区域企业执行大气污染物特别排放限值
2. 关注地方大气污染物排放标准严于国标的情况
3. 未达标城市企业应配合政府限期达标措施
4. 达标城市做好巩固提升，避免反弹
5. 跟踪标准修订动态，及时更新治理设施
