# 生态环境法典与排污许可管理条例衔接

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人民代表大会 |

## 二、主要内容
法典将排污许可确立为固定污染源核心管理制度，与《排污许可管理条例》形成"基本法+行政法规"双层架构。法典明确排污许可覆盖所有固定污染源，按污染物产生量、排放量和对环境的影响程度实行分类管理（重点/简化/登记），强化许可证后监管，统一排污许可执法规则。

## 三、关键条款/案例要点
| 衔接要点 | 内容 |
|---------|------|
| 分类管理 | 重点管理、简化管理、登记管理三级 |
| 申请核发 | 排污单位主动申请，生态环境部门核发 |
| 许可事项 | 污染物种类、排放浓度、排放量 |
| 执法依据 | 排污许可证作为执法基础 |
| 无证排污 | 责令改正并处罚款 |

## 四、合规要点
1. 依法申请取得排污许可证，不得无证排污
2. 按许可证要求开展自行监测、记录台账、提交报告
3. 排污事项发生变化须及时变更或重新申请
4. 许可证到期前30日申请延续
5. 配合许可证后监管，如实提供资料
