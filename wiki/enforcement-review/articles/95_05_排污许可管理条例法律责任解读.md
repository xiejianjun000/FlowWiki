# 排污许可管理条例法律责任解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 国务院 |

## 二、主要内容
本章对未取得排污许可证排污、欺骗取得许可证、超许可排放、未按规定开展自行监测、未按规定提交执行报告、未按规定公开信息、违反排污口管理规定等违法行为设定法律责任。明确罚款幅度（最高100万）、按日连续处罚、查封扣押、限产停产、行政拘留等强制措施。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第33条 | 无证排污处罚 |
| 第34条 | 欺骗取得许可证 |
| 第35条 | 超许可排放处罚 |
| 第38条 | 自行监测违法处罚 |
| 第43条 | 按日连续处罚 |

## 四、合规要点
1. 不得未取得排污许可证排污
2. 申请材料应真实，不得欺骗取得许可证
3. 按许可证要求排放，不得超许可排放
4. 依法开展自行监测，按时提交执行报告
5. 关注按日连续处罚、查封扣押、拘留适用
