# 土壤污染防治法法律责任解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章对土壤污染重点监管单位未履行义务、向农用地排放有毒有害物质超标、未按规定进行土壤污染状况调查、未按规定实施风险管控和修复、土壤污染责任人未承担责任等违法行为设定法律责任。明确罚款幅度、按日连续处罚、查封扣押、行政拘留、刑事责任追究，强化"双罚制"和第三方责任。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第86条 | 重点监管单位未履义务处罚 |
| 第88条 | 农用地排放超标处罚 |
| 第90条 | 未按规定调查处罚 |
| 第94条 | 第三方机构责任 |
| 第97条 | 刑事责任追究 |

## 四、合规要点
1. 重点监管单位履行土壤污染防治义务，避免处罚
2. 不得向农用地排放有毒有害物质超标
3. 工业企业搬迁依法开展土壤污染状况调查
4. 土壤污染责任人承担风险管控和修复责任
5. 第三方机构不得出具虚假报告
