# 环境行政处罚证据指南解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
指南规范环境行政处罚证据收集、审查和运用。明确证据种类（书证、物证、视听资料、电子数据、证人证言、当事人陈述、鉴定意见、现场勘验笔录）、证据收集要求、证据保全、证据审查（合法性、真实性、关联性）、证据运用和证明标准。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 证据种类 | 8种法定证据 |
| 收集要求 | 合法、客观、全面 |
| 证据保全 | 易灭失证据及时保全 |
| 证据审查 | 合法性、真实性、关联性 |
| 证明标准 | 明显优势证据标准 |

## 四、合规要点
1. 配合执法人员依法收集证据，如实提供
2. 关注证据合法性，对非法证据提出异议
3. 保留反驳证据，维护自身合法权益
4. 关注明显优势证据标准在环境处罚中的适用
5. 涉及鉴定意见的，关注鉴定机构和人员资质
