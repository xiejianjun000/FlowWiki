# 排污许可证分类管理名录解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
名录规定排污许可分类管理范围。按污染物产生量、排放量和对环境的影响程度，将排污单位分为重点管理、简化管理、登记管理三级；按国民经济行业分类（GB/T 4754）和代码、产品类别、生产能力等指标识别管理类别，是排污单位判断是否纳入许可及管理级别的核心依据。

## 三、关键条款/案例要点
| 类别 | 适用范围 |
|------|---------|
| 重点管理 | 重点行业大型企业、重点污染物排放单位 |
| 简化管理 | 一般行业中小型企业 |
| 登记管理 | 污染物产生量较小的单位 |
| 不纳入 | 影响极小的部分行业 |
| 动态调整 | 名录定期修订更新 |

## 四、合规要点
1. 按国民经济行业分类代码识别本单位管理类别
2. 重点管理单位按规定申请取得排污许可证
3. 简化管理单位按规定申请取得排污许可证
4. 登记管理单位按规定填报排污登记表
5. 关注名录修订动态，及时调整管理类别
