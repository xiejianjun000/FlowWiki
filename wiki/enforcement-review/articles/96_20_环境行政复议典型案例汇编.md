# 环境行政复议典型案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集环境行政复议典型案例，涵盖处罚决定撤销、变更、确认违法、责令履行等复议决定类型。分析案件复议申请、复议审查、复议决定、复议理由，重点关注程序违法、事实不清、证据不足、法律适用错误、自由裁量不当等复议撤销理由。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 程序违法 | 未告知听证权利、未送达 |
| 事实不清 | 证据不足、认定错误 |
| 法律适用错误 | 法条引用错误 |
| 自由裁量不当 | 处罚幅度不合理 |
| 责令履行 | 不作为、未依法履职 |

## 四、合规要点
1. 学习复议案例，识别执法问题
2. 关注复议撤销理由，作为应诉依据
3. 收集证据反驳处罚决定
4. 关注程序合法性，对程序违法提出异议
5. 关注自由裁量合理性，对不当处罚主张变更
