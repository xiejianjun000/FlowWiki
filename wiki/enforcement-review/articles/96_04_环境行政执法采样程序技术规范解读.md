# 环境行政执法采样程序技术规范解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规范环境行政执法采样程序技术要求。明确采样人员要求（2人以上、出示执法证）、采样设备（清洁、完好、标准检定）、采样方法（瞬时样、混合样、时间样）、采样记录（时间、地点、方法、数量、保存）、样品保存和运输、样品分析等。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 采样人员 | 2人以上，出示执法证 |
| 采样设备 | 清洁、完好、检定合格 |
| 采样方法 | 瞬时样、混合样、时间样 |
| 采样记录 | 完整、准确、可追溯 |
| 样品保存 | 按标准保存和运输 |

## 四、合规要点
1. 配合执法人员依法采样，关注采样人员资质
2. 采样记录签字确认，记录真实情况
3. 关注采样方法符合标准要求
4. 样品保存和运输符合标准
5. 对采样程序违法提出异议
