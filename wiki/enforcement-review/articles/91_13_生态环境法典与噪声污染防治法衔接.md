# 生态环境法典与噪声污染防治法衔接

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人民代表大会 |

## 二、主要内容
法典整合吸收《噪声污染防治法》，将其纳入污染防治编噪声污染防治章节。法典统一声环境功能区划和声环境质量标准，强化工业噪声、建筑施工噪声、交通运输噪声、社会生活噪声分类防治，建立噪声敏感建筑物集中区域管控、夜间施工许可、低频噪声管控等制度，完善违法投诉举报处理机制。

## 三、关键条款/案例要点
| 衔接要点 | 内容 |
|---------|------|
| 工业噪声 | 排放标准、边界噪声管控 |
| 施工噪声 | 夜间施工许可、噪声限值 |
| 交通噪声 | 隔声屏障、限鸣限速 |
| 社会生活 | 低频噪声管控、投诉处理 |
| 敏感建筑 | 隔声设计、防护距离 |

## 四、合规要点
1. 工业企业执行工业企业厂界环境噪声排放标准
2. 建筑施工夜间作业须取得夜间施工许可
3. 噪声敏感建筑物集中区域禁止新建噪声排放企业
4. 文化娱乐、商业经营等场所落实社会生活噪声管控
5. 配合噪声投诉处理，及时整改扰民问题
