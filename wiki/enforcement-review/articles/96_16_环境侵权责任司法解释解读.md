# 环境侵权责任司法解释解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 最高人民法院 |

## 二、主要内容
司法解释规范环境侵权民事案件审理。明确环境侵权责任构成（污染环境、破坏生态造成损害）、归责原则（无过错责任）、举证责任（因果关系倒置）、数人侵权责任、第三人责任、不可抗力免责、正当防卫免责、损害赔偿范围和计算、精神损害赔偿等。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第1条 | 环境侵权责任构成 |
| 第6条 | 无过错责任原则 |
| 第7条 | 因果关系举证责任倒置 |
| 第12条 | 数人侵权 |
| 第18条 | 损害赔偿范围 |

## 四、合规要点
1. 污染环境造成他人损害须承担侵权责任
2. 关注无过错责任原则，无过错亦可能担责
3. 因果关系举证责任倒置，但原告仍需初步举证
4. 数人侵权的，关注按份责任和连带责任划分
5. 损害赔偿包括人身、财产、精神损害
