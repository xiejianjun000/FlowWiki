# 生态环境法典法律责任编解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人民代表大会 |

## 二、主要内容
法律责任编整合各类生态环境违法行为的责任追究规则，构建行政责任、民事责任、刑事责任有机衔接的责任体系。法典统一按日连续处罚、查封扣押、限产停产、行政拘留等行政强制措施适用规则，完善生态环境损害赔偿制度，强化环境公益诉讼，明确单位犯罪和环境犯罪追诉标准。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第160条 | 按日连续处罚适用 |
| 第165条 | 查封扣押适用 |
| 第170条 | 限产停产适用 |
| 第175条 | 行政拘留适用 |
| 第180条 | 生态环境损害赔偿 |
| 第185条 | 环境公益诉讼 |

## 四、合规要点
1. 建立环境合规风险预警机制，防范违法行为发生
2. 收到责令改正决定后立即整改，避免按日连续处罚
3. 配合行政执法，不得拒绝、阻挠查封扣押
4. 关注环境犯罪追诉标准，防范刑事风险
5. 涉及生态损害应主动参与磋商赔偿
