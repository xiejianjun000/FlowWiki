# 大气污染防治法查封扣押适用

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
查封扣押是大气法赋予生态环境部门的行政强制措施，针对违法排放大气污染物造成或可能造成严重污染的情形适用。生态环境部门可以查封、扣押造成污染物排放的设施、设备。决定书须载明当事人基本情况、违法事实、查封扣押设施清单、申请行政复议或提起行政诉讼的途径。

## 三、关键条款/案例要点
| 适用要点 | 内容 |
|---------|------|
| 适用情形 | 违法排放造成或可能造成严重污染 |
| 实施主体 | 生态环境主管部门 |
| 实施对象 | 造成污染物排放的设施、设备 |
| 期限要求 | 一般不超过30日，延长不超过30日 |
| 救济途径 | 申请行政复议或提起行政诉讼 |

## 四、合规要点
1. 不得拒绝、阻挠生态环境部门查封扣押
2. 配合实施，提供便利，如实提供情况
3. 整改完成后申请解除查封扣押
4. 查封扣押期间不得擅自启用、隐匿、变卖被查封设备
5. 不服查封扣押决定可依法申请复议或诉讼
