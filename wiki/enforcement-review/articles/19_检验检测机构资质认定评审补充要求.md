# 《检验检测机构资质认定生态环境监测机构评审补充要求》（2025版vs2018版）新旧规对比+合规指引

2025年12月，市场监管总局与生态环境部联合发布《检验检测机构资质认定生态环境监测机构评审补充要求（2025年）》，与2026年1月1日起施行的《生态环境监测条例》构建"法规+技术规范"双重监管体系。

## 一、新旧版本逐条对比分析

### 1. 人员管理要求对比

- **人员总数**：2018版无量化要求 → 2025版监测人员总数不少于20人（噪声等特殊类别不少于10人）
- **职称占比**：中级及以上占比不低于15% → 不低于25%
- **专业背景**：未明确限定专业范围 → 需具有生态环境监测领域相关专业背景大专及以上学历
- **技术负责人**：5年以上工作经历 → 8年以上
- **授权签字人**：3年以上工作经历 → 6年以上
- **质量负责人**：未明确年限 → 6年以上工作经历
- **独立作业条件**：经培训确认即可 → 从业3个月及以上方可独立作业
- **终身追责制**：机构及负责人对数据真实性负责 → 采样分析人员、审核与授权签字人分别对原始监测数据、监测报告的真实性**终身负责**

### 2. 资质能力要求对比

- **监测类别划分**：未明确划分 → 划分为13个类别（水、废气、土壤、固废、海水、噪声、辐射等）
- **能力要求**：允许单项资质 → 申请单一类别资质必须具备该类别全部基础检测能力
- **管理体系运行时限**：无明确要求 → 需有效运行满6个月方可申请
- **备案要求**：仅需资质认定 → 资质认定与主管部门备案**双要求**
- **分支机构管理**：无明确要求 → 需单独取得资质认定，禁止"挂靠""借证"

### 3. 设备与技术要求对比

- **设备防篡改**：无要求 → 专用仪器设备应具备防范篡改、伪造监测数据的功能
- **设备标识**：无要求 → 所有仪器设备赋予唯一"数字身份证"
- **信息化系统**：鼓励使用LIMS → **强制使用**LIMS系统
- **数据存储**：电子记录需备份 → 采用**国密算法**加密存储，异地备份

### 4. 场地与设施要求对比

- **采样管理**：至少2人在场 → 主要监测点位需安装**视频监控**并与监管部门联网
- **场地使用权**：未明确 → 租用期限不少于资质认定证书有效期（且不少于1年）

### 5. 数据与记录管理要求对比

- **记录保存期限**：未明确规定 → 原始记录保存**不少于5年**
- **记录方式**：电子/纸质均可 → 全流程23个关键节点需**电子签名**确认
- **数据防篡改**：无要求 → 鼓励采用**区块链存证**等技术
- **异常数据处理**：无规范 → 异常数据需形成专项报告

### 6. 流程管理要求对比

- **弄虚作假防控**：建立防范制度 → 明确**数据造假六类禁则**（未监测出报告、篡改记录、调换样品等）
- **标准更新管理**：外来文件需受控 → 新增标准更新预警机制
- **自查要求**：无要求 → 定期开展内部合规自查

## 二、合规实操指引

1. **人员合规**：确保人员总数≥20人，中级职称占比≥25%，关键岗位满足年限要求；签订责任承诺书
2. **资质与备案**：对照13类逐项核查，2026年1月1日前完成备案
3. **设备与系统**：2026年6月底前完成防篡改功能排查；搭建/升级LIMS系统
4. **场地与采样**：为监测点位安装视频监控并与监管部门联网
