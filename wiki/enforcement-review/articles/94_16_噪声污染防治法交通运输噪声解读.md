# 噪声污染防治法交通运输噪声解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章规定交通运输噪声污染防治制度。明确机动车、铁路机车、城市轨道交通、机动船舶、航空器噪声排放标准，禁止机动车夜间鸣笛，禁止在市区使用高音喇叭；新建、改建、扩建公路、铁路、城市轨道交通穿越噪声敏感建筑物集中区域须设置隔声屏障；推行低噪声路面、隔声门窗等措施。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第50条 | 机动车噪声排放标准 |
| 第52条 | 禁止鸣笛 |
| 第55条 | 隔声屏障 |
| 第58条 | 低噪声路面 |
| 第60条 | 航空器噪声 |

## 四、合规要点
1. 机动车噪声排放符合标准
2. 禁止夜间鸣笛、市区使用高音喇叭
3. 公路、铁路穿越敏感区域须设置隔声屏障
4. 推行低噪声路面改造
5. 关注航空器、船舶噪声管控
