# 环境犯罪司法解释解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 最高人民法院、最高人民检察院 |

## 二、主要内容
司法解释规范环境犯罪案件审理。明确污染环境罪追诉标准（"严重污染环境"和"情节严重"的具体情形）、非法处置进口固体废物罪标准、环境监管失职罪标准、共犯认定、单位犯罪、自首立功、从重从轻情节、缓刑适用、罚金标准、生态环境修复责任。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第1条 | 污染环境罪追诉标准 |
| 第3条 | "情节严重"情形 |
| 第7条 | 共犯认定 |
| 第10条 | 单位犯罪 |
| 第15条 | 生态环境修复 |

## 四、合规要点
1. 关注污染环境罪追诉标准，防范刑事风险
2. 不得排放、倾倒、处置有毒有害污染物
3. 关注单位犯罪的双罚制（罚单位+罚责任人）
4. 涉刑案件主动配合调查，争取自首立功
5. 关注生态环境修复义务的刑事责任适用
