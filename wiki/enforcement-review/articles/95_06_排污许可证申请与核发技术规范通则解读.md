# 排污许可证申请与核发技术规范通则解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
通则规范排污许可证申请与核发技术要求。明确排污单位基本情况填报、生产设施及排放口规范化判定、污染物排放许可浓度和排放量核算方法、自行监测要求、环境管理台账和执行报告编制要求、可行技术参考等内容，为行业技术规范编制提供基础。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 适用范围 | 全行业排污单位 |
| 申请材料 | 排污许可证申请表、自行监测方案 |
| 核算方法 | 物料衡算、产排污系数法、实测法 |
| 监测要求 | 自行监测方案、监测频次 |
| 台账报告 | 电子台账、季度年度执行报告 |

## 四、合规要点
1. 按通则要求填报排污单位基本情况
2. 规范生产设施及排放口
3. 依法核算污染物排放许可浓度和排放量
4. 编制可行的自行监测方案
5. 按要求建立环境管理台账和提交执行报告
