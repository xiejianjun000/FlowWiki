# 环境行政处罚听证程序规定解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定规范环境行政处罚听证程序。明确听证适用情形（较大数额罚款、没收较大数额违法所得、责令停产停业、吊销许可证等）、听证申请（3日内提出）、听证通知（7日前）、听证主持人和参加人、听证程序（调查、申辩、质证、辩论）、听证笔录、听证期限等。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第5条 | 听证适用情形 |
| 第7条 | 听证申请 |
| 第9条 | 听证通知 |
| 第15条 | 听证主持人 |
| 第20条 | 听证程序 |

## 四、合规要点
1. 收到听证告知书后3日内提出听证申请
2. 依法委托代理人参加听证
3. 听证中行使申辩、质证、辩论权利
4. 关注听证笔录内容，确保记录准确
5. 听证结果作为处罚决定重要依据
