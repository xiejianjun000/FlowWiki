# 排污许可管理条例监督检查解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 国务院 |

## 二、主要内容
本章规定排污许可监督检查制度。明确生态环境部门开展许可证后监督检查方式（现场检查、台账核查、监测比对、数据审核等），建立执法监测、随机抽查、信用监管机制；排污单位应配合检查，如实提供资料；强化持证排污、按证排污、超许可排放监管。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第23条 | 监督检查方式 |
| 第25条 | 现场检查 |
| 第26条 | 台账核查 |
| 第27条 | 监测比对 |
| 第29条 | 信用监管 |

## 四、合规要点
1. 配合生态环境部门现场检查，如实提供资料
2. 做好台账记录，接受台账核查
3. 接受监测比对，确保数据真实
4. 关注信用监管结果对企业信用评级影响
5. 及时整改监管发现的问题
