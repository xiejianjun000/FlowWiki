# 排污许可管理条例刑事责任追究

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 国务院 |

## 二、主要内容
排污许可管理条例对违反本条例规定构成犯罪的行为，依法追究刑事责任。主要涉及《刑法》第338条污染环境罪、第339条非法处置进口固体废物罪、第408条环境监管失职罪。重点打击通过逃避监管方式排放有毒有害污染物、篡改伪造自动监测数据、非法排放持久性有机污染物等行为。

## 三、关键条款/案例要点
| 刑事罪名 | 适用情形 |
|---------|---------|
| 污染环境罪（338） | 排放有毒物质严重污染环境 |
| 非法处置固废罪（339） | 非法处置进口固废 |
| 环境监管失职罪（408） | 监管部门严重不负责任 |
| 提供虚假证明文件罪 | 第三方机构出具虚假报告 |
| 破坏计算机信息系统罪 | 篡改自动监测数据 |

## 四、合规要点
1. 不得排放、倾倒、处置有毒有害污染物
2. 不得篡改、伪造自动监测数据
3. 第三方机构不得出具虚假环境服务报告
4. 涉刑案件积极配合侦查，争取从宽处理
5. 关注"两高"司法解释关于环境犯罪追诉标准
