# 水污染防治法城镇水污染防治解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章规范城镇水污染防治。明确城镇污水集中处理设施建设、运营和监管，要求城镇污水集中处理设施的运营单位取得排污许可证；污泥处置应无害化；推进城镇雨污分流改造，提高污水收集率；建立城镇污水处理厂出水水质监督性监测制度。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第49条 | 城镇污水集中处理设施 |
| 第50条 | 排污许可 |
| 第51条 | 污泥处置 |
| 第52条 | 雨污分流 |
| 第53条 | 污水收集率 |

## 四、合规要点
1. 城镇污水集中处理运营单位依法取得排污许可证
2. 污水处理设施正常运行，确保出水达标
3. 污泥依法处置，不得随意倾倒
4. 推进雨污分流改造，提高收集率
5. 配合监督性监测，公开监测信息
