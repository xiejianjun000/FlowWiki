# 生态环境法典自然生态保护编解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人民代表大会 |

## 二、主要内容
自然生态保护编整合生物多样性保护、生态保护红线、自然保护地、森林、草原、湿地、荒漠等生态系统保护规范，构建"山水林田湖草沙一体化保护和系统治理"制度。法典确立生态保护红线刚性约束，完善自然保护地分类体系，强化生物遗传资源保护和外来入侵物种防控，建立生态保护补偿机制。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第80条 | 生态保护红线划定与管控 |
| 第85条 | 自然保护地体系 |
| 第90条 | 生物多样性保护 |
| 第95条 | 外来入侵物种防控 |
| 第100条 | 生态保护补偿 |
| 第105条 | 生态系统修复 |

## 四、合规要点
1. 涉及生态保护红线的项目须严格准入审查
2. 自然保护地内禁止不符合功能定位的开发活动
3. 涉及生物遗传资源利用须依法审批和惠益分享
4. 防范外来入侵物种引入和扩散风险
5. 生态破坏后应依法开展生态修复
