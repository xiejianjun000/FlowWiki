# 水污染防治法公益诉讼适用

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
水法对破坏水环境、损害社会公共利益的行为，建立环境公益诉讼制度。符合条件的社会组织（设区的市级以上人民政府民政部门登记、专门从事环保公益活动连续5年以上且无违法记录）可提起民事公益诉讼；检察机关在无适格社会组织或社会组织不提起时，可提起民事公益诉讼，也可对违法行使职权或不作为的行政机关提起行政公益诉讼。

## 三、关键条款/案例要点
| 适用要点 | 内容 |
|---------|------|
| 原告资格 | 社会组织、检察机关 |
| 适用情形 | 损害水环境公共利益 |
| 前置程序 | 检察机关公告30日 |
| 诉讼请求 | 停止侵害、排除妨碍、恢复原状、赔偿损失 |
| 与生态损害赔偿衔接 | 生态损害赔偿优先 |

## 四、合规要点
1. 关注社会组织环境公益诉讼风险，建立应诉准备
2. 检察机关公告30日内可启动生态损害赔偿磋商
3. 主动整改可减轻或免除公益诉讼追责
4. 关注行政公益诉讼对监管部门履职的督促作用
5. 公益诉讼赔偿金专项用于水生态修复
