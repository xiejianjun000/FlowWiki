# 排污许可管理条例排污管理解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 国务院 |

## 二、主要内容
本章规定排污许可证后管理要求。明确排污单位落实自行监测、环境管理台账记录、执行报告提交、信息公开义务；建立排污口规范化管理制度，不得私设排污口；按许可证要求运行污染防治设施；发生异常情况及时报告；开展排污许可证后管理自查。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第18条 | 自行监测 |
| 第19条 | 台账记录 |
| 第20条 | 执行报告 |
| 第21条 | 信息公开 |
| 第22条 | 排污口规范化 |

## 四、合规要点
1. 按自行监测方案开展监测，保存原始记录
2. 建立环境管理台账，如实记录运行情况
3. 按时提交季度、年度执行报告
4. 如实公开污染物排放信息
5. 排污口规范化设置，不得私设排污口
