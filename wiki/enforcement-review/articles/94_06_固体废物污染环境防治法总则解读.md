# 固体废物污染环境防治法总则解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
总则确立固废法立法目的、基本原则和监管体制。本法以保护和改善生态环境、防治固体废物污染环境为宗旨，规定减量化、资源化、无害化原则，污染者依法负责原则，明确生态环境部门统一监督管理、住建、卫生健康、农业农村等部门分工负责的体制，建立固废污染环境防治目标责任制和考核评价制度。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第1条 | 立法目的 |
| 第3条 | 减量化、资源化、无害化原则 |
| 第4条 | 污染者依法负责 |
| 第6条 | 监督管理体制 |
| 第7条 | 目标责任制和考核评价 |

## 四、合规要点
1. 产生固废的单位落实污染防治主体责任
2. 推行清洁生产，从源头减量
3. 依法分类管理工业固废、生活垃圾、建筑垃圾、农业固废、危废
4. 配合生态环境部门统一监督管理
5. 关注固废污染环境防治目标责任制考核
