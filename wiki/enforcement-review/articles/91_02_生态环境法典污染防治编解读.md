# 生态环境法典污染防治编解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人民代表大会 |

## 二、主要内容
污染防治编整合大气、水、土壤、固废、噪声、放射性等污染防治法律规范，构建统一的污染防治制度体系。法典明确排污许可作为固定污染源核心管理制度，统一污染物排放标准体系、监测制度、信息公开要求，强化源头防控和全过程监管，并对新污染物、温室气体排放管控作出原则性规定。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第30条 | 排污许可管理制度 |
| 第35条 | 污染物排放标准 |
| 第42条 | 污染源自动监测 |
| 第48条 | 新污染物管控 |
| 第52条 | 温室气体排放管控 |
| 第60条 | 重污染天气应对 |

## 四、合规要点
1. 依法取得排污许可证，按证排污、按证管理
2. 执行污染物排放标准，确保达标排放
3. 安装、使用污染物自动监测设备并联网
4. 关注新污染物管控要求，开展排查评估
5. 配合重污染天气应急响应措施
