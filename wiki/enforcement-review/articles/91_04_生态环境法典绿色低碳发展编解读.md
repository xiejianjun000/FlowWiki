# 生态环境法典绿色低碳发展编解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人民代表大会 |

## 二、主要内容
绿色低碳发展编确立"双碳"目标法律地位，构建以碳达峰碳中和为引领的绿色低碳发展制度体系。法典规定清洁生产、循环经济、节能降碳、可再生能源、绿色金融、绿色消费等制度安排，建立碳排放统计核算、碳排放权交易、碳足迹管理等机制，推动生产生活方式绿色转型。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第120条 | 碳达峰碳中和目标 |
| 第125条 | 清洁生产制度 |
| 第130条 | 循环经济促进 |
| 第135条 | 碳排放权交易 |
| 第140条 | 绿色金融 |
| 第145条 | 碳足迹管理 |

## 四、合规要点
1. 重点排放单位应纳入碳排放权交易并按期履约
2. 依法开展清洁生产审核，落实强制清洁生产要求
3. 开展碳排放核算与报告，确保数据真实准确
4. 推行绿色设计，构建循环经济产业链
5. 关注碳足迹管理要求，应对国际碳壁垒
