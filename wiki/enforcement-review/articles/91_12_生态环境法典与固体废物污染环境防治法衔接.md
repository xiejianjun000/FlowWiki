# 生态环境法典与固体废物污染环境防治法衔接

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人民代表大会 |

## 二、主要内容
法典整合吸收《固体废物污染环境防治法》，将其纳入污染防治编固废污染防治章节。法典强化工业固废、生活垃圾、建筑垃圾、农业固废、危险废物全过程监管，落实生产者责任延伸制度，建立危废经营许可、转移联单、跨省转移审批制度，推行"无废城市"建设和减量化、资源化、无害化原则。

## 三、关键条款/案例要点
| 衔接要点 | 内容 |
|---------|------|
| 工业固废 | 产生者责任、综合利用 |
| 危废经营 | 经营许可、转移联单 |
| 跨省转移 | 审批制度、就近处置 |
| 生活垃圾 | 分类投放、收费制度 |
| 建筑垃圾 | 减量化、资源化 |

## 四、合规要点
1. 工业固废产生者落实污染防治责任，建立台账
2. 危废经营单位须取得许可证，规范转移联单
3. 危废跨省转移依法报批，不得擅自转移
4. 依法分类投放生活垃圾，履行缴费义务
5. 严格履行生产者责任延伸制度
