# 土壤污染防治法预防和保护解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章规定土壤污染预防保护制度。明确土壤污染重点监管单位名录、土壤污染防治义务、地下储罐备案、有毒有害物质管控、农业投入品使用管控、农用地分类管理、建设用地土壤污染风险管控等制度。重点监管单位须建立土壤污染隐患排查制度，制定自行监测方案。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第20条 | 重点监管单位名录 |
| 第21条 | 重点监管单位义务 |
| 第22条 | 隐患排查制度 |
| 第23条 | 自行监测 |
| 第26条 | 农用地分类管理 |

## 四、合规要点
1. 重点监管单位建立土壤污染隐患排查制度
2. 制定自行监测方案并开展监测
3. 地下储罐依法备案
4. 涉有毒有害物质企业落实管控措施
5. 农用地分类管理，禁止不安全利用
