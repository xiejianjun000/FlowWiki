# 环境行政处罚案卷评查标准解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
标准规范环境行政处罚案卷评查工作。明确评查内容（主体合法性、事实证据、法律适用、程序合法性、文书制作、自由裁量）、评查标准（优秀、合格、不合格）、评查方式（自查、抽查、互查）、评查结果运用（问题整改、责任追究）、评查频次。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 评查内容 | 主体、事实、法律、程序、文书、裁量 |
| 评查标准 | 优秀、合格、不合格 |
| 评查方式 | 自查、抽查、互查 |
| 评查结果 | 问题整改、责任追究 |
| 评查频次 | 年度评查、专项评查 |

## 四、合规要点
1. 关注处罚案卷评查结果，及时整改问题
2. 案卷评查发现的问题可能成为复议诉讼理由
3. 关注案卷主体合法性和程序合法性
4. 关注法律适用准确性和自由裁量合理性
5. 评查结果影响执法人员绩效考核
