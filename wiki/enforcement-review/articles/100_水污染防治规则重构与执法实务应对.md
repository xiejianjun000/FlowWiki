# 从单行法到《生态环境法典》：水污染防治规则重构与执法实务应对

## 一、立法层级与体系重构：从单行专门法到法典化基本法的根本性转变

1. **法律位阶与效力层级根本差异**：原法由全国人大常委会制定（专项单行法），法典由全国人大制定（领域统领性基本法），法典效力覆盖生态保护、污染防治、绿色低碳发展全领域，水污染防治作为第二编"污染防治"下专项分编，执法无需再援引单行法。
2. **体例结构与监管覆盖全面重构**：原法8章103条，聚焦末端治理；法典设7章专项分编、60余条，新增流域协同治理、地下水精细化管控、农业农村面源污染等内容。
3. **原则与导向升级**：原法三大原则（预防为主、防治结合、综合治理），法典新增生态保护优先、损害担责、绿色低碳发展三大原则。
4. **核心立法考量**：破解单行法监管碎片化、权责脱节、适用混乱，落实"山水林田湖草沙一体化保护和系统治理"。

## 二、核心监管规则重构

1. **入河排污口监管统一**（第275-278条）：审批、监管、执法权统一归生态环境部门，新增三类违法情形（均为行为罚）。原法审批与执法主体分离的问题得到解决。
2. **地下水全链条闭环监管**（第287-293条）：7条专项条款，覆盖源头防控、过程管控、末端修复。新增泉域保护、含水层违规开采、报废矿井未封井回填三类禁止情形。
3. **工业废水稀释排放违法认定逻辑变化**（第298条、第1139条）：删除"逃避监管"主观前提，确立"客观行为归责"原则，只要稀释排放即构成违法。
4. **农业农村与饮用水水源保护**（第301-302条、第310-313条）：新增水产养殖尾水超标排放、灌溉渠道违规排污、水源地违禁品使用、未开展污染风险评估四类违法情形。

## 三、法律责任体系优化

1. **处罚额度差异化精准调整**（第1138条）：严重违法行为处罚翻倍提升，一般违法保持原尺度，统一排污许可处罚标准。
2. **新增罚则填补空白**（第1139条）：新增稀释排放、消防废物直排水体、农业灌溉渠道违规排污、地下水新增违法等五项独立处罚条款。
3. **处罚通用规则全域统一**：按日计罚（第1060条）设为全领域通用规则；双罚制（第1120条）扩展至全领域严重违法行为；轻微违法不予处罚规则（第1056条）明确化。
4. **生态损害追责与行政处罚衔接**（第17条、第1150条）：行政处罚同时启动生态环境损害赔偿程序。

## 四、执法实务应对

1. **新旧法衔接**：依《立法法》"法不溯及既往、从旧兼从轻"原则，以2026年8月15日为分界点。
2. **执法主体职责边界**：入河排污口统一归生态环境部门，流域机构负责跨区域执法。
3. **体系化法律适用**：优先适用总则通用制度，衔接生态保护编、绿色低碳发展编。
4. **举证标准优化**：稀释排放无需证明主观故意；共用排污口需查清各主体责任。
