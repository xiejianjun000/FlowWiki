# 固体废物污染环境防治法生活垃圾解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章规定生活垃圾污染防治制度。明确生活垃圾分类制度（可回收物、厨余垃圾、有害垃圾、其他垃圾），推行源头减量、分类投放、分类收集、分类运输、分类处理；建立生活垃圾处理收费制度；明确生产者责任延伸制度，限制过度包装、一次性塑料制品使用。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第43条 | 生活垃圾分类制度 |
| 第44条 | 分类投放 |
| 第45条 | 分类收集运输 |
| 第46条 | 处理收费 |
| 第49条 | 限制过度包装 |

## 四、合规要点
1. 产生生活垃圾的单位和个人依法分类投放
2. 配合生活垃圾分类收集和运输
3. 依法缴纳生活垃圾处理费
4. 限制过度包装，减少一次性塑料制品使用
5. 履行生产者责任延伸义务
