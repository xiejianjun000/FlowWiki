# 排污许可证环境管理台账编制技术规范解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规范排污许可证环境管理台账编制技术要求。明确台账分类（电子台账、纸质台账）、记录内容（基本信息、生产设施运行、污染防治设施运行、监测、固废、风险防范等）、记录频次、保存期限、归档要求等。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 台账分类 | 电子台账、纸质台账 |
| 记录内容 | 设施运行、监测、固废等 |
| 记录频次 | 实时、日、月、季度等 |
| 保存期限 | 不少于3年 |
| 归档要求 | 按年度归档 |

## 四、合规要点
1. 建立环境管理台账制度，如实记录
2. 按要求记录生产设施和污染防治设施运行情况
3. 台账记录频次符合规定
4. 保存期限不少于3年
5. 按年度归档，方便查阅和监管检查
