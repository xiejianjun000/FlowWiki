# 土壤污染防治法规划标准解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章规定土壤污染防治规划、土壤环境质量标准、土壤污染风险管控标准体系。国务院生态环境主管部门会同有关部门制定土壤环境质量标准、土壤污染风险管控标准，省级政府可制定地方标准。建立土壤环境信息共享机制，编制土壤污染防治规划，开展土壤污染状况详查。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第10条 | 土壤污染防治规划 |
| 第12条 | 土壤环境质量标准 |
| 第13条 | 土壤污染风险管控标准 |
| 第14条 | 土壤环境信息共享 |
| 第15条 | 土壤污染状况详查 |

## 四、合规要点
1. 关注土壤环境质量标准变化
2. 重点监管单位执行土壤污染风险管控标准
3. 配合土壤污染状况详查和信息共享
4. 关注地方标准严于国家标准的情况
5. 落实土壤污染防治规划要求
