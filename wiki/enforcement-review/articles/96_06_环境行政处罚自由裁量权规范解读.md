# 环境行政处罚自由裁量权规范解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规范环境行政处罚自由裁量权行使。明确自由裁量考虑因素（违法行为性质、情节、后果、主观过错、整改情况）、裁量基准（按违法行为类别设定处罚幅度）、裁量规则（从轻、减轻、从重、不予处罚情形）、集体讨论（重大复杂案件）、裁量说明理由等。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 考虑因素 | 性质、情节、后果、主观过错 |
| 裁量基准 | 按违法行为设定幅度 |
| 从轻减轻 | 主动消除、配合调查、立功 |
| 从重处罚 | 拒不改正、伪造证据、暴力抗拒 |
| 不予处罚 | 轻微并及时纠正、无主观过错 |

## 四、合规要点
1. 主动消除或减轻违法行为后果，争取从轻处罚
2. 配合调查，如实陈述，争取从轻处罚
3. 关注裁量基准，对处罚幅度提出合理异议
4. 对不予处罚情形依法主张
5. 关注集体讨论决定的程序合法性
