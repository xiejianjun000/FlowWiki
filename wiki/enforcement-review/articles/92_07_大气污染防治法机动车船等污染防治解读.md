# 大气污染防治法机动车船等污染防治解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
本章管控机动车、非道路移动机械、船舶的大气污染物排放。规定机动车排放标准、在用车排放检测、油品质量监管、I/M制度（检测/维护）、黄标车淘汰、非道路移动机械编码登记、船舶排放控制区、岸电使用等要求，推动新能源车船推广。

## 三、关键条款/案例要点
| 条款 | 核心内容 |
|------|---------|
| 第50条 | 机动车排放标准 |
| 第53条 | 在用车排放检测 |
| 第58条 | 油品质量监管 |
| 第61条 | 非道路移动机械管控 |
| 第64条 | 船舶排放控制区 |

## 四、合规要点
1. 机动车出厂前进行排放检测并达标
2. 在用车定期接受排放检测，超标维修或淘汰
3. 油品生产销售企业保证油品质量
4. 非道路移动机械进行编码登记和使用管控
5. 船舶进入排放控制区使用合规燃油或岸电
