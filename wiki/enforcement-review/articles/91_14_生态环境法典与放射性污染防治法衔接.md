# 生态环境法典与放射性污染防治法衔接

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人民代表大会 |

## 二、主要内容
法典整合吸收《放射性污染防治法》，将其纳入污染防治编放射性污染防治章节。法典保留核设施、核技术应用、铀（钍）矿和伴生放射性矿、放射性废物等专项监管制度，强化放射性同位素与射线装置安全许可、放射源分类管理、放射性废物处置监管，建立核事故应急体系和辐射环境监测网络。

## 三、关键条款/案例要点
| 衔接要点 | 内容 |
|---------|------|
| 核设施 | 选址、建造、运行、退役许可 |
| 射线装置 | 辐射安全许可证、分类管理 |
| 放射源 | I-V类分类管理、备案登记 |
| 放射性废物 | 处置许可、监测管理 |
| 核应急 | 应急计划、应急响应 |

## 四、合规要点
1. 涉核单位依法取得辐射安全许可证
2. 放射源使用、贮存、运输落实安全防护措施
3. 放射性废物依法送交有资质单位处置
4. 配合辐射环境监测和监督性监测
5. 建立核与辐射事故应急预案并演练
