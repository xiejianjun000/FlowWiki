# 排污许可证变更延续解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 国务院 |

## 二、主要内容
排污许可证事项发生变化时，排污单位应当依法申请变更。变更情形包括：排污单位名称变更、法定代表人变更、排污口数量或位置变化、污染物种类或排放量变化、污染防治设施变化等。排污许可证有效期5年，到期前30日应当申请延续。

## 三、关键条款/案例要点
| 要点 | 内容 |
|------|------|
| 变更情形 | 名称变更、排污口变化、设施变化等 |
| 变更申请 | 提交变更申请材料 |
| 变更审批 | 生态环境部门审核 |
| 有效期 | 5年 |
| 延续申请 | 到期前30日申请延续 |

## 四、合规要点
1. 排污事项变化前依法申请变更
2. 提交完整变更申请材料
3. 许可证到期前30日申请延续
4. 不得擅自变更排污事项
5. 关注变更延续审批进度
