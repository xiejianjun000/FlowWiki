# 生态环境法典与环境影响评价法衔接

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人民代表大会 |

## 二、主要内容
法典整合环境影响评价法律制度，将环评作为生态环境预防性制度的核心。法典保留建设项目环评、规划环评、战略环评三层架构，强化环评与排污许可、三同时制度的衔接，明确重大变动须重新报批环评，统一环评文件分类管理（报告书/报告表/登记表），完善公众参与和听证程序。

## 三、关键条款/案例要点
| 衔接要点 | 内容 |
|---------|------|
| 环评分类 | 报告书/报告表/登记表三级管理 |
| 重大变动 | 须重新报批环评 |
| 公众参与 | 报告书项目强制公参 |
| 与排污许可衔接 | 环评批复作为申领许可证依据 |
| 与三同时衔接 | 环保设施与主体工程同步 |

## 四、合规要点
1. 建设项目开工前依法完成环评审批
2. 项目建设发生重大变动须重新报批环评
3. 环评批复文件作为后续排污许可申领依据
4. 严格落实环保设施"三同时"要求
5. 公众参与环节依法公开信息、组织听证
