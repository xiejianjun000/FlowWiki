# 水污染防治法与排污许可衔接

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 法规解读 |
| 适用范围 | 全国 |
| 发布机关 | 全国人大常委会 |

## 二、主要内容
水法与《排污许可管理条例》形成"基本法+行政法规"双层架构，排污许可作为水污染物排放监管核心制度。水法规定企业事业单位和其他生产经营者直接或间接向水体排放工业废水和医疗污水的，应当取得排污许可证；城镇污水集中处理设施运营单位也应取得排污许可证；排污许可制度覆盖所有水固定污染源。

## 三、关键条款/案例要点
| 衔接要点 | 内容 |
|---------|------|
| 适用范围 | 所有水固定污染源 |
| 分类管理 | 重点管理、简化管理、登记管理 |
| 许可事项 | 排放口、污染物种类、浓度、排放量 |
| 执法依据 | 排污许可证作为执法基础 |
| 无证排污 | 责令改正并处罚款 |

## 四、合规要点
1. 工业废水和医疗污水排放单位依法取得排污许可证
2. 城镇污水集中处理运营单位取得排污许可证
3. 按许可证要求开展自行监测和台账记录
4. 排放口数量、位置、污染物种类变化须变更
5. 配合许可证后监管执法检查
