# 生态环境损害赔偿磋商案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部、最高人民法院 |

## 二、主要内容
本汇编收集生态环境损害赔偿磋商典型案例，涵盖大气污染生态损害赔偿磋商、水污染生态损害赔偿磋商、土壤污染生态损害赔偿磋商、固废污染生态损害赔偿磋商、生态破坏损害赔偿磋商等典型情形，分析磋商启动、磋商程序、磋商协议、协议司法确认、协议履行。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 大气污染 | 磋商 |
| 水污染 | 磋商 |
| 土壤污染 | 磋商 |
| 固废污染 | 磋商 |
| 生态破坏 | 磋商 |

## 四、合规要点
1. 生态环境损害发生后可启动磋商程序
2. 主动参与磋商可减轻诉讼风险
3. 磋商协议须明确修复和赔偿内容
4. 磋商协议可申请司法确认
5. 磋商协议具有法律效力，须履行
