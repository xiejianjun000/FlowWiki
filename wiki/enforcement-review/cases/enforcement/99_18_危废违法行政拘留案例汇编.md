# 危废违法行政拘留案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部、公安部 |

## 二、主要内容
本汇编收集危废违法行政拘留适用典型案例，涵盖无证经营危废拘留、危废非法转移拘留、危废非法处置拘留、危废跨省转移未经审批拘留、危废贮存量超标拘留等典型情形，分析移送程序、拘留期限、适用对象，部分案件涉及污染环境罪追究。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 无证经营 | 行政拘留 |
| 非法转移 | 行政拘留 |
| 非法处置 | 行政拘留 |
| 跨省未审批 | 行政拘留 |
| 贮存超标 | 行政拘留 |

## 四、合规要点
1. 危废经营单位必须取得许可证
2. 危废转移依法报批，使用电子联单
3. 危废依法处置，不得倾倒、堆放
4. 关注主要负责人和直接责任人员的个人责任
5. 涉嫌犯罪的依法移送公安机关
