# 固废违法处置按日连续处罚案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集固废违法处置按日连续处罚典型案例，涵盖工业固废违法倾倒、生活垃圾违规处置、建筑垃圾非法运输、农业固废乱堆乱放、危废不规范贮存、危废非法转移处置等典型情形，分析违法事实、复查情况、计罚天数和金额，部分案件涉及高额罚款和刑事责任。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 工业固废 | 违法倾倒 |
| 生活垃圾 | 违规处置 |
| 建筑垃圾 | 非法运输 |
| 农业固废 | 乱堆乱放 |
| 危废贮存 | 不规范贮存 |

## 四、合规要点
1. 依法处置固废，建立台账
2. 收到责令改正决定后立即整改
3. 整改完成后主动申请复查
4. 关注固废违法处置高额罚款风险
5. 涉嫌犯罪的依法移送公安机关
