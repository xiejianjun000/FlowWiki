# 森林生态损害赔偿案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 国家林业和草原局、最高人民法院 |

## 二、主要内容
本汇编收集森林生态损害赔偿典型案例，涵盖滥伐林木生态损害赔偿、盗伐林木生态损害赔偿、违法占用林地生态损害赔偿、森林火灾生态损害赔偿、毁坏珍贵树木生态损害赔偿等典型情形，分析损害认定、赔偿范围、磋商程序、诉讼结果、资金使用。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 滥伐林木 | 生态损害赔偿 |
| 盗伐林木 | 生态损害赔偿 |
| 占用林地 | 生态损害赔偿 |
| 森林火灾 | 生态损害赔偿 |
| 毁坏珍贵树木 | 生态损害赔偿 |

## 四、合规要点
1. 森林破坏造成生态损害须承担修复和赔偿
2. 主动参与磋商可减轻诉讼风险
3. 修复方案须科学可行
4. 赔偿资金专项用于森林生态修复
5. 关注损害认定和赔偿范围
