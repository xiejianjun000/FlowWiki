# 生态保护执法典型案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集生态保护执法典型案例，涵盖生态保护红线违法占用、自然保护区内违法开发、生物多样性破坏、非法采伐、非法捕捞、湿地破坏、草原退化、外来入侵物种引入等典型违法情形，分析违法事实、查处过程、处罚依据和启示。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 生态红线 | 违法占用 |
| 自然保护区 | 违法开发 |
| 生物多样性 | 破坏栖息地 |
| 非法采伐 | 滥伐林木 |
| 湿地破坏 | 违法占用 |

## 四、合规要点
1. 项目选址避开生态保护红线
2. 自然保护区内禁止违法开发活动
3. 涉及生物多样性影响须开展评估
4. 不得非法采伐林木、捕捞渔业资源
5. 防范外来入侵物种引入
