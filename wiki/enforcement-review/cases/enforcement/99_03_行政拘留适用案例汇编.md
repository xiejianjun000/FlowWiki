# 行政拘留适用案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部、公安部 |

## 二、主要内容
本汇编收集行政拘留适用典型案例，涵盖未取得排污许可证排污拘留、通过逃避监管方式排放拘留、伪造篡改监测数据拘留、不正常运行污染防治设施拘留等典型情形，分析适用情形、移送程序、拘留期限、适用对象（企业主要负责人和直接责任人员）。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 无证排污 | 拘留 |
| 逃避监管 | 拘留 |
| 监测造假 | 拘留 |
| 设施不运行 | 拘留 |
| 综合适用 | 多措施 |

## 四、合规要点
1. 不得未取得排污许可证排放污染物
2. 不得通过逃避监管方式排放污染物
3. 监测数据真实、完整、准确
4. 关注主要负责人和直接责任人员的个人责任
5. 涉及移送公安的案件应积极配合调查
