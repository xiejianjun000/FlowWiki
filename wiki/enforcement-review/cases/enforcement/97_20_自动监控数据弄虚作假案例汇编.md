# 自动监控数据弄虚作假案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集自动监控数据弄虚作假执法典型案例，涵盖自动监测设备未正常运行、篡改自动监测数据、伪造自动监测数据、自动监测设备擅自拆除或闲置、稀释排放干扰监测、自动监测设备未联网、自动监测数据传输造假等典型违法情形，多涉及按日连续处罚、行政拘留和刑事责任追究。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 设备未运行 | 自动监测设备停运 |
| 篡改数据 | 修改监测参数 |
| 伪造数据 | 伪造监测记录 |
| 设备拆除 | 擅自拆除或闲置 |
| 稀释排放 | 干扰监测 |

## 四、合规要点
1. 自动监测设备正常运行，不得擅自停运
2. 不得篡改、伪造自动监测数据
3. 不得擅自拆除或闲置自动监测设备
4. 不得稀释排放干扰监测
5. 自动监测设备依法联网，数据真实传输
