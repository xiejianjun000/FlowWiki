# 放射环境执法典型案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集放射环境执法典型案例，涵盖未取得辐射安全许可证使用放射源、放射源丢失被盗、放射源非法转移处置、辐射剂量超标、放射工作人员未培训、辐射监测数据造假、核设施违法排放、放射性废物违法处置等典型违法情形。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 辐射安全许可 | 无证使用放射源 |
| 放射源管理 | 丢失被盗 |
| 非法转移 | 未审批转移 |
| 剂量超标 | 超标辐射 |
| 监测造假 | 数据篡改 |

## 四、合规要点
1. 涉核单位依法取得辐射安全许可证
2. 放射源使用、贮存、运输落实安全防护
3. 放射源丢失被盗立即报告
4. 放射性废物依法处置
5. 放射工作人员依法培训
