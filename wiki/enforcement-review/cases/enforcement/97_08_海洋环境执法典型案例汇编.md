# 海洋环境执法典型案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部、中国海警局 |

## 二、主要内容
本汇编收集海洋环境执法典型案例，涵盖陆源排污口违法、海洋工程未批先建、海岸工程违法、船舶溢油事故、海洋倾废违法、海洋石油平台违法排放、海上养殖污染、海洋保护区违法等典型违法情形，涉及生态环境部门和中国海警局协同执法。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 陆源排污 | 入海排污口违法 |
| 海洋工程 | 未批先建 |
| 船舶溢油 | 事故污染 |
| 海洋倾废 | 违法倾倒 |
| 海洋平台 | 违法排放 |

## 四、合规要点
1. 入海排污口依法备案并规范排放
2. 海洋工程依法取得环评批复
3. 船舶配备防污设备，禁止违法排放
4. 海洋倾废依法取得许可
5. 海洋石油平台规范运行
