# 土壤环境执法典型案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集土壤环境执法典型案例，涵盖土壤污染重点监管单位未履行义务、向农用地排放有毒有害物质超标、未按规定开展土壤污染状况调查、未按规定实施风险管控和修复、工业企业搬迁地块未调查、第三方机构出具虚假报告等典型违法情形。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 重点监管单位 | 未履义务 |
| 农用地 | 排放超标 |
| 工业搬迁 | 未开展调查 |
| 风险管控 | 未按规定实施 |
| 第三方机构 | 虚假报告 |

## 四、合规要点
1. 土壤污染重点监管单位履行防治义务
2. 不得向农用地排放有毒有害物质超标
3. 工业企业搬迁依法开展土壤污染状况调查
4. 风险管控和修复方案科学可行
5. 第三方机构不得出具虚假报告
