# 湿地生态损害赔偿案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 国家林业和草原局、最高人民法院 |

## 二、主要内容
本汇编收集湿地生态损害赔偿典型案例，涵盖违法占用湿地生态损害赔偿、破坏湿地植被生态损害赔偿、湿地水体污染生态损害赔偿、湿地围垦生态损害赔偿、湿地采砂采矿生态损害赔偿等典型情形，分析损害认定、赔偿范围、磋商程序、诉讼结果。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 占用湿地 | 生态损害赔偿 |
| 破坏植被 | 生态损害赔偿 |
| 水体污染 | 生态损害赔偿 |
| 围垦湿地 | 生态损害赔偿 |
| 采砂采矿 | 生态损害赔偿 |

## 四、合规要点
1. 湿地破坏造成生态损害须承担修复和赔偿
2. 主动参与磋商可减轻诉讼风险
3. 修复方案须科学可行
4. 赔偿资金专项用于湿地生态修复
5. 关注损害认定和赔偿范围
