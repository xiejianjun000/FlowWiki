# 自动监控数据弄虚作假限产停产案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集自动监控数据弄虚作假限产停产适用典型案例，涵盖自动监测设备未正常运行限产停产、篡改自动监测数据限产停产、伪造自动监测数据限产停产、自动监测设备擅自拆除或闲置限产停产、稀释排放干扰监测限产停产等典型情形。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 设备未运行 | 限产停产 |
| 篡改数据 | 限产停产 |
| 伪造数据 | 限产停产 |
| 设备拆除 | 限产停产 |
| 稀释排放 | 限产停产 |

## 四、合规要点
1. 自动监测设备正常运行，不得擅自停运
2. 不得篡改、伪造自动监测数据
3. 不得擅自拆除或闲置自动监测设备
4. 不得稀释排放干扰监测
5. 整改完成后申请解除限产停产
