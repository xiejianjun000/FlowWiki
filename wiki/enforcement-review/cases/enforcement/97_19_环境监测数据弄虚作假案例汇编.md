# 环境监测数据弄虚作假案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集环境监测数据弄虚作假执法典型案例，涵盖监测机构出具虚假报告、采样不规范、实验室数据造假、监测委托方伪造数据、企业自行监测数据造假、第三方治理机构篡改数据、监测仪器未经检定等典型违法情形，部分案件涉及提供虚假证明文件罪和污染环境罪。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 监测机构 | 出具虚假报告 |
| 采样不规范 | 采样程序违法 |
| 实验室造假 | 数据篡改 |
| 自行监测造假 | 企业伪造数据 |
| 第三方治理 | 篡改数据 |

## 四、合规要点
1. 监测机构依法取得资质，规范操作
2. 采样程序合法规范，记录完整
3. 实验室数据真实、完整、准确
4. 自行监测数据不得造假
5. 第三方治理机构不得篡改数据
