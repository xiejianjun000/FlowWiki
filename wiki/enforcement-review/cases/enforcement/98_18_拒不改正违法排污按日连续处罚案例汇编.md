# 拒不改正违法排污按日连续处罚案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集拒不改正违法排污按日连续处罚典型案例，涵盖责令改正后复查仍超标排放、责令改正后继续逃避监管排放、责令改正后拒不整改、虚假整改、整改不到位等典型情形，分析违法事实、复查情况、计罚天数和金额，重点关注计罚天数认定。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 复查仍超标 | 拒不改正 |
| 继续逃避监管 | 拒不改正 |
| 拒不整改 | 不配合 |
| 虚假整改 | 应付检查 |
| 整改不到位 | 不彻底 |

## 四、合规要点
1. 收到责令改正决定后立即整改
2. 整改完成后主动申请复查
3. 整改应彻底，不得虚假整改
4. 复查合格后保留整改证据
5. 关注计罚天数认定和救济途径
