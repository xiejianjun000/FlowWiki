# 固废污染生态环境损害赔偿案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部、最高人民法院 |

## 二、主要内容
本汇编收集固废污染生态环境损害赔偿典型案例，涵盖工业固废违法倾倒生态损害赔偿、危废非法处置生态损害赔偿、生活垃圾违规处置生态损害赔偿、建筑垃圾非法运输生态损害赔偿、农业固废乱堆乱放生态损害赔偿等典型情形。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 工业固废 | 违法倾倒生态损害赔偿 |
| 危废 | 非法处置生态损害赔偿 |
| 生活垃圾 | 违规处置生态损害赔偿 |
| 建筑垃圾 | 非法运输生态损害赔偿 |
| 农业固废 | 乱堆乱放生态损害赔偿 |

## 四、合规要点
1. 固废污染造成生态损害须承担修复和赔偿
2. 主动参与磋商可减轻诉讼风险
3. 修复方案须科学可行
4. 赔偿资金专项用于固废污染修复
5. 关注损害认定和赔偿范围
