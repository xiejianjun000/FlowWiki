# 查封扣押复议诉讼案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集查封扣押复议诉讼典型案例，涵盖对查封扣押决定不服申请复议、提起诉讼的案件，分析复议诉讼请求、争议焦点（适用情形、决定程序、实施对象、期限要求）、复议决定、诉讼判决，为企业应对查封扣押提供参考。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 复议申请 | 请求解除查封扣押 |
| 诉讼提起 | 请求撤销查封扣押 |
| 争议焦点 | 适用情形、程序合法性 |
| 复议决定 | 维持、撤销、变更 |
| 诉讼判决 | 维持、撤销、变更 |

## 四、合规要点
1. 收到查封扣押决定后60日内申请复议或6个月内提起诉讼
2. 复议诉讼请求应明确具体
3. 关注适用情形和程序合法性
4. 关注实施对象和期限要求
5. 依法应对查封扣押决定
