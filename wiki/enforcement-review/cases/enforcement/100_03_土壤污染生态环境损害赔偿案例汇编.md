# 土壤污染生态环境损害赔偿案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部、最高人民法院 |

## 二、主要内容
本汇编收集土壤污染生态环境损害赔偿典型案例，涵盖工业企业搬迁地块土壤污染生态损害赔偿、农用地污染生态损害赔偿、危废渗漏土壤污染生态损害赔偿、化学品泄漏土壤污染生态损害赔偿等典型情形，分析损害认定、赔偿范围、磋商程序、诉讼结果、资金使用。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 工业搬迁 | 土壤污染生态损害赔偿 |
| 农用地 | 污染生态损害赔偿 |
| 危废渗漏 | 土壤污染生态损害赔偿 |
| 化学品泄漏 | 土壤污染生态损害赔偿 |
| 综合适用 | 磋商+诉讼 |

## 四、合规要点
1. 土壤污染造成生态损害须承担修复和赔偿
2. 主动参与磋商可减轻诉讼风险
3. 修复方案须科学可行
4. 赔偿资金专项用于土壤修复
5. 关注损害认定和赔偿范围
