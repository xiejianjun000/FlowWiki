# 生态环境损害赔偿资金管理案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部、财政部、最高人民法院 |

## 二、主要内容
本汇编收集生态环境损害赔偿资金管理典型案例，涵盖赔偿资金收缴、资金账户管理、资金使用审批、资金用于生态修复、资金使用监督、资金结余处理等典型情形，分析资金管理制度、使用程序、监督机制、违规处理，为赔偿资金规范管理提供参考。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 资金收缴 | 赔偿金缴纳 |
| 账户管理 | 专项账户 |
| 使用审批 | 修复项目审批 |
| 资金使用 | 生态修复 |
| 资金监督 | 审计监督 |

## 四、合规要点
1. 生态环境损害赔偿资金依法收缴
2. 资金纳入专项账户管理，专款专用
3. 资金使用须审批，用于生态修复
4. 资金使用接受监督和审计
5. 资金结余按规定处理
