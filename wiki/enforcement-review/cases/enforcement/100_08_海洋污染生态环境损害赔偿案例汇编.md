# 海洋污染生态环境损害赔偿案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部、中国海警局、最高人民法院 |

## 二、主要内容
本汇编收集海洋污染生态环境损害赔偿典型案例，涵盖船舶溢油事故生态损害赔偿、海洋工程违法排放生态损害赔偿、陆源排污口违法生态损害赔偿、海洋倾废违法生态损害赔偿、海洋石油平台违法排放生态损害赔偿等典型情形。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 船舶溢油 | 事故生态损害赔偿 |
| 海洋工程 | 违法排放生态损害赔偿 |
| 陆源排污 | 违法生态损害赔偿 |
| 海洋倾废 | 违法生态损害赔偿 |
| 海洋平台 | 违法排放生态损害赔偿 |

## 四、合规要点
1. 海洋污染造成生态损害须承担修复和赔偿
2. 主动参与磋商可减轻诉讼风险
3. 修复方案须科学可行
4. 赔偿资金专项用于海洋生态修复
5. 关注损害认定和赔偿范围
