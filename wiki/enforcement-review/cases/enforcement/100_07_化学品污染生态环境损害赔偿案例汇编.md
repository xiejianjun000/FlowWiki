# 化学品污染生态环境损害赔偿案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部、最高人民法院 |

## 二、主要内容
本汇编收集化学品污染生态环境损害赔偿典型案例，涵盖危险化学品事故生态损害赔偿、新化学物质违法排放生态损害赔偿、持久性有机污染物排放生态损害赔偿、化学品泄漏生态损害赔偿等典型情形，分析损害认定、赔偿范围、磋商程序、诉讼结果。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 危险化学品事故 | 生态损害赔偿 |
| 新化学物质 | 违法排放生态损害赔偿 |
| 持久性有机物 | 排放生态损害赔偿 |
| 化学品泄漏 | 生态损害赔偿 |
| 综合适用 | 磋商+诉讼 |

## 四、合规要点
1. 化学品污染造成生态损害须承担修复和赔偿
2. 主动参与磋商可减轻诉讼风险
3. 修复方案须科学可行
4. 赔偿资金专项用于化学品污染治理
5. 关注损害认定和赔偿范围
