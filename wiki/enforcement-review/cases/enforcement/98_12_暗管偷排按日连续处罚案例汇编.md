# 暗管偷排按日连续处罚案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集暗管偷排按日连续处罚典型案例，涵盖企业私设暗管排放废水、利用渗井渗坑排放、利用裂隙溶洞排放、私设排污口偷排等典型情形，多涉及按日连续处罚、查封扣押、限产停产、行政拘留、刑事责任追究等综合措施适用，部分案件涉及污染环境罪。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 私设暗管 | 偷排废水 |
| 渗井渗坑 | 排放污染物 |
| 裂隙溶洞 | 排放污染物 |
| 私设排污口 | 偷排 |
| 综合追责 | 多措施适用 |

## 四、合规要点
1. 不得私设暗管排放废水
2. 不得利用渗井、渗坑、裂隙、溶洞排放污染物
3. 不得私设排污口偷排
4. 关注逃避监管方式排放的综合追责
5. 涉嫌犯罪的依法移送公安机关
