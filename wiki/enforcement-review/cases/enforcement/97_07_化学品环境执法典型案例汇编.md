# 化学品环境执法典型案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集化学品环境执法典型案例，涵盖未办理危险化学品环境管理登记、新化学物质未登记投产、持久性有机污染物违法使用、高关注化学品未落实风险管控、化学品环境污染事故应急不到位、化学品非法转移处置等典型违法情形。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 危化品登记 | 未办理登记 |
| 新化学物质 | 未登记投产 |
| 持久性有机物 | 违法使用 |
| 高关注化学品 | 未落实管控 |
| 事故应急 | 不到位 |

## 四、合规要点
1. 危险化学品生产使用企业依法办理环境管理登记
2. 新化学物质投产前完成环境管理登记
3. 持久性有机污染物排放企业落实淘汰替代
4. 高关注化学品落实风险管控措施
5. 建立化学品环境污染事故应急预案
