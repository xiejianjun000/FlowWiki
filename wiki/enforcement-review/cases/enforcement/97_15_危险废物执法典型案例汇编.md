# 危险废物执法典型案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集危险废物执法典型案例，涵盖无证经营危废、危废非法转移、危废非法处置、危废跨省转移未经审批、危废联单不规范、危废贮存量超标、危废混堆、危废非法倾倒、危废鉴别造假等典型违法情形，部分案件涉及污染环境罪追究。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 无证经营 | 未取得许可证 |
| 非法转移 | 跨省未审批 |
| 非法处置 | 倾倒、堆放 |
| 联单不规范 | 未使用电子联单 |
| 鉴别造假 | 虚假鉴别 |

## 四、合规要点
1. 危废经营单位必须取得许可证
2. 危废转移依法报批，使用电子联单
3. 危废依法处置，不得倾倒、堆放
4. 跨省转移依法报批
5. 危废鉴别科学规范，不得造假
