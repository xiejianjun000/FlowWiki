# 生态环境损害赔偿诉讼案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 最高人民法院 |

## 二、主要内容
本汇编收集生态环境损害赔偿诉讼典型案例，涵盖大气污染生态损害赔偿诉讼、水污染生态损害赔偿诉讼、土壤污染生态损害赔偿诉讼、固废污染生态损害赔偿诉讼、生态破坏损害赔偿诉讼等典型情形，分析诉讼请求、争议焦点、举证责任、判决结果、与公益诉讼的衔接。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 大气污染 | 诉讼 |
| 水污染 | 诉讼 |
| 土壤污染 | 诉讼 |
| 固废污染 | 诉讼 |
| 生态破坏 | 诉讼 |

## 四、合规要点
1. 磋商不成可提起生态环境损害赔偿诉讼
2. 诉讼请求应明确修复和赔偿内容
3. 关注举证责任和争议焦点
4. 关注与公益诉讼的衔接
5. 判决结果具有法律效力，须履行
