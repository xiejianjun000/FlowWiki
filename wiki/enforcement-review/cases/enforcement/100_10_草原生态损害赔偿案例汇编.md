# 草原生态损害赔偿案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 国家林业和草原局、最高人民法院 |

## 二、主要内容
本汇编收集草原生态损害赔偿典型案例，涵盖违法开垦草原生态损害赔偿、过度放牧草原退化生态损害赔偿、违法占用草原生态损害赔偿、草原火灾生态损害赔偿、非法采挖草原植物生态损害赔偿等典型情形。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 违法开垦 | 草原生态损害赔偿 |
| 过度放牧 | 草原退化生态损害赔偿 |
| 占用草原 | 生态损害赔偿 |
| 草原火灾 | 生态损害赔偿 |
| 非法采挖 | 草原植物生态损害赔偿 |

## 四、合规要点
1. 草原破坏造成生态损害须承担修复和赔偿
2. 主动参与磋商可减轻诉讼风险
3. 修复方案须科学可行
4. 赔偿资金专项用于草原生态修复
5. 关注损害认定和赔偿范围
