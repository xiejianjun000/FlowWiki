# 环评违法按日连续处罚案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

## 二、主要内容
本汇编收集环评违法按日连续处罚典型案例，涵盖未批先建、未验先投、环评文件造假、重大变动未重新报批、登记表备案弄虚作假、规划环评未落实等典型情形，分析违法事实、复查情况、计罚天数和金额，部分案件涉及环评机构弄虚作假追责。

## 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 未批先建 | 环评未批复开工 |
| 未验先投 | 未验收投产 |
| 环评造假 | 文件弄虚作假 |
| 重大变动 | 未重新报批 |
| 规划环评 | 未落实 |

## 四、合规要点
1. 建设项目环评批复后方可开工建设
2. 环保设施验收后方可投入生产
3. 环评文件应真实、准确
4. 重大变动须重新报批环评
5. 关注环评机构弄虚作假追责
