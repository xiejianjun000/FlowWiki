# source_path: /Users/mac/企业合规AI管理知识库/flowwiki/raw/inbox/案例_排污许可_超许可排放.txt

案例编号：CASE-PWXK-2024-002
案例类型：行政处罚
行业：钢铁

【当事人信息】
处罚对象：河北鑫达钢铁集团有限公司（以下简称"鑫达钢铁"），住所地河北省唐山市迁安经济开发区。法定代表人王某。该公司持有排污许可证（证书编号：91130283795487XXXX001P），许可有效期为2023年1月1日至2027年12月31日，为国家重点监控企业。

【违法事实】
2024年4月，唐山市生态环境局对鑫达钢铁开展排污许可专项执法检查。检查发现：

1. 该公司排污许可证载明：烧结机机头烟气排放口SO2年许可排放量为120吨，NOx年许可排放量为280吨，颗粒物年许可排放量为60吨。
2. 调阅该公司2023年度排污许可执行报告及自行监测数据显示：2023年度该公司烧结机机头烟气排放口SO2实际排放量为158.6吨，超过年许可排放量38.6吨，超标比例32.2%；NOx实际排放量为356.8吨，超过年许可排放量76.8吨，超标比例27.4%。
3. 现场检查时，执法人员对该公司烧结机机头烟气排放口进行了现场采样监测。监测结果显示：SO2排放浓度为68mg/m³，超过《钢铁烧结、球团工业大气污染物排放标准》（GB 28662-2012）表1规定的排放限值50mg/m³，超标0.36倍；NOx排放浓度为125mg/m³，超过排放标准限值100mg/m³，超标0.25倍。
4. 经调查核实，该公司烧结机脱硫设施采用石灰石-石膏湿法脱硫工艺，因脱硫浆液循环泵故障未及时维修，导致脱硫效率下降，污染物排放浓度超标。
5. 该公司虽建立了环境管理台账，但对脱硫设施故障期间的运行情况记录不完整，未按规定向生态环境主管部门报告设施故障情况。
6. 2023年度，该公司通过排污权交易市场购买SO2排污权指标20吨，但仍有18.6吨缺口；NOx排污权指标未购买，存在76.8吨缺口。

【违反条款】
《排污许可管理条例》第十七条第一款：排污单位应当遵守排污许可证规定，按照生态环境管理要求运行和维护污染防治设施，建立环境管理制度，严格控制污染物排放。

《排污许可管理条例》第十八条第二款：排污单位应当按照排污许可证规定排放污染物；排放污染物的种类、浓度、排放量等不得超过排污许可证规定的排放限值和许可排放量。

《中华人民共和国大气污染防治法》第十八条：企业事业单位和其他生产经营者建设对大气环境有影响的项目，应当依法进行环境影响评价、公开环境影响评价文件；向大气排放污染物的，应当符合大气污染物排放标准，遵守重点大气污染物排放总量控制要求。

【处罚依据】
《排污许可管理条例》第三十四条第（一）项：违反本条例规定，排污单位超过排污许可证规定的污染物排放浓度或者排放量排放污染物的，由生态环境主管部门责令改正或者限制生产、停产整治，处20万元以上100万元以下的罚款；情节严重的，吊销排污许可证，报经有批准权的人民政府批准，责令停业、关闭。

《中华人民共和国大气污染防治法》第九十九条第（二）项：违反本法规定，有下列行为之一的，由县级以上人民政府生态环境主管部门责令改正或者限制生产、停产整治，并处十万元以上一百万元以下的罚款；情节严重的，报经有批准权的人民政府批准，责令停业、关闭：（二）超过大气污染物排放标准或者超过重点大气污染物排放总量控制指标排放大气污染物的。

【处罚结果】
唐山市生态环境局作出如下行政处罚：
1. 责令鑫达钢铁立即改正违法行为，确保污染物达标排放，严格执行排污许可证规定的总量控制要求；
2. 对超过排污许可证规定的污染物排放量排放污染物的行为处以罚款85万元；
3. 对超过大气污染物排放标准排放大气污染物的行为处以罚款50万元；
4. 对未按规定建立环境管理台账记录的行为处以罚款5万元。

合并处罚140万元。同时，责令该公司在30日内制定整改方案，完成脱硫设施升级改造，确保污染物达标排放。

【法律依据】
《排污许可管理条例》第十七条、第十八条、第三十四条、第三十七条；《中华人民共和国大气污染防治法》第十八条、第九十九条；《钢铁烧结、球团工业大气污染物排放标准》（GB 28662-2012）。
