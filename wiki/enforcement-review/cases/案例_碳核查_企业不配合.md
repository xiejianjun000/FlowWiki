# source_path: /Users/mac/企业合规AI管理知识库/raw/inbox/案例_碳核查_企业不配合.txt

案例编号：CASE-CT-2024-005
案例类型：碳核查-企业不配合
行业：水泥

【当事人信息】
处罚对象：天山水泥集团有限公司（以下简称"天山水泥"），住所地X省U市米东区。法定代表人白某。该公司主要从事水泥生产、销售，年产能水泥1200万吨、熟料850万吨，为全国碳排放权交易市场重点排放单位。

【违法事实】
2024年6月，生态环境厅组织对重点排放单位开展碳排放核查时，天山水泥拒不配合碳核查工作，拒绝提供相关资料，阻碍执法检查。经立案调查，查明以下违法事实：

一、拒绝提供核查资料。2024年6月10日，X省生态环境厅委托的第三方核查机构到天山水泥开展2023年度碳排放现场核查时，该公司以各种理由拒绝提供核查所需的原始资料，包括：

1. 拒绝提供能源消耗台账和原始凭证：
   - 拒绝提供2023年度原煤、石灰石、燃料油等原燃材料的采购台账、过磅单、化验记录、入库出库记录等原始凭证；
   - 仅提供汇总报表，不提供原始记录，且汇总报表数据与实际情况明显不符。

2. 拒绝提供生产运行记录：
   - 拒绝提供熟料生产线运行记录、窑炉温度记录、产量记录、中控操作记录等生产数据；
   - 拒绝允许核查人员进入中控室查看生产运行数据。

3. 拒绝提供财务凭证：
   - 拒绝提供原燃材料采购发票、付款凭证、成本核算资料等财务凭证；
   - 以"商业秘密"为由拒绝提供相关财务数据。

4. 拒绝提供其他相关资料：
   - 拒绝提供环境影响评价文件、排污许可证、在线监测数据等环保资料；
   - 拒绝提供企业基本信息、组织结构、人员配置等基础资料。

二、阻碍核查工作开展。天山水泥采取多种手段阻碍碳核查工作：

1. 拖延时间：
   - 核查人员到达现场后，迟迟不安排对接人员，拖延时间达数小时；
   - 以"负责人不在"、"资料找不到"等各种理由拖延，拒不配合。

2. 刁难核查人员：
   - 要求核查人员提供各种不必要的证明文件；
   - 限制核查人员活动范围，不允许进入生产现场、化验室、中控室等关键场所。

3. 威胁恐吓：
   - 企业负责人对核查人员进行言语威胁，声称"敢如实核查就让你们好看"；
   - 安排保安人员跟随、监视核查人员。

4. 撕毁封存资料：
   - 核查人员发现部分原始记录存在篡改痕迹，准备封存相关资料时，企业人员抢夺并撕毁了部分资料。

三、情节严重。天山水泥拒不配合碳核查的行为，造成严重后果：
1. 导致2023年度碳排放核查工作无法正常进行，影响全省碳核查工作进度；
2. 该公司2023年度碳排放报告无法得到有效核查，数据真实性存疑；
3. 严重扰乱了碳排放管理秩序，损害了碳市场的公信力；
4. 在行业内造成恶劣影响，起到不良示范作用。

【调查过程】
2024年6月10日，第三方核查机构在天山水泥开展现场核查时受阻，核查机构立即向X省生态环境厅报告。
6月11日，X省生态环境厅决定立案调查，并向天山水泥送达《配合检查通知书》。
6月12日，省生态环境厅执法人员会同核查机构再次到天山水泥，要求其配合检查，仍遭到拒绝。
6月15日-6月25日，执法人员先后三次到该公司，依法进行调查取证，对相关人员进行询问。
6月20日，对该公司法定代表人白某、总经理毛某、环保总监崔某、生产厂长康某等进行约谈。
6月30日，案件调查终结，作出行政处罚决定。

【处罚结果】
X省生态环境厅认定天山水泥的行为违反了《碳排放权交易管理办法（试行）》第二十七条"重点排放单位应当配合生态环境主管部门组织的碳排放核查，如实提供相关资料，不得拒绝、阻碍、隐瞒"的规定。

依据《碳排放权交易管理办法（试行）》第四十一条、《中华人民共和国环境保护法》第二十一条、《中华人民共和国行政处罚法》第二十八条，作出以下行政处罚：
一、责令立即改正，于2024年7月31日前配合完成2023年度碳排放核查工作，如实提供全部相关资料；
二、处以罚款人民币300万元（顶格处罚）；
三、将该公司环境违法信息记入社会诚信档案，实施联合惩戒；
四、将该公司列为重点监管对象，增加监督检查频次；
五、取消其2023-2024年度环保专项资金补助资格，收回已拨付的节能降碳项目补助资金800万元；
六、将案件移送公安机关，对直接负责的主管人员和其他直接责任人员追究治安管理责任。

同时，对全国碳排放权交易市场相关处理：
一、在其配合完成核查工作前，暂停其参与全国碳排放权交易市场交易资格；
二、暂不确认其2023年度碳排放数据，按最高值核定其2023年度碳排放量，并据此核定配额清缴义务；
三、核减其2024年度碳排放配额100万吨。

【法律依据】
《碳排放权交易管理办法（试行）》第二十七条、第四十一条；
《中华人民共和国环境保护法》第二十一条、第六十三条；
《企业环境信用评价办法》；
《中华人民共和国治安管理处罚法》第五十条。
