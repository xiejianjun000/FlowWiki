# source_path: /Users/mac/企业合规AI管理知识库/flowwiki/raw/inbox/案例_环评_重大变动未重新报批.txt

案例编号：CASE-HP-2024-003
案例类型：行政处罚
行业：钢铁

【当事人信息】
处罚对象：青山市宏达钢铁有限公司（以下简称"宏达钢铁"），住所地C省青山市钢铁产业园区。法定代表人赵某某。该公司是一家中型钢铁联合企业，现有年产钢300万吨的生产能力，持有排污许可证。

【违法事实】
2024年4月，C省生态环境厅在开展钢铁行业专项督察时发现：宏达钢铁于2022年6月取得《年产300万吨钢铁联合项目环境影响报告书》的批复（C环审〔2022〕45号），但在项目建设过程中，该公司擅自对项目建设内容进行了重大调整，未重新报批环评文件。

经现场核查和比对环评批复文件，发现以下重大变动：

1. 生产规模：原环评批复为年产钢300万吨，实际建成后产能达到年产钢450万吨，产能增加50%；
2. 生产工艺：原环评批复为转炉炼钢工艺，实际增设了2台60吨电炉，增加电炉炼钢工艺路线；
3. 原辅材料：原环评批复以铁矿石为主要原料，实际增加了废钢使用量，年使用废钢从50万吨增加到200万吨；
4. 废气治理设施：原环评批复烧结机烟气采用"脱硫+脱硝+除尘"工艺，实际建设时取消了脱硝设施，仅保留脱硫和除尘；
5. 废水排放：原环评批复生产废水零排放，实际增设了废水排放口，生产废水经处理后排入附近河流；
6. 总投资额：原环评批复总投资85亿元，实际总投资达到120亿元。

经调查核实，宏达钢铁在建设过程中，根据市场情况自行调整了建设方案，但未就上述重大变动向原环评审批部门重新报批环评文件。该公司董事长赵某某辩称"只是优化调整，不是重大变动"，认为"只要污染治理能跟上就行，没必要重新报批"。

经C省生态环境厅组织专家论证，认定上述变动属于《建设项目环境影响评价分类管理名录》和《关于做好建设项目重大变动环境影响评价管理工作的通知》中规定的重大变动情形，应当重新报批环境影响评价文件。

【处罚结果】
C省生态环境厅认定宏达钢铁的行为违反了《中华人民共和国环境影响评价法》第二十四条第一款"建设项目的环境影响评价文件经批准后，建设项目的性质、规模、地点、采用的生产工艺或者防治污染、防止生态破坏的措施发生重大变动的，建设单位应当重新报批建设项目的环境影响评价文件"的规定。

依据《中华人民共和国环境影响评价法》第三十一条第一款，对宏达钢铁建设项目发生重大变动未重新报批环评文件的违法行为，处以实际建设项目总投资额1.5%的罚款，即人民币1800万元。

同时责令该公司立即停止违法生产，限期6个月内重新报批环境影响评价文件，在取得新的环评批复前不得恢复生产。依法查封擅自增设的2台电炉设备。

鉴于该公司违法情节特别严重，产能大幅增加且擅自取消脱硝设施，C省生态环境厅将该案移送公安机关，对直接负责的主管人员和其他直接责任人员建议处以行政拘留。同时将该公司环境违法信息纳入社会信用评价体系，实施联合惩戒。

【法律依据】
《中华人民共和国环境保护法》第十九条、第六十一条、第六十三条；
《中华人民共和国环境影响评价法》第二十四条、第三十一条；
《建设项目环境保护管理条例》第二十一条、第二十二条；
《关于做好建设项目重大变动环境影响评价管理工作的通知（试行）》。
