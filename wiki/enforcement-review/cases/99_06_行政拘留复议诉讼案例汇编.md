## 行政拘留复议诉讼案例汇编

### 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 公安部、生态环境部 |

### 二、主要内容
本汇编收集行政拘留复议诉讼典型案例，涵盖对行政拘留决定不服申请复议、提起诉讼的案件，分析复议诉讼请求、争议焦点（适用情形、移送程序、拘留期限、适用对象）、复议决定、诉讼判决，为企业主要负责人和直接责任人员应对行政拘留提供参考。

### 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 复议申请 | 请求撤销拘留 |
| 诉讼提起 | 请求撤销拘留 |
| 争议焦点 | 适用情形、移送程序 |
| 复议决定 | 维持、撤销、变更 |
| 诉讼判决 | 维持、撤销、变更 |

### 四、合规要点
1. 收到行政拘留决定后60日内申请复议或6个月内提起诉讼
2. 复议诉讼请求应明确具体
3. 关注适用情形和移送程序合法性
4. 关注拘留期限和适用对象
5. 依法应对行政拘留决定
