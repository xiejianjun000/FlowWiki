## 噪声环境执法典型案例汇编

### 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 全国 |
| 发布机关 | 生态环境部 |

### 二、主要内容
本汇编收集噪声环境执法典型案例，涵盖工业企业厂界噪声超标、建筑施工夜间施工违法、机动车违法鸣笛、商业经营活动使用高音喇叭扰民、室内装修扰民、公共场所活动噪声超标、社会生活噪声投诉等典型违法情形。

### 三、关键条款/案例要点
| 案例类别 | 典型案例 |
|---------|---------|
| 工业噪声 | 厂界超标 |
| 施工噪声 | 夜间违法施工 |
| 交通噪声 | 鸣笛扰民 |
| 商业噪声 | 高音喇叭 |
| 社会生活 | 室内装修扰民 |

### 四、合规要点
1. 工业企业执行厂界环境噪声排放标准
2. 建筑施工夜间作业须取得许可
3. 不得使用高音喇叭扰民
4. 室内装修避开休息时间
5. 配合噪声投诉举报处理
