# 江州高新区规划环评未落实案

## 案例概述

2024年1月，I省生态环境厅在开展全省省级以上工业园区规划环评落实情况专项督查时发现：江州市高新技术产业开发区存在规划环评未落实、项目入园把关不严、跟踪评价未开展等突出问题。园区违规引进6家高污染项目，12家企业存在未批先建等违法行为，且集中供热、污水处理、危废处置等环保基础设施均未按期建成。I省生态环境厅对管委会处以罚款30万元，对该园区实行区域限批，将其列为省级环保督察典型案例挂牌督办，5名相关责任人被给予党纪政务处分。

## 当事人信息

处罚对象：江州市高新技术产业开发区管理委员会（以下简称"高新区管委会"），住所地I省江州市高新技术产业开发区。法定代表人、管委会主任吴某某。

园区内涉及企业：12家未批先建、不符合规划环评要求的企业。

## 违法事实

2024年1月，I省生态环境厅在专项督查中发现江州市高新区存在以下突出问题：

**一、规划环评落实不到位：**
1. 高新区规划环境影响报告书于2020年8月经I省生态环境厅审查通过（I环办函〔2020〕128号），审查意见明确要求重点发展电子信息、生物医药、新材料等主导产业，严格限制高污染、高耗能项目入园；
2. 但高新区管委会违规引进了6家化工、电镀、印染等高污染项目，与园区主导产业定位不符；
3. 规划环评要求的集中供热中心、污水处理厂提标改造、危险废物集中处置中心等基础设施均未按期建成，严重滞后；
4. 园区环境质量下降：2023年PM2.5较2020年上升18%，纳污河流断面水质从III类下降为IV类。

**二、项目入园把关不严：**
1. 高新区管委会降低环保准入门槛，对入园项目环评审批"开绿灯"，要求生态环境分局"特事特办"；
2. 园区内12家企业存在未批先建、未验先投等环境违法行为，其中8家为化工、电镀类高污染企业；
3. 部分项目环评文件降低评价等级，将应编制报告书的项目改为报告表，将应编制报告表的项目改为登记表备案；
4. 园区未建立规划环评与项目环评联动机制，入园项目未落实规划环评的准入和管控要求。

**三、跟踪评价未开展：**
1. 按照《规划环境影响评价条例》要求，对环境有重大影响的规划实施后，规划编制机关应当及时组织环境影响的跟踪评价；
2. 高新区规划实施已超过3年，但至今未组织开展规划环境影响跟踪评价；
3. 园区未建立环境监测体系，对园区环境质量变化和污染物排放缺乏有效监控。

高新区管委会为追求经济发展指标和招商引资业绩，片面强调"项目为王"，忽视生态环境保护。

## 违法条款

《中华人民共和国环境影响评价法》第十五条：对环境有重大影响的规划实施后，编制机关应当及时组织环境影响的跟踪评价，并将评价结果报告审批机关；发现有明显不良环境影响的，应当及时提出改进措施。

《规划环境影响评价条例》第二十四条：对环境有重大影响的规划实施后，规划编制机关应当及时组织规划环境影响的跟踪评价。

## 处罚依据

- 《中华人民共和国环境影响评价法》第十四条、第十五条、第三十条。
- 《规划环境影响评价条例》第二条、第十三条、第二十四条、第三十条。
- 《中华人民共和国环境保护法》第十九条、第二十九条。
- 《关于加强规划环境影响评价与建设项目环境影响评价联动工作的意见》。
- 《党政领导干部生态环境损害责任追究办法（试行）》。

## 处罚决定

I省生态环境厅依法对高新区管委会采取以下措施：

**一、行政处罚：**
1. 依据《中华人民共和国环境影响评价法》第三十条和《规划环境影响评价条例》第三十条，对高新区管委会未组织开展规划环境影响跟踪评价的行为处以罚款30万元；
2. 对园区内12家未批先建、未验先投的企业依法予以查处，合计罚款达2600万元，其中3家企业相关责任人被移送公安机关行政拘留。

**二、行政措施：**
1. 对高新区管委会予以通报批评，责令限期整改6个月；
2. 对该园区实行区域限批，整改期间暂停审批园区内除污染治理和民生工程以外的所有建设项目环境影响评价文件；
3. 将该问题作为省级环境保护督察典型案例挂牌督办，向社会公开曝光；
4. 向江州市委、市政府移送问题线索，建议对相关责任人进行追责问责。

**三、整改要求：**
1. 严格落实规划环评审查意见，限期清理不符合产业定位的高污染企业；
2. 加快园区环保基础设施建设，确保集中供热、污水处理、危废处置等按期建成投运；
3. 建立规划环评与项目环评联动机制，严格项目入园环境准入；
4. 组织开展规划环境影响跟踪评价；
5. 建立健全园区环境监测体系。

2024年7月，江州市纪委监委对高新区管委会主任吴某某等5名相关责任人分别给予了党纪政务处分。

## 合规启示

1. 工业园区管理机构（管委会）是规划环评落实的第一责任主体，必须将规划环评审查意见作为园区开发建设的刚性约束，不能以"发展优先"为由降低环保要求。
2. 规划实施超过3年且对环境有重大影响的，必须及时组织开展规划环境影响跟踪评价。
3. 园区环保基础设施（集中供热、污水处理、危废处置）应与园区开发同步建设，不能滞后。
4. 建立规划环评与项目环评联动机制，是确保入园项目符合园区环境准入要求的关键制度。
5. 规划环评落实不到位不仅面临行政处罚和区域限批，相关责任人还将被追责问责，面临党纪政务处分。
