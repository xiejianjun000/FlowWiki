# 润丰石化后评价未开展案

## 案例概述

2024年5月，J省生态环境厅在开展重点建设项目环境影响后评价专项检查时发现：海东市润丰石化有限公司500万吨/年炼油改扩建项目自2019年6月投产运行近5年，但未按规定组织开展环境影响后评价。该项目运行过程中已出现多项与环评批复不符的情形，包括实际产能超出设计16%、新增渣油加氢装置、废水排放口位置变动等。J省生态环境厅依法责令其限期完成后评价并处以罚款15万元，并针对重大变动部分要求重新报批环评文件。

## 当事人信息

处罚对象：海东市润丰石化有限公司（以下简称"润丰石化"），住所地J省海东市石化工业园区。法定代表人孙某某。该公司主要从事石油炼制和石油化工产品生产，现有原油加工能力500万吨/年，持有排污许可证。

## 违法事实

2024年5月，J省生态环境厅在开展重点建设项目环境影响后评价专项检查时发现，润丰石化500万吨/年炼油改扩建项目存在未按规定开展环境影响后评价的违法行为。

**项目基本情况：**
- 环境影响报告书于2016年12月由原环境保护部批复（环审〔2016〕185号）；
- 项目于2019年6月通过竣工环境保护验收，正式投入生产；
- 总投资额约68亿元，主要包括常减压蒸馏、催化裂化、加氢精制、硫磺回收等生产装置。

**未开展后评价的违法事实：**
根据《中华人民共和国环境影响评价法》第二十七条和《建设项目环境影响后评价管理办法（试行）》的规定，该项目属于"可能造成重大环境影响的编制环境影响报告书的建设项目"，且正式投入生产满五年，应当开展环境影响后评价。截至2024年5月检查时，润丰石化未按规定组织开展环境影响后评价。

**运行过程中出现的不符情形：**
1. 实际原油加工量达到580万吨/年，超出设计产能16%；
2. 因油品质量升级，新增渣油加氢装置，生产工艺发生变化；
3. 废水排放口位置发生变动，新增雨水排放口；
4. 危险废物产生量较环评预测增加约40%；
5. 部分废气排放口实际排放浓度和排放量与环评预测值存在较大差异。

**环境管理问题：**
- 环境管理台账不完善，环境监测数据不完整；
- 未按规定报告重大变动情况；
- 环境风险防控措施未完全落实，应急预案未按最新要求修订。

润丰石化法定代表人孙某某称"不知道还要做后评价，以为验收完就没事了"，该公司环保部门曾就后评价事宜提交过请示但未获重视。

## 违法条款

《中华人民共和国环境影响评价法》第二十七条：在项目建设、运行过程中产生不符合经审批的环境影响评价文件的情形的，建设单位应当组织环境影响的后评价，采取改进措施，并报原环境影响评价文件审批部门和建设项目审批部门备案。

《建设项目环境影响后评价管理办法（试行）》第二条、第三条、第六条。

## 处罚依据

- 《中华人民共和国环境影响评价法》第三十一条第三款。
- 《建设项目环境影响后评价管理办法（试行）》第十一条、第十二条。
- 《中华人民共和国环境保护法》第四十一条。
- 《建设项目环境保护管理条例》第十九条、第二十条。

## 处罚决定

J省生态环境厅认定润丰石化的行为违反了环境影响后评价的相关规定。

1. 责令润丰石化限期6个月内完成环境影响后评价工作，并将后评价文件报J省生态环境厅备案。
2. 处以罚款15万元。
3. 针对运行过程中出现的重大变动情况：
   - 在后评价中重点分析产能扩大、工艺变化等对环境的影响；
   - 对生产工艺重大变动的部分，依法重新报批环境影响评价文件；
   - 限期整改环境管理中存在的问题，完善环境监测体系和环境风险防控措施。
4. 将该公司列为重点监管对象，增加现场检查频次。
5. 将环境违法信息记入社会诚信档案。

## 合规启示

1. 环境影响后评价是环评制度的延续和补充。对于可能造成重大环境影响的建设项目，投产满五年后应当主动开展后评价，不能以为验收完成就"一劳永逸"。
2. 项目运行中出现的产能扩大、工艺变化、污染物排放差异等情况必须如实报告，属于重大变动的应重新报批环评文件。
3. 企业应建立健全环境管理台账，持续监测项目实际环境影响，为后评价提供数据支撑。
4. 管理层应重视环保部门的合规建议，避免因"不重视"导致行政处罚和信用惩戒。
