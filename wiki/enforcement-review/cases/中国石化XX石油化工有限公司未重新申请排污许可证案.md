# 中国石化XX石油化工有限公司未重新申请排污许可证案

## 案例概述

中国石化XX石油化工有限公司在排污许可证有效期内实施"炼化一体化扩能改造项目"：原油加工能力从500万吨/年提升至800万吨/年，并新增100万吨/年对二甲苯（PX）装置。该扩能项目于2023年12月建成并投入试生产，但未依法重新申请取得排污许可证。原许可排放量已无法覆盖新增排放量（预计年新增SO2 450吨、NOx 520吨、VOCs 380吨、COD 210吨），且现场监测PX装置VOCs排放浓度超标0.54倍。福建省生态环境厅合并处罚165万元，责令限产。

## 当事人信息

- **当事人**：中国石化XX石油化工有限公司
- **住所地**：福建省泉州市泉港石化工业区
- **法定代表人**：孙某
- **排污许可证编号**：91350505717898XXXX001P
- **原许可有效期**：2021年5月20日至2026年5月19日
- **原许可产品**：原油加工500万吨/年、乙烯80万吨/年、聚乙烯40万吨/年、聚丙烯35万吨/年

## 违法事实

1. **扩能改造未重新申请排污许可证**：2022年10月启动"炼化一体化扩能改造项目"，原油加工能力从500万吨/年提升至800万吨/年，新增100万吨/年对二甲苯（PX）装置。2023年12月建成投入试生产，但未重新申请排污许可证。
2. **污染物排放种类和排放量大幅增加**：新增SO2、NOx、颗粒物、VOCs、非甲烷总烃、苯系物、石油类、COD、氨氮、总氮、总磷等多种污染物。
3. **原许可排放量严重不足**：预计年新增SO2约450吨、NOx约520吨、VOCs约380吨、COD约210吨，均超过原排污许可证许可的排放总量。
4. **新增排放口未纳入管理**：PX装置废气排放口未纳入排污许可证管理，无污染物排放许可限值。现场监测VOCs排放浓度185mg/m³（GB 31570-2015表4限值120mg/m³，超标0.54倍）。
5. **已获环评批复但未同步申请排污许可证**：已编制环境影响评价文件并取得批复，但误认为有环评批复即可投产，忽视了排污许可证的重新申请要求。

## 违法条款

1. **《排污许可管理条例》第十五条第（一）项**：在排污许可证有效期内，新建、改建、扩建排放污染物的项目的，应当重新申请取得排污许可证。
2. **《排污许可管理条例》第十五条第（二）项**：生产经营场所、污染物排放口位置或者污染物排放方式、排放去向发生变化的，应当重新申请取得排污许可证。
3. **《排污许可管理条例》第十五条第（三）项**：污染物排放种类或者排放量发生变化导致排污许可事项变更的，应当重新申请取得排污许可证。
4. **《中华人民共和国环境保护法》第四十五条第二款**：实行排污许可管理的企业事业单位和其他生产经营者应当按照排污许可证的要求排放污染物；未取得排污许可证的，不得排放污染物。

## 处罚依据

1. **《排污许可管理条例》第三十三条第（一）项**：排污单位未取得排污许可证排放污染物的，由生态环境主管部门责令改正或者限制生产、停产整治，处20万元以上100万元以下的罚款；情节严重的，责令停业、关闭。
2. **《中华人民共和国大气污染防治法》第九十九条第（一）项**：未依法取得排污许可证排放大气污染物的，由县级以上人民政府生态环境主管部门责令改正或者限制生产、停产整治，并处十万元以上一百万元以下的罚款。

## 处罚决定

1. 责令立即改正，于60日内重新申请取得排污许可证。
2. 未重新申请取得排污许可证排放污染物：罚款100万元。
3. VOCs超标排放：罚款65万元。
4. **合并处罚165万元**。重新取得排污许可证前，限制扩能改造项目生产负荷。案件作为典型案例向社会公开，对企业主要负责人进行约谈。

## 合规启示

1. **环评批复不能替代排污许可证**：取得环评批复仅完成了环境影响评价程序，投产前还须重新申请取得排污许可证，二者是独立的法律制度。
2. **扩能改造触发重新申请义务**：排污许可管理条例第十五条规定了四类须重新申请的情形，任何一类触发都须重新申请。本案同时触发了三类（新建项目、排放口变化、排放量变化）。
3. **重新申请在投产前完成**：新建/改建/扩建项目须在投入生产或使用前取得与项目匹配的排污许可证，不得"先投产后补证"。
4. **大型石化项目重新申请周期长**：须提前规划，扩能改造项目的排污许可证重新申请涉及复杂的排放量核算和技术评估，应至少提前6个月启动准备工作。
5. **典型案例公开的附加影响**：被作为典型案例向社会公开将对企业声誉和投资者信心造成重大影响，远超罚款金额本身。
