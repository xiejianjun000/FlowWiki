# source_path: /Users/mac/企业合规AI管理知识库/raw/inbox/案例_碳排放权交易_虚假申报.txt

案例编号：CASE-CT-2024-001
案例类型：碳排放权交易-虚假申报
行业：钢铁

【当事人信息】
处罚对象：兴华钢铁集团有限公司（以下简称"兴华钢铁"），住所地H省W市钢铁工业区。法定代表人何某。该公司主要从事钢铁冶炼、钢材生产，年产生铁320万吨、粗钢350万吨、钢材330万吨，为全国碳排放权交易市场重点排放单位。

【违法事实】
2024年5月，生态环境部组织全国碳排放权交易市场重点排放单位碳排放报告质量专项监督帮扶中，发现兴华钢铁2021-2023年度碳排放报告存在严重数据造假问题。经立案调查，查明以下违法事实：

一、虚假申报碳排放数据。兴华钢铁在2021、2022、2023三个年度的碳排放报告中，通过多种手段虚减碳排放量，骗取碳排放配额：

1. 低报燃料消耗量：
   - 2021年度：申报原煤消耗量286万吨，实际消耗量365万吨，低报79万吨，少计碳排放约168万吨CO₂当量；
   - 2022年度：申报原煤消耗量298万吨，实际消耗量378万吨，低报80万吨，少计碳排放约170万吨CO₂当量；
   - 2023年度：申报原煤消耗量305万吨，实际消耗量392万吨，低报87万吨，少计碳排放约185万吨CO₂当量。

2. 虚报燃料低位发热量：
   - 将实际收到基低位发热量申报值平均为22.8MJ/kg，实际检测值为20.5MJ/kg，通过高估发热量约11.2%，相应减少单位燃料消耗量计算。

3. 隐瞒排放因子选用错误：
   - 故意选用低于实际值的碳排放因子，使碳氧化率取值偏高，进一步虚减碳排放量。

4. 隐瞒排放源：
   - 未申报2台80t/h备用锅炉的碳排放，该两台锅炉年耗煤约18万吨，对应碳排放约38万吨CO₂当量/年。

二、骗取碳排放配额。通过上述虚假申报手段，兴华钢铁三个年度共计少报碳排放量约：
- 2021年度：约206万吨CO₂当量；
- 2022年度：约208万吨CO₂当量；
- 2023年度：约223万吨CO₂当量；
三年合计少报约637万吨CO₂当量，占实际排放量的15.8%，相应骗取碳排放配额价值约3.2亿元（按全国碳市场平均价格约50元/吨计算）。

三、数据造假手段。该公司专门成立"数据优化小组"，系统性地实施碳排放数据造假，主要手段包括：
1. 建立两套账：一套记录真实生产数据，仅供内部使用；另一套用于应对监管检查；
2. 篡改原始记录，伪造入厂煤质检测报告，编造煤质化验记录；
3. 编造虚假的生产记录和能耗台账；
4. 指使相关人员统一口径，应对检查时提供虚假材料。

【调查过程】
2024年5月8日，生态环境部专项监督帮扶组在对兴华钢铁进行现场核查时，发现碳排放数据异常，决定立案调查。
5月10日，执法人员对兴华钢铁进行现场检查，调取了相关资料。
5月15日-6月5日，调取该公司2021-2023年的生产记录、能源消耗台账、财务凭证、煤质检测报告、采购合同、过磅单等原始资料。
5月20日-6月10日，委托国家应对气候变化战略研究和国际合作中心对该公司碳排放量进行核算。
6月5日-6月15日，对该公司法定代表人何某、总经理马某、环保总监吕某、能源处处长杜某、化验室主任等8人进行询问调查。
6月25日，案件调查终结，作出行政处罚决定。

【处罚结果】
生态环境部认定兴华钢铁的行为违反了《碳排放权交易管理办法（试行）》第二十六条"重点排放单位应当按照规定报送温室气体排放报告，对排放报告的真实性、完整性、准确性负责"的规定。

依据《碳排放权交易管理办法（试行）》第三十九条、《中华人民共和国行政处罚法》第二十八条，作出以下行政处罚：
一、责令限期改正，于2024年8月31日前重新提交2021-2023年度真实、完整、准确的碳排放报告；
二、处以罚款人民币500万元（顶格处罚）；
三、将该公司环境违法信息记入社会诚信档案，实施联合惩戒；
四、取消其2021-2023年度环保专项资金补助资格，收回已拨付的节能降碳项目补助资金2800万元；
五、将案件移送公安机关，对直接负责的主管人员和其他直接责任人员追究刑事责任。

同时，对全国碳排放权交易市场相关处理：
一、责令其按照重新核算的碳排放量，于2024年9月30日前足额补缴2021-2023年度碳排放配额，并承担相应的违约责任，缴纳违约金约9600万元；
二、暂停其参与全国碳排放权交易市场交易资格6个月；
三、对其已取得的CCER抵销比例限制使用。

【法律依据】
《碳排放权交易管理办法（试行）》第二十六条、第三十九条；
《温室气体排放核算与报告要求 钢铁生产企业》（GB/T 32151.5-2015）；
《企业环境信用评价办法》；
《中华人民共和国刑法》第二百六十六条（诈骗罪相关条款）。
