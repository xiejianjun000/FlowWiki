# 五大行业清洁生产标准汇编

## 一、钢铁行业清洁生产标准（HJ 465-2022）

### 1.1 适用范围

- 适用于钢铁行业炼焦、烧结球团、炼铁、炼钢及钢铁联合企业的清洁生产审核、评估和绩效评定
- 不适用于电炉炼钢企业

### 1.2 清洁生产等级

| 等级 | 含义 |
|------|------|
| 一级 | 国际清洁生产先进水平 |
| 二级 | 国内清洁生产先进水平 |
| 三级 | 国内清洁生产一般水平 |

### 1.3 钢铁行业清洁生产定量评价指标

#### 炼焦工序

| 指标 | 单位 | 一级 | 二级 | 三级 |
|------|------|------|------|------|
| 工序能耗（折标煤） | kgce/t焦 | ≤ 110 | ≤ 115 | ≤ 125 |
| 吨焦耗新水 | m³/t焦 | ≤ 1.5 | ≤ 2.0 | ≤ 2.5 |
| 吨焦耗蒸汽 | GJ/t焦 | ≤ 0.20 | ≤ 0.40 | ≤ 0.60 |
| 焦炉煤气利用率 | % | 100 | ≥ 99 | ≥ 95 |
| 吨焦耗电 | kWh/t焦 | ≤ 30 | ≤ 35 | ≤ 40 |

#### 烧结工序

| 指标 | 单位 | 一级 | 二级 | 三级 |
|------|------|------|------|------|
| 工序能耗（折标煤） | kgce/t烧结矿 | ≤ 45 | ≤ 50 | ≤ 55 |
| 吨烧结矿耗新水 | m³/t烧结矿 | ≤ 0.10 | ≤ 0.15 | ≤ 0.25 |
| 烧结机烟气脱硫率 | % | ≥ 95 | ≥ 90 | ≥ 85 |
| 烧结机NOx排放浓度 | mg/m³ | ≤ 100 | ≤ 200 | ≤ 300 |

#### 炼铁工序

| 指标 | 单位 | 一级 | 二级 | 三级 |
|------|------|------|------|------|
| 工序能耗（折标煤） | kgce/t铁 | ≤ 360 | ≤ 385 | ≤ 410 |
| 吨铁耗新水 | m³/t铁 | ≤ 0.5 | ≤ 1.0 | ≤ 1.5 |
| 高炉煤气利用率 | % | 100 | ≥ 99 | ≥ 95 |
| 高炉TRT发电量 | kWh/t铁 | ≥ 35 | ≥ 30 | ≥ 25 |

#### 炼钢工序（转炉）

| 指标 | 单位 | 一级 | 二级 | 三级 |
|------|------|------|------|------|
| 工序能耗（折标煤） | kgce/t钢 | ≤ -25 | ≤ -20 | ≤ -10 |
| 吨钢耗新水 | m³/t钢 | ≤ 0.5 | ≤ 1.0 | ≤ 1.5 |
| 转炉煤气利用率 | % | 100 | ≥ 99 | ≥ 95 |
| 吨钢耗电 | kWh/t钢 | ≤ 15 | ≤ 20 | ≤ 30 |

### 1.4 钢铁行业清洁生产定性评价指标

#### 生产工艺与装备要求

##### 炼焦
- 一级：干熄焦率 100%
- 二级：干熄焦率 ≥ 95%
- 三级：干熄焦率 ≥ 90%

##### 烧结
- 一级：厚料层烧结（≥ 700mm）
- 二级：厚料层烧结（≥ 600mm）
- 三级：厚料层烧结（≥ 500mm）

##### 炼铁
- 一级：高炉炉顶压力 ≥ 0.20 MPa
- 二级：高炉炉顶压力 ≥ 0.15 MPa
- 三级：高炉炉顶压力 ≥ 0.10 MPa

##### 炼钢
- 一级：转炉干法除尘率 100%
- 二级：转炉干法除尘率 ≥ 90%
- 三级：转炉干法除尘率 ≥ 80%

#### 环境管理要求

- 环境管理体系认证：ISO 14001
- 清洁生产审核：每 5 年开展一次
- 环境信息公开：年度公开

## 二、电镀行业清洁生产标准（HJ 314-2022）

### 2.1 适用范围

- 适用于电镀行业（含专业电镀企业和拥有电镀车间的企业）的清洁生产审核、评估和绩效评定
- 涵盖镀锌、镀铜、镀镍、镀铬、镀金、镀银等主要镀种

### 2.2 电镀行业清洁生产定量评价指标

#### 资源能源利用指标

| 指标 | 单位 | 一级 | 二级 | 三级 |
|------|------|------|------|------|
| 工业水重复利用率 | % | ≥ 90 | ≥ 80 | ≥ 70 |
| 单位面积镀件耗水量 | m³/m² | ≤ 0.10 | ≤ 0.15 | ≤ 0.20 |
| 单位面积镀件综合能耗 | kgce/m² | ≤ 1.0 | ≤ 1.5 | ≤ 2.0 |
| 单位面积镀件耗电量 | kWh/m² | ≤ 3.0 | ≤ 4.5 | ≤ 6.0 |

#### 镀层金属利用率

| 镀种 | 单位 | 一级 | 二级 | 三级 |
|------|------|------|------|------|
| 镀锌 | % | ≥ 90 | ≥ 85 | ≥ 80 |
| 镀铜 | % | ≥ 90 | ≥ 85 | ≥ 80 |
| 镀镍 | % | ≥ 95 | ≥ 90 | ≥ 85 |
| 镀铬 | % | ≥ 30 | ≥ 25 | ≥ 20 |
| 镀金 | % | ≥ 99 | ≥ 97 | ≥ 95 |
| 镀银 | % | ≥ 95 | ≥ 90 | ≥ 85 |

#### 污染物产生指标

| 指标 | 单位 | 一级 | 二级 | 三级 |
|------|------|------|------|------|
| 单位面积镀件废水产生量 | m³/m² | ≤ 0.10 | ≤ 0.15 | ≤ 0.20 |
| 单位面积镀件COD产生量 | g/m² | ≤ 5 | ≤ 8 | ≤ 12 |
| 单位面积镀件总铬产生量 | g/m² | ≤ 0.5 | ≤ 1.0 | ≤ 2.0 |
| 单位面积镀件六价铬产生量 | g/m² | ≤ 0.1 | ≤ 0.2 | ≤ 0.5 |
| 单位面积镀件总镍产生量 | g/m² | ≤ 0.3 | ≤ 0.5 | ≤ 1.0 |

### 2.3 电镀行业清洁生产定性评价指标

#### 生产工艺与装备要求

##### 镀锌

| 等级 | 要求 |
|------|------|
| 一级 | 三价铬钝化或无铬钝化 |
| 二级 | 三价铬钝化 |
| 三级 | 六价铬钝化 |

##### 镀铬

| 等级 | 要求 |
|------|------|
| 一级 | 三价铬镀铬或代铬镀 |
| 二级 | 低浓度六价铬镀铬 |
| 三级 | 标准六价铬镀铬 |

##### 镀前处理

| 等级 | 要求 |
|------|------|
| 一级 | 超声波前处理 |
| 二级 | 化学除油 + 电解除油 |
| 三级 | 化学除油 |

#### 镀液净化回收

| 等级 | 要求 |
|------|------|
| 一级 | 闭路循环 + 离子交换 + 反渗透 |
| 二级 | 离子交换 + 反渗透 |
| 三级 | 化学沉淀 |

## 六、清洁生产标准对企业环保合规的意义

### 6.1 强制性审核的依据

- 使用有毒有害原料或排放有毒有害物质的企业，应按行业清洁生产标准开展强制性清洁生产审核
- 审核结果应达到三级及以上要求

### 6.2 排污许可管理依据

- 排污许可证核发时应参考清洁生产标准要求
- 清洁生产水平低的企业应进行清洁生产技术改造

### 6.3 环境影响评价依据

- 建设项目环境影响评价应分析项目清洁生产水平
- 新建、改建、扩建项目应达到二级及以上清洁生产水平

### 6.4 环境保护专项资金支持依据

- 达到一级、二级清洁生产水平的企业，优先获得环保专项资金支持
- 达到一级水平的企业，可享受税收优惠

### 6.5 企业环境信用评价依据

- 企业清洁生产水平作为环境信用评价的重要指标
- 高清洁生产水平的企业获得较高环境信用等级

## 八、对企业环保合规工作的启示

1. **对标先进**：企业应主动对标一级、二级清洁生产水平
2. **持续改进**：通过清洁生产审核，不断改进生产工艺和设备
3. **资源化利用**：加强副产物、废物的资源化利用
4. **节能减排**：通过清洁生产，实现节能、节水、节材
5. **降低风险**：使用低毒低害原料，降低环境风险
6. **提升形象**：高清洁生产水平，提升企业环保形象
7. **政策红利**：享受环保专项资金、税收优惠等政策
