# create_excel_templates_fixed（工具脚本）

## 是什么
Python 脚本，用于批量生成排污许可相关 Excel 模板（审查核对表、台账、监测方案等）。

## 何时用
需要标准化 Excel 交付物时（如给企业下发的自查表、内部审查模板）。

## 怎么用
```
python3 raw/tools/create_excel_templates_fixed.py
```
