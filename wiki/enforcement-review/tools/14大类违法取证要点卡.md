# 14 大类违法取证要点卡（工具）

每类含：构成要件 + 取证要点 + 适用条款 + 处罚幅度。
完整条目见 执法检查14大类违法认定。

## 速查（现场）
- 无证/届满/吊销后排放 → 许可证查询截图+生产证据+监测数据
- 超许可 → 监测数据+许可证限值+排放量核算
- 逃避监管 → 勘查笔录+设备运行记录（暗管/篡改/不正常运行）
- 自行监测 → 许可证要求+监测报告（因子/频次/联网）
- 台账/报告 → 平台提交记录+实际排放（保存≥5年）

## 移送公安标准
逃避监管方式排放、拒不停止无证排污、涉嫌污染环境罪 → 移送。
