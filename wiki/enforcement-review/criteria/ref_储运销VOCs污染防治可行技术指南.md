# 储运销VOCs污染防治可行技术指南

## 一、基本信息

| 项目 | 内容 |
|------|------|
| 适用范围 | 油品、化学品储运、加油站、油码头 |
| 发布机关 | 生态环境部 |

## 二、主要污染源
- 储罐呼吸：VOCs
- 装卸车船：VOCs
- 加油站：油气
- 管道泄漏：VOCs

## 三、可行污染防治技术

| 污染源 | 推荐技术 | 去除效率 |
|--------|----------|----------|
| 储罐 | 内浮顶+二次密封 | 减排90% |
| 装卸 | 密闭装卸+油气回收 | ≥95% |
| 加油站 | 三次油气回收 | ≥95% |
| 管道 | LDAR泄漏检测 | 减排80% |

## 四、排放限值

| 污染物 | 排放限值 |
|--------|----------|
| 储罐VOCs | 去除率≥95% |
| 装卸VOCs | ≤25mg/L（液阻） |
| 加油站 | 气液比1.0-1.2 |
| 厂界非甲烷总烃 | 4mg/m³ |

## 五、合规要点

1. 储罐推行内浮顶+二次密封
2. 装卸车船密闭化+油气回收
3. 加油站三次回收
4. LDAR制度化
