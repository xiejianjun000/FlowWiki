# 废旧印刷电路板回收处理技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 527-2010附录 |
| 适用范围 | 印刷电路板回收处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废旧印刷电路板回收处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 废印刷电路板 |
| 处理工艺 | 破碎+分选+冶金 |
| 金属回收 | 铜、金、银、钯等 |
| 非金属利用 | 玻璃纤维、树脂等利用 |
| 污染防治 | 防止二次污染 |

## 四、合规要点
1. 采用先进工艺回收金属
2. 非金属材料合理利用
3. 处理过程防止二次污染
4. 建立处理记录档案
