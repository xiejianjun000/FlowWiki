# 废铅蓄电池收集运输技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 519-2020 |
| 适用范围 | 收集运输 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池收集、运输的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 收集要求 | 防破裂、防漏液 |
| 包装方式 | 专用容器、托盘 |
| 运输车辆 | 具备危废运输资质 |
| 转移联单 | 电子联单管理 |
| 运输路线 | 避开敏感区域 |

## 四、合规要点
1. 收集时防止电池破裂漏液
2. 使用专用容器包装
3. 运输车辆具备资质
4. 通过电子联单管理转移
