# 危险废物填埋场风险管理

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 169-2018 |
| 适用范围 | 填埋场风险管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场全过程风险识别、评估和管理。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 风险源 | 废物特性、防渗失效、渗滤液泄漏 |
| 风险评估 | 概率分析+后果评估 |
| 风险等级 | 高、中、低三级 |
| 管控措施 | 工程管控+管理管控 |
| 动态管理 | 根据风险变化调整措施 |

## 四、合规要点
1. 定期开展风险评估
2. 按风险等级实施差异化管控
3. 工程管控措施落实到位
4. 风险变化时及时调整
