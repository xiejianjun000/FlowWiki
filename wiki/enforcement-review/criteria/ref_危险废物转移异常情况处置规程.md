# 危险废物转移异常情况处置规程

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 169-2018附录 |
| 适用范围 | 异常情况处置 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物转移过程异常情况的处理程序。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 异常情形 | 数量不符、包装损坏、车辆故障 |
| 报告程序 | 立即报告移出地和接受地生态环境部门 |
| 处置措施 | 暂停转移、现场处置、记录 |
| 联单处理 | 异常情况在联单中记录 |
| 后续跟踪 | 异常情况处理结果跟踪 |

## 四、合规要点
1. 异常情况立即报告
2. 采取暂停转移和现场处置措施
3. 联单中如实记录异常情况
4. 跟踪异常处理结果
