# 危险废物转移车辆标识标志规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 13392-2005 |
| 适用范围 | 转移车辆标识 |
| 发布机关 | 交通运输部 |

## 二、主要内容
规定了危险废物转移车辆标识标志的设置和规格。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 标识类型 | 危险货物运输标识、菱形警告牌 |
| 标识内容 | UN编号、危险类别、应急电话 |
| 标识规格 | 菱形≥250mm×250mm |
| 设置位置 | 车辆前后部和侧面 |
| 夜间识别 | 反光材料或照明 |

## 四、合规要点
1. 按规范设置车辆标识
2. 标识内容完整准确
3. 标识位置醒目便于识别
4. 标识保持清晰完好
