# 铅蓄电池回收利用管理暂行办法

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 工信部节〔2019〕78号 |
| 适用范围 | 铅蓄电池回收利用管理 |
| 发布机关 | 工业和信息化部 |

## 二、主要内容
规定了铅蓄电池生产者、销售者、回收者、利用处置者的责任。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 生产者责任延伸 | 生产者承担回收责任 |
| 回收体系 | 建立规范回收体系 |
| 利用处置 | 交由持证单位利用处置 |
| 信息化管理 | 建立回收追溯系统 |
| 目标完成率 | 2025年回收率≥70% |

## 四、合规要点
1. 生产者落实延伸责任
2. 建立规范回收体系
3. 交由持证单位利用处置
4. 建立回收追溯信息系统
