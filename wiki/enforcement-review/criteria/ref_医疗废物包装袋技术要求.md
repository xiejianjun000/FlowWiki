# 医疗废物包装袋技术要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 26994-2011 |
| 适用范围 | 医疗废物包装袋 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了医疗废物包装袋的技术要求和试验方法。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 材质 | 聚乙烯（PE） |
| 厚度 | ≥0.05mm |
| 颜色 | 黄色 |
| 标识 | 医疗废物标识+警告语 |
| 性能要求 | 防渗漏、防破裂 |

## 四、合规要点
1. 使用符合标准的黄色包装袋
2. 包装袋性能满足防渗防破
3. 标识清晰醒目
4. 包装袋使用一次后废弃
