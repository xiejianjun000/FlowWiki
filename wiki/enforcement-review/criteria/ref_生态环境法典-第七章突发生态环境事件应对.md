# 生态环境法典-第七章突发生态环境事件应对

> ACE Generator 编译 | Reflector 审核通过

## 基本信息

- **通过**：2026年3月12日第十四届全国人大第四次会议
- **施行**：2026年8月15日
- **章节**：第一编 总则 第七章（第117-126条，共10条）
- **体系**：整合现行30余部生态环境法律，废止《环境保护法》等10部单行法

## 条文要点

| 条号 | 主题 | 核心变化 |
|------|------|---------|
| 117 | 管理体系 | 4环节 -> 5环节，新增"监测预警"和"调查评估" |
| 118 | 分级标准 | I/II/III/IV四级，分级标准制定权上收至国务院 |
| 119 | 责任体系 | 首次法律确立"分级负责、属地为主、部门协同" |
| 120 | 部门协同 | 法律固化生态环境+应急两部门协作 |
| 121 | 企业责任 | 新增隐患排查、物资储备、演练三项强制义务 |
| 122 | 次生污染防治 | 全新条款：其他灾害中须同步保护生态环境 |
| 123 | 预案体系 | 新增企业预案备案要求 |
| 124 | 监测预警 | 新增生态部门主动研判和预警建议权 |
| 125 | 跨区域联动 | 全新条款：强制跨区域通报和联动 |
| 126 | 事后评估 | "评估公布" -> "调查处理+损害赔偿+生态修复"闭环 |

## 罚则

- 第1235条：未制定预案/未配备设备/未及时报告/未采取措施，设定行政处罚
- 第1236条：最高罚款 **2000万元**；情节特别严重 2~5 倍罚款

## 指挥长要点速查

1. "五个第一时间"有法可依（第117条）
2. 跨区域联动是法定义务（第125条）
3. 企业责任大幅加强（第121条）
4. 处置结束不是终点，评估影响赔偿修复（第126条）
5. 罚则空前严厉（第1236条）
