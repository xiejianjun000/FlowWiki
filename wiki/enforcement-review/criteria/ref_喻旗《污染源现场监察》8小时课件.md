## 三、第一部分：监察人员素质

> "德能勤绩廉"五字诀。

- **德**：政治素质好，事业心、正义感、服务意识、合作共事。
- **能**：业务能力三层次——环保法规标准/污染防治技术/生产工艺流程。
  - 活到老学到老，特别是生产工艺。
  - 建立庞大智囊团；掌握方法（事先准备、事后总结）。
  - 政治敏感性 + 协调能力 + 胆大心细。
- **勤**：能吃苦耐劳，身体素质好。
- **绩**：环境质量改善、经济高质量发展、群众满意。
- **廉**：廉洁奉公。

## 四、第二部分：单一污染源现场监察（核心方法论）

### 4.1 现场监察四字诀："看、听、问、测"

> 查污染发现工艺问题，改工艺解决污染问题。

| 环节 | 内容 |
|---|---|
| **看** | 一看卫星图片；二看纳污环境；三看进排污口；四看污染治理工艺、装备与运行；五看生产工艺与装备；六看原辅材料；七看环境管理 |
| **听** | 听操作人员介绍；听周边群众的意见与建议 |
| **问** | 询问关键问题；注意询问技巧 |
| **测** | 必要的监测是不输官司的保证（选准因子、测准样品、程序合规） |

### 4.2 七看排查法（速查生态环境问题）

| 序 | 名称 | 关键看点 |
|---|---|---|
| 一看 | 卫星照片 | 寻找相关信息线索-关键字（前期准备） |
| 二看 | 纳污环境 | 水文地质（潮汐、河床、海岸、喀斯特、断层）+ 气象（风沙、暴雨）+ 周边植被 |
| 三看 | 进排污口 | 雨水排放口、进出水口、水量变化、藻类微生物、排气设施、在线监控、偷排设施 |
| 四看 | 污染治理 | 工艺、装备、设施运转→判断是否**假运行**；关注污泥浓缩/脱水/产生时间 |
| 五看 | 生产工艺 | 规模、工艺、装备、污染物性质。**金句：污染的实质是资源放错了位置；没有落后的行业和产品，只有落后的工艺** |
| 六看 | 原辅材料 | 资源分布及利用、燃料及原料来源、含量变化 |
| 七看 | 环境管理 | 环境质量、各项审批手续、排污许可证、运行记录、污泥去向 |

## 五、第三部分：排污者六大类作弊方式 + 监管对策

### 5.1 作弊动机

> 工艺落后 → 资源回收率低 → 产污多 → 治污投资/运转费高 → "省钱/省力/省事"铤而走险。
> 作弊方式**永远遵循"最省钱、最省力、最省事、最安全"的规律**。

### 5.2 六类作弊方式总览

| 类别 | 作弊手法 | 监管对策要点 |
|---|---|---|
| ① 在线监测设施作弊 | 采样子系统/分析子系统/数采通讯/参数修改 | 突击检查 + 比对监测（低中高浓度三档）|
| ② 各种类型偷排 | 暗管/移动式/井下/江心/雨洪闸偷排 | 看纳污环境 + 红外成像 + 暗管排查 |
| ③ 稀释排放 | 用清水/达标中水稀释 | 进出水量平衡 + 工况比对 |
| ④ "零排放"规避 | 循环利用、回用等名义 | 全厂水平衡 + 物料衡算 |
| ⑤ "小马拉大车 / 大马拉小车" | 治污设施规模与生产不匹配 | 查设备能力/环评/产业政策/生产工艺设计 |
| ⑥ 假资料数据 | 假铭牌/假记录/假报表 | 查批复/统计/原材料账/税务发票/水电气 |

### 5.3 在线监测作弊四子手段（详解）

1. **采样子系统**：让企业排放的真实样品采不到（采样头加装过滤网、临时开循环泵、进假样等）
2. **分析子系统**：测量值偏低（修改标准曲线、量程、删除超标数据、使用假标样、设定假参数）
3. **数据采集和通讯子系统**：过滤数据 / 直接传输模拟假数据
4. **计算参数**：修改含氧量、空气过剩系数、温度等

> 提示：采样作弊企业自己可做；分析/数采/通讯/参数修改需**与设备制造商或运营商联手**——这意味着追责要拉长链条。

### 5.4 自动监控数据异常 8 种情形

1. 长期无正当理由无自动监控数据
2. 数据长期在分析方法检出限上下波动
3. 数据变化幅度长期在某一固定值上下小幅波动
4. 数据变化幅度长期在量程 2% 以内波动
5. 监督性监测与同时段自动监控误差超过 HJ/T 354、HJ/T 75 规定的比对监测指标范围
6. 分析仪器/数采仪/监控中心三组数据偏差 > 1%
7. 生产工况/治理设施运行与自动监控数据相关性异常
8. 其他不符合逻辑的数据变化

### 5.5 仪器参数异常 4 种

1. 仪器量程设置过大
2. 实际监测条件变化但仪器参数未调整/未备案
3. 自动监控数据换算公式与国家技术规定不一致
4. 标准曲线改变未登记备案

### 5.6 设施状态异常 3 种

1. 部分擅自停运或闲置
2. 工作环境变化未备案
3. 硬件/软件变化未备案

### 5.7 突击检查自动监测设施五步法

| 步骤 | 操作 |
|---|---|
| ① 控制设备 | 首先切断站房与外界网络连接，不准被检查对象随意操作仪器 |
| ② 收集信息 | 询问仪器浓度计算公式 C=ax+b 或 C=ax²+bx+c，记录 a/b/c 参数；对比校准记录与设备设置是否一致 |
| ③ 查采样与监控因子 | 采样点位、监控因子、仪器选择是否规范 |
| ④ 查数采与传输 | 仪器-数采仪误差 < 1%；数采仪-监控中心一致；全省统一平台、数采仪直连监控仪器 |
| ⑤ 比对监测 | 用低/中/高三种浓度的水质质控样或标气（N₂/O₂/SO₂/NOₓ），低浓度查截距、高浓度查上限、接近排放标准的样品计算误差 |

> 注意要点：先经验判断再比对/远程比对/监测；**点源面源流域监控相结合**——参考地表水/空气自动站、污水处理厂进水口自动监测。

### 5.8 偷排类作弊特征

1. 工艺落后、产污种类多量大、治污投资和运转费用高
2. 污染治理设施运转不正常（特别是无回收价值且处置费高的危废和难处置固废）
3. 附近有大环境容量、市政管网和渗漏条件
4. 调节池水线落差大、应急池常常存有清水
5. 周边环境敏感、环评不同意设置排放口

## 六、第四部分：生态环境监察最新技术

| 技术 | 用途 |
|---|---|
| 1. 卫星照片 | 寻找违法排污口线索 |
| 2. 无人机/无人船 | 搜索目标、抵近现场取证、全方位拍摄、采样监测 |
| 3. 红外成像（夜视仪） | 偷排废水（温差/反应热）、偷排废气（测温判断设施运行） |
| 4. 快速监测 | 快速监测仪器和方法 |
| 5. 机船联用 | 无人机携带红外热成像仪定位 + 引导无人船采样/在线监测 |
| 6. 汽车定位 | 移动源排查 |
| 7. 声呐探测 | 禁飞区、水下和地下暗管探测 |

> 装备清单：秒级水质 VOC 质谱仪、车载 ICP-MS、X 射线荧光分析仪、夜视仪、执法记录仪、无人机+热成像、无人船、声呐。

## 七、第五部分：给现场同志的 9 条建议

1. **树立绿色发展理念**：两山论和高质量发展是精髓。
2. **把监察当做事业干**：事先准备，事后总结。
3. **学会先判断后排查**：熟记各类参数（法规标准/治污工艺/生产工艺/产业政策）。
4. **学会"四最"排查方式**：用"最省钱/最省力/最省事/最安全"的思维方式换位思考。
5. **学会改工艺治污染**：查排污发现工艺问题，改工艺解决污染问题。
6. **经验不能替代监测**：采样代表性 + 程序不违规。
7. **鼓励企业自纠错误**：守法是执法目标；停产和追刑责是解决突出问题的最有效手段。
8. **高度重视群众投诉**：特别关注实名举报。
9. **保护自己关爱下属**：穷尽职责、守住底线。
