# 危险废物贮存场所分区分类管理指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2025-2012附录 |
| 适用范围 | 贮存场所分区分类管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物按危险特性和相容性分类存放的要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 分类原则 | 按危险特性（T/I/R/C）分类 |
| 相容性分析 | 防止不相容废物接触反应 |
| 分区存放 | 物理隔离，标识清晰 |
| 间距要求 | ≥0.5m通道，便于检查 |
| 禁忌配置 | 氧化剂与还原剂分开 |

## 四、合规要点
1. 按危险特性和相容性分类存放
2. 防止不相容废物接触反应
3. 分区标识清晰便于管理
4. 定期核对分区分类情况
