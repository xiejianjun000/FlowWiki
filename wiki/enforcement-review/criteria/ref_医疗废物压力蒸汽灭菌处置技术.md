# 医疗废物压力蒸汽灭菌处置技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ/T 276-2006附录 |
| 适用范围 | 压力蒸汽灭菌 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了医疗废物压力蒸汽灭菌处置的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 感染性废物、损伤性废物 |
| 灭菌温度 | ≥121°C |
| 压力 | 0.1MPa |
| 灭菌时间 | ≥30分钟 |
| 效果验证 | 生物指示剂（枯草芽孢杆菌） |

## 四、合规要点
1. 灭菌参数符合规范要求
2. 使用生物指示剂验证效果
3. 灭菌后废物按一般固废处理
4. 记录灭菌过程参数
