# 废铅蓄电池再生企业大气污染物排放限值

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 31570-2015 |
| 适用范围 | 大气污染物排放限值 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池再生企业大气污染物排放限值。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 铅及其化合物 | ≤0.5mg/m³ |
| 硫酸雾 | ≤10mg/m³ |
| 颗粒物 | ≤30mg/m³ |
| SO₂ | ≤200mg/m³ |
| NOx | ≤300mg/m³ |

## 四、合规要点
1. 废气处理设施完善有效
2. 大气污染物排放符合限值
3. 安装在线监测系统
4. 定期监测废气排放
