# 各省清洁生产审核实施细则 安徽

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 皖发改规〔2023〕4号 |
| 适用范围 | 安徽省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 安徽省发展和改革委员会、安徽省生态环境厅 |
| 实施日期 | 2023-08-01 |

## 二、主要内容
安徽省实施细则结合长三角一体化发展，强化皖北煤化工、皖江城市带承接产业转移、合芜蚌自主创新等区域特色，推动家电、汽车、水泥等优势产业清洁生产审核全覆盖。

## 三、清洁生产技术要求
| 阶段 | 安徽特色要求 |
|------|-------------|
| 名单确定 | 长三角一体化协同 |
| 区域特色 | 皖北煤化工、皖江产业带 |
| 优势产业 | 家电、汽车、水泥 |
| 跨区互认 | 长三角区域互认 |
| 产业转移 | 承接企业重点审核 |

## 四、合规要点
1. 长三角产业转移承接企业应在投产后1年内开展审核。
2. 煤化工企业审核应包含矿井水综合利用内容。
3. 长三角区域审核结果在安徽予以互认。
4. 通过审核企业纳入合芜蚌自主创新配套支持。
