# 一般工业固废跨省转移审批程序

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 部令第23号 |
| 适用范围 | 一般工业固废跨省转移审批 |
| 发布机关 | 生态环境部 |

## 二、主要内容
明确了一般工业固废跨省转移的备案程序、审批时限和监管要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 审批层级 | 省级生态环境部门 |
| 审批时限 | 备案制，材料齐全即备案 |
| 备案材料 | 转移备案表、接受单位证明、运输协议 |
| 有效期 | 每次备案有效期1年 |
| 监管方式 | 信息系统全程跟踪 |

## 四、合规要点
1. 提前与接受地省级部门沟通
2. 通过信息系统提交备案材料
3. 确保运输路线合理、安全
4. 保留转移全过程记录
