# 塑料制品企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国塑料加工工业协会发〔2022〕5号 |
| 适用范围 | 塑料薄膜、板材、管材、注塑件等制造企业 |
| 发布机关 | 中国塑料加工工业协会 |
| 实施日期 | 2022-07-01 |

## 二、主要内容
本指南针对塑料制品企业特点，重点识别原料预处理、成型、二次加工等关键工序清洁生产潜力。强调废塑料再生利用、VOCs管控、能量回收。涵盖塑料回收、VOCs减排审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万元产值VOCs |
| 审核 | 注塑、吹塑工序 |
| 方案筛选 | 废塑料回收+VOCs |
| 高费方案 | 闭路水循环 |
| 实施验证 | 减排+综合利用 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 应分类回收废塑料，建立再生料利用渠道。
2. 注塑、吹塑工序应配套VOCs处理。
3. 含卤素塑料加工应配套废气处理。
4. 增塑剂应选用环保型替代品。
