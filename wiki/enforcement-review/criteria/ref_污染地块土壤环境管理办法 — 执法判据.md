# 污染地块土壤环境管理办法 — 执法判据

> ACE Generator 编译 | Reflector 审核通过

## 行政处罚条款

本办法罚则条款较少，主要依赖上位法。

| 条号 | 违法行为 | 处罚方式 | 法定幅度 |
|------|---------|---------|---------|
| 第三十二条 | 受委托专业机构编制报告不负责任/弄虚作假致报告失实 | 失信情况记入环境信用记录+通过企业信用信息公示系统公开 | 信用惩戒 |
| -- | 未按要求开展土壤环境调查 | 依照《土壤污染防治法》处罚 | 按上位法幅度 |
| -- | 治理修复弄虚作假 | 依照《土壤污染防治法》处罚 | 按上位法幅度 |

## 刑事衔接条款

本办法未直接规定刑事衔接条款。污染地块治理修复中非法排放、倾倒有毒有害物质涉嫌犯罪的，依据《刑法》第三百三十八条污染环境罪追究刑事责任。

专业机构在风险管控、治理修复中弄虚作假造成污染的，除受处罚外还应与造成污染的其他责任者承担连带责任（第十一条第三款）。

## 程序性条款

| 条号 | 内容摘要 |
|------|---------|
| 第二条 | 适用行业：有色金属冶炼/石油加工/化工/焦化/电镀/制革/危废贮存利用处置 |
| 第三条 | 适用情形：拟收回/已收回/用途拟变更为居住和公共设施用地的地块 |
| 第六条 | 全国污染地块土壤环境管理信息系统，土地使用权人须在线填报信息 |
| 第十条 | 责任主体变更的由继承债权债务者承担；灭失/不明确由县级政府承担 |
| 第十条 | 土壤污染治理与修复实行终身责任制 |
| 第十三条 | 接到通知后6个月内完成初步调查，上传信息系统并公开 |
| 第十四条 | 初步调查确认污染后建污染地块名录并确定风险等级 |
| 第十六条 | 接到污染地块名录通知后须开展详细调查并公开 |
| 第十七条 | 在详细调查基础上开展风险评估并公开 |
| 第二十三条 | 拟开发为居住/公共设施的污染地块需治理修复后方可开发 |
| 第二十六条 | 效果评估公开不少于2个月 |
| 第二十七条 | 未经治理修复或未达标的地块，不予批准涉及该地块的环评 |

## 执法要点

1. **适用范围**：仅适用于拟收回/已收回/用途变更的地块，不具备上述情形的另行规定
2. **调查时序**：初步调查6个月、详细调查另行通知，均须上传信息系统并公开
3. **终身责任制**：土壤污染治理修复终身追责，责任主体变更不影响追责
4. **专业机构信用**：弄虚作假的机构记入环境信用记录并向社会公开（第三十二条）
5. **环评联动**：未经治理修复或未达标的地块，环评不予批准（第二十七条），是关键执法抓手
6. **连带责任**：专业机构弄虚作假造成污染的须承担连带责任（第十一条第三款）
