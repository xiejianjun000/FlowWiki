# 危险废物检测方法通则

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ/T 20-1998 |
| 适用范围 | 危险废物检测方法 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物检测的通用要求、方法选择和质量控制。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 方法选择 | 优先国家标准方法 |
| 检测精度 | 符合方法标准要求 |
| 质控措施 | 空白、平行、加标回收 |
| 数据报告 | 保留3位有效数字 |
| 检测周期 | 按方法标准规定执行 |

## 四、合规要点
1. 检测方法优先选用国家标准
2. 全过程实施质量控制
3. 检测数据可追溯
4. 检测报告经审核后发出
