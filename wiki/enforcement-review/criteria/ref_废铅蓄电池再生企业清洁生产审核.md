# 废铅蓄电池再生企业清洁生产审核

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 469-2018 |
| 适用范围 | 清洁生产审核 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池再生企业清洁生产审核的要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 审核周期 | 每5年审核一次 |
| 审核内容 | 工艺、能耗、水耗、污染物 |
| 审核程序 | 准备→评估→方案→实施 |
| 审核报告 | 报告归档并报送 |
| 中高费方案 | 落实审核中高费方案 |

## 四、合规要点
1. 按周期开展清洁生产审核
2. 审核覆盖关键环节
3. 落实中高费方案
4. 审核报告归档报送
