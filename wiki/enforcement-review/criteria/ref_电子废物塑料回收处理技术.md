# 电子废物塑料回收处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 527-2010附录 |
| 适用范围 | 塑料回收处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了电子废物塑料回收处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 电子废物中的塑料部件 |
| 处理工艺 | 分选+清洗+造粒 |
| 塑料种类 | ABS、PS、PP、PE等 |
| 再生塑料 | 符合产品标准 |
| 污染防治 | 防止二次污染 |

## 四、合规要点
1. 塑料分类回收利用
2. 再生塑料符合产品标准
3. 处理过程防止二次污染
4. 建立塑料回收档案
