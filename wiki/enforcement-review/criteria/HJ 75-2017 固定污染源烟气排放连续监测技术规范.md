## HJ 75-2017 固定污染源烟气（SO₂、NOx、颗粒物）排放连续监测技术规范

### 一、标准基本信息

- **标准号**：HJ 75-2017
- **替代标准**：HJ/T 75-2007
- **实施日期**：2018年3月1日
- **归口部门**：生态环境部

### 二、适用范围

适用于固定污染源烟气排放连续监测系统的设计、安装、调试、验收、运行和管理。

### 三、监测系统组成

1. 颗粒物CEMS
2. 气态污染物CEMS（SO₂、NOx）
3. 烟气参数CEMS（O₂、温度、压力、流速、湿度）

### 四、技术性能要求

| 指标 | 限值 |
|------|------|
| 颗粒物准确度 | ≤±15% |
| SO₂准确度 | ≤±15% |
| NOx准确度 | ≤±15% |
| 流速准确度 | ≤±10% |
| O₂准确度 | ≤±15% |
| 系统响应时间 | ≤200s |

### 五、安装要求

- 监测断面位于垂直管段
- 距弯头、阀门下游≥4倍烟道直径
- 距弯头上游≥2倍烟道直径
- 优先布设于负压段

### 六、验收与运行

#### 6.1 验收
- 调试期≥7天
- 验收测试期≥7天
- 参比方法对比测试≥3次

#### 6.2 运行
- 定期校准：颗粒物每24h零点和量程校准
- 气态污染物每24h零点和量程校准
- 定期维护：每周至少1次

### 七、数据有效性

- 1小时均值：至少45分钟有效数据
- 日均值：至少18小时有效数据
- 月均值：至少20天有效数据

### 八、违法处罚

未安装CEMS或CEMS未正常运行的，依据《大气污染防治法》第100条，处**2万元以上20万元以下罚款**。

### 九、对企业环保合规工作的启示

1. CEMS安装必须符合规范要求
2. 定期校准与维护是数据有效的前提
3. 数据审核异常及时排查
4. 建立CEMS运维台账
