# 一般工业固废管理计划编制指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1200-2021附录B |
| 适用范围 | 一般工业固废产生单位管理计划编制 |
| 发布机关 | 生态环境部 |

## 二、主要内容
指导企业编制年度一般工业固废管理计划，明确减量化目标和利用处置方案。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 计划内容 | 产生预测、减量目标、利用处置方案 |
| 编制周期 | 每年编制一次 |
| 报送时限 | 每年3月31日前报送 |
| 调整机制 | 重大变化30日内更新 |
| 审批程序 | 企业审核→报送生态环境部门 |

## 四、合规要点
1. 按指南要求编制年度管理计划
2. 制定明确的减量化和资源化目标
3. 落实管理计划中的各项措施
4. 重大变化时及时调整并报备
