# 废铅蓄电池贮存污染控制技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 519-2020第6章 |
| 适用范围 | 贮存污染控制 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池贮存场所的污染控制要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 选址要求 | 远离敏感区域 |
| 防渗要求 | 符合GB 18597 |
| 贮存时间 | ≤1年 |
| 酸液收集 | 设置酸液收集设施 |
| 监测要求 | 地下水、土壤监测 |

## 四、合规要点
1. 贮存场所符合选址防渗要求
2. 设置酸液收集设施
3. 贮存时间不超过1年
4. 定期开展环境监测
