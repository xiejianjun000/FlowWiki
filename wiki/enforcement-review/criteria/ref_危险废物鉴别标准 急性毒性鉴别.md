# 危险废物鉴别标准 急性毒性鉴别

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 5085.2-2007 |
| 适用范围 | 危险废物急性毒性鉴别 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物急性毒性初筛和鉴别标准值。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 经口毒性 | LD₅₀≤200mg/kg |
| 经皮毒性 | LD₅₀≤1000mg/kg |
| 吸入毒性 | LC₅₀≤10mg/L |
| 试验方法 | 小鼠/大鼠经口、经皮、吸入试验 |
| 鉴别结论 | 符合任一即具有急性毒性 |

## 四、合规要点
1. 急性毒性试验在具备资质的实验室开展
2. 试验过程符合动物伦理要求
3. 保留试验原始记录和数据
4. 鉴别结论用于名录外危废判定
