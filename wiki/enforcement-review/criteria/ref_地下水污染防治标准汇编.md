# 地下水污染防治标准汇编

## 一、地下水污染防治法规体系

### 1.1 法律法规依据

#### 《中华人民共和国水污染防治法》（2018年修订）

- 第四十二条：兴建地下工程设施或者进行地下勘探、采矿等活动，应当采取防护性措施，防止地下水污染
- 第四十三条：人工回灌补给地下水，不得恶化地下水质
- 第四十四条：化学品生产企业以及工业集聚区、矿山开采区、尾矿库、危险废物处置场、垃圾填埋场等的运营、管理单位，应当采取防渗漏等措施，并建设地下水水质监测井进行监测

#### 《中华人民共和国土壤污染防治法》（2019年1月1日施行）

- 第二十二条：设区的市级以上地方人民政府农业农村、林业部门应当会同生态环境、自然资源部门，对农用地地块土壤污染状况调查、风险评估、风险管控、修复等活动进行监督管理
- 第五十条：土壤污染重点监管单位生产经营用地的用途变更或者在其土地使用权收回、转让前，应当进行土壤污染状况调查

#### 《地下水管理条例》（国务院令第748号，2021年12月1日施行）

- 适用范围：中华人民共和国领域内地下水调查评价、规划、利用、保护、治理、监督管理等活动
- 主要制度：地下水调查评价、规划、取水许可、节约保护、超采治理、污染防治、监督管理等

### 1.2 部门规章

- 《地下水污染防治实施方案》（环土壤〔2019〕72号）
- 《关于推进地下水污染防治重点区划定工作的通知》（环办土壤函〔2022〕382号）
- 《工业企业地下水防治工作指南》（环办土壤函〔2020〕445号）

## 二、地下水质量标准

### 2.1 GB/T 14848-2017 地下水质量标准

#### 地下水质量分类

| 类别 | 适用范围 |
|------|---------|
| Ⅰ类 | 地下水化学组分含量低，适用于各种用途 |
| Ⅱ类 | 地下水化学组分含量较低，适用于各种用途 |
| Ⅲ类 | 地下水化学组分含量中等，以人体健康基准值为依据，主要适用于集中式生活饮用水水源及工农业用水 |
| Ⅳ类 | 地下水化学组分含量较高，以农业和工业用水质量要求为依据，除适用于农业和部分工业用水外，适当处理后可作生活饮用水 |
| Ⅴ类 | 地下水化学组分含量高，不宜作生活饮用水，其他用水可根据使用目的选用 |

## 三、地下水污染防治重点区划定

### 3.1 重点区类型

#### 地下水污染防治重点区

| 类型 | 范围 |
|------|------|
| 饮用水水源保护区 | 集中式地下水饮用水水源地保护区 |
| 污染风险区 | 已存在地下水污染的区域 |
| 保护区 | 涉及地下水功能的自然保护区、生态红线区 |
| 其他重点区 | 法律法规规定的其他地下水污染防治重点区 |

### 3.2 重点区管理要求

#### 饮用水水源保护区

1. **一级保护区**：禁止新建、改建、扩建与供水设施和保护水源无关的建设项目
2. **二级保护区**：禁止新建、改建、扩建排放污染物的建设项目
3. **准保护区**：严格控制排放污染物的建设项目

#### 污染风险区

1. 加密监测
2. 限制新建污染源
3. 督促现有污染源治理
4. 推进污染场地修复

## 四、重点行业地下水污染防治

### 4.1 重点行业类型

1. 化工行业（含石油化工）
2. 电镀行业
3. 制药行业
4. 皮革行业
5. 印染行业
6. 有色金属冶炼行业
7. 危险废物处置行业
8. 垃圾填埋场
9. 矿山开采
10. 加油站

### 4.2 重点行业防渗要求

#### 化工行业

1. 生产装置区：HDPE 防渗膜，渗透系数 ≤ 1.0×10⁻¹² cm/s
2. 储罐区：双层罐 + 防渗漏检测系统
3. 管道区：双层管道 + 防渗漏检测系统
4. 污水处理设施：混凝土防渗 + 防渗膜

#### 加油站

1. 储油罐：双层钢制罐或玻璃钢罐
2. 输油管道：双层管道
3. 防渗漏检测：在线监测系统
4. 观察井：四周设置观察井

#### 垃圾填埋场

按 GB 16889-2024《生活垃圾填埋场污染控制标准》要求：

1. 防渗系统：双层人工合成衬垫
2. 渗滤液收集：底部导排系统
3. 地下水监测井：周围至少 5 口监测井

### 4.3 地下水水质监测井

#### 监测井设置

1. **本底监测井**：污染源上游 1 口
2. **污染扩散监测井**：污染源两侧各 1 口
3. **污染监测井**：污染源下游 1-2 口

#### 监测井技术要求

1. 井深：穿透污染层
2. 井管：UPVC 或不锈钢管
3. 滤水管：开孔率 10%-15%
4. 井台：保护井口

## 五、地下水监测

### 5.1 HJ 164-2020 地下水环境监测技术规范

#### 监测井布设

##### 布设原则

1. 代表性
2. 可比性
3. 长期性
4. 经济性

##### 布设方法

1. 网格法：按 1-5 km 网格布设
2. 带状法：沿河流、海岸布设
3. 源项法：围绕污染源布设

#### 监测项目

##### 必测项目

- pH、总硬度、溶解性总固体、氯化物、硫酸盐、氨氮、硝酸盐氮、亚硝酸盐氮、高锰酸盐指数

##### 选测项目

- 重金属、挥发性有机物、半挥发性有机物、农药类

#### 监测频次

| 类别 | 监测频次 |
|------|---------|
| 重点污染源监测井 | 每月 1 次 |
| 饮用水水源监测井 | 每月 1 次 |
| 一般监测井 | 每季度 1 次 |
| 本底监测井 | 每年 1 次 |

### 5.2 HJ 25.2-2019 建设用地土壤污染风险管控和修复监测技术导则

适用于污染场地地下水监测：

#### 监测点位布设

1. 污染源内：3-5 个监测点
2. 污染源外：1-2 个监测点
3. 上、下游：本底、扩散点

#### 监测项目

按场地污染特征确定。

### 5.3 监测方法

| 项目 | 监测方法 |
|------|---------|
| pH | GB 6920 玻璃电极法 |
| 总硬度 | GB 7477 EDTA 滴定法 |
| 溶解性总固体 | GB 11901 重量法 |
| 氨氮 | HJ 535 纳氏试剂分光光度法 |
| 硝酸盐氮 | HJ 347 紫外分光光度法 |
| 重金属 | HJ 700 ICP-MS 法 |
| 挥发性有机物 | HJ 639 吹扫捕集气相色谱-质谱法 |
| 半挥发性有机物 | HJ 834 气相色谱-质谱法 |
| 农药类 | HJ 699 气相色谱-质谱法 |

## 六、地下水污染修复

### 6.1 修复技术

#### 按修复地点分类

| 类型 | 主要技术 |
|------|---------|
| 异位修复 | 抽出处理法、土壤开挖处理 |
| 原位修复 | 原位化学氧化、原位化学还原、原位生物修复、原位曝气、渗透性反应墙 |

#### 按污染类型分类

##### 重金属污染修复

1. 抽出处理法
2. 渗透性反应墙
3. 原位稳定化/固化

##### 有机物污染修复

1. 抽出处理法
2. 原位化学氧化（高锰酸盐、过硫酸盐、芬顿试剂）
3. 原位化学还原（零价铁）
4. 原位生物修复
5. 原位曝气
6. 土壤气相抽提

### 6.2 修复目标

#### 修复目标确定原则

1. 满足地下水质量标准
2. 满足饮用水水源要求
3. 满足生态环境要求
4. 考虑技术可行性和经济合理性

#### 修复目标值

- 一般按 GB/T 14848 Ⅲ类水质标准
- 敏感区域按 Ⅱ类或 Ⅰ类水质标准
- 非敏感区域可按 Ⅳ类水质标准

### 6.3 修复效果评估

#### 评估内容

1. 修复前后水质对比
2. 修复效率
3. 残留污染物
4. 二次污染

#### 评估标准

- 修复目标达标率 ≥ 90%
- 残留污染物浓度 ≤ 修复目标值的 1.5 倍
- 无二次污染

## 七、违法处罚依据

### 7.1 《水污染防治法》第八章 法律责任

| 违法行为 | 法律依据 | 罚款金额 |
|---------|---------|---------|
| 未采取防护性措施，造成地下水污染 | 第八十五条 | 责令改正，处 10-100 万元罚款 |
| 人工回灌补给地下水，恶化地下水质 | 第八十五条 | 责令改正，处 10-100 万元罚款 |
| 未建设地下水水质监测井进行监测 | 第八十五条 | 责令改正，处 2-20 万元罚款 |
| 未采取防渗漏等措施 | 第八十五条 | 责令改正，处 10-100 万元罚款 |

### 7.2 《土壤污染防治法》第九十四条

- 土壤污染重点监管单位未履行土壤污染状况调查义务的，处 2-20 万元罚款
- 情节严重的，处 20-100 万元罚款

### 7.3 《地下水管理条例》第八章 法律责任

- 未按照规定取用地下水的，责令限期改正，处 2-10 万元罚款
- 未经批准擅自取用地下水的，责令停止违法行为，处 2-10 万元罚款

## 九、对企业环保合规工作的启示

1. **开展地下水调查**：定期开展地下水水质监测
2. **建立监测井**：按规定建设地下水水质监测井
3. **防渗措施**：采取防渗措施，防止地下水污染
4. **应急预案**：编制地下水污染应急预案
5. **及时处置**：发现地下水污染及时处置
6. **配合调查**：配合生态环境部门调查
7. **承担费用**：承担地下水污染修复费用
8. **建立档案**：完整保存地下水监测档案
