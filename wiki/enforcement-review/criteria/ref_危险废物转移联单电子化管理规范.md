# 危险废物转移联单电子化管理规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1200-2021附录D |
| 适用范围 | 转移联单电子化 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物转移联单电子化系统的功能和操作要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 系统功能 | 联单生成、传送、确认、查询 |
| 身份认证 | 数字证书+生物识别 |
| 数据要素 | 废物信息、运输信息、交接信息 |
| 传输时效 | 实时传输至全国固废信息系统 |
| 存档要求 | 电子联单保存≥10年 |

## 四、合规要点
1. 通过电子联单系统办理转移
2. 确保身份认证信息安全
3. 联单数据实时传输至信息系统
4. 电子联单长期保存备查
