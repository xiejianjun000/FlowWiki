# 危险废物转移包装技术要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 12463-2009 |
| 适用范围 | 转移包装技术要求 |
| 发布机关 | 交通运输部 |

## 二、主要内容
规定了危险废物转移包装的材质、结构、性能和标识要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 包装材质 | 与废物相容，不发生反应 |
| 包装结构 | 密封、防渗、防破裂 |
| 性能要求 | 通过跌落、堆码、气密试验 |
| 包装标识 | 危废标识、UN编号、危险特性 |
| 包装等级 | I类、II类、III类 |

## 四、合规要点
1. 包装材质与废物相容
2. 包装性能通过标准试验
3. 包装标识完整清晰
4. 包装等级与废物危险特性匹配
