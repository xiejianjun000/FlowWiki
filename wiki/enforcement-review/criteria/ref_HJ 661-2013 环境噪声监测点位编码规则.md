# HJ 661-2013 环境噪声监测点位编码规则

## 一、标准基本信息

- **标准号**：HJ 661-2013
- **实施日期**：2013年9月1日

## 二、适用范围

适用于环境噪声监测点位的编码、识别和管理。

## 三、编码原则

### 3.1 编码结构

```
XX XXXX XX XX XX
│  │    │  │  │
│  │    │  │  └─ 序号
│  │    │  └──── 监测类型
│  │    └─────── 功能区类型
│  └──────────── 市/县代码
└─────────────── 省/自治区/直辖市代码
```

### 3.2 监测类型代码

- 01：区域声环境监测
- 02：道路交通噪声监测
- 03：功能区噪声监测
- 04：工业企业厂界噪声监测
- 05：建筑施工场界噪声监测
- 06：社会生活噪声监测

### 3.3 功能区类型代码

- 0：0类区
- 1：1类区
- 2：2类区
- 3：3类区
- 4a：4a类区
- 4b：4b类区

## 四、编码管理

- 编码唯一性
- 编码稳定性
- 编码可扩展性

## 五、对企业环保启示

1. 监测点位编码统一管理
2. 便于数据查询和统计分析
3. 支持环境噪声信息化管理
