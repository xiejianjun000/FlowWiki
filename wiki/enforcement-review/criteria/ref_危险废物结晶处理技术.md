# 危险废物结晶处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014第6.2条 |
| 适用范围 | 结晶处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物结晶处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 含盐废液 |
| 结晶方式 | 冷却结晶、蒸发结晶 |
| 晶体纯度 | 符合回收要求 |
| 母液处理 | 返回处理或处置 |
| 设备要求 | 耐腐蚀材质 |

## 四、合规要点
1. 根据废物特性选择结晶方式
2. 控制结晶条件保证纯度
3. 母液合理处理处置
4. 设备耐腐蚀可靠
