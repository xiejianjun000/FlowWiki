# 橡胶制品企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国橡胶工业协会发〔2022〕6号 |
| 适用范围 | 轮胎、橡胶板管带、橡胶零件等制造企业 |
| 发布机关 | 中国橡胶工业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对橡胶制品企业特点，重点识别混炼、成型、硫化等关键工序清洁生产潜力。强调低温连续混炼、废气收集处理、废橡胶再生利用。涵盖VOCs、硫化烟气管控审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨胶能耗、VOCs |
| 审核 | 混炼、硫化工序 |
| 方案筛选 | 废胶回收+烟气治理 |
| 高费方案 | 低温连续混炼 |
| 实施验证 | 减排+回收 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 应采用低温连续混炼工艺。
2. 硫化机应配套烟气收集处理装置。
3. 废橡胶应建立再生胶、胶粉利用渠道。
4. 排放废气应执行GB 27632排放标准。
