# 危险废物毒性物质含量鉴别技术细则

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 5085.6附录 |
| 适用范围 | 毒性物质含量鉴别技术细则 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了毒性物质含量鉴别的具体检测项目、方法和限值。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 剧毒物质清单 | 39种（如氰化物、汞化合物） |
| 致癌物质清单 | 63种（如苯并[a]芘） |
| 检测方法 | GB方法或行业标准方法 |
| 数据计算 | 各物质含量之和≥限值即判定 |
| 报告要求 | 列明检出物质及含量 |

## 四、合规要点
1. 检测项目覆盖废物中可能存在的毒性物质
2. 使用标准检测方法保证数据可靠
3. 准确计算毒性物质含量
4. 鉴别结论用于危废判定
