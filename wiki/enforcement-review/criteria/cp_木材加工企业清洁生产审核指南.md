# 木材加工企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国木材协会发〔2022〕5号 |
| 适用范围 | 锯材、木片、人造板原料加工企业 |
| 发布机关 | 中国木材协会 |
| 实施日期 | 2022-07-01 |

## 二、主要内容
本指南针对木材加工企业特点，重点识别锯材、干燥、刨光等关键工序清洁生产潜力。强调木粉木屑回收、能量回收、低甲醛胶黏剂应用。涵盖木材利用率、VOCs减排审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | m³锯材能耗、木粉 |
| 审核 | 锯切、干燥工序 |
| 方案筛选 | 木粉回收+干燥节能 |
| 高费方案 | 余热回收系统 |
| 实施验证 | 节能+综合利用 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 木粉、木屑应回收作燃料或原料。
2. 干燥窑应使用废木料作燃料。
3. 含醛胶黏剂应使用低甲醛或无醛替代品。
4. 边角料应回收综合利用。
