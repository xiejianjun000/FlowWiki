## HJ 956-2018 排污许可证申请与核发技术规范 精炼石油产品制造

### 一、标准基本信息

- **标准号**：HJ 956-2018
- **实施日期**：2018年7月1日

### 二、适用范围

适用于原油加工及石油制品制造排污单位。

### 三、产污环节

- 催化裂化：颗粒物、SO₂、NOx、催化剂
- 催化重整：VOCs、苯
- 延迟焦化：VOCs、石油焦
- 污水处理：VOCs、氨、硫化氢
- 储运系统：VOCs

### 四、水污染物许可排放限值

| 污染物 | 直接排放 | 间接排放 |
|--------|----------|----------|
| COD | 60 | 500 |
| BOD₅ | 20 | 100 |
| 氨氮 | 8 | 30 |
| 总氮 | 25 | 50 |
| 总磷 | 1.0 | 3.0 |
| 石油类 | 5 | 20 |
| 挥发酚 | 0.3 | 1.0 |
| 总氰化物 | 0.2 | 0.5 |
| 硫化物 | 0.5 | 1.0 |
| 苯 | 0.1 | 0.1 |
| 甲苯 | 0.1 | 0.1 |

### 五、大气污染物许可排放限值

| 污染源 | 颗粒物 | SO₂ | NOx | VOCs | 苯 |
|--------|--------|-----|-----|------|-----|
| 催化裂化 | 50 | 100 | 200 | - | - |
| 加热炉 | 50 | 100 | 200 | - | - |
| 储罐 | - | - | - | 20 | - |
| 装卸 | - | - | - | 30 | - |
| 污水处理 | - | - | - | 60 | 0.5 |
| 设备密封点 | - | - | - | 10000 ppm | - |

### 六、自行监测

- 主要排放口：颗粒物、SO₂、NOx在线监测
- VOCs：每月1次
- LDAR（泄漏检测与修复）：每年1次
- 储罐、装卸：每年1次

### 七、对企业环保启示

1. 石化行业VOCs治理是关键
2. LDAR是VOCs管控核心
3. 储运系统VOCs治理重点
