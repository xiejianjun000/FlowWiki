# 危险废物转移过程GPS监控技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | JT/T 1180.2-2018 |
| 适用范围 | 转移过程GPS监控 |
| 发布机关 | 交通运输部 |

## 二、主要内容
规定了危险废物转移车辆GPS监控的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 定位精度 | ≤10m |
| 数据传输 | 实时传输至监管平台 |
| 轨迹保存 | ≥1年 |
| 报警功能 | 偏航、超速、长时间停车报警 |
| 设备要求 | 北斗/GPS双模定位 |

## 四、合规要点
1. 转移车辆安装GPS监控设备
2. 实时传输定位数据至监管平台
3. 轨迹数据长期保存
4. 异常情况及时报警处置
