二、制定目的与依据
================================================================================

为贯彻《中华人民共和国环境保护法》《中华人民共和国水法》《中华人民共和国
水污染防治法》《中华人民共和国大气污染防治法》和《排污许可管理条例》，加强
固定污染源排放监测监管，规范排污单位废气、污水排放口监测点位设置，制定本标准。

制定背景与主要考虑：
1. 统一技术要求：此前GB/T 16157、HJ/T 397、HJ 75等十余项标准中均有监测点位
   设置要求，但规定不尽一致，给排污单位带来困扰。本标准的出台统一了相关技术
   要求。
2. 完善技术内容：增加了监测梯架设置、视频监控安装、风险源警示监控、信息标识牌
   等通用性要求，保证监测点位的可达性和人员安全性。
3. 增加点位管理要求：明确了监测点位全生命周期管理要求，为加强污染源监测和环境
   监管执法提供支撑。

================================================================================
三、适用范围
================================================================================

适用于排污单位（海洋油气开发工程除外）对固定污染源排放口手工监测点位、自动
监测点位的规范化设计、建设、改造、整改、验收和管理。

排放标准中对处理设施效率有明确要求的，处理设施入口也应执行本标准，其他处理
设施入口等中间过程监测点位可参照执行。

五、术语和定义（共12条）
================================================================================

3.1 排污单位：各类排放污染物的企业事业单位和其他生产经营者。
3.2 排放口：将在生产与生活活动中产生的废气、污水向大气或环境水体排放的构筑物。
3.3 监测点位：为开展固定污染源监测而设置的位置或场所，包括在排放口设置的监测孔、
    工作平台、梯架及其保障性、辅助性设施等。
3.4 废气：在生产与生活活动中排放的气体及其中混合的颗粒物的总称。
3.5 污水：在生产与生活活动中排放的水的总称。
3.6 监测断面：为测量或采集样品，设置在排气筒/烟道上垂直于气流方向，或设置在
    排水管道/渠道上垂直于水流方向的横断面。
3.7 监测孔：为监测或采集废气样品，在监测断面处开设的孔口。
3.8 工作平台：永久性安装在建筑物或设备上的具有一定面积和承载负荷的，带有防护
    装置的，可用于环境监测的稳定工作平台。
3.9 防护栏杆：永久性安装在梯架、平台、通道、升降口及其他敞开边缘防止人员坠落的
    围护设施。
3.10 梯架：永久性安装在建筑物或设备上，供人员通往工作平台而设置的钢直梯、钢斜梯、
     转梯或升降梯等。
3.11 坠落高度基准面：可能坠落范围内最低处的水平面。
3.12 量水堰（槽）：设置在排水管道/渠道上，由上下游行近段、堰体和水位观测设施
     组成的用于流量计测量的装置。

六、废气排放口监测点位设置技术要求
================================================================================

6.1 监测断面要求

6.1.1 断面类型与位置
- 监测断面包含手工监测断面和自动监测断面
- 应设置在规则的圆形、矩形排气筒/烟道上的竖直段或水平段
- 避开拉筋等影响监测的内部结构件
- 宜设置在排气筒/烟道的负压段（有特殊要求的除外）

6.1.2 断面距离要求
- 自动监测断面和手工监测断面：
  上游距离弯头、阀门、变径管 ≥ 4倍烟道直径
  下游距离上述部件 ≥ 2倍烟道直径
- 排气筒出口处视为变径
- 对于矩形排气筒/烟道，以当量直径计：D = 2×L×W/(L+W)
- 旧标准为"前6后3"，新标准调整为"前4后2"，更宽松

6.1.3 无法满足时的措施
- 应选择流场均匀稳定的监测断面，避开涡流区
- 保证断面无紊流，流速相对均方差 σr ≤ 0.15

6.1.4 自动与手工断面关系
- 所有自动监测断面应设置在手工监测断面上游 0.5m内

6.2 监测孔要求

6.2.1 内径要求
- 手工监测孔内径应满足相关污染物和排气参数的监测需要
- 一般应 ≥ 80mm（旧标准中颗粒物≥80mm、气态污染物≥40mm，新标准统一为≥80mm）

6.2.2 密封要求
- 手工监测孔应符合密封要求
- 封闭形式宜优先参照HG/T 21533、HG/T 21534、HG/T 21535设计为快开方式
- 采用盖板、管堵或管帽封闭的，应在监测时便于开启

6.2.3 正压/高温/有毒气体
- 对正压下输送高温或有毒有害气体的排气筒/烟道，应安装带有闸板阀的密封防喷监测孔
- 其他形式的手工监测孔外沿距离排气筒/烟道或保温层外壁距离应 ≤ 50mm

6.2.4 部件平整要求
- 法兰、闸板阀等部件伸入排气筒/烟道部分应与其内壁平齐

6.2.5 CEMS下游监测孔
- 烟气排放连续监测系统的监测断面下游 0.5m内，应开设手工监测孔

6.2.6 圆形排气筒监测孔数量
- 竖直圆形：
  D ≤ 1m时，至少1个
  1m < D ≤ 3.5m时，至少设置相互垂直的2个
  D > 3.5m时，至少设置相互垂直的4个
- 水平圆形：
  D ≤ 3.5m时，至少在侧面水平位置设置1个
  D > 3.5m时，至少在两侧水平对称位置设置2个
- 手工监测孔应设在直径线上

6.2.7 矩形排气筒监测孔
- 竖直矩形：
  L或W ≤ 3.5m时，至少在长边一侧开1排水平的监测孔
  L和W均 > 3.5m时，至少在长边两侧对开各1排水平的监测孔
- 水平矩形：
  W ≤ 3.5m时，至少在单侧开设1排竖直的监测孔
  W > 3.5m时，至少在烟道两侧各开设1排竖直的监测孔
- 相邻两孔间距 ≤ 1m
- 两端孔距烟道内壁 ≤ 0.5m

6.2.8 顶部开孔
- 水平排气筒/烟道侧面不具备条件且高度或直径 ≤ 3.5m时，可在顶部开设监测孔

6.3 工作平台要求

6.3.1 一般要求
- 设置条件：监测断面距离坠落高度基准面2m以上时，应配套建设永久、安全、便于
  采样和测试的工作平台（不得使用临时或移动平台）
- 平台位置：除在水平烟道顶部开设监测孔外，工作平台宜设置在监测孔的正下方
  1.2m ~ 1.3m处

6.3.2 结构要求
- 尺寸：
  工作平台长度应 ≥ 2m
  监测断面直径（圆形）或监测孔方向长度（矩形）> 1m时，宽度应 ≥ 2m
  ≤ 1m时，宽度应 ≥ 1.5m
- 净高：
  单层工作平台及通道上方竖直方向净高应 ≥ 2m
  多层工作平台的每层净高应 ≥ 1.9m
- 铺装材料：
  宜采用厚度 ≥ 4mm的花纹钢板或经防滑处理的钢板铺装
  相邻钢板不应搭接，上表面高度差 ≤ 4mm
  载荷满足GB 4053.3要求
- 间隙距离：工作平台与竖直烟道/排气筒的间隙距离 ≤ 10mm

6.3.3 防护要求
- 防护栏杆：距离坠落高度基准面1.2m以上的工作平台及通道所有敞开边缘应设置
  防护栏杆，工作平台的防护栏杆应带踢脚板
- 栏杆高度：防护栏杆高度应 ≥ 1.2m
- 扶手：宜选用外径30mm~50mm钢管，扶手后应有不少于75mm净空间
- 踢脚板：宜采用不小于100mm×2mm钢板制作，顶部在平台面上高度应不小于100mm，
  底部距平台面应不大于10mm
- 中间栏杆：扶手和踢脚板之间应至少设置一道中间栏杆，空隙间距 ≤ 500mm
- 立柱间距：防护栏杆端部应设置立柱，立柱间距应 ≤ 1m
- 防腐涂装：平台及防护栏杆安装后，应对其至少涂一层底漆和一层面漆，或采用
  等效的防锈防腐涂装

6.3.4 其他要求
- 电源：
  主要排放口及自动监测点位工作平台应设置220V防水低压配电箱
  内设漏电保护器、三相接地线、不少于2个插座（额定电流≥10A）
  其他排放口50m内应配备永久电源和不少于2个电缆卷盘（长度≥50m）
- 视频监控：
  监控范围应包含工作平台所有采样探头、监测孔等
  分辨率不低于200万（1920×1080）像素
  帧率不低于30fps
  图像延迟≤600ms
  录像保存时限原则上不少于1年
- 照明：
  夜间生产的主要排放口工作平台和梯架应设置固定照明
  照度标准值不低于30lx
- 安全防护：
  工作平台附近有危险源时，应设置防护装置和安全标志
  上方有坠落物体隐患时，应在平台上方3m高处设置顶棚等防护装置

6.4 梯架要求

- 距离0.5m~2m：应按照GB 4053.1或GB 4053.2要求设置固定式钢梯
- 距离≥2m：应安装钢斜梯、转梯到达监测平台，不得仅设置钢直梯
  梯架无障碍宽度应≥0.8m，倾角≤38°，踏板深度≥80mm，相邻踏板前后重叠
  10mm~35mm
- 梯高>6m：应设置梯间平台
- 高度≥20m：应安装升降梯或其他等效吊装设备
- 高度≥40m：宜安装电梯到达工作平台

================================================================================
七、污水排放口监测点位设置技术要求
================================================================================

7.1 总体要求
- 原则上，一个排污单位仅保留一个污水排放口
- 排放口位置应符合环评文件及排污许可证要求
- 排放口型式应满足流量测定和样品采集的基本条件
- 不得设置旁路或暗管，所有废水必须经处理达标后通过唯一合法排放口外排

7.2 监测点位位置要求
- 监测点位宜设置在厂界内或厂界外10m范围内
- 应避开雨水混入区域

7.3 不同类型排放口的技术要求
- 明渠排放口：必须安装标准化量水堰或量水槽（如巴歇尔槽、三角堰等），保证
  流量测量精度
- 压力管道式排放口：应安装电磁流量计或其他符合计量要求的流量装置，上游直管段
  长度≥5倍管道直径，下游≥2倍管道直径
- 小流量排放口（日排放量<50m³）：应设置规则形状的排水管道或渠道，上游顺直段
  长度≥3m，并设有不低于0.1m的垂直落差，以便形成稳定水流用于测流

八、信息标志牌要求
================================================================================

8.1 技术规格
- 尺寸：480mm×300mm
- 颜色：底色及立柱为绿色，图案、边框、支架和文字为白色
- 材质：表面经搪瓷或贴膜处理，无气泡、无色差，耐候性强
- 字体：中文使用黑体字，清晰易读
- 二维码：嵌入二维码，链接至排污单位相关信息系统，编码规则按HJ 1297执行

8.2 污水排放口标志牌信息内容
- 排污单位名称
- 排污许可证编号
- 排放去向（如"进入城镇污水处理厂"或"直接排入XX河流"）
- 污水来源（如"生产废水""生活污水"）
- 污水处理工艺投运时间
- 其他按排污许可证要求载明的内容

8.3 安装位置
- 安装位置不得妨碍正常监测工作
- 标志牌上缘距离工作平台基准面约2m，便于识别和扫码
- 污水监测点位可安装于建筑物立面或采用独立立柱支撑

================================================================================
九、排放口监测点位管理要求
================================================================================

9.1 日常运行维护
- 排污单位应建立监测点位日常运行维护制度，确保设施完好、正常运行
- 建立管理台账，记录各排放口的位置、编号、监测点参数、建设时间、改造情况等
  信息，并随排污许可证变更及时更新

9.2 全过程管理
- 标准明确了监测点位建设、管理、变更的全过程管理要求
- 鼓励利用数字化管理系统进行动态维护

9.3 标志牌维护
- 标志牌必须保持清晰、完整
- 发现形象损坏、颜色污染或有变化、退色等不符合情况，应及时修复或更换
- 检查时间至少每年一次

十二、实施保障与过渡期安排
================================================================================

1. 过渡期：考虑到现有企业改造通常需在大修停产期间进行，标准设定了两年过渡期，
   2027年1月1日起正式实施。
2. 新建企业：应按照本标准设置监测点位。
3. 已有企业：应在实施之日前完成升级改造。
4. 衔接安排：按新标准设置或改造的，视为同时满足旧标准要求，不会因新旧规定不
   一致而受处罚。
