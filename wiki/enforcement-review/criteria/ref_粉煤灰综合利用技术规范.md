# 粉煤灰综合利用技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 1596-2017 |
| 适用范围 | 粉煤灰的综合利用活动 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了粉煤灰在水泥、混凝土、建材等领域利用的技术要求和品质指标。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 品质分级 | I级、II级、III级 |
| 细度要求 | I级≤12.0%，II级≤25.0% |
| 烧失量 | I级≤5.0%，II级≤8.0% |
| 利用途径 | 水泥混合材、混凝土掺合料、路基材料 |
| 放射性 | 符合GB 6566要求 |

## 四、合规要点
1. 使用前检测粉煤灰品质指标
2. 控制掺量保证产品性能
3. 利用过程防止二次污染
4. 建立粉煤灰利用台账
