# 废酸废碱物化处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014附录 |
| 适用范围 | 废酸废碱物化处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废酸废碱物化处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 废酸处理 | 中和、回收利用 |
| 废碱处理 | 中和、回收利用 |
| 中和剂 | 石灰、废碱/废酸互补 |
| pH控制 | 6-9 |
| 副产物 | 硫酸钙等可综合利用 |

## 四、合规要点
1. 废酸废碱互补中和利用
2. 可回收利用的废酸废碱回收
3. 中和后pH达标排放
4. 副产物合理利用
