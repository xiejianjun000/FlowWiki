# 国家危险废物名录2025年版详解

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 部令第23号 |
| 适用范围 | 国家危险废物名录的解读和适用 |
| 发布机关 | 生态环境部 |

## 二、主要内容
详解2025年版名录的修订内容、危险废物代码、行业来源和危险特性。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 废物类别 | 46大类467种危险废物 |
| 代码体系 | 8位行业代码+3位废物代码 |
| 行业来源 | 按国民经济行业分类 |
| 危险特性 | T毒性/I易燃/R反应/C腐蚀 |
| 豁免清单 | 附录中列明豁免管理内容 |

## 四、合规要点
1. 准确识别本企业产生的危险废物
2. 按名录代码申报和管理危废
3. 关注豁免清单减少管理成本
4. 及时跟踪名录修订动态
