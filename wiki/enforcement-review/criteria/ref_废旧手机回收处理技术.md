# 废旧手机回收处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 527-2010附录 |
| 适用范围 | 手机回收处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废旧手机回收处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 各类废旧手机 |
| 处理工艺 | 拆解+分选+回收 |
| 数据销毁 | 手机数据彻底销毁 |
| 贵金属回收 | 金、银、钯等 |
| 污染防治 | 防止二次污染 |

## 四、合规要点
1. 手机规范拆解处理
2. 手机数据彻底销毁
3. 贵金属回收利用
4. 处理过程防止污染
