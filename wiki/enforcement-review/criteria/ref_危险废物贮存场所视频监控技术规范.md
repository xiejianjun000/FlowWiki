# 危险废物贮存场所视频监控技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1200-2021附录C |
| 适用范围 | 贮存场所视频监控 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物贮存场所视频监控的安装、运行和管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 监控范围 | 场所出入口、贮存区、装卸区 |
| 摄像头要求 | 高清（≥1080P）、夜视 |
| 存储要求 | 录像保存≥90天 |
| 数据传输 | 实时传输至监管平台 |
| 运行管理 | 24小时不间断运行 |

## 四、合规要点
1. 按规范安装视频监控系统
2. 监控范围覆盖关键区域
3. 录像保存不少于90天
4. 系统保持正常运行
