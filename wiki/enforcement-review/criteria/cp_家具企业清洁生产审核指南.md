# 家具企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国家具协会发〔2022〕5号 |
| 适用范围 | 木质、金属、竹藤、塑料家具制造企业 |
| 发布机关 | 中国家具协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对家具企业特点，重点识别锯材、拼板、涂装、组装等关键工序清洁生产潜力。强调水性涂料、UV固化涂料、木粉粉尘回收、VOCs管控。涵盖水性涂料占比、VOCs减排审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万元产值VOCs |
| 审核 | 涂装工序重点 |
| 方案筛选 | 水性漆+UV固化 |
| 高费方案 | VOCs处理升级 |
| 实施验证 | VOCs减排 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 应使用水性涂料或UV涂料。
2. 喷漆房应配套VOCs处理装置。
3. 金属家具应使用粉末涂料。
4. 木粉、边角料应回收利用。
