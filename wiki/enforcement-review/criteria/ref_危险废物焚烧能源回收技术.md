# 危险废物焚烧能源回收技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 176-2020第7.5条 |
| 适用范围 | 焚烧能源回收 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧余热回收和利用技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 余热回收 | 余热锅炉回收烟气热量 |
| 蒸汽参数 | 根据利用方式确定 |
| 利用方式 | 发电、供热、自用 |
| 能效要求 | 热效率≥70% |
| 安全措施 | 防止高温腐蚀和积灰 |

## 四、合规要点
1. 配置余热回收系统提高能效
2. 防止高温腐蚀和积灰
3. 余热合理利用降低成本
4. 定期维护余热回收设备
