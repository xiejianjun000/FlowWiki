# 含砷废物物化处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014附录 |
| 适用范围 | 含砷废物物化处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了含砷废物物化处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 含砷废液、含砷废料 |
| 处理工艺 | 铁盐沉淀+絮凝 |
| 沉淀剂 | 三氯化铁+石灰 |
| pH控制 | 7-8 |
| 出水要求 | 砷≤0.5mg/L |

## 四、合规要点
1. 含砷废物单独收集处理
2. 铁盐沉淀+絮凝组合
3. 出水砷含量达标排放
4. 污泥按危废规范处置
