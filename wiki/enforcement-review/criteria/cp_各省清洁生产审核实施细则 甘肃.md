# 各省清洁生产审核实施细则 甘肃

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 甘发改规〔2023〕4号 |
| 适用范围 | 甘肃省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 甘肃省发展和改革委员会、甘肃省生态环境厅 |
| 实施日期 | 2023-08-01 |

## 二、主要内容
甘肃省实施细则对接黄河流域生态保护和西部大开发战略，重点推动石化、有色、钢铁、新能源等支柱产业清洁生产升级。强化祁连山生态保护区、黄河甘肃段工业企业审核要求。

## 三、清洁生产技术要求
| 阶段 | 甘肃特色要求 |
|------|-------------|
| 名单确定 | 黄河流域+祁连山保护 |
| 重点产业 | 石化、有色、钢铁、新能源 |
| 祁连山 | 生态敏感区重点管控 |
| 节水优先 | 水资源约束突出 |
| 西部开发 | 政策资金叠加 |

## 四、合规要点
1. 祁连山生态保护区企业审核应严格节水指标。
2. 石化企业审核应包含挥发性有机物管控。
3. 有色冶炼企业审核应包含重金属总量控制。
4. 新能源装备制造企业审核可享受绿色通道。
