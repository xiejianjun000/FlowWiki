# 危险废物处理后判定规则

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 5085.7-2019第6条 |
| 适用范围 | 危险废物处理后的判定 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物处理后产物和残渣的判定规则。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 处理过程 | 利用、处置、预处理 |
| 残渣判定 | 处理后仍具危险特性的按危废管理 |
| 产物判定 | 符合产品标准的可不按危废管理 |
| 鉴别要求 | 处理后需重新鉴别特性 |
| 管理衔接 | 与利用处置许可证衔接 |

## 四、合规要点
1. 处理后产物和残渣分别鉴别
2. 符合产品标准方可作为产品
3. 残渣按危废规范管理
4. 保留处理和鉴别全过程记录
