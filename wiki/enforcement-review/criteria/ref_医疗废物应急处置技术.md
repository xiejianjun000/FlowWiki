# 医疗废物应急处置技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ/T 177-2005附录 |
| 适用范围 | 应急处置 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了医疗废物突发情况应急处置技术。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 应急情况 | 疫情暴发、处置设施故障 |
| 应急设施 | 移动式焚烧炉、临时贮存 |
| 处置方式 | 就地处置或转移处置 |
| 防护要求 | 加强个人防护 |
| 环境监测 | 加强环境监测 |

## 四、合规要点
1. 制定应急处置预案
2. 配置应急设施和物资
3. 应急情况下及时处置
4. 加强防护和环境监测
