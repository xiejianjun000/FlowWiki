# 各省清洁生产审核实施细则 江苏

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 苏发改规〔2023〕3号 |
| 适用范围 | 江苏省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 江苏省发展和改革委员会、江苏省生态环境厅 |
| 实施日期 | 2023-07-01 |

## 二、主要内容
江苏省实施细则结合长江经济带保护要求，强调沿江化工企业强制性审核全覆盖，建立省、市、县三级审核联动机制，将清洁生产审核与排污许可、环境信用评价深度衔接。

## 三、清洁生产技术要求
| 阶段 | 江苏特色要求 |
|------|-------------|
| 名单确定 | 沿江化工+印染+电镀全覆盖 |
| 三级联动 | 省、市、县分工审核 |
| 衔接机制 | 与排污许可、信用评价联动 |
| 化工专项 | 化工园区整体审核 |
| 资金奖补 | 节能减排专项资金优先 |

## 四、合规要点
1. 沿江1公里范围内化工企业应每3年开展1次清洁生产审核。
2. 化工园区应制定园区级清洁生产审核计划并报省生态环境厅备案。
3. 审核结果作为排污许可证年审和环境信用评价的重要依据。
4. 中/高费方案实施情况纳入企业环境信息强制性披露内容。
