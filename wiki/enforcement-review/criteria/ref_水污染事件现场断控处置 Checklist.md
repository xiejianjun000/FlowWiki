# 水污染事件现场断控处置 Checklist

> ACE Generator 编译 | Reflector 审核通过
> 核心理念：以空间换时间（找空间 -> 定方案 -> 抓演练）；三级防控（不出厂区 -> 不出公共空间 -> 不出园区）

## 0. 接报与启动（0-30分钟）

- [ ] 核实：位置、污染物、泄漏量、入水方式、受影响水体
- [ ] 启动预案，报告（较大及以上：30分钟电话+60分钟书面）
- [ ] 通知下游水厂、取水口、沿岸居民
- [ ] 调集处置组、监测组、保障组到位
- [ ] 判定事件级别，必要时启动IV级及以上响应

## 1. 断（断源·源头控制）

- [ ] 关闸：关闭雨水/污水排口闸阀，切至事故应急池
- [ ] 收容：围堰/防火堤收容泄漏物
- [ ] 堵漏：封堵漏点，围堤收容
- [ ] 限排/停产：关停相关企业工序
- [ ] 确认：事故废水是否控制在企业应急池内（一级防控）

## 2. 控（控扩散·拦截暂存）

- [ ] 筑坝拦截：溢点上下游设临时坝
- [ ] 闸坝调度：分段拦蓄，控制清水，隔离污染团
- [ ] 回抽转输：管线转输至园区公共应急池
- [ ] 导流引流：引至临时储存空间
- [ ] 核对空间清单（一河一策一图）

## 3. 治（削减·污染处置）

- [ ] 投加：依污染物投加混凝剂/吸附剂/氧化剂
- [ ] 吸附：吸油毡、活性炭、打捞漂浮物
- [ ] 絮凝沉淀：投药沉淀，泥渣按危废处置
- [ ] 旁路治理：引至旁建处理设施
- [ ] 稀释：加大泄流（须配沉淀，避免仅下移）

## 4. 测（应急监测，HJ 589-2021）

- [ ] 布点：对照/控制/削减/敏感点断面
- [ ] 频次：初期加密，随态势稳定递减
- [ ] 快筛+确证：便携筛查 -> 实验室定量
- [ ] 底泥反释警惕：持续监测浓度反弹
- [ ] 达标后方可终止监测

## 5. 保（饮用水与公众）

- [ ] 超标时通知水厂调整工艺/停取/启用备用水源
- [ ] 受影响人群医疗救治/疏散
- [ ] 信息发布统一管理
