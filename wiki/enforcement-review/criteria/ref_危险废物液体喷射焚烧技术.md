# 危险废物液体喷射焚烧技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 176-2020第6.2条 |
| 适用范围 | 液体喷射焚烧技术 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物液体喷射焚烧的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 液态危险废物 |
| 雾化方式 | 机械雾化或蒸汽雾化 |
| 燃烧温度 | ≥1100°C |
| 喷嘴要求 | 耐腐蚀、耐磨损 |
| 处理能力 | 根据废物量确定 |

## 四、合规要点
1. 液体喷射炉适用于液态废物
2. 喷嘴材质耐腐蚀耐磨损
3. 雾化效果保证燃烧效率
4. 定期清理和维护喷嘴
