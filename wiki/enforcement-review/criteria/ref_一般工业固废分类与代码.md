# 一般工业固废分类与代码

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1200-2021附录A |
| 适用范围 | 一般工业固废的分类和代码标识 |
| 发布机关 | 生态环境部 |

## 二、主要内容
建立了一般工业固废分类代码体系，按行业来源和废物种类进行编码，便于信息化管理。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 分类原则 | 按行业来源+废物特性 |
| 代码结构 | 4位行业代码+4位废物代码 |
| I类固废 | 浸出液不超GB 8978一级标准 |
| II类固废 | 浸出液超GB 8978一级标准但低于危废 |
| 代码管理 | 全国统一编码，动态更新 |

## 四、合规要点
1. 按标准准确分类固废并使用统一代码
2. 建立分类代码台账，定期核对
3. 代码变更时及时更新管理档案
4. 分类存贮避免I类与II类混存
