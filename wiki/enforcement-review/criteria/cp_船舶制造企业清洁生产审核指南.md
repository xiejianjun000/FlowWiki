# 船舶制造企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国船舶工业行业协会发〔2022〕7号 |
| 适用范围 | 金属船舶制造、修理及拆解企业 |
| 发布机关 | 中国船舶工业行业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对船舶制造企业特点，重点识别船体建造、涂装、舾装、拆解等关键工序清洁生产潜力。强调超高压水除锈、废钢回收、含油废水处理、VOCs管控。涵盖废钢、含油废水审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万元产值VOCs |
| 审核 | 涂装、拆解工序 |
| 方案筛选 | 超高压水除锈+VOCs |
| 高费方案 | 废钢回收系统 |
| 实施验证 | 减排+回收 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 应采用超高压水除锈工艺。
2. 喷漆应配套VOCs处理装置。
3. 拆船作业应在专业拆船厂进行。
4. 含油废水、洗舱水应处理后回用。
