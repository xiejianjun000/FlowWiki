# 危险废物转移应急预案编制指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 169-2018 |
| 适用范围 | 转移应急预案 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物转移过程突发环境事件应急预案的编制要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 风险识别 | 交通事故、泄漏、火灾等 |
| 应急组织 | 转移单位、运输单位、接受单位 |
| 响应程序 | 发现→报告→处置→善后 |
| 应急物资 | 随车配备应急物资 |
| 演练要求 | 每年至少1次演练 |

## 四、合规要点
1. 编制转移应急预案并备案
2. 随车配备应急物资
3. 定期开展应急演练
4. 应急情况下及时响应处置
