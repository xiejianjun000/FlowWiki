# 排污许可证申请与核发技术规范 非金属矿物制品业（陶瓷）

## 一、标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1104-2020（扩展适用） |
| 适用范围 | 建筑陶瓷、卫生陶瓷、日用陶瓷、艺术陶瓷制造 |

## 二、产污环节与污染物

### 2.1 主要生产单元
- 制粉：球磨、喷雾干燥
- 成型：压制、注浆
- 干燥：干燥窑
- 施釉：喷釉、浸釉
- 烧成：隧道窑、辊道窑

### 2.2 主要污染物
- 废气：颗粒物、SO₂、NOx、氟化物、铅、镉
- 废水：SS、COD、重金属
- 固废：废泥、废釉、废瓷

## 三、许可排放限值

### 3.1 大气污染物

| 污染物 | 排放浓度限值(mg/m³) |
|--------|---------------------|
| 颗粒物 | 20 |
| SO₂ | 50 |
| NOx | 200 |
| 氟化物 | 3 |
| 铅及其化合物 | 0.5 |

### 3.2 水污染物（直接排放）

| 污染物 | 排放限值(mg/L) |
|--------|----------------|
| SS | 50 |
| COD | 60 |
| 总铅 | 0.5 |

## 四、监测要求

- 喷雾塔、窑炉安装CEMS
- 季度监测氟化物、重金属

## 五、违法处罚依据

《大气污染防治法》第99条、《水污染防治法》第83条、《排污许可管理条例》第33-35条。

## 六、合规启示

1. 推行清洁燃料（天然气）
2. 含铅釉料替代
3. 废泥回用
