# 钢渣综合利用技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 24774-2009 |
| 适用范围 | 钢渣的综合利用活动 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了钢渣处理、加工和在建材、道路工程等领域利用的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 处理工艺 | 热焖、水淬、风淬、自然粉化 |
| 金属铁含量 | ≤2% |
| 游离氧化钙 | ≤5% |
| 利用途径 | 道路基层、沥青骨料、水泥原料 |
| 稳定性要求 | 浸水膨胀率≤2% |

## 四、合规要点
1. 钢渣处理前进行稳定性检验
2. 控制游离氧化钙含量避免膨胀
3. 利用过程采取抑尘措施
4. 记录钢渣产生和利用数据
