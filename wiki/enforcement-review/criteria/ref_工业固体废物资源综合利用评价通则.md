# 工业固体废物资源综合利用评价通则

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 30106-2013 |
| 适用范围 | 工业固废资源综合利用评价 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了工业固废资源综合利用评价的通用原则、方法和基本要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 评价范围 | 采矿、冶金、化工、建材等行业 |
| 评价原则 | 全过程评价、生命周期分析 |
| 资源化率计算 | 利用量/产生量×100% |
| 环境效益评价 | 污染物减排量、能源节约量 |
| 评价周期 | 每3年开展一次 |

## 四、合规要点
1. 评价覆盖固废综合利用全过程
2. 采用生命周期方法分析环境影响
3. 评价结果作为政策支持依据
4. 评价资料应真实完整
