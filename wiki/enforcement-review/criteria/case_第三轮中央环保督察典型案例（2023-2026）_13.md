# 第三轮中央环保督察典型案例（2023-2026）

> 第三轮督察自2023年11月启动，截至第六批（2026年5月）已覆盖22省+12央企，新增流域督察和专项督察方式。

## 各批次典型案例概要

### 第一批（2023年11月）— 5省

| 省份 | 典型问题 |
|------|---------|
| 福建 | 海域违规围填海、福州企业污染 |
| 河南 | 矿山生态修复滞后 |
| 海南 | 红树林保护不力 |
| 甘肃 | 甘南矿产开发生态破坏 |
| 青海 | 海北垃圾填埋场暗管渗滤液直排 |

### 第二批（2024年5月）— 7省

含流域督察试点：上海水环境、浙江海洋生态、江西矿区、湖北磷石膏、湖南湘江重金属、重庆、云南

### 第三批（2024年10月）— 4省+4央企

首次纳入能源央企（中国石油、中国石化、中国中化、中国化学工程），安徽长江岸线保护、四川小水电等

### 第四批（2025年5月）— 5省+3央企+黄河流域督察

山西黄河流域、内蒙古草原退化、山东大气污染等；央企（中国华能、中国大唐、国家电投）

### 第五批（2025年11月）— 3省+5央企+大运河专项

北京怀柔昌平生态保护、河北廊坊辛集农村污染等；央企（中国华电、国家能源投资、鞍钢、中国宝武、中国中煤）；大运河专项涉及8省市

### 第六批（2026年5月）— 7省+兵团

辽宁抚顺营口大气、吉林延边生态破坏、黑龙江齐齐哈尔湿地、广西玉林违法采矿、广东惠州阳江海洋生态、广西北海钦州海洋生态

## 第三轮新特点

| 维度 | 变化 |
|------|------|
| 能源央企 | 首次纳入中国石油、中国石化等 |
| 流域督察 | 长江流域、黄河流域专项督察 |
| 专项督察 | 大运河专项（8省市） |
| 典型案例密度 | 同批次分2-3轮通报 |
| 法规升级 | 《工作条例》施行 |
