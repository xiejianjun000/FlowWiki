# 废弃电器电子产品处理技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 527-2010第6章 |
| 适用范围 | 处理技术 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废弃电器电子产品处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 处理原则 | 减量化、资源化、无害化 |
| 处理工艺 | 拆解、破碎、分选 |
| 危险废物管理 | 按危废规范管理 |
| 污染物控制 | 三废达标排放 |
| 资源回收 | 提高资源回收率 |

## 四、合规要点
1. 按规范开展废弃电器电子产品处理
2. 危险废物按规范管理
3. 污染物达标排放
4. 提高资源综合回收率
