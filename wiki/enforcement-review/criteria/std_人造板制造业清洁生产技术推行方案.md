# 人造板制造业清洁生产技术推行方案

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 工信部联节〔2023〕112号 |
| 适用范围 | 胶合板、纤维板、刨花板、饰面人造板生产企业 |
| 发布机关 | 工业和信息化部 |
| 实施日期 | 2023-06-01 |

## 二、主要内容
本方案明确人造板制造业清洁生产技术推广路径，重点推行低游离甲醛胶黏剂、无醛胶黏剂、废水循环利用、木粉粉尘回收、热能回收。设定2025年无醛人造板占比、废水回用率量化目标。

## 三、清洁生产技术要求
| 技术类别 | 推行目标 |
|---------|---------|
| 无醛胶黏剂 | 占比≥50% |
| 低游离甲醛胶 | 全行业覆盖 |
| 废水循环 | 回用率≥90% |
| 木粉回收 | 回收率≥95% |
| 热能回收 | 大型企业覆盖 |

## 四、合规要点
1. 应使用低游离甲醛或无醛胶黏剂。
2. 热磨废水应配套处理回用装置。
3. 木粉粉尘应回收作燃料或原料。
4. 干燥尾气应配套热能回收装置。
