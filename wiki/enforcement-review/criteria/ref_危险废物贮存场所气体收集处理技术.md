# 危险废物贮存场所气体收集处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2025-2012第7章 |
| 适用范围 | 贮存场所气体收集处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了易挥发危险废物贮存场所气体收集和处理技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 气体收集 | 局部排风+全面通风 |
| 收集效率 | ≥90% |
| 处理工艺 | 活性炭吸附、催化燃烧、生物过滤 |
| 排放限值 | 符合GB 16297或地方标准 |
| 在线监测 | 主要污染物在线监控 |

## 四、合规要点
1. 易挥发废物贮存场所配置气体收集系统
2. 定期检查收集效率和处理效果
3. 排放浓度符合标准限值
4. 保留气体处理运行记录
