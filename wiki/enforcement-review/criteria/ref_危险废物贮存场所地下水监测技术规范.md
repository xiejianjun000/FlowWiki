# 危险废物贮存场所地下水监测技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18597-2023附录D |
| 适用范围 | 贮存场所地下水监测 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物贮存场所地下水监测井布设、监测项目和频次。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 监测井布设 | 上游1个、下游≥3个 |
| 监测项目 | pH、特征污染物、重金属等 |
| 监测频次 | 每季度至少1次 |
| 采样方法 | 按HJ 25.2规定执行 |
| 数据管理 | 建立监测档案并定期分析 |

## 四、合规要点
1. 按规范布设地下水监测井
2. 定期开展地下水监测
3. 监测数据与背景值对比分析
4. 发现异常及时排查处置
