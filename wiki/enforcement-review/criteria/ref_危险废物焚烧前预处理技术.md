# 危险废物焚烧前预处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 176-2020第6.3条 |
| 适用范围 | 焚烧前预处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧前的预处理技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 预处理目的 | 调整热值、去除杂质、稳定进料 |
| 预处理方式 | 破碎、混合、中和、脱水 |
| 设备配置 | 破碎机、混合机、储罐 |
| 安全措施 | 防爆、防毒、防泄漏 |
| 预处理记录 | 记录预处理过程和参数 |

## 四、合规要点
1. 根据废物特性选择预处理方式
2. 预处理设备安全可靠
3. 预处理过程做好安全防护
4. 记录预处理参数便于追溯
