# 化工企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中石化协发〔2022〕15号 |
| 适用范围 | 石化、化工、精细化工企业 |
| 发布机关 | 中国石油和化学工业联合会 |
| 实施日期 | 2022-06-01 |

## 二、主要内容
本指南针对化工企业特点，规定审核重点部位识别、物料平衡、能量平衡、水平衡和反应工艺评价方法。强调反应过程优化、溶剂回收、副产物资源化、火炬气全回收。涵盖审核启动到验收全过程操作要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 物料衡算+能流分析 |
| 审核 | 反应器、蒸馏塔重点 |
| 方案筛选 | 反应工艺+设备改造 |
| 高费方案 | 余热回收+溶剂回收 |
| 实施验证 | 经济+环境双效益 |
| 持续改进 | 工艺优化常态化 |

## 四、合规要点
1. 重点关注反应转化率、选择性、收率三率指标。
2. 火炬气、弛放气应全部回收利用。
3. 高浓度母液、废溶剂应优先资源化回收。
4. 检测数据应保留至少5年备查。
