# GB13457-1992 肉类加工工业水污染物排放标准

## 标准概述
- 标准编号：GB13457-1992
- 标准名称：肉类加工工业水污染物排放标准
- 发布机关：生态环境主管部门、国家市场监督管理总局（见标准原文）。
- 发布日期：见标准原文。
- 施行日期：1992-07-01
- 适用范围：见标准原文适用范围。

## 适用行业
对应 GB/T 4754 行业代码：135（农副食品加工业）

## 核心限值表
| 污染物 | 排放限值 | 单位 | 适用条件 |
|--------|---------|------|---------|
| 生化需氧量 | 一级标准:60 / 二级标准:120 / 三级标准:600 | mg/L | 见标准 |
| 化学需氧量 | 一级标准:120 / 二级标准:250 / 三级标准:1000 | mg/L | 见标准 |
| 悬浮物 | 一级标准:80 / 二级标准:200 / 三级标准:600 | mg/L | 见标准 |
| 动植物油 | 一级标准:20 / 二级标准:30 / 三级标准:100 | mg/L | 见标准 |
| 氨氮 | 一级标准:25 / 二级标准:40 | mg/L | 见标准 |
| pH | 一级标准:6~9 / 二级标准:6~9 / 三级标准:6~9 | 无量纲 | 见标准 |
| 大肠菌群数 | 一级标准:5000 / 二级标准:10000 | 个/L | 见标准 |
| 排水量（m³/t活屠重或原料肉） | 一级标准:7.2 | mg/L | 见标准 |

## 监测要求
（采样点、频次、方法提要）见标准原文及配套监测方法标准。核心要求：按 GB/T 16157、HJ/T 397 等规范布点采样；水污染物在企业废水总排放口及车间排放口监控；大气污染物在排气筒、厂界监控点监测。

## 对企业的影响
- 需识别本标准适用工序及排放口，建立污染物台账。
- 依据直接/间接排放、现有/新建企业、一般/重点区域选择对应限值。
- 配套安装治理设施并保留运行记录，确保稳定达标。
- 定期开展自行监测，保存原始监测数据不少于规定年限。
- 关注修改单及地方排放标准，及时更新合规判定依据。
