# 啤酒企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国酒业协会发〔2022〕6号 |
| 适用范围 | 啤酒制造及麦芽生产企业 |
| 发布机关 | 中国酒业协会 |
| 实施日期 | 2022-07-01 |

## 二、主要内容
本指南针对啤酒企业特点，重点识别糖化、发酵、过滤、灌装等关键工序清洁生产潜力。强调麦糟综合利用、酵母回收、CO₂回收、CIP清洗。涵盖水耗、能耗、COD、综合利用审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 千升啤酒水耗、COD |
| 审核 | 糖化、发酵重点 |
| 方案筛选 | 麦糟+酵母回收 |
| 高费方案 | CO₂回收系统 |
| 实施验证 | 节水+综合利用 |
| 持续改进 | 智能酿造 |

## 四、合规要点
1. 麦糟、酵母应全部综合利用。
2. CO₂应配套回收装置。
3. 应采用CIP原位清洗节水工艺。
4. 排放废水应执行GB 19821排放标准。
