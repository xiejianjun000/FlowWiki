# 危险废物转移事故应急处置技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 169-2018附录 |
| 适用范围 | 转移事故应急处置 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物转移过程突发事故的应急处置技术和措施。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 事故类型 | 泄漏、火灾、爆炸、交通事故 |
| 处置程序 | 警戒→评估→处置→清理→善后 |
| 泄漏处置 | 堵漏、收集、吸附、中和 |
| 火灾处置 | 适用灭火剂、防止二次污染 |
| 环境监测 | 事故现场及周边环境监测 |

## 四、合规要点
1. 事故发生后立即启动应急响应
2. 按规范开展应急处置
3. 防止事故扩大和二次污染
4. 做好事故后期清理和善后
