# 电石渣综合利用技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1097-2020 |
| 适用范围 | 电石法PVC产生电石渣的利用 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了电石渣在建材、环保等领域利用的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| Ca(OH)₂含量 | ≥80% |
| 利用途径 | 水泥原料、脱硫剂、中和剂 |
| pH控制 | 强碱性，需中和处理 |
| 含水率 | ≤30% |
| 杂质控制 | 去除硅铁等杂质 |

## 四、合规要点
1. 电石渣利用前进行脱水处理
2. 防止强碱性对设备和环境的影响
3. 建立电石渣利用台账
4. 定期监测利用产物质量
