# 各省清洁生产审核实施细则 湖北

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 鄂发改规〔2023〕6号 |
| 适用范围 | 湖北省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 湖北省发展和改革委员会、湖北省生态环境厅 |
| 实施日期 | 2023-09-01 |

## 二、主要内容
湖北省实施细则对接长江经济带绿色发展，强化沿江化工企业"关改搬转"后审核要求，突出磷化工、钢铁、汽车制造等优势产业清洁生产升级。建立长江中游城市群审核协作机制。

## 三、清洁生产技术要求
| 阶段 | 湖北特色要求 |
|------|-------------|
| 名单确定 | 沿江化工关改搬转企业 |
| 重点行业 | 磷化工、钢铁、汽车 |
| 中游协作 | 长江中游城市群协作 |
| 磷石膏 | 综合利用纳入审核 |
| 资金支持 | 长江保护专项资金 |

## 四、合规要点
1. 关改搬转后企业应在投产6个月内完成清洁生产审核。
2. 磷化工企业审核应包含磷石膏综合利用内容。
3. 长江中游城市群（鄂湘皖赣）审核专家可跨省参与。
4. 通过审核的企业可享受长江保护专项资金优先支持。
