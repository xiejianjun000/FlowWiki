# 各省清洁生产审核实施细则 云南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 云发改规〔2023〕5号 |
| 适用范围 | 云南省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 云南省发展和改革委员会、云南省生态环境厅 |
| 实施日期 | 2023-09-01 |

## 二、主要内容
云南省实施细则围绕长江、珠江上游生态屏障建设，突出有色金属、磷化工、烟草等特色产业清洁生产升级。强化九大高原湖泊流域工业企业审核要求，建立面向南亚东南亚的清洁生产技术合作机制。

## 三、清洁生产技术要求
| 阶段 | 云南特色要求 |
|------|-------------|
| 名单确定 | 长江珠江上游+九湖流域 |
| 特色产业 | 有色、磷化工、烟草 |
| 九湖保护 | 流域企业重点审核 |
| 跨境合作 | 面向南亚东南亚 |
| 生物多样性 | 重点关注内容 |

## 四、合规要点
1. 九大高原湖泊流域企业应每3年完成1次审核。
2. 有色金属企业审核应包含重金属总量控制。
3. 烟草企业审核应关注VOCs和异味控制。
4. 跨境合作项目审核标准可参照云南特色要求。
