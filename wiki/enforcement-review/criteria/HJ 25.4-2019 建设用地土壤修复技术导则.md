## 建设用地土壤修复技术导则

### 前言

为贯彻《中华人民共和国环境保护法》《中华人民共和国土壤污染防治法》，保护生态环境，保障人体健康，规范建设用地土壤修复技术工作，制定本标准。

本标准规定了建设用地土壤修复的工作原则、工作程序、修复技术筛选、常用修复技术、修复方案制定、修复工程实施、修复效果评估和修复验收的技术要求。

本标准为首次发布。

本标准由生态环境部土壤生态环境司、法规与标准司组织制订。

本标准主要起草单位：中国环境科学研究院、国家环境保护土壤环境管理与污染控制重点实验室。

本标准生态环境部2019年1月29日批准。

本标准自2019年7月1日起实施。

本标准由生态环境部解释。

---

### 1 适用范围

本标准规定了建设用地土壤修复的工作原则、工作程序、技术方法和技术要求。

本标准适用于建设用地土壤污染修复活动，包括：
- 建设用地土壤修复技术筛选
- 建设用地土壤修复方案制定
- 建设用地土壤修复工程实施
- 建设用地土壤修复效果评估
- 建设用地土壤修复验收

本标准也适用于建设用地土壤污染风险管控中的修复相关活动。

本标准不适用于放射性污染和致病性生物污染的土壤修复。

### 3 术语和定义

#### 3.1 土壤修复（soil remediation）

利用物理、化学或生物的方法固定、转移、吸收、降解或转化土壤中的污染物，使其浓度降低到可接受水平，或将有毒有害的污染物转化为无害物质的过程。

#### 3.2 原位修复（in-situ remediation）

在不移动受污染土壤的情况下，直接在场地原位对污染土壤进行修复的技术方式。

#### 3.3 异位修复（ex-situ remediation）

将受污染土壤从原位置挖出或抽取后，在场地内或场地外进行处理的修复技术方式。

#### 3.4 修复技术（remediation technology）

用于降低土壤中污染物浓度或危害性的各种工程技术方法的总称。

#### 3.5 修复目标（remediation goal）

根据风险评估结果，结合技术可行性和经济合理性确定的土壤或地下水中污染物需要达到的浓度限值或风险水平。

#### 3.6 修复方案（remediation plan）

为实现修复目标而制定的总体技术方案和实施计划，包括技术路线、工艺参数、工程设计、进度安排、质量保证等内容。

#### 3.7 风险管控（risk management and control）

为降低土壤污染对人体健康和生态环境的风险，采取的隔离、阻断、管控等措施，包括污染源控制、暴露途径阻断和长期监测等。

#### 3.8 土壤气相抽提（soil vapor extraction, SVE）

通过在包气带土壤中设置抽提井，利用真空抽提产生的气流将土壤中的挥发性和半挥发性有机污染物解吸并带出地面进行处理的原位修复技术。

#### 3.9 生物通风（bioventing）

通过向土壤中通入空气（或氧气），促进好氧微生物的活性，加速土壤中有机污染物生物降解的原位修复技术。

#### 3.10 热脱附（thermal desorption）

通过加热污染土壤，使污染物挥发或分离，并对挥发的污染物进行收集处理的修复技术，可分为原位热脱附和异位热脱附。

#### 3.11 化学氧化（chemical oxidation）

向污染土壤或地下水中投加化学氧化剂，将污染物氧化降解为低毒或无毒物质的修复技术。

#### 3.12 固化稳定化（solidification/stabilization, S/S）

通过向污染土壤中添加固化剂/稳定剂，改变土壤的物理化学性质，将污染物包裹固定或降低其迁移性和生物可利用性的修复技术。

#### 3.13 土壤淋洗（soil washing）

利用水或化学淋洗剂，通过物理分离和化学溶解作用，将污染物从土壤中洗脱分离的异位修复技术。

#### 3.14 生物修复（bioremediation）

利用微生物的代谢作用降解土壤中的有机污染物，或将重金属转化为低毒形态的修复技术，包括原位生物修复和异位生物修复。

#### 3.15 植物修复（phytoremediation）

利用植物及其根际微生物的吸收、挥发、转化、固定等作用去除土壤中污染物的修复技术。

#### 3.16 填埋处置（landfill disposal）

将污染土壤运输至符合环保要求的填埋场进行最终处置的方式。

#### 3.17 二次污染（secondary pollution）

在土壤修复过程中产生的新的污染物或污染形式，对环境造成的新的污染。

#### 3.18 修复效果评估（remediation effectiveness assessment）

在修复工程完成后，通过系统的监测和评估，判断修复工程是否达到预期修复目标的过程。

### 4 修复原则与工作程序

#### 4.1 修复原则

##### 4.1.1 安全第一原则

土壤修复应确保修复工程实施过程中的人员安全和环境安全，防止二次污染和安全事故的发生。

##### 4.1.2 风险可控原则

土壤修复应以人体健康和生态环境风险控制为核心，确保修复后场地风险可接受。

##### 4.1.3 技术可行原则

选择的修复技术应技术成熟可靠，能够有效去除或降低土壤中的污染物，达到修复目标。

##### 4.1.4 经济合理原则

在满足修复目标和安全要求的前提下，选择经济合理的修复技术和方案，降低修复成本。

##### 4.1.5 因地制宜原则

应根据场地的污染特征、水文地质条件、土地利用方式等因素，选择适宜的修复技术和方案。

##### 4.1.6 绿色可持续原则

应优先选择资源消耗少、环境影响小、二次污染少的修复技术，实现绿色可持续修复。

#### 4.2 修复工作程序

建设用地土壤修复一般包括以下阶段：

1. **修复前期工作**
   - 土壤污染状况调查
   - 风险评估
   - 确定修复目标和修复范围
   - 修复技术筛选

2. **修复方案制定**
   - 修复技术路线确定
   - 修复工艺参数设计
   - 修复工程设计
   - 二次污染防控措施
   - 修复方案比选与确定

3. **修复工程实施**
   - 施工准备
   - 施工过程管理
   - 过程监测
   - 质量控制

4. **修复效果评估与验收**
   - 修复效果监测
   - 修复效果评估
   - 修复验收
   - 后期管理

**注**：根据场地实际情况和修复目标，可对工作程序进行适当调整。

### 5 修复技术筛选

#### 5.1 筛选原则

- **目标导向**：以实现修复目标为核心，确保所选技术能够有效去除或控制污染物
- **条件适配**：充分考虑场地的污染特征、水文地质条件、土地利用方式等因素
- **技术成熟**：优先选择技术成熟、工程应用案例多的修复技术
- **经济合理**：在满足修复要求的前提下，选择成本较低的技术
- **环境友好**：优先选择二次污染小、资源消耗少的绿色修复技术
- **安全可靠**：确保修复工程实施过程中的人员安全和环境安全

#### 5.2 筛选依据

##### 5.2.1 污染特征

- 污染物类型（重金属、有机物、农药、石油烃等）
- 污染物浓度水平和超标程度
- 污染物的物理化学性质（挥发性、溶解度、吸附性、降解性等）
- 污染深度和污染范围
- 污染的均匀程度

##### 5.2.2 场地条件

- 水文地质条件（含水层分布、地下水位、渗透性等）
- 土壤性质（质地、有机质含量、pH值、孔隙度等）
- 场地地形地貌
- 场地周边环境（敏感目标分布、土地利用现状等）
- 场地可利用空间

##### 5.2.3 修复目标

- 修复目标值
- 修复范围和深度
- 修复工期要求
- 修复后土地利用方式

##### 5.2.4 技术特点

- 技术原理和适用范围
- 技术成熟度和工程应用经验
- 处理效率和处理周期
- 投资成本和运行成本
- 二次污染产生情况
- 操作维护要求

#### 5.3 技术可行性分析

##### 5.3.1 污染物适用性分析

分析修复技术对目标污染物的处理效果：
- 是否适用于该类污染物的处理
- 能够达到的处理效率和最终浓度水平
- 是否会产生有毒有害的中间产物或副产物
- 对复合污染的处理效果

##### 5.3.2 场地条件适应性分析

分析场地条件对修复技术的适用性：
- 水文地质条件是否满足技术要求
- 土壤性质是否有利于修复技术的实施
- 污染深度和范围是否在技术适用范围内
- 场地空间是否满足工程实施要求

##### 5.3.3 技术成熟度分析

评估修复技术的成熟程度：
- 技术发展阶段（实验室研究、中试、工程应用）
- 国内外工程应用案例数量和效果
- 技术的可靠性和稳定性
- 相关技术标准和规范情况

#### 5.4 经济可行性分析

##### 5.4.1 费用构成

修复工程费用一般包括：

**（1）前期费用**
- 调查评估费
- 方案设计费
- 审批验收费

**（2）工程建设费用**
- 设备购置费
- 材料费
- 施工费
- 安装调试费

**（3）运行费用**
- 人工费
- 能源费
- 药剂费
- 维护费
- 监测费

**（4）其他费用**
- 二次污染处理费
- 风险准备金
- 管理费

##### 5.4.2 费用估算方法

- 单位处理量估算法
- 工程类比法
- 定额法
- 分项累加法

#### 5.5 环境影响分析

##### 5.5.1 二次污染分析

分析修复过程可能产生的二次污染：
- 废气排放（挥发性有机物、粉尘等）
- 废水排放（淋洗废水、抽取的地下水等）
- 固体废物（废药剂、废活性炭、污泥等）
- 噪声污染
- 生态破坏（植被破坏、土壤结构破坏等）

##### 5.5.2 资源消耗分析

分析修复过程的资源消耗：
- 能源消耗（电、燃油、天然气等）
- 水资源消耗
- 药剂和材料消耗
- 土地资源占用

##### 5.5.3 环境影响控制措施

针对可能产生的环境影响，提出相应的控制措施：
- 废气收集和处理措施
- 废水收集和处理措施
- 固体废物安全处置措施
- 噪声控制措施
- 生态恢复措施

#### 5.6 修复技术筛选矩阵

采用多指标综合评价法进行修复技术筛选，建立筛选矩阵：

| 评价指标 | 权重 | 评价标准 | 技术A评分 | 技术B评分 | 技术C评分 |
|---------|------|---------|----------|----------|----------|
| 处理效果 | 0.25 | 达标能力、处理效率 | | | |
| 技术可行性 | 0.20 | 成熟度、适用性、可靠性 | | | |
| 经济合理性 | 0.20 | 建设成本、运行成本 | | | |
| 环境友好性 | 0.15 | 二次污染、资源消耗 | | | |
| 施工周期 | 0.10 | 修复工期、施工难度 | | | |
| 安全可靠性 | 0.10 | 施工安全、运行安全 | | | |
| **综合得分** | **1.00** | | | | |

根据综合得分排序，选择2~3种技术进行进一步的可行性研究和方案比选。

#### 5.7 中试试验

对于复杂场地或采用新技术的情况，应进行中试试验：
- 验证修复技术的处理效果
- 确定最佳工艺参数
- 评估实际运行成本
- 发现和解决可能出现的问题
- 为工程设计提供依据

中试试验的规模应能反映实际工程情况，试验周期应足够长以获得可靠的数据。

### 6 常用修复技术

#### 6.1 土壤气相抽提（SVE）

##### 6.1.1 技术原理

通过在包气带中设置抽提井，利用真空泵产生负压，使空气流经污染土壤，将挥发性和半挥发性有机污染物从土壤颗粒和孔隙水中解吸出来，随气流带到地面进行处理。

##### 6.1.2 适用范围

**适用污染物：**
- 挥发性有机物（VOCs）：苯系物、氯代烃、汽油等
- 半挥发性有机物（SVOCs）：沸点较高的有机物
- 部分挥发性重金属：汞等

**适用条件：**
- 包气带厚度大于1 m
- 土壤渗透性较好（渗透系数 > 10⁻⁴ cm/s）
- 地下水位埋深较大，抽提不影响地下水
- 污染物具有一定的挥发性

**不适用条件：**
- 地下水位以上包气带太薄
- 土壤黏重、渗透性差
- 污染物沸点太高、挥发性差
- 存在游离态DNAPL或LNAPL

##### 6.1.3 工艺设计

**（1）抽提井设计**
- 井距：根据土壤渗透性和影响半径确定，一般5~20 m
- 井深：进入污染底板以下1~2 m
- 滤管长度：覆盖整个污染深度
- 井径：一般100~200 mm

**（2）抽提系统设计**
- 抽提流量：根据影响半径和井数确定
- 真空度：根据深度和阻力损失确定，一般5~20 kPa
- 气相流速：保持一定的气流速度，确保污染物有效解吸

**（3）尾气处理系统**
- 活性炭吸附：适用于低浓度、大风量尾气
- 催化燃烧：适用于中高浓度尾气
- 生物过滤：适用于可生物降解的污染物
- 冷凝回收：适用于高浓度、有回收价值的污染物

##### 6.1.4 运行参数

- 抽提流量：单井0.5~5 m³/min
- 真空度：5~20 kPa
- 孔隙气体流速：0.1~1.0 cm/s
- 修复周期：一般6个月~2年

##### 6.1.5 优缺点

**优点：**
- 原位修复，对场地扰动小
- 设备简单，操作方便
- 处理成本相对较低
- 处理效果好，尤其适用于挥发性有机物

**缺点：**
- 仅适用于包气带
- 对低渗透性土壤效果差
- 对重质非水相液体（DNAPL）处理效果有限
- 尾气处理不当可能造成二次污染

#### 6.2 生物通风

##### 6.2.1 技术原理

通过向包气带土壤中通入空气（或氧气），提高土壤中的氧气含量，促进好氧微生物的生长和代谢活性，加速土壤中有机污染物的生物降解。

##### 6.2.2 适用范围

**适用污染物：**
- 石油烃类（汽油、柴油、润滑油等）
- 苯系物（BTEX）
- 其他可生物降解的挥发性和半挥发性有机物

**适用条件：**
- 包气带厚度较大
- 土壤渗透性较好
- 污染物可生物降解
- 土壤中存在降解菌或可接种降解菌

**不适用条件：**
- 污染物生物降解性差
- 土壤渗透性太差
- 污染物浓度过高，对微生物有毒性
- 地下水位波动频繁

##### 6.2.3 工艺设计

**（1）通风井设计**
- 注气井和抽提井结合布置
- 井距：根据影响半径确定，一般5~15 m
- 井深：覆盖整个污染深度

**（2）通风系统设计**
- 注气流量：根据土壤孔隙度和需氧量确定
- 注气压力：根据深度和阻力确定
- 通风方式：间歇通风或连续通风

**（3）强化措施**
- 添加营养物质（氮、磷等）
- 调节土壤pH值
- 接种高效降解菌
- 补充电子受体

##### 6.2.4 运行参数

- 气固比：一般5~50
- 注气压力：5~20 kPa
- 孔隙气体流速：0.01~0.1 cm/s
- 修复周期：一般1~3年

##### 6.2.5 优缺点

**优点：**
- 原位修复，对场地扰动小
- 处理成本低
- 二次污染小，环境友好
- 操作简单，运行维护方便

**缺点：**
- 修复周期长
- 对污染物浓度有一定限制
- 受温度影响大，低温时效果差
- 不适用于难降解有机物

#### 6.3 热脱附

##### 6.3.1 技术原理

通过直接或间接加热污染土壤，使土壤中的污染物达到沸点以上，挥发或分解成气态，然后将含污染物的气体收集处理。

按加热方式可分为：
- 原位热脱附：在原位对土壤进行加热
- 异位热脱附：将土壤挖出后加热处理

按操作温度可分为：
- 低温热脱附：100~300℃，主要处理挥发性有机物
- 高温热脱附：300~600℃，主要处理半挥发性有机物和部分重金属

##### 6.3.2 适用范围

**适用污染物：**
- 挥发性有机物（VOCs）
- 半挥发性有机物（SVOCs）：多环芳烃、农药、多氯联苯等
- 部分重金属：汞、砷等挥发性重金属
- 石油烃类

**适用条件：**
- 异位热脱附：适用于各种土壤类型
- 原位热脱附：适用于渗透性较好的土壤

**不适用条件：**
- 含有大量腐殖质或有机质的土壤（可能吸附污染物难以脱附）
- 热稳定性极强的污染物
- 异位热脱附需要较大的施工和处理场地

##### 6.3.3 工艺设计（异位热脱附）

**（1）预处理系统**
- 土壤筛分、破碎
- 去除大块杂物
- 调节土壤含水率

**（2）加热系统**
- 回转窑热脱附
- 螺旋推进式热脱附
- 流化床热脱附
- 红外加热热脱附

**（3）尾气处理系统**
- 颗粒物去除：旋风除尘器、布袋除尘器
- 酸性气体去除：喷淋塔、碱洗
- 有机物去除：活性炭吸附、催化燃烧、热力焚烧
- 重金属去除：活性炭吸附、布袋除尘

**（4）土壤冷却与收集**
- 出窑土壤冷却
- 处理后土壤收集堆放

##### 6.3.4 运行参数

- 处理温度：150~600℃（根据污染物确定）
- 停留时间：10~60 min
- 处理能力：根据设备规模确定
- 尾气温度：200~400℃

##### 6.3.5 优缺点

**优点：**
- 处理效果好，可处理多种污染物
- 处理效率高，修复周期短
- 异位热脱附适用范围广，不受场地条件限制
- 可回收有价值的污染物

**缺点：**
- 处理成本高
- 能耗大
- 尾气处理复杂，易产生二次污染
- 异位修复需开挖土壤，对场地扰动大
- 原位热脱附施工复杂

#### 6.4 化学氧化

##### 6.4.1 技术原理

向污染土壤或地下水中投加化学氧化剂，通过氧化反应将污染物降解为低毒或无毒的小分子物质（如CO₂和H₂O）。

常用氧化剂：
- 高锰酸盐（高锰酸钾、锰酸钠）
- 过氧化氢（Fenton试剂：过氧化氢+亚铁离子）
- 臭氧
- 过硫酸盐（过硫酸钠、过硫酸铵）
- 次氯酸钠等

##### 6.4.2 适用范围

**适用污染物：**
- 石油烃类
- 苯系物（BTEX）
- 氯代烃：三氯乙烯、四氯乙烯等
- 多环芳烃（PAHs）
- 酚类、醇类、酮类等有机物
- 部分无机物：硫化物、氰化物等

**适用条件：**
- 原位化学氧化：适用于渗透性较好的土壤和地下水
- 异位化学氧化：适用于各种土壤类型

**不适用条件：**
- 土壤中还原性物质含量过高（消耗氧化剂）
- 土壤有机质含量过高（消耗氧化剂）
- 重金属污染（一般无效，可能改变形态）
- 部分难氧化的有机物

##### 6.4.3 工艺设计（原位化学氧化）

**（1）注入井设计**
- 井距：根据氧化剂的影响半径确定，一般2~8 m
- 井深：进入污染深度以下1~2 m
- 注入方式：重力注入、压力注入、循环注入

**（2）氧化剂选择与投加量**
- 根据污染物类型选择氧化剂种类
- 投加量：根据污染物量和土壤耗氧量确定，一般为理论计算量的2~5倍
- 分次投加或连续投加

**（3）反应条件控制**
- pH值调节：Fenton氧化需酸性条件，高锰酸盐氧化适用较宽pH范围
- 温度：温度升高可加速反应
- 催化剂：Fenton试剂需亚铁离子催化，过硫酸盐需活化

**（4）地下水抽提处理（如需要）**
- 抽出被氧化的地下水
- 处理达标后回灌或排放

##### 6.4.4 运行参数

- 氧化剂投加量：根据污染物浓度和土壤性质确定
- 反应时间：数天至数月
- 修复周期：一般3~12个月
- pH值：Fenton 2~4，高锰酸盐 4~9

##### 6.4.5 优缺点

**优点：**
- 处理效率高，反应速度快
- 原位修复，对场地扰动小
- 适用范围广，可处理多种有机物
- 设备相对简单

**缺点：**
- 氧化剂消耗量大，成本较高
- 可能产生有毒中间产物
- 可能改变土壤性质和结构
- 对土壤和地下水的化学性质有影响
- 非选择性氧化，有机质等会消耗氧化剂

#### 6.5 固化稳定化（S/S）

##### 6.5.1 技术原理

向污染土壤中添加固化剂/稳定剂，通过物理包裹和化学固定作用，改变土壤的物理化学性质，将污染物封装在固化体中，或降低污染物的迁移性和生物可利用性，从而减少污染物对人体健康和生态环境的危害。

常用固化剂/稳定剂：
- 水泥基固化剂：硅酸盐水泥、铝酸盐水泥等
- 石灰基固化剂：生石灰、熟石灰等
- 粉煤灰、矿渣等工业废料
- 有机螯合剂、硫化物等化学稳定化药剂

##### 6.5.2 适用范围

**适用污染物：**
- 重金属：镉、铅、铬、汞、砷、铜、锌、镍等
- 半挥发性和非挥发性有机物（部分技术）
- 放射性物质（特殊领域）

**适用条件：**
- 异位固化稳定化：适用于各种土壤类型
- 原位固化稳定化：适用于渗透性较好的场地

**不适用条件：**
- 挥发性强的有机物（处理过程中易挥发损失）
- 土壤体积增容有限制的场地
- 需要完全去除污染物的场景

##### 6.5.3 工艺设计（异位固化稳定化）

**（1）预处理系统**
- 土壤开挖、筛分、破碎
- 调节土壤含水率和粒度

**（2）药剂混合系统**
- 药剂选择与配比设计
- 计量投加系统
- 搅拌混合设备（强制式搅拌机、螺旋搅拌等）

**（3）养护系统**
- 混合后土壤堆放养护
- 控制养护温度和湿度
- 养护时间：一般7~28天

**（4）质量检测**
- 养护后取样检测
- 检测指标：抗压强度、浸出毒性、污染物浓度等

##### 6.5.4 运行参数

- 固化剂掺量：一般5%~30%（占土壤干重）
- 养护时间：7~28天
- 养护温度：常温
- 抗压强度：一般要求≥0.3 MPa（根据用途确定）
- 浸出毒性：低于相关标准限值

##### 6.5.5 优缺点

**优点：**
- 技术成熟，应用广泛
- 处理成本相对较低
- 处理周期短
- 可同时处理多种重金属
- 处理后土壤可再利用（路基材料、建筑回填等）

**缺点：**
- 污染物未被去除，只是被固定
- 土壤体积增容（一般增加10%~30%）
- 长期稳定性需要监测
- 对挥发性有机物处理效果有限
- 可能改变土壤结构和功能

#### 6.6 土壤淋洗

##### 6.6.1 技术原理

利用水或化学淋洗剂（表面活性剂、螯合剂、酸/碱溶液等），通过物理分离和化学溶解/解吸作用，将污染物从土壤颗粒表面洗脱并转移到液相中，然后对淋洗废水进行处理，实现土壤净化。

##### 6.6.2 适用范围

**适用污染物：**
- 重金属：镉、铅、铜、锌、镍等
- 挥发性和半挥发性有机物
- 石油烃类
- 农药类

**适用条件：**
- 砂性土、砾石土等渗透性好的土壤
- 污染物主要吸附在土壤颗粒表面
- 黏粒含量低（一般<20%~30%）

**不适用条件：**
- 黏重土壤（黏粒含量高）
- 污染物渗入土壤矿物晶格内部
- 场地水资源缺乏
- 淋洗废水难以处理

##### 6.6.3 工艺设计

**（1）预处理系统**
- 土壤开挖、筛分
- 去除大块杂物和砾石
- 粒度分级（粗砂、细砂、粉土黏粒）

**（2）淋洗系统**
- 淋洗剂选择：水、表面活性剂、螯合剂、酸/碱等
- 淋洗方式：批量淋洗、连续淋洗、逆流淋洗
- 液固比：一般5:1~20:1
- 淋洗级数：一般2~5级
- 淋洗设备：搅拌罐、淋洗柱、滚筒筛等

**（3）固液分离系统**
- 重力沉降
- 过滤（压滤机、真空过滤机等）
- 离心分离

**（4）废水处理系统**
- 重金属废水：化学沉淀、离子交换、膜分离等
- 有机物废水：生物处理、活性炭吸附、高级氧化等
- 回用或达标排放

##### 6.6.4 运行参数

- 液固比：5:1~20:1
- 淋洗时间：30 min~2 h/级
- 淋洗级数：2~5级
- 处理后土壤含水率：15%~30%

##### 6.6.5 优缺点

**优点：**
- 污染物从土壤中去除，处理彻底
- 处理效率高，周期短
- 处理后土壤可再利用
- 可处理多种污染物

**缺点：**
- 异位修复，需开挖土壤
- 对黏重土壤处理效果差
- 淋洗剂消耗量大，成本较高
- 废水处理复杂，易产生二次污染
- 可能破坏土壤结构和肥力

#### 6.7 生物修复

##### 6.7.1 技术原理

利用微生物（细菌、真菌等）的代谢作用，将土壤中的有机污染物降解为CO₂和H₂O等无害物质，或将重金属转化为低毒、低迁移性的形态。

按修复位置分为：
- 原位生物修复：在原位置进行
- 异位生物修复：挖出后在生物反应器或处理场进行

##### 6.7.2 适用范围

**适用污染物：**
- 石油烃类（汽油、柴油、原油等）
- 苯系物（BTEX）
- 酚类、醇类、酮类等
- 多环芳烃（低分子量PAHs）
- 农药（部分可降解品种）
- 氰化物等
- 重金属（通过生物吸附、生物转化降低毒性和迁移性）

**适用条件：**
- 污染物可生物降解
- 土壤中存在降解微生物或可接种
- 环境条件适宜微生物生长（温度、水分、pH、营养、氧气等）
- 污染物浓度在微生物耐受范围内

**不适用条件：**
- 难降解有机物（高氯代有机物、二噁英等）
- 重金属（不能被降解，只能转化形态）
- 污染物浓度过高，对微生物有毒性
- 环境条件恶劣（极端温度、pH等）

##### 6.7.3 工艺设计（异位生物堆肥）

**（1）预处理**
- 土壤开挖、筛分、破碎
- 调节土壤含水率（20%~40%）
- 调节碳氮比（C:N = 25:1~30:1）
- 添加调理剂（秸秆、木屑、堆肥等）

**（2）生物堆构建**
- 堆体高度：1.5~3 m
- 堆体宽度：3~6 m
- 长度：根据场地和处理量确定
- 通风系统：强制通风或翻堆通风

**（3）过程控制**
- 温度监测与控制
- 含水率监测与调节
- 氧气浓度监测
- pH值监测与调节
- 定期翻堆（自然通风方式）

**（4）腐熟与后处理**
- 腐熟时间：1~6个月
- 处理后土壤筛分
- 检测达标后回用或处置

##### 6.7.4 运行参数

- 含水率：20%~40%
- pH值：6.5~8.5
- 温度：中温20~40℃，高温45~65℃
- 碳氮比：25:1~30:1
- 氧气浓度：>5%（好氧）
- 修复周期：3~12个月

##### 6.7.5 优缺点

**优点：**
- 环境友好，二次污染小
- 处理成本低
- 可改善土壤结构和肥力
- 原位修复对场地扰动小

**缺点：**
- 修复周期长
- 受环境条件影响大（温度、季节等）
- 对难降解污染物效果差
- 对高浓度污染物处理效果有限
- 处理效果不稳定

#### 6.8 植物修复

##### 6.8.1 技术原理

利用植物及其根际微生物的作用去除土壤中的污染物，主要机制包括：

- **植物提取**：植物吸收土壤中的污染物并积累在地上部分，通过收割植物去除污染物
- **植物挥发**：植物吸收污染物后通过叶面挥发到大气中
- **植物固定**：植物根系分泌物质使污染物固定，降低其迁移性和生物可利用性
- **植物降解**：植物分泌酶类降解有机污染物
- **根际生物降解**：植物根际微生物降解有机污染物

##### 6.8.2 适用范围

**适用污染物：**
- 重金属：镉、锌、铜、镍、砷、铅、汞等（植物提取/固定）
- 石油烃类、多环芳烃等有机物（根际生物降解）
- 部分农药、炸药等有机污染物

**适用条件：**
- 污染物浓度中等或较低
- 污染深度较浅（一般在根系分布范围内，0~2 m）
- 场地面积较大
- 修复周期要求不紧迫

**不适用条件：**
- 污染物浓度过高（对植物有毒害作用）
- 污染深度大
- 修复工期要求短
- 污染面积小、污染重的场地

##### 6.8.3 工艺设计

**（1）植物选择**
- 超富集植物（重金属）：东南景天、蜈蚣草、遏蓝菜等
- 高生物量植物：杨树、柳树、玉米、向日葵等
- 耐污染植物：芦苇、香蒲等
- 考虑本地适生树种

**（2）种植设计**
- 种植密度：根据植物种类确定
- 种植方式：直播、移栽、扦插等
- 种植季节：选择适宜的季节种植

**（3）强化措施**
- 添加螯合剂（重金属植物提取）：EDTA、柠檬酸等
- 施肥：氮、磷、钾等营养元素
- 调节土壤pH值
- 水分管理
- 接种根际微生物

**（4）植物收获与处置**
- 收获时间：根据生长周期和污染物积累情况确定
- 收获方式：收割地上部分
- 植物处置：安全焚烧、堆肥、填埋等

##### 6.8.4 运行参数

- 修复周期：一般1~5年，甚至更长
- 植物生长周期：每年1季或多季
- 重金属富集系数：因植物和元素而异

##### 6.8.5 优缺点

**优点：**
- 环境友好，生态友好
- 处理成本低
- 不破坏土壤结构
- 具有景观效益
- 适用于大面积、低浓度污染

**缺点：**
- 修复周期长
- 受气候、季节影响大
- 对高浓度污染物不适用
- 对深层污染不适用
- 植物处置可能带来二次污染
- 超富集植物生物量小，处理效率低

#### 6.9 填埋处置

##### 6.9.1 技术原理

将污染土壤运输至符合环保要求的危险废物填埋场或生活垃圾填埋场进行最终处置，将污染物与环境隔离，防止其对人体健康和生态环境造成危害。

##### 6.9.2 适用范围

**适用情况：**
- 污染土壤无法通过其他修复技术有效处理
- 其他修复技术在技术或经济上不可行
- 污染土壤量较小
- 应急处理

**分类：**
- 危险废物填埋：列入危险废物名录的污染土壤
- 生活垃圾填埋：未列入危险废物名录、满足入场要求的污染土壤
- 安全填埋：专门的危险废物安全填埋场

##### 6.9.3 技术要求

**（1）入场要求**
- 危险废物填埋：需进行危险废物鉴别，符合入场标准
- 生活垃圾填埋：需符合入场控制标准
- 含水率要求：一般<60%
- 不得含有游离液体

**（2）运输要求**
- 使用密闭运输车辆
- 防止沿途泄漏和遗撒
- 按规定路线和时间运输
- 办理转移联单（危险废物）

**（3）填埋作业要求**
- 分层填埋、分层压实
- 每日覆盖
- 渗滤液收集和处理
- 填埋气收集和处理
- 雨污分流

##### 6.9.4 环境管理

- 渗滤液监测
- 地下水监测
- 填埋气监测
- 封场后长期监测（一般不少于30年）

##### 6.9.5 优缺点

**优点：**
- 处理彻底，风险可控
- 适用范围广，几乎所有污染土壤都可填埋
- 处理周期短
- 技术成熟可靠

**缺点：**
- 处理成本高（运输+填埋费）
- 占用土地资源
- 长期环境风险（渗滤液渗漏）
- 未从根本上消除污染物
- 不符合循环经济和可持续发展理念

### 7 修复方案制定

#### 7.1 技术路线选择

##### 7.1.1 选择原则

- 技术可行性与经济合理性相结合
- 单一技术与组合技术相结合
- 原位修复与异位修复相结合
- 快速修复与长效管控相结合
- 工程实施与环境安全相结合

##### 7.1.2 组合修复技术

对于复杂污染场地，常采用多种修复技术组合使用：

**常见组合方式：**
- 土壤气相抽提 + 生物通风（SVE+BV）
- 化学氧化 + 生物修复
- 土壤淋洗 + 生物修复/固化稳定化
- 原位热脱附 + 土壤气相抽提
- 固化稳定化 + 阻隔填埋
- 植物修复 + 化学钝化

**组合策略：**
- 预处理 + 主处理 + 后处理
- 快速降低浓度 + 长效控制
- 重污染区异位处理 + 轻污染区原位处理
- 浅层修复 + 深层管控

#### 7.2 工艺参数设计

##### 7.2.1 设计依据

- 土壤污染状况调查结果
- 风险评估报告和修复目标
- 修复技术原理和工艺要求
- 场地水文地质条件
- 相关技术规范和标准
- 中试试验结果（如有）

##### 7.2.2 设计内容

**（1）处理规模**
- 污染土壤方量
- 污染地下水方量
- 日均处理量
- 总处理周期

**（2）关键工艺参数**
- 药剂投加量和投加频率
- 温度、压力、流量等操作参数
- 反应/处理时间
- 水力停留时间
- 气固比、液固比等

**（3）设备选型**
- 主要设备规格和数量
- 辅助设备规格和数量
- 备用设备配置

**（4）工程布局**
- 总体平面布置
- 设备安装位置
- 管线走向
- 临时设施布置

#### 7.3 二次污染防控

##### 7.3.1 废气污染防控

**主要污染源：**
- 异位修复：开挖、装卸、筛分、破碎过程的扬尘和VOCs
- 原位修复：抽提尾气
- 热脱附：高温烟气

**防控措施：**
- 密闭作业：密闭筛分、密闭输送
- 集气系统：负压收集废气
- 废气处理：活性炭吸附、催化燃烧、喷淋洗涤等
- 防尘措施：洒水抑尘、覆盖防尘网
- 厂界监测：设置厂界监测点

##### 7.3.2 废水污染防控

**主要污染源：**
- 土壤淋洗废水
- 抽取的地下水
- 场地降雨径流
- 设备冲洗废水
- 生活污水

**防控措施：**
- 雨污分流：设置围堰、排水沟
- 废水收集：设置收集池、调节池
- 废水处理：根据水质选择处理工艺
- 回用或达标排放：处理后优先回用，不能回用的达标排放
- 防渗措施：处理设施、暂存场做防渗处理

##### 7.3.3 固体废物污染防控

**主要来源：**
- 废药剂、废催化剂
- 废活性炭
- 水处理污泥
- 废包装材料
- 施工建筑垃圾

**防控措施：**
- 分类收集、分类暂存
- 危险废物交有资质单位处置
- 一般废物按规定处置
- 可回收利用的进行回收利用
- 暂存场做好防渗、防雨、防扬散

##### 7.3.4 噪声污染防控

**主要来源：**
- 施工机械
- 风机、水泵
- 破碎、筛分设备
- 运输车辆

**防控措施：**
- 选用低噪声设备
- 减振、隔声措施
- 合理安排作业时间
- 设置围挡、绿化带
- 厂界噪声达标

#### 7.4 工程安全

##### 7.4.1 施工安全

**（1）人员安全**
- 安全培训和安全教育
- 个人防护装备（安全帽、防护手套、防毒面具、防护服等）
- 有害气体监测
- 有限空间作业安全
- 职业健康监护

**（2）设备安全**
- 设备定期检查维护
- 电气安全
- 起重作业安全
- 动火作业安全
- 危险化学品储存和使用安全

**（3）场地安全**
- 围挡和警示标志
- 夜间照明
- 消防设施
- 应急通道
- 地下管线保护

##### 7.4.2 环境应急

**（1）风险识别**
- 化学品泄漏
- 废水事故排放
- 废气事故排放
- 火灾、爆炸
- 人员中毒

**（2）应急预案**
- 应急组织机构
- 应急响应程序
- 应急物资储备
- 应急处置措施
- 应急通讯与联络

**（3）应急演练**
- 定期开展应急演练
- 评估和完善应急预案

#### 7.5 修复方案比选

对2~3个备选修复方案进行综合比选，确定推荐方案：

| 比选指标 | 权重 | 方案一 | 方案二 | 方案三 |

#### 8.3 过程监测

##### 8.3.1 监测目的

- 掌握修复工程运行状况
- 验证修复效果
- 及时发现和解决问题
- 调整优化工艺参数
- 为修复效果评估提供依据

##### 8.3.2 监测内容

**（1）修复效果监测**
- 土壤中污染物浓度变化
- 地下水中污染物浓度变化
- 土壤气中污染物浓度变化

**（2）工艺参数监测**
- 流量、压力、温度
- 药剂投加量
- 风量、风压
- 含水率、pH值
- 氧化还原电位、溶解氧（生物修复）

**（3）二次污染监测**
- 厂界无组织排放监测（颗粒物、VOCs）
- 废水排放监测
- 噪声监测

**（4）环境质量监测**
- 环境空气质量监测
- 地下水质量监测
- 土壤环境质量监测（周边）

##### 8.3.3 监测频率

根据修复技术类型和施工阶段确定监测频率：
- 施工初期：高频监测，验证工艺参数
- 施工稳定期：定期监测，掌握变化趋势
- 施工后期：加密监测，评估修复效果
- 一般为每周1~2次或每月1~2次

##### 8.3.4 监测数据分析与应用

- 及时整理分析监测数据
- 绘制污染物浓度变化曲线
- 评估修复进展和趋势
- 预测达标时间
- 必要时调整工艺参数
- 发现异常及时处理

#### 8.4 工程变更管理

施工过程中出现以下情况时，应进行工程变更：
- 场地条件与原调查结果有较大差异
- 修复效果未达到预期
- 发现新的污染区域或污染物
- 设计方案存在缺陷
- 外部条件发生变化

工程变更应：
- 进行技术经济论证
- 按规定程序审批
- 做好变更记录
- 及时通知相关方

### 9 修复效果评估

#### 9.1 评估目的

在修复工程完成后，通过系统的监测和评估，判断修复工程是否达到预期的修复目标，确认土壤污染风险是否降低到可接受水平。

#### 9.2 评估依据

- 土壤污染状况调查报告
- 风险评估报告
- 修复方案及批复文件
- 修复工程施工合同
- 修复工程竣工验收资料
- 修复效果监测数据
- 相关标准和规范

#### 9.3 评估方法

##### 9.3.1 监测布点法

在修复区域内系统布设监测点，采集土壤样品进行分析检测，与修复目标值进行比较。

**布点原则：**
- 全面性：覆盖整个修复区域
- 代表性：能代表修复区域的修复效果
- 针对性：在原重污染区和污染边界加密布点

**布点数量：**
- 不少于修复前监测点数量的70%
- 满足统计检验要求

**布点方法：**
- 系统布点法
- 分区布点法
- 重点加密法

##### 9.3.2 对比评价法

将修复后的监测结果与修复前的调查结果进行对比，评价修复效果。

**评价指标：**
- 污染物浓度变化率
- 达标率
- 污染物去除率
- 风险降低程度

##### 9.3.3 统计检验法

采用统计方法检验修复前后污染物浓度是否有显著性差异：
- t检验
- 非参数检验
- 置信区间法

##### 9.3.4 空间对比法

通过空间插值分析，对比修复前后污染物的空间分布变化：
- 污染范围变化
- 污染程度变化
- 高浓度区变化

#### 9.4 合格判定

##### 9.4.1 判定标准

修复工程合格应同时满足以下条件：

**（1）浓度达标**
- 修复区域内土壤中污染物浓度达到修复目标值
- 地下水污染物浓度达到修复目标值（如有）

**（2）达标率要求**
- 所有监测点的达标率应达到一定比例（如100%或95%以上）
- 超标点的超标倍数应在可接受范围内

**（3）风险可接受**
- 修复后的致癌风险不超过可接受水平
- 修复后的非致癌危害指数不超过可接受水平

##### 9.4.2 不合格处理

如果修复效果评估不合格，应：
- 分析不合格原因
- 评估剩余风险
- 制定补充修复方案
- 实施补充修复
- 重新进行效果评估

#### 9.5 自验收

修复工程完工后，施工单位应进行自验收：
- 核查工程完成情况
- 整理施工记录和监测数据
- 进行修复效果自评
- 编制自验收报告
- 准备正式验收资料

### 10 修复验收

#### 10.1 验收条件

修复工程验收应具备以下条件：

- 完成修复方案和合同约定的全部内容
- 修复效果达到修复目标要求
- 施工过程资料完整、规范
- 质量保证和质量控制资料完整
- 环境保护设施和措施落实到位
- 编制完成修复效果评估报告
- 通过相关部门的监督检查

#### 10.2 验收程序

1. **验收申请**
   - 施工单位向委托方提出验收申请
   - 提交验收资料

2. **资料审查**
   - 审查验收资料的完整性和规范性
   - 审查修复过程的合规性

3. **现场核查**
   - 核查工程完成情况
   - 核查现场环境状况
   - 核查监测点位和监测设施

4. **采样监测**
   - 验收监测布点和采样
   - 实验室分析检测
   - 出具监测报告

5. **验收评审**
   - 召开验收评审会
   - 听取汇报、查阅资料、质询讨论
   - 形成验收意见

6. **验收结论**
   - 通过验收
   - 限期整改后验收
   - 不通过验收

#### 10.3 验收资料

验收应提交以下资料：

- 修复工程验收申请
- 土壤污染状况调查报告
- 风险评估报告
- 修复方案及批复
- 修复工程施工合同
- 施工组织设计
- 开工报告、完工报告
- 施工记录（施工日志、设备运行记录、药剂使用记录等）
- 质量保证和质量控制资料
- 过程监测报告
- 修复效果评估报告
- 竣工图
- 工程变更资料
- 环境监测报告（废气、废水、噪声等）
- 自验收报告
- 其他相关资料

#### 10.4 后期管理

##### 10.4.1 长期监测

对于以下情况，应进行长期监测：
- 实施风险管控的地块
- 修复后仍存在低浓度污染物的地块
- 污染物性质稳定、可能长期存在的地块
- 存在地下水污染的地块
- 场地用途变更为敏感用地的地块

长期监测内容和要求见HJ 25.2。

##### 10.4.2 场地使用限制

对于未完全修复或实施风险管控的地块，应明确使用限制：
- 限制土地用途
- 限制开发深度
- 限制地下水开采
- 设置警示标志
- 建立场地档案

##### 10.4.3 场地档案管理

建立完善的场地档案，包括：
- 污染调查资料
- 风险评估资料
- 修复方案和设计资料
- 施工记录和监测数据
- 验收资料
- 后期管理资料

档案应长期保存，作为场地开发利用和环境管理的依据。
