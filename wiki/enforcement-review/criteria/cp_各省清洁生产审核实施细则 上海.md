# 各省清洁生产审核实施细则 上海

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 沪发改规范〔2023〕8号 |
| 适用范围 | 上海市行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 上海市发展和改革委员会、上海市生态环境局 |
| 实施日期 | 2023-08-01 |

## 二、主要内容
上海市实施细则突出"绿色低碳+清洁生产"协同推进，将碳排放强度纳入审核指标体系，强化工业园区整体审核模式，建立长三角清洁生产审核互认机制。规定强制性审核名单由市生态环境局会同市发改委联合发布。

## 三、清洁生产技术要求
| 阶段 | 上海特色要求 |
|------|-------------|
| 名单确定 | 双超双有 + 碳排放强度超标 |
| 园区审核 | 整体审核+产业链协同 |
| 碳排放核算 | 与审核同步开展 |
| 互认机制 | 长三角区域结果互认 |
| 资金支持 | 绿色信贷优先支持 |

## 四、合规要点
1. 高能耗、高排放企业必须同步开展碳排放核算与清洁生产审核。
2. 工业园区可整体开展审核，园区内企业共享审核成果。
3. 长三角区域其他省市审核结果经备案后予以认可。
4. 审核报告电子版通过上海市"一网通办"平台提交。
