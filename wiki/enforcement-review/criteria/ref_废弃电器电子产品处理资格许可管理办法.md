# 废弃电器电子产品处理资格许可管理办法

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 部令第13号 |
| 适用范围 | 处理资格许可管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废弃电器电子产品处理资格的许可条件和程序。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 许可条件 | 场地、技术、人员、管理符合要求 |
| 许可程序 | 申请→受理→审查→公示→发证 |
| 有效期 | 3年 |
| 变更延续 | 提前30日申请 |
| 监督管理 | 各级生态环境部门监管 |

## 四、合规要点
1. 处理单位持证规范经营
2. 许可证范围与实际经营一致
3. 到期前及时申请延续
4. 接受生态环境部门监管
