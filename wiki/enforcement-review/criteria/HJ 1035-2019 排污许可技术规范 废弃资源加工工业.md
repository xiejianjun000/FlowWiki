## HJ 1035-2019 排污许可证申请与核发技术规范 废弃资源加工工业

### 一、标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1035-2019 |
| 发布日期 | 2019-06-13 |
| 实施日期 | 2019-06-13 |
| 发布机关 | 生态环境部 |
| 适用范围 | 废弃资源加工工业排污单位（含金属废料、非金属废料、电子废弃物加工） |

### 二、适用范围

本标准适用于指导废弃资源加工工业排污单位填报排污许可证申请信息，指导核发机关审核确定排污单位排污许可要求。

### 三、产污环节与主要污染物

#### 3.1 主要生产单元
- 废金属回收加工：分拣、破碎、压块、熔炼
- 废塑料回收加工：分选、清洗、造粒
- 废橡胶回收加工：粉碎、脱硫、再生
- 废纸回收加工：分拣、打浆、脱墨
- 电子废弃物处理：拆解、破碎、分选、冶炼

#### 3.2 主要污染物
- 废气：颗粒物、VOCs、二噁英、重金属（铅、汞、镉）
- 废水：COD、SS、石油类、重金属、氨氮
- 固废：不可利用废物、二次危险废物（HW48）

### 四、许可排放限值

#### 4.1 大气污染物排放限值

| 污染物 | 排放浓度限值(mg/m³) |
|--------|---------------------|
| 颗粒物 | 30 |
| 二噁英类 | 0.5 ng-TEQ/m³ |
| 铅及其化合物 | 0.5 |
| 镉及其化合物 | 0.1 |
| 汞及其化合物 | 0.05 |
| 非甲烷总烃 | 80 |

#### 4.2 水污染物排放限值（直接排放）

| 污染物 | 排放限值(mg/L) |
|--------|----------------|
| COD | 80 |
| SS | 50 |
| 氨氮 | 10 |
| 石油类 | 5.0 |
| 总铜 | 0.5 |
| 总锌 | 1.5 |

### 五、监测要求

- 熔炼炉排口安装颗粒物、二噁英在线监测
- 废水总排口安装COD、氨氮在线监测
- 半年监测一次重金属

### 六、违法处罚依据

依据《大气污染防治法》第99条、《水污染防治法》第83条、《固体废物污染环境防治法》第108条、《排污许可管理条例》第33-35条。

### 七、对企业环保合规工作的启示

1. 重点防控二噁英与重金属排放
2. 严控电子废弃物拆解的二次污染
3. 规范危险废物（HW48）处置与转移联单
4. 落实废弃资源再生利用的环境风险全过程管控
