# 各省清洁生产审核实施细则 福建

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 闽发改规〔2023〕5号 |
| 适用范围 | 福建省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 福建省发展和改革委员会、福建省生态环境厅 |
| 实施日期 | 2023-09-01 |

## 二、主要内容
福建省实施细则对接海峡西岸经济区建设，突出电子信息、纺织鞋服、食品加工等优势产业清洁生产升级，强化海洋工程装备、海洋化工等海洋特色产业审核。建立两岸清洁生产技术交流合作机制。

## 三、清洁生产技术要求
| 阶段 | 福建特色要求 |
|------|-------------|
| 名单确定 | 双超双有+海洋特色产业 |
| 优势产业 | 电子、纺织鞋服、食品 |
| 海洋特色 | 海工装备、海洋化工 |
| 两岸合作 | 技术交流、人才培训 |
| 闽台合资 | 简化程序 |

## 四、合规要点
1. 闽台合资企业审核可申请简化程序。
2. 纺织鞋服企业审核应包含VOCs管控内容。
3. 海洋工程装备企业审核应关注海洋生态保护。
4. 通过审核企业优先纳入省级绿色制造名单。
