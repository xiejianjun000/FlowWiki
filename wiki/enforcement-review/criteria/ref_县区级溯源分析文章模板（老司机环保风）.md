# 县区级溯源分析文章模板（老司机环保风味）× 湖南实战

> 用途：参照"老司机环保"公众号的科普深度文写法，为湖南省任一县（市、区）生成一篇
> **数据驱动、机理清晰、带认知纠偏、给管控建议**的溯源分析文章。
> 触发方式见文末"请求格式"。本文档为模板，每次生成时按"填坑清单"替换为真实数据。

## 〇、数据底座与硬限制（每篇必读）
- **县域数据**：`county_daily`（AQI + 首要污染物 + 全省排名）、`county_diagnosis`（AQI级诊断，source 常为"未知"）。**无六参数浓度**。
- **区域代理**：该县所属**市州**的 `city_hourly` / `station_hourly`（六参数 + 风向风速）作为 O₃/NO₂/Ox/比值/传输的代理背景。
- **气象补充**：边界层高度 `bl_height` 在市州表为空 → 从 Open-Meteo 或 `meteor_analysis` / `weather_era5` 补。
- **工业源**：从知识库定性写该县工业结构（如冷水江=锑业冶炼+钢铁+火电），**严禁列排污许可企业清单、严禁写许可相关信息**（红线）。
- **判据库**：ND 系列（自然/二次驱动）、PC 系列（相位链传输）、OX 系列（Ox 四曲线）、o3_sensitivity（华中校准 S5）均可调用。

## 一、文章结构（老司机环保风味）
1. **标题**：设问 / 反直觉钩子。例：《XX县臭氧高，真的是"缺NOx滴定"吗？》《为什么XX县总在XX风向上"接盘"区域污染？》
2. **【开篇·现象】**：该县某时段 AQI、首要污染物、全省排名变化（一句反直觉钩子引出问题）。
3. **【框架·机理】**：点明用哪套框架——Ox=O₃+NO₂ / 特征比值法 / 相位链传输 / ND-PC 判据。
4. **【数据·拆解】**：
   - 县域 AQI 趋势 + 排名变化（county_daily + county_diagnosis）
   - 所属市州国控六参数 + 气象（标注"以市州国控为代理"）
   - 比值诊断：PM2.5/PM10、NO₂/SO₂、O₃（来自市州代理）
5. **【归因·多因子】**：
   - 工业源结构（定性）+ 风向匹配（上风向工业/传输通道）
   - 气象：温度/湿度/风速/边界层（Open-Meteo 补 BLH）
   - 区域传输：相位链 PC 判据 + `transport_channels`
   - 认知纠偏：ND003 滴定叙事护栏 / ND005 OPE / ND006 四分量拆解（若适用）
6. **【管控建议】**：分污染带 / 分时段 / VOC+NOx 协同削减。
7. **【数据来源与口径】**：明确 county_daily=省控AQI排名、city_hourly=市州国控代理、工业源=知识库定性（不含许可清单）。
8. **【参考文献】**：对应老司机环保文 + 国标（GB 3095-2026、HJ 1352-1354）+ ND/PC/OX 判据源。

## 二、填坑清单（生成时逐条替换）
| 坑位 | 取数位置 | 说明 |
|------|----------|------|
| 县名 / 所属市州 | 用户提供 | 如 冷水江市（娄底市） |
| 时间段 / 污染过程 | 用户提供（建议给具体日期窗口） | 重污染或 O₃ 高值过程 |
| 县域 AQI 趋势 | `county_daily` WHERE county_name=? | 按 query_date 排序 |
| 全省排名变化 | `county_daily.sort_rank` / `county_diagnosis.rank_change` | 注意排名越小越优 |
| 市州六参数代理 | `city_hourly` / `station_hourly` WHERE city_name=? | O₃/NO₂/PM2.5/PM10/SO₂/CO |
| 风向风速 | 同上 `wind_direction`/`wind_speed` | 传输通道判定 |
| 边界层高度 | Open-Meteo / `meteor_analysis` | 市州表 bl_height 为空 |
| 工业结构 | 知识库（定性，非许可清单） | 红线：禁列企业清单 |
| 判据调用 | src/natural_ozone_drivers.py (ND)、phase_chain_transport.py (PC)、no2_rebound_diagnostics.py (OX) | 见各模块 docstring |

## 三、请求格式（用户触发语，可直接复制）
```
就 <县名>（<所属市州>） <时间段/污染过程描述> 写一篇老司机环保风格的溯源分析文章
```
示例：
```
就 冷水江市（娄底） 2026年6月下旬臭氧高值过程 写一篇老司机环保风格的溯源分析文章
```
可选加约束：
- "重点用 Ox 框架拆滴定叙事" → 强化 ND003/ND006
- "重点看区域传输" → 强化 PC 相位链
- "只要 1500 字科普版" / "要带数据表的完整版"

## 四、合规红线（生成时必须遵守）
1. 市州级报告用国控、县域报告用省控（县域 AQI 走 county_daily）。
2. 县域溯源**可写该县工业结构（定性）**，但**禁止列排污许可企业清单、禁止写许可相关信息**。
3. 文末必须标注数据口径（县域 AQI 排名 vs 市州国控代理）。
4. 不虚构浓度数据；六参数不足时明确写"以市州国控为代理"而非伪装成县站实测。

## 五、增强建议（打通县区级六参数后更准）
- 当前 county_daily 仅 AQI；若后续采集省控站点六参数并落库，可将 Ox/比值/滴定分析直接下沉到县，
  届时把"市州国控代理"替换为"该县省控站实测"即可，模板其余结构不变。
