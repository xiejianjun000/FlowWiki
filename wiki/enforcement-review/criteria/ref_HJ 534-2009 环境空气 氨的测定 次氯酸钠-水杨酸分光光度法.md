# HJ 534-2009 环境空气 氨的测定 次氯酸钠-水杨酸分光光度法

## 一、标准基本信息

- **标准号**：HJ 534-2009
- **实施日期**：2010年4月1日

## 二、方法原理

氨被稀硫酸吸收液吸收，在亚硝基铁氰化钠催化下，与水杨酸和次氯酸钠反应生成蓝色化合物，在697nm波长下测定吸光度。

## 三、适用范围

- 检出限：0.003 mg/m³
- 测定下限：0.012 mg/m³
- 测定上限：50 mg/m³

适用于环境空气中氨测定。

## 四、干扰与消除

- 硫化氢干扰：醋酸铅棉过滤
- 三甲胺干扰：少量加入亚硝基铁氰化钠
- 颗粒物干扰：滤膜过滤

## 五、仪器设备

- 大气采样器
- 分光光度计
- 比色皿：10mm

## 六、采样方法

- 吸收瓶：大型气泡吸收管
- 吸收液：0.01 mol/L H₂SO₄
- 采样流量：0.5-1.0 L/min
- 采样时间：30-60 min

## 七、分析步骤

1. 取吸收液10 mL
2. 加入水杨酸-酒石酸钠溶液
3. 加入亚硝基铁氰化钠溶液
4. 加入次氯酸钠溶液
5. 显色1h
6. 697nm波长测定

## 八、结果计算

```
C(NH₃) = (W - W₀) / Vstd
```

## 九、质量保证

- 全程序空白
- 加标回收率：90-110%
- 平行样偏差：≤10%

## 十、对企业环保启示

1. 灵敏度高于纳氏试剂法
2. 适用于低浓度氨监测
3. 不含汞试剂，环保安全
