# 废铅蓄电池再生企业危废管理

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 519-2020第8章 |
| 适用范围 | 再生企业危废管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池再生企业的危险废物管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 危废种类 | 废酸、废塑料、铅泥等 |
| 贮存要求 | 符合GB 18597 |
| 转移要求 | 电子联单管理 |
| 处置要求 | 持证单位处置 |
| 台账管理 | 全过程记录 |

## 四、合规要点
1. 危废分类规范管理
2. 贮存符合标准要求
3. 转移使用电子联单
4. 处置交持证单位
