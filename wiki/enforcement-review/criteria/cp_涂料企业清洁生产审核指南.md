# 涂料企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国涂料工业协会发〔2022〕5号 |
| 适用范围 | 涂料、油墨、颜料及类似产品制造企业 |
| 发布机关 | 中国涂料工业协会 |
| 实施日期 | 2022-07-01 |

## 二、主要内容
本指南针对涂料企业特点，重点识别树脂合成、色浆研磨、调漆等关键工序清洁生产潜力。强调水性涂料替代、溶剂回收、VOCs源头减排。涵盖低VOCs产品占比、溶剂回收审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万元产值VOCs |
| 审核 | 树脂合成、调漆 |
| 方案筛选 | 水性涂料+溶剂回收 |
| 高费方案 | 反应工艺升级 |
| 实施验证 | VOCs减排 |
| 持续改进 | 低VOCs产品 |

## 四、合规要点
1. 应扩大水性、粉末等低VOCs涂料比例。
2. 溶剂应配套回收装置，回收率不低于70%。
3. VOCs应执行GB 37824排放标准。
4. 含重金属颜料废渣应作为危险废物处置。
