# 危险废物鉴别标准 反应性鉴别

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 5085.5-2007 |
| 适用范围 | 危险废物反应性鉴别 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物反应性鉴别标准和判定方法。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 爆炸性 | 受热/撞击/摩擦易爆炸 |
| 与水反应性 | 遇水产生易燃气体或有毒气体 |
| 氰化物释放 | 产生HCN≥250mg/kg |
| 硫化物释放 | 产生H₂S≥500mg/kg |
| 鉴别结论 | 符合任一即具有反应性 |

## 四、合规要点
1. 反应性测试做好安全防护
2. 取样过程防止反应触发
3. 保留试验数据和安全记录
4. 鉴别结论用于危废分类管理
