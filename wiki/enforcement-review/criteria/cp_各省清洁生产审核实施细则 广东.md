# 各省清洁生产审核实施细则 广东

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 粤发改规〔2023〕4号 |
| 适用范围 | 广东省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 广东省发展和改革委员会、广东省生态环境厅 |
| 实施日期 | 2023-05-01 |

## 二、主要内容
广东省实施细则对接粤港澳大湾区建设，建立港澳资企业清洁生产审核绿色通道，推行"互联网+审核"模式，强化粤港、粤澳清洁生产合作。突出电子信息、石化、汽车制造等优势产业的清洁生产要求。

## 三、清洁生产技术要求
| 阶段 | 广东特色要求 |
|------|-------------|
| 名单确定 | 双超双有 + 重点行业重点抓 |
| 港澳资通道 | 简化程序、互认专家 |
| 互联网+审核 | 线上评审、远程视频验收 |
| 产业集群 | 集群整体推进 |
| 粤港澳合作 | 联合培训、技术交流 |

## 四、合规要点
1. 港澳资企业可申请粤港澳大湾区清洁生产审核绿色通道。
2. 重点行业（电子、石化、汽车）企业5年内至少完成1次审核。
3. 审核过程应使用广东省清洁生产信息管理系统。
4. 通过验收的企业纳入广东省绿色企业名录，享受差别化政策。
