# 危险废物填埋场运行管理规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18598-2019第7章 |
| 适用范围 | 填埋场运行管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场的运行管理、操作和监督要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 入场检验 | 逐批检测废物特性 |
| 填埋作业 | 分区填埋、日覆盖 |
| 运行记录 | 废物信息、作业记录 |
| 人员配置 | 持证操作人员 |
| 应急管理 | 应急预案、物资、演练 |

## 四、合规要点
1. 入场废物逐批检验合格
2. 填埋作业规范分区实施
3. 运行记录完整可追溯
4. 应急预案定期演练
