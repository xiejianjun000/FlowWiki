# GB18596-2001 畜禽养殖业污染物排放标准

## 标准概述
- 标准编号：GB18596-2001
- 标准名称：畜禽养殖业污染物排放标准
- 发布机关：生态环境主管部门、国家市场监督管理总局（见标准原文）。
- 发布日期：见标准原文。
- 施行日期：2003-01-01
- 适用范围：见标准原文适用范围。

## 适用行业
对应 GB/T 4754 行业代码：031, 032, 039, 132（农副食品加工业）

## 核心限值表
| 污染物 | 排放限值 | 单位 | 适用条件 |
|--------|---------|------|---------|
| 生化需氧量 | I级:150 / II级:200 | mg/L | 见标准 |
| 化学需氧量 | I级:400 / II级:600 | mg/L | 见标准 |
| 悬浮物 | I级:200 / II级:400 | mg/L | 见标准 |
| 氨氮 | I级:80 / II级:120 | mg/L | 见标准 |
| 总磷 | I级:8.0 / II级:12.0 | mg/L | 见标准 |
| 粪大肠菌群数 | I级:10000 / II级:10000 | 个/L | 见标准 |
| 蛔虫卵 | I级:2.0 / II级:2.0 | 个/L | 见标准 |
| 蛔虫卵死亡率（%） | 指标:≥95 | % | 见标准 |
| 粪大肠菌群数（个/kg） | 指标:≤10⁵ | 个/kg | 见标准 |
| 臭气浓度 | 标准值:≤70（I级）/ ≤60（II级） | 无量纲 | 见标准 |

## 监测要求
（采样点、频次、方法提要）见标准原文及配套监测方法标准。核心要求：按 GB/T 16157、HJ/T 397 等规范布点采样；水污染物在企业废水总排放口及车间排放口监控；大气污染物在排气筒、厂界监控点监测。

## 对企业的影响
- 需识别本标准适用工序及排放口，建立污染物台账。
- 依据直接/间接排放、现有/新建企业、一般/重点区域选择对应限值。
- 配套安装治理设施并保留运行记录，确保稳定达标。
- 定期开展自行监测，保存原始监测数据不少于规定年限。
- 关注修改单及地方排放标准，及时更新合规判定依据。
