# 危险废物贮存场所事故应急池设计规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 50160-2008 |
| 适用范围 | 事故应急池设计 |
| 发布机关 | 住房和城乡建设部 |

## 二、主要内容
规定了危险废物贮存场所事故应急池的设计要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 容积计算 | 最大泄漏量+消防废水量+降雨量 |
| 位置设置 | 便于收集泄漏液和消防废水 |
| 防渗要求 | 与贮存场所同等防渗标准 |
| 配套设备 | 泵、阀门、导流管道 |
| 标识管理 | 标识清晰，定期检查 |

## 四、合规要点
1. 事故应急池容积满足设计要求
2. 防渗等级与贮存场所一致
3. 配套设备定期检查维护
4. 应急池保持空池备用状态
