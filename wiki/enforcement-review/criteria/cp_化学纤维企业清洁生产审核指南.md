# 化学纤维企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国化纤工业协会发〔2022〕6号 |
| 适用范围 | 粘胶、涤纶、锦纶、氨纶等化学纤维制造企业 |
| 发布机关 | 中国化学纤维工业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对化学纤维企业特点，重点识别聚合、纺丝、后处理等关键工序清洁生产潜力。强调溶剂回收、二硫化碳管控、含锌废水处理、废丝回收。涵盖溶剂回收率、COD减排审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨纤维COD、溶剂 |
| 审核 | 纺丝、后处理 |
| 方案筛选 | 溶剂回收+废丝利用 |
| 高费方案 | 闭路循环系统 |
| 实施验证 | 减排+回收 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 粘胶纤维企业应配套二硫化碳回收。
2. 涤纶企业应配套EG/PTA回收。
3. 含锌、含酸废水应分质处理回用。
4. 废丝、废料应回收再生利用。
