# 危险废物填埋场渗滤液处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014第7章 |
| 适用范围 | 渗滤液处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场渗滤液的处理技术和排放要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 渗滤液特性 | 高浓度有机物、重金属 |
| 处理工艺 | 预处理+生化处理+深度处理 |
| 排放限值 | 符合GB 8978或地方标准 |
| 回灌处理 | 可作为辅助处理方式 |
| 应急储存 | 设置应急储存池 |

## 四、合规要点
1. 渗滤液处理工艺完善有效
2. 处理后排放符合标准限值
3. 应急储存池防止外溢
4. 定期监测渗滤液水质水量
