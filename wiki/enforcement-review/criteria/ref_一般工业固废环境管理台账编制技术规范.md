# 一般工业固废环境管理台账编制技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1200-2021 |
| 适用范围 | 一般工业固废产生单位台账编制 |
| 发布机关 | 生态环境部 |

## 二、主要内容
详细规定了一般工业固废环境管理台账的编制要求、记录内容、格式和保存方式。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 台账类型 | 电子台账+纸质台账 |
| 记录要素 | 产生节点、种类、数量、流向 |
| 计量要求 | 精度不低于±5% |
| 签字确认 | 经办人、复核人签字 |
| 电子化报送 | 对接全国固废信息系统 |

## 四、合规要点
1. 按规范格式编制台账，确保要素齐全
2. 计量器具定期校准
3. 台账记录与实际操作同步
4. 指定专人负责台账管理
