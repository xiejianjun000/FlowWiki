## 🔧 二、方法架构

### 2.1 全流程自动化

```
污染源配置 → 气象数据驱动 → 扩散模拟 → 浓度制图 → 多格式输出
    ↓              ↓              ↓           ↓           ↓
 CONTROL文件    GDAS/GFS      hycs_std    concplot    PDF/PNG/GIF
```

### 2.2 五大功能模块

| 模块 | 功能 | 输出 |
|------|------|------|
| **参数统一配置** | 模拟时间、污染源坐标、排放高度、释放速率 | CONTROL文件 |
| **控制文件自动生成** | 多源排放、网格配置、垂直分层 | 标准HYSPLIT输入 |
| **核心扩散模拟** | 输送、扩散、沉降、干湿沉积 | cdump浓度文件 |
| **专业可视化制图** | 对数色标、标准配色、地图叠加 | PS/EPS图形 |
| **多格式成果输出** | PDF矢量、PNG序列、GIF动画 | 直接可用成果 |


## 📊 三、技术参数详解

### 3.1 污染源配置（核心）

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 经纬度 | 污染源位置 | 用户输入 |
| 排放高度 | 烟囱/释放高度 | 分层双源配置 |
| 释放速率 | 污染物排放强度 | μg/s |
| 热源强度 | 烟气抬升效应 | 火灾场景优化值 |

**关键创新**：**分层双源配置**
- 低层源：贴近地面排放（适用于一般工业泄漏）
- 高层源：热烟气抬升（适用于火灾真实场景）

### 3.2 模拟网格配置

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 水平分辨率 | 0.01°~0.05° | 约1~5km |
| 垂直分层 | 10~15层 | 地面到对流层顶 |
| 模拟时长 | 48小时 | 突发事件标准窗口 |
| 输出间隔 | 1小时 | 浓度快照频率 |

### 3.3 污染物参数（PM₂.₅示例）

| 参数 | 设置值 | 依据 |
|------|--------|------|
| 粒径分布 | 2.5 μm | PM₂.₅定义 |
| 密度 | 1.5 g/cm³ | 典型颗粒物密度 |
| 干沉降速度 | 0.2 cm/s | Stokes定律 |
| 湿沉降系数 | 5×10⁻⁵ /s | 雨除效率 |


## 🎨 四、可视化关键技术

### 4.1 对数色标分级（核心创新）

**问题**：线性色标导致高浓度区域"一片红"，低浓度区域看不清

**解决方案**：
```
浓度分级：log₁₀(C) → 整数区间映射
配色方案：
  低浓度（10⁰~10¹）：蓝→青→绿（冷色系）
  中浓度（10¹~10²）：黄→橙（过渡色）
  高浓度（10²~10³）：红→深红（警示色）
```

**效果**：高低浓度层次清晰，中心区域不饱和

### 4.2 多格式输出规范

| 格式 | 用途 | 特点 |
|------|------|------|
| **PDF矢量** | 应急报告、汇报材料 | 高清、可编辑、可直接上报 |
| **PNG序列** | 逐小时快照 | 单时刻分析、印刷排版 |
| **GIF动画** | 动态演示、决策展示 | 直观展示演变全过程 |

### 4.3 地图底图叠加

- 自动加载行政边界矢量
- 标注污染源位置、受体点位
- 叠加路网、水系（可选）
- 标题自动生成事件名称
