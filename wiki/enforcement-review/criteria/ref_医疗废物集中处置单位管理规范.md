# 医疗废物集中处置单位管理规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ/T 177-2005第8章 |
| 适用范围 | 处置单位管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了医疗废物集中处置单位的管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 经营许可 | 持危废经营许可证 |
| 服务范围 | 覆盖本行政区域 |
| 人员配置 | 持证操作人员 |
| 应急预案 | 编制并备案 |
| 信息公开 | 定期公开处置情况 |

## 四、合规要点
1. 处置单位持证规范经营
2. 服务范围满足区域需求
3. 人员持证上岗
4. 定期公开处置信息
