# GB28662-2012 钢铁烧结、球团工业大气污染物排放标准

## 标准概述
- 标准编号：GB28662-2012
- 标准名称：钢铁烧结、球团工业大气污染物排放标准
- 发布机关：生态环境主管部门、国家市场监督管理总局（见标准原文）。
- 发布日期：见标准原文。
- 施行日期：2012-10-01
- 适用范围：适用于现有钢铁烧结及球团生产企业或生产设施的大气污染物排放管理，以及钢铁烧结及球团工业建设项目的环境影响评价、环境保护设施设计、竣工环境保护验收及其投产后的大气污染物排放管理。

## 适用行业
对应 GB/T 4754 行业代码：312, 313（黑色金属冶炼和压延加工业）

## 核心限值表
| 污染物 | 排放限值 | 单位 | 适用条件 |
|--------|---------|------|---------|
| 颗粒物 | 80 / 50 / 40 | mg/m³ | 现有/新建/特别排放限值 |
| SO2 | 600 / 200 / 180 | mg/m³ | 现有/新建/特别排放限值 |
| NOx | 500 / 300 / 300 | mg/m³ | 现有/新建/特别排放限值 |
| 颗粒物（无组织） | 8.0 / 5.0 | mg/m³ | 有厂房/露天 |

## 监测要求
（采样点、频次、方法提要）见标准原文及配套监测方法标准。核心要求：按 GB/T 16157、HJ/T 397 等规范布点采样；水污染物在企业废水总排放口及车间排放口监控；大气污染物在排气筒、厂界监控点监测。

## 对企业的影响
- 需识别本标准适用工序及排放口，建立污染物台账。
- 依据直接/间接排放、现有/新建企业、一般/重点区域选择对应限值。
- 配套安装治理设施并保留运行记录，确保稳定达标。
- 定期开展自行监测，保存原始监测数据不少于规定年限。
- 关注修改单及地方排放标准，及时更新合规判定依据。
