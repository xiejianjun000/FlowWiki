# GB4053.1 标准名称：HJ 1405-2024《排污单位污染物排放口监测点位设置技术规范》

> 原始文件：raw/standards/done_标准_HJ_1405-2024_搜索结果.txt

适用范围
================================================================================

适用于排污单位（海洋油气开发工程除外）对固定污染源排放口手工监测点位、自动
监测点位的规范化设计、建设、改造、整改、验收和管理。

术语和定义（共12条）
================================================================================


## 核心限值
- 保证断面无紊流，流速相对均方差 σr ≤ 0.15
- 其他形式的手工监测孔外沿距离排气筒/烟道或保温层外壁距离应 ≤ 50mm
D ≤ 1m时，至少1个
1m < D ≤ 3.5m时，至少设置相互垂直的2个
D ≤ 3.5m时，至少在侧面水平位置设置1个
L或W ≤ 3.5m时，至少在长边一侧开1排水平的监测孔
W ≤ 3.5m时，至少在单侧开设1排竖直的监测孔
- 相邻两孔间距 ≤ 1m
- 两端孔距烟道内壁 ≤ 0.5m
- 水平排气筒/烟道侧面不具备条件且高度或直径 ≤ 3.5m时，可在顶部开设监测孔
≤ 1m时，宽度应 ≥ 1.5m
相邻钢板不应搭接，上表面高度差 ≤ 4mm
- 间隙距离：工作平台与竖直烟道/排气筒的间隙距离 ≤ 10mm
- 中间栏杆：扶手和踢脚板之间应至少设置一道中间栏杆，空隙间距 ≤ 500mm
- 立柱间距：防护栏杆端部应设置立柱，立柱间距应 ≤ 1m
