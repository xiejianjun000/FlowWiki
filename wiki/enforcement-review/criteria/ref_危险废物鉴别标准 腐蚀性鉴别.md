# 危险废物鉴别标准 腐蚀性鉴别

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 5085.1-2007 |
| 适用范围 | 危险废物腐蚀性鉴别 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物腐蚀性鉴别标准值和检测方法。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| pH值鉴别 | pH≥12.5或pH≤2.0 |
| 腐蚀速率 | 钢制容器腐蚀速率≥6.35mm/a |
| 检测方法 | 玻璃电极法测定pH |
| 采样要求 | 按HJ/T 298规定执行 |
| 鉴别结论 | 符合任一即具有腐蚀性 |

## 四、合规要点
1. 采样按HJ/T 298规范执行
2. 使用标准方法测定pH
3. 保留检测原始数据
4. 鉴别报告符合HJ 298要求
