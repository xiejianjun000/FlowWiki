# 废弃电器电子产品处理企业资格审查和许可指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 生态环境部公告2010年 |
| 适用范围 | 处理资格审查和许可 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废弃电器电子产品处理企业资格审查和许可的具体要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 审查内容 | 场地、设施、技术、人员、管理 |
| 审查程序 | 申请→受理→审查→公示→发证 |
| 现场核查 | 核查场地、设施、记录 |
| 技术要求 | 处理工艺符合规范 |
| 管理要求 | 建立环境管理制度 |

## 四、合规要点
1. 按指南要求申请处理资格
2. 场地设施技术符合要求
3. 配合生态环境部门现场核查
4. 建立完善环境管理制度
