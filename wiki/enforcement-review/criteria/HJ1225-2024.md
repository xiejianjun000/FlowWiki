# HJ1225-2024 企业温室气体排放核查技术规范

## 标准概述
- **标准编号**：HJ 1225-2024
- **标准名称**：企业温室气体排放核查技术规范
- **发布机关**：生态环境部
- **实施日期**：2024-09-01
- **代替标准**：HJ 1225-2021
- **适用范围**：纳入全国碳排放权交易市场的重点排放单位的温室气体排放核查工作；也适用于地方碳市场企业、自愿核查企业、温室气体排放清单审核

## 核查范围
| 边界类型 | 说明 |
|---------|------|
| 组织边界 | 企业拥有或控制的所有生产设施 |
| 运行边界 | 范围1直接排放、范围2间接排放 |
| 时间边界 | 报告年度（1月1日至12月31日） |
| 温室气体 | CO₂、CH₄、N₂O（按行业指南要求） |

## 核查程序
### 核查准备阶段
- 签订核查合同
- 组建核查组（组长+核查员+技术专家）
- 文件评审（完整性、一致性、合理性、齐全性）
- 制定核查计划
- 下发核查通知

### 现场核查阶段
- 首次会议
- 现场勘查（生产装置、排放源、计量器具）
- 数据核查（活动数据、排放因子、核算过程）
- 人员访谈
- 内部沟通与不符合确认
- 末次会议

### 核查报告阶段
- 问题整改
- 编制核查报告
- 内部审核
- 提交报告

## 核查技术方法

### 活动数据核查方法
| 方法 | 适用场景 |
|-----|---------|
| 凭证核对 | 发票、过磅单、结算单核对 |
| 台账核对 | 出入库台账、库存记录核对 |
| 仪表核对 | 计量仪表记录核对 |
| 趋势分析 | 月度/年度变化趋势分析 |
| 交叉验证 | 与产量、产值等数据对比 |
| 现场复核 | 抽查计量器具、抄表记录 |

### 排放因子核查要点
- 检测方法须符合标准要求
- 检测机构须具备CMA/CNAS资质
- 检测频次：每月不少于1次
- 加权平均计算须正确
- 低位发热量按GB/T 213标准检测
- 碳氧化率按指南规定选取

## 数据质量管理核查
- 是否建立碳排放数据管理制度
- 计量器具是否定期检定/校准
- 数据记录是否完整、可追溯
- 是否建立内部审核机制
- 人员是否经过培训

## 对企业的影响
- 核查工作须严格遵守本技术规范的各项要求
- 核查组人员资质须满足3年核查经验+中级以上职称
- 核查档案保存不少于10年
- 不符合项分为重大不符合、一般不符合、观察项三级
