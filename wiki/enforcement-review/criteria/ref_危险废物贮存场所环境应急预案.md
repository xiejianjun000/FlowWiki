# 危险废物贮存场所环境应急预案

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 169-2018 |
| 适用范围 | 贮存场所环境应急预案 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物贮存场所环境应急预案的编制、演练和备案要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 预案内容 | 风险评估、应急组织、响应程序 |
| 应急物资 | 吸附材料、防护用品、堵漏工具 |
| 演练频次 | 每年至少1次综合演练 |
| 预案备案 | 向县级生态环境部门备案 |
| 修订更新 | 至少每3年修订一次 |

## 四、合规要点
1. 编制并备案环境应急预案
2. 配备充足的应急物资
3. 定期开展应急演练
4. 预案适时修订更新
