# 生态环境保护法律法规汇编（2026.5）

> 涵盖生态环境法典、环境保护法、水/大气/噪声/土壤/固废/核安全等全领域法律规章及司法解释的综合性法规汇编。

## 汇编结构

### 综合类
- 中华人民共和国生态环境法典
- 中华人民共和国环境保护法
- 畜禽规模养殖污染防治条例
- 全国污染源普查条例

### 专项领域

| 领域 | 主要内容 |
|------|---------|
| 水污染防治 | 水污染防治法、地下水管理条例、城镇排水与污水处理条例、淮河/太湖/南水北调/密云水库等流域规定 |
| 大气污染防治 | 大气污染防治法及相关标准 |
| 土壤污染防治 | 土壤污染防治法 |
| 固体废物 | 固废法、危险废物管理 |
| 噪声污染防治 | 噪声污染防治法 |
| 核与辐射安全 | 核安全法、放射性污染防治法 |

### 配套材料
- **部门规章** — 生态环境部发布的规范性文件
- **司法解释** — 最高人民法院、最高人民检察院涉环境司法解释
- **国际公约** — 中国已缔约的环境保护国际公约

## 知识价值

该汇编是环保实务工作的一站式法规查询工具，适用于：

1. **执法活动** — 查找执法依据和处罚条款
2. **环评编制** — 确认项目适用的法规要求
3. **企业合规** — 环保合规管理法规参考
4. **诉讼仲裁** — 环境纠纷法律依据
