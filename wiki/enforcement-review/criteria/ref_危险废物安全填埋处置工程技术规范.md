# 危险废物安全填埋处置工程技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014 |
| 适用范围 | 安全填埋工程设计建设 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物安全填埋场的工程设计、施工和验收要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 场址选择 | 地质稳定、远离水源 |
| 库容设计 | 满足10年以上服务年限 |
| 防渗系统 | 双层人工合成材料 |
| 渗滤液收集 | 导排系统+收集池 |
| 配套设施 | 分析化验、应急设施 |

## 四、合规要点
1. 工程设计与规范要求一致
2. 防渗系统施工质量经验收合格
3. 渗滤液收集系统完善
4. 配套设施齐全有效
