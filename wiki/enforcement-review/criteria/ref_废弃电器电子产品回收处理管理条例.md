# 废弃电器电子产品回收处理管理条例

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 国务院令第551号 |
| 适用范围 | 电子废物回收处理管理 |
| 发布机关 | 国务院 |

## 二、主要内容
规定了废弃电器电子产品回收处理的管理制度。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用范围 | 电视机、电冰箱、洗衣机、空调器、微型计算机等 |
| 处理资格 | 实行处理资格许可制度 |
| 处理基金 | 征收处理基金补贴处理企业 |
| 生产者责任 | 生产者承担回收处理责任 |
| 法律责任 | 未取得资格处5万-50万元罚款 |

## 四、合规要点
1. 处理单位必须取得处理资格许可
2. 按规定征收和使用处理基金
3. 生产者落实回收处理责任
4. 建立回收处理全过程记录
