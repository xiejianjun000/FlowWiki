# HJ 1079-2019 固定污染源废气 氯苯类化合物的测定 气相色谱法

## 一、标准基本信息

- **标准号**：HJ 1079-2019
- **实施日期**：2020年6月1日

## 二、方法原理

用活性炭吸附采样管采集废气，二硫化碳解吸，经气相色谱分离，FID检测器测定。

## 三、适用范围

- 检出限：0.02 mg/m³
- 测定下限：0.08 mg/m³

适用于固定污染源有组织排放废气中氯苯类化合物测定。

## 四、测定物质

- 氯苯
- 2-氯甲苯
- 3-氯甲苯
- 4-氯甲苯
- 1,3-二氯苯
- 1,4-二氯苯
- 1,2-二氯苯

共7种。

## 五、采样方法

- 采样管：椰壳活性炭管
- 采样流量：0.5 L/min
- 采样时间：30-60 min

## 六、仪器设备

- 大气采样器
- 气相色谱仪（带FID检测器）
- 色谱柱：DB-624（30m×0.25mm×1.4μm）

## 七、分析条件

- 进样口温度：200°C
- 检测器温度：260°C
- 升温程序：40°C保持3min → 5°C/min → 100°C → 10°C/min → 220°C保持2min

## 八、结果计算

```
C = (A样 - A空) × C标 × V标 / (A标 × V)
```

## 九、质量保证

- 全程序空白
- 平行样偏差：≤20%
- 加标回收率：80-120%

## 十、对企业环保启示

1. 涉氯企业应开展氯苯类监测
2. 二硫化碳解吸效率需保证
3. 二氯苯有毒性，应重点管控
