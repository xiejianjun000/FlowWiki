## HJ 1114-2020 排污许可证申请与核发技术规范 印刷工业

### 一、标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1114-2020 |
| 发布日期 | 2020-02-28 |
| 实施日期 | 2020-02-28 |
| 发布机关 | 生态环境部 |
| 适用范围 | 印刷工业排污单位 |

### 二、适用范围

本标准适用于指导印刷工业排污单位在全国排污许可证管理信息平台填报相关申请信息，指导核发机关审核确定排污单位排污许可要求。

### 三、产污环节与主要污染物

#### 3.1 主要生产单元
- 印前制版工序
- 印刷工序（平版、凹版、凸版、孔版印刷）
- 印后加工工序（覆膜、上光、复合）
- 清洗工序

#### 3.2 主要污染物
- 废气：VOCs（重点）、苯、甲苯、二甲苯、乙酸乙酯、乙酸丁酯
- 废水：COD、SS、氨氮、石油类、重金属（来自润版液）
- 固废：废油墨罐、废润版液、废PS版、废胶片（HW06、HW49）

### 四、许可排放限值

#### 4.1 大气污染物排放限值

| 污染物 | 排放浓度限值(mg/m³) |
|--------|---------------------|
| 非甲烷总烃 | 50 |
| 苯 | 1 |
| 甲苯 | 15 |
| 二甲苯 | 20 |
| 颗粒物 | 30 |

#### 4.2 水污染物排放限值（直接排放）

| 污染物 | 排放限值(mg/L) |
|--------|----------------|
| COD | 80 |
| SS | 50 |
| 氨氮 | 10 |
| 石油类 | 5.0 |

### 五、监测要求

- 重点排放口VOCs在线监测
- 季度手工监测特征污染物
- 废水总排口监测COD、氨氮

### 六、违法处罚依据

依据《大气污染防治法》第99条、《水污染防治法》第83条、《排污许可管理条例》第33-35条。

### 七、对企业环保合规工作的启示

1. 重点控制VOCs排放，使用低VOCs含量原辅材料
2. 加强废气收集效率，落实"应收尽收"
3. 规范危险废物（HW06废溶剂）贮存与处置
4. 推行水性油墨、UV油墨等清洁生产技术
