# 废催化剂物化处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014附录 |
| 适用范围 | 废催化剂物化处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废催化剂物化处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 含贵金属、含重金属催化剂 |
| 处理工艺 | 酸浸+沉淀+回收 |
| 贵金属回收 | 铂、钯、铑等 |
| 重金属回收 | 镍、钴、铜等 |
| 残渣处置 | 按危废处置 |

## 四、合规要点
1. 废催化剂优先回收贵金属
2. 回收工艺高效低耗
3. 残渣按危废规范处置
4. 防止处理过程二次污染
