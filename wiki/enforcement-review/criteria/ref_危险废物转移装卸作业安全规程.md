# 危险废物转移装卸作业安全规程

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 12463-2009附录 |
| 适用范围 | 装卸作业安全 |
| 发布机关 | 交通运输部 |

## 二、主要内容
规定了危险废物转移装卸作业的安全要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 作业前检查 | 包装完好、车辆状况、防护用品 |
| 作业要求 | 轻装轻卸、防止撞击和倾倒 |
| 禁止行为 | 抛掷、滚动、倒置 |
| 防泄漏措施 | 配备应急物资、设置围挡 |
| 作业人员 | 持证作业、穿戴防护用品 |

## 四、合规要点
1. 装卸前检查包装和车辆状况
2. 作业人员持证并穿戴防护用品
3. 轻装轻卸防止包装破损
4. 配备应急物资防泄漏
