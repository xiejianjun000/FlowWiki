# 专用设备制造企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国机械工业联合会发〔2022〕9号 |
| 适用范围 | 矿山、冶金、化工、电力等专用设备制造企业 |
| 发布机关 | 中国机械工业联合会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对专用设备制造企业特点，重点识别焊接、机械加工、涂装、装配等关键工序清洁生产潜力。强调高效焊接、低VOCs涂装、废油废液回收。涵盖焊烟、VOCs、废油审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万元产值VOCs、焊烟 |
| 审核 | 焊接、涂装工序 |
| 方案筛选 | 焊烟收集+高固体分涂料 |
| 高费方案 | 涂装线升级 |
| 实施验证 | 减排+综合利用 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 焊接工序应配套焊烟收集处理装置。
2. 大型设备涂装应使用高固体分涂料。
3. 废油、废切削液应回收处理。
4. 探伤作业应配套射线防护和废液处理。
