# 一般工业固体废物申报登记管理办法

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 部令第15号 |
| 适用范围 | 工业固体废物产生单位的申报登记 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了一般工业固废产生单位按年度向生态环境主管部门申报登记固废种类、产生量、流向等信息的程序和要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 申报周期 | 每年1月31日前申报上一年度 |
| 申报内容 | 种类、产生量、综合利用量、处置量、贮存量 |
| 申报方式 | 全国固体废物管理信息系统在线申报 |
| 变更申报 | 信息变更后30日内更新 |
| 法律责任 | 未申报处1万元以上10万元以下罚款 |

## 四、合规要点
1. 按时完成年度申报登记工作
2. 申报数据应与台账数据保持一致
3. 保留申报凭证及相关证明材料
4. 信息变更时及时更新申报
