# 含油废物物化处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014附录 |
| 适用范围 | 含油废物物化处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了含油废物物化处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 废矿物油、油水混合物 |
| 处理工艺 | 隔油+气浮+生化 |
| 油回收 | 回收利用废油 |
| 出水要求 | 符合GB 8978 |
| 污泥处置 | 按危废处置 |

## 四、合规要点
1. 含油废物分类收集
2. 废油回收利用减少浪费
3. 出水达标排放
4. 污泥按危废规范处置
