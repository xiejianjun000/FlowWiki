# HJ 25.2-2019 建设用地土壤污染风险管控和修复监测技术导则

## 适用范围（第1条）

本标准规定了建设用地土壤污染风险管控和修复监测的工作原则、工作程序、监测内容、技术方法和监测报告编制要求。

适用监测类型：
- 土壤污染风险管控效果监测
- 土壤修复工程过程监测
- 土壤修复效果评估监测
- 土壤污染长期监测
- 建设用地土壤污染状况调查中的土壤、地下水、地表水和环境空气监测

不适用范围：放射性污染和致病性生物污染的监测。

## 核心术语（第3条）

- **风险管控（3.1）**：采取隔离、阻断、管控等措施降低土壤污染风险
- **土壤修复（3.2）**：利用物理、化学或生物方法固定、转移、吸收、降解或转化污染物
- **风险管控效果监测（3.3）**：评估风险管控措施有效性的监测活动
- **修复工程过程监测（3.4）**：修复工程实施过程中的质量和安全监测
- **修复效果评估监测（3.5）**：评估修复是否达到预期目标的监测
- **长期监测（3.6）**：确认污染物浓度持续稳定达标的长期跟踪监测
- **土壤气（3.7）**：土壤孔隙中的气体，含挥发性有机物等
- **监测井（3.8）**：为监测地下水或土壤气而专门建造的井
- **质控样（3.9）**：空白样、平行样、加标样、标准物质等
- **检出限（3.10）**：某分析方法在给定可靠度内可检出的最小浓度或量

## 监测原则与基本要求（第4条）

### 五项监测原则（4.1）

1. **针对性（4.1.1）**：根据管控/修复目标、污染特征和场地条件确定监测对象和参数
2. **规范性（4.1.2）**：严格按法规和标准规范执行，确保数据可比、可追溯
3. **系统性（4.1.3）**：系统考虑土壤、地下水、地表水、环境空气等各介质
4. **经济性（4.1.4）**：满足精度要求前提下优化方案、合理配置资源
5. **安全性（4.1.5）**：确保监测人员安全，防止二次污染

### 基本要求（4.2）

- **监测单位资质**（4.2.1）：具备相应资质和能力，人员持证上岗，设备定期检定校准
- **监测方案**（4.2.2）：包含目的、依据、内容、方法、质控措施，可根据实际调整
- **监测数据**（4.2.3）：真实、准确、完整，有完整可追溯记录，规范处理评价

## 土壤监测（第5条）

### 表层土壤监测（5.1）

**点位布设方法**（5.1.2）：
- 系统布点法、分区布点法、专业判断布点法

**点位数量限值**（5.1.2（3））：

| 地块规模 | 面积范围 | 最少采样点数 |
|----------|----------|--------------|
| 小型地块 | ≤5,000 m² | 不少于7个 |
| 中型地块 | 5,000~50,000 m² | 不少于10个 |
| 大型地块 | >50,000 m² | 不少于15个 |

**采样深度**（5.1.3）：表层一般 0~0.5 m；修复效果评估按修复深度确定。

**监测项目**（5.1.4）：关注污染物（必测）+ 其他污染物（选测）+ pH、有机质、阳离子交换量、土壤质地等理化性质。

**监测频次**（5.1.5）：

| 监测类型 | 频次要求 |
|----------|----------|
| 风险管控效果监测 | 每季度不少于1次 |
| 修复工程过程监测 | 每月不少于1次 |
| 修复效果评估监测 | 修复后1~2次 |
| 长期监测 | 第1年每季度1次，第2年起每年1~2次 |

### 深层土壤监测（5.2）

**点位要求**（5.2.2）：
- 数量不少于表层监测点数量的30%
- 每个污染区域至少3个深层监测点

**采样深度**（5.2.3）：穿透整个污染层至无污染土层；采样层间距一般 0.5~1 m，高浓度层位加密。

**监测频次**（5.2.5）：

| 监测类型 | 频次要求 |
|----------|----------|
| 风险管控效果监测 | 每半年不少于1次 |
| 修复工程过程监测 | 按修复深度和工艺确定 |
| 修复效果评估监测 | 修复后1次 |
| 长期监测 | 每年不少于1次 |

### 土壤气监测（5.3）

**布点要求**（5.3.2）：
- 每个污染区域至少3个监测点
- 沿地下水流向和土壤气扩散方向布设
- 敏感目标附近布设监测点

**采样深度**（5.3.3）：一般在地下水位以上 0.5~1 m 处；厚包气带应分层布设。

**监测项目**（5.3.4）：
- 必测：VOCs（苯系物、氯代烃等）
- 选测：其他挥发性污染物
- 参数：温度、湿度、压力、氧气浓度、二氧化碳浓度

**采样方法**（5.3.5）：
- 主动采样法：真空泵抽取，适用透气性好地层
- 被动采样法：扩散吸附采集，适用长期监测

**监测频次**（5.3.6）：

| 监测类型 | 频次要求 |
|----------|----------|
| 风险管控效果监测 | 每季度不少于1次 |
| 修复工程过程监测 | 每月不少于1次 |
| 修复效果评估监测 | 修复后1~2次 |
| 长期监测 | 第1年每季度1次，第2年起每半年1次 |

## 地下水监测（第6条）

### 监测井布设（6.2）

**平面布设原则**（6.2.2（1））：
- 沿地下水流向布设，上游设对照井，污染区及下游设监测井
- 垂直于地下水流向设监测断面，每断面不少于3个监测井
- 敏感目标附近布设监测井

**垂向布设**（6.2.2（2））：多层含水层分层布设；穿透主要污染层，进入下伏相对不透水层不少于1 m。

**监测井数量限值**（6.2.3）：

| 地块规模 | 最少监测井数量 |
|----------|----------------|
| 小型地块 | 不少于3口（含对照井） |
| 中型地块 | 不少于5口（含对照井） |
| 大型地块 | 不少于7口（含对照井） |

对照井不少于1口，布设在地下水流向上游未受污染区域。

### 洗井标准（6.3.2）

- 出水量稳定
- 水温、pH值、电导率等参数稳定
- 出水清澈，无明显悬浮物

### 采样方法（6.3.3）

| 方法 | 适用范围 | 要点 |
|------|----------|------|
| 贝勒管采样法 | 小口径监测井 | 缓慢操作，避免扰动含水层 |
| 潜水泵采样法 | 大口径监测井 | 控制流量，出水稳定后采样 |
| 气囊泵采样法 | 挥发性有机物 | 低流速，避免曝气和挥发损失 |

### 样品保存（6.3.4）

| 项目类别 | 保存条件 | 最长保存期 |
|----------|----------|------------|
| 挥发性有机物 | 4℃以下冷藏避光 | 7天 |
| 重金属 | 加硝酸酸化至 pH<2 | 180天 |
| 氰化物 | NaOH调至 pH>12，4℃冷藏 | 24小时 |

### 监测项目（6.4）

**必测项目**（6.4.1）：
- 关注污染物（按调查和风险评估确定）
- 常规指标：pH、总硬度、溶解性总固体、硫酸盐、氯化物、铁、锰、铜、锌、铝、挥发酚类、阴离子合成洗涤剂、高锰酸盐指数、氨氮、硝酸盐、亚硝酸盐、氟化物、汞、砷、镉、六价铬、铅、总大肠菌群、细菌总数等

### 监测频次（6.5）

| 监测类型 | 频次要求 |
|----------|----------|
| 风险管控效果监测 | 每季度不少于1次 |
| 修复工程过程监测 | 每月不少于1次 |
| 修复效果评估监测 | 修复后1~2次 |
| 长期监测 | 第1年每季度1次，第2~5年每半年1次，5年后每年1次 |

### 质量控制（6.6）

**现场质控**（6.6.1）：
- 每批次至少1个现场空白样
- 每批次至少1个现场平行样
- 不同监测井之间彻底清洗采样设备
- 采样过程完整记录

**实验室质控**（6.6.2）：
- 通过计量认证或实验室认可
- 每批次进行空白实验、平行样分析、加标回收实验
- 定期使用标准物质质控

## 地表水监测（第7条）

### 监测断面布设（7.2）

| 断面类型 | 位置 |
|----------|------|
| 对照断面 | 污染排放口上游，未受影响河段 |
| 控制断面 | 排放口下游，污染物充分混合处 |
| 消减断面 | 控制断面下游，浓度显著降低处 |

河流采样在主流通流线上布设采样垂线，按河宽确定垂线数量（7.3）。

### 监测项目（7.4）

必测项目（7.4.1）：关注污染物 + 常规指标（水温、pH、DO、高锰酸盐指数、COD、BOD5、氨氮、总磷、总氮、铜、锌、氟化物、硒、砷、汞、镉、六价铬、铅、氰化物、挥发酚、石油类、阴离子表面活性剂、硫化物、粪大肠菌群）。

### 监测频次（7.5）

| 监测类型 | 频次要求 |
|----------|----------|
| 风险管控效果监测 | 每季度不少于1次 |
| 修复工程过程监测 | 每月不少于1次 |
| 修复效果评估监测 | 修复后1次 |
| 长期监测 | 每半年不少于1次 |

## 环境空气监测（第8条）

### 监测点位布设（8.2）

- **厂界监测点**（8.2.2）：沿地块边界布设，主导风向下风向加密
- **敏感目标监测点**：周边居民区、学校、医院等
- **背景监测点**：主导风向上风向未受污染区

**点位数量**（8.2.3）：

| 点位类型 | 最少数量 |
|----------|----------|
| 厂界监测点 | 不少于4个（下风向加密） |
| 敏感目标监测点 | 按周边敏感目标分布确定 |
| 背景监测点 | 不少于1个 |

### 监测方法（8.4）

| 方法 | 适用场景 |
|------|----------|
| 主动采样法（8.4.1） | 小时浓度、日均浓度等短期监测 |
| 被动采样法（8.4.2） | 长期平均浓度监测 |
| 自动监测法（8.4.3） | 需连续监测的情况 |

### 监测频次（8.5）

| 监测类型 | 频次要求 | 每次监测时长 |
|----------|----------|--------------|
| 风险管控效果监测 | 每季度不少于1次 | 不少于3天 |
| 修复工程过程监测 | 每月不少于1次 | 不少于3天 |
| 修复效果评估监测 | 修复后1次 | 不少于7天 |
| 长期监测 | 每半年不少于1次 | 不少于7天 |

## 风险管控效果监测（第9条）

### 监测内容（9.2）

**管控措施有效性（9.2.1）**：
- 污染源管控：源头是否有效控制，排放是否达标
- 暴露途径阻断：隔离层是否完好，阻断是否有效
- 监测管控措施：长期监测系统是否正常运行

**环境介质监测（9.2.2）**：土壤、地下水、土壤气、环境空气、地表水（如涉及）。

### 监测频次（9.4）

| 阶段 | 频次要求 |
|------|----------|
| 实施初期 | 每月不少于1次 |
| 稳定运行期 | 每季度不少于1次 |
| 长期运行期 | 每半年或每年不少于1次 |

### 效果评估判定（9.5）

- 污染物浓度是否持续稳定达标
- 污染范围是否扩大
- 敏感目标处是否达标
- 管控措施是否完好有效

## 修复工程过程监测（第10条）

### 过程参数监测（10.2.1）

**异位修复**：土壤开挖量/运输量、设施运行参数（温度、压力、流量、时间）、药剂投加量和频率、尾气处理设施运行状况。

**原位修复**：药剂注入量和压力、地下水抽提量/回灌量、土壤温度/湿度、地下水位、土壤气相压力。

**生物修复**：微生物活性、营养物质浓度、溶解氧（好氧）、氧化还原电位、电子受体/供体浓度。

### 二次污染防控监测（10.2.3）

废气排放、废水排放、固体废物处置、噪声、环境空气质量。

### 监测频次（10.4）

| 监测内容 | 频次要求 |
|----------|----------|
| 过程参数监测 | 每日或实时 |
| 修复效果中间监测 | 每月不少于1次 |
| 二次污染防控监测 | 每周或每月 |

## 修复效果评估监测（第11条）

### 监测点位（11.3）

- 点位数量不少于修复前监测点数量的 **70%**（11.3.3）
- 采用系统布点法、加密布点法、对照布点法（11.3.2）
- 表层采样深度 0~0.5 m，深层覆盖整个修复深度（11.4）

### 监测频次（11.6）

修复工程完成后进行1~2次评估监测。慢性释放或难降解污染物可在修复后3~6个月进行第二次监测。

### 评估方法（11.7）

| 方法 | 说明 |
|------|------|
| 单因子评价法（11.7.1） | 达标率 =（达标点数 / 总点数）× 100% |
| 统计检验法（11.7.2） | t检验、非参数检验、置信区间法 |
| 空间对比法（11.7.3） | 空间插值分析，对比修复前后污染物空间分布 |

## 长期监测（第12条）

### 适用情形（12.2）

- 实施风险管控的地块
- 修复后仍存在低浓度污染物的地块
- 污染物性质稳定、可能长期存在的地块
- 存在地下水污染的地块
- 场地用途变更为敏感用地的地块

### 监测频次（12.5）

| 时间阶段 | 频次要求 |
|----------|----------|
| 第1年 | 每季度1次 |
| 第2~5年 | 每半年1次 |
| 第5年以后 | 每年1次 |

连续5年以上稳定达标可适当降低频次；出现异常应增加频次。

### 监测期限（12.6）

一般不少于5年。性质稳定、难降解污染物应延长监测期限。

### 异常情况处理（12.7）

1. 及时核实数据，排除监测误差
2. 增加监测频次，密切关注变化趋势
3. 分析异常原因，评估风险程度
4. 必要时采取应急措施
5. 及时向相关部门报告

## 质量保证和质量控制（第13条）

### 采样质控（13.3）

| 质控措施 | 要求 | 条款 |
|----------|------|------|
| 现场空白 | 每批次不少于1个（设备空白+运输空白+试剂空白） | 13.3.1 |
| 现场平行样 | 每批次不少于10% | 13.3.2 |
| 设备清洗 | 不同监测点之间彻底清洗，必要时采集设备空白验证 | 13.3.3 |

### 实验室分析质控（13.5）

| 质控措施 | 比例/要求 | 条款 |
|----------|-----------|------|
| 空白实验 | 每批次方法空白+试剂空白 | 13.5.3 |
| 平行样分析 | 不低于10% | 13.5.3 |

## 与其他标准的关系

- **HJ 25.1-2019**：调查技术导则，调查阶段监测的技术依据
- **HJ 25.3-2019**：风险评估技术导则，确定关注污染物的依据
- **HJ 25.4-2019**：修复技术导则，修复工程过程监测的工程设计依据
- **HJ 25.5-2018**：效果评估技术导则，修复效果评估监测的衔接标准
- **HJ/T 166**：土壤环境监测技术规范，通用土壤采样分析规范
- **HJ/T 164**：地下水环境监测技术规范，通用地下水监测规范
