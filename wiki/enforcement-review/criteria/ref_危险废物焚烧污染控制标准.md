# 危险废物焚烧污染控制标准

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18484-2020 |
| 适用范围 | 危险废物焚烧污染控制 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧设施大气污染物排放限值和监测要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 烟尘 | ≤20mg/m³ |
| CO | ≤80mg/m³ |
| TOC | ≤20mg/m³ |
| HCl | ≤60mg/m³ |
| 二噁英 | ≤0.1ng-TEQ/m³ |

## 四、合规要点
1. 焚烧设施排放符合GB 18484限值
2. 安装在线监测系统并联网
3. 定期监测二噁英和重金属
4. 建立运行和监测台账
