# 危险废物转移交接确认技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1200-2021附录D |
| 适用范围 | 转移交接确认 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物转移交接确认的程序和要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 交接程序 | 核验→称重→确认→签字 |
| 核验内容 | 废物名称、代码、数量、包装 |
| 称重要求 | 使用检定合格的计量器具 |
| 确认方式 | 电子联单确认 |
| 异常处理 | 数量不符或包装损坏时拒收 |

## 四、合规要点
1. 交接时核验废物信息
2. 称重数据准确记录
3. 通过电子联单确认交接
4. 异常情况及时拒收并报告
