# 医疗废物分类目录

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 卫生部令第36号 |
| 适用范围 | 医疗废物分类 |
| 发布机关 | 国家卫生健康委 |

## 二、主要内容
规定了医疗废物的分类、特征和包含内容。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 感染性废物 | 被病原体污染的废物 |
| 病理性废物 | 病理切片、组织器官 |
| 损伤性废物 | 针头、手术刀等锐器 |
| 药物性废物 | 过期、变质药品 |
| 化学性废物 | 化学试剂、汞血压计 |

## 四、合规要点
1. 按目录准确分类医疗废物
2. 不同类别废物分开收集
3. 分类标识清晰
4. 分类错误及时纠正
