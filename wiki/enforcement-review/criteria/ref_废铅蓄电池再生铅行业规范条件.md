# 废铅蓄电池再生铅行业规范条件

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 工信部公告2016年 |
| 适用范围 | 再生铅行业规范 |
| 发布机关 | 工业和信息化部 |

## 二、主要内容
规定了废铅蓄电池再生铅企业的规范条件。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 企业规模 | 处理能力≥5万吨/年 |
| 工艺技术 | 清洁生产工艺 |
| 能耗要求 | ≤130kgce/t |
| 环保要求 | 排放符合标准 |
| 产品质量 | 再生铅符合标准 |

## 四、合规要点
1. 再生铅企业规模符合要求
2. 采用清洁生产工艺
3. 能耗和排放达标
4. 产品质量符合标准
