# 排污许可证申请与核发技术规范 人造板制造工业

## 一、标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1032-2019 |
| 发布日期 | 2019-03-25 |
| 实施日期 | 2019-03-25 |
| 适用范围 | 胶合板、纤维板、刨花板、其他人造板制造排污单位 |

## 二、产污环节与污染物

### 2.1 主要生产单元
- 备料：剥皮、削片、刨花制备
- 干燥：纤维干燥、刨花干燥
- 施胶：调胶、施胶
- 热压成型：铺装、热压、冷却
- 后处理：锯边、砂光

### 2.2 主要污染物
- 废气：颗粒物、VOCs（甲醛、苯酚）、甲醛、苯酚
- 废水：COD、SS、氨氮、甲醛、苯酚
- 固废：废木屑、废胶、废活性炭（HW06）

## 三、许可排放限值

### 3.1 大气污染物

| 污染物 | 排放浓度限值(mg/m³) |
|--------|---------------------|
| 颗粒物 | 30 |
| 甲醛 | 0.5 |
| 苯酚 | 5 |
| 非甲烷总烃 | 80 |

### 3.2 水污染物（直接排放）

| 污染物 | 排放限值(mg/L) |
|--------|----------------|
| COD | 80 |
| SS | 50 |
| 氨氮 | 10 |
| 甲醛 | 1.0 |
| 苯酚 | 0.5 |

## 四、监测要求

- 干燥机排口安装颗粒物在线监测
- 热压机排口监测甲醛、VOCs
- 废水总排口季度监测

## 五、违法处罚依据

《大气污染防治法》第99条、《水污染防治法》第83条、《排污许可管理条例》第33-35条。

## 六、合规启示

1. 重点控制甲醛排放，使用低游离甲醛胶黏剂
2. 干燥工序废气深度治理
3. 废胶、废活性炭规范处置
