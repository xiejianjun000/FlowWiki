# 铜冶炼行业清洁生产典型案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 粗铜冶炼、精铜冶炼企业 |
| 发布机关 | 生态环境部/工信部 |
| 编制时间 | 2023-2024 |

## 二、典型案例概览
1. 某铜冶炼厂闪速熔炼案例
2. 某铜冶炼厂含砷废水处理案例
3. 某铜冶炼厂铜渣综合利用案例
4. 某铜冶炼厂烟气制酸案例

## 三、清洁生产方案效果
| 案例 | 投资额 | 节能效益 | 减排效果 |
|------|--------|----------|----------|
| 闪速熔炼 | 8000万元 | 能耗降20% | 减排SO₂10% |
| 含砷废水处理 | 2500万元 | 砷回收率≥95% | 砷减排90% |
| 铜渣综合利用 | 1800万元 | 利用率≥90% | 减少占地 |
| 烟气制酸 | 5000万元 | 硫回收率≥99% | SO₂减排95% |

## 四、合规启示
1. 闪速熔炼是铜冶炼节能核心工艺。
2. 含砷废水应处理回收砷资源。
3. 铜渣应综合利用作建材原料。
4. 烟气应制酸回收硫资源。
