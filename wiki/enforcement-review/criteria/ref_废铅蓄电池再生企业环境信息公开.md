# 废铅蓄电池再生企业环境信息公开

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 环办固体〔2019〕53号 |
| 适用范围 | 环境信息公开 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池再生企业环境信息公开的内容和要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 公开内容 | 排放数据、危废管理、环境绩效 |
| 公开方式 | 企业网站、政府平台 |
| 公开频次 | 按季度更新 |
| 公开时限 | 信息产生后10个工作日内 |
| 法律责任 | 未公开处1万-3万元罚款 |

## 四、合规要点
1. 按规定公开环境信息
2. 信息公开内容真实准确
3. 按季度更新公开内容
4. 通过多个渠道便于公众获取
