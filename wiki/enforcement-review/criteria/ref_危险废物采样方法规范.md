# 危险废物采样方法规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ/T 298-2007附录A |
| 适用范围 | 危险废物采样方法 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物采样的份样数、采样量、采样工具、采样方法等要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 份样数 | 按产生量5-50个份样 |
| 采样量 | 每个份样≥1kg或1L |
| 采样工具 | 避免与样品反应的材质 |
| 采样方法 | 随机/系统/分层采样 |
| 样品保存 | 避光、低温、密封保存 |

## 四、合规要点
1. 采样方案根据废物特性制定
2. 采样工具不与样品发生反应
3. 样品标识清晰可追溯
4. 采样记录现场填写完整
