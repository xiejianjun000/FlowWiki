# HJ 701-2014 固体废物 部分元素的测定 电感耦合等离子体发射光谱法

## 一、标准基本信息

- **标准号**：HJ 701-2014
- **实施日期**：2015年2月1日

## 二、方法原理

固体废物经消解后，通过进样系统进入ICP-OES仪，元素在等离子体中被激发产生特征谱线，强度与元素浓度成正比。

## 三、适用范围

- 检出限：0.05-10 mg/kg

适用于固体废物中22种元素测定。

## 四、测定元素

银、铝、砷、硼、钡、铍、铋、钙、镉、钴、铬、铜、铁、钾、镁、锰、钠、镍、磷、铅、锶、锌。

## 五、仪器设备

- ICP-OES仪
- 微波消解仪或电热板
- 自动进样器

## 六、试剂

- 硝酸、盐酸、氢氟酸、高氯酸（优级纯）
- 多元素标准溶液

## 七、分析步骤

1. 称取0.5g样品于消解罐
2. 加入6 mL HNO₃+2 mL HCl+2 mL HF
3. 微波消解
4. 冷却后转入50 mL容量瓶
5. 加水定容
6. 上机测定

## 八、结果计算

```
C(mg/kg) = (I - I₀) × V × f / m
```

## 九、质量保证

- 全程序空白
- 平行样偏差：≤15%
- 加标回收率：85-115%

## 十、对企业环保启示

1. ICP-OES适用于中高浓度
2. 一次进样可测定多种元素
3. 微波消解适合含硅样品
