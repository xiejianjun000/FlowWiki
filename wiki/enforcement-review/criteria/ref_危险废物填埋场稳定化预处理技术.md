# 危险废物填埋场稳定化预处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014第6章 |
| 适用范围 | 稳定化预处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋前稳定化预处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 稳定化方式 | 水泥固化、化学药剂稳定化 |
| 固化剂 | 水泥、沥青、有机聚合物 |
| 配比设计 | 根据废物特性确定 |
| 养护时间 | ≥7天 |
| 检测要求 | 固化体浸出毒性检测 |

## 四、合规要点
1. 根据废物特性选择稳定化方式
2. 固化剂配比经过试验确定
3. 固化体养护后检测达标
4. 记录稳定化处理参数
