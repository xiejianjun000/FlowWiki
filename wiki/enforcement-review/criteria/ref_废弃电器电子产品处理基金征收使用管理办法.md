# 废弃电器电子产品处理基金征收使用管理办法

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 财政部公告2012年 |
| 适用范围 | 处理基金征收使用 |
| 发布机关 | 财政部 |

## 二、主要内容
规定了废弃电器电子产品处理基金的征收和使用。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 征收对象 | 电器电子产品生产者 |
| 征收标准 | 电视机13元/台、电冰箱12元/台等 |
| 基金用途 | 补贴处理企业 |
| 补贴标准 | 根据处理量核定 |
| 监督管理 | 财政、税务、生态环境部门监管 |

## 四、合规要点
1. 生产者按规定缴纳处理基金
2. 处理企业按规定申请补贴
3. 基金使用接受监督管理
4. 保留基金缴纳和补贴凭证
