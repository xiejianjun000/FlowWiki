# 危险废物膜分离处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014第6.2条 |
| 适用范围 | 膜分离处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物膜分离处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 含油废液、含盐废液 |
| 膜类型 | 反渗透、超滤、纳滤 |
| 分离效率 | ≥95% |
| 膜清洗 | 定期化学清洗 |
| 浓缩液处理 | 进一步处理或处置 |

## 四、合规要点
1. 根据废物特性选择膜类型
2. 定期清洗保证膜通量
3. 浓缩液进一步处理
4. 监测出水水质
