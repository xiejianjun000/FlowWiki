# 在线监测执法督察与企业合规知识库

## 概述

本 Skill 提供污染源在线监测（CEMS/自动监测）领域的全面知识支持，覆盖两大核心场景：

- **执法督察**：现场检查、证据固定、案件移送、裁量基准、法律适用的全流程技术支持
- **企业合规**：法定义务自查、禁止行为识别、违法后果预警、合规体系建设

知识库经历5轮深度学习建设，累计219种造假方法、266条研判规则、234种识别方法、138个典型案例、55项法律法规，以《中华人民共和国生态环境法典》（5编1242条，2026年8月15日施行）为核心法律依据。

## 核心法律框架

### 《中华人民共和国生态环境法典》

- **结构**：5编（总则编、污染防治编、生态保护编、绿色低碳发展编、法律责任编），共1242条
- **生效日期**：2026年8月15日
- **整合**：整合现行30余部生态环境法律法规

### 核心条款速查

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| **第80条** | 六类禁止弄虚作假行为 | 行为定性 — 所有造假案件的核心定性条款 |
| **第76-79条** | 监测设施安装、运行、联网、视频监控 | 义务认定 — 企业是否履行法定义务 |
| **第81条** | 技术服务机构义务 | 第三方责任 — 运维/检测机构违法行为 |
| **第1085条** | 企事业单位一般违法处罚（2-20万） | 行政处罚 — 一般违规 |
| **第1086条** | 企事业单位弄虚作假处罚（10-200万+停产） | 行政处罚 — 严重违法 |
| **第1087条** | 技术服务机构弄虚作假处罚（10-200万+吊销+禁业） | 行政处罚 — 第三方 |
| **第1071条** | 刑事责任衔接（刑法第338/286/229条） | 刑事追诉 — 污染环境罪/破坏计算机信息系统罪/提供虚假证明文件罪 |
| **第1062条第6项** | 政府官员篡改监测数据责任 | 公职人员追责 |
| **第1067条** | 技术服务机构与委托方连带责任 | 民事赔偿 |

## 两大使用场景

### 场景一：执法督察

**适用人群**：生态环境执法督察人员

**使用入口**：HTML工具 `enforcement-quick-reference/enforcement-quick-reference.html`（离线可用，手机/平板适配）

**完整工作流**：

```
日常非现场巡查
  │
  ├─ 发现数据异常 → 读取「研判规则/02-研判规则全量库_第三轮.md」→ 匹配异常模式
  │
  ├─ 准备现场检查 → 打开「enforcement-quick-reference.html」→ 出发前准备清单
  │
  ├─ 现场检查 → 速查「35种检查清单」+「六步法（查看测听问录）」逐项核查
  │
  ├─ 发现涉嫌造假 → 读取「执法取证/01-执法取证与程序规范.md」→ 电子证据固定
  │
  ├─ 法律适用 → 读取「法律法规/03-生态环境法典索引与知识库映射.md」→ 法典条款定位
  │
  ├─ 量罚参考 → 读取「执法取证/02-裁量基准与量刑标准.md」→ 处罚幅度确定
  │
  ├─ 案件移送 → 速查「移送流程」→ 3日决定→24小时移交→3/7/30日立案

  └─ 案例参考 → 读取「典型案例/」→ 138个案例类比分析
```

## 调用规则

### 当用户提出以下问题时，应调用本 Skill：

**执法督察类**：
- "如何判断监测数据是否造假？"
- "现场检查应该检查哪些项目？"
- "在线监测造假怎么取证？"
- "这个案子应该怎么定性？用什么条款处罚？"
- "案件移送公安的程序是什么？"
- "这个造假行为属于哪种类型？"
- "有没有类似的案例可以参考？"
- "生态环境法典对在线监测有什么规定？"
- "第三方运维机构造假怎么处罚？"

**企业合规类**：
- "企业在线监测有哪些法定义务？"
- "我们公司怎么自查在线监测是否合规？"
- "在线监测违规会有什么后果？"
- "运维记录应该怎么做？"
- "生态环境法典对排污单位有什么要求？"
- "第三方运维机构需要注意什么？"
- "在线监测数据异常怎么处理？"

### 响应策略

1. **先判断场景**：执法督察还是企业合规
2. **定位主查文件**：根据上表确定主要查阅的文件
3. **读取文件**：使用 Read 工具读取对应的知识库文件
4. **提取关键信息**：从文件中提取与用户问题直接相关的内容
5. **提供结构化回答**：
   - 执法场景：行为定性 → 条款适用 → 处罚标准 → 案例参考
   - 企业场景：义务清单 → 风险识别 → 后果评估 → 整改建议
6. **必要时推荐HTML工具**：现场检查推荐速查手册，企业自查推荐合规指南

### 知识库文件路径

知识库根目录为当前工作目录下的 `knowledge_base/`。读取文件时使用绝对路径。例如：
- `knowledge_base/研判规则/02-研判规则全量库_第三轮.md`
- `knowledge_base/法律法规/03-生态环境法典索引与知识库映射.md`
- `knowledge_base/执法取证/01-执法取证与程序规范.md`
