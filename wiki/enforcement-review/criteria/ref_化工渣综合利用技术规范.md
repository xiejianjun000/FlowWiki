# 化工渣综合利用技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1097-2020 |
| 适用范围 | 化工行业固废的综合利用 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了化工渣（电石渣、磷石膏、硫铁矿渣等）综合利用的技术要求和污染控制。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 利用前处理 | 中和、脱水、分级 |
| 有害物质限值 | 符合GB 5085鉴别标准 |
| 利用途径 | 建材原料、土壤改良、化工原料 |
| 污染控制 | 废气、废水达标排放 |
| 产品质量 | 符合相应产品标准 |

## 四、合规要点
1. 利用前开展危险废物鉴别
2. 建立化工渣利用全过程污染控制
3. 防止重金属等有害物质富集
4. 定期监测利用产物环境影响
