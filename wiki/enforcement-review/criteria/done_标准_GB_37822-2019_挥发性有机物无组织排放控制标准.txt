一、适用范围
================================================================================

  本标准规定了：
  - VOCs物料储存无组织排放控制要求
  - VOCs物料转移和输送无组织排放控制要求
  - 工艺过程VOCs无组织排放控制要求
  - 设备与管线组件VOCs泄漏控制要求
  - 敞开液面VOCs无组织排放控制要求
  - VOCs无组织排放废气收集处理系统要求
  - 企业厂区内及周边污染监控要求

  适用于：
  - 涉及VOCs无组织排放的现有企业或生产设施的VOCs无组织排放管理
  - 涉及VOCs无组织排放的建设项目的环境影响评价、环境保护设施设计、
    竣工环境保护验收、排污许可证核发及其投产后的VOCs无组织排放管理

  因安全因素或特殊工艺要求不能满足本标准规定的，可采取其他等效污染
  控制措施，并向当地生态环境主管部门报告。

三、重要术语和定义
================================================================================

  3.1 挥发性有机物（VOCs）
      参与大气光化学反应的有机化合物，或根据有关规定确定的有机化合物。
      可采用TVOC或NMHC作为污染物控制项目。

  3.2 总挥发性有机物（TVOC）
      对废气中的单项VOCs物质进行测量，加和得到VOCs物质的总量。

  3.3 非甲烷总烃（NMHC）
      氢火焰离子化检测器有响应的除甲烷外的气态有机化合物的总和。

  3.4 无组织排放
      大气污染物不经过排气筒的无规则排放。

  3.5 密闭
      污染物质不与环境空气接触的状态或作业方式。

  3.6 VOCs物料
      VOCs质量占比大于等于10%的物料，以及有机聚合物材料。

  3.7 挥发性有机液体
      真实蒸气压>=0.3kPa的单一组分有机液体，或混合物中真实蒸气压
      >=0.3kPa的组分总质量占比>=20%的有机液体。

  3.8 现有企业
      本标准实施之日前已建成投产或环评文件已通过审批或备案的工业
      企业或生产设施。

  3.9 新建企业
      自本标准实施之日起环评文件通过审批或备案的新建、改建和扩建
      的工业建设项目。

  3.10 重点地区
       大气污染严重或生态环境脆弱，需要严格控制大气污染物排放的地区。

五、VOCs物料储存无组织排放控制要求
================================================================================

  5.1 基本要求
      （1）VOCs物料应储存于密闭的容器、包装袋、储罐、储库、料仓中。
      （2）容器或包装袋应存放于室内或设置有雨棚、遮阳和防渗设施的
           专用场地，非取用状态时应加盖、封口。
      （3）VOCs物料储库、料仓应满足密闭空间要求。

  5.2 挥发性有机液体储罐控制要求

      ┌─────────────────────────────────┬──────────────────────────┐
      │ 条件                             │ 控制要求                 │
      ├─────────────────────────────────┼──────────────────────────┤
      │ 蒸气压>=76.6kPa 且 容积>=75m3   │ 采用低压罐、压力罐或     │
      │                                 │ 其他等效措施             │
      ├─────────────────────────────────┼──────────────────────────┤
      │ 27.6kPa<=蒸气压<76.6kPa         │ 浮顶罐（高效密封）、     │
      │ 且 容积>=75m3                    │ 固定顶罐（废气收集处理   │
      │                                 │ 效率>=80%）、气相平衡系统│
      ├─────────────────────────────────┼──────────────────────────┤
      │ 重点地区特别控制要求             │ 处理效率不低于90%        │
      └─────────────────────────────────┴──────────────────────────┘

  5.3 储罐运行维护要求
      （1）浮顶罐应保持完好，无孔洞缝隙，浮顶始终漂浮于物料表面。
      （2）固定顶罐应保持完好，定期检查呼吸阀定压。
      （3）不符合要求的应在90天内修复或排空停止使用。

================================================================================
六、VOCs物料转移和输送无组织排放控制要求
================================================================================

  （1）液态VOCs物料应采用密闭管道输送，非管道输送采用密闭容器、罐车。
  （2）粉状、粒状VOCs物料应采用气力输送设备、管状带式输送机、螺旋
       输送机等密闭输送方式。
  （3）挥发性有机液体装载应采用底部装载方式；若采用顶部浸没式装载，
       出料管口距离槽（罐）底部高度应小于200mm。
  （4）装载控制要求：
       - 蒸气压>=27.6kPa 且 年装载量>=500m3的，废气处理效率>=80%
       - 特别控制要求（重点地区）：处理效率>=90%

================================================================================
七、工艺过程VOCs无组织排放控制要求
================================================================================

  7.1 化工生产过程
      （1）物料投加和卸放应采用密闭方式，废气排至VOCs废气收集
           处理系统。
      （2）反应设备进料置换废气、挥发排气、反应尾气等应排至VOCs
           废气收集处理系统。
      （3）离心、过滤、干燥等分离精制单元应采用密闭设备。
      （4）真空系统应采用干式真空泵，真空排气应排至VOCs废气收集
           处理系统。

  7.2 含VOCs产品的使用过程
      （1）VOCs质量占比>=10%的含VOCs产品，使用过程应采用密闭设备
           或在密闭空间内操作。
      （2）包括调配、涂装、印刷、粘结、印染、干燥、清洗等作业。

  7.3 台账要求
      （1）企业应建立台账，记录含VOCs原辅材料和产品的相关信息。
      （2）台账保存期限不少于3年。
      （3）载有VOCs物料的设备在开停工、检维修和清洗时，应退净
           残存物料。

================================================================================
八、设备与管线组件VOCs泄漏控制要求（LDAR）
================================================================================

  8.1 管控范围
      企业中载有气态/液态VOCs物料的设备与管线组件密封点>=2000个，
      应开展泄漏检测与修复（LDAR）工作。

  8.2 管控对象
      泵、压缩机、搅拌器、阀门、开口阀或开口管线、法兰及其他连接件、
      泄压设备、取样连接系统等。

  8.3 泄漏认定浓度

  ┌────────────────────────────────┬──────────────────┬──────────────────┐
  │ 物料类型                       │ 一般地区          │ 重点地区          │
  │                                │ (μmol/mol)       │ (μmol/mol)       │
  ├────────────────────────────────┼──────────────────┼──────────────────┤
  │ 气态VOCs物料                   │      5000        │      2000        │
  ├────────────────────────────────┼──────────────────┼──────────────────┤
  │ 液态VOCs物料(挥发性有机液体)   │      5000        │      2000        │
  └────────────────────────────────┴──────────────────┴──────────────────┘

  8.4 检测频次
      应按频次对密封点进行VOCs泄漏检测，包括每周目视观察。

================================================================================
九、敞开液面VOCs无组织排放控制要求
================================================================================

  （1）对于VOCs物料（或含VOCs物料）的敞开液面，应采取有效措施
       控制VOCs无组织排放。
  （2）主要涉及废水收集系统、处理设施、循环水系统等敞开液面。

================================================================================
十、VOCs无组织排放废气收集处理系统要求
================================================================================

  （1）废气收集系统排风罩应符合GB/T 16758规定，外部排风罩控制
       风速不应低于0.3 m/s。
  （2）废气收集系统应在负压下运行。
  （3）收集的废气中NMHC初始排放速率>=3kg/h时，应配置VOCs处理
       设施，处理效率不应低于80%。
       （重点地区：>=2kg/h时即需配置VOCs处理设施，处理效率>=80%）
  （4）排气筒高度不低于15m。
  （5）进入VOCs燃烧装置的废气需换算为基准含氧量3%的排放浓度。
  （6）台账保存期限不少于3年。

================================================================================
十一、企业厂区内及周边污染监控要求
================================================================================

  企业边界及周边VOCs监控执行GB 16297或相关行业排放标准的规定。

================================================================================
十二、污染物监测要求
================================================================================

  （1）企业应建立监测制度，制定监测方案，开展自行监测。
  （2）监测采样和测定方法按GB/T 16157、HJ/T 397、HJ 732、HJ 38、
       HJ 1012、HJ 1013等执行。
  （3）设备与管线组件泄漏监测按HJ 733执行。

================================================================================
十三、实施与监督
================================================================================

  由生态环境部负责解释。县级以上人民政府生态环境主管部门负责监督实施。

附录A（资料性附录）厂区内VOCs无组织排放监控要求
================================================================================

  A.1 厂区内VOCs无组织排放限值

  ┌──────────────┬──────────┬──────────────┬──────────────┬──────────────┐
  │ 污染物项目   │ 排放限值 │ 特别排放限值 │ 限值含义      │ 监控位置      │
  │              │ (mg/m3)  │ (mg/m3)      │              │              │
  ├──────────────┼──────────┼──────────────┼──────────────┼──────────────┤
  │ NMHC         │   10     │      6       │ 1小时平均     │ 厂房外        │
  │              │          │              │ 浓度值        │              │
  ├──────────────┼──────────┼──────────────┼──────────────┼──────────────┤
  │ NMHC         │   30     │     20       │ 任意一次      │ 厂房外        │
  │              │          │              │ 浓度值        │              │
  └──────────────┴──────────┴──────────────┴──────────────┴──────────────┘

  A.2 监测位置
      在厂房门窗或通风口、其他开口（孔）等排放口外1m，距离地面
      1.5m以上位置处进行监测。

  A.3 监测方法
      - 1小时平均浓度值：采用连续1小时采样计平均值，或在1小时内
        以等时间间隔采集3~4个样品计平均值。
      - 任意一次浓度值：一次采样测定值。

================================================================================
附录B（资料性附录）VOCs物料信息台账
================================================================================

  企业应记录含VOCs原辅材料名称、VOCs质量占比、使用量、回收量、
  去除量等信息，台账保存期限不少于3年。

================================================================================
标准制定背景
================================================================================

  本标准为贯彻《中华人民共和国环境保护法》和《中华人民共和国大气
  污染防治法》，防治环境污染，改善环境质量，加强对VOCs无组织排放
  的控制和管理而制定。这是我国首个专门针对VOCs无组织排放控制的
  国家排放标准，对VOCs管控具有里程碑意义。
