# 陶瓷企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国陶瓷工业协会发〔2022〕6号 |
| 适用范围 | 建筑陶瓷、卫生陶瓷、日用陶瓷生产企业 |
| 发布机关 | 中国陶瓷工业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对陶瓷企业特点，重点识别原料制备、成型、施釉、烧成等关键工序清洁生产潜力。强调喷雾塔余热利用、窑炉脱硝除尘、废瓷砖回收。涵盖天然气替代、余热回收、废料综合利用审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨瓷能耗、烟尘 |
| 审核 | 喷雾塔、窑炉 |
| 方案筛选 | 天然气+余热回收 |
| 高费方案 | 脱硝除尘升级 |
| 实施验证 | 减排+节能 |
| 持续改进 | 智能窑炉 |

## 四、合规要点
1. 新建建筑陶瓷生产线应使用天然气。
2. 喷雾塔应配套高效脱硫除尘。
3. 窑炉应配套SNCR或SCR脱硝。
4. 废瓷砖、废泥料应全部回收。
