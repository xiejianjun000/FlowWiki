# 废铅蓄电池再生企业能耗限额

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 21250-2014 |
| 适用范围 | 能耗限额 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了废铅蓄电池再生企业的能耗限额要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 限额等级 | 1级、2级、3级 |
| 能耗限额 | 1级≤130，2级≤150，3级≤170kgce/t |
| 计算方法 | 按标准规定计算 |
| 节能要求 | 采用节能技术 |
| 监测要求 | 建立能耗监测系统 |

## 四、合规要点
1. 建立能耗监测系统
2. 能耗达到限额标准
3. 采用节能技术降低能耗
4. 定期核算能耗指标
