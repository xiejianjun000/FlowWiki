## 四、污染源解析

### 4.1 夜间PM2.5来源（00-06时）

**PM2.5/PM10=0.85**（凌晨高峰期）：
- >0.8 → **二次生成主导**
- 可能来源：燃煤+SO₂氧化 → 硫酸盐

**SO₂日变化**：
```
00:00 → 28.3 μg/m³ (高)
06:00 → 20.7 μg/m³ (降)
12:00 → 7.5 μg/m³ (低)
```

**推断**: 夜间燃煤排放 → SO₂高 → 凌晨边界层压低 → PM2.5二次生成积累

### 4.2 白天O₃来源（09-18时）

**VOCs来源**（强VOCs控制区）：
1. **工业源**：
   - 锡矿山锑业（有色金属冶炼，VOCs排放）
   - 冷水江钢铁（焦化、烧结工序）
   - 金竹山电厂（燃油/燃煤）
   
2. **天然源**：
   - 夏季高温 → 植被BVOCs释放（萜烯类）
   - 冷水江市周边森林覆盖率高

3. **生物质燃烧**：
   - PM2.5/PM10=0.68 → 不完全燃烧贡献

### 4.3 风向匹配

| 时间 | 风向 | 可能贡献源 |

## 六、管控建议

### 6.1 短期应急（今日下午）

| 时段 | 措施 |
|------|------|
| **13:00-17:00** | O₃峰值管控窗口 |
| **锡矿山锑业** | 暂停涉VOCs工序（冶炼、焙烧） |
| **冷钢** | 优化焦化工序，减少VOCs无组织排放 |
| **加油站** | 夜间装卸油（避开高温时段） |
| **柴油车** | 县城主干道限行 |

### 6.2 长期措施

1. **VOCs减排**
   - 建立本地源清单（锑冶炼、钢铁行业）
   - 安装VOCs在线监测
   
2. **氨减排**
   - 避免过度脱硝（Science研究：氨减排可降PM2.5达20-60%）

3. **区域联防**
   - 与邵阳市协同管控（可能的传输通道）
