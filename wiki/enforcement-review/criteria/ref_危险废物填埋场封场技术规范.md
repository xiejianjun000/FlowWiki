# 危险废物填埋场封场技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18598-2019第9章 |
| 适用范围 | 封场技术 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场封场的技术要求和程序。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 封场时机 | 达到设计标高或停止使用 |
| 封场程序 | 方案编制→审批→实施→验收 |
| 覆盖系统 | 多层结构（植被层+排水层+防渗层） |
| 稳定化要求 | 填埋体稳定后封场 |
| 验收要求 | 经生态环境部门验收合格 |

## 四、合规要点
1. 按规范编制封场方案
2. 封场覆盖系统符合设计要求
3. 封场后经验收合格
4. 封场后持续维护监测
