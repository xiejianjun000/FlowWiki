## HJ 693-2014 固定污染源废气 氮氧化物的测定 定电位电解法

### 一、标准基本信息

- **标准号**：HJ 693-2014
- **实施日期**：2014年12月1日

### 二、方法原理

NO通过渗透膜进入电解液，在恒电位工作电极上发生氧化反应，产生的极限扩散电流与NO浓度成正比。NO₂需转化为NO后测定。

### 三、适用范围

- 检出限：3 mg/m³
- 测定下限：10 mg/m³
- 测定上限：6200 mg/m³

适用于固定污染源废气中NOx测定。

### 四、干扰与消除

| 干扰物 | 干扰程度 | 消除方法 |
|--------|----------|----------|
| SO₂ | 正干扰 | SO₂过滤器 |
| NH₃ | 负干扰 | NH₃过滤器 |
| CO | 轻微干扰 | - |
| H₂O | 严重干扰 | 冷凝除湿 |

### 五、仪器设备

- 定电位电解仪
- NO₂转化炉
- 烟尘测试仪
- 标准气体

### 六、分析步骤

1. 仪器预热≥30分钟
2. 零点和量程校准
3. NO₂转化效率测试（≥95%）
4. 测定样品气体
5. 读数稳定后记录

### 七、结果计算

```
NOx = NO + NO₂
NO₂ = NO₂转化后读数 - 转化前读数
```

### 八、质量保证

- NO₂转化效率：≥95%
- 仪器漂移：≤±2%满量程/24h
- 平行样偏差：≤10%

### 九、对企业环保启示

1. NO₂转化效率是关键指标
2. 燃烧烟气NO以NO为主（95%）
3. 脱硝出口NO₂占比可能上升
