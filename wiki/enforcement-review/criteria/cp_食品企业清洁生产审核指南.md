# 食品企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国食品工业协会发〔2022〕8号 |
| 适用范围 | 焙烤、糖果、调味品、方便食品等制造企业 |
| 发布机关 | 中国食品工业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对食品企业特点，重点识别原料处理、加工、清洗、包装等关键工序清洁生产潜力。强调CIP原位清洗、节水节电、有机废渣饲料化或产沼。涵盖水耗、能耗、COD、油脂回收审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万元产值水耗、COD |
| 审核 | 加工、清洗工序 |
| 方案筛选 | CIP节水+废渣利用 |
| 高费方案 | 中水回用系统 |
| 实施验证 | 节水+减排 |
| 持续改进 | 包装轻量化 |

## 四、合规要点
1. 应采用CIP原位清洗节水工艺。
2. 有机废渣应饲料化或产沼利用。
3. 废油脂应回收作化工原料或生物柴油。
4. 排放废水应执行GB 8978排放标准。
