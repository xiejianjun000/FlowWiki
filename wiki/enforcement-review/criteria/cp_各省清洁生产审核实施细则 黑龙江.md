# 各省清洁生产审核实施细则 黑龙江

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 黑发改规〔2023〕4号 |
| 适用范围 | 黑龙江省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 黑龙江省发展和改革委员会、黑龙江省生态环境厅 |
| 实施日期 | 2023-08-01 |

## 二、主要内容
黑龙江省实施细则对接东北振兴和冰雪经济战略，重点推动装备制造、石油化工、煤炭、农林产品加工等传统产业清洁生产升级。强化松花江流域、大小兴安岭生态保护区审核要求。

## 三、清洁生产技术要求
| 阶段 | 黑龙江特色要求 |
|------|-------------|
| 名单确定 | 松花江流域+大小兴安岭 |
| 重点产业 | 装备、石化、煤炭、农产品加工 |
| 寒地特色 | 能源约束突出 |
| 东北振兴 | 政策资金支持 |
| 对俄合作 | 技术交流与互认 |

## 四、合规要点
1. 松花江流域企业审核应包含水污染物总量控制。
2. 石油化工企业审核应关注挥发性有机物管控。
3. 煤炭企业审核应包含矿井水综合利用。
4. 农林产品加工企业审核应突出资源化利用。
