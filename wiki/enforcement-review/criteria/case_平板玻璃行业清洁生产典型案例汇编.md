# 平板玻璃行业清洁生产典型案例汇编

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 文档类型 | 案例汇编 |
| 适用范围 | 浮法玻璃、压延玻璃制造企业 |
| 发布机关 | 生态环境部/工信部 |
| 编制时间 | 2023-2024 |

## 二、典型案例概览
1. 某玻璃厂熔窑余热发电案例
2. 某玻璃厂全氧燃烧技术案例
3. 某玻璃厂碎玻璃回收案例
4. 某玻璃厂脱硫脱硝案例

## 三、清洁生产方案效果
| 案例 | 投资额 | 节能效益 | 减排效果 |
|------|--------|----------|----------|
| 余热发电 | 3500万元 | 年发电4000万kWh | 减排CO₂3万吨 |
| 全氧燃烧 | 5000万元 | 能耗降15% | NOx减排70% |
| 碎玻璃回收 | 800万元 | 回收率≥90% | 减少原料消耗 |
| 脱硫脱硝 | 2500万元 | 脱硫率≥95% | SO₂减排90% |

## 四、合规启示
1. 熔窑余热发电可显著降低综合能耗。
2. 全氧燃烧技术可大幅降低NOx排放。
3. 碎玻璃回收率应不低于90%。
4. 脱硫脱硝是平板玻璃行业减排核心。
