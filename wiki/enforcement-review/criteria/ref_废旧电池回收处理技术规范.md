# 废旧电池回收处理技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 527-2010附录 |
| 适用范围 | 废旧电池回收处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废旧电池回收处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 各类废旧电池 |
| 处理工艺 | 分类处理+冶金回收 |
| 金属回收 | 铅、镍、钴、锂等 |
| 危险废物管理 | 按危废规范管理 |
| 污染防治 | 防止二次污染 |

## 四、合规要点
1. 电池分类处理回收金属
2. 危险废物按规范管理
3. 处理过程防止二次污染
4. 建立处理记录档案
