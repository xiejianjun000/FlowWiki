# 钢铁企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国钢铁工业协会发〔2022〕10号 |
| 适用范围 | 烧结、球团、焦化、炼铁、炼钢、轧钢联合企业 |
| 发布机关 | 中国钢铁工业协会 |
| 实施日期 | 2022-07-01 |

## 二、主要内容
本指南针对钢铁联合企业特点，重点识别烧结机、焦炉、高炉、转炉、轧机等关键设备清洁生产潜力。强调余热余能回收、煤气全回收、超低排放改造、水资源梯级利用。涵盖全流程能流、物流、水流分析。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨钢综合能耗、水耗 |
| 审核 | 烧结、焦化、高炉 |
| 方案筛选 | 余热回收+煤气回收 |
| 高费方案 | 超低排放改造 |
| 实施验证 | 节能+减排双效益 |
| 持续改进 | 智能化管控 |

## 四、合规要点
1. 烧结机应配套脱硫脱硝设施。
2. 焦炉应配套干熄焦装置。
3. 高炉煤气、转炉煤气应全部回收。
4. 吨钢综合能耗应达到HJ 465规定。
