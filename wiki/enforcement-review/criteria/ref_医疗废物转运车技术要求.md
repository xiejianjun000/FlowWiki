# 医疗废物转运车技术要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 26994-2011附录 |
| 适用范围 | 医疗废物转运车 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了医疗废物转运车的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 车辆类型 | 厢式冷藏货车 |
| 车厢材质 | 不锈钢或玻璃钢 |
| 温度控制 | ≤20°C |
| 密封性能 | 防渗漏、防散落 |
| 标识要求 | 医疗废物运输标识 |

## 四、合规要点
1. 使用符合标准的转运车
2. 车厢密封防渗漏
3. 控制运输温度
4. 车辆标识清晰
