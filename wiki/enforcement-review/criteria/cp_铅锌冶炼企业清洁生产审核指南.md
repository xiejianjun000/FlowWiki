# 铅锌冶炼企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国有色金属工业协会发〔2022〕12号 |
| 适用范围 | 粗铅、电解铅、湿法炼锌、火法炼锌企业 |
| 发布机关 | 中国有色金属工业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对铅锌冶炼企业特点，重点识别烧结焙烧、熔炼、电解等关键工序清洁生产潜力。强调富氧熔炼、SO₂制酸、含铅废渣综合利用、含汞烟尘处置。涵盖铅锌回收率、重金属减排审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨铅锌能耗、SO₂ |
| 审核 | 熔炼、电解工序 |
| 方案筛选 | 制酸+含汞烟尘 |
| 高费方案 | 富氧熔炼升级 |
| 实施验证 | 铅锌回收 |
| 持续改进 | 智能冶炼 |

## 四、合规要点
1. 应采用富氧底吹或基夫赛特工艺。
2. 烟气应配套制酸装置。
3. 含汞烟尘应专门收集处置。
4. 含铅、镉废水应深度处理回用。
