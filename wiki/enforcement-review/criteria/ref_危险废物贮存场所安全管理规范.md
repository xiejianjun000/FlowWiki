# 危险废物贮存场所安全管理规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18597-2023第7章 |
| 适用范围 | 贮存场所安全管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物贮存场所的防火、防爆、防毒等安全管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 防火要求 | 禁火、防爆电气、消防设施 |
| 防爆要求 | 易燃易爆废物单独存放 |
| 防毒要求 | 通风、防护用品、监测 |
| 动火作业 | 严格执行动火审批 |
| 培训要求 | 员工每年≥16小时安全培训 |

## 四、合规要点
1. 落实防火防爆防毒措施
2. 动火作业严格执行审批
3. 员工定期安全培训
4. 安全设施定期检查维护
