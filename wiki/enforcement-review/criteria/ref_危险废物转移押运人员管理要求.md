# 危险废物转移押运人员管理要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | JT/T 618-2004 |
| 适用范围 | 押运人员管理 |
| 发布机关 | 交通运输部 |

## 二、主要内容
规定了危险废物转移押运人员的资格、职责和管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 资格要求 | 持押运员证、危废培训合格 |
| 职责要求 | 全程押运、应急处理、记录 |
| 配备标准 | 每车至少1名押运员 |
| 培训要求 | 每年≥24小时培训 |
| 体检要求 | 每年职业健康体检 |

## 四、合规要点
1. 押运人员持证上岗
2. 全程押运履行职责
3. 定期培训和体检
4. 应急情况下及时处置
