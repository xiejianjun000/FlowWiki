# 危险废物贮存期限管理规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18597-2023第6.3条 |
| 适用范围 | 贮存期限管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物贮存期限及延期审批要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 贮存期限 | 原则上不超过1年 |
| 延期条件 | 特殊情况经批准可延长 |
| 延期审批 | 报省级生态环境部门批准 |
| 延期时限 | 延长不超过1年 |
| 延期材料 | 延期申请、原因说明、处置方案 |

## 四、合规要点
1. 严格控制贮存期限不超过1年
2. 需延期时提前申请审批
3. 建立贮存期限预警机制
4. 超期贮存及时处置或申请延期
