# 农药企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国农药工业协会发〔2022〕5号 |
| 适用范围 | 化学农药原药及制剂生产企业 |
| 发布机关 | 中国农药工业协会 |
| 实施日期 | 2022-06-15 |

## 二、主要内容
本指南针对农药企业特点，重点识别合成、分离、制剂等关键工序清洁生产潜力。强调溶剂回收、含盐废水资源化、VOCs全流程管控。涵盖反应工艺优化、设备改造、循环利用审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万元产值能耗、VOCs |
| 审核 | 反应釜、蒸馏塔 |
| 方案筛选 | 溶剂回收+含盐废水 |
| 高费方案 | 反应工艺优化 |
| 实施验证 | 收率+减排 |
| 持续改进 | 智能反应 |

## 四、合规要点
1. 溶剂应配套回收装置，回收率不低于75%。
2. 高浓度含盐废水应分质处理，盐资源化利用。
3. VOCs应执行GB 37824排放标准。
4. 农药废液、废包装应作为危险废物处置。
