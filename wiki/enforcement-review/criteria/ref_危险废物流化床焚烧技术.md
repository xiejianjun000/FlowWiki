# 危险废物流化床焚烧技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 176-2020第6.2条 |
| 适用范围 | 流化床焚烧技术 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物流化床焚烧的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 污泥、粉状废物 |
| 床层材料 | 石英砂 |
| 流化风速 | 3-5m/s |
| 焚烧温度 | 850-950°C |
| 优点 | 传热效率高、燃烧充分 |

## 四、合规要点
1. 流化床适用于污泥等废物
2. 控制流化风速保证燃烧
3. 定期补充床层材料
4. 利用其传热效率高的优势
