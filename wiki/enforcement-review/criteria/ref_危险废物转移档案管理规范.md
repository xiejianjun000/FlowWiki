# 危险废物转移档案管理规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1200-2021附录 |
| 适用范围 | 转移档案管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物转移档案的整理、保存和查询要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 档案内容 | 联单、合同、运输凭证、应急预案 |
| 整理要求 | 按转移批次整理归档 |
| 保存期限 | ≥10年 |
| 查阅权限 | 生态环境部门可随时查阅 |
| 电子档案 | 与纸质档案同步保存 |

## 四、合规要点
1. 按批次整理转移档案
2. 档案保存不少于10年
3. 电子档案与纸质档案同步
4. 档案管理便于查询追溯
