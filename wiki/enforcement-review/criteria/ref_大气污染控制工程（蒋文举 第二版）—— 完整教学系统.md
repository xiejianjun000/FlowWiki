## 全书知识体系

### 第一章 大气污染概述

**知识点：**
- 概念：大气污染（定义：由于人类活动或自然过程使某些物质进入大气，达到足够浓度和时间，危害人体健康或环境的现象）
- 分类：按污染源（工业源、交通源、生活源）、按污染物（一次/二次污染物）
- 主要污染物：TSP、PM10、PM2.5、SO2、NOx、CO、O3、VOCs
- 危害：人体健康（呼吸系统、心血管）、材料腐蚀、生态破坏、气候变化
- 控制策略：源头削减 → 过程控制 → 末端治理
- 中国大气环境标准体系：GB 3095-2012《环境空气质量标准》

**关键数据：**
- 中国SO2年排放量峰值约2500万吨（2006年），2020年降至约318万吨
- PM2.5年均浓度标准：一级15μg/m³，二级35μg/m³

**自测题：**
1. [选择题] 下列哪项属于二次污染物？A) SO2 B) PM10 C) O3 D) CO
2. [选择题] PM2.5 的二级标准年均浓度限值是？A) 15μg/m³ B) 35μg/m³ C) 75μg/m³ D) 150μg/m³
3. [选择题] 大气污染控制策略的正确顺序是？A) 末端治理→过程控制→源头削减 B) 源头削减→过程控制→末端治理 C) 过程控制→末端治理→源头削减
4. [计算题] 某燃煤电厂SO2排放浓度为800mg/m³，烟气量10万m³/h，计算年排放量（年运行7000h），并判断是否需要脱硫（排放标准200mg/m³）。

### 第二章 大气污染气象学

**知识点：**
- 大气结构：对流层(0-12km)、平流层(12-50km)、中间层、热层
- 气象要素：风向、风速、温度、湿度、大气稳定度
- 大气稳定度分类：Pasquill分类法（A:极不稳定 → F:稳定）
- 逆温层：辐射逆温、下沉逆温、锋面逆温
- 烟流形状与大气稳定度关系：波浪型(不稳定)、锥型(中性)、扇型(稳定)、熏烟型、屋脊型

**公式：**
- 高斯扩散模型（高架连续点源）：
  ```
  C(x,y,z) = Q/(2πuσyσz) · exp(-y²/2σy²) · [exp(-(z-H)²/2σz²) + exp(-(z+H)²/2σz²)]
  ```
  - C: 污染物浓度(mg/m³)
  - Q: 源强(mg/s)
  - u: 平均风速(m/s)
  - H: 有效源高(m) = 烟囱高度 + 烟气抬升高度
  - σy, σz: 水平和垂直扩散参数(m)

**数值例题：**
某烟囱高100m，SO2排放速率100g/s，风速4m/s，大气稳定度D级。计算下风向1000m处轴线地面浓度。
（σy=68m, σz=32m, 烟气抬升高度ΔH=20m, H=120m）

**自测题：**
1. [选择题] 对流层中温度随高度增加而降低的速率称为？A) 绝热率 B) 递减率 C) 扩散率 D) 沉降率
2. [选择题] 熏烟型扩散发生在什么条件下？A) 不稳定大气 B) 中性大气 C) 逆温层下 D) 强对流
3. [计算题] 某烟囱SO2排放速率80g/s，风速3m/s，D级稳定度，有效源高80m。求下风向500m处轴线地面浓度（σy=36m, σz=18m）。

### 第三章 大气污染化学

**知识点：**
- 光化学反应：NO2光解引发，生成O3等氧化剂
- 光化学烟雾形成机制：NOx + VOCs + 阳光 → O3 + PAN + 醛酮
- 酸雨形成：SO2 + OH· → H2SO4；NOx + OH· → HNO3
- 臭氧层破坏：CFCs → Cl·催化分解O3（一个Cl·可破坏10万个O3分子）
- 温室效应：CO2、CH4、N2O、CFCs的温室效应贡献

**自测题：**

### 第四章 颗粒物性质与测试

**知识点：**
- 粒径表示方法：空气动力学直径、斯托克斯直径
- 粒径分布：对数正态分布、Rosin-Rammler分布
- 粒径分布函数：频率分布、累积分布（筛上/筛下）
- 采样方法：滤膜称重法、β射线法、TEOM微量振荡天平法
- 排放标准：火电厂30mg/m³，钢铁行业特殊排放限值10mg/m³

**公式：**
- 对数正态分布概率密度函数：
  ```
  f(dp) = 1/(√(2π) · dp · lnσg) · exp(-(ln dp - ln dg)²/(2 ln²σg))
  ```
  - dg: 几何平均直径
  - σg: 几何标准差

**自测题：**
1. [选择题] 空气动力学直径相同的颗粒物，具有相同的？A) 质量和密度 B) 沉降速度 C) 比表面积 D) 光学性质
2. [计算题] 某粉尘的粒径分布服从对数正态分布，dg=10μm，σg=2.0。求粒径1μm）、扩散荷电（10¹¹Ω·cm)导致的问题
- 烟气调质：SO3、NH3、水分调质改善粉尘比电阻

**公式：**
- Deutsch-Anderson公式：
  ```
  η = 1 - exp(-A·ωe/Q)
  ```
  - A: 集尘面积(m²), Q: 烟气量(m³/s), ωe: 有效驱进速度(m/s)
- 多依奇公式的修正（Matts-Ohnfeldt）：
  ```
  η = 1 - exp(-(A·ωk/Q)^k)
  ```
  - k: 经验指数(0.4-0.7)

**数值例题：**
某电除尘器处理烟气量100m³/s，集尘面积5000m²，有效驱进速度0.1m/s。
计算除尘效率。若要求效率提高到99.9%，需要多少集尘面积？

**自测题：**
1. [选择题] 反电晕现象通常发生在粉尘比电阻大于多少时？A) 10⁸Ω·cm B) 10¹⁰Ω·cm C) 10¹¹Ω·cm D) 10¹³Ω·cm
2. [计算题] 某电除尘器集尘面积3000m²，烟气量80m³/s，ωe=0.08m/s。求除尘效率。若想达到99.5%，需增加多少面积？

### 第八章 湿式除尘技术

**知识点：**
- 洗涤机理：惯性碰撞、截留、扩散、凝并
- 文丘里洗涤器：喉管气速50-100m/s，压降2000-10000Pa
- 喷淋塔：空塔气速0.6-1.5m/s，液气比0.5-3L/m³
- 废水处理：湿式除尘伴生的废水处理问题

**公式：**
- Calvert切割粒径公式（文丘里）：
  ```
  dp50 = 1.17 × 10⁻³ · √(μ·d·f/(ρp·vg))
  ```
  - d: 液滴直径, f: 经验系数, vg: 喉管气速

**自测题：**
1. [选择题] 文丘里洗涤器喉管气速通常为？A) 5-10m/s B) 20-30m/s C) 50-100m/s D) 200-300m/s
2. [计算题] 某文丘里洗涤器喉管气速80m/s，液滴直径100μm，粉尘密度2000kg/m³。估算dp50。

### 第九章 吸收法净化技术

**知识点：**
- 气液吸收原理：双膜理论、亨利定律、传质速率方程
- 吸收剂选择：石灰石/石灰（脱硫）、NaOH（脱酸）、氨水（脱硝）
- 填料塔设计：塔径、塔高、填料选择、压降计算
- 石灰石-石膏湿法脱硫（FGD）：CaCO₃ + SO₂ → CaSO₃ → CaSO₄·2H₂O

**公式：**
- 亨利定律：p* = H·x
- 传质速率：NA = KG·(p - p*) = KL·(c* - c)
- 填料塔高度（传质单元法）：
  ```
  Z = HOG · NOG = (G/(KG·a·P)) · ∫(dy/(y-y*))
  ```

**数值例题：**
某填料塔用清水吸收SO₂，进气SO₂浓度2000ppm，要求出口浓度200ppm，气体流量10000m³/h。
计算：最小液气比（亨利系数H=50atm）和实际液气比（取1.5倍最小液气比）。

**自测题：**
1. [选择题] 湿法脱硫（FGD）的主要副产物是？A) CaO B) CaSO₄·2H₂O C) CaCO₃ D) Ca(OH)₂
2. [计算题] 某吸收塔进气SO₂浓度1500ppm，出口要求150ppm，气体流量8000m³/h，亨利系数H=45atm。求最小液气比。

### 第十章 吸附法净化技术

**知识点：**
- 吸附类型：物理吸附（范德华力）、化学吸附（化学键）
- 吸附等温线：Langmuir、Freundlich、BET
- 常用吸附剂：活性炭（比表面积500-1500m²/g）、沸石、硅胶
- 固定床吸附器设计：穿透曲线、传质区长度、床层压降
- 再生技术：热再生、蒸汽再生、真空再生

**公式：**
- Langmuir等温式：
  ```
  q = qm·b·P/(1 + b·P)
  ```
  - q: 吸附量, qm: 单层饱和吸附量, b: 吸附常数

- 穿透时间（Wheeler方程）：
  ```
  t = (W·qm/(Q·C0)) - (ρb·qm/(kv·C0))·ln((C0-C)/C)
  ```

**数值例题：**
某活性炭固定床吸附VOCs，床层高度0.5m，截面积0.5m²，活性炭装填量125kg。
进气浓度500mg/m³，流量1000m³/h，吸附容量0.25kg/kg。
计算：理论穿透时间和实际运行周期。

**自测题：**
1. [选择题] 活性炭的主要吸附机理是？A) 化学吸附 B) 物理吸附 C) 离子交换 D) 螯合作用
2. [计算题] 某固定床装填活性炭200kg，吸附容量0.2kg/kg，进气浓度800mg/m³，流量2000m³/h。求理论穿透时间。

### 第十一章 催化转化技术

**知识点：**
- 催化原理：降低活化能，不改变平衡
- SCR脱硝：4NH₃ + 4NO + O₂ → 4N₂ + 6H₂O（V₂O₅-WO₃/TiO₂催化剂）
- VOCs催化燃烧：VOCs + O₂ → CO₂ + H₂O（Pt/Pd催化剂）
- 催化剂失活：烧结、中毒、堵塞、磨损
- 空速(SV)：体积空速 = Q/Vcat（通常3000-10000h⁻¹）

**公式：**
- 催化反应速率（幂律式）：
  ```
  r = k·Cn = A·exp(-Ea/RT)·Cn
  ```
- 催化床层压降（Ergun方程）：
  ```
  ΔP/L = 150·μ·(1-ε)²·u/(dp²·ε³) + 1.75·ρ·(1-ε)·u²/(dp·ε³)
  ```

**数值例题：**
某SCR脱硝反应器处理烟气量50万m³/h，NOx浓度400mg/m³，要求脱硝效率90%。
催化剂体积空速5000h⁻¹，氨氮摩尔比1.05。
计算：催化剂体积、氨耗量（25%氨水）。

**自测题：**
1. [选择题] SCR脱硝的典型反应温度窗口是？A) 150-200℃ B) 300-400℃ C) 500-600℃ D) 700-800℃
2. [计算题] 某VOCs催化燃烧装置，处理风量30000m³/h，空速8000h⁻¹。求催化剂装填量。

### 第十二章 燃烧净化技术

**知识点：**
- 直接燃烧（TO）：温度700-800℃，停留时间0.5-1s，去除率>99%
- 催化燃烧（CO）：温度250-400℃，贵金属催化剂
- 蓄热式燃烧（RTO）：热回收率>95%，切换阀控制
- 燃烧三要素：温度(3T) + 停留时间 + 湍流度
- 热力型NOx：温度>1300℃时N₂+O₂→NO

**公式：**
- 燃烧温度估算：
  ```
  T = T0 + ΔHc·C/(ρ·Cp)
  ```
  - ΔHc: 燃烧热, C: 可燃物浓度

**自测题：**
1. [选择题] RTO的热回收效率通常可达？A) 50-60% B) 70-80% C) 95%以上 D) 100%
2. [计算题] 某RTO处理VOCs浓度2000mg/m³（以甲苯计，热值40MJ/kg），风量20000m³/h。估算自热运行所需的最低VOCs浓度。
