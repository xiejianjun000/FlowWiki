# 危险废物氧化还原处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014第6.2条 |
| 适用范围 | 氧化还原处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物氧化还原处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 含氰废物、含硫废物 |
| 氧化剂 | 次氯酸钠、双氧水、臭氧 |
| 还原剂 | 亚硫酸钠、硫酸亚铁 |
| 反应条件 | 温度、pH、时间控制 |
| 排放控制 | 出水达标排放 |

## 四、合规要点
1. 根据废物特性选择药剂
2. 严格控制反应条件
3. 处理后出水达标排放
4. 记录反应过程参数
