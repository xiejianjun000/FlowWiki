# 危险废物填埋污染控制标准

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18598-2019 |
| 适用范围 | 危险废物填埋污染控制 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场的选址、设计、运行、封场和监测要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 选址要求 | 远离敏感区域，地质条件稳定 |
| 防渗要求 | 双层人工合成材料防渗 |
| 入场要求 | 需经稳定化固化预处理 |
| 监测要求 | 地下水、土壤、大气定期监测 |
| 封场要求 | 封场覆盖系统+长期维护 |

## 四、合规要点
1. 填埋场符合选址和防渗要求
2. 废物入场前进行稳定化预处理
3. 定期开展环境监测
4. 封场后持续维护30年
