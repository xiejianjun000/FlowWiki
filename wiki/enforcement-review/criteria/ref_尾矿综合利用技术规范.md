# 尾矿综合利用技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 39489-2020 |
| 适用范围 | 矿山尾矿的综合利用 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了尾矿在建材、充填、土地复垦等领域利用的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 利用前处理 | 分级、脱水、有害组分去除 |
| 利用途径 | 尾矿充填、建材原料、土地复垦 |
| 有害物质限值 | 符合GB 5085鉴别标准 |
| 放射性 | 符合GB 6566要求 |
| 环境监测 | 利用场地定期监测 |

## 四、合规要点
1. 尾矿利用前进行安全评估
2. 防止尾矿中重金属污染环境
3. 建立尾矿利用台账
4. 利用场地定期开展环境监测
