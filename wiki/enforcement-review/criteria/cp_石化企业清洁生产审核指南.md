# 石化企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国石油和化学工业联合会发〔2022〕16号 |
| 适用范围 | 石油炼制、石油化工、合成树脂等企业 |
| 发布机关 | 中国石油和化学工业联合会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对石化企业特点，重点识别常减压、催化裂化、加氢精制、催化重整等装置清洁生产潜力。强调加氢工艺、酸性气回收制硫、VOCs全流程管控、含油污泥处置。涵盖能流、物流、污染物产生分析。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨原油能耗、VOCs |
| 审核 | 催化裂化、加氢重点 |
| 方案筛选 | 硫回收+VOCs管控 |
| 高费方案 | 加氢工艺升级 |
| 实施验证 | 节能+减排 |
| 持续改进 | 智慧炼化 |

## 四、合规要点
1. 应配套酸性气硫磺回收装置。
2. VOCs应执行GB 31570排放标准。
3. 含油污泥应作为危险废物处置。
4. 火炬气应全部回收利用。
