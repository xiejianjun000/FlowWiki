# 一般工业固废转移管理办法

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 部令第23号 |
| 适用范围 | 一般工业固废跨省转移管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规范了一般工业固废转移活动，明确跨省转移备案程序和省内转移管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 省内转移 | 通过信息系统备案 |
| 跨省转移 | 向移出地省级生态环境部门备案 |
| 备案材料 | 转移计划、接受单位资质、运输协议 |
| 运输要求 | 防止扬散、流失、渗漏 |
| 接受单位 | 具备相应利用处置能力 |

## 四、合规要点
1. 转移前核实接受单位资质和能力
2. 通过全国固废信息系统完成备案
3. 运输过程采取防撒漏措施
4. 保留转移联单和运输凭证
