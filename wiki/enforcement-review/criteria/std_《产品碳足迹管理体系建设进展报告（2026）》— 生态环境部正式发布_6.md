## 三、出口企业面临的三重压力

> 产品碳足迹管理体系建设正在加速推进。出口企业面临前所未有的碳足迹压力。**提前布局不是选择题，而是必答题**。

### 3.1 第一重压力：欧盟碳边境调节机制（CBAM）实质征收

> 出口钢铁、铝、水泥、化肥、氢气等产品到欧盟的企业，要**提供产品碳足迹数据**。
> 没有数据，**适用默认值**，**碳关税成本更高**。

**影响范围**：钢铁 / 铝 / 水泥 / 化肥 / 氢气等基础工业品

### 3.2 第二重压力：国际客户的供应链要求

> 跨国企业纷纷要求供应商**披露产品碳足迹**，将**碳表现纳入供应商评估**。
> 碳排放高的产品可能在**供应链竞争中出局**。

**核心变化**：
- 从"偶尔索要材料" → "**常态化、标准化审核**"
- 从"加分项" → "**供应链准入的通用必备材料**"

### 3.3 第三重压力：碳足迹认证成为市场准入条件

> 部分国际市场要求产品获得碳足迹认证，没有认证可能**无法进入某些市场或享受关税优惠**。

**重点审核材料**：
- 产品碳足迹填报
- 原辅材料能耗明细
- 绿电使用证明
- 第三方核查报告

## 五、出口企业布局的 4 步法

> 面对碳足迹压力，出口企业要从 4 个步骤提前布局。

### 步骤 1：开展产品碳足迹核算

- 按照相关标准对出口产品进行碳足迹核算
- 掌握产品全生命周期的碳排放情况
- 核算范围：原材料获取 / 生产制造 / 运输配送等环节
- **核算方法要规范，数据要可靠**

### 步骤 2：建立产品碳足迹数据库

- 将核算数据纳入数据库管理
- 实现数据的存储、查询、更新
- **支撑产品碳足迹的持续核算和对外披露**

### 步骤 3：优化产品碳足迹

**5 大减排措施**：

| 措施 | 价值 |
| --- | --- |
| 原材料替代 | 降低上游碳足迹 |
| 工艺优化 | 提升能效 |
| 能源结构调整 | 绿电替代 |
| 运输方式改进 | 低碳物流 |
| 循环利用 | 减少原料投入 |

### 步骤 4：开展产品碳足迹认证

- 委托**第三方机构**进行核查认证
- 获得**权威证明**
- 增强碳足迹数据的可信度
- 满足客户和监管要求

## 六、企业核心抓手：5 项基础工作

> 建议企业优先落地五项基础工作：

1. **梳理核心产品**：聚焦出口占比高、客户关注度高、能耗强度大的产品，建立**重点管理清单**
2. **明确核算边界**：清晰界定各环节核算范围，**从源头规避争议**
3. **夯实活动数据**：常态化归集原辅材料消耗、能源耗用、产品批次产量、物流方式与运距等**核心数据**
4. **建立因子台账**：对所有使用的排放因子**逐一登记**，**确保口径延续性**
5. **完善证据链条**：整合采购凭证、计量台账、能源账单、生产报表等佐证材料，确保数据**可溯源、可核验**

> 产品碳足迹核算涉及大量数据，数据管理是布局的关键环节。

| 要素 | 关键点 |
| --- | --- |
| **能源消耗数据** | 电力 / 燃气 / 蒸汽等能源消耗量要准确计量 |
| **物料消耗数据** | 原材料 / 辅助材料的消耗量要统计完整 |
| **生产数据** | 产品产量 / 良品率 / 生产时间等数据要记录准确 |
| **运输数据** | 原材料和产品的运输距离 / 运输方式要记录完整 |
| **数字化工具** | AI+能碳管理平台可帮助企业建立数据库，实现统一管理 |

## 八、供应链碳数据：企业的核心难点

> 产品碳足迹核算的难点在于**供应链碳数据**。原材料碳足迹数据要从上游供应商获取，协调难度大。

### 8.1 解决路径

| 步骤 | 内容 |
| --- | --- |
| 1 | **推动供应商开展碳管理** |

| 3 | **建立碳数据收集机制** |
| 4 | **优先从主要供应商、关键原材料入手** |
| 5 | 逐步扩展到**全部供应商和原材料** |

### 8.2 时间规划

| 阶段 | 时间 | 工作 |
| --- | --- | --- |
| **短期** | 3-6 个月 | 完成主要产品的碳足迹核算，建立初步的数据库 |
| **中期** | 6-12 个月 | 完善数据管理体系，推进供应链碳数据收集，实施产品低碳化改进 |
| **长期** | 持续 | 持续更新碳足迹数据，开展碳足迹认证，支撑市场拓展和合规要求 |

## 九、碳足迹管理范式转变

### 9.1 从"应急"到"合规"

> 过去，国内企业开展产品碳足迹核算多为**被动响应**：
> - 满足海外客户供应链审核
> - 申报绿色工厂或零碳工厂资质
> - 应对 CBAM 及 ESG 信息披露
>
> 这种**阶段性应急模式**存在明显漏洞：产品核算边界模糊、原材料数据残缺、能耗分摊规则不统一、排放因子来源杂乱。
> 一旦遭遇复核或抽查，企业常面临**数据无法溯源的被动局面**。

> 碳足迹数据库的落地释放明确信号：**产品碳足迹管理不再是一次性材料编制**，而需建立**统一、可比、可追溯的常态化数据体系**。

### 9.2 从"粗放"到"规范"

> **排放因子是碳足迹核算结果公允性的核心变量**。
> 此前多数企业依赖咨询机构经验或网络零散资料，因子选取缺乏合规依据，公信力不足。
> 数据库上线后，行业因子选取将形成**统一参照标准**，**粗放式套用因子的空间大幅压缩**。

**核心要求**：
- 因子来源可溯源
- 适用边界可解释
- 版本更新有记录
- 从根源上规避核查争议

### 9.3 从"宣传"到"对标"

> 数据库的另一核心价值是搭建**行业可比的低碳评价基准**。
> 以往企业展示低碳竞争力多依托节能改造、绿电替代等**定性描述**，缺乏产品维度的量化对标。
> 随着数据库完善，同类产品碳排放水平、核心排放工序、能源结构影响等指标将实现**标准化对标**。

**下游客户筛选逻辑转变**：
- 从"是否具备碳足迹报告" → "**碳排放水平优劣、行业排名层级**"的深度考核

## 十一、CBAM 详细影响分析

### 11.1 首批纳入产品

| 产品类别 | 涉及行业 |
| --- | --- |
| **钢铁** | 长流程 / 短流程钢铁 |
| **铝** | 电解铝 / 再生铝 |
| **水泥** | 熟料 / 水泥 |
| **化肥** | 氮肥 / 磷肥 |
| **氢气** | 灰氢 / 蓝氢 / 绿氢 |

### 11.2 企业应对建议

| 步骤 | 内容 |
| --- | --- |
| **数据采集** | 采集产品全生命周期碳排放数据 |
| **第三方核查** | 委托 CBAM 认可的核查机构出具报告 |
| **CBAM 注册** | 在欧盟 CBAM 注册系统注册 |
| **申报** | 按时提交 CBAM 申报表 |
| **购买 CBAM 证书** | 支付碳关税成本 |

### 11.3 默认值风险

> 没有数据，**适用默认值**，**碳关税成本更高**。
> 默认值通常**显著高于实际值**，所以企业应**主动核算 + 第三方核查**，避免被高估。

## 十二、对国内企业的 5 大影响

### 12.1 政策合规成本上升

- 碳足迹核算 + 认证成本
- 因子数据库使用费（可能）
- 第三方核查费用

### 12.2 供应链传导压力

- 上游供应商需要提供碳数据
- 推动全产业链碳管理
- 中小企业受冲击更大

### 12.3 国际市场准入

- CBAM 强制要求
- 跨国客户供应链要求
- 绿色贸易壁垒

### 12.4 行业竞争格局

- 低碳产品获得竞争优势
- 高碳产品逐步淘汰
- 行业集中度可能提升

### 12.5 ESG 评级

- 碳足迹是 ESG 评级核心指标
- 影响企业融资能力
- 影响企业品牌价值

## 十三、行动清单

### 选项 A：企业立即行动

1. **建立碳足迹管理团队**（生产 + 质量 + 采购 + 外贸多部门协同）
2. **开展核心产品碳足迹核算**（3-6 个月）
3. **建立产品碳足迹数据库**（数字化平台）
4. **推动供应商碳数据收集**（从主要供应商开始）
5. **开展碳足迹认证**（第三方核查）
6. **应对 CBAM 注册和申报**

### 选项 B：地方政府行动

1. **建设地方碳足迹因子数据库**（区域特色）
2. **推动企业取得碳足迹认证**（粤港澳大湾区模式）
3. **将碳足迹纳入出口支持政策**（深圳模式）
4. **建立行业碳排放基准**（差异化监管）
5. **培育第三方核查机构**（专业服务生态）

### 选项 C：行业协会行动

1. **制定行业碳足迹核算指南**（结合行业特点）
2. **建立行业因子数据库**（与国家库互补）
3. **开展行业碳足迹对标**（基准 + 排名）
4. **组织碳足迹培训**（中小企业赋能）
5. **推动国际互认**（行业协会层面）

### 选项 D：消费者参与

1. **关注产品碳标签**（选购低碳产品）
2. **了解产品碳足迹**（查询国家数据库）
3. **倡导低碳消费**（影响企业行为）
4. **参与碳普惠**（个人减排激励）
