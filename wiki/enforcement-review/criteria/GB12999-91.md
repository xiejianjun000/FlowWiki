# GB12999-91 标准名称：HJ 493-2009 水质采样 样品的保存和管理技术规定

> 原始文件：raw/standards/done_标准_HJ_493-2009_水质采样样品的保存和管理技术规定.txt

适用范围

  本标准规定了水样从容器的准备到添加保护剂等各环节的保存措施，以及样品的标签
  设计、运输、接收和保证样品保存质量的通用技术。

  适用于：天然水、生活污水及工业废水。

  当所采集的水样（瞬时样或混合样）不能立即在现场分析，必须送往实验室测试时，
  本标准所提供的样品保存技术与管理程序均适用。


## 核心限值
- 测COD用H₂SO₄酸化至pH≤2
│  9   │ 化学需氧量(COD)    │ G      │ 用H₂SO₄酸化，pH≤2              │ 2d       │ 500mL     │
│ 12   │ TOC                │ G      │ 用H₂SO₄酸化pH≤2，1~5℃          │ 7d       │ 250mL     │
│ 14   │ 总磷               │ P或G   │ 用H₂SO₄或HCl酸化，pH≤2         │ 24h      │ 250mL     │
│ 15   │ 氨氮               │ P或G   │ 用H₂SO₄酸化，pH≤2              │ 24h      │ 250mL     │
│       │ 镍、铁、锰、     │        │ (pH≤2)                          │          │           │
│ 28   │ 二价铁             │ P酸洗  │ 用HCl酸化至pH≤2，避免接触空气   │ 7d       │ 100mL     │
│ 33   │ 石油类/油类        │ 溶剂洗G│ 用HCl酸化至pH≤2                 │ 7d       │ 250mL     │
（每125mL容器加入0.1mL的10mg/L Na₂S₂O₃）
- 保存方法：用 HNO₃ 酸化至 pH≤2
