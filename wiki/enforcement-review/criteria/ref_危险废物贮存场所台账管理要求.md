# 危险废物贮存场所台账管理要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18597-2023第8章 |
| 适用范围 | 贮存场所台账管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物贮存场所台账的记录、保存和报送要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 记录内容 | 入库、出库、库存信息 |
| 记录要素 | 废物名称、代码、数量、日期、经办人 |
| 保存期限 | ≥5年 |
| 数据报送 | 对接全国固废信息系统 |
| 盘点要求 | 每月盘点，账实相符 |

## 四、合规要点
1. 建立规范的贮存台账
2. 记录入库出库全过程信息
3. 每月盘点确保账实相符
4. 台账数据及时报送信息系统
