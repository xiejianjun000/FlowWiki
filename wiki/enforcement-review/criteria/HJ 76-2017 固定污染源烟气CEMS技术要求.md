## HJ 76-2017 固定污染源烟气排放连续监测系统技术要求

### 一、标准基本信息

- **标准号**：HJ 76-2017
- **替代标准**：HJ/T 76-2007
- **实施日期**：2018年3月1日

### 二、适用范围

适用于CEMS的设计、生产、出厂检测和选型使用。

### 三、技术要求

#### 3.1 颗粒物CEMS

| 指标 | 要求 |
|------|------|
| 测量范围 | 0-50至0-10000 mg/m³ |
| 示值误差 | ≤±2%满量程 |
| 响应时间 | ≤60s |
| 零点漂移 | ≤±2%满量程/24h |
| 量程漂移 | ≤±2%满量程/24h |

#### 3.2 气态污染物CEMS

| 指标 | SO₂ | NOx |
|------|-----|-----|
| 测量范围 | 0-250至0-5000 mg/m³ | 0-250至0-5000 mg/m³ |
| 示值误差 | ≤±2%满量程 | ≤±2%满量程 |
| 响应时间 | ≤200s | ≤200s |
| 零点漂移 | ≤±2.5%/24h | ≤±2.5%/24h |
| 量程漂移 | ≤±2.5%/24h | ≤±2.5%/24h |

### 四、分析方法

- 颗粒物：激光后向散射法、β射线法
- SO₂：非分散红外法、紫外差分吸收法
- NOx：非分散红外法、紫外差分吸收法、化学发光法

### 五、数据采集与处理

- 数据采集频率：≥1次/分钟
- 数据存储：现场存储≥6个月
- 远程传输：与生态环境部门联网

### 六、对企业合规启示

1. 选择合格CEMS设备
2. 确保数据采集传输合规
3. 配备合格运维人员
