# 危险废物急性毒性鉴别试验方法

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 5085.2附录 |
| 适用范围 | 急性毒性鉴别试验方法 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了急性毒性鉴别的试验动物、剂量、观察指标和判定。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 试验动物 | 小鼠（18-22g）或大鼠（180-220g） |
| 给药途径 | 经口、经皮、吸入 |
| 观察周期 | 14天 |
| 判定指标 | LD₅₀/LC₅₀ |
| 试验要求 | 符合GLP规范 |

## 四、合规要点
1. 试验在GLP实验室开展
2. 试验过程符合动物伦理
3. 数据记录完整可追溯
4. 试验报告经审核后出具
