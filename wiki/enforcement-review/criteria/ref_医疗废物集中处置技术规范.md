# 医疗废物集中处置技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ/T 177-2005 |
| 适用范围 | 医疗废物集中处置 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了医疗废物集中处置单位的技术要求和管理。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 处置方式 | 高温焚烧为主 |
| 处理能力 | 满足服务区域需求 |
| 收集范围 | 覆盖本行政区域 |
| 运行管理 | 持证经营、规范运行 |
| 排放控制 | 符合GB 18484 |

## 四、合规要点
1. 处置单位持证规范经营
2. 处置能力满足服务需求
3. 排放符合国家标准
4. 运行管理规范有序
