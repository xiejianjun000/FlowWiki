# 一般工业固体废物贮存和填埋污染控制标准

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18599-2020 |
| 适用范围 | 一般工业固体废物的贮存、填埋场建设、运行、封场及污染控制 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了一般工业固体废物贮存场、填埋场的选址、设计、运行、封场和监测要求，按I类和II类场地分类管理。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| I类场适用 | 第I类一般工业固废 |
| II类场适用 | 第II类一般工业固废 |
| 防渗要求 | 天然基础层≥0.75m且K≤1.0×10⁻⁵cm/s |
| 渗滤液排放 | 符合GB 8978或地方标准 |
| 监测井布设 | 地下水流向上游1个、下游至少3个 |

## 四、合规要点
1. 严格按照固废分类确定场型（I类/II类）
2. 建立完善的防渗系统和渗滤液收集系统
3. 定期开展地下水和渗滤液监测并记录台账
4. 封场后持续维护30年以上
