# 焦化企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国炼焦行业协会发〔2022〕7号 |
| 适用范围 | 常规焦炉、热回收焦炉、半焦（兰炭）生产企业 |
| 发布机关 | 中国炼焦行业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对焦化企业特点，重点识别备煤、炼焦、化产回收等关键工序清洁生产潜力。强调干熄焦、煤气净化回收、焦化废水深度处理回用。涵盖余热回收、煤气回收、废水回用审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨焦能耗、水耗 |
| 审核 | 焦炉、化产回收 |
| 方案筛选 | 干熄焦+煤气回收 |
| 高费方案 | 废水深度处理 |
| 实施验证 | 节能+减排 |
| 持续改进 | 智能焦化 |

## 四、合规要点
1. 焦炉应配套干熄焦装置。
2. 焦炉煤气应全部回收利用。
3. 焦化废水应深度处理回用。
4. 排放污染物应执行GB 16171排放标准。
