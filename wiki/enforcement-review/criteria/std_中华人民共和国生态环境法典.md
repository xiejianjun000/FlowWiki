# 中华人民共和国生态环境法典

> 以习近平生态文明思想为引领的生态环境领域基础性、综合性法典，2026年编纂出台，整合10部现行生态环境法律。

## 法典概述

生态环境法典编纂采取"适度法典化"模式，分三类情况处理：

### 第一类：全部纳入（10部法律，法典出台后不再保留）

| 法律名称 | 说明 |
|---------|------|
| 环境保护法 | 环境领域基础法 |
| 环境影响评价法 | 环评制度法律依据 |
| 清洁生产促进法 | 清洁生产促进 |
| 海洋环境保护法 | 海洋污染防治 |
| 大气污染防治法 | 大气环境管理 |
| 水污染防治法 | 水环境管理 |
| 土壤污染防治法 | 土壤环境管理 |
| 固体废物污染环境防治法 | 固废管理 |
| 噪声污染防治法 | 噪声管理 |
| 放射性污染防治法 | 辐射安全 |

### 第二类：择要纳入（现行法律继续保留）

森林法、草原法、湿地保护法、海岛保护法、国家公园法、长江保护法、黄河保护法、青藏高原生态保护法、循环经济促进法、能源法、节约能源法等继续保留，法典作出协调性、开放性规定。

### 第三类：原则性引领

应对气候变化、碳达峰碳中和、绿色低碳发展等方面尚未制定专门法律，法典就此作出原则性、引领性规定，为今后法律制度建设确定原则、奠定基础、留有空间。

### 法典结构

生态环境法典共**5编1242条**，附新旧与关联对照，便于法律适用衔接。

#### 第一编：总则（9章147条）

基本规定（立法目的、基本原则、公众参与等，含全国生态日规定）→ 监督管理（体制、机制、督察、考核、河湖长制等）→ 规划和生态环境分区管控（生态保护红线、分区管控）→ 标准和监测（标准体系、基准、监测制度）→ 生态环境影响评价（环评、温室气体纳入环评）→ 生态保护补偿（财政纵向、地区横向、市场机制）→ 突发生态环境事件应对（监测预警、应急联动）→ 保障措施（财税、金融、产业等）→ 信息公开与公众参与

**重要修改**：将温室气体排放纳入生态环境影响评价管理（第82条）；强化环评技术单位责任与备案管理制度（第99条）；明确环评不予批准的法定情形（第105条）；增加建设项目运行中落实环保措施的法定要求（第108条）。不再保留现行《环境保护法》关于"每年6月5日为环境日"的规定。

#### 第二编：污染防治

整合现行大气、水、土壤、固废、噪声、放射性污染防治法和海洋环境保护法中污染防治规定，构建"蓝天、碧水、净土"三大攻坚战框架，增加化学物质、电磁辐射、光等新领域污染防治制度。

#### 第三编：生态保护

涵盖生态系统保护、生物多样性保护、自然保护区管理等内容，与森林法、草原法、湿地保护法等继续保留的法律协调适用。

#### 第四编：绿色低碳发展

对应对气候变化、碳达峰碳中和、绿色低碳发展等作出原则性、引领性规定，为后续专门立法奠定基础。

#### 第五编：法律责任和附则

系统整合归并10部法律的罚则规定，统一处罚标准和执法程序。

## 知识价值

生态环境法典是中国环境法律体系的里程碑，对以下领域具有基础性参考价值：

1. **环保执法** — 法典条款是执法活动的最高法律依据
2. **环评审查** — 环评制度在法典中的定位和调整
3. **排污许可** — 排污许可制度的法典化
4. **生态保护** — 生态保护红线的法律地位
