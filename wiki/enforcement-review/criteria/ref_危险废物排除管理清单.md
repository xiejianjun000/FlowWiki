# 危险废物排除管理清单

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 部令第23号附录 |
| 适用范围 | 危险废物排除管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了不按危险废物管理的废物清单和条件。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 排除条件 | 经鉴别不具有危险特性 |
| 清单内容 | 特定行业特定废物 |
| 排除程序 | 鉴别→申请→审核→公告 |
| 管理要求 | 排除后按一般工业固废管理 |
| 动态更新 | 根据鉴别结果定期调整 |

## 四、合规要点
1. 经鉴别后方可申请排除管理
2. 排除后按一般固废规范管理
3. 保留鉴别和排除证明材料
4. 排除清单变化时及时调整管理
