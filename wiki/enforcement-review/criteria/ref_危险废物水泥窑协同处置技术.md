# 危险废物水泥窑协同处置技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 662-2013 |
| 适用范围 | 水泥窑协同处置 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物水泥窑协同处置的技术要求和管理。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 有机溶剂、废液、污泥等 |
| 处置温度 | ≥1450°C |
| 烟气停留时间 | ≥6秒 |
| 投加位置 | 窑头、分解炉、窑尾 |
| 限值控制 | 水泥产品有害物质限值 |

## 四、合规要点
1. 水泥窑协同处置高温高效
2. 控制投加比例和位置
3. 水泥产品符合有害物质限值
4. 监测烟气排放达标
