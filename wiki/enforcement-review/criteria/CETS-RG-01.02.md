# CETS-RG-01.02 区域温室气体排放核算与报告指南 数据质量控制规范

## 标准概述
- **文件编号**：CETS—RG—01.02—V01—2024
- **标准名称**：区域温室气体排放核算与报告指南 数据质量控制规范
- **发布机关**：生态环境部
- **实施日期**：2024-04-01
- **适用范围**：省、市、县级行政区域温室气体排放核算的数据质量管理工作

## 数据质量维度
| 维度 | 要求 |
|------|------|
| 准确性 | 数据应尽可能接近真实值，减少偏差 |
| 完整性 | 覆盖所有排放源和吸收汇，避免遗漏 |
| 一致性 | 同一区域的时间序列数据应使用一致方法 |
| 可比性 | 不同区域间应采用可比的核算方法 |
| 代表性 | 数据应能代表所描述的地理区域和时间段 |
| 及时性 | 数据应及时更新，反映最新情况 |
| 透明性 | 数据来源、方法、假设应完整记录 |

## 数据质量管理体系
- **QC（质量控制）**：常规技术活动，包括数据检验、复核、比对、标定
- **QA（质量保证）**：独立于QC的评审体系，包括内审、外审、同行评议

## 不确定性评估
### 评估方法
- 采用IPCC方法学进行不确定性量化
- 对关键排放源开展敏感性分析

### 不确定性等级
| 等级 | 相对不确定性 | 评价 |
|------|------------|------|
| 高 | ≤±5% | 数据质量高 |
| 中 | ±5%-±15% | 良好 |
| 中下 | ±15%-±30% | 可接受 |
| 低 | >±30% | 需改进 |

## 对企业的影响
- 区域温室气体清单编制机构须执行本规范的数据质量要求
- 区域核算结果是各级政府碳达峰碳中和考核的依据，数据质量至关重要
- 企业层面数据是区域核算的基础，须配合提供准确数据
