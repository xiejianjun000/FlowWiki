# GB4287-2012 纺织染整工业水污染物排放标准

## 标准概述
- 标准编号：GB4287-2012
- 标准名称：纺织染整工业水污染物排放标准
- 发布机关：环境保护部、国家质量监督检验检疫总局
- 发布日期：2012-10-19
- 施行日期：2013-01-01
- 适用范围：见标准原文适用范围。

## 适用行业
对应 GB/T 4754 行业代码：171, 172, 173, 174, 175, 176, 177, 178, 181, 182, 183, 281, 282, 283, 831（纺织业）

## 核心限值表
| 污染物 | 排放限值 | 单位 | 适用条件 |
|--------|---------|------|---------|
| COD | 直接排放:80 / 间接排放:200 | mg/L | 见标准 |
| BOD5 | 直接排放:20 / 间接排放:50 | mg/L | 见标准 |
| SS | 直接排放:50 / 间接排放:100 | mg/L | 见标准 |
| 氨氮 | 直接排放:10 / 间接排放:20 | mg/L | 见标准 |
| 总氮 | 直接排放:15 / 间接排放:30 | mg/L | 见标准 |
| 总磷 | 直接排放:0.5 / 间接排放:1.5 | mg/L | 见标准 |
| 苯胺类 | 直接排放:1.0 / 间接排放:2.0 | mg/L | 见标准 |
| 二氧化氯 | 直接排放:0.5 / 间接排放:0.5 | mg/L | 见标准 |
| 色度（稀释倍数） | 直接排放:50 / 间接排放:80 | 倍 | 见标准 |
| 总锑 | 直接排放:0.1 / 间接排放:0.1 | mg/L | 见标准 |
| 六价铬 | 直接排放:0.2 / 间接排放:0.5 | mg/L | 见标准 |

## 监测要求
（采样点、频次、方法提要）见标准原文及配套监测方法标准。核心要求：按 GB/T 16157、HJ/T 397 等规范布点采样；水污染物在企业废水总排放口及车间排放口监控；大气污染物在排气筒、厂界监控点监测。

## 对企业的影响
- 需识别本标准适用工序及排放口，建立污染物台账。
- 依据直接/间接排放、现有/新建企业、一般/重点区域选择对应限值。
- 配套安装治理设施并保留运行记录，确保稳定达标。
- 定期开展自行监测，保存原始监测数据不少于规定年限。
- 关注修改单及地方排放标准，及时更新合规判定依据。
