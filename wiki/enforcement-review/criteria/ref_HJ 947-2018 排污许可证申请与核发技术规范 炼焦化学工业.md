# HJ 947-2018 排污许可证申请与核发技术规范 炼焦化学工业

## 一、标准基本信息

- **标准号**：HJ 947-2018
- **实施日期**：2018年7月1日

## 二、适用范围

适用于焦化企业（备煤、炼焦、熄焦、煤气净化、焦油加工）排污单位。

## 三、产污环节

- 装煤：颗粒物、苯并[a]芘、苯、VOCs
- 推焦：颗粒物、SO₂
- 熄焦：颗粒物
- 焦炉烟囱：颗粒物、SO₂、NOx
- 煤气净化：苯、H₂S、氨、VOCs
- 废水：苯并[a]芘、氰化物、挥发酚

## 四、水污染物许可排放限值

| 污染物 | 直接排放 | 间接排放 |
|--------|----------|----------|
| COD | 80 | 300 |
| 氨氮 | 10 | 30 |
| 总氮 | 25 | 50 |
| 挥发酚 | 0.3 | 1.0 |
| 总氰化物 | 0.5 | 1.0 |
| 硫化物 | 1.0 | 1.0 |
| 苯 | 0.1 | 0.1 |
| 苯并[a]芘 | 0.00003 | 0.00003 |

## 五、大气污染物许可排放限值

| 污染源 | 颗粒物 | SO₂ | NOx | 苯并[a]芘 | 苯 |
|--------|--------|-----|-----|-----------|-----|
| 装煤 | 50 | 100 | - | 0.0003 | - |
| 推焦 | 30 | 50 | 500 | - | - |
| 焦炉烟囱 | 30 | 50 | 500 | - | - |
| 煤气净化 | 30 | - | - | 0.0003 | 5 |

## 六、自行监测

- 主要排放口：颗粒物、SO₂、NOx在线监测
- 苯并[a]芘：每季度1次
- 苯：每月1次
- 焦油渣：危废转移

## 七、对企业环保启示

1. 苯并[a]芘为致癌特征污染物
2. 焦化废水零排放是趋势
3. 焦炉煤气应回收利用
