# 废铅蓄电池再生企业职业卫生防护

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GBZ 1-2010 |
| 适用范围 | 职业卫生防护 |
| 发布机关 | 国家卫生健康委 |

## 二、主要内容
规定了废铅蓄电池再生企业的职业卫生防护要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 职业病危害 | 铅尘、铅烟、硫酸雾 |
| 防护设施 | 密闭、通风、净化 |
| 防护用品 | 防尘口罩、防护服 |
| 职业体检 | 每年1次铅接触体检 |
| 警示标识 | 职业病危害警示标识 |

## 四、合规要点
1. 配置职业病防护设施
2. 配备合格防护用品
3. 定期开展铅接触职业体检
4. 设置职业病危害警示标识
