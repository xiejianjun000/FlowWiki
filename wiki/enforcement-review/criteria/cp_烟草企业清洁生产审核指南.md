# 烟草企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国烟草总公司发〔2022〕8号 |
| 适用范围 | 卷烟、雪茄烟、烟丝等制造企业 |
| 发布机关 | 中国烟草总公司 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对烟草企业特点，重点识别烟叶处理、制丝、卷接、包装等关键工序清洁生产潜力。强调烟尘回收、烟梗烟末综合利用、VOCs管控。涵盖烟尘回收率、VOCs减排审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万支卷烟能耗、烟尘 |
| 审核 | 制丝、卷接工序 |
| 方案筛选 | 烟尘回收+烟梗利用 |
| 高费方案 | VOCs处理升级 |
| 实施验证 | 减排+综合利用 |
| 持续改进 | 智能制造 |

## 四、合规要点
1. 应配套烟尘回收装置，回收作烟草薄片。
2. 烟梗、烟末应综合利用，不得外排。
3. 卷接、包装工序应控制VOCs排放。
4. 排放废水应执行GB 8978排放标准。
