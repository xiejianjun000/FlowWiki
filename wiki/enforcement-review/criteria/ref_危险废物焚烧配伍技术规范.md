# 危险废物焚烧配伍技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 176-2020第6.4条 |
| 适用范围 | 焚烧配伍 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧前配伍的技术要求和方法。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 配伍原则 | 热值、氯含量、重金属含量控制 |
| 热值范围 | 适宜范围8000-14000kJ/kg |
| 氯含量 | ≤3% |
| 配伍方案 | 实验室分析+计算确定 |
| 配伍记录 | 记录配伍比例和过程 |

## 四、合规要点
1. 焚烧前进行废物配伍设计
2. 控制氯含量防止设备腐蚀
3. 控制重金属含量保护环境
4. 记录配伍过程便于追溯
