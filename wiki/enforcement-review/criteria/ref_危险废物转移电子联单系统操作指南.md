# 危险废物转移电子联单系统操作指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 生态环境部公告2024年 |
| 适用范围 | 电子联单系统操作 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物转移电子联单系统的操作流程和注意事项。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 账户管理 | 注册→认证→授权 |
| 联单操作 | 新建→填报→传送→确认 |
| 状态查询 | 实时查询转移状态 |
| 异常处理 | 联单作废、修改、补录 |
| 数据导出 | 支持导出统计报表 |

## 四、合规要点
1. 操作人员熟悉系统功能
2. 按规范操作电子联单
3. 异常情况及时处理
4. 定期导出数据备份
