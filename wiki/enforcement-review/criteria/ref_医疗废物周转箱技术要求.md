# 医疗废物周转箱技术要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 26994-2011附录 |
| 适用范围 | 医疗废物周转箱 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了医疗废物周转箱的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 材质 | 高密度聚乙烯（HDPE） |
| 结构 | 带盖密封、便于搬运 |
| 颜色 | 黄色 |
| 标识 | 医疗废物标识 |
| 性能要求 | 防渗漏、耐腐蚀、易清洗消毒 |

## 四、合规要点
1. 使用符合标准的周转箱
2. 周转箱性能满足运输要求
3. 定期清洗消毒
4. 损坏时及时更换
