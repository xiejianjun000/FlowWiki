# 各省清洁生产审核实施细则 河南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 豫发改规〔2023〕5号 |
| 适用范围 | 河南省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 河南省发展和改革委员会、河南省生态环境厅 |
| 实施日期 | 2023-08-01 |

## 二、主要内容
河南省实施细则聚焦黄河流域生态保护和高质量发展，强化沿黄地区煤化工、电解铝、农副产品加工等产业审核要求。建立"省-市-县"三级审核咨询机构备案管理体系。

## 三、清洁生产技术要求
| 阶段 | 河南特色要求 |
|------|-------------|
| 名单确定 | 黄河流域重点行业 |
| 重点行业 | 煤化工、电解铝、农产品加工 |
| 三级管理 | 省市县分级备案 |
| 黄河保护 | 沿黄1公里重点管控 |
| 资金支持 | 省级专项资金扶持 |

## 四、合规要点
1. 沿黄1公里范围内工业企业应每3年开展1次审核。
2. 煤化工企业审核应包含碳排放强度评估。
3. 审核咨询机构应在省市县三级任一级备案。
4. 验收结果作为黄河流域生态环境保护督察参考。
