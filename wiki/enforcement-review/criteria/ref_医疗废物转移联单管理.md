# 医疗废物转移联单管理

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 卫生部令第36号 |
| 适用范围 | 医疗废物转移联单 |
| 发布机关 | 国家卫生健康委 |

## 二、主要内容
规定了医疗废物转移联单的管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 联单制度 | 一式三份（产生、运输、处置单位） |
| 联单内容 | 废物类别、数量、交接时间 |
| 保存期限 | ≥3年 |
| 报告制度 | 定期报告生态环境和卫健部门 |
| 台账管理 | 联单+台账记录 |

## 四、合规要点
1. 按规定使用转移联单
2. 联单内容完整准确
3. 联单保存不少于3年
4. 定期报告相关部门
