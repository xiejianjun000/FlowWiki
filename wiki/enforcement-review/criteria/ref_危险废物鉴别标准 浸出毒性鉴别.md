# 危险废物鉴别标准 浸出毒性鉴别

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 5085.3-2007 |
| 适用范围 | 危险废物浸出毒性鉴别 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物浸出毒性鉴别项目和标准值。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 鉴别项目 | 无机元素和有机物共40项 |
| 浸出方法 | 硫酸硝酸法（HJ/T 299）、醋酸缓冲法（HJ/T 300） |
| 铅限值 | ≤5mg/L |
| 汞限值 | ≤0.1mg/L |
| 鉴别结论 | 任一项目超限值即具有浸出毒性 |

## 四、合规要点
1. 按废物类型选择浸出方法
2. 检测项目覆盖废物特征污染物
3. 保留浸出液检测原始数据
4. 鉴别结论指导废物处置方式
