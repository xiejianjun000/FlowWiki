# 玻璃企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国建筑玻璃与工业玻璃协会发〔2022〕7号 |
| 适用范围 | 浮法平板玻璃、压延玻璃、玻璃纤维制造企业 |
| 发布机关 | 中国建筑玻璃与工业玻璃协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对玻璃企业特点，重点识别配料、熔窑、成型、退火等关键工序清洁生产潜力。强调熔窑余热回收、低氮燃烧、含锡废水回用。涵盖能源替代、余热发电、废气治理审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 每重箱能耗、SO₂ |
| 审核 | 熔窑、退火窑 |
| 方案筛选 | 余热发电+脱硫脱硝 |
| 高费方案 | 低氮燃烧升级 |
| 实施验证 | 节能+减排 |
| 持续改进 | 智能熔窑 |

## 四、合规要点
1. 熔窑应配套余热发电装置。
2. 应配套脱硫脱硝除尘一体化治理。
3. 含锡废水应单独处理回用。
4. 排放废气应执行GB 26453排放标准。
