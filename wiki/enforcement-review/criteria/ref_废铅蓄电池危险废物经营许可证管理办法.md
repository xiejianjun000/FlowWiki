# 废铅蓄电池危险废物经营许可证管理办法

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 部令第23号 |
| 适用范围 | 经营许可证管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池经营单位的许可条件和程序。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 许可条件 | 技术、场地、人员、管理符合要求 |
| 许可类型 | 收集、贮存、利用、处置 |
| 许可程序 | 申请→受理→审查→公示→发证 |
| 有效期 | 5年 |
| 变更延续 | 提前30日申请 |

## 四、合规要点
1. 经营单位持证规范经营
2. 许可证范围与实际经营一致
3. 到期前及时申请延续
4. 变更事项及时报批
