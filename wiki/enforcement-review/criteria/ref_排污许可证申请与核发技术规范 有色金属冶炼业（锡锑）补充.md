# 排污许可证申请与核发技术规范 有色金属冶炼业（锡锑）

## 一、标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 959-2018、HJ 1100-2020（扩展适用） |
| 适用范围 | 锡冶炼、锑冶炼、再生锡锑制造 |

## 二、产污环节与污染物

### 2.1 主要生产单元
- 焙烧：锡精矿焙烧、锑精矿焙烧
- 熔炼：反射炉、电炉、奥斯麦特炉
- 精炼：火法精炼、电解精炼
- 烟化：烟化炉挥发回收

### 2.2 主要污染物
- 废气：SO₂、颗粒物、锡、锑、砷、铅
- 废水：COD、SS、锡、锑、铅、砷
- 固废：锡锑渣、砷锑渣（HW48、HW24）

## 三、许可排放限值

### 3.1 大气污染物

| 污染物 | 排放浓度限值(mg/m³) |
|--------|---------------------|
| 颗粒物 | 30 |
| SO₂ | 100 |
| 锡及其化合物 | 1.0 |
| 锑及其化合物 | 0.5 |
| 砷及其化合物 | 0.5 |

### 3.2 水污染物（直接排放）

| 污染物 | 排放限值(mg/L) |
|--------|----------------|
| COD | 60 |
| 总锡 | 1.0 |
| 总锑 | 0.5 |
| 总铅 | 0.5 |
| 总砷 | 0.3 |

## 四、监测要求

- 烟化炉烟尘在线监测
- 含锑废水分质处理

## 五、违法处罚依据

《大气污染防治法》第99条、《水污染防治法》第83条、《排污许可管理条例》第33-35条。

## 六、合规启示

1. 烟化炉挥发回收有价金属
2. 砷锑渣危废规范处置
3. 制酸回收SO₂
