# 危险废物集中贮存设施运行管理规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2025-2012第8章 |
| 适用范围 | 集中贮存设施运行管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物集中贮存设施的运行管理、安全和应急管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 运行制度 | 建立操作规程和管理制度 |
| 人员配置 | 配备持证操作人员 |
| 安全管理 | 防火、防爆、防毒措施 |
| 应急管理 | 应急预案、物资、演练 |
| 档案管理 | 运行记录≥5年 |

## 四、合规要点
1. 建立完善的运行管理制度
2. 操作人员持证上岗
3. 安全管理措施落实到位
4. 定期开展应急演练
