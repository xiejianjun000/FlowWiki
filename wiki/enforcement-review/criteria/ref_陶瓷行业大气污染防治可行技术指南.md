# 陶瓷行业大气污染防治可行技术指南

## 一、基本信息

| 项目 | 内容 |
|------|------|
| 指南编号 | HJ 853-2017（参考） |
| 适用范围 | 建筑陶瓷、卫生陶瓷、日用陶瓷 |
| 发布机关 | 生态环境部 |

## 二、主要污染源
- 喷雾塔：颗粒物、SO₂
- 窑炉：SO₂、NOx、氟化物
- 喷釉：颗粒物、重金属

## 三、可行污染防治技术

| 污染源 | 推荐技术 | 去除效率 |
|--------|----------|----------|
| 喷雾塔除尘 | 旋风+袋式除尘 | ≥99% |
| 窑炉脱硫 | 半干法/湿法 | ≥85% |
| 窑炉脱硝 | SCR | ≥70% |
| 喷釉粉尘 | 水帘+袋除尘 | ≥95% |
| 氟化物 | 湿法脱硫协同 | ≥70% |

## 四、排放限值

| 污染物 | 排放限值(mg/m³) |
|--------|-----------------|
| 颗粒物 | 20 |
| SO₂ | 50 |
| NOx | 200 |
| 氟化物 | 3 |

## 五、合规要点

1. 推行清洁燃料（天然气）
2. 喷雾塔粉尘深度治理
3. 喷釉含铅釉料替代
4. 废泥回用
