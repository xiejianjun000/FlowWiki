# 医疗废物处置在线监测技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 76-2017 |
| 适用范围 | 处置在线监测 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了医疗废物处置设施在线监测系统的要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 监测项目 | 烟尘、SO₂、NOx、CO、O₂ |
| 数据传输 | 实时传输至监管平台 |
| 校准要求 | 定期自动和人工校准 |
| 运行率 | ≥95% |
| 数据保存 | ≥5年 |

## 四、合规要点
1. 安装在线监测系统并联网
2. 监测数据实时传输
3. 定期校准保证准确性
4. 数据长期保存备查
