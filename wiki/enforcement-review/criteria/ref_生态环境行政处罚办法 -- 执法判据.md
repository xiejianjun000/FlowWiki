# 生态环境行政处罚办法 -- 执法判据

> ACE Generator 编译 | Reflector 审核通过

## 行政处罚条款

| 条号 | 违法行为/适用情形 | 处罚方式 | 法定幅度/要求 |
|------|-------------------|----------|---------------|
| 第7条 | 同一违法行为违反多个规范 | 按罚款数额高的规定处罚 | 一事不再罚款 |
| 第8条 | 各类生态环境违法行为 | 7类处罚种类 | 警告、罚款没收、许可证件、限制停产关闭、限期拆除、拘留、其他 |
| 第9条 | 实施处罚时 | 责令改正或限期改正 | 可单独下达或与处罚一并下达 |

## 刑事衔接条款

| 条号 | 衔接内容 | 要点 |
|------|----------|------|
| 第17条 | 涉嫌行政拘留 | 移送公安机关或海警机构 |
| 第17条 | 涉嫌犯罪 | 移送司法机关，不得以行政处罚代替刑事处罚 |
| 第17条 | 责令停业关闭 | 报有批准权的人民政府 |

## 程序性条款

| 条号 | 程序要求 | 要点 |
|------|----------|------|
| 第6条 | 回避 | 三种法定回避情形+兜底条款，申请回避应说明理由 |
| 第10条 | 执法人员 | 不少于两人，须有行政执法资格 |
| 第13条 | 管辖 | 违法行为发生地管辖 |
| 第14条 | 管辖争议 | 最先立案的管辖，协商不成报共同上级指定 |
| 第15条 | 管辖变更 | 重大疑难案件可报请上级指定，上级可直接管辖或交下级 |
| 第16条 | 案件移送 | 不属于本机关管辖的移送有管辖权的机关，受移送不得再自行移送 |
| 第18条 | 立案期限 | 15日内决定是否立案，经批准可延长15日 |
| 第19条 | 立案条件 | 四项条件：初步证据、应/可处罚、本机关管辖、追责期限内 |
| 第20条 | 撤销立案 | 新情况不符合立案条件的应撤销 |
| 第21条 | 调查取证 | 指定专人，全面客观公正 |
| 第22条 | 协助调查 | 可发协助调查函请求其他机关协助 |
| 第23条 | 亮证执法 | 应主动出示执法证件，不出示的可被拒绝 |
| 第24条 | 检查措施 | 进入场所、询问、查阅复制；必要时可暗查 |
| 第25条 | 取证要求 | 不得暴力威胁引诱欺骗，应告知当事人权利，听取陈述申辩 |

## 执法要点

- **立案条件的四要素**（第19条）：执法中每个案件立案前必须审查四项条件是否齐备，尤其是追责期限的判断
- **一事不再罚款**（第7条）：同一违法行为违反多个规范，只按罚款数额高的处罚。注意是"罚款"不再罚，责令改正等非罚款措施仍可并用
- **不得以罚代刑**（第17条）：发现涉嫌犯罪必须移送司法机关，这是刚性要求。执法中应注意区分行政违法与刑事犯罪的边界
- **暗查的适用**（第24条）：必要时可采取暗查或其他方式调查，这为在线监测数据异常等案件的调查取证提供了法律支持
- **协助调查函**（第22条）：跨区域案件调查可发函请求协助，收到函的机关应当依法协助，这为跨区域执法协作提供了程序依据
