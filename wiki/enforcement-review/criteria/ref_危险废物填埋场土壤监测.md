# 危险废物填埋场土壤监测

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 25.2-2019 |
| 适用范围 | 土壤监测 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场周边土壤监测的布点、采样和分析要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 布点原则 | 网格法+专业判断法 |
| 布点密度 | 场区周边≥5个点 |
| 采样深度 | 表层0-0.5m |
| 监测项目 | 重金属、有机物 |
| 监测频次 | 每年1次 |

## 四、合规要点
1. 按规范布设土壤监测点
2. 采样覆盖表层土壤
3. 监测项目覆盖主要污染物
4. 监测结果与背景值对比
