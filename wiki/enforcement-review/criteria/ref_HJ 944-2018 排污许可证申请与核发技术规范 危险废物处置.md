# HJ 944-2018 排污许可证申请与核发技术规范 危险废物处置

## 一、标准基本信息

- **标准号**：HJ 944-2018
- **实施日期**：2018年7月1日

## 二、适用范围

适用于危险废物焚烧、填埋、物化处理排污单位。

## 三、产污环节

- 焚烧炉：颗粒物、SO₂、NOx、HCl、HF、重金属、二噁英
- 填埋场：渗滤液
- 物化处理：含油、重金属废水
- 储存：VOCs、臭气

## 四、大气污染物许可排放限值

| 污染源 | 颗粒物 | SO₂ | NOx | HCl | 二噁英 |
|--------|--------|-----|-----|-----|--------|
| 焚烧炉 | 65 | 200 | 500 | 60 | 0.5 ng-TEQ |
| 储存 | - | - | - | - | - |
| 厂界无组织 | 1.0 | - | - | - | - |

## 五、水污染物许可排放限值

| 污染物 | 直接排放 | 间接排放 |
|--------|----------|----------|
| COD | 60 | 300 |
| 氨氮 | 10 | 30 |
| 总汞 | 0.005 | 0.005 |
| 总镉 | 0.05 | 0.05 |
| 总铬 | 0.5 | 0.5 |
| 总砷 | 0.3 | 0.3 |
| 总铅 | 0.5 | 0.5 |

## 六、自行监测

- 焚烧炉：颗粒物、SO₂、NOx在线监测
- HCl、HF：每季度1次
- 重金属：每季度1次
- 二噁英：每年1次
- 渗滤液：重金属每月1次

## 七、对企业环保启示

1. 危废处置需持经营许可证
2. 焚烧二噁英是关键指标
3. 填埋场防渗渗漏监控
