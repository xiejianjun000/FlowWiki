# 危险废物焚烧重金属控制技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18484-2020附录 |
| 适用范围 | 重金属控制 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧过程重金属的控制技术和措施。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 控制方式 | 配伍控制+烟气净化 |
| 吸附工艺 | 活性炭吸附 |
| 除尘工艺 | 袋式除尘器 |
| 排放限值 | 汞≤0.1mg/m³、铅≤1.0mg/m³ |
| 飞灰管理 | 按危废管理处置 |

## 四、合规要点
1. 配伍控制废物重金属含量
2. 活性炭吸附烟气重金属
3. 袋式除尘器高效除尘
4. 重金属排放符合限值
