# 各省清洁生产审核实施细则 河北

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 冀发改规〔2023〕4号 |
| 适用范围 | 河北省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 河北省发展和改革委员会、河北省生态环境厅 |
| 实施日期 | 2023-07-01 |

## 二、主要内容
河北省实施细则围绕京津冀协同发展和雄安新区建设，对接北京冬奥会清洁生产遗产，重点推动钢铁、水泥、玻璃、焦化等去产能行业审核全覆盖。建立京津冀清洁生产审核信息共享机制。

## 三、清洁生产技术要求
| 阶段 | 河北特色要求 |
|------|-------------|
| 名单确定 | 钢铁、水泥、玻璃、焦化全覆盖 |
| 京津冀协同 | 信息共享、专家互认 |
| 超低排放 | 与审核同步推进 |
| 雄安新区 | 高标准绿色审核 |
| 退城搬迁 | 搬迁企业重点审核 |

## 四、合规要点
1. 钢铁企业应每3年完成1次清洁生产审核，超低排放改造同步纳入。
2. 退城搬迁企业应在搬迁前完成审核。
3. 京津冀三省市审核专家可跨省参与评审。
4. 雄安新区范围内企业审核标准从严执行。
