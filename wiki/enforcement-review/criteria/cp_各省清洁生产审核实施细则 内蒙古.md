# 各省清洁生产审核实施细则 内蒙古

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 内发改规〔2023〕5号 |
| 适用范围 | 内蒙古自治区行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 内蒙古自治区发展和改革委员会、内蒙古自治区生态环境厅 |
| 实施日期 | 2023-09-01 |

## 二、主要内容
内蒙古自治区实施细则围绕黄河"几字弯"生态保护和北方生态安全屏障建设，重点推动煤电、煤化工、稀土、电解铝等特色优势产业清洁生产升级。强化草原生态保护区、黄河流域审核要求。

## 三、清洁生产技术要求
| 阶段 | 内蒙古特色要求 |
|------|-------------|
| 名单确定 | 黄河几字弯+北方生态屏障 |
| 特色产业 | 煤电、煤化工、稀土、电解铝 |
| 草原保护 | 生态敏感区重点管控 |
| 节水节能 | 双约束指标 |
| 西部开发 | 政策叠加 |

## 四、合规要点
1. 草原生态保护区工业企业审核应严格节水、节地指标。
2. 煤电企业审核应包含超低排放和碳捕集内容。
3. 稀土企业审核应包含放射性废渣管控内容。
4. 电解铝企业审核应包含氟化物排放控制。
