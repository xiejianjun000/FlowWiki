# 危险废物混合后判定规则

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 5085.7-2019第5条 |
| 适用范围 | 危险废物混合后的判定 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物与其他废物混合后的判定规则。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 混合范围 | 危废+危废、危废+一般固废 |
| 判定规则 | 混合物按危废管理（另有规定除外） |
| 例外情形 | 经鉴别不具有危险特性的除外 |
| 豁免情形 | 符合豁免清单条件的可豁免 |
| 管理要求 | 混合物按原危废代码管理 |

## 四、合规要点
1. 避免危险废物与一般固废混合
2. 混合后需重新鉴别特性
3. 保留混合过程记录
4. 按规则确定混合物管理方式
