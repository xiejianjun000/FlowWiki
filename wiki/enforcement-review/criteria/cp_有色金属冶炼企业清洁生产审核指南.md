# 有色金属冶炼企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国有色金属工业协会发〔2022〕9号 |
| 适用范围 | 铜、铅、锌、镍、钴等有色金属冶炼企业 |
| 发布机关 | 中国有色金属工业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对有色金属冶炼企业特点，重点识别造锍、吹炼、电解等关键工序清洁生产潜力。强调富氧熔炼先进工艺、SO₂制酸、含重金属废渣综合利用、废水深度处理回用。涵盖重金属全流程审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨金属能耗、SO₂ |
| 审核 | 熔炼、电解工序 |
| 方案筛选 | 制酸+废渣利用 |
| 高费方案 | 富氧熔炼升级 |
| 实施验证 | 减排+回收 |
| 持续改进 | 智能冶炼 |

## 四、合规要点
1. 烟气应配套双转双吸制酸装置。
2. 含重金属废水应深度处理回用。
3. 含重金属废渣应回收金属后利用。
4. 排放废水应执行GB 25467排放标准。
