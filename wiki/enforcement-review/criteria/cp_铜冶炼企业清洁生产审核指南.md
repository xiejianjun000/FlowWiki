# 铜冶炼企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国有色金属工业协会发〔2022〕10号 |
| 适用范围 | 粗铜、阳极铜、电解铜生产企业 |
| 发布机关 | 中国有色金属工业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对铜冶炼企业特点，重点识别造锍、吹炼、精炼等关键工序清洁生产潜力。强调闪速熔炼/底吹熔炼先进工艺、SO₂制酸、含铜废渣综合利用。涵盖铜回收率、硫回收率审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨铜能耗、SO₂ |
| 审核 | 造锍、吹炼工序 |
| 方案筛选 | 制酸+废渣回收 |
| 高费方案 | 闪速熔炼升级 |
| 实施验证 | 铜+硫回收 |
| 持续改进 | 智能炼铜 |

## 四、合规要点
1. 应采用闪速熔炼或底吹熔炼工艺。
2. 烟气应配套双转双吸制酸装置。
3. 含铜废渣应回收铜后利用。
4. 排放废水应执行GB 25467排放标准。
