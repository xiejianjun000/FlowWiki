# 废铅蓄电池回收试点工作指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 工信部公告2019年 |
| 适用范围 | 回收试点 |
| 发布机关 | 工业和信息化部 |

## 二、主要内容
规定了废铅蓄电池回收试点的工作内容和管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 试点目标 | 探索规范化回收模式 |
| 试点主体 | 生产企业、回收企业、再生企业 |
| 试点范围 | 全国重点地区 |
| 试点内容 | 回收体系、信息化、标准体系 |
| 评估总结 | 定期评估试点效果 |

## 四、合规要点
1. 试点单位按要求开展工作
2. 探索可推广的回收模式
3. 建立信息化追溯系统
4. 定期总结评估试点效果
