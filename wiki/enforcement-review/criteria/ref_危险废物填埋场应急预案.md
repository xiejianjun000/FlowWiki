# 危险废物填埋场应急预案

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 169-2018 |
| 适用范围 | 填埋场应急预案 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场突发环境事件应急预案的编制和演练要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 风险源 | 防渗破裂、渗滤液泄漏、火灾 |
| 应急组织 | 指挥、处置、监测、保障组 |
| 响应程序 | 发现→报告→响应→处置→善后 |
| 应急物资 | 应急材料、设备、防护用品 |
| 演练频次 | 每年至少1次综合演练 |

## 四、合规要点
1. 编制应急预案并备案
2. 配备应急物资和设备
3. 定期开展应急演练
4. 应急情况下及时响应
