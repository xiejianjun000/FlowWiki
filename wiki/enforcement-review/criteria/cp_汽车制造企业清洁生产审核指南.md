# 汽车制造企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国汽车工业协会发〔2022〕9号 |
| 适用范围 | 汽车整车制造、改装汽车、零部件制造企业 |
| 发布机关 | 中国汽车工业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对汽车制造企业特点，重点识别冲压、焊装、涂装、总装等关键工序清洁生产潜力。强调水性涂料+电泳涂装、烘干废气RTO处理、废溶剂回收、磷化废液处理。涵盖VOCs、磷、镍等关键污染物审核。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 辆车能耗、VOCs |
| 审核 | 涂装工序重点 |
| 方案筛选 | 水性漆+RTO |
| 高费方案 | 电泳涂装升级 |
| 实施验证 | VOCs减排 |
| 持续改进 | 智能涂装 |

## 四、合规要点
1. 涂装线应采用水性涂料+电泳涂装工艺。
2. 烘干废气应配套RTO或RCO处理装置。
3. 磷化废液、电泳废液应分质处理。
4. 排放废水应执行GB 21900排放标准。
