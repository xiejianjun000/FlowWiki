# 危险废物填埋场后期维护管理

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18598-2019第10章 |
| 适用范围 | 后期维护管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场封场后的维护管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 维护期限 | ≥30年 |
| 维护内容 | 覆盖系统、监测系统、渗滤液处理 |
| 监测要求 | 继续环境监测 |
| 资金保障 | 建立后期维护基金 |
| 管理责任 | 明确责任主体 |

## 四、合规要点
1. 封场后持续维护30年以上
2. 定期维护覆盖和监测系统
3. 建立后期维护资金保障
4. 明确后期管理责任主体
