# 危险废物鉴别标准 通则

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 5085.7-2019 |
| 适用范围 | 危险废物鉴别的总则性规定 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物鉴别的程序、方法和判定规则，是其他鉴别标准的统领性文件。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 鉴别程序 | 名录识别→特性鉴别→毒性物质含量鉴别 |
| 判定规则 | 列入名录或具有任一危险特性 |
| 混合规则 | 危险废物与其他废物混合按危废管理 |
| 处理规则 | 处理后仍具危险特性的按危废管理 |
| 除外规则 | 经鉴别不具有危险特性的可排除 |

## 四、合规要点
1. 严格按GB 5085.7鉴别程序开展鉴别
2. 名录识别优先于特性鉴别
3. 保留鉴别全过程的原始记录
4. 鉴别结论与处置方案匹配
