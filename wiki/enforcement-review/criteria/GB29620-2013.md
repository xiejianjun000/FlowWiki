# GB29620-2013 砖瓦工业大气污染物排放标准

## 标准概述
- 标准编号：GB29620-2013
- 标准名称：砖瓦工业大气污染物排放标准
- 发布机关：环境保护部、国家质量监督检验检疫总局
- 发布日期：2013-09-17
- 施行日期：2014-01-01
- 适用范围：见标准原文适用范围。

## 适用行业
对应 GB/T 4754 行业代码：303（非金属矿物制品业）

## 核心限值表
| 污染物 | 排放限值 | 单位 | 适用条件 |
|--------|---------|------|---------|
| 颗粒物 | 工序:原料破碎及成型 / 现有企业:30 / 新建企业:20 / 特别排放:10 | mg/m³ | 见标准 |
| 颗粒物 | 工序:人工干燥及焙烧 / 现有企业:30 / 新建企业:20 / 特别排放:10 | mg/m³ | 见标准 |
| 二氧化硫 | 工序:人工干燥及焙烧 / 现有企业:850（修改单后执行更严格要求） / 新建企业:150（修改单调整） / 特别排放:100 | mg/m³ | 见标准 |
| 氮氧化物 | 工序:人工干燥及焙烧 / 现有企业:450 / 新建企业:300 / 特别排放:200 | mg/m³ | 见标准 |
| 氟化物 | 工序:人工干燥及焙烧 / 现有企业:3 / 新建企业:2 / 特别排放:1 | mg/m³ | 见标准 |

## 监测要求
（采样点、频次、方法提要）见标准原文及配套监测方法标准。核心要求：按 GB/T 16157、HJ/T 397 等规范布点采样；水污染物在企业废水总排放口及车间排放口监控；大气污染物在排气筒、厂界监控点监测。

## 对企业的影响
- 需识别本标准适用工序及排放口，建立污染物台账。
- 依据直接/间接排放、现有/新建企业、一般/重点区域选择对应限值。
- 配套安装治理设施并保留运行记录，确保稳定达标。
- 定期开展自行监测，保存原始监测数据不少于规定年限。
- 关注修改单及地方排放标准，及时更新合规判定依据。
