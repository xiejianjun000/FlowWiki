# 危险化学品安全管理条例解读

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 国务院令第645号 |
| 适用范围 | 危险化学品生产、储存、使用、经营、运输 |
| 发布机关 | 国务院 |

## 二、主要内容
对危险化学品安全管理条例进行解读，明确危险化学品全过程安全管理要求。

## 三、关键技术要求
| 环节 | 关键要求 | 监管部门 |
|------|---------|---------|
| 生产 | 安全许可 | 应急 |
| 储存 | 专库储存 | 应急/公安 |
| 使用 | 使用登记 | 应急 |
| 运输 | 资质运输 | 交通 |

## 四、合规要点
1. 应建立危化品台账
2. 应配安全管理人员
3. 应定期安全评价
4. 应制定应急预案
