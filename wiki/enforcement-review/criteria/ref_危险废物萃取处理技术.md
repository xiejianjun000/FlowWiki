# 危险废物萃取处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014第6.2条 |
| 适用范围 | 萃取处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物萃取处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 含有机物废物、含油废物 |
| 萃取剂 | 有机溶剂 |
| 萃取效率 | ≥95% |
| 萃取剂回收 | 蒸馏回收 |
| 安全措施 | 防火、防爆、防毒 |

## 四、合规要点
1. 选择高效低毒萃取剂
2. 萃取剂回收重复利用
3. 萃取过程做好安全防护
4. 记录萃取工艺参数
