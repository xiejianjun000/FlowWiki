# 危险废物鉴别单位管理要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 部令第23号 |
| 适用范围 | 危险废物鉴别单位资质与管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物鉴别单位的资质条件、人员要求、质量管理和监督检查。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 资质条件 | 具备CMA资质和相关检测能力 |
| 人员要求 | 技术负责人≥5年经验 |
| 质量管理 | 建立质量管理体系并有效运行 |
| 档案管理 | 鉴别档案保存≥10年 |
| 监督检查 | 各级生态环境部门定期检查 |

## 四、合规要点
1. 鉴别单位应具备相应资质和能力
2. 建立完善的鉴别质量管理体系
3. 档案资料完整保存可追溯
4. 配合生态环境部门监督检查
