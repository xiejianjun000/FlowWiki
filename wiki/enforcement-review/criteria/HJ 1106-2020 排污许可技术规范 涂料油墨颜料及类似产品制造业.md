## HJ 1106-2020 排污许可证申请与核发技术规范 涂料、油墨、颜料及类似产品制造业

### 一、标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1106-2020 |
| 标准名称 | 排污许可证申请与核发技术规范 涂料、油墨、颜料及类似产品制造业 |
| 发布日期 | 2020-02-28 |
| 实施日期 | 2020-02-28 |
| 发布机关 | 生态环境部 |
| 适用范围 | 涂料、油墨、颜料及类似产品制造业排污单位 |

### 二、适用范围

本标准适用于指导涂料、油墨、颜料及类似产品制造业排污单位在全国排污许可证管理信息平台填报相关申请信息，适用于指导核发机关审核确定排污单位排污许可要求。

### 三、产污环节与主要污染物

#### 3.1 主要生产单元
- 树脂合成工序
- 研磨分散工序
- 调漆工序
- 过滤包装工序
- 溶剂回收工序

#### 3.2 主要污染物
- 废气：VOCs、苯、甲苯、二甲苯、颗粒物
- 废水：COD、SS、氨氮、总磷、石油类、特征污染物
- 固废：废树脂、废溶剂、废滤渣（HW12、HW06）

### 四、许可排放限值

#### 4.1 大气污染物排放限值

| 污染物 | 排放浓度限值(mg/m³) | 排放速率限值(kg/h) |
|--------|---------------------|---------------------|
| 颗粒物 | 30 | 1.5 |
| 苯 | 1 | 0.05 |
| 甲苯 | 15 | 0.6 |
| 二甲苯 | 20 | 1.0 |
| 非甲烷总烃 | 80 | 5.0 |

#### 4.2 水污染物排放限值（直接排放）

| 污染物 | 排放限值(mg/L) |
|--------|----------------|
| COD | 80 |
| SS | 50 |
| 氨氮 | 10 |
| 总磷 | 1.0 |
| 石油类 | 5.0 |

### 五、监测要求

- 主要排放口安装VOCs在线监测
- 废水总排口安装COD、氨氮在线监测
- 季度手工监测特征污染物
- 建立环境管理台账

### 六、环境管理台账要求

- 记录生产设施运行信息
- 记录污染治理设施运行情况
- 记录监测数据
- 记录固体废物产生与处置情况

### 七、违法处罚依据

依据《大气污染防治法》第99条、《水污染防治法》第83条、《排污许可管理条例》第33-35条。

### 八、对企业环保合规工作的启示

1. 重点关注VOCs治理，落实源头削减
2. 加强废溶剂分类收集与回收利用
3. 规范危险废物（HW06、HW12）贮存
4. 建立完善的台账与执行报告体系
