# 人造板企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国林产工业协会发〔2022〕6号 |
| 适用范围 | 胶合板、纤维板、刨花板、细木工板等制造企业 |
| 发布机关 | 中国林产工业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对人造板企业特点，重点识别削片、热磨、铺装、热压等关键工序清洁生产潜力。强调无醛胶黏剂、游离甲醛控制、木粉回收、热能中心。涵盖能源替代、VOCs管控审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | m³板能耗、甲醛 |
| 审核 | 热磨、热压工序 |
| 方案筛选 | 无醛胶+热能中心 |
| 高费方案 | 甲醛废气治理 |
| 实施验证 | 减排+节能 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 应使用低醛或无醛胶黏剂。
2. 热压机应配套甲醛废气收集处理。
3. 砂光粉应回收作锅炉燃料。
4. 应配套热能中心使用废木料。
