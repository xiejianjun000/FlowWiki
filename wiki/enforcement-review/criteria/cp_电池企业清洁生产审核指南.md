# 电池企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国电池工业协会发〔2022〕7号 |
| 适用范围 | 铅酸蓄电池、锂离子电池、镍氢电池等制造企业 |
| 发布机关 | 中国电池工业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对电池企业特点，重点识别极板制造、组装、化成等关键工序清洁生产潜力。强调重金属控制、含铅含汞废水处理、废电池回收。涵盖重金属全流程、循环利用审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万kVAh重金属产生 |
| 审核 | 极板、化成工序 |
| 方案筛选 | 重金属控制+废水回用 |
| 高费方案 | 废电池回收 |
| 实施验证 | 重金属减排 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 含铅废气应配套高效滤筒+湿法除尘。
2. 含铅废水应单独处理回用，零排放。
3. 废电池回收率不低于90%。
4. 排放废水应执行GB 30484排放标准。
