# 危险废物转移联单填报技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1200-2021附录D |
| 适用范围 | 联单填报 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物转移联单的填报内容、格式和要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 填报内容 | 废物信息、数量、运输、交接 |
| 填报格式 | 电子联单标准格式 |
| 填报时限 | 转移前填报，实时更新 |
| 数据校验 | 系统自动校验数据完整性 |
| 签字确认 | 经办人电子签名 |

## 四、合规要点
1. 按规范填报转移联单
2. 数据准确完整无遗漏
3. 填报后及时确认传输
4. 电子签名确认责任
