# 危险废物刚性填埋场技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014附录 |
| 适用范围 | 刚性填埋场 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物刚性填埋场的设计、建设和运行要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 高危险废物、反应性废物 |
| 结构形式 | 钢筋混凝土结构 |
| 防渗要求 | 混凝土+人工合成材料 |
| 分单元设计 | 独立单元便于管理 |
| 运行管理 | 严格分区分类 |

## 四、合规要点
1. 刚性填埋场适用于高危险废物
2. 钢筋混凝土结构保证安全
3. 分单元设计便于管理
4. 运行严格分区分类
