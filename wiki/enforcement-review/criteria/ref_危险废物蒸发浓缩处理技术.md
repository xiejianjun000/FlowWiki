# 危险废物蒸发浓缩处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014第6.2条 |
| 适用范围 | 蒸发浓缩处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物蒸发浓缩处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 高浓度废液 |
| 蒸发方式 | 单效、多效、MVR |
| 浓缩倍数 | 根据废物特性确定 |
| 二次蒸汽 | 冷凝处理 |
| 浓缩液处理 | 进一步处理或处置 |

## 四、合规要点
1. 根据废液特性选择蒸发方式
2. MVR技术节能高效
3. 二次蒸汽冷凝处理达标
4. 浓缩液合理处置
