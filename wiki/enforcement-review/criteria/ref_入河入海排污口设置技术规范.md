# 入河入海排污口设置技术规范

## 一、总则

### 1.1 适用范围

- 适用于入河入海排污口的选址、设计、施工、验收、运行
- 适用于新建、改建、扩建排污口
- 适用于现有排污口的整治与规范化

### 1.2 基本要求

1. 排污口设置应当符合水功能区划、海洋功能区划
2. 排污口设置应当符合水污染防治规划、海洋环境保护规划
3. 排污口设置应当符合水污染物排放总量控制要求
4. 排污口设置应当符合生态保护红线要求

## 二、排污口选址

### 2.1 禁止设置区域

#### 入河排污口禁止设置区域

1. 饮用水水源一级保护区
2. 自然保护区核心区、缓冲区
3. 风景名胜区核心景区
4. 重要渔业水域
5. 地表水Ⅰ类、Ⅱ类水质水域
6. 法律法规规定禁止设置的其他水域

#### 入海排污口禁止设置区域

1. 海洋自然保护区核心区
2. 海洋特别保护区重点保护区
3. 重要渔业水域
4. 海滨风景名胜区核心景区
5. 海水浴场
6. 海水养殖区
7. 法律法规规定禁止设置的其他海域

### 2.2 限制设置区域

#### 入河排污口限制设置区域

1. 饮用水水源二级保护区
2. 自然保护区实验区
3. 风景名胜区非核心景区
4. 地表水Ⅲ类水质水域
5. 其他法律法规规定限制设置的水域

#### 入海排污口限制设置区域

1. 海洋自然保护区实验区
2. 海洋特别保护区一般控制区
3. 其他法律法规规定限制设置的海域

### 2.3 允许设置区域

- 除禁止设置区域、限制设置区域以外的其他水域、海域

### 2.4 选址技术要求

#### 水文条件

1. 排污口应设置在水流条件良好的水域
2. 避开水流回流区、死水区
3. 避开饮用水取水口下游 1000m 以内
4. 避开游泳场下游 100m 以内

#### 水深条件

- 入海排污口：水深 ≥ 5m
- 入河排污口：水深 ≥ 1m

#### 距离条件

| 排污口类型 | 与下游饮用水取水口距离 | 与下游渔业水域距离 |
|----------|---------------------|------------------|
| 工业企业排污口 | ≥ 1000m | ≥ 500m |
| 城镇污水处理厂排污口 | ≥ 1000m | ≥ 500m |
| 其他排污口 | ≥ 1000m | ≥ 500m |

## 三、排污口设计

### 3.1 排污口类型

#### 按排放方式分类

| 类型 | 适用场景 |
|------|---------|
| 重力流排放 | 污水靠重力流入水体 |
| 压力流排放 | 污水靠泵加压排放 |
| 跌水排放 | 污水从高处跌落排放 |

#### 按排放位置分类

| 类型 | 适用场景 |
|------|---------|
| 岸边排放 | 排污口设置在岸边 |
| 离岸排放 | 排污口设置在离岸一定距离 |
| 深水排放 | 排污口设置在深水区域 |

### 3.2 排污口结构

#### 岸边排污口

```text
[管道] → [闸阀] → [扩散管] → [水体]
        ↓
   [取样平台]
```

#### 离岸排污口

```text
[岸边管道] → [水下管道] → [排放头] → [水体]
              ↓                ↓
         [检修井]         [扩散器]
```

#### 深水排放口

```text
[岸边管道] → [扩散管] → [多孔排放头] → [深水水体]
              ↓              ↓
         [检修井]       [上升管]
```

### 3.3 排污口规模

#### 设计排放量

- 排放量应按建设项目最大排放量设计
- 设计排放量应留有 30% 余量
- 应考虑不同季节、不同工况的排放量变化

#### 排放管径

$$D = \sqrt{\frac{4Q}{\pi v}}$$

其中：
- $D$ = 排放管径（m）
- $Q$ = 设计排放量（m³/s）
- $v$ = 流速（m/s，一般取 0.5-1.5）

### 3.4 监测设施设计

#### 监测点位

1. 排放管道上设置监测点位
2. 监测点位应便于取样
3. 监测点位应设置取样平台

#### 监测设备

1. 流量计：电磁流量计、超声波流量计
2. 水质监测仪：pH、COD、氨氮、总磷、总氮
3. 自动采样器：自动定时取样

#### 监测用房

1. 监测设备用房面积 ≥ 10 m²
2. 配备空调、电源、水源
3. 配备数据传输设备

## 四、排污口施工

### 4.1 施工准备

1. 编制施工方案
2. 办理施工许可证
3. 准备施工材料、设备
4. 进行施工放样

### 4.2 施工过程

#### 岸上施工

1. 开挖管道沟槽
2. 敷设管道
3. 安装阀门、监测设备
4. 回填沟槽
5. 修筑取样平台

#### 水下施工

1. 水下开挖沟槽
2. 沉放管道
3. 连接管道
4. 安装排放头
5. 水下回填

#### 海上施工

1. 海上开挖沟槽
2. 沉放管道
3. 连接管道
4. 安装扩散器
5. 海底回填

### 4.3 施工质量

#### 质量控制

1. 材料质量：管道、阀门、监测设备符合设计要求
2. 施工质量：管道铺设、连接、回填符合规范
3. 防渗处理：管道连接处、阀门处做好防渗

#### 质量验收

1. 管道试压：按设计压力 1.5 倍试压
2. 管道试漏：充水检查无渗漏
3. 监测设备调试：监测设备运行正常
4. 验收报告：编制施工质量验收报告

## 五、排污口标识

### 5.1 标识牌设置

#### 标识牌位置

1. 排污口附近醒目位置
2. 排污口管道上
3. 监测点位附近

#### 标识牌数量

- 每个排污口至少设置 1 块标识牌
- 重要排污口设置 2-3 块标识牌

### 5.2 标识牌内容

#### 基本信息

1. 排污口名称
2. 排污口编号
3. 排污单位名称
4. 排污口位置
5. 排放去向

#### 排放信息

1. 主要污染物
2. 排放标准
3. 排放限值
4. 实际排放浓度
5. 实际排放量

#### 管理信息

1. 监督管理部门
2. 举报电话
3. 排污许可证编号

### 5.3 标识牌规格

#### 尺寸

- 标准尺寸：800mm×600mm
- 重要排污口：1200mm×800mm

#### 材质

- 不锈钢板
- 铝合金板
- 防紫外线塑料板

#### 颜色

- 背景色：白色
- 边框色：深绿色
- 文字色：黑色
- 标识符色：根据管理类型确定

## 六、排污口验收

### 6.1 验收条件

#### 必备条件

1. 排污口按设计方案建设完成
2. 排污口设施运行正常
3. 监测设施配备齐全
4. 标识牌设置完成
5. 登记备案手续完成

### 6.2 验收内容

1. 排污口位置：与设计一致
2. 排放管径：与设计一致
3. 排放能力：达到设计要求
4. 监测设施：运行正常
5. 标识牌：内容齐全
6. 档案资料：完整

### 6.3 验收程序

#### 第一步：建设单位申请

- 提交验收申请
- 提交验收资料

#### 第二步：生态环境部门审查

- 审查验收资料
- 现场核查

#### 第三步：验收监测

- 委托有资质机构监测
- 出具监测报告

#### 第四步：验收意见

- 形成验收意见
- 验收合格的予以确认
- 验收不合格的整改后重新验收

## 七、排污口运行

### 7.1 运行管理

#### 日常运行

1. 监测设施日常运行
2. 排放情况日常记录
3. 异常情况及时处理

#### 设备维护

1. 定期检查设备运行情况
2. 定期校准监测设备
3. 定期维护管道、阀门

#### 应急管理

1. 编制应急预案
2. 配备应急物资
3. 定期开展应急演练

### 7.2 排放管理

#### 排放达标

1. 排放浓度符合排放标准
2. 排放总量符合总量控制指标
3. 排放流量符合设计要求

#### 排放记录

1. 排放浓度、流量、总量记录
2. 监测数据记录
3. 异常排放记录

#### 排放报告

1. 月度排放报告
2. 季度排放报告
3. 年度排放报告

## 八、排污口整治

### 8.1 整治对象

#### 应予取缔的排污口

1. 在禁止设置区域的排污口
2. 非法设置的排污口
3. 长期不排放但未注销的排污口

#### 应予整治的排污口

1. 排放超标的排污口
2. 监测设施不完善的排污口
3. 排放规模与批准不符的排污口

### 8.2 整治措施

#### 取缔措施

1. 拆除排污管道
2. 拆除监测设备
3. 恢复岸坡
4. 注销登记备案

#### 整治措施

1. 完善监测设施
2. 调整排放规模
3. 改进处理工艺
4. 实现达标排放

#### 规范化措施

1. 设置标识牌
2. 规范取样点位
3. 完善档案

### 8.3 整治验收

1. 整治完成后组织验收
2. 验收合格的予以确认
3. 验收不合格的继续整改

## 九、海洋排污口特殊要求

### 9.1 海洋环境条件

#### 海洋水文条件

1. 潮汐条件：避开强潮区
2. 海流条件：选择海流条件良好海域
3. 波浪条件：避开强波浪区
4. 水深条件：水深 ≥ 5m

#### 海洋生态条件

1. 避开重要渔业水域
2. 避开海洋自然保护区
3. 避开海水浴场
4. 避开海水养殖区

### 9.2 排放深度

| 排放规模（m³/d） | 排放深度（m） |
|---------------|-------------|
| ≤ 10000 | ≥ 5 |
| 10000-100000 | ≥ 10 |
| ≥ 100000 | ≥ 15 |

### 9.3 扩散器设计

#### 扩散器结构

- 多孔扩散器
- 上升管
- 喷嘴

#### 扩散器参数

| 参数 | 数值 |
|------|------|
| 扩散器长度 | 按排放规模确定 |
| 喷嘴数量 | 按扩散器长度确定 |
| 喷嘴间距 | 2-5 m |
| 喷嘴直径 | 0.1-0.3 m |
| 喷嘴角度 | 30-45° |

### 9.4 海洋环境影响评价

#### 评价内容

1. 初始稀释度计算
2. 扩散范围计算
3. 影响范围预测
4. 海洋生态影响评价

#### 评价标准

- 初始稀释度：≥ 50（一般海域）、≥ 100（敏感海域）
- 扩散范围：≤ 排放许可范围
- 影响范围：≤ 排放影响范围

## 十一、对企业环保合规工作的启示

1. **依法设置排污口**：按程序申请设置排污口
2. **规范设计**：按技术规范设计排污口
3. **规范施工**：按设计要求施工，保证质量
4. **配备监测设施**：配备完善的监测设施
5. **设置标识牌**：按规定设置标识牌
6. **及时验收**：建设完成后及时组织验收
7. **规范运行**：建立运行管理制度
8. **定期维护**：定期维护设备和管道
9. **配合检查**：配合监督检查
10. **及时整治**：发现的问题及时整治
