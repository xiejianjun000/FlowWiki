# 排污许可证申请与核发技术规范 汽车整车制造工业（补充）

## 一、标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1117.2-2020（扩展） |
| 适用范围 | 汽车整车制造、改装汽车制造、低速汽车制造 |

## 二、产污环节与污染物

### 2.1 主要生产单元
- 冲压：板材剪切、冲压成型
- 焊接：点焊、弧焊、激光焊
- 涂装：电泳、中涂、面漆、清漆
- 总装：内饰、底盘、整车装配
- 检测：发动机测试、尾气检测

### 2.2 主要污染物
- 废气：VOCs（涂装为主）、颗粒物、焊接烟尘、烘干废气
- 废水：COD、SS、石油类、重金属、磷酸盐
- 固废：废漆渣、废溶剂、磷化渣、废油（HW12、HW06、HW17）

## 三、许可排放限值

### 3.1 大气污染物

| 污染物 | 排放浓度限值(mg/m³) |
|--------|---------------------|
| 苯 | 1 |
| 甲苯 | 20 |
| 二甲苯 | 20 |
| 非甲烷总烃 | 50 |
| 颗粒物 | 30 |

### 3.2 水污染物（直接排放）

| 污染物 | 排放限值(mg/L) |
|--------|----------------|
| COD | 60 |
| SS | 50 |
| 石油类 | 3.0 |
| 总锌 | 1.5 |
| 总镍 | 0.5 |

## 四、监测要求

- 涂装喷漆室VOCs在线监测
- 烘干室废气监测
- 废水总排口COD、氨氮在线监测

## 五、违法处罚依据

《大气污染防治法》第99条、《水污染防治法》第83条、《排污许可管理条例》第33-35条。

## 六、合规启示

1. 涂装工序VOCs全过程管控，使用水性涂料
2. 磷化废液分质处理
3. 危废（HW12、HW06、HW17）规范处置
