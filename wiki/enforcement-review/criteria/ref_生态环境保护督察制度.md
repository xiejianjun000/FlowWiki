# 生态环境保护督察制度

> 对应司局：中央生态环境保护督察协调局。中央生态环境保护督察是生态环境领域最高层级的监督制度，涵盖督察进驻、典型案例、反馈报告、整改落实全链条。

## 领域概述

生态环境保护督察是中国环境治理的核心制度安排，经历从试点到党内法规再到工作条例的持续升级：

| 维度 | 内容 |
|------|------|
| 制度层级 | 从《督察方案（试行）》→《工作规定》（党内法规）→《工作条例》 |
| 督察方式 | 例行督察 + 回头看 + 专项督察（流域/大运河等） |
| 督察对象 | 省级党委政府 → 央企 → 国务院部门 |
| 典型案例 | 约280+个（截至2026年5月） |

## 核心内容

本领域资料涵盖：

1. **督察制度沿革** — 2015年河北试点至2026年制度完善
2. **历轮督察时间线** — 第一轮（2015-2018）、回头看（2018）、第二轮（2019-2022）、第三轮（2023-进行中）
3. **典型案例分类** — 覆盖"两高"项目、污水直排、非法采矿、危废处置等六大高频问题
4. **反馈与整改体系** — 反馈机制、整改方案、整改报告全流程
