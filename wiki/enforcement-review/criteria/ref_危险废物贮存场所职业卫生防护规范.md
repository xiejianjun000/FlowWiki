# 危险废物贮存场所职业卫生防护规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GBZ 1-2010 |
| 适用范围 | 贮存场所职业卫生防护 |
| 发布机关 | 国家卫生健康委员会 |

## 二、主要内容
规定了危险废物贮存场所职业病危害防护要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 职业病危害 | 粉尘、毒物、噪声等 |
| 防护设施 | 通风、密闭、隔离 |
| 防护用品 | 防毒面具、防护服、手套 |
| 职业体检 | 上岗前、在岗、离岗体检 |
| 警示标识 | 职业病危害警示标识 |

## 四、合规要点
1. 配置职业病防护设施
2. 配备合格的个人防护用品
3. 定期开展职业健康体检
4. 设置职业病危害警示标识
