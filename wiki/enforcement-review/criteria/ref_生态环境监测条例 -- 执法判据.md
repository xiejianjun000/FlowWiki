# 生态环境监测条例 -- 执法判据

> ACE Generator 编译 | Reflector 审核通过

## 行政处罚条款

本条例49条全文中，前200行主要为制度性规定，未直接规定处罚条款。处罚条款集中在条例后半部分（第33-49条），需结合法典第五编第1086-1093条适用。

| 条号 | 违法行为 | 适用处罚 | 法定幅度 |
|------|----------|----------|----------|
| 第25条 | 企事业单位实施监测数据弄虚作假6种行为 | 转致法典第1088条 | 10万-100万元（单位）+5万-20万元（个人） |
| 第25条 | 企事业单位负责人指使弄虚作假 | 转致法典第1088条 | 同上 |
| 第19条 | 政府工作人员对公共监测数据弄虚作假 | 依法给予处分 | 构成犯罪的追究刑事责任 |
| 第19条 | 打击报复拒绝弄虚作假的单位和个人 | 依法给予处分 | - |
| 第28条 | 技术服务机构不具备资质或不备案 | 转致法典第1089条 | 没收违法所得+2万-20万元罚款 |
| 第32条 | 技术服务机构对监测数据弄虚作假 | 转致法典第1091条 | 没收违法所得+10万-50万元（情节严重50万-200万元+禁止从业） |
| 第26条 | 未按规定保存原始监测记录 | 转致法典第1086条 | 2万-20万元 |

## 刑事衔接条款

- 第19条：政府工作人员弄虚作假或打击报复，构成犯罪的依法追究刑事责任
- 监测数据弄虚作假情节严重的，可能构成提供虚假证明文件罪

## 程序性条款

| 条号 | 程序要求 | 要点 |
|------|----------|------|
| 第2条 | 适用范围 | 领域及管辖海域内开展监测及相关活动 |
| 第7条 | 监测职责分工 | 生态环境主管部门负责监测工作，有关部门在各自职责范围内负责有关工作 |
| 第11条 | 监测网络组织 | 国家和设区的市级以上地方分别组织 |
| 第13条 | 监测站点保护 | 任何单位不得侵占损毁或干扰正常运行 |
| 第15条 | 信息发布 | 统一发布，不得违法发布 |
| 第23条 | 自动监测联网 | 应安装自动监测设备的应与生态环境主管部门联网 |
| 第26条 | 记录保存 | 至少保存5年（无其他规定时） |
| 第28条 | 技术机构备案 | 应向生态环境主管部门备案并提交书面承诺 |

## 执法要点

- **弄虚作假的6种法定情形**（第25条）是执法认定的核心依据：未实际监测出报告、篡改伪造原始记录、故意漏检、调换样品或干扰采样、破坏设备或修改参数使数据失真、其他。执法中应逐一对照
- **自行监测与公共监测的区分**（第2条）：公共监测是政府行为，自行监测是企事业单位法定义务，违法主体和适用条款不同
- **技术服务机构的双重责任**：未备案/不具备资质按第1089条处罚，弄虚作假按第1091条处罚，处罚幅度差异大，需准确认定违法性质
- **视频监控要求**（第21条）：主要监测点位应安装可获取监测活动和设备运行情况的视频监控设备并联网，这是2026年新增的监督手段
