# 废铅蓄电池再生企业环境风险评估

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 169-2018 |
| 适用范围 | 环境风险评估 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池再生企业环境风险评估的要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 评估范围 | 大气、水、土壤环境风险 |
| 评估方法 | 源项分析→扩散分析→影响评估 |
| 风险等级 | 高、中、低三级 |
| 评估周期 | 每3-5年评估一次 |
| 风险管控 | 根据评估结果制定管控措施 |

## 四、合规要点
1. 定期开展环境风险评估
2. 评估覆盖多环境要素
3. 根据评估结果落实管控措施
4. 评估报告归档备查
