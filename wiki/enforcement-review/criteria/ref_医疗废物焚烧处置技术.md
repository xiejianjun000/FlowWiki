# 医疗废物焚烧处置技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ/T 177-2005第6章 |
| 适用范围 | 焚烧处置技术 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了医疗废物焚烧处置的技术要求和工艺。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 焚烧炉型 | 热解炉、回转窑 |
| 焚烧温度 | ≥850°C |
| 烟气停留时间 | ≥2秒 |
| 排放限值 | 符合GB 18484 |
| 残渣处置 | 按一般固废或危废处置 |

## 四、合规要点
1. 焚烧温度和停留时间满足要求
2. 烟气排放符合标准限值
3. 残渣按规定处置
4. 运行记录完整
