# 危险废物填埋场地下水监测

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18598-2019附录B |
| 适用范围 | 地下水监测 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场地下水监测井的布设和监测要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 监测井数量 | 上游1个+下游≥3个 |
| 井深要求 | 覆盖主要含水层 |
| 监测项目 | pH、重金属、特征污染物 |
| 监测频次 | 每季度1次 |
| 评价标准 | GB/T 14848 |

## 四、合规要点
1. 按规范布设地下水监测井
2. 定期开展地下水监测
3. 监测数据与背景值对比分析
4. 发现异常及时排查处置
