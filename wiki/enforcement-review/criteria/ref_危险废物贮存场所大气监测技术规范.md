# 危险废物贮存场所大气监测技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ/T 55-2000 |
| 适用范围 | 贮存场所大气监测 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物贮存场所大气监测的布点、采样和分析要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 监测点位 | 场所边界、敏感点 |
| 监测项目 | VOCs、特征污染物 |
| 监测频次 | 每季度至少1次 |
| 采样方法 | 按HJ/T 55规定执行 |
| 评价标准 | GB 16297或地方标准 |

## 四、合规要点
1. 按规范布设大气监测点
2. 监测项目覆盖特征污染物
3. 定期开展大气监测
4. 监测结果评价符合性
