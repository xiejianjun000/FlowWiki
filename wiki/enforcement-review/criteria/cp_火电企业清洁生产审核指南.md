# 火电企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国电力企业联合会发〔2022〕6号 |
| 适用范围 | 燃煤、燃气、燃油火电厂及热电联产企业 |
| 发布机关 | 中国电力企业联合会 |
| 实施日期 | 2022-06-15 |

## 二、主要内容
本指南针对火电企业特点，重点识别锅炉、汽轮机、烟气治理、循环水系统等关键设备清洁生产潜力。强调超超临界机组、超低排放、节水改造、CCUS技术应用。涵盖能流、水流、污染物产生分析。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 供电煤耗、水耗 |
| 审核 | 锅炉、汽轮机重点 |
| 方案筛选 | 余热回收+节水改造 |
| 高费方案 | 超低排放升级 |
| 实施验证 | 节能+减排 |
| 持续改进 | 智慧电厂 |

## 四、合规要点
1. 燃煤机组应达到超低排放要求。
2. 循环水应梯级利用，空冷机组优先。
3. 脱硫废水应零排放处理。
4. 粉煤灰、脱硫石膏应综合利用。
