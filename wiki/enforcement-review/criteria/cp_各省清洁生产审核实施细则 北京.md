# 各省清洁生产审核实施细则 北京

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 京发改规〔2023〕5号 |
| 适用范围 | 北京市行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 北京市发展和改革委员会、北京市生态环境局 |
| 实施日期 | 2023-06-01 |

## 二、主要内容
北京市实施细则细化了强制性审核名单的确定程序、审核咨询机构管理、审核报告评审、验收与奖补等内容。明确市级部门负责统筹，区级负责日常监督，建立北京市清洁生产审核信息管理系统统一归集数据。

## 三、清洁生产技术要求
| 阶段 | 北京特色要求 |
|------|-------------|
| 名单确定 | 排污许可重点管理 + 双超双有 |
| 机构管理 | 备案制 + 信用评价 |
| 报告评审 | 专家库随机抽取5名 |
| 验收 | 区级初审、市级复核 |
| 奖补 | 中/高费方案最高补贴300万 |

## 四、合规要点
1. 强制性审核名单每年3月底前公布，企业应于名单公布后2个月内启动审核。
2. 审核咨询机构应在北京市备案，且与被审核企业无利益关系。
3. 审核报告应通过北京市清洁生产信息管理系统线上提交。
4. 验收通过后3年内不再纳入强制性审核名单（违法行为除外）。
