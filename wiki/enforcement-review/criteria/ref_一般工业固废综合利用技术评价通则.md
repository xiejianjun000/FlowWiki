# 一般工业固废综合利用技术评价通则

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 41015-2021 |
| 适用范围 | 一般工业固废综合利用技术评价 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了一般工业固废综合利用技术评价的基本原则、指标体系、评价方法和程序。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 评价原则 | 科学性、客观性、可操作性 |
| 评价指标 | 资源化率、能耗、污染物排放、经济性 |
| 评价方法 | 层次分析法+模糊综合评价 |
| 评价等级 | 优秀、良好、合格、不合格 |
| 评价报告 | 含技术说明、检测数据、结论 |

## 四、合规要点
1. 评价前收集完整的技术资料和数据
2. 评价指标数据应有检测报告支撑
3. 评价结论应明确技术适用范围
4. 评价报告保存至少5年
