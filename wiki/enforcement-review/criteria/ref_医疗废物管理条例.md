# 医疗废物管理条例

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 国务院令第380号 |
| 适用范围 | 医疗废物管理 |
| 发布机关 | 国务院 |

## 二、主要内容
规定了医疗废物的分类、收集、贮存、运输、处置和监督管理。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用范围 | 医疗卫生机构、处置单位 |
| 分类管理 | 感染性、病理性、损伤性、药物性、化学性 |
| 集中处置 | 县级以上集中处置 |
| 转移联单 | 全过程联单管理 |
| 法律责任 | 未按规定处置处1万-3万元罚款 |

## 四、合规要点
1. 按条例规定分类管理医疗废物
2. 通过集中处置单位规范处置
3. 全过程使用转移联单
4. 建立医疗废物管理责任制
