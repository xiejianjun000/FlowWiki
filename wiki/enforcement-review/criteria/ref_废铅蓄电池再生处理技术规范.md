# 废铅蓄电池再生处理技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 519-2020第7章 |
| 适用范围 | 再生处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池再生处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 处理工艺 | 火法冶金、湿法冶金 |
| 预处理 | 破碎分选 |
| 铅回收率 | ≥99% |
| 再生铅质量 | 符合产品标准 |
| 污染防治 | 废气、废水、固废处理 |

## 四、合规要点
1. 采用先进处理工艺提高回收率
2. 再生铅质量符合产品标准
3. 处理过程污染防治到位
4. 建立处理记录档案
