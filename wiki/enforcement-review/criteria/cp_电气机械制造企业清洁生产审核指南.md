# 电气机械制造企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国电器工业协会发〔2022〕5号 |
| 适用范围 | 电机、变压器、电线电缆、家用电器等制造企业 |
| 发布机关 | 中国电器工业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对电气机械制造企业特点，重点识别绕线、浸漆、装配等关键工序清洁生产潜力。强调无溶剂绝缘漆、废铜回收、含油废水处理回用。涵盖VOCs、废铜、含油废水审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万元产值VOCs、废铜 |
| 审核 | 浸漆、绕线工序 |
| 方案筛选 | 无溶剂漆+废铜回收 |
| 高费方案 | 浸漆烘干升级 |
| 实施验证 | 减排+回收 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 浸漆工序应使用无溶剂或水溶性绝缘漆。
2. 浸漆烘干废气应配套VOCs处理装置。
3. 废铜、废铝应回收综合利用。
4. 含油废水应处理后回用。
