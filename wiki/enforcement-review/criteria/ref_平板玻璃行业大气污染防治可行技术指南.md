# 平板玻璃行业大气污染防治可行技术指南

## 一、基本信息

| 项目 | 内容 |
|------|------|
| 指南编号 | HJ 861-2017（参考） |
| 适用范围 | 浮法玻璃、压延玻璃窑炉 |
| 发布机关 | 生态环境部 |

## 二、主要污染源
- 玻璃窑烟气：SO₂、NOx、颗粒物、HCl、HF
- 配料：颗粒物
- 退火窑：VOCs

## 三、可行污染防治技术

| 污染源 | 推荐技术 | 去除效率 |
|--------|----------|----------|
| 窑炉烟气除尘 | 电除尘+袋除尘 | ≥99% |
| 窑炉脱硫 | 湿法脱硫（石灰石-石膏） | ≥90% |
| 窑炉脱硝 | SCR脱硝 | ≥80% |
| 配料粉尘 | 袋式除尘 | ≥99% |
| 全氧燃烧 | 减排30-50% | - |

## 四、排放限值

| 污染物 | 排放限值(mg/m³) |
|--------|-----------------|
| 颗粒物 | 20 |
| SO₂ | 100 |
| NOx | 400 |
| HCl | 30 |

## 五、合规要点

1. 推行全氧燃烧技术
2. 烟气脱硫脱硝
3. 配料密闭化
4. 碎玻璃回炉利用
