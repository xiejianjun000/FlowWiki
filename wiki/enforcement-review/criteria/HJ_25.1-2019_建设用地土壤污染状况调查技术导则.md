# HJ 25.1-2019 建设用地土壤污染状况调查技术导则

## 标准概述

- **标准编号**：HJ 25.1-2019
- **标准名称**：建设用地土壤污染状况调查技术导则
- **发布机关**：生态环境部
- **批准日期**：2019年1月29日
- **实施日期**：2019年7月1日
- **起草单位**：中国环境科学研究院、国家环境保护土壤环境管理与污染控制重点实验室
- **法律依据**：《中华人民共和国环境保护法》《中华人民共和国土壤污染防治法》
- **适用范围**：建设用地土壤污染状况调查（初步调查、详细调查、风险评估、风险管控效果评估、修复效果评估及定期跟踪调查所需调查）
- **不适用范围**：放射性污染和致病性生物污染的土壤调查
- **地位**：首次发布，为HJ 25系列技术导则的首部

## 调查原则（第4条）

| 原则 | 要求 |
|------|------|
| 针对性原则（4.1） | 根据用地功能、潜在污染特征和调查目的确定调查范围、内容和精度 |
| 规范性原则（4.2） | 严格按国家法律法规、标准规范和技术导则执行 |
| 可操作性原则（4.3） | 结合地块实际，综合考虑现场条件、技术可行性和经济合理性 |
| 经济性原则（4.4） | 满足目的和精度前提下优化方案，合理配置资源 |
| 循序渐进原则（4.5） | 分阶段进行，前一阶段结果决定下一阶段内容和深度 |

## 调查阶段划分（第5条）

建设用地土壤污染状况调查分为三个阶段，可根据实际情况合并或调整：

### 第一阶段：污染识别（5.1）

通过资料收集、现场踏勘和人员访谈，识别污染源、污染类型和污染程度。**原则上不进行现场采样分析**。

### 第二阶段：初步调查（5.2）

通过初步采样分析，确定污染物种类、浓度和空间分布，判断污染程度和范围。

### 第三阶段：详细调查（5.3）

通过详细采样分析，进一步明确污染物空间分布特征和迁移转化规律，为风险评估、风险管控和修复方案制定提供依据。

## 第一阶段：污染识别（第6条）

### 工作程序（6.1）

资料收集 → 现场踏勘 → 人员访谈 → 污染识别与分析 → 编制第一阶段调查报告

### 资料收集内容（6.2.1）

**（1）地块使用历史资料**
- 土地利用变更资料（历次土地使用性质、使用时间、主要生产经营活动）
- 地块内及周边企业基本信息（企业名称、产品、工艺、原辅材料、污染物排放）
- 建筑物/构筑物布局和用途（危险化学品储存区、生产装置区、污水处理设施、固废堆放场）
- 地下管线、地下储罐、地下构筑物分布

**（2）环境污染资料**
- 污染物排放记录（废气、废水、固废的种类、排放量、排放方式和去向）
- 环境监测资料（土壤、地下水、地表水、环境空气）
- 环保设施运行记录
- 环境污染事故记录（时间、原因、污染物种类和数量、影响范围、处置措施）
- 环保投诉和处罚记录

**（3）自然环境资料**
- 区域自然地理概况（地理位置、地形地貌、气候气象）
- 水文地质资料（含水层分布、地下水流向、水位、水化学类型）
- 土壤类型和分布
- 周边敏感目标分布（居民区、学校、医院、饮用水源地、基本农田）

**（4）其他资料**：建设用地规划文件、环评文件、岩土工程勘察报告、地下管线图、卫星遥感影像

### 现场踏勘（6.3）

踏勘内容包括地块现状（建筑物分布、地面硬化、植被覆盖、污染迹象——异味/异常颜色/异常植被、排污口分布、固废堆放）和周边环境（企业分布、敏感目标、地表水水质、地下水开采使用）。

踏勘方法包括现场观察记录、拍照摄像、便携式检测设备快速筛查、绘制现场踏勘示意图。

### 人员访谈（6.4）

访谈对象（6.4.1）：地块使用权人或管理人员、现任和离任企业负责人/技术人员/操作人员、周边居民、环保部门管理人员、其他知情人员。

访谈内容（6.4.2）：地块使用历史和变更、生产工艺与污染物排放、环保设施建设运行、环境污染事故、投诉纠纷、敏感目标分布变化。

访谈要求（6.4.3）：做好记录（必要时录音需征得同意）、访谈人和被访谈人签字确认、信息核实和交叉验证。

### 污染识别与分析（6.5）

**污染源识别（6.5.1）**：生产装置区、原辅材料储存区、产品储存区、污水处理设施、固废堆放场、地下储罐、危险废物暂存场等。

**污染物识别（6.5.2）**：
| 类别 | 示例 |
|------|------|
| 重金属 | 镉、汞、砷、铅、铬、铜、锌、镍 |
| 挥发性有机物（VOCs） | 苯系物、氯代烃、石油烃 |
| 半挥发性有机物（SVOCs） | 多环芳烃、邻苯二甲酸酯类 |
| 农药类 | 有机氯、有机磷等 |
| 其他特征污染物 | 根据行业特征确定 |

**污染途径分析（6.5.3）**：大气沉降、废水排放和下渗、固体废物淋滤、泄漏和溢洒、垂直入渗和水平迁移。

**概念模型建立（6.5.4）**：基于污染识别建立调查地块概念模型（污染源位置/类型/强度、污染物种类和性质、迁移途径和环境归宿、敏感受体类型和分布）。

## 第二阶段：初步调查（第7条）

### 工作程序（7.1）

制定初步采样调查方案 → 现场采样 → 实验室分析 → 数据分析与评价 → 编制第二阶段调查报告

### 采样点布设方法（7.2.2）

**（1）系统布点法**：将调查地块划分为等面积网格，初步调查阶段网格大小一般不超过 **40 m x 40 m**。

**（2）分区布点法**：按土地使用功能、污染源分布分区布设，**每个分区不少于3个点**。

**（3）专业判断布点法**：根据污染源位置专业判断布点，应与系统布点法或分区布点法结合使用。

### 采样点数量（7.2.3）

| 地块规模 | 面积范围 | 最少采样点数 |
|----------|---------|-------------|
| 小型地块 | ≤5,000 m² | 不少于 **7个** |
| 中型地块 | 5,000~50,000 m² | 不少于 **10个** |
| 大型地块 | >50,000 m² | 不少于 **15个** |

> 注：采样点数量包括地块内采样点和对照点。

### 对照点要求（7.2.4）

- 布设在调查地块外，土壤形成条件相似、未受或基本未受调查地块污染源影响的区域
- 数量**不少于3个**
- 分别布设在调查地块的不同方位

### 采样深度（7.2.5）

| 类型 | 深度要求 |
|------|---------|
| 表层土壤 | 0~0.5 m |
| 一般污染物深层采样 | ≥地下水位以上，且**不少于3 m** |
| 易迁移VOCs/SVOCs | 穿透污染晕，且**不少于5 m** |
| 存在DNAPL时 | 穿透含水层底板 |

每个采样点的土壤采样层数**不少于3层**。

### 监测项目（7.2.6）

**必测项目**：
- 重金属：镉、汞、砷、铅、铬（六价）、铜、锌、镍
- 挥发性有机物：苯、甲苯、乙苯、二甲苯、三氯乙烯、四氯乙烯、三氯甲烷、四氯化碳等
- 半挥发性有机物：多环芳烃（16种）、邻苯二甲酸酯类等
- 石油烃（C10-C40）
- 氰化物、氟化物等

**选测项目**：根据地块实际情况和行业特征选择特征污染物。

### 样品保存期限（7.3.3）

| 分析项目 | 保存条件 | 最长期限 |
|----------|---------|---------|
| 挥发性有机物 | 4℃以下冷藏避光 | **7天** |
| 半挥发性有机物 | 4℃以下冷藏避光 | **10天** |
| 重金属 | 4℃以下冷藏 | **180天** |

### 污染程度评价（7.5.3）

**单因子污染指数法**：

$$P_i = C_i / S_i$$

- Pi：土壤中污染物i的污染指数
- Ci：土壤中污染物i的实测浓度（mg/kg）
- Si：污染物i的评价标准值（mg/kg）

**评价标准**（采用GB 36600规定的风险筛选值和管制值）：

| 污染指数 | 含义 | 行动要求 |
|----------|------|---------|
| Pi ≤ 1 | 未超过风险筛选值 | 污染风险可忽略 |
| 1 < Pi ≤ 管制值/筛选值 | 超过筛选值但未超过管制值 | 可能存在风险，需进一步评估 |
| Pi > 1（以管制值为标准） | 超过风险管制值 | 存在不可接受风险，需采取风险管控或修复措施 |

## 第三阶段：详细调查（第8条）

### 工作目的（8.1）

进一步明确污染物空间分布特征（水平和垂直方向）、浓度水平和污染程度、迁移转化规律、对地下水的影响，为风险评估和修复方案制定提供详细基础数据。

### 加密布点要求（8.2.1）

- 水平方向：网格大小一般不超过 **20 m x 20 m**
- 垂直方向：采样间距一般不超过 **0.5 m**
- 重点关注重污染区域和污染边界区域

### 土壤气调查（8.3）

**目的**（8.3.1）：了解土壤中挥发性有机物浓度水平和分布特征，评估对人体健康的潜在风险。

**监测井布设**（8.3.4）：
- 布设在污染区域及其周边
- 监测深度根据污染物性质和地层结构确定
- 每个污染区域**至少3个土壤气监测点**

**采样方法**：
- 主动采样法：通过真空泵抽取（适用于透气性较好地层）
- 被动采样法：通过扩散吸附采集（适用于长期监测）

### 补充调查（8.4）

**水文地质调查**（8.4.1）：含水层岩性/厚度/分布、地下水水位/流向/流速、水化学类型和水质、包气带岩性/结构/厚度、土壤渗透性和孔隙度。

**土壤理化性质**（8.4.2）：质地、pH值、有机质含量、阳离子交换量、密度和孔隙度、渗透系数。

**污染物形态分析**（8.4.3）：重金属赋存形态——水溶态、酸溶态/可交换态、还原态、氧化态、残渣态。

## 质量保证和质量控制（第9条）

### 现场采样QC（9.2）

| 质控项 | 要求 |
|--------|------|
| 采样点偏差（9.2.1） | 位置偏差不超过**1 m**，深度偏差不超过**0.1 m** |
| 现场平行样（9.2.3） | 每批次不少于**1个** |
| 现场空白样（9.2.3） | 每批次不少于**1个** |

### 实验室分析QC（9.3）

- 实验室应通过**计量认证或实验室认可**
- 每批次样品：空白实验、平行样分析（比例不低于**10%**）、加标回收实验（比例不低于**10%**）
- 标准物质/质控样品分析
- 建立实验室内部质量控制体系

## 调查报告编制要求（第10条）

### 报告内容结构（10.2）

1. 封面（项目名称、调查单位、编制日期、报告编号）
2. 目录
3. 概述（背景和目的、调查依据——法律法规/标准规范/技术文件、调查范围、工作流程、时间安排）
4. 地块基本情况（地理位置和交通、自然环境概况、土地利用现状和历史、周边环境状况）
5. 第一阶段调查结果（资料收集分析、现场踏勘、人员访谈、污染识别、概念模型）
6. 第二阶段调查结果（采样方案、现场采样、实验室分析、数据评价、污染范围和程度）
7. 第三阶段调查结果（如开展）
8. 土壤污染概念模型（污染源、污染物、污染途径、敏感受体）
9. 调查结论与建议
10. 附件（采样点位置图、土壤剖面图、污染物浓度等值线图、现场照片、实验室检测报告等）

### 主要图件要求（10.3）

- 调查地块地理位置图
- 调查地块及周边土地利用现状图
- 采样点平面布置图
- 土壤剖面图
- 污染物浓度等值线图（平面和剖面）
- 污染范围分布图
- 地下水流向图
- 敏感目标分布图
