# 废铅蓄电池再生污染防治可行技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 512-2009 |
| 适用范围 | 污染防治可行技术 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池再生过程污染防治可行技术。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 废气治理 | 袋式除尘+酸雾净化 |
| 废水治理 | 化学沉淀+过滤 |
| 固废处置 | 按危废规范处置 |
| 噪声控制 | 隔音减振 |
| 铅尘控制 | 密闭收集+除尘 |

## 四、合规要点
1. 采用可行技术防治污染
2. 废气废水治理设施完善
3. 固废按危废规范处置
4. 铅尘密闭收集处理
