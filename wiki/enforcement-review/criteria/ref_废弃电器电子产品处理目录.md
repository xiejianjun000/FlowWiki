# 废弃电器电子产品处理目录

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 发改委公告2016年 |
| 适用范围 | 处理目录 |
| 发布机关 | 国家发展和改革委员会 |

## 二、主要内容
规定了废弃电器电子产品处理目录的内容。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 目录内容 | 14类产品 |
| 产品类别 | 电视机、电冰箱、洗衣机、空调器、微型计算机等 |
| 动态调整 | 根据情况定期调整 |
| 管理要求 | 目录内产品按条例管理 |
| 基金征收 | 目录内产品征收处理基金 |

## 四、合规要点
1. 按目录范围管理废弃电器电子产品
2. 目录内产品按条例规定处理
3. 及时跟踪目录调整动态
4. 目录内产品征收处理基金
