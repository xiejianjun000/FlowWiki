# 生态环境部：碳排放权交易安排与近期要闻

> 采集时间：2026-05-31 | 来源：生态环境部官网 + Tavily 搜索

## 🔥 核心政策：2026年全国碳排放权交易安排

**来源**：生态环境部《关于做好2026年全国碳排放权交易市场有关工作的通知》

### 行业扩围
- **发电、钢铁、水泥、铝冶炼**四大行业纳入全国碳排放权交易市场
- 年度直接排放量 ≥ 2.6万吨CO₂当量的单位需纳入管理

### 关键时间节点
| 时间 | 事项 |
|------|------|
| 2026-04-10前 | 向钢铁/水泥/铝冶炼预分配2025年度配额 |
| 2026-06-30前 | 向发电行业预分配2025年度配额 |
| 2026-06-30前 | 完成发电行业2025年度排放报告核查 |
| 2026-07-31前 | 完成钢铁/水泥/铝冶炼排放报告核查 |
| 2026-09-30前 | 核定并分配2025年度配额 |
| 2026-10-31前 | 公布2027年度重点排放单位名录 |
| 2026-12-31前 | 完成2025年度配额清缴 |

### 其他重点行业（准备中）
石化、化工、建材（平板玻璃）、有色（铜冶炼）、造纸、民航 —— 2025年度排放报告需在3月31日前报送。

## 📋 碳排放权交易收费新政

**发改价格〔2026〕667号**：国家发改委、生态环境部联合发布碳排放权交易收费通知，明确交易收费标准。

---

## 📌 2026年重点任务（全国生态环境保护工作会议）

1. **修订碳排放权交易管理办法**
2. **推行免费+有偿混合配额分配方式**
3. **制定跨境碳交易管理办法**
4. 加大CCER供给，建立自愿减排项目和减排量监管机制
5. 推动碳足迹核算标准编制，更新电力碳足迹因子
6. 推进非CO₂温室气体控排（甲烷MRV体系）
7. 制定碳捕集利用与封存（CCUS）发展意见
8. 深化减污降碳协同创新

## 💡 为什么值得看？

- 钢铁行业正式纳入碳市场，直接关联**冷钢碳排放平台**项目
- 配额混合分配（免费+有偿）是重大制度变化，影响碳价和企业成本
- 跨境碳交易管理办法将出台，需关注与CBAM的衔接
- 湖南省作为钢铁大省，碳市场扩围影响省内重点企业
