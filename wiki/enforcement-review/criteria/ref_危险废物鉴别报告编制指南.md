# 危险废物鉴别报告编制指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 298-2019附录 |
| 适用范围 | 危险废物鉴别报告编制 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物鉴别报告的内容、格式、编制要求和审核程序。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 报告结构 | 前言、采样、检测、判定、结论 |
| 数据呈现 | 表格+文字说明 |
| 附件材料 | 采样记录、检测报告、照片 |
| 审核签字 | 编制人、审核人、批准人签字 |
| 报告存档 | 纸质+电子档，保存≥10年 |

## 四、合规要点
1. 报告内容完整、数据准确
2. 附件材料齐全可追溯
3. 审核签字齐全方为有效
4. 报告电子化归档便于查询
