# 危险废物转移路线规划指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | JT/T 1180.2-2018附录 |
| 适用范围 | 转移路线规划 |
| 发布机关 | 交通运输部 |

## 二、主要内容
规定了危险废物转移路线规划的原则和要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 路线原则 | 避开人口密集区、饮用水源 |
| 禁行区域 | 生态红线、自然保护区 |
| 路线备案 | 提前向交通部门备案 |
| 应急路线 | 制定备用路线 |
| 运输时段 | 避开交通高峰和极端天气 |

## 四、合规要点
1. 转移路线避开敏感区域
2. 提前向交通部门备案
3. 制定应急备用路线
4. 合理安排运输时段
