# 危急废物焚烧应急处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 169-2018 |
| 适用范围 | 焚烧应急处置 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧设施突发情况应急处理技术。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 应急情况 | 停电、设备故障、废物异常 |
| 处理程序 | 停炉→评估→处置→恢复 |
| 废物处置 | 应急时转移至备用设施 |
| 环境保护 | 防止污染物超标排放 |
| 应急演练 | 每年至少1次 |

## 四、合规要点
1. 制定应急处置预案
2. 配置应急设备和备用设施
3. 应急情况下及时处置
4. 定期开展应急演练
