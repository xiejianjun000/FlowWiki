# HJ 469-2018 清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 469-2018 |
| 适用范围 | 所有开展清洁生产审核的工业企业及有关部门 |
| 发布机关 | 生态环境部 |
| 实施日期 | 2018-07-12 |
| 替代版本 | HJ 469-2009 |

## 二、主要内容
本标准规定了清洁生产审核的术语和定义、原则、程序、方法及报告编制要求。适用于工业企业自愿性或强制性清洁生产审核工作，其他企事业单位可参照执行。审核程序包括审核准备、预审核、审核、方案产生与筛选、方案实施及持续清洁生产六个阶段。

## 三、清洁生产技术要求
| 阶段 | 关键产出 |
|------|---------|
| 审核准备 | 审核小组成立、工作计划 |
| 预审核 | 物料平衡、水平衡、能源平衡 |
| 审核 | 重点关注部位及原因分析 |
| 方案产生与筛选 | 中/高费方案清单 |
| 方案实施 | 经济与环境效益验证 |
| 持续清洁生产 | 制度化、常态化机制 |

## 四、合规要点
1. 强制性审核企业每五年开展一次，且应于名单公布后一年内完成。
2. 审核报告应由具备相应能力的审核咨询机构或企业自行编制，并对真实性负责。
3. 审核实施过程应保留物料、能源、水等平衡的原始数据及计算依据不少于五年。
4. 中/高费方案实施率不低于60%，且应进行环境效益与经济效益的验证。
