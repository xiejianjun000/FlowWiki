# 含铬废液物化处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014附录 |
| 适用范围 | 含铬废液物化处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了含铬废液物化处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 电镀含铬废液、含铬废水 |
| 处理工艺 | 还原沉淀法 |
| 还原剂 | 亚硫酸钠、硫酸亚铁 |
| 沉淀剂 | 氢氧化钠 |
| 出水要求 | 总铬≤1.5mg/L，六价铬≤0.5mg/L |

## 四、合规要点
1. 六价铬还原为三价铬
2. 调节pH沉淀去除
3. 出水铬含量达标排放
4. 污泥按危废规范处置
