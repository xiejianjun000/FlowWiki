# 废弃电器电子产品深度处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 527-2010附录 |
| 适用范围 | 深度处理技术 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废弃电器电子产品深度处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 深度处理目的 | 深度回收有价值物质 |
| 处理工艺 | 火法冶金、湿法冶金 |
| 贵金属回收 | 金、银、钯等 |
| 再生利用 | 再生原料符合标准 |
| 污染防治 | 深度处理过程污染防治 |

## 四、合规要点
1. 深度处理提高资源回收率
2. 贵金属回收利用
3. 再生原料符合产品标准
4. 处理过程污染防治到位
