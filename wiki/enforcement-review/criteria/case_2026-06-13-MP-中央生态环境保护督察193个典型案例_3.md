## 二、按主题分类的典型问题（193 个案例的核心议题）

> 以下分类基于全部 193 个案例的标题与内容的归纳整理。

### 1. **水环境问题**（占比最高，约 35%）

- **生活污水直排 / 黑臭水体**：上海、武汉、株洲、长春、菏泽、绥化等
- **污水收集处理设施建设滞后**：上海、湖北、重庆、广东、浙江、辽宁等
- **水环境基础设施短板**：江苏、河南、陕西、广东、宁夏等
- **污水处理厂运行管理问题**：银川、固原、甘肃部分城市
- **流域水环境问题**：嘉陵江、黄河龙门段、洞庭湖、洪湖、滇池
- **黑臭水体返黑返臭**：山东菏泽、吉林长春、黑龙江哈尔滨

### 2. **大气污染防治**（约 25%）

- **大气污染防治工作推进不力**：辽宁抚顺营口、宁夏乌海、陕西咸阳、河南许昌
- **重点领域大气污染**：天津、山西、内蒙古乌海、河北唐山
- **空气质量反弹 / 下降**：江苏淮安宿迁、四川泸州内江、浙江、重庆
- **重污染天气多发**：新疆"乌昌石"区域
- **大气污染反弹严重**：湖北、湖南、辽宁

### 3. **生态破坏 / 自然保护地**（约 20%）

- **矿山生态破坏**：
  - 山西忻州、太原清徐、晋中
  - 陕西榆林、韩城
  - 内蒙古巴彦淖尔、赤峰、乌海
  - 河北承德兴隆、邯郸
  - 辽宁沈抚示范区
  - 江西新余、吉安
  - 广西玉林、岑溪
  - 西藏昌都
  - 宁夏中卫
  - 河南焦作北山、新乡辉县卫辉
  - 山东济宁
- **湿地破坏**：黑龙江齐齐哈尔、湖南洞庭湖、江西鄱阳湖
- **自然保护区破坏**：四川广元雅安、湖北九宫山、贵州铜仁、青海
- **草原生态破坏**：内蒙古通辽、青海
- **森林 / 林地破坏**：云南、海南沿海防护林、黑龙江森工集团
- **海洋生态保护**：浙江温州、广东惠州阳江、广西北海钦州、福建平潭、福建漳州
- **红树林保护不力**：海南、广西北部湾国际港务集团
- **水电开发破坏生态**：云南文山州、青海

### 4. **固体废物 / 建筑垃圾 / 危险废物**（约 12%）

- **建筑垃圾违规处置 / 倾倒**：
  - 北京平谷丰台
  - 上海、浙江杭州、江西、湖北武汉和神农架、湖南张家界永州、重庆
  - 海南海口、广东云浮
- **危险废物非法处置**：
  - 中国有色集团下属东方公司
  - 中国黄金集团
  - 黑龙江萝北县石墨园区
- **固体废物非法倾倒填埋**：广东肇庆潮州、山西
- **污泥违规处置**：宁夏吴忠、河北、四川遂宁、辽宁朝阳
- **垃圾填埋场污染**：河南新乡、湖北孝感、贵州毕节、贵州六盘水、吉林长春农安

### 5. **"两高"项目违规**（约 5%）

- **违规上马焦化项目**：山西晋中、河南汝州、贵州六盘水
- **钢铁行业违规**：河北邯郸、河北唐山
- **能耗双控不力**：广东云浮、吉林辽源、辽宁、江西九江德安
- **违规上马"两高"项目**：宁夏宁东基地、吴忠中卫石嘴山

### 6. **水资源管理**（约 3%）

- **违规取水用水**：山西晋中吕梁、内蒙古鄂尔多斯棋盘井、西藏
- **地下水超采**：河南周口
- **水资源管理粗放**：陕西宝鸡铜川、新疆玛纳斯河流域、甘肃张掖
- **水资源保护节约存在短板**：山东东营

## 五、督察红线的 5 大启示

### 1. 对**基层生态环境执法人员**的启示

- **从"事后查处"到"事前预防"**：193 个案例中超过 60% 涉及**历史遗留 / 长期失管**问题
- **从"运动式整治"到"常态化监管"**：约 30% 案例出现"屡治屡空 / 敷衍整改 / 假装整改"
- **强化"一企一档 + 闭环管理 + 全程留痕"**（参见 [[2026-06-13-MP-基层生态环境执法人员规范履职五环节]]）

### 2. 对**企业环保负责人**的启示

- **关注本行业 193 个案例中的"高频问题"**——自查自纠
- **避免"以生态修复之名违规操作"**：三门峡挖湖造景、沈阳采空区治理等案例均是
- **关注跨省督察动向**：本省案例 → 跨省案例 → 全国共性 → 制定年度合规计划

### 3. 对**园区 / 地方政府**的启示

- **污水处理厂 / 垃圾处理设施**是高频被督察点 → 必须 100% 达标运行
- **建筑垃圾 / 一般工业固废**的全流程台账是底线
- **自然保护区、湿地、海洋**红线绝对不能碰

### 4. 对**环保垂域 AI / 行业服务商**的启示

- **193 个案例 = 海量合规数据集** → 可用于训练**"督察问题预测 / 自查清单生成 / 整改方案匹配"**的垂域 AI
- 配合 [[2026-06-13-MP-环保AI-企业雨水排口标准]] 中的 60 万份文件库 + 多模型协作 + 工信部备案 AI 范式

### 5. 对**督察制度本身**的启示

- **督察从"全覆盖"到"回头看"**——已督察过的省份 + 新一轮的"回头看"
- **央企纳入督察**（中国有色集团、中国黄金集团）—— 体现督察深化
- **跨流域 / 跨省份共性问题**——需要国家层面统筹
