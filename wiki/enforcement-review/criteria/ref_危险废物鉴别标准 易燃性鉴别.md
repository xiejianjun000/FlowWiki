# 危险废物鉴别标准 易燃性鉴别

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 5085.4-2007 |
| 适用范围 | 危险废物易燃性鉴别 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物易燃性鉴别标准和试验方法。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 液态易燃 | 闪点<60°C |
| 固态易燃 | 摩擦/撞击易自发着火 |
| 气态易燃 | 常压下与空气混合易燃 |
| 试验方法 | 闭口杯闪点测定 |
| 鉴别结论 | 符合任一即具有易燃性 |

## 四、合规要点
1. 易燃性测试在具备防火条件实验室开展
2. 使用标准闭口杯闪点测定仪
3. 测试过程做好防火防爆措施
4. 保留试验数据和鉴别结论
