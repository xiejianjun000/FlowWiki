# 危险废物浸出毒性鉴别技术细则

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 5085.3附录 |
| 适用范围 | 浸出毒性鉴别技术细则 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了浸出毒性鉴别的检测项目、浸出方法和限值。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 检测项目 | 40项无机和有机污染物 |
| 浸出方法选择 | 按废物特性和处置方式确定 |
| 铅限值 | 5mg/L |
| 镉限值 | 1mg/L |
| 总铬限值 | 15mg/L |

## 四、合规要点
1. 根据废物特性选择浸出方法
2. 检测项目覆盖特征污染物
3. 浸出液检测数据完整
4. 鉴别结论指导处置方式选择
