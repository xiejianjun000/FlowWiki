# 危险废物焚烧残渣处置技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1134-2020 |
| 适用范围 | 焚烧残渣处置 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧残渣的处置技术和管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 残渣特性 | 需鉴别是否为危废 |
| 处置方式 | 危废→安全填埋；非危废→综合利用 |
| 热灼减率 | ≤5% |
| 鉴别要求 | 按GB 5085鉴别 |
| 台账管理 | 记录产生量、处置去向 |

## 四、合规要点
1. 残渣按规定进行危险废物鉴别
2. 危废残渣安全填埋处置
3. 非危废残渣合理利用
4. 建立残渣处置台账
