# 危险废物转移车辆技术要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 13392-2005 |
| 适用范围 | 转移车辆技术要求 |
| 发布机关 | 交通运输部 |

## 二、主要内容
规定了危险废物转移车辆的技术要求和标识。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 车辆资质 | 具备危险货物运输资质 |
| 车辆类型 | 厢式货车或罐式车辆 |
| 安全设施 | 灭火器、防泄漏装置、GPS |
| 车辆标识 | 危险货物运输标识 |
| 检验要求 | 每年检验一次 |

## 四、合规要点
1. 使用具备资质的危险货物运输车辆
2. 车辆安全设施完备有效
3. 车辆标识清晰醒目
4. 车辆定期检验合格
