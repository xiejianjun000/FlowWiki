# 污染源现场监察

## 概念定义

生态环境部门对**单一污染源**（企业、园区、设施）开展的入厂现场监督检查行为，核心是发现违法排污线索、识别环境违法行为、固定证据。

## 核心方法论（喻旗体系）

### 1. 现场监察四字诀："看、听、问、测"

| 环节 | 关键动作 |
|---|---|
| 看 | 一看卫星图片；二看纳污环境；三看进排污口；四看污染治理工艺、装备与运行；五看生产工艺与装备；六看原辅材料；七看环境管理 |
| 听 | 听操作人员介绍；听周边群众的意见与建议 |
| 问 | 询问关键问题；注意询问技巧 |
| 测 | 选准监测因子、测准每个样品、程序不出错误 |

### 2. 七看排查法（速查生态环境问题）

- **一看卫星照片**（前期准备，找线索）
- **二看纳污环境**（水文地质 + 气象 + 周边植被）
- **三看进排污口**（水质、水量、藻类微生物、偷排设施、在线监控）
- **四看污染治理**（判断是否假运行）
- **五看生产工艺**（规模、工艺、装备、污染物性质）
- **六看原辅材料**（资源分布、燃料/原料来源与含量）
- **七看环境管理**（环评/排污许可/运行记录/污泥去向）

### 3. 排污者六大类作弊方式

1. 利用在线监测设施作弊
2. 各种类型的偷排
3. 稀释排放
4. 采用"循环利用"等方式"零排放"规避监管
5. "小马拉大车"或"大马拉小车"
6. 用各种假资料数据作弊

> **金句**：作弊方式永远遵循"最省钱、最省力、最省事、最安全"的规律。

### 4. 在线监测作弊四子手段

- 采样子系统作弊（企业可独立完成）
- 分析子系统作弊（需设备厂商/运营商配合）
- 数据采集和通讯子系统作弊
- 修改含氧量、过剩系数、温度等计算参数

## 现代监察技术（"技防"）

| 技术 | 用途 |
|---|---|
| 卫星照片 | 寻找违法排污口线索 |
| 无人机 / 无人船 | 搜索目标、抵近取证、采样监测 |
| 红外成像（夜视仪） | 偷排废水（温差/反应热）、偷排废气（设施运行） |
| 快速监测（VOC 质谱、车载 ICP-MS、XRF） | 秒级现场分析 |
| 机船联用 | 无人机红外定位 + 无人船采样 |
| 声呐探测 | 禁飞区、水下/地下暗管 |
