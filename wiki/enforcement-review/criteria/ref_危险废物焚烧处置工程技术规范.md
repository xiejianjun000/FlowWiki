# 危险废物焚烧处置工程技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 176-2020 |
| 适用范围 | 焚烧处置工程设计建设 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧处置工程的总体设计、工艺和设备要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 焚烧炉型 | 回转窑、液体喷射炉、固定床等 |
| 燃烧温度 | ≥1100°C |
| 烟气停留时间 | ≥2秒 |
| 过剩空气系数 | 1.5-2.5 |
| 助燃燃料 | 天然气、轻柴油等清洁燃料 |

## 四、合规要点
1. 焚烧炉型与废物特性匹配
2. 燃烧温度和停留时间满足要求
3. 配置完善的烟气净化系统
4. 建立运行管理规程
