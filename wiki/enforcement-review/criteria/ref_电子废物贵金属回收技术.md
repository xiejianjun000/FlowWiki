# 电子废物贵金属回收技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 527-2010附录 |
| 适用范围 | 贵金属回收 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了电子废物贵金属回收的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 含贵金属电子废物 |
| 回收工艺 | 火法冶金、湿法冶金 |
| 贵金属种类 | 金、银、钯、铂等 |
| 回收率 | ≥95% |
| 污染防治 | 防止二次污染 |

## 四、合规要点
1. 采用先进工艺回收贵金属
2. 回收率达到标准要求
3. 处理过程防止二次污染
4. 建立贵金属回收档案
