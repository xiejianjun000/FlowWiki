# 湖南湘中博一检测技术有限公司_环境违法案件案卷

关于湖南湘中博一检测技术有限公司
环境违法案件现场核查及立案情况的报告
一、案件来源及背景
根据生态环境部调研交办问题清单，2026年5月20日，生态环境部大气司行业处联合湖南省生态环境厅对冷水江钢铁有限责任公司（以下简称“冷钢”）开展现场检查。在检查过程中，发现冷钢委托的第三方检测公司——湖南湘中博一检测技术有限公司（以下简称“湘中博一”）在承担冷钢自行监测任务中存在多项违法行为。威底市生态环境支队联合省厅专家组成调查组，对该公司涉嫌环境违法问题开展现场核查。
本次核查主要针对《生态环境部调研冷水江钢铁有限责任公司交办问题整改调度清单》中列明的相关问题，重点包括：自行监测报告造假、烟气测试不规范等环境违法行为。
二、当事人基本情况
当事人：湖南湘中博一检测技术有限公司
统一社会信用代码：91431300344682316A
法定代表人：廖兰平
住所：湖南省威底市威星区紫鹊界路与富厚街交叉口西北角1号
案由：涉嫌违反《生态环境监测条例》案
三、现场核查情况
（一）自行监测报告造假问题
现场查看企业自行监测报告（编号BYCJ260110161），烧结脱硫废气（DA048）氟化物监测原始记录及监测报告中有氧含量测试结果（涉及到折算），但没有烟气测试打印小票，也没有氧含量校准记录。第三方检测公司（湘中博一）也未在该仪器上找到相关记录，涉嫌编造氧含量测试数据。
（二）烟气测试不规范问题
1. 现场查看企业自行监测报告（编号BYCJ260110161），DA063等6个排气筒烟气测试未按照HJ/T397-2007规定，在一小时内等时间间隔采集3~4个样品，并计算均值，而是在2个小时内采集了3个样品，不符合标准规定。
2. 现场查看1#石灰窑比对监测报告（编号ZYJC-JCC-HJJC-T-2026-2051），颗粒物空白样品称重记录显示采样嘴型号为10mm，但采样记录中显示为8mm，两者不一致，5#高炉出铁场、1#石灰窑存在同样情形，造成颗粒物采样体积存在偏差，监测结果失真。
四、违法事实认定
经现场核查，湘中博一存在以下违法行为：
1. 自行监测报告造假。该公司在承担冷钢烧结脱硫废气（DA048）氟化物监测任务中，监测报告中有氧含量测试结果，但无烟气测试打印小票和氧含量校准记录，且第三方检测公司未在相关仪器上找到记录，涉嫌编造氧含量测试数据。
2. 烟气测试不规范。DA063等6个排气筒烟气测试未按照HJ/T397-2007规定采集样品；1#石灰窑比对监测报告中采样嘴型号记录与称重记录不一致，导致监测结果失真。
上述行为涉嫌违反了《生态环境监测条例》第二十五条第五项的规定。
五、证据锁定情况
调查组已对以下证据进行固定和锁定：
1. 自行监测报告（编号BYCJ260110161）原件；
2. 烧结脱硫废气（DA048）氟化物监测原始记录；
3. 1#石灰窑比对监测报告（编号ZYJC-JCC-HJJC-T-2026-2051）；
4. 现场检查记录及相关人员询问笔录；
5. 生态环境部调研交办问题整改调度清单。
六、立案依据
根据《生态环境监测条例》第二十五条第五项的规定，第三方检测机构未按照规定开展监测活动，或者编造、篡改监测数据的，由负责调查核查的部门责令改正，并处二万元以上五万元以下罚款；情节严重的，处五万元以上二十万元以下罚款。
同时，根据《中华人民共和国环境保护法》第六十五条的规定，环境监测机构以及从事环境监测设备维护、运营的机构或个人，有下列行为之一的，由县级以上人民政府环境保护主管部门责令改正，处二万元以上五万元以下罚欻：（三）篡改、伪造监测数据，或者开展监测活动时弄虚作假的。
湘中博一上述行为符合立案条件，建议依法立案查处。
七、处理建议
1. 建议对湘中博一环境违法行为正式立案，开展进一步调查取证；
2. 约谈湘中博一相关责任人，核实自行监测报告真实性，依法处理责任主体；
3. 调取原始检测记录和仪器日志，进一步固定违法证据；
4. 责令冷钢重新委托有资质的检测机构开展监测；
5. 依据《生态环境监测条例》第二十五条第五项规定，依法作出行政处罚决定。
八、下一步工作计划
1. 完成案情询问，形成完整的询问笔录；
2. 调取湘中博一原始检测记录及仪器日志，进一步固定违法证据；
3. 整理完善案卷材料，依法作出行政处罚决定；
4. 督促冷钢重新委托有资质检测机构开展监测，确保监测数据真实可靠。
