# 造纸企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国造纸协会发〔2022〕7号 |
| 适用范围 | 制浆、造纸、纸板及纸制品生产企业 |
| 发布机关 | 中国造纸协会 |
| 实施日期 | 2022-07-01 |

## 二、主要内容
本指南针对造纸企业特点，重点识别蒸煮、漂白、筛选、造纸机等关键设备清洁生产潜力。强调封闭筛选、ECF/TCF漂白、白水回收、碱回收。涵盖化学浆、机械浆、废纸浆审核重点。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨浆能耗、水耗、COD |
| 审核 | 蒸煮、漂白、纸机 |
| 方案筛选 | 白水回收+中段水回用 |
| 高费方案 | 漂白工艺升级 |
| 实施验证 | 节水+减排 |
| 持续改进 | 闭路循环水 |

## 四、合规要点
1. 化学浆企业应配套碱回收装置。
2. 应采用ECF或TCF漂白工艺替代元素氯。
3. 造纸机应配套白水回收装置。
4. 中段水回用率不低于70%。
