# 一般工业固体废物管理台账制定指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1200-2021 |
| 适用范围 | 产生一般工业固体废物的单位台账管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
明确了一般工业固废产生、收集、贮存、利用、处置各环节台账记录要求，规范数据采集和报送。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 记录频次 | 按月汇总，按季报送 |
| 记录内容 | 种类、数量、流向、利用处置方式 |
| 保存期限 | 不少于5年 |
| 数据来源 | 地磅、计量器具、合同凭证 |
| 台账格式 | 电子台账为主，纸质台账备查 |

## 四、合规要点
1. 建立规范的固废台账记录制度并指定专人负责
2. 确保数据真实、完整、可追溯
3. 按时报送至固体废物管理信息系统
4. 定期核对台账与实际产生情况
