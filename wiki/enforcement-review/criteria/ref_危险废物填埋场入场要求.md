# 危险废物填埋场入场要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18598-2019第6章 |
| 适用范围 | 填埋场入场要求 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场废物入场标准和检测要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 入场检测 | 浸出毒性、含水率等 |
| 浸出限值 | 符合GB 5085.3 |
| 含水率 | ≤60% |
| 稳定化要求 | 需经预处理稳定化 |
| 禁止废物 | 医疗废物、反应性废物等 |

## 四、合规要点
1. 入场废物经检测符合标准
2. 废物稳定化预处理后入场
3. 禁止不符合要求的废物入场
4. 保留入场检测记录
