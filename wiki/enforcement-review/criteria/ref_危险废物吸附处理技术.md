# 危险废物吸附处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014第6.2条 |
| 适用范围 | 吸附处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物吸附处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 含有机物废液、含金属废液 |
| 吸附剂 | 活性炭、沸石、树脂 |
| 吸附效率 | ≥90% |
| 吸附剂再生 | 热再生或化学再生 |
| 废吸附剂 | 按危废处置 |

## 四、合规要点
1. 选择高效适用的吸附剂
2. 定期更换或再生吸附剂
3. 废吸附剂按危废处置
4. 监测出水污染物含量
