# 废矿物油物化处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014附录 |
| 适用范围 | 废矿物油物化处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废矿物油物化处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 废润滑油、废液压油 |
| 处理工艺 | 沉降+酸碱精制+白土精制 |
| 再生基础油 | 符合产品标准 |
| 综合利用 | 再生利用优先 |
| 残渣处置 | 按危废处置 |

## 四、合规要点
1. 废矿物油优先再生利用
2. 再生基础油符合产品标准
3. 处理过程防止二次污染
4. 残渣按危废规范处置
