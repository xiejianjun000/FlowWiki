# 尾矿污染环境防治管理办法 — 执法判据

## 行政处罚条款

| 条号 | 违法行为 | 处罚方式 | 法定幅度 |
|------|---------|---------|---------|
| 第三十条 | 未建立尾矿环境管理台账并如实记录 | 依照固废法/水法/土壤法处罚 | 按上位法幅度 |
| 第三十条 | 超过水污染物排放标准排放水污染物 | 依照固废法/水法/土壤法处罚 | 按上位法幅度 |
| 第三十条 | 未依法报批环评擅自开工建设 | 依照固废法/水法/土壤法处罚 | 按上位法幅度 |
| 第三十条 | 未按规定开展土壤和地下水环境监测 | 依照固废法/水法/土壤法处罚 | 按上位法幅度 |
| 第三十条 | 未依法开展突发环境事件应急处置 | 依照固废法/水法/土壤法处罚 | 按上位法幅度 |
| 第三十条 | 擅自倾倒/堆放/丢弃/遗撒尾矿 | 依照固废法/水法/土壤法处罚 | 按上位法幅度 |
| 第三十一条 | 未按时填报上一年度相关信息 | 责令改正+警告；拒不改正处3万元以下罚款 | 0-3万元 |
| 第三十二条 | 向环境排放尾矿水未设置排放口标志 | 责令改正+警告；拒不改正处5万元以下罚款 | 0-5万元 |
| 第三十三条 | 未按要求开展污染隐患排查治理 | 责令改正+警告；拒不改正处10万元以下罚款 | 0-10万元 |

## 刑事衔接条款

本办法未直接规定刑事衔接条款。擅自倾倒、堆放尾矿造成严重污染的，依据《刑法》第三百三十八条污染环境罪追究刑事责任。

## 程序性条款

| 条号 | 内容摘要 |
|------|---------|
| 第五条 | 尾矿库实行分类分级环境监督管理（一级/二级/三级） |
| 第七条 | 环境管理台账保存>=5年，运营管理单位台账永久保存 |
| 第九条 | 禁止在生态保护红线/永久基本农田/河道行洪区等区域建尾矿库 |
| 第十四条 | 实行排污许可管理的单位应申请取得排污许可证 |
| 第十七条 | 尾矿水优先返回选矿使用；排放须达标，不得与库外雨水混合排放 |
| 第十九条 | 排放期间每月至少1次水污染物监测；排放有毒有害物的每季度对受纳水体监测 |
| 第二十条 | 每年汛期前至少1次全面污染隐患排查 |
| 第二十二条 | 应编制/修订/备案突发环境事件应急预案 |
| 第二十八条 | 一级和二级尾矿库运营管理单位应列入重点排污单位名录 |

## 执法要点

1. **分类分级**：省级确定清单，市级实施管理；一级二级纳入重点排污单位
2. **台账管理**：关注台账保存年限和填报及时性（每年1月31日前填报上一年度信息）
3. **尾矿水排放**：须设排放口标志+安装流量计+视频监控；记录保存>=5年、视频>=3个月
4. **隐患排查**：汛期前全面排查是硬要求，是执法检查必查项
5. **封场后监管**：渗滤液设施运行至连续两年无渗滤液产生或稳定达标；地下水监测至下游连续两年不超标
