# 医疗废物利器盒技术要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 26994-2011附录 |
| 适用范围 | 医疗废物利器盒 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了医疗废物利器盒的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 材质 | 耐穿刺硬质材料 |
| 容量 | 1L-20L多种规格 |
| 颜色 | 黄色 |
| 标识 | 医疗废物标识+利器警告 |
| 性能要求 | 防穿刺、密封、不可再开 |

## 四、合规要点
1. 使用符合标准的利器盒
2. 利器盒防穿刺密封可靠
3. 利器直接放入不可取出
4. 装满3/4时封闭更换
