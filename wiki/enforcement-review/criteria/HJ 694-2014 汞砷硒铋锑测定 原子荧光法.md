## HJ 694-2014 水质 汞、砷、硒、铋和锑的测定 原子荧光法

### 一、标准基本信息

- **标准号**：HJ 694-2014
- **实施日期**：2014年12月1日

### 二、方法原理

在酸性条件下，汞被硼氢化钾还原为原子态汞，由载气带入原子化器，用原子荧光光谱仪测定。

### 三、适用范围

- 汞检出限：0.06 μg/L
- 砷检出限：0.3 μg/L
- 硒检出限：0.4 μg/L
- 铋检出限：0.2 μg/L
- 锑检出限：0.3 μg/L

### 四、仪器设备

- 原子荧光光谱仪
- 汞、砷、硒高强度空心阴极灯
- 电热板

### 五、试剂

- 硼氢化钾溶液（10 g/L）
- 硫脲-抗坏血酸溶液
- 盐酸（优级纯）
- 标准溶液

### 六、分析步骤

1. 取水样50 mL
2. 加入5 mL HNO₃+1 mL HClO₄
3. 电热板加热消解至近干
4. 加入5 mL盐酸溶解残渣
5. 加入10 mL硫脲-抗坏血酸
6. 加水定容至50 mL
7. 上机测定

### 七、结果计算

```
C(mg/L) = (A - A₀) × f
```

### 八、质量保证

- 全程序空白
- 平行样偏差：≤10%
- 加标回收率：85-115%

### 九、对企业环保启示

1. 重金属为剧毒污染物
2. 重点行业：电镀、有色冶炼、化工
3. 原子荧光法灵敏度高
