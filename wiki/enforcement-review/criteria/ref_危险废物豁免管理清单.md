# 危险废物豁免管理清单

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 部令第23号附录 |
| 适用范围 | 危险废物豁免管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了部分危险废物在特定环节的豁免管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 豁免环节 | 收集、运输、利用、处置 |
| 豁免条件 | 满足特定条件方可豁免 |
| 豁免内容 | 仅豁免特定环节的许可证要求 |
| 清单动态调整 | 随名录修订同步更新 |
| 不豁免情形 | 环境保护责任不豁免 |

## 四、合规要点
1. 对照清单确定可豁免的废物
2. 满足豁免条件方可享受豁免
3. 豁免不等于免责，仍需规范管理
4. 保留豁免管理相关记录
