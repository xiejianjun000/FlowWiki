# 医疗废物微波处置技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ/T 229-2006 |
| 适用范围 | 微波处置 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了医疗废物微波处置的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 感染性废物 |
| 微波频率 | 2450MHz |
| 处置温度 | ≥95°C |
| 处置时间 | ≥30分钟 |
| 效果验证 | 生物指示剂验证 |

## 四、合规要点
1. 微波处置参数符合规范
2. 处置效果经验证合格
3. 适用于感染性废物处置
4. 处置后废物按一般固废处理
