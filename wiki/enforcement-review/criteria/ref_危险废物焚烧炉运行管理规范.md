# 危险废物焚烧炉运行管理规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 176-2020第8章 |
| 适用范围 | 焚烧炉运行管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧炉的运行管理、操作和检修要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 运行参数 | 温度、停留时间、空气系数 |
| 操作规程 | 制定详细操作规程 |
| 检修周期 | 每年检修1次 |
| 人员配置 | 持证操作人员 |
| 记录要求 | 运行参数实时记录 |

## 四、合规要点
1. 按操作规程运行焚烧炉
2. 运行参数符合规范要求
3. 定期检修维护设备
4. 运行记录完整可追溯
