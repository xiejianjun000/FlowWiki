# 危险废物转移信息化监管平台技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1200-2021 |
| 适用范围 | 信息化监管平台 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物转移信息化监管平台的技术要求和功能。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 平台功能 | 联单管理、跟踪监控、统计分析 |
| 数据接口 | 对接全国固废信息系统 |
| 安全要求 | 等保三级以上 |
| 数据存储 | 数据保存≥10年 |
| 运行维护 | 7×24小时不间断运行 |

## 四、合规要点
1. 监管平台功能完善运行稳定
2. 数据接口与国家系统对接
3. 安全等级符合要求
4. 数据长期保存可追溯
