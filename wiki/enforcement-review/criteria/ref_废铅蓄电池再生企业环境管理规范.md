# 废铅蓄电池再生企业环境管理规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 519-2020第8章 |
| 适用范围 | 再生企业环境管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池再生企业的环境管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 管理机构 | 设置环保管理机构 |
| 管理制度 | 建立环境管理制度 |
| 人员配置 | 环保管理人员持证 |
| 台账档案 | 全过程记录 |
| 信息公开 | 定期公开环境信息 |

## 四、合规要点
1. 设置环保管理机构
2. 建立完善环境管理制度
3. 环保人员持证上岗
4. 定期公开环境信息
