# 危险废物焚烧烟气净化技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 176-2020第7章 |
| 适用范围 | 焚烧烟气净化 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧烟气净化工艺和技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 脱酸工艺 | 半干法+干法 |
| 除尘工艺 | 袋式除尘器 |
| 脱硝工艺 | SNCR/SCR |
| 二噁英控制 | 急冷+活性炭吸附 |
| 排放标准 | GB 18484 |

## 四、合规要点
1. 烟气净化工艺完善有效
2. 急冷塔控制二噁英生成
3. 活性炭吸附重金属和二噁英
4. 定期维护净化设备
