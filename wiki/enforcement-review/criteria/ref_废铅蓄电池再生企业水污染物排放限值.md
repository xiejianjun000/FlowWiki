# 废铅蓄电池再生企业水污染物排放限值

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 31570-2015 |
| 适用范围 | 水污染物排放限值 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池再生企业水污染物排放限值。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 总铅 | ≤0.5mg/L |
| 总镉 | ≤0.1mg/L |
| 总汞 | ≤0.05mg/L |
| 总砷 | ≤0.3mg/L |
| SS | ≤50mg/L |

## 四、合规要点
1. 废水处理设施完善有效
2. 水污染物排放符合限值
3. 定期监测排放水质
4. 建立排放台账
