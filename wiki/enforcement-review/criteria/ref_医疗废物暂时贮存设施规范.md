# 医疗废物暂时贮存设施规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ/T 177-2005第5章 |
| 适用范围 | 暂时贮存设施 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了医疗废物暂时贮存设施的设计和管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 选址要求 | 远离医疗区、食品加工区 |
| 建筑要求 | 防鼠、防蚊蝇、防渗漏 |
| 贮存温度 | ≤20°C（特殊废物冷藏） |
| 贮存时间 | ≤2天（5-10月），≤3天（11-4月） |
| 管理要求 | 标识、台账、专人管理 |

## 四、合规要点
1. 暂时贮存设施符合规范
2. 严格控制贮存时间
3. 专人管理建立台账
4. 定期消毒保持清洁
