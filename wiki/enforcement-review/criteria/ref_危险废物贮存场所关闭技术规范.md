# 危险废物贮存场所关闭技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18597-2023第9章 |
| 适用范围 | 贮存场所关闭 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物贮存场所关闭的程序、技术和验收要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 关闭程序 | 方案编制→审批→实施→验收 |
| 清理要求 | 废物、容器、设施全部清理 |
| 污染评估 | 土壤、地下水污染评估 |
| 风险管控 | 必要时进行风险管控或修复 |
| 验收要求 | 经生态环境部门验收合格 |

## 四、合规要点
1. 关闭前编制方案并报批
2. 清理所有废物和设施
3. 开展土壤地下水污染评估
4. 经验收合格后方可关闭
