# 危险废物回转窑焚烧技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 176-2020第6.2条 |
| 适用范围 | 回转窑焚烧技术 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物回转窑焚烧的技术要求和设计参数。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 固态、半固态、液态废物 |
| 窑体转速 | 0.2-2.0r/min可调 |
| 倾斜角度 | 1-3° |
| 焚烧温度 | 800-1000°C（二燃室≥1100°C） |
| 处理能力 | 5-100t/d |

## 四、合规要点
1. 回转窑技术适用于多种废物
2. 严格控制窑体运行参数
3. 二燃室保证完全燃烧
4. 定期检修窑体和耐火材料
