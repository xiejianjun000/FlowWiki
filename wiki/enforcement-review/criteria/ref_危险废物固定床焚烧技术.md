# 危险废物固定床焚烧技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 176-2020第6.2条 |
| 适用范围 | 固定床焚烧技术 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物固定床焚烧的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 少量固态危险废物 |
| 焚烧温度 | ≥1100°C |
| 燃烧方式 | 层状燃烧 |
| 处理能力 | ≤10t/d |
| 适用场景 | 中小企业或特殊废物 |

## 四、合规要点
1. 固定床焚烧适用于少量废物
2. 控制燃烧温度和供风
3. 定期清理炉渣
4. 适用于特殊废物处置
