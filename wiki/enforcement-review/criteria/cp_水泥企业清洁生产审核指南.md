# 水泥企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国水泥协会发〔2022〕5号 |
| 适用范围 | 新型干法水泥生产企业及协同处置固废的水泥窑 |
| 发布机关 | 中国水泥协会 |
| 实施日期 | 2022-06-01 |

## 二、主要内容
本指南针对水泥企业特点，重点识别生料磨、回转窑、水泥磨等关键设备清洁生产潜力。强调余热发电、低氮燃烧、SCR脱硝、协同处置固废能力。涵盖原燃料替代、能源梯级利用、污染物协同控制。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨熟料能耗、电耗 |
| 审核 | 回转窑、磨机重点 |
| 方案筛选 | 余热发电+脱硝 |
| 高费方案 | 协同处置改造 |
| 实施验证 | 节能+协同 |
| 持续改进 | 替代燃料 |

## 四、合规要点
1. 应配套余热发电装置。
2. 应配套SNCR或SCR脱硝装置。
3. 协同处置固废应执行HJ 662要求。
4. 粉尘应执行GB 4915超低排放要求。
