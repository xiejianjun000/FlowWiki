# 危险废物柔性填埋场技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014附录 |
| 适用范围 | 柔性填埋场 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物柔性填埋场的设计、建设和运行要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 经稳定化处理的危险废物 |
| 防渗结构 | 双层人工合成材料 |
| 场区特点 | 适应地基变形 |
| 运行管理 | 与安全填埋场一致 |
| 封场要求 | 封场覆盖系统 |

## 四、合规要点
1. 柔性填埋场适应地基条件
2. 防渗系统符合双层结构要求
3. 运行管理与安全填埋场一致
4. 封场覆盖系统完善
