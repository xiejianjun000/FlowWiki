## HJ 1122-2020 排污许可证申请与核发技术规范 羽毛（绒）加工工业

### 一、标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1122-2020 |
| 发布日期 | 2020-02-28 |
| 实施日期 | 2020-02-28 |
| 发布机关 | 生态环境部 |
| 适用范围 | 羽毛（绒）加工工业排污单位 |

### 二、适用范围

本标准适用于指导羽毛（绒）加工工业排污单位填报排污许可证申请信息，指导核发机关审核确定排污许可要求。

### 三、产污环节与主要污染物

#### 3.1 主要生产单元
- 原料洗涤工序
- 脱脂工序
- 烘干除尘工序
- 分选包装工序

#### 3.2 主要污染物
- 废气：羽毛粉尘、恶臭（氨、硫化氢）
- 废水：COD、SS、氨氮、动植物油、总磷
- 固废：废羽毛渣、污泥

### 四、许可排放限值

#### 4.1 大气污染物排放限值

| 污染物 | 排放浓度限值(mg/m³) |
|--------|---------------------|
| 颗粒物 | 50 |
| 氨 | 1.5 |
| 硫化氢 | 0.06 |
| 臭气浓度 | 1000（无量纲） |

#### 4.2 水污染物排放限值（直接排放）

| 污染物 | 排放限值(mg/L) |
|--------|----------------|
| COD | 100 |
| SS | 70 |
| 氨氮 | 15 |
| 动植物油 | 10 |
| 总磷 | 1.0 |

### 五、监测要求

- 主要除尘排放口安装颗粒物在线监测
- 恶臭区域安装氨、硫化氢监测
- 废水总排口安装COD、氨氮在线监测

### 六、违法处罚依据

依据《大气污染防治法》第99条、《水污染防治法》第83条、《排污许可管理条例》第33-35条。

### 七、对企业环保合规工作的启示

1. 重点治理恶臭污染，落实异味管控
2. 加强除尘效率，避免羽毛粉尘扩散
3. 废水深度处理，提高循环利用率
4. 污泥规范处置，避免二次污染
