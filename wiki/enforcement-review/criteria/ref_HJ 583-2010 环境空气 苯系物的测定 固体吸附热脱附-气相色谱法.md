# HJ 583-2010 环境空气 苯系物的测定 固体吸附热脱附-气相色谱法

## 一、标准基本信息

- **标准号**：HJ 583-2010
- **实施日期**：2010年12月1日

## 二、方法原理

用填充有Tenax TA的采样管采集空气样品，富集苯系物。采样后加热脱附，进入气相色谱分离，用FID检测器测定。

## 三、适用范围

- 检出限：0.3 μg/m³
- 测定下限：1.2 μg/m³
- 测定上限：100 μg/m³

适用于环境空气和室内空气中苯系物测定。

## 四、测定物质

- 苯
- 甲苯
- 乙苯
- 二甲苯（邻、间、对）
- 苯乙烯
- 异丙苯

共8种苯系物。

## 五、采样方法

- 采样管：Tenax TA填充管
- 采样流量：50-200 mL/min
- 采样时间：30-60 min
- 采样体积：5-10 L

## 六、仪器设备

- 大气采样器
- 热脱附装置
- 气相色谱仪（带FID检测器）
- 色谱柱：DB-1或DB-5（30m×0.25mm×0.25μm）

## 七、分析条件

### 7.1 热脱附条件
- 脱附温度：280°C
- 脱附时间：10 min
- 冷阱温度：-30°C
- 冷阱加热：300°C

### 7.2 色谱条件
- 进样口温度：200°C
- 检测器温度：250°C
- 升温程序：40°C保持5min → 5°C/min → 100°C → 10°C/min → 220°C保持2min

## 八、结果计算

```
C = (A样 - A空) × m标 / (A标 × V)
```

## 九、质量保证

- 采样管空白
- 平行样偏差：≤15%
- 加标回收率：80-120%

## 十、对企业环保合规启示

1. 苯系物为重点管控VOCs
2. 涉苯企业应定期监测厂界苯系物
3. 选择合格采样管并保证空白
