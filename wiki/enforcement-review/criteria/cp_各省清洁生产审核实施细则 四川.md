# 各省清洁生产审核实施细则 四川

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 川发改规〔2023〕7号 |
| 适用范围 | 四川省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 四川省发展和改革委员会、四川省生态环境厅 |
| 实施日期 | 2023-08-15 |

## 二、主要内容
四川省实施细则结合长江黄河上游生态屏障建设，强化攀西钒钛、川南化工、川东北天然气化工等特色产业集群审核要求。建立成渝地区双城经济圈清洁生产审核互认机制。

## 三、清洁生产技术要求
| 阶段 | 四川特色要求 |
|------|-------------|
| 名单确定 | 双超双有+长江黄河上游 |
| 特色产业 | 钒钛、化工、天然气化工 |
| 成渝双城 | 经济圈结果互认 |
| 高海拔 | 资源化利用优先 |
| 资金支持 | 西部大开发资金 |

## 四、合规要点
1. 长江黄河上游企业审核应突出水土保持和生物多样性保护。
2. 攀西钒钛企业审核应包含钛渣、钒渣综合利用内容。
3. 成渝地区双城经济圈审核结果互认。
4. 西部大开发税收优惠与审核通过情况挂钩。
