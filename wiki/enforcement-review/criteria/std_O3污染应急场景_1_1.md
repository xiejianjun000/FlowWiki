# O3污染应急场景

## 适用
O₃ 日最大 8h（MDA8）> 160 μg/m³（轻度）及以上光化学污染预警/应急。

## 关键判据（来自 raw/ 真实判据）
- O₃ 分级：160–200 轻度 / 200–250 中度 / >250 重度。
- 气象高风险：温度 > 28℃ 且 RH < 60%；白天 NO₂/NO > 29。
- 风速 < 1.0 m/s 本地累积；> 2.25 m/s 区域传输贡献显著。

## 应急标准流程
1. **研判**：[[O3敏感性诊断]] 判定 VOCs / NOx / 协同控制区。
2. **溯源**：[[特征比值法]] + 风向玫瑰图 + 前体物（[[VOCs]]/[[NO2]]）来源。
3. **管控**：VOCs 区控溶剂/餐饮/工业有机；NOx 区控机动车/工业炉窑（[[DB43-3082-2024]]）。
4. **评估**：[[市州级溯源场景]] 闭环。

## 湖南要点
- 夏季长株潭偏 VOCs/协同，需 VOCs+NOx 协同减排（5:1 削减比类比）。
- 移动源电动化后注意"滴定≠改善"效应（Ox 框架）。
