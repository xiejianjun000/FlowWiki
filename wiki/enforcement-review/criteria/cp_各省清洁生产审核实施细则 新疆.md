# 各省清洁生产审核实施细则 新疆

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 新发改规〔2023〕6号 |
| 适用范围 | 新疆维吾尔自治区行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 新疆维吾尔自治区发展和改革委员会、自治区生态环境厅 |
| 实施日期 | 2023-10-01 |

## 二、主要内容
新疆维吾尔自治区实施细则结合丝绸之路经济带核心区建设，重点推动石油天然气化工、煤炭煤电、有色金属、纺织等特色优势产业清洁生产升级。强化塔里木河流域、天山北坡经济带审核要求。

## 三、清洁生产技术要求
| 阶段 | 新疆特色要求 |
|------|-------------|
| 名单确定 | 丝绸之路经济带+生态敏感区 |
| 特色产业 | 石油天然气、煤化工、纺织 |
| 水资源 | 极端严格节水 |
| 跨境合作 | 中亚国家技术交流 |
| 西部开发 | 多重政策叠加 |

## 四、合规要点
1. 塔里木河流域企业审核应执行最严格节水指标。
2. 石油天然气化工企业审核应包含伴生气综合利用。
3. 煤化工企业审核应包含废水零排放要求。
4. 棉纺织企业审核应关注节水与染整清洁工艺。
