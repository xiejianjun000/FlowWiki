# 危险废物转移管理办法

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 部令第23号 |
| 适用范围 | 危险废物转移全过程管理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物转移的联单管理、电子化报送、跨省审批和监管要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 联单制度 | 电子联单为主，纸质联单备查 |
| 转移审批 | 跨省转移需生态环境部审批 |
| 转移报告 | 通过信息系统实时报告 |
| 运输要求 | 符合危险货物运输规定 |
| 法律责任 | 未按规定转移处10万-100万元罚款 |

## 四、合规要点
1. 通过信息系统办理转移联单
2. 跨省转移提前申请审批
3. 运输符合危险货物运输要求
4. 保留转移全过程凭证
