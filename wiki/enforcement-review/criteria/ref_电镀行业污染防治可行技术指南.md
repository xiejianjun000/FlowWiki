# 电镀行业污染防治可行技术指南

## 一、基本信息

| 项目 | 内容 |
|------|------|
| 适用范围 | 电镀、化学镀、阳极氧化 |
| 发布机关 | 生态环境部 |

## 二、主要污染源
- 酸雾：HCl、H₂SO₄、HNO₃、HF、CrO₃
- 含氰废气：HCN
- 重金属废水：Cr⁶⁺、Ni、Cu、Zn、CN⁻
- 危废：含铬污泥、含氰废液（HW17、HW33）

## 三、可行污染防治技术

| 污染源 | 推荐技术 | 去除效率 |
|--------|----------|----------|
| 酸雾 | 网式净化器+碱液喷淋 | ≥95% |
| 含氰废气 | 次氯酸钠氧化喷淋 | ≥98% |
| 含铬废水 | 化学沉淀+离子交换 | ≥99% |
| 含氰废水 | 碱性氯化氧化 | ≥99% |
| 重金属污泥 | 危废规范处置 | - |

## 四、排放限值

| 污染物 | 排放限值(mg/L) |
|--------|----------------|
| 总铬 | 1.0 |
| 六价铬 | 0.2 |
| 总镍 | 0.5 |
| 总氰化物 | 0.2 |

## 五、合规要点

1. 含铬、含氰废水分质处理
2. 推行无氰电镀、三价铬钝化
3. 危废规范贮存与处置
