# 危险废物贮存场所设计技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2025-2012 |
| 适用范围 | 危险废物贮存场所设计 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物贮存场所的总体布局、建筑设计、设施配置等要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 场所容量 | 满足最大贮存量的1.2倍 |
| 建筑结构 | 钢筋混凝土结构，防腐蚀 |
| 通风设施 | 强制通风换气≥6次/小时 |
| 导流设施 | 设置导流沟和收集池 |
| 消防设施 | 按GB 50016配置 |

## 四、合规要点
1. 设计阶段充分考虑防腐蚀和防渗
2. 配置完善的通风和导流设施
3. 消防设施符合规范要求
4. 设计文件经审查后实施
