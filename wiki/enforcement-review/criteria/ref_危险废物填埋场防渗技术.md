# 危险废物填埋场防渗技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18598-2019第6章 |
| 适用范围 | 填埋场防渗 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场防渗系统的设计和施工要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 防渗结构 | 双层人工合成材料+黏土层 |
| HDPE膜厚度 | ≥2.0mm |
| 黏土层厚度 | ≥0.75m，K≤1.0×10⁻⁷cm/s |
| 渗漏检测 | 设置渗漏检测层 |
| 施工质量 | 焊接、检验符合规范 |

## 四、合规要点
1. 防渗系统符合双层结构要求
2. HDPE膜焊接质量经检测合格
3. 黏土层渗透系数满足要求
4. 渗漏检测系统有效运行
