# 危险废物焚烧在线监测技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 76-2017 |
| 适用范围 | 焚烧在线监测 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧设施在线监测系统的安装、运行和管理。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 监测项目 | SO₂、NOx、CO、O₂、烟尘 |
| 采样位置 | 烟囱或烟道 |
| 数据传输 | 实时传输至监管平台 |
| 校准要求 | 每天自动校准，每月人工校准 |
| 运行率 | ≥95% |

## 四、合规要点
1. 安装在线监测系统并联网
2. 监测数据实时传输
3. 定期校准保证数据准确
4. 系统运行率符合要求
