# 危险废物焚烧飞灰处置技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1134-2020 |
| 适用范围 | 焚烧飞灰处置 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧飞灰的处置技术和管理要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 飞灰特性 | 危废（含二噁英、重金属） |
| 稳定化处理 | 水泥固化、化学稳定化 |
| 处置方式 | 安全填埋 |
| 豁免条件 | 经处理后符合GB 16889可卫生填埋 |
| 管理要求 | 按危废管理，台账记录 |

## 四、合规要点
1. 飞灰按危废规范管理
2. 稳定化处理后检测达标
3. 符合条件方可卫生填埋
4. 建立飞灰处理处置台账
