# 危险废物贮存场所防渗技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18597-2023第6章 |
| 适用范围 | 贮存场所防渗 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物贮存场所防渗层的设计、施工和验收要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 天然基础层 | 厚度≥0.75m，K≤1.0×10⁻⁷cm/s |
| 人工合成材料 | HDPE膜厚度≥2.0mm |
| 防渗层结构 | 天然+人工复合防渗 |
| 渗漏检测 | 设置渗漏检测层 |
| 施工质量 | 焊接、检验符合规范 |

## 四、合规要点
1. 防渗层设计施工符合规范
2. HDPE膜焊接质量经检测合格
3. 设置渗漏检测系统
4. 防渗工程验收合格后投入使用
