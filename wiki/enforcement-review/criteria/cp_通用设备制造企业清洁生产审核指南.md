# 通用设备制造企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国机械工业联合会发〔2022〕8号 |
| 适用范围 | 锅炉、泵、阀门、压缩机、轴承等通用设备制造企业 |
| 发布机关 | 中国机械工业联合会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对通用设备制造企业特点，重点识别铸造、机械加工、装配等关键工序清洁生产潜力。强调粉末涂料、切削液回用、废金属回收、低噪声工艺。涵盖粉尘、VOCs、废油审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万元产值VOCs、粉尘 |
| 审核 | 铸造、机械加工 |
| 方案筛选 | 粉末涂料+切削液回用 |
| 高费方案 | 铸造升级 |
| 实施验证 | 减排+综合利用 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 铸造工序应配套除尘装置，粉尘回收回用。
2. 机械加工应使用长寿命切削液并循环过滤。
3. 涂装应优先使用粉末涂料或水性涂料。
4. 边角料、废金属应回收综合利用。
