# 废旧显示器回收处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 527-2010附录 |
| 适用范围 | 显示器回收处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废旧显示器回收处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | CRT显示器、液晶显示器 |
| 处理工艺 | 拆解+分选+回收 |
| 特殊处理 | 含汞背光源单独处理 |
| 资源回收 | 玻璃、塑料、金属回收 |
| 污染防治 | 防止二次污染 |

## 四、合规要点
1. 显示器分类拆解处理
2. 含汞部件单独处理
3. 资源分类回收利用
4. 处理过程防止污染
