# 医疗废物处置职业健康监护

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GBZ 188-2014 |
| 适用范围 | 职业健康监护 |
| 发布机关 | 国家卫生健康委 |

## 二、主要内容
规定了医疗废物处置人员职业健康监护要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 监护对象 | 处置单位从业人员 |
| 体检类型 | 上岗前、在岗、离岗、应急 |
| 体检项目 | 常规项目+病原微生物检测 |
| 体检频次 | 每年1次 |
| 档案管理 | 一人一档 |

## 四、合规要点
1. 从业人员定期职业体检
2. 建立职业健康监护档案
3. 异常情况及时处理
4. 应急情况开展应急体检
