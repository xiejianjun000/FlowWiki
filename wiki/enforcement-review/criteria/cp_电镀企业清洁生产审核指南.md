# 电镀企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国表面工程协会发〔2022〕5号 |
| 适用范围 | 专业电镀企业及含电镀工序的工业企业 |
| 发布机关 | 中国表面工程协会 |
| 实施日期 | 2022-06-15 |

## 二、主要内容
本指南针对电镀企业特点，重点识别镀槽、漂洗槽、回收槽等关键环节清洁生产潜力。强调无毒低毒工艺替代、逆流漂洗、溶液回收、重金属分类处理。涵盖审核重点部位识别、方案筛选、效益验证全过程。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 镀层金属利用率、耗水强度 |
| 审核 | 镀槽、漂洗槽重点 |
| 方案筛选 | 逆流漂洗+溶液回收 |
| 高费方案 | 工艺替代（三价铬等） |
| 实施验证 | 重金属减排+节水 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 应优先采用三价铬替代六价铬工艺。
2. 含氰、含铬、含镍废水应分类处理。
3. 逆流漂洗装置应配套建设。
4. 镀槽废液应作为危险废物处置。
