# 危险废物填埋场气体收集处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014第7章 |
| 适用范围 | 填埋场气体收集处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场气体的收集和处理技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 气体成分 | CH₄、CO₂、VOCs、H₂S |
| 收集系统 | 导气井+收集管道 |
| 处理方式 | 火炬燃烧、综合利用 |
| 监测要求 | 气体浓度定期监测 |
| 安全措施 | 防爆、防中毒 |

## 四、合规要点
1. 配置气体收集处理系统
2. 定期监测气体浓度
3. 防爆措施落实到位
4. 气体处理符合环保要求
