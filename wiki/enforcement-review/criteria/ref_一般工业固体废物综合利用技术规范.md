# 一般工业固体废物综合利用技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1097-2020 |
| 适用范围 | 一般工业固废的综合利用活动 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了一般工业固废用于建材生产、道路工程、土地利用等综合利用途径的技术要求和污染控制措施。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 综合利用途径 | 建材原料、道路基材、土壤改良等 |
| 有害物质限值 | 符合GB 30760等相关标准 |
| 利用过程污染控制 | 废气、废水、噪声达标排放 |
| 产品质量 | 符合相应产品标准 |
| 环境风险评估 | 利用前开展环境影响分析 |

## 四、合规要点
1. 综合利用前进行环境风险评估
2. 建立综合利用台账并记录流向
3. 确保利用过程污染物达标排放
4. 综合利用产品符合相关质量标准
