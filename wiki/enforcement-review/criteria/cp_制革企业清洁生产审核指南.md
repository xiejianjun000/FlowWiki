# 制革企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国皮革协会发〔2022〕6号 |
| 适用范围 | 牛皮、羊皮、猪皮制革及毛皮加工企业 |
| 发布机关 | 中国皮革协会 |
| 实施日期 | 2022-07-01 |

## 二、主要内容
本指南针对制革企业特点，重点识别浸水、脱毛、鞣制、染色等关键工序清洁生产潜力。强调保毛脱毛、无铬鞣制、含铬废水分类处理、铬回收。涵盖水耗、COD、氨氮、总铬等指标审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨皮水耗、COD、铬 |
| 审核 | 鞣制、脱毛重点 |
| 方案筛选 | 无铬鞣+保毛脱毛 |
| 高费方案 | 铬回收系统 |
| 实施验证 | 减排+节水 |
| 持续改进 | 闭路水循环 |

## 四、合规要点
1. 含铬废水应单独收集处理，铬回收率不低于90%。
2. 鼓励采用无铬鞣制、保毛脱毛等清洁工艺。
3. 含铬污泥应作为危险废物处置。
4. 排放废水应执行GB 30486排放标准。
