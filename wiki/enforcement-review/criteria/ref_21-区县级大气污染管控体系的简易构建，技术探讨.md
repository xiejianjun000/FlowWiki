# 区县级大气污染管控体系的简易构建，技术探讨

应读者留言撰写
区县级精细化管控体系构建，技术探讨
—— 经验性框架
一、问题的起点
上级预报预警通常面向区域尺度，推送到区县一级时，收到的往往是“未来三天扩散条件不利，需加强管控”这样的概括性提醒。至于不利到什么程度、哪个时段最危险、本地哪种污染特征最突出、历史上类似气象条件下浓度通常会到什么水平——这些直接影响管控力度和节奏的关键细节，并不总能从上级文件里读到。这不是信息传递链条中谁的失职，而是尺度决定的信息颗粒度天然差异。
但区县恰恰是大气攻坚的执行末梢。工地扬尘管不管、重点企业限不限、洒水车几点出动——这些决策需要更精细的判断依据。好消息是，做出这种判断所需要的数据和工具，绝大部分已经公开、免费、不依赖编程基础即可上手。
本文并非操作手册，而是提供一种技术探讨的思路：没有太多技术力量的区县一级，如何在现有条件下，用公开的监测数据、气象信息和一台装着Excel的电脑，在日常工作之余，逐步搭建起对所在区县大气污染规律的认知框架，并将这种认知转化为更有针对性的管控节奏，以提升工作效率及指向性。文中涉及的机制讨论以已有研究文献为基础，数据示例为一般性说明。
二、数据从哪里来
2.1 空气质量监测数据
全国城市空气质量实时发布平台是最基础的数据源。各地生态环境局官网均可查到国控站点逐时浓度数据，包括PM2.5、PM10、O3、NO2、SO2、CO六项常规指标。部分平台支持数据导出，部分只提供网页查看——后者也不构成障碍，手动复制粘贴到Excel后整理或者让豆包等工具帮忙整理，几十天的逐时数据量并不大。
关键提醒：先确认拿到的数据是原始浓度（单位ug/m3）还是AQI分指数（无量纲）。
2.2 气象数据
气象条件决定了污染物“排出来以后去哪儿”。对区县分析最有价值的参数包括风速和风向（水平扩散能力）、温度（影响边界层发展和光化学反应速率）、相对湿度（影响二次颗粒物生成）、边界层高度（BLH, Boundary Layer Height，污染物垂直扩散空间的“天花板”），以及降雨信息。
其中BLH可能是最不直观但对污染浓度解释力最强的参数。BLH即大气的“呼吸深度”——白天太阳加热地面，热对流将边界层顶推至800甚至1500米，污染物被搅匀在一个很深的空间里；夜间地面辐射冷却，边界层塌缩到一两百米甚至不足百米，同等排放量被压在一个极薄的气层内。已有研究表明BLH从800米压缩至200米时，PM2.5浓度的响应远不止线性4倍，往往达到6—8倍，因为存在气溶胶辐射反馈（Aerosol-Radiation Feedback, ARF）等非线性放大机制。
气象数据来源：当地气象局常规观测）、或生态环境监测站自有气象站。站点与空气质量监测点越近，数据匹配性越好。如果缺乏BLH直接观测，可通过温度廓线等渠道间接获取。

2.3 排放源信息与管控台账
这是区县环保的“主场优势”。辖区内几家重点企业、哪条路扬尘严重、哪个工地正在施工、什么季节焚烧高发——这些信息虽难以量化为精确排放清单，但作为定性背景，在解释数据异常和制定管控方案时极为关键。将它们记录在一个简单的Excel台账中——日期、事件、位置——日积月累就是一笔不可替代的本地知识库。
三、回头看：从历史数据中提取本地规律
有了数据之后，第一件值得做的事情不是预测，而是回看。将所在站点过去一到两年的逐日、逐时数据拉进Excel，做三件“基础功课”。
3.1 画出全年的季节节律
按月汇总PM2.5和O3日均值，画一条全年曲线。几乎一定能看到清晰的季节交替——PM2.5秋冬偏高、春夏回落；O3反过来，春末夏初爬升、秋冬几乎消失。当这条曲线具体到本地站点时，几个关键节点会变得精确：PM2.5的“攻坚起始月”、O3的“抬头月”，以及两者交叉重叠的“复合污染过渡期”。
大量观测研究表明，在华北、长三角、中部等区域的春季过渡期（通常3—5月），O3-8h已多日可超过WHO指导值100 ug/m3，同时PM2.5夜间仍频繁突破限值。这种“白天臭氧午后冲顶、深夜颗粒物封顶”的日内切换，是复合污染的典型特征。掌握本地进入这一窗口的时间点，就是精细化管控的第一步。
3.2 拆出24小时“呼吸节律”
将一段时间的逐时数据按小时取平均，画出PM2.5、O3、NO2的24小时平均曲线。这条曲线是污染的“日变化指纹”——它会告诉几个核心信息：PM2.5在几点开始累积、几点达峰、几点回落；O3在几点起攀、几点封顶；以及NO2的“午后光解谷值”出现在哪个时段。
图2  PM2.5-O3-NO2典型24小时节律与BLH联动示意
图2呈现了一种具有普遍代表性的日变化结构。PM2.5的“堆积窗口”主要在傍晚至凌晨，对应BLH塌缩和通风系数锐减。O3的“生成窗口”在午前至午后，对应太阳辐射驱动的光化学反应链。NO2在午后因光解（NO2 + hv → NO + O, O + O2 → O3）被消耗，是O3的前体物；夜间因BLH压缩和机动车排放累积而回升，又通过N2O5非均相水解路径转化为硝酸盐，成为PM2.5二次无机组分的重要来源。
这种“午后光化学”与“夜间颗粒化学”的双相过程，是同一套化学体系在24小时内的两种表达形态。对管控节奏的启示很直接：如果PM2.5的堆积主要发生在夜间，那么夜间施工管控、渣土运输管理的价值可能被低估了；如果O3的生成高峰在11—16时，那么这个时段对VOCs排放源的关注优先级应当更高。

3.3 标记“典型日”和“异常日”
翻阅历史数据时，挑出两类日子做重点标记。一类是“典型重污染日”——PM2.5日均超标的那些天，记下当日气象条件（风速、风向、温度、湿度、降雨），观察共同特征。另一类是“异常日”——气象条件看上去不太差但浓度莫名偏高的日子，或者气象条件很差但浓度没飙起来的日子。前者可能指向某个临时性本地排放源（突发工地、焚烧），后者可能说明那类气象配置下还有某种缓冲因子在起作用。
这种标记不需要统计检验，只需要Excel条件格式标红加一列备注。积累到一定量以后，对“什么条件下辖区会出问题”的判断力会显著提升。
四、找到本地的“命门”：关键气象阈值
做完基础功课之后，下一步值得尝试的是从数据中提取几个关键气象阈值。这里的“阈值”不是严格统计检验结果，而是实操意义上的经验判据——当某个气象参数越过某条线，污染态势大概率会恶化。
4.1 风速扩散阈值
在Excel中做一张散点图，X轴逐时风速、Y轴PM2.5浓度。不需要跑回归，目视即可辨识——在绝大多数城市会看到一个清晰的分界线：风速低于某个值（通常在2—3.5 m/s区间），PM2.5散点呈“高原”态，浓度普遍偏高且对风速变化不敏感；越过这个值后，浓度随风速增大近似指数衰减。
这个分界点就是该站点的“临界扩散风速”。物理含义是：当风速低于此值时，水平输送能力不足以克服近地面逆温层的垂直压制，污染物进入“静稳积累”模态，此时浓度主要由排放强度和BLH决定。已有多城市分析表明这一阈值大致在2.5—3.5 m/s区间，但具体值因地形和下垫面而异——山前城市可能偏高，平原开阔地带可能偏低。
4.2 湿度跃升阈值
类似地，将PM2.5按相对湿度分段做箱线图。大量观测研究揭示了一个共性模式：RH低于60%时PM2.5中位数处于较低水平，60%—70%略有抬升，超过70%后出现“阶梯式跃升”，80%以上进一步右移并频繁出现极端高值。
这一跃升的化学机制在于：当RH超过约65%—70%时，气溶胶颗粒的吸湿性增长变得显著，颗粒物含水量（AWC, Aerosol Water Content）快速上升，为SO2向硫酸盐的液相氧化（SO2 + H2O2 → H2SO4）和N2O5向硝酸盐的水解通道提供了反应介质。同时高湿条件下气溶胶粒径增大、消光效应增强，进一步削弱太阳辐射、抑制边界层发展，形成“高湿→化学生成加速→辐射反馈→BLH压低→浓度升高”的多环正反馈。

4.3 通风系数：综合性指标
将BLH与风速的乘积定义为通风系数VC = BLH × WS（单位m2/s），是一个简洁有效的综合扩散指标。已有研究将VC < 3000 m2/s作为“低扩散”参考阈值。从多城市数据来看，白天VC通常在2000—12000 m2/s，夜间可低至300—1500 m2/s，白夜比达3—9倍。这意味着同等排放量在夜间会产生远高于白天的地面浓度。
如果能获取逐时BLH数据，在Excel中计算逐时VC、绘制VC时间序列并标注低于3000 m2/s的时段，就能以一种非常直观的方式识别出“扩散不利窗口”。将这些窗口与历史PM2.5峰值叠合比对，可以验证VC阈值在本地的适用性并进行校准。
五、往前看：气象预报与历史规律的结合
回看历史是为了给前瞻提供依据。当积累了足够的本地规律认知（季节节律、日变化指纹、关键阈值、典型日特征）之后，就具备了将气象预报信息“翻译”为污染预判的能力。
5.1 短期预判（1—3天）
大多数城市的气象台会发布未来72小时逐时风速、温度、湿度预报。将这些预报值与已经建立的阈值体系比对，即可做出定性判断：如果未来48小时风速持续低于本地临界扩散风速、湿度升至70%以上、且无明显降雨，则PM2.5将进入“静稳积累”模态，需提前启动管控措施。如果预报显示温度跃升至20°C以上、湿度降至50%以下、风速中等，则需警惕O3午后冲高。
这种“阈值触发式”预判虽然粗糙，但在区县层面已经足够实用——它提供的不是精确浓度数值（那是数值模式的工作），而是“大概率恶化/改善”的方向性判断和“哪个时段最需要盯”的节奏信号。
5.2 季节性预研判
在每年管控季到来之前，将过去两三年同期数据做一次系统复盘：同期重污染日的气象配置分布、主导风向下的传输特征、本地排放源有无新增变化。这种复盘形成的“经验速查卡”，比等待上级部署更具主动性。
值得特别关注的是春季过渡期。大量研究表明部分城市的O3-NOx-VOCs敏感性正从典型的VOC受限向VOC-NOx共限迁移，这意味着固定的单因子优先策略可能并非最优。在O3抬头和PM2.5尚未完全退场的重叠窗口内，分时段协同的管控思路比“一刀切”更有现实依据。
六、工具层面：简易构建的话，Excel就够了
需要强调的是，上述所有分析都不依赖专业统计软件或编程能力。Excel的数据透视表、条件格式、散点图、折线图功能足以覆盖日均汇总、逐时平均、分段统计、阈值标注、VC计算等全部操作。
6.1 实操线索
逐时数据按小时取平均：用数据透视表，行标签为“小时”，值为“浓度”的平均值，即可生成24小时节律曲线。按月汇总同理，行标签换成“月份”。风速-PM2.5散点图：直接选中两列数据插入散点图，肉眼识别阈值。VC计算：新增一列“=BLH列×风速列”，然后条件格式标红低于3000 m2/s的单元格。
对于更进一步的数据整理需求——比如从网页复制粘贴的数据格式混乱、时间列格式不统一——可以利用AI工具将杂乱数据整理为标准表格后复制回Excel。这在处理非结构化数据时节省大量时间。
6.2 本地数据看板
如果条件允许，建议逐步搭建一个本地数据看板，哪怕只是一个结构化的Excel可视化工作簿，包含几个固定工作表：逐时原始数据、24小时节律曲线（按季度更新）、关键阈值表（风速、湿度、VC）、重污染日台账、管控措施记录。这个工作簿的价值在于积累——第一年可能只是定性感知，第二年开始有对比基线，第三年的判断就有了统计底气。
七、小结
以上讨论的分析框架，核心逻辑可以浓缩为一句话：排放决定“底盘”，气象决定“波动”。在排放总量短期内难以大幅改变的前提下，气象条件——特别是边界层高度、风速和相对湿度——对污染物浓度的日际和日内波动起主导调控作用。识别本地的气象敏感结构和关键阈值，是将管控从“被动响应”推向“主动预判”的关键一步。
需要指出的是，上述方法存在明确局限：它是基于统计相关性的经验方法，不能替代源解析和数值模式的定量因果推断。特别是当排放结构发生显著变化时，历史规律需要重新校准。此外，区域传输对本地浓度的贡献在许多城市占比可达30%—50%甚至更高，这部分并非区县层面可以独立控制的。
但局限不等于无效。在“没有精确工具”和“什么都不做”之间，一个基于历史数据的经验性分析框架，哪怕只能将预判准确率从50%提升到70%，对管控决策的时效性和针对性也已经有实质意义。大气攻坚的“最后一公里”，需要的不仅仅是自上而下的指令传达，也需要自下而上的规律认知。而后者的起点，或许就是一台电脑、一张Excel表、和持续积累本地数据的耐心。
