二、适用范围（第1章）
═══════════════════════════════════════════════════════════════════

本标准规定了环境空气质量评价的术语定义、评价范围、评价时段、评价项目、
评价方法及数据统计要求等内容。

适用于环境空气质量评价与管理。

评价范围包括三个层级：
1. 点位（监测站点）评价——针对某监测点位（包括城市点、区域点、背景点、
   污染监测点和交通点）所代表空间范围的评价。
2. 城市评价——针对地级及以上城市建成区的评价（县、市、区、旗参照执行）。
3. 区域评价——针对由多个城市组成的连续空间区域的评价。

（注：与2013版相比，删除了"全国范围内"的表述）

四、术语和定义（第3章）
═══════════════════════════════════════════════════════════════════

主要术语包括：

1. 环境空气质量评价：以GB 3095为依据，对某空间范围内环境空气质量进行
   的定性或定量评价过程，包括达标情况判断、变化趋势分析和质量优劣比较。

2. 点位环境空气质量评价：针对某监测点位（含城市点、区域点、背景点、
   污染监测点和交通点）所代表空间范围的评价。

3. 城市环境空气质量评价：针对地级及以上城市建成区的评价。县（市、区、旗）
   参照执行。评价方式以城市建成区内的国家环境空气质量监测点位监测结果
   为代表。

4. 区域环境空气质量评价：针对由多个城市组成的连续空间区域的评价。

5. 环境空气质量达标：污染物浓度不超过GB 3095规定的浓度限值（含过渡阶段
   限值）且符合数据统计要求。

6. 超标倍数：污染物浓度超过GB 3095对应浓度限值的倍数。

7. 达标率：点位或城市在短期评价（小时/日）中结果为达标的百分比。

8. 例外事件（新增，2026版）：不可抗力因素导致且短期内无法有效合理管控，
   致使环境空气中污染物浓度上升的事件。监测数据需标注例外事件期间，但
   统计时不剔除，纳入正常计算；若因考虑例外事件导致有效性不满足，统计
   结果仍有效。

五、评价项目（第4章）
═══════════════════════════════════════════════════════════════════

5.1 基本评价项目（6项）
┌──────────┬────────────────────────────────────────────────────┐
│ 污染物   │ 评价指标                                             │
├──────────┼────────────────────────────────────────────────────┤
│ SO₂      │ 1小时平均、日平均、年平均 + 日平均第98百分位数       │
│ NO₂      │ 1小时平均、日平均、年平均 + 日平均第98百分位数       │
│ CO       │ 1小时平均、日平均 + 日平均第95百分位数               │
│ O₃       │ 日最大8小时平均 + 日最大8小时平均第90百分位数        │
│ PM₁₀     │ 日平均、年平均 + 日平均第95百分位数                   │
│ PM₂.₅    │ 日平均、年平均 + 日平均第95百分位数                   │
└──────────┴────────────────────────────────────────────────────┘

小时评价：SO₂、NO₂、CO、O₃的1小时平均
日评价：SO₂、NO₂、CO、PM₁₀、PM₂.₅日平均，O₃日最大8小时平均
年评价：各项目的年平均及对应特定百分位数浓度

5.2 其他评价项目
包括 TSP（总悬浮颗粒物）、NOₓ（氮氧化物）、BaP（苯并[a]芘）、
Pb（铅）等。

六、评价方法（第5章）
═══════════════════════════════════════════════════════════════════

6.1 达标评价
- 以GB 3095规定的浓度限值为依据。
- 污染物浓度不超过GB 3095规定的浓度限值（含过渡阶段限值）且符合数据
  统计要求，即为达标。
- 日评价和年评价分别按对应指标进行。

6.2 多项目日综合达标率（达标天数比例）——2026版新增
新增公式A.3，日评价和年评价均需统计综合达标天数及达标率。
计算方法参见附录A.3。

6.3 变化趋势评价
- 评价周期不少于5年。
- 采用Spearman秩相关系数进行趋势判定（方法见附录B）。

6.4 三年滑动平均——2026版新增
对点位、城市、区域的污染物浓度计算前三年滑动平均值，公式见附录A.7
（式A.6）。

6.5 环境空气质量状况比较评价（附录C）
用于不同地区间环境空气质量状况的比较评价。

（1）单项指数法（2026版修订）
    Iᵢ = Cᵢ/Sᵢ
    其中：Cᵢ为污染物i的年平均或特定百分位数浓度，Sᵢ为GB 3095中
    二级标准浓度限值。
    注：2013版取年平均值与日平均特定百分位数最大值的比值，2026版
    简化为直接比值。

（2）综合指数法（2026版增加权重因子）
    I_max = MAX(ωᵢ·Iᵢ)
    I_sum = Σ(ωᵢ·Iᵢ)
    其中：ωᵢ为污染物i的权重因子（可依管理需求调整）。
    注：2013版为无权重简单求和（I_sum = ΣIᵢ），2026版引入权重。

七、数据统计要求（第6章）
═══════════════════════════════════════════════════════════════════

7.1 数据有效性规定

（1）O₃日最大8小时平均有效性
  当日8:00至24:00至少有14个有效8小时平均浓度值；若不足14个但日最大
  8小时平均浓度超过限值标准时，统计结果仍有效，否则无效。

（2）年度特定百分位数有效性
  对于SO₂、NO₂、CO、PM₁₀、PM₂.₅日均值及O₃日最大8小时平均的特定百分位数，
  日历年内至少需有324个有效日数据，且每月至少27个（2月至少25个），否则
  统计结果无效。

（3）城市建成区日评价点位有效性
  有效监测点位数量不得低于城市点总数量的75%（总数<4个时不低于50%），
  否则以最大点位浓度代替；因不可控原因使点位长时间停运并获上级部门同意
  时，不纳入总数量统计。

（4）例外事件数据有效性
  例外事件期间的监测数据纳入正常统计；若因考虑例外事件导致有效性不满足，
  统计结果仍有效。

7.2 数据完整性要求

（1）日综合评价
  所有基本评价项目必须全部参与评价。若已测项全部达标但存在缺测或无效项，
  则日综合评价无效；已测项存在不达标则综合不达标。

（2）年度综合评价
  已测项全部达标但存在缺测或无效项时，年综合评价按不达标处理并注明该
  项目；已测项有不达标时，无论是否缺测，均按不达标处理。

7.3 数据修约要求（2026版细化——分层修约）
  实行分层修约：原始监测数据、统计数据、达标评价数据分别按表3要求保留
  不同小数位数。
  示例：PM₂.₅原始数据取整，统计数据保留1位小数，达标评价数据取整。
  修约按GB/T 8170执行。

九、2026版主要修订内容总结（与HJ 663-2013对比）
═══════════════════════════════════════════════════════════════════

1. 调整了城市环境空气质量评价定义（删除"全国范围内"表述）
2. 增加了"例外事件"定义（不可抗力因素导致浓度上升的事件，数据不剔除
   但需标注）
3. 调整了数据统计有效性规定（O₃有效性判定规则细化、城市点位不足时
   处理规则等）
4. 调整了数据完整性要求（日/年综合评价的缺测处理规则）
5. 调整了数据修约要求（实行分层修约）
6. 增加了多项目日综合达标率（达标天数比例）计算方法
7. 调整了环境空气质量状况比较评价方法（单项指数法公式简化、综合指数法
   增加权重因子ωᵢ）
8. 增加了三年滑动平均计算方法

十、配套标准体系
═══════════════════════════════════════════════════════════════════

本标准与以下标准同步发布／实施，共同构成新的环境空气质量标准体系：
1. GB 3095—2026《环境空气质量标准》（2026年2月14日发布）
2. HJ 633—2026《环境空气质量指数（AQI）技术规定》（替代HJ 633-2012）

以上三项标准同步于2026年3月1日起实施，配合更严格的PM₂.₅等污染物浓度
限值，分阶段实施——第一阶段至2030年底执行过渡限值，2031年起执行最终
限值。
