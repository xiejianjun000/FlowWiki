# 铝冶炼企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国有色金属工业协会发〔2022〕11号 |
| 适用范围 | 氧化铝、电解铝及铝加工企业 |
| 发布机关 | 中国有色金属工业协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对铝冶炼企业特点，重点识别铝土矿溶出、电解等关键工序清洁生产潜力。强调大型预焙槽、氧化铝下料、含氟烟气净化、电解槽废内衬处置、赤泥综合利用。涵盖节能降耗审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 吨铝能耗、氟化物 |
| 审核 | 电解槽、焙烧炉 |
| 方案筛选 | 含氟烟气净化+赤泥利用 |
| 高费方案 | 大型预焙槽 |
| 实施验证 | 节能+减排 |
| 持续改进 | 智能电解 |

## 四、合规要点
1. 应采用400kA及以上大型预焙槽。
2. 含氟烟气应配套干法净化装置。
3. 电解槽废内衬应作为危险废物处置。
4. 赤泥应建立综合利用渠道。
