# 危险废物焚烧炉技术要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 176-2020第6章 |
| 适用范围 | 焚烧炉技术要求 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧炉的技术指标和性能要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 处理能力 | 匹配废物产生量 |
| 燃烧效率 | ≥99.9% |
| 焚毁去除率 | ≥99.99% |
| 温度控制 | ≥1100°C可调节 |
| 自动化程度 | DCS自动控制 |

## 四、合规要点
1. 焚烧炉性能指标符合要求
2. 配置DCS自动控制系统
3. 定期检修维护焚烧炉
4. 运行参数实时监控
