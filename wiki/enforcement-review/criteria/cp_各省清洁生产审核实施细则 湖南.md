# 各省清洁生产审核实施细则 湖南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 湘发改规〔2023〕4号 |
| 适用范围 | 湖南省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 湖南省发展和改革委员会、湖南省生态环境厅 |
| 实施日期 | 2023-07-15 |

## 二、主要内容
湖南省实施细则突出有色金属冶炼、化工、陶瓷等传统产业绿色转型，强化湘江流域重金属污染防控与清洁生产协同。建立长株潭城市群审核协同机制，推动省级清洁生产审核示范园区建设。

## 三、清洁生产技术要求
| 阶段 | 湖南特色要求 |
|------|-------------|
| 名单确定 | 湘江流域重金属重点防控 |
| 重点行业 | 有色冶炼、化工、陶瓷 |
| 长株潭 | 城市群协同审核 |
| 重金属 | 总量控制纳入审核 |
| 示范园区 | 省级示范引领 |

## 四、合规要点
1. 湘江流域涉重金属企业应每3年开展1次审核。
2. 有色金属冶炼企业审核应包含重金属总量控制内容。
3. 长株潭三市可共享审核专家资源。
4. 省级清洁生产示范园区企业享受差别化政策支持。
