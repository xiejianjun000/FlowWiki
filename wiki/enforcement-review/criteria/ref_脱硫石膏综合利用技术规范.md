# 脱硫石膏综合利用技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 37785-2019 |
| 适用范围 | 燃煤电厂脱硫石膏的利用 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了脱硫石膏在建材等领域利用的技术要求和品质指标。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| CaSO₄·2H₂O含量 | ≥90% |
| 氯离子含量 | ≤100mg/kg |
| 利用途径 | 纸面石膏板、石膏砌块、水泥缓凝剂 |
| 白度 | ≥50% |
| 含水率 | ≤10% |

## 四、合规要点
1. 脱硫石膏品质符合建材原料要求
2. 控制氯离子含量防止钢筋腐蚀
3. 建立脱硫石膏利用台账
4. 防止储存过程结块和污染
