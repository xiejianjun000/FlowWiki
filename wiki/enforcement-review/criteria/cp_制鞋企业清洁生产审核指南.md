# 制鞋企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国皮革协会发〔2022〕8号 |
| 适用范围 | 皮鞋、运动鞋、布鞋、塑料鞋制造企业 |
| 发布机关 | 中国皮革协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对制鞋企业特点，重点识别裁断、缝制、成型、整理等关键工序清洁生产潜力。强调水性胶黏剂替代、UV固化工艺、VOCs全流程管控。涵盖水性胶占比、VOCs减排审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万双鞋VOCs |
| 审核 | 喷漆、刷胶工序 |
| 方案筛选 | 水性胶+UV固化 |
| 高费方案 | VOCs处理升级 |
| 实施验证 | VOCs减排 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 应使用水性胶黏剂或热熔胶。
2. 喷漆、刷胶工序应配套VOCs处理装置。
3. 鞋底边角料应回收作再生原料。
4. 接触溶剂岗位应配套职业健康防护。
