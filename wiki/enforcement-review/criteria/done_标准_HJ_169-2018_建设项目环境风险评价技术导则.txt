================================================================================
一、适用范围
================================================================================

本标准规定了建设项目环境风险评价的一般性原则、内容、程序和方法。

【适用对象】
适用于涉及有毒有害和易燃易爆危险物质生产、使用、储存（包括使用管线输运）的
建设项目可能发生的突发性事故（不包括人为破坏及自然灾害引发的事故）的环境风险
评价。

【不适用对象】
- 不适用于生态风险评价
- 不适用于核与辐射类建设项目的环境风险评价

【其他说明】
- 对于有特定行业环境风险评价技术规范要求的建设项目，本标准规定的一般性原则适用
- 相关规划类环境影响评价中的环境风险评价可参考本标准

三、术语和定义（第3章）
================================================================================

3.1 环境风险 environmental risk
指突发性事故对环境造成的危害程度及可能性。

3.2 环境风险潜势 environmental risk potential
对建设项目潜在环境危害程度的概化分析表达，是基于建设项目涉及的物质和工艺系统
危险性及其所在地环境敏感程度的综合表征。

3.3 风险源 risk source
指存在物质或能量意外释放，并可能产生环境危害的源。例如一个储罐。

3.4 危险物质 hazardous substance
指具有易燃易爆、有毒有害等特性，会对环境造成危害的物质。

3.5 危险单元 hazardous unit
由一个或多个风险源构成的具有相对独立功能的单元，事故状况下应可实现与其他功能
单元的分割。例如一个罐区。

3.6 最大可信事故 maximum credible event
基于经验统计分析，在一定可能性区间内发生的事故中，造成环境危害最严重的事故。
在实际应用中，最大可信事故是所有预测概率不为零的事故中，对环境（或健康）危害
最严重的重大事故。最大可信事故的设定是在大量统计资料基础上的一种合理假设。

3.7 大气毒性终点浓度 air toxic endpoint
指人员短期暴露可能会导致出现健康影响或死亡的大气污染物浓度，用于判断周边环境
风险影响程度。参照美国PAC标准值分级原则，分为1级和2级：
- 1级（毒性终点浓度-1，对应PAC-3）：低于该限值时，绝大多数人员暴露1小时
  不会对生命造成威胁；超过该限值时，有可能对人群造成生命威胁
- 2级（毒性终点浓度-2，对应PAC-2）：低于该限值时，暴露1小时一般不会对人体
  造成不可逆的伤害，或出现的症状一般不会损伤个体采取有效防护措施的能力

四、总则（第4章）
================================================================================

4.1 一般性原则
- 环境风险评价应以突发性事故导致的危险物质环境急性损害防控为目标
- 对建设项目的环境风险进行分析、预测和评估
- 提出环境风险预防、控制、减缓措施
- 明确环境风险监控及应急建议要求
- 为建设项目环境风险防控提供科学依据

4.2 评价工作程序（图1 评价工作程序流程图）

   [风险调查]
       ↓
   [环境风险潜势初判]
       ↓
   （判断：潜势为Ⅰ→简单分析→评价结论与建议）
       ↓（潜势为Ⅱ及以上）
   [风险识别]
   ├── 物质危险性识别
   ├── 生产系统危险性识别
   └── 危险物质向环境转移的途径识别
       ↓
   [风险事故情形分析]
   ├── 事故情形设定
   └── 源项分析（源强计算）
       ↓
   [风险预测与评价]
   ├── 大气环境风险预测与评价
   ├── 地表水环境风险预测与评价
   └── 地下水环境风险预测与评价
       ↓
   [环境风险管理]
   ├── 风险防范措施
   ├── 应急预案要求
   └── 应急监测
       ↓
   [评价结论与建议]

   注：流程中设有"优化调整"的反馈回路，各步骤可相互反馈调整

4.3 评价工作等级划分

4.3.1 环境风险潜势划分
环境风险潜势划分为 I、II、III、IV/IV+ 级。风险潜势由危险物质及工艺系统危险性
（P）与环境敏感程度（E）共同确定。

4.3.2 评价工作等级

┌────────────────────┬────────────┬────────┬────────┬──────────┐
│  环境风险潜势      │  Ⅳ、Ⅳ+    │  Ⅲ    │  Ⅱ    │   Ⅰ     │
├────────────────────┼────────────┼────────┼────────┼──────────┤
│  评价工作等级      │  一级      │  二级  │  三级  │ 简单分析 │
└────────────────────┴────────────┴────────┴────────┴──────────┘

- 一级：最高等级，需进行详细的定量预测与评价（最不利+最常见气象条件）
- 二级：需进行较详细的评价分析（最不利气象条件）
- 三级：进行一般性评价分析（定性分析）
- 简单分析：在描述危险物质、环境影响途径、环境危害后果、风险防范措施等方面
  给出定性说明（见附录A）

4.4 评价工作内容

（1）一级评价
- 需选取最不利气象条件和事故发生地最常见气象条件，选择适用的数值方法进行
  分析预测
- 给出风险事故情形下危险物质释放可能造成的影响范围与程度
- 对于存在极高大气环境风险的项目，应进一步开展关心点概率分析

（2）二级评价
- 需选取最不利气象条件，选择适用的数值方法进行分析预测
- 给出风险事故情形下危险物质释放可能造成的影响范围与程度

（3）三级评价
- 应定性分析说明环境影响后果

4.5 评价范围

【大气环境风险评价范围】
- 一级、二级评价：距建设项目边界一般不低于 5 km
- 三级评价：距建设项目边界一般不低于 3 km
- 管线项目：一、二级不低于 200 m，三级不低于 100 m
- 评价范围应以项目边界创建等距离缓冲区，而非以项目中心画圆
- 当大气毒性终点浓度预测到达距离超出评价范围时，应根据预测到达距离进一步
  调整评价范围
- 若评价范围外存在需要特别关注的环境敏感目标，评价范围需延伸至所关心的目标

【地表水环境风险评价范围】
- 参照 HJ 2.3《环境影响评价技术导则 地表水环境》确定
- 评价范围应覆盖环境风险影响范围所及的水环境保护目标水域

【地下水环境风险评价范围】
- 参照 HJ 610《环境影响评价技术导则 地下水环境》确定
- 通常以项目所在水文地质单元作为评价范围

五、风险调查（第5章）
================================================================================

5.1 建设项目风险源调查
- 调查建设项目危险物质数量和分布情况
- 调查生产工艺特点
- 了解危险物质的生产、使用、储存情况

5.2 环境敏感目标调查
- 调查评价范围内各环境要素的环境敏感目标
- 明确敏感目标的位置、规模、保护级别等

================================================================================
六、环境风险潜势初判（第6章）
================================================================================

6.1 潜势划分

环境风险潜势综合等级由 P 和 E 的分级确定。

6.2 危险物质及工艺系统危险性（P）的分级

P的分级由以下两步确定：

（1）Q值（危险物质数量与临界量比值）
   计算每种风险物质在厂界内的最大存在总量与其临界量的比值之和：
   Q = q1/Q1 + q2/Q2 + ... + qn/Qn
   式中：qn为每种危险物质的最大存在总量（t），Qn为每种危险物质的临界量（t）

   - 当 Q < 1 时，环境风险潜势为 I 级
   - 当 Q >= 1 时，Q值划分为三档：
     * 1 ≤ Q < 10
     * 10 ≤ Q < 100
     * Q ≥ 100

（2）M值（行业及生产工艺评分）
   根据附录C表C.1进行评分，详见"附录C"部分。

（3）P分级判断表
   ┌──────────────────────┬───────┬───────┬───────┬───────┐
   │  危险物质数量与     │  M1   │  M2   │  M3   │  M4   │
   │  临界量比值（Q）    │       │       │       │       │
   ├──────────────────────┼───────┼───────┼───────┼───────┤
   │  Q ≥ 100            │  P1   │  P1   │  P2   │  P3   │
   │  10 ≤ Q < 100       │  P1   │  P2   │  P3   │  P4   │
   │  1 ≤ Q < 10         │  P2   │  P3   │  P4   │  P4   │
   └──────────────────────┴───────┴───────┴───────┴───────┘

   P1：极高危害  P2：高度危害  P3：中度危害  P4：轻度危害

6.3 环境敏感程度（E）的分级

E分级分别按大气环境、地表水环境和地下水环境三个要素确定，每个要素分为：
E1（环境高度敏感区）、E2（环境中度敏感区）、E3（环境低度敏感区）。
详见"附录D"部分。

6.4 风险潜势划分矩阵

┌──────────────────────┬────────┬────────┬────────┬────────┐
│  环境敏感程度（E）  │  P1    │  P2    │  P3    │  P4    │
├──────────────────────┼────────┼────────┼────────┼────────┤
│  E1（高度敏感）      │  IV+   │  IV    │  III   │  III   │
│  E2（中度敏感）      │  IV    │  III   │  III   │  II    │
│  E3（低度敏感）      │  III   │  III   │  II    │  I     │
└──────────────────────┴────────┴────────┴────────┴────────┘

注：IV+为极高环境风险

七、风险识别（第7章）
================================================================================

7.1 物质危险性识别
- 识别主要原辅材料、燃料、中间产品、副产品、最终产品、污染物、火灾和爆炸
  伴生/次生物等的危险性
- 按附录B识别危险物质，明确其易燃易爆、有毒有害特性及分布

7.2 生产系统危险性识别
- 包括主要生产装置、储运设施、公用工程和辅助生产设施，以及环境保护设施等
- 按工艺流程和平面布置功能区划进行危险单元划分
- 分析风险源的危险性、存在条件和转化为事故的触发因素

7.3 危险物质向环境转移的途径识别
- 分析危险物质特性及可能的环境风险类型
- 识别影响环境的途径（大气环境、水环境、土壤等）
- 分析可能影响的环境敏感目标

7.4 风险识别方法
- 可选用安全检查表法、预先危险性分析法、事故树分析法、事件树分析法等
- 综合运用多种方法进行全面识别

7.5 风险识别结果
- 列出风险源、危险物质、危险单元清单
- 明确风险类型（泄漏、火灾、爆炸等）
- 给出环境风险识别结果汇总表

================================================================================
八、风险事故情形分析（第8章）
================================================================================

8.1 事故情形设定
- 基于风险识别结果，设定可能发生的事故情形
- 重点考虑最大可信事故
- 事故概率通常以10^-6为界限（低于此概率被认为是极小概率事件）

8.2 源项分析

8.2.1 源项分析方法
- 基于风险事故情形的设定，合理估算源强
- 泄漏频率可参考附录E的推荐方法确定
- 也可采用事故树分析、事件树分析或类比法等确定

8.2.2 事故源强的确定

（1）计算法（适用于腐蚀或应力作用引起的泄漏型事故）
   采用附录F推荐的计算方法：

   【液体泄漏速率】伯努利方程
   QL = Cd * A * ρ * [2(P-P0)/ρ + 2gh]^0.5
   式中：
   QL — 液体泄漏速率（kg/s）
   Cd — 液体泄漏系数（圆形裂口0.65，三角形0.60，长方形0.55）
   A  — 裂口面积（m^2）
   P  — 容器内介质压力（Pa）
   P0 — 环境压力（Pa）
   ρ  — 液体密度（kg/m^3）
   g  — 重力加速度（9.81 m/s^2）
   h  — 裂口之上液位高度（m）

   【气体泄漏速率】
   临界流条件：P0/P ≤ [2/(k+1)]^[k/(k+1)]
   次临界流：P0/P > [2/(k+1)]^[k/(k+1)]
   气体泄漏速率：
   QG = Y * Cd * A * P * √[Mk/(RTG) * (2/(k+1))^((k+1)/(k-1))]
   式中：
   Y  — 流出系数（临界流Y=1.0）
   Cd — 气体泄漏系数（圆形1.00，三角形0.95，长方形0.90）
   M  — 分子量
   R  — 气体常数 8.314 J/(mol·K)
   TG — 气体温度（K）
   k  — 气体的绝热指数（热容比）

（2）经验估算法
   适用于火灾、爆炸等突发性事故伴生/次生的污染物释放

（3）其他参数设定
   - 设置紧急隔离系统的单元泄漏时间一般设定为 10 min
   - 未设置的设定为 30 min
   - 泄漏液体蒸发时间一般按 15~30 min 计
   - 装卸事故泄漏量按装卸物质流速和管径及失控时间计算（一般按 5~30 min 计）
   - 长输管线按管道截面100%断裂估算，考虑截断阀启动前后的泄漏量

九、风险预测与评价（第9章）
================================================================================

9.1 大气环境风险预测与评价

9.1.1 预测模型（附录G）

根据物质密度采用理查德森数（Ri）判断烟气类型：
- 连续排放：Ri ≥ 1/6 为重质气体；Ri < 1/6 为轻质气体
- 瞬时排放：有相应的计算公式
- 对于密度小于空气的气体（如CO），不计算理查德森数，直接判定为轻质气体

【模型选择】
┌──────────────────┬─────────────────────────────────────┐
│ 气体类型         │ 推荐模型                            │
├──────────────────┼─────────────────────────────────────┤
│ 重质气体         │ SLAB模型（适用于重质气体扩散模拟） │
│ 轻质气体         │ AFTOX模型                           │
│ 中性气体         │ AFTOX模型                           │
│ 液池蒸发气体     │ AFTOX模型                           │
│ 两相混合物       │ SLAB模型                            │
└──────────────────┴─────────────────────────────────────┘

9.1.2 预测参数
- 最不利气象条件：F类稳定度、风速1.5m/s、温度25℃、相对湿度50%
- 最常见气象条件：根据当地气象统计资料确定（通常D类稳定度）
- 地表粗糙度、是否考虑地形、地形数据精度等
- 预测范围通常以厂址为中心，轴线最远距离5000m
- 计算点通常设置50m间距的网格点

9.1.3 大气毒性终点浓度值（附录H）
- 1级（毒性终点浓度-1）：绝大多数人员暴露1h不会对生命造成威胁
- 2级（毒性终点浓度-2）：暴露1h一般不会对人体造成不可逆伤害

十、环境风险管理（第10章）
================================================================================

10.1 风险管理目标
- 以突发性事故导致的危险物质环境急性损害防控为目标
- 提出环境风险预防、控制、减缓措施
- 确保项目环境风险可接受

10.2 风险防范措施

10.2.1 一般原则
- 提出的环境风险防范措施必须科学、合理、有效
- 强调企业与园区和区域管理的联动
- 参考借鉴美国、欧盟等先进环境风险管理方法

10.2.2 具体措施要求
（1）大气环境风险防范措施
   - 有毒有害气体泄漏监测、报警系统
   - 事故废气收集处理系统
   - 防火、防爆设施

（2）水环境风险防范措施
   - 三级防控体系（单元级防控、厂区级防控、园区级防控）
   - 事故应急池
   - 雨污切换阀门
   - 围堰、防火堤

（3）其他防范措施
   - 危险化学品运输与储存安全防范
   - 火灾爆炸防范
   - 配备备用电源
   - 定期检修维护

10.3 应急预案编制要求
- 对企业突发环境事件应急预案的编制或完善提出原则要求
- 应急预案应与园区和区域应急管理体系相衔接

应急预案主要内容：
（1）应急计划区：确定危险化学品数量及分布，明确应急计划区并给出分布图
（2）指挥机构及人员：明确指挥人员名单、职责、临时替代者、指挥地点及值班表
（3）预案分级响应条件：规定预案的级别及分级响应程序
（4）应急救援保障：明确应急设施、设备与器材，落实专人管理
（5）报警、通讯联络方式：事故报警电话号码、通讯联络方法、特殊情况下的
    报警通讯方式
（6）应急措施：应急环境监测、抢险救援和控制措施，应急检测、防护、清除泄漏
    措施和器材
（7）人员撤离计划：紧急撤离、疏散路线，应急剂量控制及撤离组织计划
（8）事故应急救援关闭程序与恢复措施：应急状态终止程序，善后处理和恢复措施
（9）应急培训计划：定期安排人员培训与演练
（10）公众教育和信息：对工厂邻近地区开展公众教育和信息发布

================================================================================
十一、评价结论与建议（第11章）
================================================================================

11.1 评价结论
- 明确建设项目环境风险的可接受程度
- 对于可接受项目：结论为"本项目环境风险水平可接受；风险管理措施有效、可靠；
  从环境风险的角度分析，本项目可行"

11.2 建议
- 针对风险管理中存在的问题提出改进建议
- 对后续环境管理提出要求
