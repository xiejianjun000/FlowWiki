# 危险废物贮存容器技术要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18597-2023附录B |
| 适用范围 | 危险废物贮存容器 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物贮存容器的材质、结构、标识和使用要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 容器材质 | 与废物相容，不发生反应 |
| 容器结构 | 密封、防渗、耐腐蚀 |
| 容量限制 | 不超过容器额定容量 |
| 标识要求 | 危废标签、危险特性标识 |
| 完好性检查 | 定期检查并记录 |

## 四、合规要点
1. 容器材质与贮存废物相容
2. 容器密封完好无破损
3. 危废标签信息完整清晰
4. 定期检查容器完好性
