# 赤泥综合利用技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 31789-2015 |
| 适用范围 | 氧化铝生产赤泥的综合利用 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了赤泥在建材、路基、土壤改良等领域利用的技术要求和安全控制。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| pH值控制 | 利用前pH≤9.5 |
| 放射性 | 符合GB 6566要求 |
| 利用途径 | 路基材料、水泥原料、砖材 |
| 重金属限值 | 符合GB 38800 |
| 环境监测 | 利用场地定期监测 |

## 四、合规要点
1. 赤泥利用前进行脱碱处理
2. 监测利用场地土壤和地下水
3. 防止高碱性和重金属污染
4. 建立赤泥利用台账
