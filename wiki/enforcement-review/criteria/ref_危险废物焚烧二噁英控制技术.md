# 危险废物焚烧二噁英控制技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18484-2020附录 |
| 适用范围 | 二噁英控制 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧过程二噁英的控制技术和措施。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 控制温度 | 急冷至200°C以下 |
| 停留时间 | 高温区≥2秒 |
| 活性炭吸附 | 喷入活性炭吸附 |
| 催化分解 | 催化降解二噁英 |
| 排放限值 | ≤0.1ng-TEQ/m³ |

## 四、合规要点
1. 配置急冷塔控制二噁英生成
2. 喷入活性炭吸附二噁英
3. 定期监测烟气二噁英浓度
4. 排放浓度符合限值
