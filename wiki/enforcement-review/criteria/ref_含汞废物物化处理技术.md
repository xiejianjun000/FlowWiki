# 含汞废物物化处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014附录 |
| 适用范围 | 含汞废物物化处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了含汞废物物化处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 含汞废液、含汞废料 |
| 处理工艺 | 硫化物沉淀+离子交换 |
| 沉淀剂 | 硫化钠 |
| 吸附剂 | 巯基树脂 |
| 出水要求 | 汞≤0.05mg/L |

## 四、合规要点
1. 含汞废物单独收集处理
2. 硫化物沉淀+离子交换组合
3. 出水汞含量达标排放
4. 防止汞蒸气挥发
