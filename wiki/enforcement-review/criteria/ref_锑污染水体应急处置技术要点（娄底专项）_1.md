# 锑污染水体应急处置技术要点（娄底专项）

> ACE Generator 编译 | Reflector 审核通过

## 适用场景

娄底市涉锑（锡矿山、青峰河/涟溪河、资江干流）突发含锑废水外泄、尾矿库直排、锑浓度异常等事件。

## 处置技术链

```
拦截断源 -> 水利调度 -> 加药捕集/沉淀降锑 -> 工程拦截过滤 -> 备用水源切换
```

## 应急物资清单

| 类别 | 物资 | 用途 |
|------|------|------|
| 除锑药剂 | PFS、FC、硫酸铁 | 铁盐絮凝捕集锑 |
| 助凝剂 | PAM | 强化絮凝 |
| 沉淀/吸附 | 硫化钠、活性炭 | 低温低浊复合处理 |
| 拦截设施 | 橡胶坝、围堰、沙袋 | 分级拦截 |
| 储运 | 槽罐车、应急池、泵 | 收集处置 |
| 监测 | 锑快检包、便携重金属仪 | 加密监测 |

## 除锑药剂技术参数

| 方法 | 最佳条件 | 去除率 |
|------|---------|--------|
| FC饮用水除锑 | 0.2 mmol/L Fe3+, pH 7 | 94.1% |
| PFS絮凝 | pH 4-11, 絮凝体密实 | 适配河道/水厂 |
| 硫化钠+铁盐+PAM（低温专利） | pH 8-9, Na2S 15-30倍, Fe 40-50倍 | **99.75%** |

## 关键警示

- **底泥反释**：枯水期+高温+高光照 -> 底泥锑释放反弹（2022坪口断面教训）
- **跨界传导**：资江娄底-邵阳-益阳联防联控必设
