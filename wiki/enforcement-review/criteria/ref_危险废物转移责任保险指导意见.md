# 危险废物转移责任保险指导意见

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 环办固体〔2019〕53号 |
| 适用范围 | 转移责任保险 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物转移责任保险的投保范围和要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 投保主体 | 转移单位、运输单位 |
| 保险范围 | 第三方人身、财产、环境损害 |
| 保险金额 | 根据风险等级确定 |
| 理赔程序 | 出险→报案→定损→理赔 |
| 鼓励政策 | 保费补贴、税收优惠 |

## 四、合规要点
1. 按指导意见投保责任保险
2. 保险范围覆盖主要风险
3. 保险金额与风险匹配
4. 出险时及时报案理赔
