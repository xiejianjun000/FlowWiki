# 各省清洁生产审核实施细则 浙江

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 浙发改规〔2023〕7号 |
| 适用范围 | 浙江省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 浙江省发展和改革委员会、浙江省生态环境厅 |
| 实施日期 | 2023-09-01 |

## 二、主要内容
浙江省实施细则以数字经济为引领，建设"清洁生产审核一件事"数字化平台，推行全流程网上办理。强化"腾笼换鸟、凤凰涅槃"政策协同，对通过审核的企业在用能权、排污权交易中给予优惠。

## 三、清洁生产技术要求
| 阶段 | 浙江特色要求 |
|------|-------------|
| 名单确定 | 双超双有+亩均效益D档 |
| 数字化 | "一件事"全流程网办 |
| 要素配置 | 用能权/排污权优惠 |
| 长三角互认 | 与沪苏皖结果互认 |
| 亩均评价 | 与亩均效益联动 |

## 四、合规要点
1. 亩均效益综合评价D档企业应纳入强制性审核名单。
2. 审核报告应通过"清洁生产审核一件事"平台提交。
3. 中/高费方案实施后可申请用能权、排污权交易优惠。
4. 验收结果在长三角区域（沪苏浙皖）予以互认。
