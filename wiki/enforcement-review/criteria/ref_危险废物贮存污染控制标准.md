# 危险废物贮存污染控制标准

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18597-2023 |
| 适用范围 | 危险废物贮存的污染控制 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物贮存场所的选址、设计、运行、安全和监测要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 选址要求 | 远离饮用水源、居民区、生态红线 |
| 防渗要求 | 等效黏土层≥0.75m，K≤1.0×10⁻⁷cm/s |
| 贮存期限 | 原则上不超过1年 |
| 分区分类 | 按危险特性和相容性分类存放 |
| 监测要求 | 地下水、土壤、大气定期监测 |

## 四、合规要点
1. 贮存场所符合选址和防渗要求
2. 按危险特性分区分类贮存
3. 建立贮存台账定期盘点
4. 贮存期限不超过1年（特殊情况需批准）
