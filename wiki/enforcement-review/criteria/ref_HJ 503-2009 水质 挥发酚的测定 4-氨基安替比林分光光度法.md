# HJ 503-2009 水质 挥发酚的测定 4-氨基安替比林分光光度法

## 一、标准基本信息

- **标准号**：HJ 503-2009
- **替代标准**：GB 7490-87
- **实施日期**：2009年11月1日

## 二、方法原理

挥发性酚类在碱性条件下（pH=10±0.2）与4-氨基安替比林反应，被铁氰化钾氧化生成红色安替比林染料，在510nm波长下测定吸光度。

## 三、适用范围

- 检出限：0.01 mg/L
- 测定下限：0.04 mg/L
- 测定上限：2.4 mg/L

适用于地表水、地下水和废水中挥发酚测定。

## 四、仪器设备

- 蒸馏装置：500 mL全玻璃蒸馏瓶
- 分光光度计
- 比色皿：20mm或30mm

## 五、试剂

- 4-氨基安替比林溶液（20 g/L）
- 铁氰化钾溶液（80 g/L）
- 缓冲溶液（NH₄Cl-NH₄OH，pH=10）
- 硫酸铜溶液
- 甲基橙指示剂
- 苯酚标准溶液

## 六、分析步骤

### 6.1 蒸馏前处理
1. 取水样250 mL
2. 加甲基橙指示剂5滴
3. 用H₃PO₄调至紫红色（pH<4）
4. 加入5 mL硫酸铜溶液
5. 加热蒸馏至馏出液225 mL
6. 冷却后加水至250 mL

### 6.2 显色测定
1. 取馏出液50 mL
2. 加入2 mL缓冲液
3. 加入1.5 mL 4-氨基安替比林溶液
4. 加入1.5 mL铁氰化钾溶液
5. 静置10 min
6. 510nm波长测定吸光度

## 七、结果计算

```
酚(mg/L) = (A - A₀) × f
```

## 八、质量保证

- 全程序空白
- 平行样偏差：≤10%
- 加标回收率：90-110%

## 九、对企业环保启示

1. 挥发酚为焦化、化工特征污染物
2. 采样后需立即加磷酸铜固定
3. 24小时内完成分析
