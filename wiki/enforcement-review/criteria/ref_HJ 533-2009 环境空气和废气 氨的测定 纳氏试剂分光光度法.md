# HJ 533-2009 环境空气和废气 氨的测定 纳氏试剂分光光度法

## 一、标准基本信息

- **标准号**：HJ 533-2009
- **替代标准**：GB/T 14668-93
- **实施日期**：2010年4月1日

## 二、方法原理

氨被稀硫酸吸收液吸收，与纳氏试剂反应生成黄棕色化合物，在420nm波长下测定吸光度。

## 三、适用范围

- 检出限：0.01 mg/m³
- 测定下限：0.04 mg/m³
- 测定上限：100 mg/m³

适用于环境空气和固定污染源废气中氨测定。

## 四、干扰与消除

| 干扰物 | 干扰程度 | 消除方法 |
|--------|----------|----------|
| 硫化氢 | 正干扰 | 醋酸铅棉过滤 |
| 三甲胺 | 正干扰 | 调整pH消除 |
| 颗粒物 | 干扰吸收 | 滤膜过滤 |

## 五、采样方法

- 吸收瓶：大型气泡吸收管
- 吸收液：0.01 mol/L H₂SO₄
- 采样流量：0.5-1.0 L/min
- 采样时间：30-60 min

## 六、仪器设备

- 大气采样器
- 分光光度计
- 比色皿：10mm

## 七、分析步骤

1. 吸收液定容至50 mL
2. 加入纳氏试剂1.0 mL
3. 显色10 min
4. 420nm波长测定吸光度

## 八、结果计算

```
C(NH₃) = (W - W₀) / Vstd
```

## 九、质量保证

- 全程序空白
- 加标回收率：90-110%
- 平行样偏差：≤10%

## 十、对企业环保启示

1. 氨为重点管控VOCs前体物
2. 脱硝氨逃逸监测必需
3. 纳氏试剂含汞，废液需单独收集
