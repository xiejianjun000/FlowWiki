# 废铅蓄电池再生铅行业清洁生产标准

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 510-2009 |
| 适用范围 | 清洁生产标准 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废铅蓄电池再生铅行业的清洁生产标准。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 工艺要求 | 清洁生产工艺 |
| 能耗指标 | 一级≤130，二级≤150，三级≤170kgce/t |
| 水耗指标 | 一级≤2，二级≤3，三级≤4m³/t |
| 污染物排放 | 三级标准 |
| 综合利用 | 提高铅回收率 |

## 四、合规要点
1. 采用清洁生产工艺降低污染
2. 能耗水耗达到标准要求
3. 污染物排放符合标准
4. 提高铅综合回收率
