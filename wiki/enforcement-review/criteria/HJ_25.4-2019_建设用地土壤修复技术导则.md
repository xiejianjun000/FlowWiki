# HJ 25.4-2019 建设用地土壤修复技术导则

## 适用范围（第1条）

本标准规定了建设用地土壤修复的工作原则、工作程序、技术方法和技术要求。

**适用于：**
- 建设用地土壤修复技术筛选
- 建设用地土壤修复方案制定
- 建设用地土壤修复工程实施
- 建设用地土壤修复效果评估
- 建设用地土壤修复验收
- 建设用地土壤污染风险管控中的修复相关活动

**不适用于：** 放射性污染和致病性生物污染的土壤修复。

## 修复原则与工作程序（第4条）

### 六项修复原则（第4.1条）

| 原则 | 核心要求 |
|------|---------|
| **安全第一** (4.1.1) | 确保人员安全和环境安全，防止二次污染和安全事故 |
| **风险可控** (4.1.2) | 以人体健康和生态环境风险控制为核心 |
| **技术可行** (4.1.3) | 技术成熟可靠，能有效达到修复目标 |
| **经济合理** (4.1.4) | 满足修复目标前提下选择经济合理的方案 |
| **因地制宜** (4.1.5) | 根据污染特征、水文地质、土地利用方式等选择适宜技术 |
| **绿色可持续** (4.1.6) | 优先选择资源消耗少、环境影响小、二次污染少的技术 |

### 修复工作程序（第4.2条）

1. **修复前期工作**：污染状况调查、风险评估、确定修复目标与范围、技术筛选
2. **修复方案制定**：技术路线确定、工艺参数设计、工程设计、二次污染防控、方案比选
3. **修复工程实施**：施工准备、施工过程管理、过程监测、质量控制
4. **修复效果评估与验收**：效果监测、效果评估、验收、后期管理

## 修复技术筛选（第5条）

### 筛选原则（第5.1条）

- 目标导向：以实现修复目标为核心
- 条件适配：充分考虑场地污染特征和水文地质条件
- 技术成熟：优先选择应用案例多的技术
- 经济合理：在满足要求前提下选择成本较低的技术
- 环境友好：优先选择二次污染小的绿色修复技术
- 安全可靠：确保施工过程中的人员和环境安全

### 筛选依据（第5.2条）

**污染特征（第5.2.1条）：** 污染物类型、浓度水平与超标程度、物理化学性质（挥发性、溶解度、吸附性、降解性）、污染深度与范围、污染均匀程度。

**场地条件（第5.2.2条）：** 水文地质条件（含水层分布、地下水位、渗透性）、土壤性质（质地、有机质含量、pH值、孔隙度）、地形地貌、周边环境敏感目标分布与可利用空间。

**修复目标（第5.2.3条）：** 修复目标值、修复范围与深度、工期要求、修复后土地利用方式。

### 筛选矩阵（第5.6条）

采用多指标综合评价法，权重分布：

| 评价指标 | 权重 |
|---------|------|
| 处理效果 | 0.25 |
| 技术可行性 | 0.20 |
| 经济合理性 | 0.20 |
| 环境友好性 | 0.15 |
| 施工周期 | 0.10 |
| 安全可靠性 | 0.10 |

综合得分排序，选择 2~3 种技术进一步比选。

### 中试试验要求（第5.7条）

对于复杂场地或采用新技术，应进行中试试验，验证处理效果、确定最佳工艺参数、评估实际运行成本、发现潜在问题。试验规模应能反映实际工程情况，周期应足够长以获得可靠数据。

## 常用修复技术（第6条）

### 6.1 土壤气相抽提 SVE（第6.1条）

**原理（第6.1.1条）：** 在包气带设抽提井，利用真空负压使空气流经污染土壤，将VOCs和SVOCs解吸带出地面处理。

**适用范围（第6.1.2条）：**
- 适用污染物：VOCs（苯系物、氯代烃、汽油等）、SVOCs、部分挥发性重金属（汞等）
- 适用条件：包气带厚度 > 1 m，渗透系数 > 10⁻⁴ cm/s，地下水位埋深较大
- 不适用：包气带太薄、土壤黏重、污染物沸点太高、存在游离态DNAPL/LNAPL

**关键工艺参数（第6.1.3-6.1.4条）：**
- 井距：一般 5~20 m
- 井深：进入污染底板以下 1~2 m
- 真空度：一般 5~20 kPa
- 单井抽提流量：0.5~5 m³/min
- 修复周期：一般 6个月~2年

**尾气处理：** 活性炭吸附（低浓度大风量）、催化燃烧（中高浓度）、生物过滤（可生物降解污染物）、冷凝回收（高浓度有回收价值）。

### 6.2 生物通风（第6.2条）

**原理（第6.2.1条）：** 向包气带通入空气/氧气，促进好氧微生物降解有机污染物。

**适用范围（第6.2.2条）：**
- 适用：石油烃类、BTEX、其他可生物降解VOCs/SVOCs
- 不适用：污染物生物降解性差、土壤渗透性太差、浓度过高对微生物有毒

**关键工艺参数（第6.2.3-6.2.4条）：**
- 井距：一般 5~15 m
- 注气压力：5~20 kPa
- 气固比：一般 5~50
- 孔隙气体流速：0.01~0.1 cm/s
- 修复周期：一般 1~3年

**强化措施：** 添加营养物质（氮、磷）、调节pH值、接种高效降解菌、补充电子受体。

### 6.3 热脱附（第6.3条）

**原理（第6.3.1条）：** 通过加热使污染物挥发或分解，将含污染物气体收集处理。

**分类与操作温度：**
- 低温热脱附：100~300℃，处理VOCs
- 高温热脱附：300~600℃，处理SVOCs和部分重金属
- 原位/异位两种方式

**适用范围（第6.3.2条）：** VOCs、SVOCs（多环芳烃、农药、PCBs）、部分重金属（汞、砷）、石油烃类。异位热脱附适用各种土壤类型。

**关键工艺参数（第6.3.3-6.3.4条）：**
- 处理温度：150~600℃（依污染物确定）
- 停留时间：10~60 min
- 尾气处理：旋风除尘/布袋除尘（颗粒物）、喷淋塔/碱洗（酸性气体）、活性炭吸附/催化燃烧/热力焚烧（有机物）

### 6.4 化学氧化（第6.4条）

**原理（第6.4.1条）：** 投加氧化剂将污染物氧化降解为低毒/无毒小分子。

**常用氧化剂：** 高锰酸盐、过氧化氢（Fenton试剂）、臭氧、过硫酸盐、次氯酸钠。

**适用范围（第6.4.2条）：**
- 适用：石油烃类、BTEX、氯代烃（TCE、PCE）、PAHs、酚类/醇类/酮类、硫化物、氰化物
- 不适用：土壤还原性物质过高、有机质过高、重金属（一般无效）

**关键工艺参数（第6.4.3-6.4.4条）：**
- 注入井距：一般 2~8 m
- 氧化剂投加量：理论计算量的 2~5 倍
- Fenton反应pH值：2~4；高锰酸盐pH值：4~9
- 修复周期：一般 3~12个月

### 6.5 固化稳定化 S/S（第6.5条）

**原理（第6.5.1条）：** 添加固化剂/稳定剂，通过物理包裹和化学固定将污染物封装或降低迁移性。

**常用药剂：** 水泥基（硅酸盐水泥等）、石灰基（生石灰、熟石灰）、粉煤灰/矿渣、有机螯合剂/硫化物。

**适用范围（第6.5.2条）：**
- 适用：重金属（镉、铅、铬、汞、砷、铜、锌、镍等）、半挥发性和非挥发性有机物
- 不适用：挥发性强的有机物、土壤体积增容有限制的场地

**关键工艺参数（第6.5.3-6.5.4条）：**
- 固化剂掺量：一般 5%~30%（占土壤干重）
- 养护时间：7~28天
- 抗压强度要求：一般 >= 0.3 MPa
- 浸出毒性：低于相关标准限值

### 6.6 土壤淋洗（第6.6条）

**原理（第6.6.1条）：** 利用水或化学淋洗剂（表面活性剂、螯合剂、酸/碱溶液）将污染物从土壤颗粒表面洗脱至液相，再处理废水。

**适用范围（第6.6.2条）：**
- 适用：重金属（镉、铅、铜、锌、镍）、VOCs/SVOCs、石油烃、农药
- 适用条件：砂性土/砾石土、黏粒含量低（一般 < 20%~30%）
- 不适用：黏重土壤、污染物渗入矿物晶格内部

**关键工艺参数（第6.6.3-6.6.4条）：**
- 液固比：5:1~20:1
- 淋洗时间：30 min~2 h/级
- 淋洗级数：2~5级
- 处理后土壤含水率：15%~30%

### 6.7 生物修复（第6.7条）

**原理（第6.7.1条）：** 利用微生物代谢降解有机污染物为CO₂和H₂O，或转化重金属形态。

**适用范围（第6.7.2条）：**
- 适用：石油烃类、BTEX、酚/醇/酮类、低分子量PAHs、可降解农药、氰化物
- 不适用：高氯代有机物、二噁英等难降解有机物

**关键工艺参数（第6.7.3-6.7.4条）：**
- 含水率：20%~40%
- pH值：6.5~8.5
- 碳氮比 C:N：25:1~30:1
- 堆体高度：1.5~3 m
- 氧气浓度：> 5%（好氧）
- 修复周期：3~12个月

### 6.8 植物修复（第6.8条）

**原理（第6.8.1条）：** 利用植物及其根际微生物，通过植物提取、植物挥发、植物固定、植物降解、根际生物降解去除污染物。

**适用范围（第6.8.2条）：**
- 适用：重金属（超富集植物如东南景天、蜈蚣草、遏蓝菜等）、石油烃/PAHs（根际降解）
- 适用条件：中低浓度、浅层（0~2 m）、大面积、工期不紧迫
- 不适用：高浓度（对植物有毒害）、深层污染

**关键参数（第6.8.4条）：** 修复周期一般 1~5年甚至更长，每年1季或多季。

**强化措施：** 添加螯合剂（EDTA、柠檬酸）、施肥、调节pH、水分管理、接种根际微生物。

### 6.9 填埋处置（第6.9条）

**原理（第6.9.1条）：** 将污染土壤运输至合规填埋场最终处置，将污染物与环境隔离。

**分类：** 危险废物填埋、生活垃圾填埋（满足入场要求）、安全填埋。

**入场技术要求（第6.9.3条）：** 需进行危险废物鉴别，含水率一般 < 60%，不得含游离液体，密闭运输，办理转移联单（危险废物）。

**封场后长期监测：** 一般不少于 30年（第6.9.4条）。

## 修复方案制定（第7条）

### 组合修复技术（第7.1.2条）

常见组合方式：
- SVE + 生物通风
- 化学氧化 + 生物修复
- 土壤淋洗 + 生物修复/固化稳定化
- 原位热脱附 + SVE
- 固化稳定化 + 阻隔填埋
- 植物修复 + 化学钝化

组合策略：预处理+主处理+后处理、快速降浓+长效控制、重污染异位+轻污染原位、浅层修复+深层管控。

### 二次污染防控（第7.3条）

**废气（第7.3.1条）：** 密闭作业+负压收集+废气处理（活性炭吸附/催化燃烧/喷淋洗涤）+洒水抑尘+厂界监测。

**废水（第7.3.2条）：** 雨污分流+围堰排水沟+收集池调节池+按水质选择处理工艺+处理后优先回用、不能回用则达标排放+设施/暂存场防渗。

**固废（第7.3.3条）：** 分类收集暂存+危险废物交有资质单位+暂存场防渗防雨防扬散。

### 方案比选（第7.5条）

对2~3个备选方案综合比选，权重：技术可行性0.25、处理效果0.20、经济合理性0.20、环境友好性0.15、施工周期0.10、安全可靠性0.10。

## 修复工程实施（第8条）

### 施工过程管理要点（第8.2条）

- **质量管理**（第8.2.1条）：原材料检验、设备运行监控、工艺参数监控记录、中间产品检测、隐蔽工程验收
- **过程监测**（第8.3条）：修复效果监测、工艺参数监测（流量/压力/温度/药剂投加量/pH/DO）、二次污染监测（厂界颗粒物/VOCs/废水/噪声）、环境质量监测

### 监测频率（第8.3.3条）

施工初期高频验证、稳定期定期监测（一般每周1~2次或每月1~2次）、后期加密评估修复效果。

## 修复效果评估（第9条）

### 评估方法（第9.3条）

| 方法 | 说明 |
|------|------|
| 监测布点法 (9.3.1) | 系统布设监测点，采样分析对比修复目标值 |
| 对比评价法 (9.3.2) | 修复后与修复前对比：浓度变化率、达标率、去除率、风险降低程度 |
| 统计检验法 (9.3.3) | t检验、非参数检验、置信区间法 |
| 空间对比法 (9.3.4) | 空间插值分析：污染范围变化、程度变化、高浓度区变化 |

**布点要求（第9.3.1条）：** 不少于修复前监测点数量的 70%，满足统计检验要求。

### 合格判定（第9.4条）

同时满足：
1. **浓度达标**（第9.4.1条）：修复区域内土壤污染物浓度达到修复目标值
2. **达标率要求**：所有监测点达标率应达到一定比例（如 100% 或 95% 以上）
3. **风险可接受**：致癌风险和非致癌危害指数不超过可接受水平

不合格时：分析原因、评估剩余风险、制定补充修复方案、实施补充修复、重新评估。

## 修复验收（第10条）

### 验收程序（第10.2条）

1. 验收申请（施工单位向委托方提出）
2. 资料审查（完整性、规范性、合规性）
3. 现场核查（工程完成情况、环境状况、监测设施）
4. 采样监测（布点、采样、分析、监测报告）
5. 验收评审（评审会、汇报、查阅、质询、验收意见）
6. 验收结论（通过 / 限期整改后验收 / 不通过）

### 验收资料清单（第10.3条）

修复工程验收申请、土壤污染状况调查报告、风险评估报告、修复方案及批复、施工合同、施工组织设计、开工/完工报告、施工记录（日志/设备运行/药剂使用）、质保质控资料、过程监测报告、修复效果评估报告、竣工图、工程变更资料、环境监测报告、自验收报告。

### 后期管理（第10.4条）

**需长期监测的情况（第10.4.1条）：** 实施风险管控地块、修复后仍有低浓度污染物、污染物性质稳定可能长期存在、存在地下水污染、用途变更为敏感用地。长期监测内容和要求见 HJ 25.2。

**使用限制（第10.4.2条）：** 限制土地用途、限制开发深度、限制地下水开采、设置警示标志、建立场地档案。

**档案管理（第10.4.3条）：** 包含污染调查、风险评估、修复方案、施工记录、监测数据、验收资料、后期管理资料，应长期保存。

## 修复方案编制大纲（附录B）

完整修复方案应包含 15 个章节（附录B.1-B.15）：
概述、场地概况、污染状况与修复目标、修复技术筛选与比选、修复工艺设计、施工组织设计、质量保证与质量控制、安全文明施工、环境保护措施、过程监测方案、修复效果评估与验收、投资估算与资金筹措、效益分析、结论与建议、附件（附图/附表）。

## 术语定义（第3条）

| 术语 | 定义 | 条款 |
|------|------|------|
| 土壤修复 | 利用物理、化学或生物方法固定/转移/吸收/降解/转化污染物至可接受水平 | 3.1 |
| 原位修复 | 不移动污染土壤，直接在场地原位修复 | 3.2 |
| 异位修复 | 将污染土壤挖出或抽取后在场地内或场地外处理 | 3.3 |
| 修复目标 | 根据风险评估，结合技术可行性和经济合理性确定的污染物浓度限值或风险水平 | 3.5 |
| 风险管控 | 采取隔离、阻断、管控等措施降低风险，包括污染源控制、暴露途径阻断和长期监测 | 3.7 |
| 二次污染 | 修复过程中产生的新的污染物或污染形式对环境造成的新的污染 | 3.17 |
| 修复效果评估 | 修复工程完成后通过系统监测和评估判断是否达到预期修复目标 | 3.18 |
