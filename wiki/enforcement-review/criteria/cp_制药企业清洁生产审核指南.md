# 制药企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国制药行业协会发〔2022〕8号 |
| 适用范围 | 化学原料药、制剂、中成药、生物制药企业 |
| 发布机关 | 中国制药行业协会 |
| 实施日期 | 2022-07-01 |

## 二、主要内容
本指南针对制药企业特点，重点识别发酵罐、反应釜、蒸馏塔、离心机等关键设备清洁生产潜力。强调发酵染菌控制、溶剂回收、菌渣综合利用、VOCs源头减排。涵盖化学药、中药、生物药三大类审核重点。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 收率、溶剂消耗强度 |
| 审核 | 反应釜、发酵罐重点 |
| 方案筛选 | 溶剂回收+菌渣利用 |
| 高费方案 | 发酵工艺优化 |
| 实施验证 | 收率+环保双效益 |
| 持续改进 | GMP同步审核 |

## 四、合规要点
1. 发酵染菌率应低于行业标准，提升菌体利用率。
2. 溶剂回收装置应配套，回收率不低于70%。
3. 发酵菌渣应按HJ 1091综合利用。
4. VOCs应执行GB 37823排放标准。
