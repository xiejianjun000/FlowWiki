# HJ 1124-2020 排污许可证申请与核发技术规范 火葬场

## 一、标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 1124-2020 |
| 发布日期 | 2020-02-28 |
| 实施日期 | 2020-02-28 |
| 发布机关 | 生态环境部 |
| 适用范围 | 火葬场（殡仪馆火化间）排污单位 |

## 二、适用范围

本标准适用于指导火葬场排污单位在全国排污许可证管理信息平台填报相关申请信息，指导核发机关审核确定排污单位排污许可要求。

## 三、产污环节与主要污染物

### 3.1 主要生产单元
- 遗体火化（火化炉）
- 祭品焚烧
- 废气处理

### 3.2 主要污染物
- 废气：颗粒物、二氧化硫、氮氧化物、一氧化碳、二噁英类、烟尘、汞
- 废水：COD、SS、氨氮、动植物油、总磷、细菌总数
- 固废：火化残渣、骨灰、污泥

## 四、许可排放限值

### 4.1 大气污染物排放限值

| 污染物 | 排放浓度限值(mg/m³) |
|--------|---------------------|
| 颗粒物 | 80 |
| 二氧化硫 | 100 |
| 氮氧化物 | 300 |
| 一氧化碳 | 100 |
| 二噁英类 | 0.5 ng-TEQ/m³ |
| 汞及其化合物 | 0.1 |

### 4.2 水污染物排放限值（直接排放）

| 污染物 | 排放限值(mg/L) |
|--------|----------------|
| COD | 60 |
| SS | 50 |
| 氨氮 | 10 |
| 动植物油 | 3.0 |
| 总磷 | 0.5 |

## 五、监测要求

- 火化炉烟气净化装置出口监测二噁英（半年一次）
- 主要排口安装颗粒物在线监测
- 废水总排口季度监测

## 六、违法处罚依据

依据《大气污染防治法》第99条、《水污染防治法》第83条、《排污许可管理条例》第33-35条。

## 七、对企业环保合规工作的启示

1. 重点控制二噁英排放，配备烟气急冷装置
2. 加强汞排放监测，配备活性炭喷射系统
3. 火化残渣规范处置
4. 落实殡葬服务场所环境影响评价
