# DB43/ 3082—2024 工业炉窑主要大气污染物排放标准

**发布日期**: 2024-08-25  
**实施日期**: 2024-09-25  
**批准机关**: 湖南省人民政府  
**归口单位**: 湖南省生态环境厅  
**起草单位**: 湖南省环境保护科学研究院、中冶长天国际工程有限责任公司、湖南省生态环境事务中心、长沙有色冶金设计研究院有限公司、中南大学、湘潭大学


## 一、适用范围

本文件规定了湖南省工业炉窑主要大气污染物有组织排放控制要求、监测和监督管理要求。

**适用行业**：
- 水泥工业（C3011）
- 钢铁工业（炼铁C3110、炼钢C3120、钢压延加工C3130、铁合金冶炼C3140）
- 焦化工业（C2521）
- 砖瓦工业（C3031）
- 陶瓷工业（C3071~C3079、C3089）
- （次）氧化锌工业（C3212、C2613、C4210）
- 有色金属废弃资源综合利用工业（C4210）

**不适用**：水泥原料矿山开采、水泥制品制造、砼结构构件制造等。

## 三、基准含氧量换算公式

**公式（1）**：
```
ρ基 = (21 - O基) / (21 - O实) × ρ实
```

式中：
- ρ基：大气污染物基准排放浓度（mg/m³）
- ρ实：实测排放浓度（mg/m³）
- O基：基准含氧量百分率
- O实：实测含氧量百分率

**有色金属废弃资源综合利用工业采用公式（2）**：
```
ρ基 = Q实 / (10000 × M) × ρ实
```

基准排气量：**10000 m³/t产品**


## 四、监测要求

### 4.1 采样位置
- 应在处理设施后监测
- 废气应急旁路：采样点安装在旁路与处理设施混合后的烟道内

### 4.2 分析方法标准

| 污染物 | 标准名称 | 标准编号 |
|-------|---------|---------|
| 颗粒物 | 固定污染源废气 低浓度颗粒物的测定 重量法 | HJ 836 |
| SO₂ | 固定污染源废气 二氧化硫的测定 便携式紫外吸收法 | HJ 1131 |
| NOx | 固定污染源废气 氮氧化物的测定 便携式紫外吸收法 | HJ 1132 |
| 氨 | 环境空气和废气 氨的测定 纳氏试剂分光光度法 | HJ 533 |


## 五、与湖南溯源项目的关联

### 5.1 超低排放判据

**水泥企业超低排放达标条件**：
- 颗粒物 ≤ 10 mg/m³
- SO₂ ≤ 35 mg/m³
- NOx ≤ 50 mg/m³
- 氨逃逸 ≤ 8 mg/m³

**溯源应用**：当监测站PM2.5/PM10比值>0.8且CO>1.5 mg/m³时，若周边水泥企业未达标，可判定为疑似主源。

### 5.2 钢铁企业特征因子

**华菱涟钢、湘钢溯源判据**：
- 烧结机机头：颗粒物10、SO₂ 35、NOx 50
- 热风炉：颗粒物10、SO₂ 50、NOx 200
- 石灰窑：颗粒物10、SO₂ 200、NOx 300

**溯源应用**：当涟钢职大站PM2.5偏高，若同时检测到SO₂>50、NOx>200，可能来自热风炉/石灰窑；若SO₂<35、NOx<50，说明烧结机已超低排放，需排查其他工序。

### 5.3 时间节点对照

| 企业类型 | 超低排放截止时间 | 溯源判据调整 |
|---------|-----------------|------------|
| 水泥（传输通道8市） | 2025-12-01 | 此后未达标企业加重嫌疑 |
| 水泥（其他6市州） | 2026-06-01 | 此后未达标企业加重嫌疑 |
| 钢铁 | 2025-10-01 | 此后未达标企业加重嫌疑 |
| 焦化 | 2026-01-01 | 此后未达标企业加重嫌疑 |


## 六、代码集成建议

### 6.1 source_parser.py 新增常量

```python
# 湖南省 DB43/3082-2024 工业炉窑超低排放限值
HUNAN_CEMENT_ULTRA_LOW = {
    'PM': 10,   # mg/m³
    'SO2': 35,
    'NOx': 50,
    'NH3': 8,
    'O2_base': 10  # %
}

HUNAN_STEEL_ULTRA_LOW = {
    'sinter': {'PM': 10, 'SO2': 35, 'NOx': 50, 'NH3': 8},
    'hot_blast': {'PM': 10, 'SO2': 50, 'NOx': 200, 'NH3': 8},
    'lime_kiln': {'PM': 10, 'SO2': 200, 'NOx': 300, 'NH3': 8}
}

HUNAN_COKING_ULTRA_LOW = {
    'coke_oven': {'PM': 10, 'SO2': 30, 'NOx': 150, 'NH3': 8}
}
```

### 6.2 判据校准逻辑

```python
def check_ultra_low_compliance(city, enterprise_type, pm25, pm10, so2, nox, co, nh3=None):
    """
    检查企业是否达到超低排放标准
    返回：(达标状态, 偏离程度, 疑似贡献)
    """
    if enterprise_type == 'cement':
        limits = HUNAN_CEMENT_ULTRA_LOW
        # 水泥特征：PM2.5/PM10<0.5，CO低
        if pm25/pm10 < 0.5 and so2 > limits['SO2']:
            return False, (so2 - limits['SO2']) / limits['SO2'], 0.6
    elif enterprise_type == 'steel':
        # 钢铁特征：CO高，NOx高
        if co > 1.5 and nox > 200:
            return False, (nox - 200) / 200, 0.7
    
    return True, 0, 0
```


## 七、关键认知

### 7.1 超低排放≠零排放

即使企业达到超低排放标准，仍会排放：
- 水泥窑颗粒物10 mg/m³ × 烟气量~100万m³/h = 10 kg/h
- 烧结机NOx 50 mg/m³ × 烟气量~200万m³/h = 100 kg/h

**溯源判断**：达标企业仍可能是主源，但需结合气象扩散条件。

### 7.2 氨逃逸新指标

本标准首次将**氨排放限值8 mg/m³**纳入强制要求（适用于使用氨水、尿素脱硝的企业）。

**溯源应用**：当监测站检测到NH₃浓度偏高（>0.5 mg/m³），且周边有脱硝设施企业，可判定氨逃逸。

### 7.3 基准含氧量差异

不同工序基准含氧量差异大：
- 水泥窑：10%
- 烧结机：16%/18%
- 焦炉：8%

**换算影响**：实测浓度需换算后才能与标准对比，否则可能误判。
