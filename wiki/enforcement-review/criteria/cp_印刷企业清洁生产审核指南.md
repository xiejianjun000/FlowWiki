# 印刷企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国印刷技术协会发〔2022〕6号 |
| 适用范围 | 平版、凹版、凸版、孔版及数字印刷企业 |
| 发布机关 | 中国印刷技术协会 |
| 实施日期 | 2022-07-15 |

## 二、主要内容
本指南针对印刷企业特点，重点识别印前、印刷、印后等关键工序清洁生产潜力。强调无水胶印、UV印刷、水性油墨、润版液循环使用。涵盖VOCs全流程管控、有机溶剂回收审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万元产值VOCs |
| 审核 | 印刷、复合工序 |
| 方案筛选 | 水性油墨+UV印刷 |
| 高费方案 | 无溶剂复合 |
| 实施验证 | VOCs减排 |
| 持续改进 | 数字化升级 |

## 四、合规要点
1. 应采用UV印刷或无水胶印工艺。
2. 复合工序应采用无溶剂或水性胶复合。
3. VOCs应执行GB 37822排放标准。
4. 废印版、废油墨桶应建立回收渠道。
