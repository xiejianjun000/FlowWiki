# 危险废物填埋场设计技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014第5章 |
| 适用范围 | 填埋场设计 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场的总体设计要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 总体布局 | 填埋区、辅助区、管理区分开 |
| 场地整平 | 底部坡度≥2% |
| 截洪沟 | 场区外围设置截洪沟 |
| 道路设计 | 满足运输和作业要求 |
| 绿化要求 | 场区周围设置绿化带 |

## 四、合规要点
1. 设计阶段充分考虑各功能区布局
2. 场地整平保证渗滤液导排
3. 截洪沟防止雨水进入填埋区
4. 绿化带减少环境影响
