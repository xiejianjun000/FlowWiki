# 危险废物焚烧酸性气体控制技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18484-2020附录 |
| 适用范围 | 酸性气体控制 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物焚烧过程酸性气体的控制技术。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 酸性气体 | HCl、SO₂、HF |
| 脱酸工艺 | 半干法、干法、湿法 |
| 脱酸剂 | Ca(OH)₂、NaOH |
| 排放限值 | HCl≤60mg/m³、SO₂≤200mg/m³ |
| 脱酸效率 | ≥90% |

## 四、合规要点
1. 配置脱酸系统控制酸性气体
2. 脱酸剂合理选择和投加
3. 定期监测酸性气体排放
4. 排放浓度符合限值
