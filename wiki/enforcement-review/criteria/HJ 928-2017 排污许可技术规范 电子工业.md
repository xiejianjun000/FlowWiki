## HJ 928-2017 排污许可证申请与核发技术规范 电子工业

### 一、标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 928-2017 |
| 发布日期 | 2017-12-29 |
| 实施日期 | 2017-12-29 |
| 发布机关 | 环境保护部 |
| 适用范围 | 电子工业排污单位（含电子元器件、电子专用材料、电真空器件、半导体、集成电路等制造） |

### 二、适用范围

本标准适用于指导电子工业排污单位在全国排污许可证管理信息平台填报相关申请信息，指导核发机关审核确定排污单位排污许可要求。

### 三、产污环节与主要污染物

#### 3.1 主要生产单元
- 半导体制造：晶圆制造、光刻、刻蚀、离子注入、化学机械抛光
- 显示器件制造：阵列、彩膜、成盒、模组
- 印制电路板制造：钻孔、电镀、蚀刻、阻焊、表面处理
- 电子元器件制造：清洗、装配、测试

#### 3.2 主要污染物
- 废气：酸性气体（硫酸雾、盐酸雾、硝酸雾、氢氟酸）、碱性气体（氨）、VOCs（异丙醇、丙酮等）、特征污染物（磷化氢、砷化氢）
- 废水：重金属（铜、镍、铬、铅、镉）、氟化物、氰化物、COD、SS、氨氮、总磷
- 固废：含铜污泥、含镍污泥、废酸、废碱、废蚀刻液、废溶剂（HW17、HW34、HW06）

### 四、许可排放限值

#### 4.1 大气污染物排放限值

| 污染物 | 排放浓度限值(mg/m³) |
|--------|---------------------|
| 氟化物 | 9 |
| 氯气 | 5 |
| 氯化氢 | 30 |
| 硫酸雾 | 30 |
| 氮氧化物 | 240 |
| 氨 | 30 |
| 非甲烷总烃 | 80 |

#### 4.2 水污染物排放限值（直接排放）

| 污染物 | 排放限值(mg/L) |
|--------|----------------|
| 总铜 | 0.5 |
| 总镍 | 0.5 |
| 总铬 | 1.0 |
| 六价铬 | 0.2 |
| 总铅 | 0.5 |
| 总镉 | 0.05 |
| 氟化物 | 10 |
| 氰化物 | 0.2 |

### 五、监测要求

- 重金属废水排口在线监测
- 含氟、含氰废水单独处理
- 废气处理设施出口定期监测特征污染物

### 六、违法处罚依据

依据《大气污染防治法》第99条、《水污染防治法》第83条、《排污许可管理条例》第33-35条。

### 七、对企业环保合规工作的启示

1. 重金属废水分质处理，避免交叉污染
2. 加强含氟、含氰废水专项治理
3. 规范危险废物（HW17、HW34、HW06）贮存与转移
4. 落实特征污染物（砷、磷化氢）监测与风险防控
