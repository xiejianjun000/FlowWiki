# 危险废物跨省转移审批程序

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 部令第23号 |
| 适用范围 | 跨省转移审批 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物跨省转移的申请、审批和监管程序。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 审批层级 | 生态环境部审批 |
| 审批时限 | 20个工作日内作出决定 |
| 申请材料 | 转移申请、合同、接受单位资质 |
| 有效期 | 每次审批有效期1年 |
| 监管要求 | 全程通过信息系统跟踪 |

## 四、合规要点
1. 提前申请跨省转移审批
2. 申请材料齐全符合要求
3. 审批通过后方可转移
4. 转移过程接受全程监管
