# 含氰废液物化处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014附录 |
| 适用范围 | 含氰废液物化处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了含氰废液物化处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 电镀含氰废液、含氰废水 |
| 处理工艺 | 碱性氯化法 |
| 氧化剂 | 次氯酸钠、液氯 |
| 反应条件 | pH≥10，氧化还原电位控制 |
| 出水要求 | 氰化物≤0.5mg/L |

## 四、合规要点
1. 含氰废液单独收集处理
2. 严格控制反应pH和电位
3. 出水氰化物达标排放
4. 操作做好防护防中毒
