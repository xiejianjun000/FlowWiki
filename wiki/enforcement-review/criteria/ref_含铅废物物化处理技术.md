# 含铅废物物化处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014附录 |
| 适用范围 | 含铅废物物化处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了含铅废物物化处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 含铅废液、铅蓄电池废料 |
| 处理工艺 | 化学沉淀+过滤 |
| 沉淀剂 | 氢氧化钠、碳酸钠 |
| pH控制 | 8-9 |
| 出水要求 | 铅≤1.0mg/L |

## 四、合规要点
1. 含铅废物单独收集处理
2. 控制最佳沉淀pH值
3. 出水铅含量达标排放
4. 污泥按危废规范处置
