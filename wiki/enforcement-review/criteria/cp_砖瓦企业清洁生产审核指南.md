# 砖瓦企业清洁生产审核指南

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 中国砖瓦工业协会发〔2022〕4号 |
| 适用范围 | 烧结砖瓦、非烧结砖瓦生产企业 |
| 发布机关 | 中国砖瓦工业协会 |
| 实施日期 | 2022-06-15 |

## 二、主要内容
本指南针对砖瓦企业特点，重点识别原料制备、成型、干燥、焙烧等关键工序清洁生产潜力。强调隧道窑节能改造、烟气脱硫除尘、工业废渣利用。涵盖窑炉升级、废坯废砖回收审核要求。

## 三、清洁生产技术要求
| 审核阶段 | 关键技术要点 |
|---------|-------------|
| 预审核 | 万块砖能耗、SO₂ |
| 审核 | 隧道窑、干燥窑 |
| 方案筛选 | 隧道窑+脱硫除尘 |
| 高费方案 | 工业废渣利用 |
| 实施验证 | 节能+减排 |
| 持续改进 | 自动化升级 |

## 四、合规要点
1. 应使用隧道窑，淘汰轮窑。
2. 应配套烟气脱硫除尘，脱硫效率不低于85%。
3. 鼓励利用粉煤灰、煤矸石等工业废渣。
4. 废坯、废砖应全部回收利用。
