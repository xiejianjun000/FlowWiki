## 三、代码改进

### 3.1 新增4个方法（diagnosis.py）

```python
# 设备异常多参数耦合检测
def _check_equipment_anomaly(self, city_data: Dict) -> Dict
    - PM2.5/PM10物理约束检查
    - O3/NO2光化学滴定关系验证
    - 固值型故障识别
    - 置信度量化评分

# BLH清晨闸门效应
def _check_blh_dawn_gate(self, weather: Dict, hourly: List[Dict]) -> Dict
    - 清晨(05-10时)BLH<400m检测
    - 弱风+高湿强化判断
    - 闸门机制说明（扩散容量收缩放大效应）

# PM2.5/PM10相态跃迁
def _check_phase_transition_pm(self, hourly, city_data, weather) -> Dict
    - 细粒(>0.8)/混合/粗粒(<0.5)三相判断
    - 高温强氧化SOA驱动检测

# 区域同步性评估
def _check_regional_sync(self, city_data: Dict, region_avg: float) -> Dict
    - 本地vs区域比值量化
    - 同步/放大/本地独立三模式
```

## 五、湖南溯源应用建议

### 5.1 设备QA验证（新增）
- 当某站点数据异常时，先用`_check_equipment_anomaly`排除设备问题
- 避免误判为污染源导致的真实数据异常

### 5.2 清晨高值诊断（强化）
- 藁城+昌黎共性机制：**BLH清晨闸门效应**
- 湖南适用：所有城市清晨污染异常诊断
- 关键：不需要排放端变化，扩散容量收缩即可放大浓度

### 5.3 相态跃迁诊断（新增）
- 邯郸方法：PM2.5/PM10比值+峰位分析
- 湖南适用：长沙/株洲/岳阳夏季高温季节
- 判断当前是细粒主导(二次)还是粗粒主导(扬尘)

### 5.4 区域联防联控（强化）
- PM2.5区域同步→长株潭联合管控优先级高
- PM10站点差异→本地扬尘管控为主
- 温江方法：本地放大≠本地排放更强
