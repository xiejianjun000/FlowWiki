# 危险废物转移风险防控技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 169-2018 |
| 适用范围 | 转移风险防控 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物转移全过程的风险识别、评估和防控措施。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 风险源 | 废物特性、包装、运输、装卸 |
| 风险评估 | 概率分析+后果评估 |
| 防控措施 | 包装、运输、应急多重防控 |
| 风险等级 | 高、中、低三级管控 |
| 动态管理 | 根据风险变化调整措施 |

## 四、合规要点
1. 转移前开展风险评估
2. 落实包装、运输、应急防控措施
3. 按风险等级实施差异化管理
4. 风险变化时及时调整防控
