# 危险废物填埋场固化固化技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 2042-2014第6章 |
| 适用范围 | 固化技术 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场固化处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 固化工艺 | 水泥固化、沥青固化、塑料固化 |
| 水泥固化 | 水泥+废物+水混合养护 |
| 沥青固化 | 高温沥青包覆废物 |
| 塑料固化 | 热塑性塑料包覆废物 |
| 性能要求 | 抗压强度≥0.98MPa |

## 四、合规要点
1. 选择适合废物特性的固化工艺
2. 固化体性能指标达标
3. 固化过程防止二次污染
4. 记录固化工艺参数
