# 危险废物填埋场监测技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB 18598-2019第8章 |
| 适用范围 | 填埋场监测 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物填埋场环境监测的项目、频次和方法。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 监测对象 | 地下水、土壤、大气、渗滤液 |
| 监测井布设 | 上游1个，下游≥3个 |
| 监测频次 | 地下水季度，土壤年度 |
| 监测项目 | 特征污染物+常规指标 |
| 数据管理 | 建立监测档案定期分析 |

## 四、合规要点
1. 按规范开展多要素环境监测
2. 监测项目和频次符合要求
3. 监测数据与背景值对比分析
4. 发现异常及时排查处置
