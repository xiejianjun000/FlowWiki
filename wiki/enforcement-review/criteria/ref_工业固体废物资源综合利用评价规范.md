# 工业固体废物资源综合利用评价规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 41015-2021 |
| 适用范围 | 工业固废资源综合利用评价活动 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了工业固废综合利用评价的原则、程序、指标体系和方法，规范评价活动。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 评价指标 | 资源利用率、环境效益、经济效益 |
| 评价程序 | 申请→受理→评审→公示→发证 |
| 评价周期 | 每3年复评一次 |
| 评价等级 | A级、B级、C级三级 |
| 证明文件 | 评价报告、检测报告、台账 |

## 四、合规要点
1. 委托具有资质的第三方机构开展评价
2. 保存评价资料至少5年
3. 评价结果作为享受税收优惠的依据
4. 综合利用量数据应与台账一致
