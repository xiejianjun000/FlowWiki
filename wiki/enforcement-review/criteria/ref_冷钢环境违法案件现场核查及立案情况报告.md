# 冷钢环境违法案件现场核查及立案情况报告

关于冷水江钢铁有限责任公司
环境违法案件现场核查及立案情况的报告
一、案件来源及背景
根据生态环境部调研交办问题清单，娄底市生态环境支队联合省厅专家组成调查组，对冷水江钢铁有限责任公司（以下简称"冷钢"）涉嫌环境违法问题开展现场核查。本次核查主要针对《生态环境部调研冷水江钢铁有限责任公司交办问题整改调度清单》中列明的相关问题，重点包括：自动和手工监测弄虚作假、自动监测设备不正常运行等环境违法行为。
二、现场核查情况
（一）气态污染物分析仪软件涉嫌存在作弊后门问题
根据交办问题清单，气态污染物分析仪可以人为修改进入设置界面，关闭SO₂监测，使输出到数采仪的SO₂数值变为0。现场查看历史监测数据发现，1月23日15:30左右SO₂数据出现波动上升，期间部分实测值达到75mg/m³，几分钟后SO₂数据陡降为0，0值持续11小时左右；4月16日6时48分起数据波动上升，几分钟后SO₂数据陡降为0，0值持续到8小时左右。
经娄底支队及省厅专家初步核实，烟气分析仪后台未发现有修改过参数的行为。该烟气分析仪持有相关机构颁发的合格证书，SO₂选项的勾选暂无证据表明为作弊选项。目前，工作专班正在联系具有资质的鉴定机构对该设备开展司法鉴定，以进一步确认是否存在软件作弊功能。
（二）人为干扰自动监测数据问题
根据交办问题清单，2026年1月25日—27日重污染天气预警期间，企业涉嫌通过断开污染物采样管路以及人为干扰流速测量设备，使氮氧化物、氧含量分别从24.9mg/m³、15.35%突变为0、20.17%，流量及流速由741243Nm³/h、4.1m/s陡降至-4448Nm³/h、-0.02m/s，制造停产假象。由于自动监测站房未按照《生态环境监测条例》要求安装视频监控，通过查看生产DCS数据，该时段全部设备参数瞬时归为零值，与烧结停产工艺逻辑不符，涉嫌伪造停运停产数据。
经现场核实，冷钢涉嫌虚假标记问题属实。根据初步调查情况，2026年1月27日，冷钢炼铁厂烧结工序未落实重污染天气应急响应措施，擅自恢复生产。调查中发现，相关人员人为采用拔管的方式干扰在线监测平台数据，该行为涉嫌干扰自动监测设施正常运行。目前，相关证据已锁定，正在进行案情询问。
（三）其他涉嫌违法问题
1. 自行监测报告造假问题：现场查看企业自行监测报告（编号BYCJ260110161），烧结脱硫废气（DA048）氟化物监测原始记录及监测报告中有氧含量测试结果，但没有烟气测试打印小票，也没有氧含量校准记录，涉嫌编造氧含量测试数据。
2. 自动监测站点未安装视频监控设备问题：不满足《生态环境监测条例》第二十一条关于视频监控设备安装的要求。
3. 烟气测试不规范问题：现场查看自行监测报告（编号BYCJ260110161），DA063等6个排气筒烟气测试未按照HJ 397规定在一小时内等时间间隔采集3~4个样品，而是在2个小时内采集了3个样品。
三、证据锁定情况
调查组已对以下证据进行固定和锁定：
1. 2026年1月25日—27日重污染天气预警期间DCS关键数据、在线监测日志等电子证据；
2. 2026年1月27日冷钢炼铁厂烧结工序生产记录及重污染天气应急响应期间企业停产限产执行情况资料；
3. 在线监测平台数据异常记录及拔管干扰的相关证据；
4. 自行监测报告（编号BYCJ260110161）及原始检测记录；
5. 相关人员询问笔录及现场检查记录。
四、违法事实认定
（一）未落实重污染天气应急响应措施
冷钢炼铁厂烧结工序在2026年1月27日重污染天气应急响应期间，未按照要求落实停产限产措施，擅自恢复生产，违反了重污染天气应急管理相关规定。
（二）干扰自动监测设施
相关人员采用拔管方式干扰在线监测平台数据，使氮氧化物、氧含量、流量及流速等监测数据出现异常突变，该行为涉嫌构成干扰自动监测设施正常运行的环境违法行为。
（三）自行监测报告造假
企业自行监测报告（编号BYCJ260110161）中烧结脱硫废气（DA048）氟化物监测原始记录及监测报告中有氧含量测试结果，但没有烟气测试打印小票，也没有氧含量校准记录，涉嫌编造氧含量测试数据。
（四）自动监测站点未安装视频监控设备
企业自动监测站点未按照《生态环境监测条例》第二十一条要求安装、使用可以获取监测活动过程和监测设备运行情况的视频监控设备，并与生态环境主管部门联网。
五、立案依据
根据《中华人民共和国大气污染防治法》第二十条、第二十四条、第一百条，《中华人民共和国环境保护法》第六十三条，以及《环境保护主管部门实施按日连续处罚办法》《行政主管部门移送适用行政拘留环境违法案件暂行办法》等规定，冷钢上述行为涉嫌构成环境违法，符合立案条件。
六、处理建议
1. 建议对冷钢环境违法行为正式立案，开展进一步调查取证；
2. 鉴于该案涉及干扰自动监测设施，可能涉嫌刑事犯罪，建议立即启动行刑衔接程序，将案件线索移送公安机关；
3. 继续推进烟气分析仪司法鉴定工作，根据鉴定结论进一步确定是否存在软件作弊行为；
4. 约谈第三方检测公司，核实自行监测报告真实性，依法处理责任主体；
5. 督促企业完成自动监测站点视频监控设备安装，对冷钢其他生产环节开展全面排查，严格落实环境保护主体责任。
七、下一步工作计划
1. 完成案情询问，形成完整的询问笔录；
2. 协调司法鉴定机构尽快开展烟气分析仪鉴定工作；
3. 整理完善案卷材料，依法作出行政处罚决定；
4. 按程序移送涉嫌刑事犯罪线索，配合公安机关开展后续工作。
工作专班现场核查组
