# 废旧电子元器件回收处理技术

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 527-2010附录 |
| 适用范围 | 电子元器件回收处理 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了废旧电子元器件回收处理的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 适用废物 | 各类废旧电子元器件 |
| 处理工艺 | 分选+冶金回收 |
| 贵稀金属回收 | 金、银、铂、钯、铑 |
| 再生利用 | 再生原料符合标准 |
| 污染防治 | 防止二次污染 |

## 四、合规要点
1. 采用先进工艺回收贵稀金属
2. 再生原料符合产品标准
3. 处理过程防止二次污染
4. 建立处理记录档案
