# 各省清洁生产审核实施细则 陕西

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 陕发改规〔2023〕4号 |
| 适用范围 | 陕西省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 陕西省发展和改革委员会、陕西省生态环境厅 |
| 实施日期 | 2023-08-01 |

## 二、主要内容
陕西省实施细则结合黄河流域生态保护和西部大开发战略，重点推动陕北能源化工、关中装备制造、陕南绿色产业三大区域特色审核。强化煤炭、石油、天然气开采及加工企业审核要求。

## 三、清洁生产技术要求
| 阶段 | 陕西特色要求 |
|------|-------------|
| 名单确定 | 黄河流域+西部开发 |
| 三大区域 | 陕北能源、关中装备、陕南绿色 |
| 能源化工 | 煤炭、石油、天然气 |
| 黄河保护 | 退耕还林还草协同 |
| 西部开发 | 政策优惠叠加 |

## 四、合规要点
1. 陕北能源化工企业审核应包含矿井水、煤矸石综合利用。
2. 关中装备制造企业审核应突出节能减排技术改造。
3. 陕南绿色产业企业审核应注重生态保护。
4. 西部大开发税收优惠与审核通过情况挂钩。
