# 各省清洁生产审核实施细则 辽宁

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 辽发改规〔2023〕5号 |
| 适用范围 | 辽宁省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 辽宁省发展和改革委员会、辽宁省生态环境厅 |
| 实施日期 | 2023-07-01 |

## 二、主要内容
辽宁省实施细则对接东北振兴战略，重点推动装备制造、石化、冶金等老工业基地支柱产业清洁生产升级。建立辽宁沿海经济带审核协同机制，强化辽河流域水污染防治与审核协同。

## 三、清洁生产技术要求
| 阶段 | 辽宁特色要求 |
|------|-------------|
| 名单确定 | 老工业基地重点行业 |
| 重点产业 | 装备制造、石化、冶金 |
| 沿海经济带 | 协同审核机制 |
| 辽河流域 | 水污染防控协同 |
| 东北振兴 | 政策资金倾斜 |

## 四、合规要点
1. 装备制造、石化、冶金企业应每5年完成1次审核。
2. 辽河流域企业审核应包含水污染物总量控制内容。
3. 辽宁沿海经济带企业可跨市共享审核专家。
4. 通过审核企业享受东北振兴专项资金优先支持。
