# 各省清洁生产审核实施细则 山东

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | 鲁发改规〔2023〕6号 |
| 适用范围 | 山东省行政区域内开展清洁生产审核的企事业单位 |
| 发布机关 | 山东省发展和改革委员会、山东省生态环境厅 |
| 实施日期 | 2023-06-15 |

## 二、主要内容
山东省实施细则聚焦化工、钢铁、地炼、焦化等传统产业转型升级，建立"上新压旧、上大压小"清洁生产审核机制，强化产能置换与清洁生产协同。提出绿色低碳高质量发展先行区清洁生产示范工程。

## 三、清洁生产技术要求
| 阶段 | 山东特色要求 |
|------|-------------|
| 名单确定 | 双超双有+产能置换企业 |
| 重点行业 | 化工、钢铁、地炼、焦化 |
| 产能置换 | 与审核挂钩 |
| 示范工程 | 高质量发展先行区 |
| 海洋特色 | 海工装备、海洋化工 |

## 四、合规要点
1. 涉及产能置换企业应同步开展清洁生产审核。
2. 化工园区应整体推进清洁生产审核。
3. 钢铁、地炼企业审核应包含超低排放改造内容。
4. 验收通过企业纳入山东省绿色低碳先行区示范名录。
