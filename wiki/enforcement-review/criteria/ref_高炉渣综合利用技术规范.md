# 高炉渣综合利用技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GB/T 20308-2020 |
| 适用范围 | 高炉渣的综合利用活动 |
| 发布机关 | 国家市场监督管理总局 |

## 二、主要内容
规定了高炉渣水淬、膨化处理及在建材领域利用的技术要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 水渣质量系数 | ≥1.20 |
| 玻璃体含量 | ≥90% |
| 利用途径 | 矿渣水泥、矿渣粉、矿渣砖 |
| 活性指数 | 7天≥55%，28天≥75% |
| 含水率 | ≤1.0% |

## 四、合规要点
1. 水淬工艺控制水渣质量
2. 磨细矿渣粉符合GB/T 18046
3. 利用过程防止粉尘污染
4. 建立高炉渣利用台账
