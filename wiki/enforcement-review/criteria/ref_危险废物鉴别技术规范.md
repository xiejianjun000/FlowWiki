# 危险废物鉴别技术规范

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 298-2019 |
| 适用范围 | 危险废物鉴别的全过程技术规范 |
| 发布机关 | 生态环境部 |

## 二、主要内容
规定了危险废物鉴别的采样、检测、判定、报告编制等全过程要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 采样要求 | 份样数按产生量确定（5-50个） |
| 检测项目 | 根据废物特性确定 |
| 判定规则 | 份样超标率≥5%判为危废 |
| 报告内容 | 样品信息、检测数据、判定依据、结论 |
| 质量保证 | 采样、运输、检测全过程质控 |

## 四、合规要点
1. 采样方案经专家论证后实施
2. 样品保存和运输符合规范
3. 委托具备CMA资质的实验室检测
4. 鉴别报告结论明确、依据充分
