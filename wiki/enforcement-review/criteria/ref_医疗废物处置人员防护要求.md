# 医疗废物处置人员防护要求

## 一、基本信息
| 项目 | 内容 |
|------|------|
| 标准编号 | GBZ 1-2010 |
| 适用范围 | 处置人员防护 |
| 发布机关 | 国家卫生健康委 |

## 二、主要内容
规定了医疗废物处置人员的个人防护要求。

## 三、关键技术要求
| 项目 | 限值/要求 |
|------|-----------|
| 防护用品 | 防护服、口罩、手套、护目镜 |
| 防护等级 | 根据接触风险确定 |
| 操作要求 | 规范穿戴和脱卸 |
| 健康监护 | 上岗前、在岗职业体检 |
| 培训要求 | 定期防护培训 |

## 四、合规要点
1. 配备符合标准的防护用品
2. 规范穿戴和脱卸防护用品
3. 定期职业健康体检
4. 定期开展防护培训
