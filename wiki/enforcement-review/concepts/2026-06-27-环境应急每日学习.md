- **事件分级标准：**
  - 特别重大（Ⅰ级）
  - 重大（Ⅱ级）
  - 较大（Ⅲ级）
  - 一般（Ⅳ级）

### （二）湖南省最新政策（2024年修订）

#### 《湖南省突发环境事件应急预案管理办法（修订版）》
- **文件编号：** 湘环发〔2024〕49号
- **发布日期：** 2024年12月5日
- **有效期至：** 2029年12月5日

**八大核心变化：**

1. **完善适用范围**
   - 新增乡镇及以上集中式地表水饮用水水源地应急预案管理
   - 新增工业园区环境应急预案管理
   - 将环境应急预案分为：政府及部门预案、工业园区预案、企事业单位预案、临时预案

2. **明确编制责任主体**
   - 政府预案：县级以上生态环境主管部门
   - 园区预案：工业园区管理机构
   - 企业预案：企事业单位自身
   - 临时预案：大型活动主办单位

3. **豁免管理机制**
   - **重要突破：** 环境风险物质Q<1（Q为环境风险物质与临界量比值）的企事业单位可实行豁免管理
   - 豁免条件：风险极低，无需编制正式应急预案

4. **专业人员要求**
   - **较大及以上环境风险企事业单位**的应急预案编制人员中，至少有一名取得：
     - 注册环保工程师执业资格证书，或
     - 环境影响评价师执业资格证书
   - **目的：** 确保预案编制质量

5. **备案时限要求**
   - 预案责任主体须在外部评审后**90个工作日内**签署实施
   - 签署实施之日起：
     - 政府及部门预案：**30个工作日内**完成备案
     - 企事业单位预案：**20个工作日内**完成备案

6. **预案评审要求**
   - 政府及部门预案：需组织专家评审
   - 较大及以上风险企事业单位预案：需组织专家评审
   - 一般风险企事业单位预案：可自行组织评审或简化程序

7. **预案修订条件**
   - 法律法规发生变化
   - 应急组织指挥体系或职责调整
   - 环境风险发生重大变化
   - 重要应急资源发生重大变化
   - 预案演练或实际应对中发现问题
   - **修订周期：** 原则上每3年至少修订一次

8. **监督管理强化**
   - 建立应急预案管理台账
   - 定期开展预案执行情况检查
   - 将预案管理纳入生态环境执法内容

#### 《娄底市突发环境事件应急预案》（2024年修订版）

**预案结构（8个部分）：**

1. **总则**
   - 编制目的、依据、工作原则
   - 适用范围、事件分级、事件类型、预案体系

2. **组织指挥体系与职责**
   - 应急指挥机构设置
   - 各部门职责分工

3. **预防与预警机制**
   - 监测和风险分析
   - 预警分级、发布、行动
   - 信息报告与通报

4. **应急响应**
   - 响应分级、响应程序
   - 响应措施、响应终止

5. **后期工作**
   - 损害评估、善后处置、总结评估

6. **应急保障**
   - 队伍、物资、资金、通信、交通、技术、机制保障

- 重大/特别重大事件：30分钟内电话报告，60分钟内书面报告（同时上报生态环境部）

**特殊情况升级报告：**

## 二、新增知识点

### 1. 环境风险物质Q值豁免机制（湖南省创新）
- **Q值定义：** 环境风险物质与临界量的比值
- **Q<1：** 风险极低，可豁免编制应急预案
- **实操意义：** 减轻小微企业负担，聚焦高风险单位

### 2. 专业人员资格要求（湖南省严格要求）
- **适用对象：** 较大及以上环境风险企事业单位
- **资格要求：** 至少1名注册环保工程师或环评师参与预案编制
- **对比：** 国家层面无此硬性要求，湖南省提高了门槛

### 3. 备案时限压缩（湖南省效率提升）
- **国家要求：** 预案发布后20个工作日内备案
- **湖南省要求：**
  - 政府预案：签署实施后30个工作日内备案（略宽松）
  - 企业预案：签署实施后20个工作日内备案（与国家一致）
- **注意：** 湖南省增加了"外部评审后90个工作日内签署实施"的前置要求

### 4. 预案修订周期法定化
- **原则：** 每3年至少修订一次
- **触发条件：** 6种情形（法律法规变化、组织调整、风险变化、资源变化、发现问题等）
- **实操提示：** 建立预案修订台账，避免超期

### 5. 饮用水水源地预案独立管理
- **湖南省要求：** 乡镇及以上集中式地表水饮用水水源地需单独编制预案
- **娄底实践：** 娄星区已完成农村饮用水水源地预案编制
- **重要性：** 饮用水安全是环境应急的重中之重

## 三、实用操作指引

### 1. 企业应急预案编制流程（湖南省标准）
```
风险评估 → 预案编制（需专业人员参与） → 内部评审 → 外部专家评审（较大及以上风险） → 
签署实施（评审后90个工作日内） → 备案（签署后20个工作日内） → 演练 → 每3年修订
```

### 2. 应急预案核心要素检查清单
- [ ] 编制依据是否更新（法律法规变化）
- [ ] 风险识别是否全面（污染源、风险物质、敏感目标）
- [ ] 组织体系是否明确（指挥、协调、处置、保障）
- [ ] 预警分级是否合理（与事件分级匹配）
- [ ] 响应程序是否可操作（流程图、措施清单）
- [ ] 应急资源是否落实（队伍、物资、装备、资金）
- [ ] 信息报告是否畅通（时限、渠道、内容）
- [ ] 演练计划是否制定（每年至少1次）

### 3. 常见问题描述与改进
| 问题 | 表现 | 改进措施 |
|------|------|----------|
| 预案与实际脱节 | 照抄模板，无针对性 | 开展现场调研，结合企业实际 |
| 风险识别不全 | 遗漏次要风险源 | 全面排查，建立风险清单 |
| 响应程序模糊 | "及时处置""妥善处理"等模糊表述 | 量化时限、明确责任人、细化措施 |
| 应急资源不足 | 预案有要求，实际无装备 | 建立 resource 台账，定期核查 |
| 演练流于形式 | 仅签字拍照，无实战内容 | 设计实战场景，检验预案有效性 |
