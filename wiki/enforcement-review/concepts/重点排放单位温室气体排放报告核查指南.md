# 重点排放单位温室气体排放报告核查指南

**文件编号**：CETS—VC—02.01—V01—2024
**发布单位**：生态环境部
**实施日期**：2024年3月15日

---

## 一、适用范围

本指南规定了全国碳排放权交易市场重点排放单位温室气体排放报告的核查程序、核查内容、核查方法和核查报告要求。

本指南适用于纳入全国碳排放权交易市场的重点排放单位（以下简称"重点排放单位"）的年度温室气体排放报告核查工作。

本指南也适用于：
- 地方碳排放权交易市场重点排放单位的排放核查
- 重点排放单位的监督性核查
- 重点排放单位的复核和复查

### 1.1 核查对象

重点排放单位编制的年度温室气体排放报告。

### 1.2 核查范围

核查范围与重点排放单位报告的核算边界一致：

| 边界类型 | 具体内容 |
|---------|---------|
| 组织边界 | 重点排放单位法人边界内的所有生产设施 |
| 运行边界 | 范围1直接排放 + 范围2间接排放 |
| 时间边界 | 报告年度（1月1日至12月31日） |
| 温室气体种类 | CO₂为主，特定行业含CH₄、N₂O等 |

### 1.3 核查目的

1. 核实排放报告的真实性、准确性和完整性
2. 确认排放量数据，作为配额清缴的依据
3. 发现数据质量问题，督促企业整改
4. 保障碳排放权交易市场的数据质量

## 三、术语和定义

### 3.1 重点排放单位 key emission unit

纳入全国碳排放权交易市场配额管理的温室气体排放单位。

### 3.2 年度排放报告 annual emission report

重点排放单位每年编制并报送的，反映其年度温室气体排放情况的报告。

### 3.3 核查 verification

核查机构依据相关法规、标准和指南，对重点排放单位的排放报告进行系统、独立的审查和核实的过程。

### 3.4 核查机构 verification body

由生态环境主管部门确认的，具备相应能力，从事重点排放单位排放报告核查的第三方机构。

### 3.5 技术核查 technical verification

对排放报告的技术内容进行的核查，包括核算边界、活动数据、排放因子、计算过程等。

### 3.6 数据质量 data quality

排放数据满足准确性、完整性、一致性、可比性和透明性的程度。

### 3.7 重大差异 material discrepancy

核查确认的排放量与企业报告排放量之间的差异超过重要性阈值。

### 3.8 配额清缴 allowance surrender

重点排放单位按照规定向生态环境主管部门上缴与其排放量相等的碳排放配额的行为。

## 四、核查基本原则

### 4.1 独立公正原则

- 核查机构和人员应独立于被核查单位
- 与被核查单位无利益关系
- 不受任何不当干预
- 保持客观公正

### 4.2 科学规范原则

- 严格按照法规标准和指南开展核查
- 采用科学的核查方法
- 规范执行核查程序
- 确保核查质量

### 4.3 证据导向原则

- 核查结论基于充分、适当的证据
- 证据应可追溯、可验证
- 原始凭证优先
- 不轻信口头陈述

### 4.4 重点突出原则

- 重点关注高排放源
- 重点关注关键数据
- 重点关注高风险领域
- 合理分配核查资源

### 4.5 保守性原则

- 证据不足时采取保守判断
- 存在多种可能时采用偏保守的结论
- 不低估排放量
- 防范数据造假风险

## 五、核查程序

### 5.1 核查委托与受理

#### 5.1.1 委托主体

- 省级生态环境主管部门
- 市级生态环境主管部门
- 重点排放单位（自愿核查）

#### 5.1.2 核查机构选择

- 从生态环境主管部门确认的核查机构名录中选择
- 通过公开招标、竞争性谈判等方式确定
- 核查机构应具备相应行业能力

#### 5.1.3 签订合同

- 明确核查范围、内容、要求
- 明确时间进度
- 明确双方权利义务
- 明确费用和支付方式
- 明确保密条款

### 5.2 核查准备

#### 5.2.1 组建核查组

核查机构组建符合要求的核查组：

| 角色 | 人数 | 要求 |
|-----|------|------|
| 组长 | 1名 | 5年以上核查经验，高级职称 |
| 专业核查员 | ≥2名 | 具备相应行业专业背景 |
| 技术专家 | 按需 | 行业资深专家（必要时） |

**注意事项：**
- 核查组成员需进行利益冲突声明
- 与被核查单位有关系的人员应回避
- 核查组成员名单需报委托方备案

#### 5.2.2 收集资料

重点排放单位应提交以下资料：

| 类别 | 资料名称 | 备注 |
|-----|---------|------|
| 基本信息 | 营业执照、统一社会信用代码证 | 复印件加盖公章 |
| 排放报告 | 年度温室气体排放报告（正文+附表） | 正式版 |
| 能源数据 | 能源消费统计表、能源平衡表 | 分品种、分用途 |
| 购入凭证 | 煤炭、油品、天然气等购入发票、过磅单 | 抽查需提供原件 |
| 库存记录 | 燃料期初、期末库存盘点表 | 有盘点人、监盘人签字 |
| 检测报告 | 煤质检测报告、油质检测报告等 | 有CMA/CNAS标志 |
| 电力数据 | 电费结算单、购售电合同 | 电网企业出具 |
| 生产数据 | 产品产量统计报表、生产运行记录 | 月度+年度 |
| 计量资料 | 计量器具台账、检定/校准证书 | 在有效期内 |
| 其他 | 工艺流程图、设施清单、组织机构图 | 加盖公章 |

#### 5.2.3 文件评审

核查组对企业提交的资料进行文件评审：

**评审内容：**
1. 报告完整性
   - 是否包含所有必要内容
   - 附表是否齐全
   - 数据是否完整

2. 方法合规性
   - 是否采用正确的行业指南
   - 方法选择是否正确
   - 边界划分是否合理

3. 数据逻辑性
   - 数据间关系是否合理
   - 年度变化是否合理
   - 与行业水平是否匹配

4. 资料充分性
   - 支持材料是否足够
   - 是否需要补充资料
   - 现场核查重点

**文件评审输出：**
- 文件评审记录
- 重点核查领域
- 需补充的资料清单
- 现场核查计划

#### 5.2.4 制定核查计划

核查组制定详细的核查计划：

| 项目 | 内容 |
|-----|------|
| 核查目的 | 核实排放报告的真实性、准确性、完整性 |
| 核查范围 | 组织边界、运行边界、时间边界 |
| 核查依据 | 适用的指南、标准、法规 |
| 重要性水平 | 排放总量的±5%（可根据规模调整） |
| 核查组组成 | 组长、成员、分工 |
| 时间安排 | 现场核查日期 |
| 重点领域 | 高排放源、关键数据、高风险项 |
| 抽样方案 | 抽样比例、样本量 |

### 5.3 现场核查

#### 5.3.1 首次会议

**时间**：现场核查第一天上午，30-60分钟

**参会人员：**
- 核查组全体成员
- 企业分管领导
- 碳排放管理员
- 能源管理负责人
- 生产管理负责人
- 质量检测负责人
- 财务负责人

**会议议程：**
1. 核查组介绍
   - 核查目的、范围、依据
   - 核查程序和方法
   - 核查组人员及独立性声明
2. 企业介绍
   - 企业基本情况
   - 碳排放核算工作开展情况
   - 报告编制情况
3. 确认安排
   - 核查日程
   - 配合人员
   - 安全注意事项
4. 签署文件
   - 保密承诺
   - 公正性声明

#### 5.3.2 现场勘查

**勘查目的：**
- 核实核算边界
- 确认排放源
- 了解生产工艺
- 检查计量设施

**勘查路线：**

```
原料储存 → 生产装置 → 燃烧设施 → 环保设施 → 产品储存
     ↓
计量点勘查：能源计量仪表、物料计量仪表
```

**勘查要点：**

| 勘查对象 | 重点关注 |
|---------|---------|
| 生产设施 | 主要装置名称、型号、数量、产能 |
| 燃烧设施 | 锅炉/窑炉台数、型号、燃料类型 |
| 燃料储存 | 煤场、油罐、气柜位置及容量 |
| 计量设施 | 能源计量点、计量器具型号、精度 |
| 环保设施 | 脱硫脱硝、除尘、污水处理等 |
| 自备电厂 | 发电机组、发电量、自用电量 |

**勘查记录：**
- 填写现场勘查记录表
- 拍摄关键设施照片
- 记录异常情况

#### 5.3.3 数据核查

**第一类：燃料消耗量核查**

核查方法和要求：

| 核查项目 | 核查方法 | 抽样比例 | 证据类型 |
|---------|---------|---------|---------|
| 煤炭消耗量 | 凭证核对+台账核对+实物核对 | ≥15% | 发票、过磅单、库存账 |
| 油品消耗量 | 凭证核对+台账核对 | ≥20% | 发票、入库单、领用记录 |
| 天然气消耗量 | 流量计数据+结算单 | 100% | 结算单、流量计记录 |

**核查重点：**
1. 购入量核查
   - 核对发票数量与过磅单数量
   - 核对不同月份购入量变化
   - 关注大额、异常采购

2. 库存量核查
   - 盘点方法是否规范
   - 盘点记录是否完整
   - 库存变化是否合理

3. 消耗量计算
   - 公式是否正确：消耗 = 期初 + 购入 - 期末 - 外售
   - 计算是否准确
   - 与产量是否匹配

**第二类：燃料品质核查**

| 核查项目 | 核查方法 | 抽样比例 | 重点关注 |
|---------|---------|---------|---------|
| 元素碳含量 | 检查检测报告+复核计算 | 100% | 检测机构资质、检测频次、取值 |
| 低位发热量 | 检查检测报告+交叉验证 | 100% | 与元素分析的匹配性 |
| 工业分析 | 检查检测报告 | ≥50% | 水分、灰分、挥发分 |

**核查要点：**
1. 检测报告真实性
   - 是否有CMA/CNAS标志
   - 检测机构是否有资质
   - 报告是否有造假嫌疑

2. 检测频次
   - 燃煤：每月不少于1次，每批次必测
   - 燃油：每批次检测
   - 燃气：根据组分变化情况

3. 取值方法
   - 是否采用加权平均
   - 加权计算是否正确
   - 是否存在选用低值情况

**第三类：电力/热力核查**

| 核查项目 | 核查方法 | 证据要求 |
|---------|---------|---------|
| 外购电量 | 核对电网企业结算单 | 12个月全部结算单 |
| 自备发电量 | 核对发电记录+上网电量+自用电量 | 运行日志、结算单 |
| 外购蒸汽 | 核对热力公司结算单 | 12个月全部结算单 |
| 转供电/蒸汽 | 核对转供记录+接收方确认 | 协议、结算单 |

**第四类：生产数据核查**

- 产品产量核对
- 产量与能耗的匹配性分析
- 产能利用率分析
- 与历史数据对比

#### 5.3.4 核算过程核查

**1. 边界核查**
- 组织边界是否完整
- 运行边界是否完整
- 是否有遗漏的排放源
- 是否有不应纳入的设施

**2. 方法核查**
- 方法选择是否符合指南
- 公式是否正确
- 参数选取是否合理

**3. 计算核查**
- 关键排放源100%复算
- 一般排放源抽查≥50%
- 汇总数据100%验算

#### 5.3.5 人员访谈

通过访谈核实信息：

| 访谈对象 | 访谈内容 | 目的 |
|---------|---------|------|
| 企业领导 | 碳排放管理重视程度、体系建设 | 了解管理层面 |
| 碳排放管理员 | 核算流程、数据来源、问题处理 | 核实核算过程 |
| 司炉工/运行人员 | 燃料使用、设备运行 | 核实一线情况 |
| 化验人员 | 取样、检测过程 | 核实检测数据 |
| 库管员 | 燃料出入库、盘点 | 核实库存数据 |
| 财务人员 | 采购结算、发票管理 | 核实购入数据 |

**访谈技巧：**
- 多问开放式问题
- 关注细节和具体数据
- 注意前后一致性
- 交叉验证不同人员的回答

#### 5.3.6 内部沟通与问题确认

每日核查结束后召开内部会议：
- 汇总当日核查发现
- 评估证据充分性
- 确定次日工作重点
- 初步判断问题性质

对发现的问题，与企业沟通确认：
- 充分听取企业解释
- 核实相关证据
- 形成书面确认

#### 5.3.7 末次会议

**时间**：现场核查最后一天下午

**会议议程：**
1. 核查组总结核查工作
2. 通报核查发现的主要问题
3. 说明初步核查结论
4. 企业发表意见
5. 明确整改要求和时限
6. 说明后续工作安排

### 5.4 核查报告

#### 5.4.1 整改验证

对核查发现的不符合项，企业应整改：

| 不符合类型 | 整改要求 | 验证方式 |
|-----------|---------|---------|
| 重大不符合 | 必须整改，重新核算排放量 | 提交整改后的报告，必要时现场验证 |
| 一般不符合 | 视影响程度确定 | 提交整改说明和证据 |
| 观察项 | 建议改进 | 不需要验证，记录在案 |

**整改期限：**
- 一般为收到不符合通知后15个工作日内
- 重大不符合可延长至30个工作日

#### 5.4.2 编制核查报告

核查组根据核查结果编制核查报告。

#### 5.4.3 内部审核

核查机构内部三级审核：
- 一级审核：核查组组长审核
- 二级审核：技术负责人审核
- 三级审核：机构负责人批准

#### 5.4.4 提交报告

核查机构向委托方提交核查报告：
- 纸质版：一式三份（委托方、企业、核查机构存档）
- 电子版：PDF格式
- 报告应加盖公章，有骑缝章

## 六、核查内容与技术要点

### 6.1 核算边界核查

#### 6.1.1 组织边界

**核查要点：**
1. 法人资格核实
   - 营业执照
   - 统一社会信用代码
   - 法人代表

2. 设施清单核实
   - 所有生产设施是否纳入
   - 分公司、分厂是否纳入
   - 租赁设施的处理

3. 变更情况
   - 本年度新增设施
   - 本年度停运/拆除设施
   - 企业重组、分立、合并

**常见问题：**
- 遗漏辅助生产设施
- 遗漏自备电厂
- 将独立法人的设施纳入
- 边界划分前后年度不一致

#### 6.1.2 运行边界

**核查要点：**
1. 范围1排放源
   - 固定燃烧排放源：所有锅炉、窑炉、加热炉等
   - 移动燃烧排放源：厂内车辆、工程机械等
   - 工艺过程排放：碳酸盐分解、化学反应等
   - 逸散排放：气体燃料泄漏、制冷剂泄漏等

2. 范围2排放
   - 外购电力
   - 外购蒸汽/热力
   - 外购冷力（如有）

3. 生物质排放
   - 单独统计，不计入总量
   - 化石燃料掺烧部分需计入

### 6.2 活动数据核查

#### 6.2.1 燃煤消耗量

**核查方法详解：**

1. **购入量核查**
   - 核对增值税专用发票：发票数量、金额、供应商
   - 核对过磅单：毛重、皮重、净重、车号
   - 核对运输单据：运输合同、运单
   - 核对付款凭证：银行转账记录

2. **库存量核查**
   - 盘点方法：体积法、称重法、激光盘煤仪
   - 盘点记录：盘点时间、盘点人员、盘点数据
   - 库存变化：期初、期末库存的合理性
   - 煤堆密度：是否采用实测密度

3. **消耗量计算**
   ```
   消耗量 = 期初库存 + 本期购入 - 期末库存 - 外售量 - 其他减少
   ```
   - 公式是否正确
   - 数据是否匹配
   - 与锅炉运行记录对比

**关键风险点：**
- 少报购入量
- 多报期末库存
- 隐瞒真实消耗量
- 检测数据造假

#### 6.2.2 燃油/燃气消耗量

**核查要点：**
1. 购入凭证核查
2. 库存核查
3. 消耗记录核查
4. 与产量、设备运行时间对比

#### 6.2.3 电力消耗量

**核查要点：**
1. 外购电力
   - 以电网企业结算单为准
   - 注意峰谷平电价不影响电量
   - 线损、变损处理是否正确

2. 自备电厂
   - 发电量是否准确
   - 上网电量是否扣除
   - 自用电量是否正确
   - 厂用电率是否合理

3. 转供电
   - 是否有转供电情况
   - 转供电量是否扣除
   - 有无接收方确认

### 6.3 排放因子核查

#### 6.3.1 元素碳含量

**核查方法：**

1. **检测报告核查**
   - 检测机构资质：CMA/CNAS证书
   - 检测方法：GB/T 476（碳含量）、GB/T 212（工业分析）
   - 检测周期：每月至少1次
   - 检测项目：收到基碳、氢、氧、氮、硫、全水分、灰分、挥发分、低位发热量

2. **数据真实性核查**
   - 核查检测报告原件
   - 与检测机构核实（必要时）
   - 对比不同批次数据的合理性
   - 与供应商数据对比
   - 与历史数据对比

3. **取值方法核查**
   - 是否采用加权平均
   - 加权计算是否正确
   - 有无选择性取值

**加权平均公式：**
```
加权平均含碳量 = Σ(某批次煤量 × 该批次含碳量) / Σ各批次煤量
```

#### 6.3.2 低位发热量

**核查要点：**
1. 检测方法是否正确
2. 高位/低位换算是否正确
3. 与元素分析结果是否匹配

**低位发热量计算公式：**
```
Qnet,ar = Qgr,ar - 206×Har - 23×Mar
```
（近似公式，具体以实测为准）

#### 6.3.3 碳氧化率

**核查要点：**
1. 是否按指南取值
2. 特殊燃烧设备取值是否合理

**参考取值：**
- 煤粉炉：98%
- 层燃炉：95%
- 循环流化床：97%
- 燃气锅炉：99%
- 燃油锅炉：98%

### 6.4 计算过程核查

#### 6.4.1 燃烧排放计算

**标准公式：**
```
E_燃烧 = Σ (FC_i × C_ar,i × OF_i × 44/12)
```

**核查要点：**
1. 公式是否正确
2. 单位换算是否正确
3. 44/12系数是否正确使用
4. 各排放源计算是否正确
5. 汇总是否准确

#### 6.4.2 间接排放计算

**外购电力：**
```
E_电力 = EC × EF_电力
```

**核查要点：**
1. 电力排放因子取值是否正确
2. 是否采用最新公布的因子
3. 电网区域划分是否正确

## 七、重要性与风险

### 7.1 重要性水平

**重要性阈值：**

| 排放规模 | 相对重要性 | 绝对重要性（参考） |
|---------|-----------|------------------|
| ≥1000万tCO₂ | ±3% | ±30万tCO₂ |
| 100万~1000万tCO₂ | ±5% | ±5万~50万tCO₂ |
| 10万~100万tCO₂ | ±5% | ±0.5万~5万tCO₂ |
| <10万tCO₂ | ±10% | ±1万tCO₂ |

**重要性应用：**
- 超过重要性阈值的差异为重大差异
- 需追溯原因，必要时调整排放量
- 作为是否出具保留结论的依据

### 7.2 风险识别与应对

#### 7.2.1 高风险领域

| 风险领域 | 风险表现 | 风险等级 | 应对措施 |
|---------|---------|---------|---------|
| 燃煤消耗量 | 少报消耗、虚增库存 | 高 | 全量核查、交叉验证、现场盘点 |
| 燃煤含碳量 | 使用低值、检测造假 | 高 | 全量核查、抽样送检、趋势分析 |
| 自备电厂 | 少算排放、多扣减 | 高 | 全量核查、运行日志核对 |
| 核算边界 | 遗漏高排放设施 | 高 | 全面勘查、清单核对 |
| 工艺排放 | 低估排放量 | 中高 | 物料衡算、现场核查 |
| 外购电力 | 少报用电量 | 中 | 结算单核对 |

#### 7.2.2 常见造假手法及识别

| 造假手法 | 表现特征 | 识别方法 |
|---------|---------|---------|
| 少报购入量 | 发票数量与实际不符 | 过磅单核对、运输记录核对 |
| 虚增期末库存 | 盘点数据偏高 | 现场抽盘、体积复核、密度核对 |
| 选用低碳值煤样 | 检测报告数值偏低 | 对比历史数据、抽样送检 |
| 伪造检测报告 | 报告格式异常、印章不符 | 与检测机构核实 |
| 自备电厂多扣减 | 上网电量虚高 | 电网结算单核对 |
| 隐瞒排放设施 | 设施清单不全 | 现场勘查、卫星影像比对 |

## 八、核查结论与报告

### 8.1 核查结论类型

#### 8.1.1 无保留结论

**适用条件：**
- 排放报告符合指南要求
- 未发现重大不符合
- 排放量差异在重要性阈值以内
- 核查范围未受限制

**表述：**
"经核查，XX公司20XX年度温室气体排放报告符合《XX行业温室气体排放核算方法与报告指南》的规定，真实、准确、完整地反映了该公司20XX年度的温室气体排放情况。"

#### 8.1.2 保留结论

**适用条件：**
- 存在个别重大问题
- 但整体不影响结论
- 或核查范围局部受限

**表述：**
"除XX事项的影响外，XX公司20XX年度温室气体排放报告符合相关规定。"

#### 8.1.3 否定结论

**适用条件：**
- 存在重大造假
- 数据严重失实
- 多项重大不符合

**表述：**
"由于存在XX等重大问题，XX公司20XX年度温室气体排放报告不符合相关规定，未能真实反映其排放情况。"
