## 任务1：熟记分级量化判据

### 1.1 《国家突发环境事件应急预案》事件分级标准

根据《国务院办公厅关于印发国家突发环境事件应急预案的通知》(国办函〔2014〕119号)，突发环境事件按照严重程度分为四级：

#### 一、特别重大突发环境事件(Ⅰ级)

凡符合下列情形之一的，为特别重大突发环境事件：

| 判断维度 | 量化阈值 |
|---------|---------|
| 死亡人数 | 30人以上 |
| 中毒/重伤人数 | 100人以上 |
| 疏散/转移人数 | 5万人以上 |
| 直接经济损失 | 1亿元以上 |
| 生态损害 | 区域生态功能丧失或该区域国家重点保护物种灭绝 |
| 饮用水水源影响 | 设区的市级以上城市集中式饮用水水源地取水中断 |
| 辐射事故 | Ⅰ、Ⅱ类放射源丢失、被盗、失控并造成大范围严重辐射污染后果；放射性同位素和射线装置失控导致3人以上急性死亡；放射性物质泄漏造成大范围辐射污染后果 |

> **注**：有关数量的表述中，"以上"含本数，"以下"不含本数。

#### 二、重大突发环境事件(Ⅱ级)

凡符合下列情形之一的，为重大突发环境事件：

| 判断维度 | 量化阈值 |
|---------|---------|
| 死亡人数 | 10人以上30人以下 |
| 中毒/重伤人数 | 50人以上100人以下 |
| 疏散/转移人数 | 1万人以上5万人以下 |
| 直接经济损失 | 2000万元以上1亿元以下 |
| 生态损害 | 区域生态功能部分丧失或该区域国家重点保护野生动植物种群大批死亡 |
| 饮用水水源影响 | 县级城市集中式饮用水水源地取水中断 |
| 辐射事故 | Ⅰ、Ⅱ类放射源丢失、被盗；放射性同位素和射线装置失控导致3人以下急性死亡或者10人以上急性重度放射病、局部器官残疾；放射性物质泄漏造成较大范围辐射污染后果 |
| 跨区域影响 | 造成跨省级行政区域影响 |

#### 三、较大突发环境事件(Ⅲ级)

凡符合下列情形之一的，为较大突发环境事件：

| 判断维度 | 量化阈值 |
|---------|---------|
| 死亡人数 | 3人以上10人以下 |
| 中毒/重伤人数 | 10人以上50人以下 |
| 疏散/转移人数 | 5000人以上1万人以下 |
| 直接经济损失 | 500万元以上2000万元以下 |
| 生态损害 | 国家重点保护的动植物物种受到破坏 |
| 饮用水水源影响 | 乡镇集中式饮用水水源地取水中断 |
| 辐射事故 | Ⅲ类放射源丢失、被盗；放射性同位素和射线装置失控导致10人以下急性重度放射病、局部器官残疾；放射性物质泄漏造成小范围辐射污染后果 |
| 跨区域影响 | 造成跨设区的市级行政区域影响 |

#### 四、一般突发环境事件(Ⅳ级)

凡符合下列情形之一的，为一般突发环境事件：

| 判断维度 | 量化阈值 |
|---------|---------|
| 死亡人数 | 3人以下 |
| 中毒/重伤人数 | 10人以下 |
| 疏散/转移人数 | 5000人以下 |
| 直接经济损失 | 500万元以下 |
| 社会影响 | 因环境污染造成跨县级行政区域纠纷，引起一般性群体影响 |
| 辐射事故 | Ⅳ、Ⅴ类放射源丢失、被盗；放射性同位素和射线装置失控导致人员受到超过年剂量限值的照射；放射性物质泄漏造成厂区内或设施内局部辐射污染后果 |
| 其他 | 对环境造成一定影响，尚未达到较大突发环境事件级别 |

### 1.2 重大以上上报情形（6类）

根据相关规定，以下6类情形应当按照重大以上事件上报：

1. **死亡30人以上或中毒100人以上**（特别重大级别）
2. **疏散转移5万人以上**（特别重大级别）
3. **直接经济损失1亿元以上**（特别重大级别）
4. **区域生态功能丧失或国家重点保护物种灭绝**（特别重大级别）
5. **设区的市级以上城市饮用水水源地取水中断**（特别重大级别）
6. **跨国界/跨省界重大影响事件**

### 1.4 应急响应对应关系

- **I级响应**：初判发生特别重大突发环境事件，由省级人民政府负责应对
- **II级响应**：初判发生重大突发环境事件，由省级人民政府负责应对
- **III级响应**：初判发生较大突发环境事件，由设区的市级人民政府负责应对
- **IV级响应**：初判发生一般突发环境事件，由县级人民政府负责应对

- 提供MSDS数据下载

**适用场景**：快速查询常见化学品的MSDS报告

**特点**：

**适用场景**：需要权威数据支撑的专业查询

### 2.2 MSDS 16项内容逐项解读

MSDS (Material Safety Data Sheet) 化学品安全技术说明书包含以下16个部分：

#### 第一部分：化学品及企业标识 (Identification)
- **内容**：化学品名称、生产企业名称、地址、邮编、电话、应急电话、传真、电子邮件地址
- **用途**：识别化学品及其供应商，应急联系

#### 第二部分：危险性概述 (Hazards Summarizing)
- **内容**：危害类别、侵入途径、健康危害、环境危害、燃爆危险、GHS标签要素
- **用途**：快速了解化学品的主要危险

#### 第三部分：成分/组成信息 (Composition/Information on Ingredients)
- **内容**：纯化学品给出化学名或通用名、CAS号；混合物给出危害性组分的浓度或浓度范围
- **用途**：了解化学品组成，评估混合风险

#### 第四部分：急救措施 (First-aid Measures)
- **内容**：吸入、皮肤接触、眼睛接触、食入的急救措施
- **用途**：事故发生时采取正确的现场急救

#### 第五部分：消防措施 (Fire-fighting Measures)
- **内容**：危险特性、灭火介质和方法、灭火注意事项、消防人员特殊防护装备
- **用途**：指导火灾扑救，防止二次灾害

#### 第六部分：泄漏应急处理 (Accidental Release Measures)
- **内容**：应急行动、应急人员防护、环保措施、消除方法、防止次生危害的预防措施
- **用途**：指导泄漏事故应急处置

#### 第七部分：操作处置与储存 (Handling and Storage)
- **内容**：安全处置注意事项、安全储存条件、安全技术措施、同禁配物隔离储存措施、包装材料信息
- **用途**：日常安全操作指导

#### 第八部分：接触控制和个体防护 (Exposure Controls/Personal Protection)
- **内容**：容许浓度（PC-TWA、PC-STEL、MAC等）、工程控制方法、个体防护设备类型和材质
- **用途**：制定职业接触控制标准

#### 第九部分：理化特性 (Physical and Chemical Properties)
- **内容**：外观与性状、pH值、沸点、熔点、闪点、爆炸上限、爆炸下限、溶解度、蒸气压、相对密度等
- **用途**：了解化学品基本性质，评估危险特性

#### 第十部分：稳定性和反应活性 (Stability and Reactivity)
- **内容**：稳定性、禁配物、避免接触的条件、聚合危害、分解产物
- **用途**：预防不当储存和混合导致的事故

#### 第十一部分：毒理学信息 (Toxicological Information)
- **内容**：急性毒性、皮肤刺激或腐蚀、眼睛损伤或刺激、呼吸或皮肤过敏、生殖细胞突变性、致癌性、生殖毒性等
- **用途**：评估健康风险

#### 第十二部分：生态学信息 (Ecological Information)
- **内容**：生态毒性、持久性和降解性、生物富集、土壤中的迁移性
- **用途**：评估环境影响

#### 第十三部分：废弃处置 (Disposal Considerations)
- **内容**：废弃物性质、废弃处置方法、废弃注意事项
- **用途**：指导安全废弃

#### 第十四部分：运输信息 (Transport Information)
- **内容**：危险货物编号、UN编号、包装类别、包装标志、包装方法、运输注意事项
- **用途**：确保运输安全合规

#### 第十五部分：法规信息 (Regulatory Information)
- **内容**：国内化学品安全管理法规、国际法规
- **用途**：确保合规管理

#### 第十六部分：其他信息 (Other Information)
- **内容**：参考文献、制修订说明、数据审批单位
- **用途**：补充信息

### 2.3 关键参数含义详解

#### IDLH (Immediately Dangerous to Life and Health)
- **中文**：立即威胁生命和健康浓度
- **定义**：美国OSHA定义，指在此浓度下，30分钟暴露可对生命造成威胁或造成不可逆的健康损害
- **用途**：选择呼吸防护装备的重要依据
- **示例**：氯气的IDLH为10ppm

#### PEL (Permissible Exposure Limit)
- **中文**：容许暴露限值
- **定义**：美国OSHA规定的8小时时间加权平均浓度限值
- **用途**：职业暴露控制标准

#### STEL (Short-Term Exposure Limit)
- **中文**：短时间接触容许浓度
- **定义**：15分钟时间加权平均浓度限值，每天不得超过4次，两次间隔至少60分钟
- **用途**：防止短时间高浓度暴露的危害
- **示例**：氨气的STEL为30mg/m³

#### LC50 (Lethal Concentration 50%)
- **中文**：半数致死浓度
- **定义**：引起一组受试动物50%死亡的空气浓度
- **单位**：mg/m³ 或 ppm
- **用途**：评估吸入毒性
- **分级**：
  - 高毒：LC50 ≤ 500 mg/m³
  - 中等毒：500 < LC50 ≤ 5000 mg/m³
  - 低毒：LC50 > 5000 mg/m³

#### LD50 (Lethal Dose 50%)
- **中文**：半数致死剂量
- **定义**：引起一组受试动物50%死亡的经口或经皮剂量
- **单位**：mg/kg体重
- **用途**：评估经口或经皮毒性
- **分级**：
  - 高毒：LD50 ≤ 5 mg/kg（经口）
  - 中等毒：5 < LD50 ≤ 50 mg/kg
  - 低毒：LD50 > 500 mg/kg

#### 闪点 (Flash Point)
- **定义**：可燃液体挥发出的蒸气与空气形成混合物，遇火源能够闪燃的最低温度
- **分类**：
  - 低闪点液体：闪点 < -18℃
  - 中闪点液体：-18℃ ≤ 闪点 < 23℃
  - 高闪点液体：23℃ ≤ 闪点 ≤ 61℃
- **用途**：火灾危险性分类的重要依据

#### 爆炸极限 (Explosion Limits)
- **爆炸下限 (LEL)**：可燃气体或蒸气在空气中能够形成爆炸性混合物的最低浓度
- **爆炸上限 (UEL)**：可燃气体或蒸气在空气中能够形成爆炸性混合物的最高浓度
- **用途**：评估火灾爆炸风险，设计通风和防爆系统

#### 溶解度 (Solubility)
- **定义**：在一定温度下，某固态/液态物质在100g溶剂中达到饱和状态时所溶解的质量
- **单位**：g/100g溶剂
- **用途**：预测污染物在水体、土壤中的迁移扩散行为

#### 蒸气压 (Vapor Pressure)
- **定义**：在恒定温度下，蒸气与液体/固体达到平衡时的压力
- **单位**：kPa 或 mmHg
- **用途**：
  - 蒸气压越高，挥发性越强
  - 预测大气中污染物浓度
  - 评估密闭空间窒息风险

## 任务3：精读HJ 589-2021突发环境事件应急监测技术规范

### 3.1 标准基本信息

- **标准名称**：《突发环境事件应急监测技术规范》(HJ 589-2021)
- **代替标准**：HJ 589-2010
- **实施日期**：2022年3月1日
- **发布单位**：生态环境部
- **起草单位**：中国环境监测总站、江苏省环境监测中心、吉林省吉林生态环境监测中心

### 3.2 适用范围

本标准适用于因生产、经营、储存、运输、使用和处置危险化学品或危险废物以及意外因素或不可抗拒的自然灾害等原因而引发的突发环境事件的应急监测，包括大气、地表水、地下水和土壤环境等的应急监测。

**不适用范围**：
- 辐射事故
- 海洋污染事件
- 涉及军事设施污染事件
- 生物及微生物污染事件
- 重污染天气等应对工作的应急监测

### 3.3 应急监测启动条件

符合以下任一条件时，应启动应急监测：

1. **发生突发环境事件**：已明确发生或可能发生突发环境事件
2. **接到事件报告**：接到相关部门或公众的突发环境事件报告
3. **发现异常情况**：通过巡查、监控等手段发现可能导致突发环境事件的异常情况
4. **预警启动后**：政府发布突发环境事件预警后

### 3.4 污染态势初步判别流程

#### 第一步：信息收集
- 事件发生时间、地点、原因
- 涉及化学品名称、数量、性质
- 气象水文条件（风向、风速、流速、流量等）
- 周边环境敏感点（居民区、水源地、农田等）

#### 第二步：污染物识别
- **已知污染物**：根据事故源项直接确定
- **未知污染物**：通过现场快速检测、便携式GC-MS等手段筛查

#### 第三步：污染途径分析
- 大气扩散：估算影响的下风向范围和浓度分布
- 水体扩散：估算污染物迁移速度、影响范围和峰值到达时间
- 土壤渗透：评估污染物渗入地下水的风险

#### 第四步：初步判别报告
- 判别污染类型（大气/水体/土壤）
- 估计影响范围和程度
- 提出初步监测方案建议

### 3.5 监测布点原则

#### 大气环境监测布点

**布点方法**：
1. **扇形布点法**：适用于主导风向明确的情况
   - 以事发地为原点，主导风向下风方向为主要监测区域
   - 布设3~5个监测点，覆盖不同距离（500m、1000m、2000m等）
   - 上风向设1个对照点

2. **同心圆布点法**：适用于风向不明或多方向扩散
   - 以事发地为圆心，按半径500m、1000m、2000m等布设同心圆
   - 每个圆周布设3~4个监测点
   - 注意考虑地形和敏感点分布

3. **网格布点法**：适用于城区或复杂地形
   - 按500m×500m或1000m×1000m网格布点
   - 优先在敏感点（学校、医院、居民区）附近加密

**布点数量**：
- 特别重大/重大事件：≥5个点
- 较大事件：≥3个点
- 一般事件：≥1~2个点

#### 地表水环境监测布点

**断面类型**：
1. **对照断面**：设在事发地上游，未受污染影响的位置（通常距事发地500m~1000m）
2. **控制断面**：设在事发地附近，反映污染程度和范围
   - 距离：事发地下游500m、1000m、3000m等
   - 数量：≥3个
3. **削减断面**：设在污染物浓度明显下降的位置，反映降解和稀释效果

**采样点位**：
- 每个断面按左、中、右设3条垂线
- 中线设表层、中层、底层3个点
- 左右垂线设表层1个点

#### 地下水环境监测布点

**布点原则**：
- 以事发地为中心，沿地下水流向布设
- 上游设1~2个背景井
- 沿途设2~3个监测井
- 下游受影响区域设1~2个监测井

**井深要求**：
- 应覆盖污染物可能渗入的含水层
- 般为地下水位下3~5m

#### 土壤环境监测布点

**布点方法**：
1. **网格布点法**：适用于污染范围不明
   - 按10m×10m或20m×20m网格布点
   
2. **放射状布点法**：适用于点源污染
   - 以事发地为中心，沿4~8个方向布点
   - 每个方向布设3~5个点

**采样深度**：
- 表层土壤：0~20cm
- 深层土壤：根据污染物特性确定，可达2~5m

### 3.6 监测项目确定方法

#### 已知污染物的监测项目
- 直接测定该污染物及相关指标
- 例：硫酸泄漏 → 监测pH、硫酸根、重金属等

#### 未知污染物的监测项目
1. **现场快速筛查**：
   - 使用便携式GC-MS、红外光谱仪等
   - 使用检测管、试纸等快速检测工具

2. **实验室确证分析**：
   - 采集样品送实验室进行全分析
   - 使用GC-MS、ICP-MS等高灵敏度方法

3. **补充监测项目**：
   - 根据现场情况，增加相关理化指标（pH、COD、DO等）

### 3.7 跟踪监测频次与调整

#### 监测频次

| 事件级别 | 初期频次 | 中期频次 | 后期频次 |
|---------|---------|---------|---------|
| 特别重大 | 每1~2小时 | 每4~8小时 | 每天1~2次 |
| 重大 | 每2~4小时 | 每8~12小时 | 每天1次 |
| 较大 | 每4~8小时 | 每天1~2次 | 每2天1次 |
| 一般 | 每天1~2次 | 每2~3天1次 | 每周1次 |

#### 监测调整条件
1. **污染物浓度下降**：可降低监测频次
2. **污染物浓度上升或出现新污染**：应增加监测频次和点位
3. **气象条件变化**：如风向改变，应调整大气监测点位
4. **应急处置措施实施**：在处置关键节点应加强监测

### 3.8 应急监测报告格式

#### 快报格式
```

```

### 3.9 质量保证要求

1. **人员要求**：监测人员应具备相应资质，持证上岗
2. **仪器要求**：
   - 现场监测仪器应经过检定/校准
   - 便携式仪器应定期用标准物质核查
3. **样品管理**：
   - 样品采集、保存、运输、分析全过程可追溯
   - 关键样品应留样备份
4. **数据处理**：
   - 按GB/T 8170进行数值修约
   - 检测限以下数据应明确标注
5. **质量控制**：
   - 每批次样品应做空白、平行、加标等质控样品
   - 质控样品合格率应≥95%

### 3.10 应急监测终止条件

符合以下所有条件时，可终止应急监测：

1. **污染源已消除**：泄漏源已封堵，不再有污染物进入环境
2. **污染物浓度达标**：连续3次监测数据显示污染物浓度达到相关标准或背景水平
3. **环境影响可控**：污染范围不再扩大，敏感点污染物浓度达标
4. **应急处置完成**：各项应急处置措施已完成并确认有效

### 3.11 HJ 589-2021与HJ 589-2010的主要修订对比

| 修订内容 | HJ 589-2010 | HJ 589-2021 |
|---------|--------------|--------------|
| 标准结构 | 按监测流程编写 | 调整为"启动-判别-方案-跟踪-报告-终止"逻辑 |
| 术语定义 | 仅有"应急监测"定义 | 新增"应急监测启动"、"污染态势初步判别"、"应急监测终止"等定义 |
| 启动条件 | 未明确规定 | 明确规定4种启动条件 |
| 污染判别 | 内容分散 | 新增"污染态势初步判别"专章 |
| 监测方案 | 内容简单 | 详细规定方案编制要求 |
| 跟踪监测 | 未明确 | 新增"跟踪监测"专章，规定频次调整原则 |
| 监测报告 | 内容简单 | 详细规定快报和正式报告格式 |
| 质量保证 | 内容分散 | 单独设立"质量保证和质量控制"章节 |
| 终止条件 | 未明确规定 | 明确规定4项终止条件 |
| 附录 | 附录A（采样方法） | 新增附录A（监测点位布设示意图）、附录B（监测报告格式）、附录C（监测数据记录表） |

## 任务4：建立5个核心案例决策复盘卡

### 案例1：2015天津港"8·12"特别重大火灾爆炸事故

#### 事件基本信息
- **时间**：2015年8月12日22时51分（起火），23时34分（第一次爆炸）
- **地点**：天津市滨海新区天津港瑞海国际物流有限公司危险品仓库
- **主要物质**：硝化棉、硝酸铵、氰化钠等多种危险化学品
- **事故原因**：
  - 直接原因：硝化棉湿润剂散失，局部干燥，高温下加速分解放热，积热自燃
  - 管理原因：企业违规超量储存危险品、安评报告弄虚作假、政府监管缺位

#### 时间线（关键决策节点）

| 时间 | 事件 | 关键决策 |
|------|------|----------|
| 8月12日22:51 | 瑞海公司仓库起火 | 企业报警，消防队出动 |
| 8月12日23:34 | 第一次爆炸（当量约7吨TNT） | 现场消防力量遭受重大损失 |
| 8月12日23:45 | 第二次更大爆炸（当量约21吨TNT） | 扩大应急，调集增援力量 |
| 8月13日01:00 | 确认事故等级为特别重大 | 启动I级应急响应 |
| 8月13日06:00 | 环保部门开始应急监测 | 布设环境空气和地表水监测点位 |
| 8月13日12:00 | 发现氰化物污染 | 调整监测方案，增加氰化物监测 |
| 8月14日 | 核心区大坑废水处置方案确定 | 调集专业队伍进行废水处理 |
| 8月15日 | 确认165人死亡、8人失踪 | 调整搜救重点 |
| 8月18日 | 环境质量数据趋于稳定 | 调整监测频次 |
| 9月13日 | 所有氰化物污染区域处理完成 | 终止环境应急监测 |

#### "六问法"分析

**1. 什么污染物？**
- 硝化棉（引发剂）
- 硝酸铵（爆炸物）
- 氰化钠（剧毒，约700吨）
- 多种有机溶剂

**2. 在哪里？往哪去？**
- 位置：天津港集装箱码头
- 大气扩散：爆炸产生有害气体（氰化氢、氮氧化物等），随风扩散
- 水体迁移：消防废水通过排水管道进入邻近水体，核心区大坑蓄积高浓度氰化物废水
- 土壤渗透：部分污染物渗入土壤和地下水

**3. 有多少？多快？**
- 硝酸铵约800吨
- 氰化钠约700吨（实际估算）
- 爆炸瞬间释放，消防废水约数万立方米
- 大气污染物在数小时内扩散至周边区域

**4. 威胁谁？**
- 现场消防人员和救援人员（已造成165人死亡）
- 周边3公里范围内居民（约1.7万户）
- 邻近水源地（北塘水库、天津滨海新区供水系统）
- 渤海湾近海水域

**5. 能用什么？**
- 灭火：大流量水炮、泡沫灭火剂（但硝酸铵火灾不宜用大量水）
- 防化：防化服、正压式空气呼吸器、氰化物解毒剂
- 监测：便携式氰化物检测仪、大气监测车、水质监测船
- 处置：废水处理车、活性炭吸附、过氧化氢氧化降解氰化物

**6. 最坏会怎样？**
- 最坏情景：700吨氰化钠全部进入环境
  - 大气：产生大量氰化氢气体，造成周边居民区重大人员伤亡
  - 水体：核心区大坑7000立方米废水（氰化物超标上千倍）进入渤海，造成近海水域生态灾难
  - 实际应对：通过筑堤围堵、废水处理，成功阻止了最坏情景发生

#### 实际决策 vs 更优方案

**实际决策**：
1. 初期灭火使用大量水，可能加剧了硝酸铵的不稳定性
2. 爆炸后环保部门约6小时后才开始应急监测，信息报告有延迟
3. 初期未充分考虑氰化钠污染风险，监测布点不够全面

**更优方案**：
1. 事前：企业应按规定存储危险品，政府应加强监管和演练
2. 事中：
   - 接警时应详细询问储存物品，避免盲目出水
   - 环保部门应在1小时内启动应急监测
   - 应第一时间考虑氰化物风险，扩大监测范围
3. 事后：全面排查全国港口危险品仓储安全

#### 指挥长教训总结
1. **信息准确是决策基础**：必须第一时间查明事故地点储存的物品清单
2. **多部门协同至关重要**：安监、环保、消防、医疗等必须统一指挥
3. **环境风险不容忽视**：危险品仓库事故必须同步开展环境应急监测
4. **公众沟通要及时透明**：政府应在第一时间发布权威信息，避免谣言传播

### 案例2：2010紫金矿业紫金山铜矿"7·3"污水渗漏事件

#### 事件基本信息
- **时间**：2010年7月3日15时50分（发现泄漏），实际泄漏始于7月3日凌晨
- **地点**：福建省龙岩市上杭县紫金山金铜矿
- **主要物质**：含铜酸性废水（主要含铜、硫酸根，无剧毒物质）
- **事故原因**：
  - 直接原因：连续强降雨导致地下水位上升，污水池底部黏土层掏空，防渗膜多处开裂
  - 管理原因：企业为压低成本使用较薄PE防渗膜（设计1.5mm，实际0.5mm），政府监管不力

#### 时间线（关键决策节点）

| 时间 | 事件 | 关键决策 |
|------|------|----------|
| 7月3日15:50 | 发现污水池水位异常下降 | 企业启动内部应急预案 |
| 7月3日18:00 | 确认约9100立方米废水渗入汀江 | 企业向县政府报告 |
| 7月4日 | 环保部门开始应急监测 | 布设汀江干流监测断面 |
| 7月6日 | 发现死鱼现象 | 政府开始收购死鱼 |
| 7月7日 | 网络开始出现质疑声音 | 企业仍未公开信息 |
| 7月12日 | 企业发布延迟9天的公告 | 引发公众强烈不满 |
| 7月13日 | 汀江水质开始好转 | 调整监测频次 |
| 7月15日 | 紫金山金矿3号应急池再次渗漏（约500立方米） | 政府责令全面停产整顿 |
| 7月16日 | 省政府成立调查组 | 启动责任追究 |
| 8月13日 | 水质全面达标 | 终止应急监测 |

#### "六问法"分析

**1. 什么污染物？**
- 含铜酸性废水
- 主要污染物：铜离子（Cu²⁺）、硫酸根（SO₄²⁻）
- pH值：酸性（最低达4.66）

**2. 在哪里？往哪去？**
- 位置：福建省上杭县，汀江上游
- 水体迁移：通过排洪涵洞进入汀江干流，向下游迁移
- 影响范围：汀江上杭段、棉花滩水库

**3. 有多少？多快？**
- 泄漏量：约9100立方米 + 后续500立方米
- 迁移速度：随江水流动，约每天10~20公里
- 影响时间：从7月3日至8月13日，约40天

**4. 威胁谁？**
- 汀江沿岸居民饮用水（但实际未影响自来水厂，因政府已新建水厂）
- 汀江流域水生生物（大量死鱼）
- 下游棉花滩水库水质
- 企业声誉和经济效益

**5. 能用什么？**
- 封堵：构筑临时围堰，防止进一步泄漏
- 处理：投加石灰中和酸性废水，投加硫化钠沉淀铜离子
- 监测：水质自动监测站、便携式铜离子检测仪
- 补偿：政府收购死鱼，对企业罚款956万元

**6. 最坏会怎样？**
- 最坏情景：废水持续泄漏，汀江流域铜污染持续数月
  - 实际应对：企业在9天后才公告，但政府在7月4日即开始应急处置，控制了影响

#### 实际决策 vs 更优方案

**实际决策**：
1. 企业发现泄漏后未及时公开信息，瞒报9天
2. 政府初期对事件严重性认识不足，应对措施不够坚决
3. 环保部门监测频次和数据公开不够及时

**更优方案**：
1. 企业应建立突发环境事件信息报告制度，1小时内报告政府
2. 政府应在发现泄漏后第一时间向社会公开信息
3. 应建立汀江流域水质自动监测预警系统

#### 指挥长教训总结
1. **信息透明是危机公关的关键**：瞒报只会加剧公众不信任
2. **企业应落实环境安全主体责任**：不能只顾成本不顾安全
3. **政府监管不能缺位**：对重点污染源应实施高频次检查
4. **生态恢复需要长期努力**：事件虽已过去，但生态修复需要数年时间

## 任务5：练习初报/续报/处理结果报告撰写

### 5.1 突发环境事件信息报告格式与要求

根据《突发环境事件信息报告办法》（环境保护部令第17号），突发环境事件信息报告分为初报、续报和处理结果报告。

#### 一、初报

**定义**：在发现或者得知突发环境事件后首次上报。

**报告时限**：
- 特别重大/重大事件：1小时内报告至省级生态环境部门，2小时内报告至生态环境部
- 较大事件：1小时内报告至设区的市级生态环境部门，2小时内报告至省级生态环境部门
- 一般事件：2小时内报告至县级生态环境部门，4小时内报告至设区的市级生态环境部门

**格式与必填项**：

```

报告时间：××年×月×日×时×分

9. 联系人及联系方式

- 较大事件：至少每2天1次

### 5.3 17号令中的报告时限起算点

《突发环境事件信息报告办法》（环境保护部令第17号，2011年5月1日起施行）规定的报告时限起算点：

#### 第四条
> 突发环境事件发生后，县级以上环境保护主管部门应当立即进行初步核查。 
> **起算点**：**发现或者得知突发环境事件之时**。

#### 具体时限要求

1. **对初步认定为一般（IV级）或者较大（III级）突发环境事件的**：
   - **县级环境保护主管部门**：应当在**2小时内**向本级人民政府和上一级环境保护主管部门报告
   - **起算点**：自发现或者得知事件之时起

2. **对初步认定为重大（II级）或者特别重大（I级）突发环境事件的**：
   - **县级环境保护主管部门**：应当在**1小时内**向本级人民政府和上一级环境保护主管部门报告
   - **省级环境保护主管部门**：接到报告后应当在**1小时内**报告省、自治区、直辖市人民政府和环境保护部
   - **起算点**：自发现或者得知事件之时起

3. **特殊情况**：
   - 情况紧急时，可以**先通过电话报告**，并立即补充书面报告
   - 对情况不够清楚、要素不全的初报，应当在**24小时内补充完善**

#### 重要注意事项

1. **"发现或者得知之时"的认定**：
   - 环境保护主管部门通过巡查、群众举报、企业报告、媒体报道等途径发现或者得知突发环境事件的时间
