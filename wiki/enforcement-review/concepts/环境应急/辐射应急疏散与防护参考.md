# 辐射应急疏散与防护参考

> 参照标准：IAEA GSG-2《用于事故计划和响应的通用安全导则》
> 
> 参考依据：《核与辐射事故应急预案编制导则》、国家核应急预案
> 
> 适用对象：应急指挥人员、政府决策人员、卫生应急人员

## 一、辐射事故分级

### 1.1 IAEA/INES国际核事件分级表

**国际核事件分级表（INES）共7级**：

```
┌─────────────────────────────────────────────────────────┐
│                    INES分级概览                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  异常事件（1-3级）                                      │
│  ├── 1级：异常 ← 最低级别偏离                            │
│  ├── 2级：事件 ← 显著偏离                               │
│  └── 3级：严重事件 ← 重大安全失效                        │
│                                                         │
│  核事故（4-7级）                                        │
│  ├── 4级：局部后果 ← 反应堆堆芯受损                      │
│  ├── 5级：广泛后果 ← 场外显著释放                        │
│  ├── 6级：重大事故 ← 部分场外防护                       │
│  └── 7级：特大事故 ← 大规模场外释放                      │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**辐射事故与INES分级对应**：

| INES级 | 辐射事故描述 | 典型场景 |
|-------|-------------|---------|
| 0级 | 偏差 | 无安全意义 |
| 1级 | 异常 | 放射源丢失（已找回）|
| 2级 | 事件 | 放射源丢失（无人受照）|
| 3级 | 严重事件 | 多人受照，放射源破损 |
| 4级 | 事故 | 局部过量照射，严重污染 |

### 1.2 我国辐射事故分级标准

**按照《放射性同位素与射线装置安全和防护条例》**：

| 事故级别 | 判定标准 | 应急响应 |
|---------|---------|---------|
| 特别重大辐射事故 | Ⅰ类、Ⅱ类放射源丢失、被盗、失控造成大范围严重辐射污染后果，或者放射性同位素和射线装置导致试验工作人员急性死亡 | 国务院统一指挥 |
| 重大辐射事故 | Ⅰ类、Ⅱ类放射源丢失、被盗、失控，或者放射性同位素和射线装置导致人员受超剂量照射 | 省级政府指挥 |
| 较大辐射事故 | Ⅲ类放射源丢失、被盗、失控，或者放射性同位素和射线装置导致人员受超剂量照射 | 市级政府指挥 |
| 一般辐射事故 | Ⅳ类、Ⅴ类放射源丢失、被盗、失控，或者放射性同位素和射线装置导致人员受超剂量照射 | 县级政府指挥 |

### 1.3 分级判定流程

```
辐射事故分级判定
│
├─ 第一步：识别事故类型
│   ├─ 放射源丢失/失窃
│   ├─ 放射源破损/污染
│   ├─ 人员受照
│   └─ 设施故障
│
├─ 第二步：评估后果
│   ├─ 人员受照剂量
│   ├─ 环境污染范围
│   ├─ 社会影响程度
│   └─ 经济损失评估
│
├─ 第三步：对照标准
│   ├─ 核素类别（Ⅰ-Ⅴ类源）
│   ├─ 受照人数
│   ├─ 剂量水平
│   └─ 污染程度
│
└─ 第四步：确定级别
    └─ 启动相应级别应急响应
```

## 二、疏散范围参考

### 2.1 放射源丢失事故疏散范围

**Ⅰ类源（极高危险源）**：

```
Ⅰ类放射源丢失（>100 TBq Co-60类）
│
├─ 搜寻范围：扩大至全市
├─ 警戒范围：≥500米
├─ 公众行动：
│   ├─ 室内隐蔽（初始）
│   ├─ 重点区域疏散
│   └─ 主动搜寻报告
├─ 行政措施：
│   ├─ 发布公众信息
│   ├─ 组织搜寻
│   └─ 必要时城市局部疏散
└─ 时间要求：立即启动搜寻，持续追踪
```

**Ⅱ类源（高危险源）**：

```
Ⅱ类放射源丢失（1-100 TBq Ir-192类）
│
├─ 搜寻范围：区县至全市
├─ 警戒范围：100-300米
├─ 公众行动：
│   ├─ 避免接近不明金属物
│   ├─ 发现异常及时报告
│   └─ 配合搜寻调查
├─ 行政措施：
│   ├─ 公告提醒
│   ├─ 重点区域排查
│   └─ 必要时区域疏散
└─ 时间要求：2小时内启动全面搜寻
```

**Ⅲ类源（中等危险源）**：

```
Ⅲ类放射源丢失（0.1-1 TBq）
│
├─ 搜寻范围：事发单位及周边
├─ 警戒范围：50-100米
├─ 公众行动：
│   ├─ 正常生活
│   └─ 发现可疑物报告
├─ 行政措施：
│   ├─ 单位内部搜寻
│   └─ 周边区域排查
└─ 时间要求：4小时内定位
```

**Ⅳ-Ⅴ类源（低危险源）**：

```
Ⅳ-Ⅴ类放射源丢失
│
├─ 搜寻范围：可控
├─ 警戒范围：通常无需
├─ 公众行动：
│   └─ 无需恐慌
├─ 行政措施：
│   └─ 追踪查找
└─ 时间要求：24小时内定位
```

### 2.2 放射源破损事故疏散范围

**破损事故特点**：
- 存在环境污染
- 可能产生气溶胶
- 需防止内照射

**疏散范围参考表**：

| 源活度 | 初始疏散范围 | 隐蔽范围 | 备注 |
|-------|-------------|---------|------|
| >100 TBq | 500-1000米 | 1-3公里 | 需专业评估 |
| 10-100 TBq | 200-500米 | 500米-1公里 | 污染区域疏散 |
| 1-10 TBq | 100-200米 | 300米 | 局部疏散 |
| <1 TBq | 50-100米 | 100米 | 视情况 |

### 2.3 放射源熔炼事故（最严重场景）

**事故背景**：
放射源进入钢铁冶炼系统，污染金属产品

**疏散范围**：

```
熔炼事故疏散决策
│
├─ 立即措施
│   ├─ 停止熔炼
│   ├─ 封闭相关设备
│   ├─ 人员撤离（车间内）
│   └─ 剂量监测
│
├─ 扩大评估
│   ├─ 产品追溯
│   ├─ 环境污染评估
│   ├─ 人员受照评估
│   └─ 污染产品范围确定
│
├─ 产品处置
│   ├─ 停止出厂
│   ├─ 暂存封存
│   └─ 检测分类
│
└─ 社会影响
    ├─ 可能涉及大量钢铁产品
    ├─ 可能涉及多个地区
    └─ 需多部门协调
```

### 2.4 疏散范围确定原则

**考虑因素**：

```
疏散范围确定要素：
│
├─ 源项特征
│   ├─ 核素类型
│   ├─ 源活度
│   └─ 射线能量
│
├─ 环境因素
│   ├─ 气象条件（风向、风速、降水）
│   ├─ 地形地貌
│   └─ 人口密度
│
├─ 时间因素
│   ├─ 事故持续时间
│   ├─ 响应时效性
│   └─ 防护措施有效性
│
└─ 社会因素
    ├─ 经济影响
    ├─ 社会秩序
    └─ 公众心理
```

**决策原则**：
- 预防为主，避免过度响应
- 防护措施收益大于代价
- 遵循可实现性原则
- 动态评估，及时调整

## 三、人员剂量控制标准

### 3.1 干预水平与行动水平

**干预水平（IL）**：应采取防护行动的剂量阈值

**行动水平（OL）**：应采取防护行动的可测量量（如剂量率、污染水平）

**通用干预水平**：

| 防护行动 | 通用干预水平（预期剂量）|
|---------|----------------------|
| 隐蔽 | 10 mSv（全身）|
| 疏散 | 50 mSv（全身）|
| 撤离 | 100 mSv（全身）|
| 碘防护（稳定碘）| 100 mGy（甲状腺）|
| 临时避迁 | 30 mSv（首月）|
| 永久迁居 | 100 mSv（累积）|

### 3.2 公众防护剂量控制

**应急响应剂量控制值**：

| 场景 | 控制剂量 | 备注 |
|-----|---------|------|
| 临时疏散 | ≤50 mSv | 可延长至100 mSv |
| 永久搬迁 | ≥100 mSv | 需权衡利弊 |
| 隐蔽 | ≤50 mSv（优化）| 一般<10 mSv |
| 食入防护 | 食入剂量≥10 mSv | 食品干预水平 |

**儿童特殊考虑**：
- 儿童对辐射更敏感
- 疏散决策时儿童优先
- 适当放宽干预水平
- 避免对儿童不必要的照射

### 3.3 应急工作人员剂量控制

**职业照射限值例外情况**：

| 情况 | 剂量限值例外 |
|-----|------------|
| 救援行动（生命救援）| 尽可能合理可行低剂量，无上限 |
| 紧急救护 | 挽救生命优先 |
| 其他紧急情况 | 必要时可超过限值，但需批准 |

**应急工作人员防护导则**：

```
应急工作人员剂量控制原则
│
├─ 第一原则：生命救援优先
│   └─ 生命救援可超出剂量限值
│
├─ 第二原则：合理可行尽量低（ALARA）
│   ├─ 采取一切防护措施
│   ├─ 控制受照剂量
│   └─ 记录评估剂量
│
├─ 第三原则：知情同意
│   ├─ 告知辐射风险
│   └─ 自愿参与原则
│
└─ 第四原则：医学观察
    ├─ 记录受照情况
    └─ 必要时医学随访
```

**应急工作人员参考剂量水平**：

| 操作类型 | 参考剂量控制 | 说明 |
|---------|------------|------|
| 简单搜寻/定位 | <5 mSv | 可多次作业 |
| 源收贮（常规）| <10 mSv | 需审批 |
| 复杂处置作业 | <50 mSv | 需批准，防护加强 |
| 高风险作业 | <100 mSv | 极特殊情况 |
| 生命救援 | 无上限 | 挽救生命优先 |

## 四、医疗救治

### 4.1 急性辐射综合征（ARS）

**定义**：短时间内大剂量全身或局部照射后引起的急性健康效应

**诊断要点**：

```
ARS诊断三要素：
│
├─ 1. 受照剂量（>1 Gy全身均匀照射）
│   ├─ 剂量估算方法
│   │   ├─ 物理剂量（场所测量、物品测量）
│   │   ├─ 生物剂量（淋巴细胞染色体畸变）
│   │   └─ 临床症状评估
│   └─ 剂量率也是重要因素
│
├─ 2. 临床表现时序
│   ├─ 早期症状（数小时-数天）
│   │   ├─ 恶心、呕吐
│   │   ├─ 腹泻
│   │   └─ 发热
│   └─ 病程进展符合规律
│
└─ 3. 实验室检查
    ├─ 血细胞变化
    ├─ 淋巴细胞计数
    └─ 骨髓象
```

**临床分型**：

| 亚综合征类型 | 受照剂量（Gy）| 主要靶器官 | 典型症状 | 预后 |
|------------|-------------|----------|---------|-----|
| 造血型 | 1-6 | 骨髓 | 血细胞减少、感染、出血 | 取决于支持治疗 |
| 胃肠型 | 6-10 | 胃肠上皮 | 严重腹泻、脱水、电解质紊乱 | 预后不良 |
| 心血管型 | 10-20 | 心脏、血管 | 循环衰竭 | 极差 |
| 脑型 | >20 | CNS | 意识障碍、抽搐 | 不可逆 |

**造血型ARS分期**：

```
造血型ARS临床进程
│
├─ 前驱期（0-2天）
│   ├─ 恶心、呕吐
│   ├─ 食欲减退
│   └─ 乏力
│
├─ 假愈期（2-20天）
│   ├─ 症状暂时缓解
│   ├─ 血象开始下降
│   └─ 表面"好转"
│
├─ 极期（20-30天）
│   ├─ 骨髓衰竭
│   ├─ 白细胞<1×10⁹/L
│   ├─ 感染发热
│   ├─ 血小板减少
│   ├─ 出血倾向
│   └─ 脱发
│
└─ 恢复期（>30天，存活者）
    ├─ 骨髓恢复
    ├─ 血细胞回升
    └─ 逐步康复
```

### 4.2 急性辐射损伤的早期识别

**现场快速评估**：

```
早期症状评估表
│
├─ 呕吐评估（重要！）
│   ├─ 2小时内呕吐 → 预示严重照射（>4 Gy）
│   ├─ 4小时内呕吐 → 预示中度照射（2-4 Gy）
│   └─ 无呕吐 → 照射剂量可能<1 Gy
│
├─ 腹泻评估
│   ├─ 早期出现 → 预示严重照射（>6 Gy）
│   └─ 无腹泻 → 照射剂量相对较低
│
├─ 发热评估
│   ├─ 早期发热 → 预后不良
│   └─ 发热出现时间与剂量相关
│
└─ 意识评估
    ├─ 意识障碍 → 脑型可能
    └─ 清醒 → 排除脑型
```

**淋巴细胞计数快速评估**：

```
淋巴细胞计数与受照剂量估算
│
├─ 采血时间：受照后6-24小时
│
├─ 淋巴细胞计数（×10⁹/L）：
│   ├─ >1.5 → 预计<1 Gy
│   ├─ 1.0-1.5 → 预计1-2 Gy
│   ├─ 0.5-1.0 → 预计2-4 Gy
│   ├─ 0.1-0.5 → 预计4-6 Gy
│   └─ <0.1 → 预计>6 Gy
│
└─ 注意：排除其他影响因素
    ├─ 既往疾病
    ├─ 药物影响
    └─ 测量时间
```

### 4.3 医疗救治流程

**分级救治体系**：

```
辐射事故伤员救治体系
│
├─ 第一级：现场急救
│   ├─ 脱离辐射区
│   ├─ 初步处理
│   ├─ 剂量估算
│   └─ 分类后送
│
├─ 第二级：区域救治
│   ├─ 详细医学检查
│   ├─ 早期对症治疗
│   ├─ 专家会诊
│   └─ 决定转诊
│
├─ 第三级：专科救治
│   ├─ 血液科为主
│   ├─ ICU支持
│   ├─ 对症支持治疗
│   └─ 骨髓移植（特定情况）
│
└─ 第四级：康复与随访
    ├─ 长期随访
    ├─ 远期效应监测
    └─ 心理康复
```

**现场处置要点**：

```
现场医疗处置
│
├─ 1. 脱离照射
│   ├─ 立即转移至安全区域
│   └─ 去除污染衣物
│
├─ 2. 体表去污
│   ├─ 清水冲洗
│   ├─ 肥皂清洗
│   └─ 避免皮肤损伤
│
├─ 3. 收集信息
│   ├─ 照射时间
│   ├─ 照射距离
│   ├─ 症状出现时间
│   └─ 既往健康状况
│
├─ 4. 初步检查
│   ├─ 生命体征
│   ├─ 血常规（尽快）
│   ├─ 淋巴细胞计数
│   └─ 呕吐腹泻情况
│
├─ 5. 对症处理
│   ├─ 补液
│   ├─ 止吐
│   ├─ 退热
│   └─ 抗感染（必要时）
│
└─ 6. 转运决策
    ├─ 根据剂量评估决定
    ├─ 疑似ARS送专科
    └─ 轻者观察随访
```

### 4.4 远期健康效应

**确定性效应（组织反应）**：

| 效应类型 | 阈值剂量 | 典型表现 |
|---------|---------|---------|
| 白内障 | 0.5 Gy（单次）| 晶状体混浊 |
| 皮肤损伤 | 2 Gy | 红斑、脱发 |
| 造血抑制 | 0.5 Gy | 暂时性血细胞减少 |
| 生育障碍 | 0.3 Gy（睾丸）| 暂时性不育 |
| 胎儿效应 | >0.1 Gy | 发育异常、智力障碍 |

**随机性效应**：

```
随机性效应特点：
├─ 无阈值
├─ 概率随剂量增加
├─ 潜伏期长（数年至数十年）
└─ 主要为癌症

癌症风险增加（全身均匀照射）：
├─ 1 Sv照射 → 约5%额外癌症风险
├─ 100 mSv → 约0.5%额外风险
└─ 10 mSv以下 → 统计学上难以检出
```

## 五、误区和警示

### 5.1 常见错误认知

**误区一：辐射事故必然导致大量人员死亡**

```
错误认知：
辐射事故=核爆炸=大量死亡

正确理解：
├─ 民用放射源事故不同于核武器
├─ 绝大多数辐射事故可控
├─ Ⅳ-Ⅴ类源事故无显著健康影响
├─ 即使Ⅰ类源事故也可通过防护减少伤亡
└─ 恐慌比辐射更危险
```

**误区二：辐射污染会持续永远**

```
错误认知：
一旦被辐射污染就永远清除不了

正确理解：
├─ 外照射：离开辐射区即停止
├─ 表面污染：洗消可清除
├─ 体内污染：可通过促排加速排除
├─ 环境衰减：核素衰变+自然迁移
└─ 大多数事故污染可清除
```

**误区三：碘化钾可以万能防护**

```
错误认知：
辐射事故吃碘片就万事大吉

正确理解：
├─ 碘片仅防护甲状腺
├─ 仅对放射性碘有效
├─ 必须在正确时间服用
├─ 过早/过晚服用无效
└─ 碘片是特殊情况下应急措施
```

**误区四：辐射事故需要立即疏散**

```
错误认知：
发现辐射事故必须立即疏散所有人员

正确理解：
├─ 疏散是成本很高的措施
├─ 需评估剂量水平
├─ 隐蔽可能更适合低剂量情况
├─ 不当疏散可能增加风险
└─ 决策需科学依据
```

### 5.2 关键警示

**警示一：不要恐慌性行动**

```
恐慌行动的风险：
├─ 车辆事故（疏散过程）
├─ 踩踏伤害
├─ 错误用药
├─ 谣言传播
└─ 社会秩序混乱

正确做法：
✓ 保持冷静
✓ 服从指挥
✓ 关注官方信息
✓ 采取科学防护
```

**警示二：不要接触不明金属物**

```
风险提示：
├─ 遗失放射源可能外观类似普通金属
├─ 放射源无色无味无形
├─ 近距离接触高活度源可造成损伤

正确做法：
✓ 发现不明金属不要捡拾
✓ 告知家人不要捡拾
✓ 发现可疑物报告相关部门
✓ 远离发光/发热/异常的物品
```

**警示三：不要自行服用碘片**

```
错误做法：
├─ 自行购买碘化钾服用
├─ 恐慌性大量服用碘
├─ 把碘酒当碘片服用

正确做法：
✓ 碘片由政府统一发放
✓ 仅在明确指示下服用
✓ 严格遵守服用剂量和时间
✓ 碘过敏者禁用
```

**警示四：不要拒绝必要疏散**

```
延误疏散的风险：
├─ 接受不必要的高剂量照射
├─ 增加健康危害
├─ 污染个人财物

正确做法：
✓ 理解疏散必要性
✓ 配合疏散安排
✓ 携带必要物品
✓ 服从安置管理
```

## 六、碘防护专题

### 6.1 碘化钾（KI）防护原理

**稳定碘阻断甲状腺的机制**：

```
甲状腺对放射性碘的吸收：
│
├─ 甲状腺需要碘合成甲状腺素
├─ 放射性碘（I-131等）进入人体后
│   被甲状腺大量浓集
├─ 浓集量可达体内总碘的30-50%
└─ 导致甲状腺受到大剂量照射

稳定碘的阻断作用：
├─ 稳定碘（KI）饱和甲状腺
├─ 占据甲状腺内碘的结合位点
├─ 阻断放射性碘的吸收
├─ 减少甲状腺剂量的90%以上
└─ 必须在放射性碘摄入前/同时服用才有效
```

### 6.2 碘化钾使用指征

**使用条件**：

```
碘防护触发条件：
│
├─ 1. 确认存在放射性碘释放
│   └─ 如核设施事故释放I-131
│
├─ 2. 预计甲状腺剂量达到阈值
│   └─ >100 mGy（成人）
│   └─ >50 mGy（儿童）
│
├─ 3. 摄入途径
│   └─ 可能通过吸入或食入摄入
│
└─ 4. 时间窗口
    └─ 放射性碘进入环境后数小时内
```

**适用人群**：

| 人群 | 优先级 | 剂量建议 |
|-----|-------|---------|
| 孕妇（胎儿）| 最高 | 与成人相同 |
| 儿童（0-18岁）| 高 | 与成人相同（按体重调整）|
| 哺乳期妇女 | 高 | 与成人相同（不影响哺乳）|
| 成人 | 中 | 标准剂量 |
| 老年人 | 中 | 标准剂量 |
| 碘过敏者 | 禁用 | 绝对禁忌 |

### 6.3 碘化钾服用方法

**标准服用方案**：

```
碘化钾服用指南
│
├─ 成人：
│   ├─ 剂量：130 mg KI（含碘100 mg）
│   └─ 频率：每日一次
│
├─ 儿童（3-18岁）：
│   ├─ 剂量：65 mg KI（含碘50 mg）
│   └─ 频率：每日一次
│
├─ 婴幼儿（1月-3岁）：
│   ├─ 剂量：32 mg KI（含碘25 mg）
│   └─ 频率：每日一次
│
├─ 新生儿（<1月）：
│   ├─ 剂量：16 mg KI（含碘12.5 mg）
│   └─ 频率：每日一次
│
└─ 特殊人群：
    ├─ 孕妇：与成人相同剂量
    └─ 甲状腺疾病患者：遵医嘱
```

**服用时机**：

```
服用时机与效果：
│
├─ 摄入放射性碘前2小时内
│   └─ 效果最佳（阻断率>95%）
│
├─ 摄入放射性碘同时
│   └─ 阻断率约85%
│
├─ 摄入放射性碘后4小时
│   └─ 阻断率约50%
│
├─ 摄入放射性碘后6小时
│   └─ 阻断率约20%
│
└─ 摄入放射性碘后12小时
    └─ 基本无效（甲状腺已饱和）
```

**服用注意事项**：

```
注意事项：
│
├─ 不良反应
│   ├─ 胃肠道不适
│   ├─ 皮疹（过敏）
│   └─ 甲状腺功能异常
│
├─ 禁忌
│   ├─ 碘过敏
│   ├─ 甲状腺功能亢进
│   └─ 结节性甲状腺肿
│
├─ 服用期限
│   └─ 一般不超过2周
│
└─ 储存
    └─ 避光、干燥保存
```
