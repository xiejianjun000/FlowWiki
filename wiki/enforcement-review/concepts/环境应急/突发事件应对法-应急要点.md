# 《中华人民共和国突发事件应对法》应急要点

> 施行日期：2007年11月1日
> 最新修订：2024年6月28日（2024年11月1日起施行）
> 来源：全国人民代表大会常务委员会

---

## 一、法律地位

《突发事件应对法》是我国应急管理领域的基础性法律，适用于**突发事件的预防与应急准备、监测与预警、应急处置与救援、事后恢复与重建**等应对活动。

---

## 二、突发事件分类分级

### （一）四大类别

| 类别 | 典型事件 |
|------|---------|
| **自然灾害** | 水旱灾害、气象灾害、地震灾害、地质灾害、海洋灾害、生物灾害、森林草原火灾 |
| **事故灾难** | 工矿商贸等企业的各类安全事故、交通运输事故、公共设施和设备事故、环境污染和生态破坏事件 |
| **公共卫生事件** | 传染病疫情、群体性不明原因疾病、食品安全和职业危害、动物疫情 |
| **社会安全事件** | 恐怖袭击事件、经济安全事件、涉外突发事件 |

**⚠️ 环境突发事件属于"事故灾难"类别**

### （二）四级分级

| 级别 | 严重程度 | 颜色标识 | 判定标准 |
|------|---------|---------|---------|
| **特别重大（Ⅰ级）** | 特别严重 | 红色 | 造成30人以上死亡，或100人以上中毒，或疏散转移10万人以上 |
| **重大（Ⅱ级）** | 严重 | 橙色 | 造成10-29人死亡，或50-99人中毒，或疏散转移1-10万人 |
| **较大（Ⅲ级）** | 较重 | 黄色 | 造成3-9人死亡，或10-49人中毒，或疏散转移5000-1万人 |
| **一般（Ⅳ级）** | 一般 | 蓝色 | 造成1-2人死亡，或10人以下中毒，或疏散转移5000人以下 |

## 三、核心制度

### （一）应急预案制度

**政府层面：**
- 国务院制定国家突发事件总体应急预案
- 国务院有关部门制定专项应急预案
- 地方各级人民政府制定本行政区域应急预案

**企事业单位：**
- 应当制定具体应急预案
- 应当定期开展应急演练
- 应当配备应急救援人员和物资

### （二）风险评估制度

- 各级政府应当对本行政区域内容易引发突发事件的危险源、危险区域进行调查登记
- 进行风险评估、检查、监控
- 责令有关单位采取安全防范措施

### （三）监测预警制度

**预警发布权限：**
| 级别 | 发布权限 |
|------|---------|
| Ⅰ级（红色） | 国务院或省级政府 |
| Ⅱ级（橙色） | 省级政府 |
| Ⅲ级（黄色） | 市级政府 |
| Ⅳ级（蓝色） | 县级政府 |

**预警内容：**
- 突发事件的类别
- 预警级别
- 起始时间
- 可能影响的范围
- 警示事项
- 应采取的措施
- 发布机关

### （四）信息报告制度

**时限要求：**
- 发生突发事件后，必须**立即**向上级人民政府报告
- 最迟不得超过**2小时**
- 重大、特别重大突发事件，必须在**1小时内**报告

**报告内容：**
- 事件发生的时间、地点
- 事件性质、起因
- 人员伤亡情况
- 已经采取的措施
- 需要协调解决的事项

## 四、应急处置措施

### （一）政府可采取的措施

| 措施类别 | 具体内容 |
|---------|---------|
| 救援救助 | 组织营救受害人员，疏散、撤离、安置受到威胁的人员 |
| 控制危险源 | 标明危险区域，封锁危险场所，划定警戒区 |
| 管制措施 | 实行交通管制、现场管制 |
| 物资征用 | 征用单位和个人的财产（事后返还或补偿） |
| 信息公开 | 及时发布有关突发事件事态发展和应急处置工作的信息 |

### （二）应急响应程序

```
┌─────────────┐
│  事件发生   │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 信息报告    │ ← 1-2小时内上报
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 启动预案    │ ← 根据级别启动对应预案
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 成立指挥部  │ ← 政府负责人任总指挥
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 应急处置    │ ← 救援、监测、管控
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 响应终止    │ ← 威胁消除后宣布终止
└─────────────┘
```

## 五、法律责任

### （一）政府责任

- 未按规定报告、通报突发事件信息的
- 未按规定发布突发事件警报的
- 未及时采取应急处置措施的
- 违法采取应急处置措施，侵犯公民合法权益的

### （二）企事业单位责任

| 违法行为 | 法律后果 |
|---------|---------|
| 未制定应急预案 | 责令改正，警告 |
| 未开展应急演练 | 责令改正，警告 |
| 迟报、谎报、瞒报、漏报信息 | 责令改正，警告，罚款 |
| 不服从政府应急处置决定 | 警告，罚款，行政处分 |

## 六、环境应急特别条款

### 第二十三条

**有关单位应当定期检查本单位各项安全防范措施的落实情况，及时消除事故隐患；掌握并及时处理本单位存在的可能引发社会安全事件的问题，防止矛盾激化和事态扩大。**

### 第四十二条

**国家建立健全突发事件预警制度。**

### 第四十三条

**可以预警的自然灾害、事故灾难和公共卫生事件的预警级别，按照突发事件发生的紧急程度、发展势态和可能造成的危害程度分为一级、二级、三级和四级，分别用红色、橙色、黄色和蓝色标示。**

### 第四十五条

**发布一级、二级警报，宣布进入预警期后，县级以上地方各级人民政府应当根据即将发生的突发事件的特点和可能造成的危害，采取下列措施：**
1. 启动应急预案
2. 责令有关部门、专业机构、监测网点和负有特定职责的人员及时收集、报告有关信息
3. 组织有关部门和机构、专业技术人员、有关专家学者，随时对突发事件信息进行分析评估
4. 定时向社会发布与公众有关的突发事件预测信息和分析评估结果
5. 按照有关规定向社会发布可能受到突发事件危害的警告，宣传避免、减轻危害的常识

## 七、实务要点

### （一）应急预案编制要求

1. **针对性**：结合本地区、本单位实际情况
2. **可操作性**：明确职责分工、处置流程、联系方式
3. **科学性**：符合技术规范和标准
4. **完整性**：包含组织体系、运行机制、应急保障、监督管理

### （二）应急演练要求

- **综合演练**：每年至少1次
- **专项演练**：每半年至少1次
- **现场处置演练**：每季度至少1次

### （三）应急物资储备

- 分类储备应急救援物资
- 建立物资调拨机制
- 定期检查更新
