## 🎯 核心知识点速查

### 国家层面
- **《突发环境事件应急管理办法》**（环境保护部令第34号，2015年）
  - 事件分级：特别重大、重大、较大、一般四级
  - 工作原则：预防为主、预防与应急相结合

- **《国家突发环境事件应急预案》**（国务院办公厅）
  - 适用范围：大气、水体、土壤污染事件

### 湖南省层面
- **《湖南省突发环境事件应急预案管理办法（修订版）》**（湘环发〔2024〕49号，2024年12月5日发布）
  - **八大变化：**
    1. 完善适用范围（新增园区、水源地、临时预案）
    2. Q<1企业可豁免预案编制
    3. 较大及以上风险企业需至少1名专业人员（注册环保工程师或环评师）
    4. 外部评审后90个工作日内签署实施
    5. 签署后20/30个工作日内完成备案
    6. 每3年至少修订一次
    7. 6种情形强制修订
    8. 强化监督管理

### 娄底市层面
- **《娄底市突发环境事件应急预案》**（2024年修订版）
  - **信息报告时限：**
    - 一般事件：3小时内报告
    - 较大事件：30分钟内电话，60分钟内书面
    - 重大/特别重大：30分钟内电话，60分钟内书面（同时报生态环境部）
  - **特殊情况：** 涉及水源地、敏感人群、重金属污染，按高等级上报
