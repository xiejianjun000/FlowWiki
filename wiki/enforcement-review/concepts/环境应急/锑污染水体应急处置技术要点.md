# 锑污染水体应急处置技术要点（娄底专项）

> 适用场景：娄底市涉锑（锡矿山闪星锑业、青峰河/涟溪河流域、资江干流）突发含锑废水外泄、尾矿库直排、锑浓度异常等事件。
> 整理日期：2026-07-11　来源：应急处置实战案例 + 公开研究文献 + 娄底冷水江实际采购药剂

---

## 一、处置技术链（"以空间换时间"）

```
① 拦截断源 → ② 水利调度(稀释/控流速) → ③ 加药捕集/沉淀降锑 → ④ 工程拦截过滤 → ⑤ 备用水源切换
```

1. **拦截断源：** 紧急修复破损管道/泵，切断污染源；河道设橡胶坝、临时围堰、拦污坝分级拦截。
2. **水利调度：** 水闸调控流量、加大泄流稀释污染团（须与沉淀降锑同步，避免"冲而不降"）。
3. **加药捕集/沉淀降锑：** 投加铁盐絮凝剂使锑形成沉淀捕集（核心技术，见第三节）。
4. **工程拦截过滤：** 活性炭/吸附材料拦截削污、工程拦截过滤。
5. **备用水源切换：** 水厂工艺调整 + 限时限量供水 + 启用备用水源 + 管网互联互通。

## 二、应急物资清单（锑污染专项）

| 类别 | 物资 | 用途/要点 |
|------|------|-----------|
| 除锑药剂 | **聚合硫酸铁（PFS）**、三氯化铁（FC）、硫酸铁 | 娄底冷水江2021年实际采购用于资江锑应急；PFS适用 pH 4–11 |
| 助凝剂 | 聚丙烯酰胺（PAM） | 强化絮凝、助沉降 |
| 沉淀/吸附 | 硫化钠（辅助）、活性炭、吸附材料 | 硫化钠+PAM 复合用于低温低浊；活性炭吸附削污 |
| 拦截设施 | 橡胶坝、围油栏/拦污坝、临时围堰、沙袋 | 分级拦截、以空间换时间 |
| 储运 | 槽罐车、应急池、抽吸泵 | 收集处置废水，防止外溢 |
| 监测 | 锑快速检测包、便携式重金属分析仪 | 加密监测、确认扩散范围 |

> 娄底本地已建**涟溪河、青丰河自动化应急设施**，启动**涟溪河旁路治理工程**；建议在冷水江、新化前置储备上述药剂与拦截物资（对应市预案"应急物资库"要求）。

## 三、除锑药剂技术参数（可操作）

### 3.1 三氯化铁（FC）饮用水除锑（烧杯实验验证）
- 最佳投加量：约 **0.2 mmol/L**
- 最佳 pH：**7**
- 对锑(Ⅲ)去除率最高约 **94.1%**（以北江水源水为本底实验）

### 3.2 聚合硫酸铁（PFS）
- 娄底冷水江实际应急采购药剂；适应 pH **4–11**，絮凝体密实、沉降快。
- 适合河道/水厂应急投加，无毒、不带来二次污染。

### 3.3 硫化钠 + 三价铁盐 + PAM 复合（低温应急专利）
- 步骤：调 pH **8–9** → 加硫化钠（锑质量 **15–30倍**）→ 加三价铁盐（**40–50倍**）→ 加 PAM（**5 ppm**）→ 静置沉淀。
- 锑去除率可达 **99.75%**，出水 < 5 μg/L（满足饮用水标准）。

### 3.4 形态与 pH 要点
- 三价锑(Ⅲ)较五价锑(Ⅴ)更易去除；去除五价锑最佳 pH≈**5**。
- 低温低浊：硫化钠+PAM 复合混凝有效（冯立师等研究）。

### 3.5 投药作业通则
1. 先取现场水样**小试**确定投加比与最佳 pH，再放大到河道/水厂级。
2. 铁盐优先用于**饮用水路径**（无二次污染）；硫化钠须控制投量避免硫化氢风险。
3. 投药后持续搅拌/曝气促进絮凝，静置沉降后取上清监测锑浓度。
4. 污泥/沉淀物按**重金属危险废物**收集处置，防止二次污染。

## 四、关键机理警示

- **底泥反释：** 枯水期 + 高温 + 高光照 → 底泥中锑重新释放，即使源头已控，断面仍可能反弹（2022坪口断面事件教训）。须持续加密监测、留足处置余量。
- **跨界传导：** 资江娄底—邵阳—益阳上下游联防联控必设，跨省界断面（坪口）须联合监测与通报。
