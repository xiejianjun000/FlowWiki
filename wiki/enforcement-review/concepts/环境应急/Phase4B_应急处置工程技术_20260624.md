## 专题1：化学中和反应计量学

### 1.1 酸碱中和——快速计量的实战公式

#### 1.1.1 硫酸泄漏中和计算

**反应方程式**：
```
H₂SO₄ + CaO → CaSO₄ + H₂O
```

**计算1：中和1吨98%硫酸需要多少吨生石灰（CaO）？**

**计算过程**：

1) 化学方程式摩尔比：
   - H₂SO₄ 分子量 = 98 g/mol
   - CaO 分子量 = 56 g/mol
   - 反应摩尔比 = 1:1

2) 计算纯H₂SO₄质量：
   ```
   m(H₂SO₄) = 1吨 × 98% = 0.98吨 = 980 kg
   ```

3) 计算需要的CaO物质的量：
   ```
   n(H₂SO₄) = 980 kg ÷ 98 g/mol = 10,000 mol
   n(CaO) = 10,000 mol（按1:1反应）
   ```

4) 计算CaO质量：
   ```
   m(CaO) = 10,000 mol × 56 g/mol = 560,000 g = 560 kg = 0.56吨
   ```

5) **实际投加量**（考虑工业纯度和反应效率）：
   - 工业生石灰纯度通常为85-90%
   - 按90%纯度计算：0.56吨 ÷ 0.90 = **0.622吨**
   - 安全系数取1.2：**0.75吨**

**答案：中和1吨98%硫酸需要约0.75吨生石灰（CaO）**

---

**计算2：中和1吨98%硫酸需要多少吨烧碱（NaOH）？**

**反应方程式**：
```
H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O
```

**计算过程**：

1) 摩尔比：H₂SO₄:NaOH = 1:2

2) 计算需要的NaOH物质的量：
   ```
   n(NaOH) = 10,000 mol × 2 = 20,000 mol
   ```

3) NaOH分子量 = 40 g/mol
   ```
   m(NaOH) = 20,000 mol × 40 g/mol = 800,000 g = 800 kg = 0.80吨
   ```

4) **实际投加量**：
   - 工业烧碱纯度通常为96-99%
   - 按98%纯度计算：0.80吨 ÷ 0.98 = **0.816吨**
   - 安全系数取1.2：**0.98吨**

**答案：中和1吨98%硫酸需要约0.98吨烧碱（NaOH）**

---

**计算3：中和1吨98%硫酸需要多少吨纯碱（Na₂CO₃）？**

**反应方程式**：
```
H₂SO₄ + Na₂CO₃ → Na₂SO₄ + CO₂↑ + H₂O
```

**计算过程**：

1) 摩尔比：H₂SO₄:Na₂CO₃ = 1:1

2) Na₂CO₃分子量 = 106 g/mol
   ```
   m(Na₂CO₃) = 10,000 mol × 106 g/mol = 1,060,000 g = 1.06吨
   ```

3) **实际投加量**：
   - 工业纯碱纯度通常为98-99%
   - 按98.5%纯度计算：1.06吨 ÷ 0.985 = **1.076吨**
   - 安全系数取1.2：**1.29吨**

**答案：中和1吨98%硫酸需要约1.29吨纯碱（Na₂CO₃）**

---

#### 1.1.2 盐酸泄漏中和计算

**反应方程式**：
```
2HCl + CaO → CaCl₂ + H₂O
```

**计算：中和1吨31%盐酸需要多少石灰？**

**计算过程**：

1) HCl分子量 = 36.5 g/mol
   ```
   m(HCl) = 1吨 × 31% = 0.31吨 = 310 kg
   n(HCl) = 310 kg ÷ 36.5 g/mol = 8,493.15 mol
   ```

2) 摩尔比：HCl:CaO = 2:1
   ```
   n(CaO) = 8,493.15 ÷ 2 = 4,246.58 mol
   ```

3) CaO分子量 = 56 g/mol
   ```
   m(CaO) = 4,246.58 mol × 56 g/mol = 237.81 kg = 0.238吨
   ```

4) **实际投加量**（按90%纯度，安全系数1.2）：
   ```
   0.238吨 ÷ 0.90 × 1.2 = **0.317吨**
   ```

**答案：中和1吨31%盐酸需要约0.32吨生石灰（CaO）**

---

#### 1.1.3 液碱泄漏中和计算

**反应方程式**：
```
2NaOH + H₂SO₄ → Na₂SO₄ + 2H₂O
```

**计算：中和1吨30%液碱需要多少稀硫酸（10%）？**

**计算过程**：

1) NaOH分子量 = 40 g/mol
   ```
   m(NaOH) = 1吨 × 30% = 0.30吨 = 300 kg
   n(NaOH) = 300 kg ÷ 40 g/mol = 7,500 mol
   ```

2) 摩尔比：NaOH:H₂SO₄ = 2:1
   ```
   n(H₂SO₄) = 7,500 ÷ 2 = 3,750 mol
   ```

3) H₂SO₄分子量 = 98 g/mol
   ```
   m(H₂SO₄纯) = 3,750 mol × 98 g/mol = 367.5 kg
   ```

4) **10%稀硫酸用量**：
   ```
   m(10% H₂SO₄) = 367.5 kg ÷ 10% = 3,675 kg = **3.68吨**
   ```

**答案：中和1吨30%液碱需要约3.68吨10%稀硫酸**

---

#### 1.1.4 氨水泄漏中和计算

**反应方程式**：
```
2NH₃ + H₂SO₄ → (NH₄)₂SO₄
```

**计算：中和1吨20%氨水需要多少稀硫酸（10%）？**

**计算过程**：

1) NH₃分子量 = 17 g/mol
   ```
   m(NH₃) = 1吨 × 20% = 0.20吨 = 200 kg
   n(NH₃) = 200 kg ÷ 17 g/mol = 11,764.71 mol
   ```

2) 摩尔比：NH₃:H₂SO₄ = 2:1
   ```
   n(H₂SO₄) = 11,764.71 ÷ 2 = 5,882.35 mol
   ```

3) H₂SO₄分子量 = 98 g/mol
   ```
   m(H₂SO₄纯) = 5,882.35 mol × 98 g/mol = 576.47 kg
   ```

4) **10%稀硫酸用量**：
   ```
   m(10% H₂SO₄) = 576.47 kg ÷ 10% = 5,764.7 kg = **5.76吨**
   ```

**答案：中和1吨20%氨水需要约5.76吨10%稀硫酸**

### 1.2 重金属沉淀/还原

#### 1.2.1 六价铬还原计算

**还原反应方程式**：
```
Cr₂O₇²⁻ + 6Fe²⁺ + 14H⁺ → 2Cr³⁺ + 6Fe³⁺ + 7H₂O
```

**计算：还原1kg Cr⁶⁺需要多少FeSO₄·7H₂O？**

**计算过程**：

1) Cr原子量 = 52 g/mol
   ```
   n(Cr⁶⁺) = 1,000 g ÷ 52 g/mol = 19.23 mol
   ```

2) 从反应式：Cr₂O₇²⁻中有2个Cr，需要6个Fe²⁺
   ```
   n(Fe²⁺) = 19.23 mol × 3 = 57.69 mol
   ```

3) FeSO₄·7H₂O分子量 = 278 g/mol
   ```
   m(FeSO₄·7H₂O) = 57.69 mol × 278 g/mol = 16,037.82 g = **16.04 kg**
   ```

4) **实际投加量**：
   - 理论值：16.04 kg
   - 实际操作过量系数：**1.5-2.0倍**
   - 按1.5倍计算：16.04 × 1.5 = **24.06 kg**
   - 按2.0倍计算：16.04 × 2.0 = **32.08 kg**

**答案：还原1kg Cr⁶⁺需要16.04kg FeSO₄·7H₂O（理论值），实际操作投加24-32kg（1.5-2.0倍过量）**

---

#### 1.2.2 pH控制要求

**FeSO₄法还原Cr⁶⁺的pH控制**：
- **最佳pH范围**：2.0-3.0
- **原因**：
  - pH < 2.0：Fe²⁺难以被氧化，反应速度慢
  - pH 2.0-3.0：Fe²⁺氧化速率适中，Cr⁶⁺还原彻底
  - pH > 3.0：Fe²⁺易氧化为Fe³⁺沉淀，降低还原效果

**操作步骤**：
1. 调节pH至2.5-3.0（用硫酸）
2. 投加FeSO₄·7H₂O，搅拌15-30分钟
3. 检测Cr⁶⁺是否降至目标值（通常<0.5 mg/L）
4. 加碱调节pH至7.5-8.5，使Cr³⁺和Fe³⁺沉淀
5. 投加PAM助凝，沉淀30-60分钟

---

#### 1.2.3 重金属氢氧化物沉淀pH窗口

**理论计算依据**：

氢氧化物沉淀的平衡：
```
Me(OH)n(s) ⇌ Meⁿ⁺ + nOH⁻
Ksp = [Meⁿ⁺][OH⁻]ⁿ
```

**沉淀开始pH计算**（以[Meⁿ⁺] = 0.01 mol/L为例）：

| 金属离子 | Ksp | 开始沉淀pH | 完全沉淀pH | 最佳pH窗口 | 数据来源 |
|---------|-----|------------|------------|-----------|---------|
| **Cr³⁺** | 6.3×10⁻³¹ | 4.0 | 5.5 | **7.0-9.0** | 实测 |
| **Cu²⁺** | 2.2×10⁻²⁰ | 5.0 | 6.5 | **8.0-9.5** | GB/T标准 |
| **Pb²⁺** | 1.2×10⁻¹⁵ | 6.5 | 8.0 | **8.5-10.0** | 实测 |
| **Zn²⁺** | 1.2×10⁻¹⁷ | 6.0 | 8.0 | **8.5-10.5** | 实测 |
| **Cd²⁺** | 2.5×10⁻¹⁴ | 8.0 | 9.5 | **9.5-11.0** | 实测 |
| **Ni²⁺** | 5.5×10⁻¹⁶ | 6.5 | 8.0 | **8.0-9.5** | 实测 |

**注**：
1. **开始沉淀**：当[Meⁿ⁺] = 0.01 mol/L时的pH
2. **完全沉淀**：当[Meⁿ⁺] < 10⁻⁵ mol/L时的pH
3. **最佳pH窗口**：沉淀效率>99%的pH范围
4. ⚠️ 部分数据待实验核实，实际操作需小试确定

---

**共沉淀与分步沉淀策略**：

1) **分步沉淀**（适用于单一污染物）：
   - 逐个调节pH至目标金属的最佳窗口
   - 分别沉淀、分别处理

2) **共沉淀**（适用于多种金属共存）：
   - 调节pH至9.0-10.0（覆盖大部分金属）
   - 加入Fe³⁺或Al³⁺作共沉淀剂
   - 形成复合氢氧化物沉淀

### 1.3 氧化剂投加量

#### 1.3.1 氰化物碱性氯化法计算

**反应方程式**（完全氧化）：
```
2CN⁻ + 5ClO⁻ + H₂O → 2CO₂ + N₂ + 5Cl⁻ + 2OH⁻
```

**计算：每氧化1kg CN⁻需要多少NaClO？**

**计算过程**：

1) CN⁻分子量 = 26 g/mol
   ```
   n(CN⁻) = 1,000 g ÷ 26 g/mol = 38.46 mol
   ```

2) 从反应式：CN⁻:ClO⁻ = 2:5
   ```
   n(ClO⁻) = 38.46 mol × (5/2) = 96.15 mol
   ```

3) NaClO分子量 = 74.5 g/mol
   ```
   m(NaClO纯) = 96.15 mol × 74.5 g/mol = 7,163.18 g = **7.16 kg**
   ```

4) **实际投加量**：
   - 市售次氯酸钠溶液有效氯含量通常为10-15%
   - 按12%有效氯计算：
     ```
     m(12% NaClO) = 7.16 kg ÷ 12% = **59.67 kg**
     ```
   - 安全系数取1.2：**71.6 kg**

**答案：完全氧化1kg CN⁻需要约71.6kg 12%次氯酸钠溶液（理论值的1.2倍）**

---

**碱性氯化法操作参数**：

| 参数 | 第一阶段（不完全氧化） | 第二阶段（完全氧化） |
|-----|---------------------|-------------------|
| **pH** | 10.0-11.0 | 8.0-9.0 |
| **ORP** | - | +300 mV以上 |
| **反应时间** | 10-15分钟 | 30-60分钟 |
| **ClO⁻:CN⁻（重量比）** | 3.5:1 | 7.15:1（理论值） |
| **实际投加比** | 4-5:1 | 8-10:1 |

**操作步骤**：
1. 调节pH至10.5-11.0
2. 投加第一阶段NaClO（按CN⁻:ClO⁻ = 1:3.5重量比）
3. 搅拌反应15分钟（CN⁻ → CNO⁻）
4. 调节pH至8.0-9.0
5. 投加第二阶段NaClO（总投加量达到CN⁻:ClO⁻ = 1:7.15）
6. 搅拌反应60分钟（CNO⁻ → CO₂ + N₂）
7. 检测CN⁻ < 0.5 mg/L（达标）

#### 2.1.3 PAC与GAC的使用场景对比

| 特性 | 粉末活性炭（PAC） | 颗粒活性炭（GAC） |

| **投加量** | 20-200 mg/L | 填充厚度0.5-2.0m |

**应急场景选择建议**：
- **突发泄漏**：选择PAC，快速投加
- **长期修复**：选择GAC，建吸附坝或吸附柱
- **组合使用**：PAC预处理 + GAC深度处理

### 2.2 沸石（Zeolite）

#### 2.2.1 天然沸石对氨氮的吸附容量

**实测数据**（25℃，pH 7.0）：

| 沸石类型 | 粒径（mm） | 氨氮吸附容量（mg/g） | 数据来源 |
|---------|-----------|-------------------|---------|
| 天然斜发沸石 | 1-2 | 2.62-4.05 | 文献[1] |

| 天然丝光沸石 | 1-2 | 3.5-5.2 | 实测 |

**影响因素**：
1. **pH**：pH 6-8时吸附量最高；pH > 9时NH₃逸出，吸附量下降
2. **温度**：升温不利于吸附（放热反应）
3. **竞争离子**：Ca²⁺、Mg²⁺、Na⁺与NH₄⁺竞争位点
4. **粒径**：粒径越小，吸附速率越快，但水头损失大

- **氨氮污染**：优先选用改性沸石（性价比高）
- **重金属污染**：优先选用改性活性炭或改性沸石（MnO₂负载）
- **有机污染物**：只能选用活性炭
- **应急场景**：天然沸石（可就近采购）

2. 用CTMAB（十六烷基三甲基溴化铵）溶液浸泡
3. 固液比1:10，60℃搅拌4小时
4. 洗涤、烘干、研磨

| 苯胺 | < 8 | 150-240 | 19-30× |
| 甲基橙 | < 15 | 280-450 | 19-30× |

**机理**：
- 天然膨润土：亲水表面，对疏水性有机物吸附弱
- 有机改性后：CTMAB的疏水长链覆盖表面，形成"有机相"，通过分配作用吸附有机物

### 2.4 专性吸附材料

#### 2.4.1 螯合树脂对重金属的选择性吸附

**常见螯合树脂类型**：

| 树脂类型 | 功能基团 | 选择性顺序 | 吸附容量（mmol/g） |
|---------|---------|-----------|-------------------|
| **亚氨基二乙酸型（IDA）** | -N(CH₂COOH)₂ | Cu²⁺ > Pb²⁺ > Zn²⁺ > Cd²⁺ > Ni²⁺ | 1.2-2.5 |
| **氨基磷酸型（AP）** | -N(CH₂PO₃H₂)₂ | Hg²⁺ > Cu²⁺ > Pb²⁺ > Cd²⁺ | 1.5-3.0 |
| **硫脲型** | -CS-NH-NH₂ | Hg²⁺ > Ag⁺ > Au³⁺ > Pd²⁺ | 2.0-4.5 |
| **巯基型** | -CH₂-SH | Hg²⁺ > Pb²⁺ > Cd²⁺ > Cu²⁺ | 1.8-3.5 |

**选择性系数（K）示例**（IDA树脂，pH 5.0）：
```
K(Cu²⁺/Na⁺) = 850
K(Pb²⁺/Na⁺) = 520
K(Zn²⁺/Na⁺) = 180
K(Cd²⁺/Na⁺) = 120
K(Ni²⁺/Na⁺) = 95
K(Ca²⁺/Na⁺) = 8
```

**应用建议**：

- **含Hg、Ag、Au废水**：选用硫脲型（选择性极高）
- **高钙镁废水**：选用巯基型（抗钙镁干扰能力强）

#### 2.4.2 铁基吸附剂对砷/锑的吸附（重点）

**砷酸根（AsO₄³⁻）和亚砷酸根（AsO₃³⁻）的去除**：

**铁基吸附剂类型**：

| 材料 | 制备方法 | As⁵⁺吸附容量（mg/g） | 适用pH |
|-----|---------|---------------------|-------|
| **水合氧化铁（HFO）** | FeCl₃水解 + NaOH沉淀 | 35-65 | 4.0-8.0 |
| **针铁矿（α-FeOOH）** | 水热合成 | 45-75 | 3.5-7.5 |
| **赤铁矿（α-Fe₂O₃）** | 焙烧HFO（300℃） | 25-45 | 4.0-9.0 |
| **负载铁氧化物活性炭** | 浸渍-焙烧法 | 55-95 | 3.0-8.0 |
| **纳米零价铁（nZVI）** | 液相还原法 | 80-150 | 5.0-9.0 |

**除砷机理**：
1. **表面络合**：AsO₄³⁻与Fe-OH形成内圈络合物
   ```
   Fe-OH + H₂AsO₄⁻ → Fe-O-AsO₃H⁻ + H₂O
   ```
2. **共沉淀**：Fe²⁺氧化为Fe³⁺，As共沉淀进入铁氧化物晶格
3. **氧化还原**（nZVI）：As⁵⁺还原为As³⁺，再被Fe(OH)₃吸附

---

**锑（Sb）的去除**：

**Sb³⁺和Sb⁵⁺（SbO₃⁻、SbO₄³⁻）的去除难点**：
- Sb³⁺：易水解，形成Sb₂O₃沉淀（pH > 6）
- Sb⁵⁺：形成Sb(OH)₆⁻络阴离子（pH > 8）

**铁基吸附剂对Sb的吸附容量**：

| 材料 | Sb³⁺吸附容量（mg/g） | Sb⁵⁺吸附容量（mg/g） | 最佳pH |
|-----|---------------------|---------------------|-------|
| **水合氧化铁（HFO）** | 45-80 | 25-45 | 6.0-8.0（Sb³⁺）<br>3.0-5.0（Sb⁵⁺） |
| **锰砂（MnO₂）** | 60-110 | 35-65 | 5.0-7.0（Sb³⁺） |
| **负载铁锰氧化物沸石** | 80-140 | 45-85 | 5.0-8.0 |

**竞争性阴离子影响**（按影响程度排序）：
```
PO₄³⁻ > SiO₃²⁻ > SO₄²⁻ > Cl⁻ > NO₃⁻
```

**工程设计建议**：
1. **含砷废水**：优先选用HFO或nZVI（吸附容量大）
2. **含锑废水**：优先选用锰砂或铁锰复合氧化物（对Sb选择性高）
3. **砷锑共存**：选用负载铁锰氧化物沸石（协同去除）
4. **pH控制**：As⁵⁺去除需pH 4-8；Sb³⁺去除需pH 6-8

---

#### 2.4.3 锰砂对锑的吸附能力

**锰砂成分**：
- 主要成分：MnO₂（软锰矿）
- 次要成分：Fe₂O₃、SiO₂、Al₂O₃
- MnO₂含量：通常20-45%

**对Sb的吸附性能**：

| 锰砂类型 | MnO₂含量（%） | Sb³⁺吸附容量（mg/g） | Sb⁵⁺吸附容量（mg/g） |
|---------|---------------|---------------------|---------------------|
| 天然锰砂（湘潭） | 35-42 | 85-110 | 45-60 |
| 改性锰砂（负载Fe） | 30-38 | 120-160 | 65-90 |
| 焙烧锰砂（400℃） | 40-48 | 95-130 | 55-75 |

**吸附机理**：
1. **表面氧化**：MnO₂将Sb³⁺氧化为Sb⁵⁺
   ```
   MnO₂ + Sb³⁺ + 2H₂O → Mn²⁺ + Sb⁵⁺ + 4OH⁻
   ```
2. **表面络合**：Sb⁵⁺与Mn-OH形成络合物
3. **共沉淀**：Sb⁵⁺与Mn²⁺（氧化释放）形成MnSb₂O₆沉淀

**影响锰砂吸附Sb的因素**：
1. **pH**：pH 5-7时吸附量最高；pH < 4时MnO₂溶出；pH > 8时Sb⁵⁺形成Sb(OH)₆⁻，吸附量下降
2. **共存离子**：Fe²⁺、Fe³⁺促进Sb吸附（共沉淀）；PO₄³⁻、SiO₃²⁻竞争吸附位点
3. **粒径**：0.5-1.0mm粒径最佳（比表面积与水头损失平衡）

**锰砂过滤器设计参数**：
- **滤速**：5-8 m/h（Sb去除）；3-5 m/h（As+Sb共去除）
- **填料厚度**：1.0-1.5 m
- **反冲洗强度**：12-15 L/(s·m²)
- **反冲洗周期**：24-48小时

**设计参数表格**：

| **坝宽** | 1.0-2.0 m | 根据流量确定，保证过流速度 |
| **活性炭层厚度** | 0.5-1.0 m | 厚度越大，吸附效果越好，但水头损失越大 |

| **坝体长** | 根据河宽确定 | 应覆盖整个河宽，防止绕流 |

#### 3.2.2 过流速度控制

**过流速度计算方法**：

```
v = Q / A
```
其中：
- v：过流速度（m/s）
- Q：流量（m³/s）
- A：过流断面面积（m²）= 坝宽 × 活性炭层孔隙率 × 有效水深

**孔隙率（ε）**：
- 颗粒活性炭：ε = 0.4-0.5
- 破碎活性炭：ε = 0.35-0.45

**示例计算**：
- 河流流量：Q = 10 m³/s
- 坝宽：B = 5 m
- 活性炭层厚度：L = 0.8 m
- 孔隙率：ε = 0.45
- 有效水深：h = 0.6 m

```
A = B × L × ε × h = 5 × 0.8 × 0.45 × 0.6 = 1.08 m²
v = 10 / 1.08 = 9.26 m/s  （过大！）
```

**调整方案**：
1. 增加坝宽至15m：
   ```
   A = 15 × 0.8 × 0.45 × 0.6 = 3.24 m²
   v = 10 / 3.24 = 3.09 m/s  （仍过大）
   ```
2. 改用多层活性炭坝（3道，每道间距10m）：
   ```
   每道过流量 = 10 / 3 = 3.33 m³/s
   A = 5 × 0.8 × 0.45 × 0.6 = 1.08 m²
   v = 3.33 / 1.08 = 3.08 m/s  （需再调整）
   ```
3. **最终方案**：坝宽20m，3道坝
   ```
   A = 20 × 0.8 × 0.45 × 0.6 = 4.32 m²
   v = 3.33 / 4.32 = 0.77 m/s  （仍>0.1m/s，需降速）
   ```
4. **增设格栅降速**：在活性炭坝前增设穿孔格栅（开孔率30%），将流速降至0.05-0.10 m/s

---

#### 3.2.3 活性炭更换频率判断

**判断依据**：

1. **出口水质检测**：
   - 当出口污染物浓度达到进口的**10%**时，开始更换
   - 当出口污染物浓度达到进口的**20%**时，必须更换

2. **穿透曲线法**：
   ```
   t_b = (C₀ × Q × t - ∫C(t)dt) / (q₀ × m)
   ```
   其中：
   - t_b：穿透时间（h）
   - C₀：进口浓度（mg/L）
   - Q：流量（m³/h）
   - q₀：饱和吸附容量（mg/g）
   - m：活性炭质量（kg）

3. **简易判断法**（应急场景）：
   - **颜色变化**：活性炭由黑色变为浅色（污染物着色）
   - **异味**：坝体下游出现污染物异味
   - **目测油膜**：坝体无法拦截油膜时

**更换周期估算**（以苯系物为例）：
- 活性炭量：10吨
- 苯浓度：10 mg/L
- 流量：100 m³/h
- 吸附容量：300 mg/g（取50% = 150 mg/g）

```
处理总量 = 10,000 kg × 150 g/kg = 1,500,000 g = 1,500,000 mg
污染物总量/小时 = 100 m³/h × 10 mg/L = 1,000 mg/h
更换周期 = 1,500,000 / 1,000 = 1,500 h ≈ 62.5天
```

**实际操作**：
- 每15天检测一次出口水质
- 出口浓度>进口浓度10%时，更换50%活性炭
- 出口浓度>进口浓度20%时，全部更换

### 3.4 化学凝胶坝/絮凝坝

#### 3.4.1 适用条件和水力要求

**化学凝胶坝原理**：
- 向水中投加**交联聚合物**（如聚丙烯酰胺、海藻酸钠），在水中形成三维网络结构凝胶
- 凝胶捕获悬浮颗粒和胶体污染物

**适用条件**：

| 条件 | 要求 | 说明 |
|-----|------|------|
| **流速** | < 0.3 m/s | 流速过快，凝胶被冲散 |
| **水深** | < 1.5 m | 水深过大，凝胶分布不均 |
| **水温** | 5-35℃ | 温度过低，凝胶化速度慢 |
| **pH** | 4-9 | 强酸强碱影响凝胶强度 |
| **污染物类型** | 悬浮物、胶体、部分溶解性有机物 | 对重金属离子效果差 |

---

#### 3.4.2 常用絮凝剂投加量

**PAC（聚合氯化铝）+ PAM（聚丙烯酰胺）复合投加**：

| 污染物 | PAC投加量（mg/L） | PAM投加量（mg/L） | 投加顺序 |
|-------|-------------------|-------------------|---------|
| **悬浮物（SS）** | 50-150 | 0.5-2.0 | 先PAC，后PAM |
| **胶体** | 80-200 | 1.0-3.0 | 先PAC，后PAM |
| **油类** | 100-250 | 2.0-5.0 | 先PAC，后PAM |
| **总磷（TP）** | 30-80 | 0.3-1.0 | 先PAC，后PAM |

**投加方式**：
1. **配药浓度**：
   - PAC：5-10%（质量浓度）
   - PAM：0.1-0.2%（阴离子型，分子量800-1200万）

2. **投加点**：
   - PAC投加点：坝前10-20m（充分混合）
   - PAM投加点：坝前5-10m（助凝）

3. **混合方式**：
   - 机械搅拌：G值=50-100 s⁻¹，搅拌时间30-60秒
   - 管道混合：静态混合器（混合效率>90%）

### 3.5 导流/分流工程

#### 3.5.1 旁通渠道设计

**旁通渠道作用**：
- 将污染水体导入处理设施
- 保护下游敏感目标（饮用水源地、水产养殖区等）

**设计参数**：

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| **设计流量** | 等于或略大于河流设计洪水标准（10年一遇） | 防止洪水冲毁渠道 |
| **渠道宽度** | 根据流量计算（v=0.5-1.0 m/s） | 流速过快，冲刷渠道；过慢，淤积 |
| **渠道深度** | 1.0-2.0 m | 深窄型渠道占地少，但施工难 |
| **边坡坡度** | 1:1.5 - 1:2.0 | 土质渠道需放缓边坡防坍塌 |
| **衬砌材料** | 混凝土或HDPE膜 | 防止渗漏污染地下水 |

---

#### 3.5.2 应急池/调蓄池容量计算

**容量计算公式**：

```
V = (Q × C₀ × t) / (C₀ - C_e)
```
简化公式（当C_e << C₀时）：
```
V ≈ Q × t
```

其中：
- V：调蓄池容量（m³）
- Q：入池流量（m³/h）
- C₀：进口浓度（mg/L）
- C_e：出口浓度（mg/L）
- t：调蓄时间（h）

**示例计算**：
- 事故排放流量：Q = 50 m³/h
- 污染物浓度：C₀ = 500 mg/L
- 目标浓度：C_e = 50 mg/L
- 处理时间：t = 6 h

```
V = (50 × 500 × 6) / (500 - 50) = 150,000 / 450 = 333.33 m³
```

**校核**：
- 6小时内总入流量 = 50 × 6 = 300 m³
- 调蓄池容量333 m³ > 300 m³，满足要求

**实际设计**：
- 考虑安全系数1.2-1.5：
  ```
  V_design = 333 × 1.3 = 433 m³
  ```
- 取整：**500 m³**

## 专题4：曝气/吹脱/化学氧化

### 4.1 曝气吹脱

#### 4.1.1 气水比对氨氮/挥发性有机物吹脱效率的影响

**吹脱原理**：
- 氨氮（NH₃-N）在pH > 11时转化为NH₃气体
- 挥发性有机物（VOCs）通过气液界面挥发

**气水比（G/L）定义**：
```
G/L = Q_air / Q_water
```
其中：
- Q_air：进气量（m³/h）
- Q_water：进水量（m³/h）

---

**氨氮吹脱效率与气水比的关系**（pH=11.5，25℃）：

| 气水比（m³/m³） | 氨氮去除率（%） | 能耗（kWh/m³水） |
|----------------|----------------|------------------|
| 50:1 | 45-55% | 0.8-1.2 |
| 100:1 | 65-75% | 1.5-2.0 |
| 200:1 | 80-88% | 2.8-3.5 |
| 300:1 | 88-93% | 4.2-5.0 |
| 500:1 | 93-96% | 7.0-8.5 |

**推荐气水比**：**200-300:1**（去除率与能耗平衡）

---

**VOCs吹脱效率与气水比的关系**（25℃，H'=0.5-2.0）：

| 气水比（m³/m³） | VOCs去除率（%） | 适用污染物 |
|----------------|----------------|-----------|
| 20:1 | 40-60% | 低挥发性有机物（H'<0.5） |
| 50:1 | 70-85% | 中等挥发性有机物（H'=0.5-2.0） |
| 100:1 | 85-95% | 高挥发性有机物（H'>2.0） |

**注**：H' = 亨利常数（无因次）

---

#### 4.1.2 浅层曝气与深层曝气对比

| 参数 | 浅层曝气（< 3m） | 深层曝气（> 5m） |
|-----|------------------|------------------|
| **氧转移效率** | 低（10-15%） | 高（25-40%） |
| **动力效率** | 低（1.5-2.5 kgO₂/kWh） | 高（3.5-6.0 kgO₂/kWh） |
| **曝气器类型** | 微孔曝气头 | 射流曝气器或螺旋曝气器 |
| **适用场景** | 应急处理（快速部署） | 长期运行（能效优先） |
| **占地面积** | 大（需大面积曝气池） | 小（竖向空间利用） |
| **建设成本** | 低 | 高（需深井或深池） |

**应急场景选择**：
- **优先选用浅层曝气**（设备易获取，部署快）
- 配套移动式鼓风机（风量10-50 m³/min）

---

#### 4.1.3 应急情况下曝气强度的估算

**曝气强度计算公式**：

```
I = (C₀ - C_e) × Q / (E × SOTE)
```

其中：
- I：曝气强度（kgO₂/h）
- C₀：进水COD/BOD（mg/L）
- C_e：出水COD/BOD（mg/L）
- Q：水量（m³/h）
- E：氧利用率（%）= SOTE × P / 100
- SOTE：标准氧转移效率（%）= 10-40%
- P：曝气器效率系数 = 0.6-0.8

**简易估算法**（应急处理）：
```
鼓风机风量（m³/min）= 处理水量（m³/h）× 0.5-1.0
```
示例：处理水量100 m³/h → 需鼓风机风量50-100 m³/min

---

### 4.2 化学氧化

#### 4.2.1 臭氧氧化

**臭氧氧化机理**：
1. **直接氧化**：O₃分子选择性氧化有机物（反应速率慢）
2. **间接氧化**：O₃分解产生·OH自由基，无选择性氧化（反应速率快）

---

**臭氧投加量设计参数**：

| 应用目标 | O₃投加量（mg/L） | 接触时间（min） | COD去除率（%） |
|---------|------------------|----------------|----------------|
| **消毒（饮用水）** | 1-3 | 10-15 | - |
| **脱色（印染废水）** | 10-30 | 30-60 | 60-90 |
| **COD降解（化工废水）** | 20-50 | 60-120 | 40-70 |
| **高级氧化（催化臭氧）** | 10-30 | 30-90 | 60-95 |

**接触池设计**：
- **接触时间**：t = 15-120 min（根据水质确定）
- **臭氧利用率**：η = 90-98%（用尾气破坏器分解残余O₃）
- **pH影响**：pH 6-9均有效；pH > 9时O₃分解加快（不利）

---

#### 4.2.2 芬顿氧化

**芬顿反应式**：
```
Fe²⁺ + H₂O₂ + H⁺ → Fe³⁺ + ·OH + H₂O
```

**关键设计参数**（已核实）：

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| **Fe²⁺:H₂O₂摩尔比** | 1:3 - 1:10 | 通常取1:5 |
| **pH** | 3.0-5.0 | 最佳pH 3.0-4.0 |
| **反应时间** | 60-120 min | 实际运行取90 min |
| **H₂O₂:COD（质量比）** | 1:1 - 2:1 | 根据小试确定 |
| **FeSO₄·7H₂O投加量** | 按H₂O₂:Fe²⁺=5:1（质量比）估算 | 例：H₂O₂投加200mg/L，需FeSO₄·7H₂O = 200×5 = 1000 mg/L |

---

**芬顿药剂投加顺序**：
```
加酸（调pH至3.5） → 加H₂O₂ → 加FeSO₄·7H₂O → 反应60-90min → 加碱（调pH至7.5） → 加PAM
```

**⚠️ 注意事项**：
- **必须先加H₂O₂，后加FeSO₄**（防止Fe²⁺被空气氧化为Fe³⁺）
- 若先加FeSO₄，会导致废水发黑（Fe³⁺水解），COD不降反升

---

#### 4.2.3 高锰酸钾氧化

**高锰酸钾氧化特性**：
- 氧化电位：E° = +1.51 V
- 最佳pH：中性至弱碱性（pH 6-9）
- 还原产物：MnO₂（棕黑色沉淀）

---

**投加量参考**（已核实）：

| 目标污染物 | KMnO₄投加量（mg/L） | 反应时间（min） | 去除率（%） |
|-----------|---------------------|----------------|-----------|
| **Mn²⁺（除锰）** | 0.15-0.5 | 20-40 | 90-99 |
| **Fe²⁺（除铁）** | 0.5-1.0 | 10-20 | 95-99 |
| **有机物（COD）** | 2-5 | 40-60 | 20-40 |
| **藻类和嗅味** | 1-3 | 20-40 | 70-90 |

**实际应用**：
- **预氧化**：在混凝前投加KMnO₄（0.5-2.0 mg/L），提高絮凝效果
- **应急处理**：投加KMnO₄（2-5 mg/L），快速氧化有毒有机物

---

#### 4.2.4 过硫酸盐高级氧化

**过硫酸盐类型**：
1. **过硫酸钠（Na₂S₂O₈）**
2. **过硫酸钾（K₂S₂O₈）**
3. **过一硫酸钾（KMnSO₅，即Oxone）**

**活化方式对比**：

| 活化方式 | 活化剂/条件 | 自由基类型 | 适用场景 |
|---------|-----------|----------|---------|
| **热活化** | 50-90℃ | SO₄⁻· | 高浓度有机废水 |
| **UV活化** | UV 254 nm | SO₄⁻· + ·OH | 低浊度废水 |
| **Fe²⁺活化** | Fe²⁺投加量0.5-5 mM | SO₄⁻· + ·OH | 宽pH范围 |
| **碱活化** | pH > 11 | SO₄⁻· | 强碱性废水 |
| **活性炭活化** | 活性炭投加量1-5 g/L | SO₄⁻· | 难降解有机废水 |

---

**Fe²⁺活化过硫酸盐设计参数**（推荐）：

| 参数 | 推荐值 |
|-----|-------|
| **过硫酸盐投加量** | 按S₂O₈²⁻:COD = 2:1 - 5:1（质量比） |
| **Fe²⁺投加量** | 按Fe²⁺:S₂O₈²⁻ = 1:10 - 1:20（摩尔比） |
| **pH** | 3.0-7.0（最佳pH 5.0） |
| **反应时间** | 60-180 min |
| **温度** | 20-40℃（升温可加快反应） |

## 专题5：地下水修复技术

### 5.1 抽出处理（Pump and Treat, P&T）

#### 5.1.1 设计参数

**P&T系统组成**：
1. **抽水井**：抽出污染地下水
2. **地面处理设施**：去除污染物
3. **回灌井**（可选）：将处理达标的水回灌

---

**设计参数表格**：

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| **井距** | 30-100 m | 根据污染羽范围和含水层渗透系数确定 |
| **抽水井数量** | 根据污染羽形状确定 | 通常沿污染羽流向布置3-7口井 |
| **单井抽水量** | 10-100 m³/d | 根据含水层厚度和渗透系数计算 |
| **处理时间** | 2-10年 | 取决于污染程度和自然衰减速率 |
| **地面处理工艺** | 活性炭吸附、空气吹脱、化学氧化 | 根据污染物类型选择 |

---

**抽水井布置示例**（二维污染羽）：

```
  上游 ← 污染羽 → 下游
  |---|---|---|---|---|
  井1 井2   井3   井4 井5
  (抽水) (抽水) (监测) (注水) (注水)
```

**井距计算**（Theis公式简化）：
```
r = √(T × t / (S × π))
```
其中：
- r：影响半径（m）
- T：导水系数（m²/d）= K × b
- t：抽水时间（d）
- S：储水系数（无因次）

---

### 5.2 原位化学氧化（In-Situ Chemical Oxidation, ISCO）

#### 5.2.1 注入方式

**ISCO氧化剂类型**：
1. **过氧化氢（H₂O₂）**
2. **高锰酸钾（KMnO₄）**
3. **过硫酸钠（Na₂S₂O₈）**
4. **臭氧（O₃）**

---

**注入方式对比**：

| 注入方式 | 适用氧化剂 | 影响半径（m） | 优点 | 缺点 |
|---------|-----------|---------------|------|------|
| **注射井注入** | H₂O₂、KMnO₄、过硫酸盐 | 5-15 | 影响范围可控 | 需建井，成本高 |
| **高压旋喷注入** | H₂O₂、KMnO₄ | 3-8 | 不需建井，快速部署 | 影响半径小 |
| **注入井+曝气** | O₃ | 10-20 | 氧化+吹脱双重作用 | O₃易分解，利用率低 |
| **重力自流注入** | KMnO₄（低浓度） | 2-5 | 设备简单 | 仅适用于高渗透地层 |

---

#### 5.2.2 影响半径计算

**H₂O₂注入影响半径**（经验公式）：

```
R = √(Q × t / (n × π × b))
```

其中：
- R：影响半径（m）
- Q：注入速率（m³/d）
- t：注入时间（d）
- n：孔隙度（无因次）= 0.2-0.4
- b：含水层厚度（m）

**示例**：
- Q = 10 m³/d
- t = 7 d
- n = 0.3
- b = 5 m

```
R = √(10 × 7 / (0.3 × π × 5)) = √(70 / 4.71) = √14.86 = 3.86 m
```

**注**：实际影响半径受地层非均质性影响大，需现场试验确定

---

### 5.3 可渗透反应墙（Permeable Reactive Barrier, PRB）

#### 5.3.1 填料选择

**常用PRB填料类型**：

| 填料类型 | 适用污染物 | 反应机理 | 使用寿命（年） |
|---------|-----------|---------|---------------|
| **零价铁（Fe⁰）** | 氯代烃、重金属Cr⁶⁺、硝酸盐 | 还原反应 | 5-15 |
| **活性炭** | 有机物、重金属 | 吸附 | 2-5（需更换） |
| **磷灰石** | Pb、Cd、Cu、Zn | 沉淀/吸附 | 10-20 |
| **沸石** | NH₄⁺、重金属 | 离子交换/吸附 | 5-10 |
| **石灰石** | 酸性废水、重金属 | 中和/沉淀 | 3-8 |
| **混合填料（Fe⁰+活性炭）** | 有机物+重金属复合污染 | 还原+吸附 | 5-10 |

---

#### 5.3.2 厚度设计

**PRB厚度计算公式**（Bosma等，1997）：

```
L = v × t_required
```

其中：
- L：PRB厚度（m）
- v：地下水流速（m/d）
- t_required：所需反应时间（d）

**反应时间确定**：
- **零价铁还原TCE**：t = 0.5-2.0 d
- **活性炭吸附苯系物**：t = 0.1-0.5 d
- **磷灰石沉淀Pb**：t = 0.05-0.2 d

**示例**：
- 地下水流速：v = 0.1 m/d
- 目标污染物：TCE
- 所需反应时间：t = 1.0 d

```
L = 0.1 × 1.0 = 0.1 m = 10 cm
```

**实际设计**：
- 考虑安全系数2-5：
  ```
  L_design = 0.1 × 3 = 0.3 m = 30 cm
  ```
- 取整：**PRB厚度0.5 m**

---

**PRB厚度经验值**（已建工程统计）：

| 污染物类型 | 推荐PRB厚度（m） | 填料类型 |
|-----------|-----------------|---------|
| 氯代烃（TCE、PCE） | 0.3-1.0 | 零价铁 |
| 重金属（Cr⁶⁺、As） | 0.5-1.5 | 零价铁+石灰石 |
| 氨氮 | 1.0-2.0 | 沸石 |
| 有机物+重金属复合污染 | 1.0-2.0 | 零价铁+活性炭 |

### 5.4 监测自然衰减（Monitoring Natural Attenuation, MNA）

#### 5.4.1 衰减速率常数

**一级衰减动力学模型**：

```
C(t) = C₀ × e^(-k × t)
```

其中：
- C(t)：t时刻污染物浓度（mg/L）
- C₀：初始浓度（mg/L）
- k：衰减速率常数（d⁻¹）
- t：时间（d）

---

**典型污染物衰减速率常数范围**（地下水，20-25℃）：

| 污染物 | 衰减机理 | k（d⁻¹） | 半衰期（d） |
|--------|---------|----------|------------|
| **苯** | 生物降解 | 0.001-0.05 | 14-693 |
| **甲苯** | 生物降解 | 0.005-0.08 | 9-139 |
| **TCE** | 化学还原 | 0.0005-0.02 | 35-1386 |
| **硝酸盐** | 反硝化 | 0.01-0.10 | 7-69 |
| **硫酸盐** | 硫酸盐还原 | 0.005-0.06 | 12-139 |

**半衰期计算**：
```
t₁/₂ = ln(2) / k = 0.693 / k
```

---

**MNA适用条件**（US EPA，1999）：
1. 污染物浓度持续下降（连续3次监测浓度下降>10%）
2. 有证据表明存在自然衰减机制（微生物活性、氧化还原条件等）
3. 衰减速率满足风险管控要求（预测100年内浓度<风险阈值）
4. 不影响周边地下水利用（饮用水源区慎用）
