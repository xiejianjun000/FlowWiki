## 专题1：大气扩散模型基础

### 1.1 高斯烟羽模型物理基础

#### 1.1.1 高斯公式（连续点源、地面反射项）

**完整公式：**

```
χ(x,y,z) = Q/(2πuσ_yσ_z) × exp(-y²/2σ_y²) × [exp(-(z-H)²/2σ_z²) + exp(-(z+H)²/2σ_z²)]
```

**各参数物理意义和单位：**

| 参数 | 物理意义 | 单位 | 说明 |
|------|----------|------|------|
| χ(x,y,z) | 空间点(x,y,z)处的污染物浓度 | μg/m³ 或 mg/m³ | 模型输出值 |
| Q | 源强（排放速率） | μg/s 或 mg/s | 连续排放强度 |
| u | 平均风速（泄漏高度处） | m/s | 通常为3-5m/s（10m高） |
| σ_y | 横向（y方向）扩散参数 | m | 随下风向距离x增大 |
| σ_z | 垂直（z方向）扩散参数 | m | 随下风向距离x增大 |
| x | 下风向距离 | m | 从排放点沿风向的距离 |
| y | 横风向距离 | m | 垂直于风向的距离 |
| z | 高度 | m | 离地面高度 |
| H | 有效源高 | m | 物理高度h + 烟气抬升Δh |

**公式推导假设：**
1. 污染物浓度在y、z轴呈高斯分布（正态分布）
2. 源强连续且均匀
3. 风速恒定且方向不变
4. 地面全反射（不吸收、不吸附）
5. 污染物不发生沉降、分解、化学反应

**地面浓度公式（z=0）：**

```
C(x,y,0,H) = Q/(πuσ_yσ_z) × exp(-y²/2σ_y²) × exp(-H²/2σ_z²)
```

**地面轴线浓度公式（y=0, z=0）：**

```
C(x,0,0,H) = Q/(πuσ_yσ_z) × exp(-H²/2σ_z²)
```

#### 1.1.2 Pasquill-Gifford稳定度分类

**稳定度等级（A-F）：**

| 等级 | 稳定度 | 特征 | 典型条件 |
|------|--------|------|----------|
| A | 极不稳定 | 强湍流，扩散快 | 白天、晴天、风速<2m/s |
| B | 不稳定 | 湍流较强 | 白天、中等日照 |
| C | 弱不稳定 | 湍流中等 | 白天、阴天或中等风速 |
| D | 中性 | 湍流适中 | 阴天或大风（风速>6m/s）、夜间中等风速 |
| E | 较稳定 | 湍流弱 | 夜间、晴天、风速<3m/s |
| F | 极稳定 | 湍流极弱 | 冬季寒夜、逆温 |

**稳定度确定方法（修订Pasquill法）：**

**步骤1：计算太阳高度角**

```
sin(h) = sin(φ)sin(δ) + cos(φ)cos(δ)cos(ω)
```

其中：
- h = 太阳高度角（度）
- φ = 当地地理纬度（度）
- δ = 太阳倾角（度，可查表）
- ω = 时角（度，15°/h）

**步骤2：查太阳辐射等级数**

根据太阳高度角和云量查表：

| 总云量/低云量 | 夜间 | ho≤15° | 15°<ho≤35° | 35°<ho≤65° | ho>65° |
|---------------|------|---------|-------------|-------------|---------|
| ≤4/≤4 | -2 | -1 | 1 | 2 | 3 |
| 5-7/≤4 | -1 | 0 | 1 | 2 | 3 |
| ≥8/≤4 | -1 | 0 | 0 | 1 | 1 |
| ≥5/5-7 | 0 | 0 | 0 | 0 | 1 |
| ≥8/≥8 | 0 | 0 | 0 | 0 | 0 |

**步骤3：查稳定度等级**

根据太阳辐射等级数和地面风速查表：

| 太阳辐射等级 | 风速≤2m/s | 2-3m/s | 3-5m/s | 5-6m/s | ≥6m/s |
|--------------|-----------|--------|--------|--------|-------|
| +3 | A | A-B | B | C | D |
| +2 | A-B | B | C | D | D |
| +1 | B | C | D | D | D |
| 0 | C | D | D | D | D |
| -1 | D | D | D | D | D |
| -2 | F | E | D | D | D |

**城市和乡村不同的σ_y、σ_z曲线：**

#### 1.1.4 有效源高H = 物理高度h + 烟气抬升Δh

**烟气抬升公式（Briggs公式）：**

**1. 浮力抬升（Hot gas plume）：**

当烟气温度高于环境温度时，产生浮力抬升。

**Briggs（1969）公式：**

**不稳定或中性大气条件（Q_H > 21000 kW）：**

```
当 x ≤ 10H_s 时：ΔH = 0.362 × Q_H^(1/3) × x^(2/3) / u
当 x > 10H_s 时：ΔH = 0.362 × Q_H^(1/3) × (10H_s)^(2/3) / u
```

**当 Q_H ≤ 21000 kW 且 (T_s - T_a) < 35 K 时：**

```
ΔH = 0.124 × Q_H / u
```

其中：
- Q_H = 烟气热排放率（kW）
- Q_H = (π/4) × d² × v_s × ρ_s × c_p × (T_s - T_a) （计算公式）
- x = 下风向距离（m）
- H_s = 烟囱物理高度（m）
- u = 烟囱高度处风速（m/s）
- v_s = 烟气出口速度（m/s）
- d = 烟囱出口直径（m）
- ρ_s = 烟气密度（kg/m³）
- c_p = 烟气比热容（kJ/(kg·K)）
- T_s = 烟气温度（K）
- T_a = 环境温度（K）

**2. 动量抬升（Cold gas plume）：**

当烟气温度接近环境温度时，主要考虑动量抬升。

**Briggs公式：**

```
ΔH = (v_s × d / u) × [1.5 + 2.7 × (T_s - T_a) / T_s × d]
```

或简化公式（Holland公式）：

```
ΔH = (v_s × d / u) × [1.5 + 2.7 × (T_s - T_a) × d / T_s]
```

**3. 综合抬升（Briggs公式）：**

```
ΔH = ΔH_buoyancy + ΔH_momentum
```

**实际应用中的简化：**

- 当浮力抬升主导时（热烟气）：ΔH ≈ 1.5 × Q_H^(1/3) / u
- 当动量抬升主导时（冷烟气）：ΔH ≈ v_s × d / u

> **待核实：** Briggs公式的具体系数和适用条件需查阅Briggs (1969, 1975, 1982)原始文献。

### 1.2 重气扩散模型

#### 1.2.1 重气（密度>空气）与中性气体的关键区别

**重气定义：**
密度大于空气的气体，如：
- 氯气（Cl₂）：分子量71，密度约为空气的2.5倍
- 二氧化硫（SO₂）：分子量64，密度约为空气的2.2倍
- 硫化氢（H₂S）：分子量34，密度约为空气的1.2倍
- 丙烷（C₃H₈）：分子量44，密度约为空气的1.5倍

**关键区别：**

| 特征 | 中性气体（如CO、NOx） | 重气（如Cl₂、SO₂） |
|------|----------------------|-------------------|
| 密度 | 接近空气 | 大于空气 |
| 扩散行为 | 主要受湍流扩散影响 | 重力作用显著，易在低洼处聚集 |
| 浓度分布 | 高斯分布 | 非高斯分布，近地面浓度高 |
| 影响范围 | 较大 | 相对较小，但近源区浓度高 |
| 持续时间 | 较短 | 较长（易停留） |
| 模型选择 | 高斯模型 | 重气扩散模型（SLAB、DEGADIS） |

---

#### 1.2.2 氯气、二氧化硫、硫化氢、丙烷等的扩散特性

**氯气（Cl₂）：**
- 密度：2.5倍空气
- 泄漏后易在地面或低洼处聚集
- 刺激性和腐蚀性极强
- ERPG-1: 1 ppm, ERPG-2: 3 ppm, ERPG-3: 20 ppm
- AEGL-1: 0.5 ppm, AEGL-2: 2.7 ppm, AEGL-3: 20 ppm

**二氧化硫（SO₂）：**
- 密度：2.2倍空气
- 易溶于水（1体积水溶解40体积SO₂）
- 刺激呼吸道
- ERPG-1: 0.3 ppm, ERPG-2: 3 ppm, ERPG-3: 15 ppm

**硫化氢（H₂S）：**
- 密度：1.2倍空气
- 臭鸡蛋味（低浓度），高浓度时嗅觉麻痹
- 剧毒，IDLH = 100 ppm
- ERPG-1: 0.1 ppm, ERPG-2: 10 ppm, ERPG-3: 50 ppm

**丙烷（C₃H₈）：**
- 密度：1.5倍空气
- 易燃，爆炸极限2.1%-9.5%
- 无色无味，需添加臭味剂

#### 1.2.3 重气扩散的SLAB/DEGADIS模型基本原理

**SLAB模型（重气连续泄漏扩散模型）：**

**基本原理：**
- 假设重气云团为矩形截面（slab shape）
- 考虑重力沉降、空气夹卷、湍流扩散
- 适用于平坦地形、连续泄漏

**控制方程：**

```
∂C/∂t + u∂C/∂x = ∂/∂z(K_z∂C/∂z) - v_settle∂C/∂z
```

其中：
- C = 浓度（kg/m³）
- u = 风速（m/s）
- K_z = 垂直扩散系数（m²/s）
- v_settle = 沉降速度（m/s）

**DEGADIS模型（重气瞬时泄漏扩散模型）：**

**基本原理：**
- 考虑重气的重力流和空气夹卷
- 适用于瞬时泄漏或短时间泄漏
- 考虑浓度相关的密度效应

**关键参数：**
- 初始密度比：ρ_gas/ρ_air
- 初始温度
- 泄漏量
- 风速和稳定度

---

#### 1.2.4 箱模型和浅层模型的概念

**箱模型（Box Model）：**

**基本原理：**
- 将重气云团简化为一个"箱子"
- 箱子尺寸（长、宽、高）随时间变化
- 考虑空气夹卷、重力沉降、扩散

**质量平衡方程：**

```
dM/dt = -E × M
```

其中：
- M = 云团质量（kg）
- E = 空气夹卷系数（1/s）

**浅层模型（Shallow Layer Model）：**

**基本原理：**
- 假设重气层厚度远小于水平尺度
- 使用浅水方程描述重气扩散
- 考虑重力流、摩擦力、湍流扩散

**控制方程：**

```
∂h/∂t + ∂(uh)/∂x + ∂(vh)/∂y = 0
∂(uh)/∂t + ∂(u²h)/∂x + ∂(uvh)/∂y = -gh∂(ρh)/∂x - τ_x/ρ
∂(vh)/∂t + ∂(uvh)/∂x + ∂(v²h)/∂y = -gh∂(ρh)/∂y - τ_y/ρ
```

其中：
- h = 重气层厚度（m）
- u, v = 平均速度分量（m/s）
- g = 重力加速度（m/s²）
- ρ = 密度（kg/m³）
- τ = 剪切应力（Pa）

### 1.3 ALOHA深度操作

#### 1.3.1 源强估算方法

**1. 液体泄漏：伯努利方程**

```
Q = C_d × A × ρ × √(2gH + 2ΔP/ρ)
```

其中：
- Q = 泄漏速率（kg/s）
- C_d = 泄漏系数（无量纲）
  - 圆形孔：0.65（Re>100），0.50（Re≤100）
  - 三角形孔：0.60（Re>100），0.45（Re≤100）
  - 长方形孔：0.55（Re>100），0.40（Re≤100）
- A = 裂口面积（m²）
- ρ = 液体密度（kg/m³）
- g = 重力加速度（9.81 m/s²）
- H = 液柱高度（m）
- ΔP = 内外压差（Pa）

**2. 气体泄漏：等熵流动**

**临界流（choked flow）：**

当 p₂/p₁ ≤ (2/(k+1))^(k/(k-1)) 时：

```
Q = C_d × A × p₁ × √(k/(R×T₁)) × (2/(k+1))^((k+1)/(2(k-1)))
```

**亚临界流（subcritical flow）：**

当 p₂/p₁ > (2/(k+1))^(k/(k-1)) 时：

```
Q = C_d × A × p₁ × √(2k/((k-1)×R×T₁)) × √((p₂/p₁)^(2/k) - (p₂/p₁)^((k+1)/k))
```

其中：
- p₁ = 容器内压力（Pa）
- p₂ = 环境压力（Pa）
- k = 气体绝热指数（空气1.4，单原子气体1.67）
- R = 气体常数（J/(mol·K)）
- T₁ = 气体温度（K）

**3. 闪蒸（Flash evaporation）：**

当液体过热时（温度高于常压沸点），部分液体瞬间汽化。

**闪蒸比例计算：**

```
F_v = (H_L - H_L') / (H_V' - H_L')
```

其中：
- F_v = 闪蒸比例（质量分数）
- H_L = 初始状态下液体焓（J/kg）
- H_L' = 闪蒸后液体焓（J/kg）
- H_V' = 闪蒸后蒸汽焓（J/kg）

**4. 液池蒸发：**

```
Q_evap = K × A × (P_sat - P_air) / (R×T)
```

其中：
- Q_evap = 蒸发速率（kg/s）
- K = 传质系数（m/s）
- A = 液池面积（m²）
- P_sat = 饱和蒸汽压（Pa）
- P_air = 空气中该物质分压（Pa）
- R = 气体常数（J/(mol·K)）
- T = 温度（K）

**5. 两相流：**

当液体和压力都参与泄漏时。

**等效泄漏系数法：**

```
Q_tp = Q_liquid × (1 + x × (ρ_L/ρ_G - 1))
```

其中：
- Q_tp = 两相流泄漏速率（kg/s）
- Q_liquid = 仅液体泄漏速率（kg/s）
- x = 气相质量分数
- ρ_L = 液体密度（kg/m³）
- ρ_G = 气体密度（kg/m³）

#### 1.3.2 输入参数敏感性分析

**哪些参数对结果影响最大？**

**1. 大气参数：**
- **风速**：影响最大，风速增加→浓度降低、影响范围增大
- **稳定度**：影响扩散参数，稳定时影响范围小但近源浓度高
- **云量**：影响稳定度分类

**2. 源参数：**
- **源强（Q）**：线性影响，源强增大→浓度成比例增大
- **有效源高（H）**：影响地面浓度，H增大→地面浓度降低
- **温度**：影响烟气抬升和密度

**3. 化学品参数：**
- **分子量**：影响重气行为
- **沸点**：影响蒸发速率
- **蒸汽压**：影响挥发速率

**敏感性排序（大致）：**
1. 风速（u）← 影响最大
2. 源强（Q）
3. 有效源高（H）
4. 稳定度
5. 其他参数

> **建议：** 进行不确定性分析时，应重点考虑风速和源强的可能变化范围。

#### 1.3.3 ALOHA模型选择：高斯vs重气

**模型切换条件：**

**使用高斯模型的条件：**
- 气体密度接近空气（分子量28-32）
- 泄漏速率较低
- 风速较大（>3m/s）
- 温度较高

**使用重气模型的条件：**
- 气体密度明显大于空气（分子量>40）
- 泄漏速率较高
- 风速较小（<3m/s）
- 温度较低

**ALOHA中的判断逻辑：**
- 当化学品数据库中标记"Heavy gas"时，优先使用重气模型
- 用户可手动选择模型类型

> **待核实：** ALOHA具体的模型切换阈值（如密度比、风速阈值）需查阅ALOHA用户手册。

#### 1.3.4 输出解读

**威胁区域（红/橙/黄）对应标准：**

**红色区域（威胁最大）：**
- 通常对应 **AEGL-3** 或 **ERPG-3**
- 暴露1小时可威胁生命
- 需立即撤离

**橙色区域（威胁中等）：**
- 通常对应 **AEGL-2** 或 **ERPG-2**
- 暴露1小时可造成不可逆伤害
- 需防护后进入

**黄色区域（威胁较小）：**
- 通常对应 **AEGL-1** 或 **ERPG-1**
- 暴露1小时可产生轻微症状
- 需注意防护

**LOC浓度的含义：**
- LOC = Level of Concern（关注浓度）
- 通常指ERPG-2或AEGL-2
- 用于确定防护距离

**常用毒性标准对比：**

| 标准 | 定义 | 暴露时间 | 用途 |
|------|------|----------|------|
| AEGL-1 | 明显不适、刺激 | 10min-8h | 公众防护 |
| AEGL-2 | 不可逆伤害、削弱逃生能力 | 10min-8h | 公众防护 |
| AEGL-3 | 威胁生命或死亡 | 10min-8h | 公众防护 |
| ERPG-1 | 轻微、短暂影响 | 1h | 工业应急 |
| ERPG-2 | 不可恢复性伤害 | 1h | 工业应急 |
| ERPG-3 | 威胁生命 | 1h | 工业应急 |
| IDLH | 立即威胁生命和健康 | 30min | 呼吸防护 |
| TLV-TWA | 时间加权平均阈限值 | 8h/40h | 职业暴露 |
| TLV-STEL | 短期暴露限值 | 15min | 职业暴露 |

---

#### 1.3.5 ALOHA的8个主要局限性和误用场景

**局限性：**

1. **地形影响：**
   - ALOHA不考虑复杂地形（山丘、建筑物）
   - 在复杂地形区域结果可能偏差较大

2. **化学反应：**
   - 不考虑化学反应（如氯气遇水生成次氯酸）
   - 实际毒性可能被低估或高估

3. **微粒：**
   - 不考虑微粒（气溶胶、烟尘）
   - 仅适用于纯气体或蒸汽

4. **化学混合物：**
   - 不考虑多组分混合物
   - 仅适用于单一化学品

5. **极低风速：**
   - 当风速<1m/s时，模型不稳定
   - 结果可能不可靠

6. **非常稳定的大气条件：**
   - 在强逆温条件下，扩散参数可能低估
   - 近源区浓度可能偏高

7. **风移和地形转向效果：**
   - 不考虑风场变化和结构传输
   - 在复杂风场区域误差较大

8. **浓度不均：**
   - 假设浓度连续分布
   - 实际泄漏可能呈瞬时团状

**误用场景：**

1. **将ALOHA结果作为精确预测：**
   - ALOHA是 screening tool，不是精确预测模型
   - 结果应作为参考，而非绝对真理

2. **忽略输入参数的不确定性：**
   - 输入参数（如风速、源强）常有误差
   - 应进行敏感性分析

3. **在复杂地形使用默认设置：**
   - 应适当调整参数或使用更高精度模型

4. **不考虑化学品混合效应：**
   - 多种化学品同时存在时，毒性可能协同或拮抗

## 专题2：河流水质模型

### 2.1 一维河流水质模型

#### 2.1.1 一维稳态基本方程

**完整方程：**

```
u·∂C/∂x = D·∂²C/∂x² - k·C
```

其中：
- C = 污染物浓度（mg/L）
- u = 河流流速（m/s）
- D = 纵向离散系数（m²/s）
- k = 衰减系数（1/d）
- x = 下风向距离（m）

**忽略扩散项后的解析解：**

当D较小或距离较远时，可忽略扩散项：

```
u·dC/dx = -k·C
```

解得：

```
C(x) = C₀ × exp(-kx/u)
```

或：

```
C(x) = C₀ × exp(-k×t)
```

其中：
- C₀ = 初始浓度（mg/L）
- t = 运移时间（d），t = x/u
- k = 衰减系数（1/d）

---

#### 2.1.2 衰减系数k的取值

**不同污染物的k值范围：**

| 污染物类型 | k值范围（1/d） | 典型值（1/d） | 依据来源 |
|------------|---------------|--------------|----------|
| **重金属** | 0.01-0.1 | 0.05 | 沉降主导，降解可忽略 |
| **有机物（BOD₅）** | 0.1-0.5 | 0.3 | 生物降解 |
| **氨氮（NH₃-N）** | 0.1-1.0 | 0.5 | 硝化作用 |
| **挥发物** | 0.5-5.0 | 2.0 | 受亨利常数和流速影响 |
| **COD** | 0.05-0.3 | 0.15 | 部分可生物降解 |
| **总磷（TP）** | 0.01-0.05 | 0.02 | 沉降、吸附 |
| **总氮（TN）** | 0.05-0.2 | 0.1 | 多种过程 |

**各取值依据来源：**

1. **重金属（如Cu、Pb、Zn、Cd）：**
   - 主要来自沉降和吸附
   - k值低，0.01-0.1 d⁻¹
   - 参考：《地表水环境质量标准》(GB 3838-2002)

2. **BOD₅：**
   - 生物降解速率
   - 受温度影响：k_T = k_20 × 1.047^(T-20)
   - 参考：Streeter-Phelps方程

3. **氨氮：**
   - 硝化速率
   - 受DO、温度、pH影响
   - 参考：《水环境数学模型》(Chapra, 1997)

4. **挥发物（如苯、甲苯）：**
   - 挥发速率受亨利常数H和流速u影响
   - k_vol = K_L × a（传质系数×比表面积）
   - 参考：Two-film理论

> **待核实：** 各地区、各河流的k值差异较大，建议通过实测数据率定。

---

#### 2.1.3 流量、流速、水深、河宽的综合曼宁公式估算

**曼宁公式（Manning's formula）：**

```
u = (1/n) × R_h^(2/3) × S^(1/2)
```

其中：
- u = 断面平均流速（m/s）
- n = 曼宁糙率系数（无量纲）
- R_h = 水力半径（m），R_h = A/P
- A = 过水截面积（m²）
- P = 湿周（m）
- S = 水力坡度（m/m），近似等于河床坡度

**流量计算：**

```
Q = A × u = A × (1/n) × R_h^(2/3) × S^(1/2)
```

**常见河道的糙率n值：**

| 河道类型 | n值 |
|----------|-----|
| 光滑混凝土渠 | 0.012 |
| 粗糙混凝土渠 | 0.015 |
| 土渠（直、整洁） | 0.022 |
| 土渠（弯曲、有杂草） | 0.030 |
| 天然河流（清洁、直） | 0.030 |
| 天然河流（弯曲、有浅滩） | 0.040 |
| 山区河流（多石、急流） | 0.050 |

**矩形河道简化：**

对于宽浅河道（B>>h）：
- A ≈ B × h
- P ≈ B
- R_h ≈ h

则：

```
u ≈ (1/n) × h^(2/3) × S^(1/2)
Q ≈ B × h × (1/n) × h^(2/3) × S^(1/2) = (B/n) × h^(5/3) × S^(1/2)
```

---

#### 2.1.4 污染团运移时间估算

**基本公式：**

```
t = L / (u × α)
```

其中：
- t = 运移时间（s）
- L = 距离（m）
- u = 河流流速（m/s）
- α = 峰值速度系数（无量纲）

**峰值速度系数α：**
- 通常α = 1.0-1.5
- α = 1.0：峰值浓度以平均流速移动
- α = 1.5：峰值浓度以1.5倍平均流速移动（层流条件）
- 实际值需根据河流流态确定

**污染团迁移的平移和衰减：**

```
C(x,t) = (M/A) × (1/(2πD_x t))^(1/2) × exp(-(x-u t)²/(4D_x t)) × exp(-k t)
```

其中：
- M = 泄漏量（kg）
- A = 河道截面积（m²）
- D_x = 纵向离散系数（m²/s）

---

### 2.2 混合区与横向扩散

#### 2.2.1 完全混合距离估算

**理论公式（中心排放）：**

```
L_m ≈ 0.4 × B² × u / D_y
```

或（使用曼宁公式推导）：

```
L_m = 3 × B² × u / (h × √(g × h × S))
```

其中：
- L_m = 完全混合距离（m）
- B = 河宽（m）
- u = 平均流速（m/s）
- D_y = 横向扩散系数（m²/s）
- h = 水深（m）
- g = 重力加速度（9.81 m/s²）
- S = 水力坡度

**经验公式（Fischer et al., 1979）：**

```
L_m = 0.1 × B² × u / (D_y)
```

**横向扩散系数D_y的估算：**

```
D_y = 0.6 × h × u × f
```

其中：
- f = 阻尼因子（无量纲），通常0.1-0.6

---

#### 2.2.2 岸边排放和非岸边排放的不同混合特征

**岸边排放：**
- 混合距离较短（仅需向一侧混合）
- 近岸浓度较高
- 完全混合距离约为中心排放的1/4

**非岸边排放（中心排放）：**
- 混合距离较长（需向两侧混合）
- 浓度分布较均匀
- 完全混合后浓度较低

**混合区长度的经验判断：**
- 岸边排放：L_m ≈ 10-20倍河宽
- 中心排放：L_m ≈ 50-100倍河宽

---

### 2.3 油类和重质溶质的特殊行为

#### 2.3.1 油的漂移方向

**漂移速度公式：**

```
V_oil = V_current + 0.03 × V_wind
```

其中：
- V_oil = 油膜漂移速度矢量（m/s）
- V_current = 表面流速矢量（m/s）→ 权重100%
- V_wind = 10m高风速矢量（m/s）→ 权重3%

**矢量叠加：**
- 油膜漂移方向 = 表面流速方向 + 风向（偏转3%）

**影响因素：**
- 风速：风越大，油膜漂移越快
- 流速：主要影响漂移方向
- 油品种类：轻质油挥发快，重质油漂移距离长

---

#### 2.3.2 油膜扩展的Fay公式

**Fay三阶段扩展理论：**

**阶段1：重力-惯性力阶段（初期）**

```
r(t) = C₁ × (g×Δρ/ρ)^(1/3) × V^(1/3) × t^(1/2)
```

**阶段2：重力-粘性力阶段（中期）**

```
r(t) = C₂ × (g×Δρ/ρ)^(1/2) × V^(1/2) × t^(1/4)
```

**阶段3：表面张力-粘性力阶段（后期）**

```
r(t) = C₃ × (σ/μ)^(1/2) × V^(1/4) × t^(1/8)
```

其中：
- r(t) = 油膜半径（m）
- V = 溢油量（m³）
- g = 重力加速度（9.81 m/s²）
- Δρ = 密度差（kg/m³）
- ρ = 水密度（kg/m³）
- μ = 油粘度（Pa·s）
- σ = 表面张力（N/m）
- t = 时间（s）
- C₁, C₂, C₃ = 经验系数

**油膜面积估算：**

```
A(t) = π × r(t)²
```

---

#### 2.3.3 重质溶质沉底后的再悬浮条件

**沉降条件：**

```
v_settle > w
```

其中：
- v_settle = 颗粒沉降速度（m/s）
- w = 水体垂直流速（m/s）

**沉降速度（Stokes公式）：**

```
v_settle = (g × (ρ_p - ρ) × d²) / (18 × μ)
```

其中：
- ρ_p = 颗粒密度（kg/m³）
- d = 颗粒直径（m）
- μ = 水动力粘度（Pa·s）

**再悬浮条件：**

```
τ_bed > τ_critical
```

其中：
- τ_bed = 床面剪切应力（Pa）
- τ_critical = 临界剪切应力（Pa）

**剪切应力计算：**

```
τ_bed = ρ × g × R_h × S
```

**临界剪切应力（Shields参数）：**

```
τ_critical = θ × (ρ_p - ρ) × g × d
```

其中：
- θ = Shields参数（无量纲），通常0.05-0.06

## 专题3：地下水溶质运移模型

### 3.1 基本概念

#### 3.1.1 达西定律

**达西定律公式：**

```
v = K × i
```

或：

```
Q = K × A × i
```

其中：
- v = 达西流速（m/s）
- Q = 流量（m³/s）
- K = 渗透系数（m/s）
- i = 水力梯度（无量纲），i = Δh/L
- A = 过水截面积（m²）
- Δh = 水头差（m）
- L = 渗流路径长度（m）

---

#### 3.1.2 渗透系数K的经验值范围

**不同岩土的渗透系数K（参考值）：**

| 岩土类型 | K（m/s） | K（m/d） | 备注 |
|----------|----------|----------|------|
| **黏土** | <10⁻⁹ | <0.0001 | 几乎不透水 |
| **粉质黏土** | 10⁻⁹~10⁻⁷ | 0.0001~0.01 | 弱透水 |
| **粉土** | 10⁻⁷~10⁻⁵ | 0.01~1 | 半透水 |
| **黄土** | 10⁻⁶~10⁻⁴ | 0.1~10 | 透水 |
| **粉砂** | 10⁻⁵~10⁻⁴ | 1~10 | 透水 |
| **细砂** | 10⁻⁴~10⁻³ | 10~100 | 透水 |
| **中砂** | 10⁻³~10⁻² | 100~1000 | 强透水 |
| **粗砂** | 10⁻²~10⁻¹ | 1000~10000 | 强透水 |
| **砾石** | 10⁻¹~10⁰ | 10000~100000 | 极强透水 |
| **卵石** | >10⁰ | >100000 | 极强透水 |

> **注：** 上述为数量级参考，实际值需通过抽水试验或实验室测定。

---

#### 3.1.3 孔隙度、有效孔隙度、水力梯度的区别

**孔隙度（n）：**

```
n = V_void / V_total
```

- 总孔隙体积与总体积之比
- 无量纲，0-1之间

**有效孔隙度（n_eff）：**

```
n_eff = V_mobile / V_total
```

- 连通孔隙中与流体流动相关的孔隙体积占比
- 通常小于总孔隙度
- 黏土的有效孔隙度可能只有总孔隙度的10%-30%

**水力梯度（i）：**

```
i = (h₁ - h₂) / L
```

- 沿渗流路径单位距离的水头损失
- 无量纲
- 驱动地下水流动的动力

---

#### 3.1.4 实际流速 vs 达西流速

**关系：**

```
v_actual = v_Darcy / n_eff
```

其中：
- v_actual = 实际平均流速（m/s）
- v_Darcy = 达西流速（m/s），v_Darcy = K×i
- n_eff = 有效孔隙度（无量纲）

**示例：**
- 达西流速：0.01 m/d
- 有效孔隙度：0.2
- 实际流速：0.01 / 0.2 = 0.05 m/d

---

### 3.2 溶质运移基本方程

#### 3.2.1 对流-弥散方程（ADE）

**一维ADE方程：**

```
∂C/∂t = D_L × ∂²C/∂x² - v × ∂C/∂x - λ × C + S
```

其中：
- C = 溶质浓度（mg/L）
- t = 时间（d）
- x = 距离（m）
- D_L = 纵向弥散系数（m²/d）
- v = 平均孔隙流速（m/d），v = v_Darcy / n_eff
- λ = 一级衰减系数（1/d）
- S = 源/汇项（mg/(L·d)）

**各项物理意义：**
- ∂C/∂t：浓度随时间变化
- D_L × ∂²C/∂x²：弥散作用（机械混合和分子扩散）
- v × ∂C/∂x：对流作用（随水流迁移）
- λ × C：衰减作用（生物降解、吸附等）
- S：外部源或汇

---

#### 3.2.2 弥散度（α_L）的取值

**弥散度定义：**

```
D_L = α_L × v
```

其中：
- D_L = 纵向弥散系数（m²/d）
- α_L = 纵向弥散度（m）
- v = 平均孔隙流速（m/d）

**α_L与迁移距离的关系：**

经验关系：

```
α_L ≈ 0.1 × L
```

其中：
- L = 迁移距离（m）

**不同尺度下的值：**

| 尺度 | 弥散度α_L（m） | 备注 |
|------|----------------|------|
| **实验室尺度**（cm级） | 0.001-0.01 | 岩芯试验 |
| **试验场地尺度**（m级） | 0.1-10 | 抽水试验 |
| **场地尺度**（10-100m） | 1-50 | 污染羽研究 |
| **区域尺度**（km级） | 100-1000 | 地下水盆地 |

> **待核实：** 弥散度的尺度效应是地下水模拟中的难题，建议参考Gelhar et al. (1992)的综述。

---

#### 3.2.3 阻滞系数R

**阻滞系数公式：**

```
R = 1 + (ρ_b × K_d) / n_eff
```

其中：
- R = 阻滞系数（无量纲）
- ρ_b = 土壤容重（kg/m³）
- K_d = 分配系数（L/kg）
- n_eff = 有效孔隙度（无量纲）

**物理意义：**
- R > 1：溶质迁移速度慢于水流速度
- R = 1：溶质不吸附，随水流同步迁移
- R越大，阻滞作用越强

**考虑阻滞的ADE方程：**

```
R × ∂C/∂t = D_L × ∂²C/∂x² - v × ∂C/∂x - λ × C
```

**分配系数K_d的查表：**

| 污染物 | 土壤类型 | K_d（L/kg） | 备注 |
|--------|----------|-------------|------|
| **苯** | 砂土 | 0.1-1 | 弱吸附 |
| **苯** | 黏土 | 1-10 | 中等吸附 |
| **铅（Pb）** | 砂土 | 10-100 | 强吸附 |
| **铅（Pb）** | 黏土 | 100-1000 | 极强吸附 |
| **砷（As）** | 砂土 | 0.1-10 | 吸附可变 |

> **注：** K_d受pH、有机质含量、阳离子交换量等影响，需通过批平衡试验测定。

---

### 3.3 应急场景中的地下水评估

#### 3.3.1 地下水污染羽迁移速度估算

**污染物迁移速度：**

```
v_contaminant = v / R
```

其中：
- v_contaminant = 污染物平均迁移速度（m/d）
- v = 地下水平均孔隙流速（m/d）
- R = 阻滞系数（无量纲）

**示例：**
- 地下水流速v = 0.5 m/d
- 阻滞系数R = 5（中等吸附）
- 污染物迁移速度 = 0.5 / 5 = 0.1 m/d

---

#### 3.3.2 污染到达敏感受体（井/河流）的时间

**到达时间估算：**

```
T = L / v_contaminant
```

其中：
- T = 到达时间（d）
- L = 距离（m）
- v_contaminant = 污染物迁移速度（m/d）

**示例：**
- 距离L = 100 m
- 迁移速度 = 0.1 m/d
- 到达时间 = 100 / 0.1 = 1000 d ≈ 2.7年

---

#### 3.3.3 抽出井的捕获区（Capture Zone）计算

**捕获区宽度（二维稳定流）：**

```
W = 2 × √(Q_w × T / (π × K × i))
```

其中：
- W = 捕获区宽度（m）
- Q_w = 抽水井流量（m³/d）
- T = 含水层导水系数（m²/d），T = K×b
- K = 渗透系数（m/d）
- b = 含水层厚度（m）
- i = 天然水力梯度（无量纲）

**捕获区长度的近似：**

```
L_upstream ≈ W
L_downstream → ∞
```

---

#### 3.3.4 自然衰减评估

**自然衰减机制：**
1. 生物降解
2. 吸附
3. 稀释
4. 挥发（对于挥发性有机物）
5. 化学氧化/还原

**评估方法：**
- 监测浓度随时间下降趋势
- 计算衰减系数λ
- 分析降解产物（如TBA来自MTBE降解）

**自然衰减的适用条件：**
- 污染物可生物降解
- 存在电子受体（O₂、NO₃⁻、SO₄²⁻、Fe³⁺、CO₂）
- 温度、pH适宜
- 无毒性抑制

## 专题4：数学模型在应急决策中的实战应用

### 4.1 快速估算工具

#### 4.1.1 不用计算机的快速估算方法

**1. 高斯烟羽模型的快速估算：**

**地面轴线浓度近似公式：**

```
C_max ≈ (0.117 × Q) / (u × H²)
```

其中：
- C_max = 地面最大浓度（μg/m³）
- Q = 源强（μg/s）
- u = 风速（m/s）
- H = 有效源高（m）

**适用条件：**
- 中性稳定度（D类）
- 平原地形
- 距离在2-10倍H之间

**2. 河流污染的快速估算：**

**完全混合浓度：**

```
C_mix = (C_river × Q_river + C_effluent × Q_effluent) / (Q_river + Q_effluent)
```

**下游浓度衰减：**

```
C(x) ≈ C_mix × exp(-k × x / u)
```

**3. 地下水污染的快速估算：**

**污染物前锋到达时间：**

```
t = (n_eff × L) / (K × i) × R
```

#### 4.1.2 查表法和诺模图的使用

**常用查表：**

1. **Pasquill稳定度查算表**
   - 输入：风速、云量、太阳高度角
   - 输出：稳定度等级（A-F）

2. **扩散参数σ_y、σ_z查算图**
   - 输入：稳定度、距离
   - 输出：σ_y、σ_z值

3. **曼宁糙率n值查算表**
   - 输入：河道类型、植被、弯曲度
   - 输出：n值

4. **渗透系数K值查算表**
   - 输入：岩土类型、颗粒级配
   - 输出：K值范围

**诺模图（Nomograph）：**

1. **高斯烟羽浓度诺模图**
   - 用于快速查算下风向浓度

2. **Streeter-Phelps氧垂曲线诺模图**
   - 用于快速估算BOD-DO关系

3. **地下水捕获区诺模图**
   - 用于快速估算抽水井影响范围

#### 4.1.3 各种经验规则的汇总（"拇指法则"）

**大气扩散：**

1. **地面最大浓度距离：**
   ```
   x_max ≈ 10-20 × H
   ```
   H为有效源高（m）

2. **风速随高度变化（幂律）：**
   ```
   u(z) = u(z_ref) × (z/z_ref)^p
   ```
   - 稳定大气：p ≈ 0.1-0.2
   - 中性大气：p ≈ 0.15-0.3
   - 不稳定大气：p ≈ 0.2-0.4

**河流水质：**

1. **完全混合距离经验值：**
   - 岸边排放：10-20倍河宽
   - 中心排放：50-100倍河宽

2. **河流流速经验值：**
   - 山区河流：1-3 m/s
   - 平原河流：0.3-1 m/s
   - 感潮河段：0.1-0.5 m/s

**地下水：**

1. **地下水流速经验值：**
   - 黏土：<0.001 m/d
   - 粉土：0.001-0.01 m/d
   - 砂土：0.01-1 m/d
   - 砾石：1-10 m/d

2. **污染羽迁移经验值：**
   - 有机污染物（如苯）：每年数十至数百米
   - 重金属：每年数米至数十米

### 4.2 模型局限性认知

#### 4.2.1 当模型结果与实测不一致时如何判断

**判断步骤：**

1. **检查输入参数：**
   - 源强是否准确？
   - 气象/水文条件是否代表？
   - 地形数据是否精细足够？

2. **检查模型假设：**
   - 稳定度分类是否合适？
   - 是否忽略重要物理过程（如化学反应、地形影响）？
   - 边界条件是否合理？

3. **检查实测数据：**
   - 监测点位是否有代表性？
   - 采样时间是否同步？
   - 分析方法是否有误差？

4. **综合分析：**
   - 如果模型低估 → 可能忽略某些源或过程
   - 如果模型高估 → 可能衰减或沉降被低估
   - 如果模式不符 → 可能模型结构不适用

**决策原则：**
- 模型是工具，不是真理
- 实测数据优于模型预测
- 多模型对比可提高可靠性

---

#### 4.2.2 模型输入参数不确定性的传递

**不确定性来源：**

1. **源强Q：** ±50%~±200%
2. **风速u：** ±20%~±50%
3. **稳定度：** 分类误差→σ参数误差
4. **衰减系数k：** ±50%~±100%
5. **渗透系数K：** ±1个数量级

**不确定性传递方法：**

1. **蒙特卡洛模拟：**
   - 对输入参数赋予概率分布
   - 多次运行模型
   - 统计输出结果的范围

2. **敏感性分析：**
   - 逐一改变输入参数
   - 观察输出变化幅度
   - 识别关键参数

3. **误差传递公式（一阶近似）：**

```
σ_C² ≈ (∂C/∂Q)² × σ_Q² + (∂C/∂u)² × σ_u² + ...
```

---

#### 4.2.3 保守假设与准确假设的选择原则

**应急决策中的原则：**

**优先保护公众健康 → 使用保守假设**

**保守假设的示例：**

1. **大气扩散：**
   - 选择稳定度F（最小扩散）
   - 使用最低风速（如1m/s）
   - 忽略降水清除

2. **河流水质：**
   - 使用最小衰减系数
   - 忽略吸附和挥发
   - 使用最小流速

3. **地下水：**
   - 使用最大渗透系数
   - 忽略吸附（R=1）
   - 使用最大水力梯度

**准确假设的场景：**

1. **长期风险评估**
2. **工程设计**
3. **科研分析**

**平衡原则：**
- 应急初期：保守假设，确保不出错
- 应急后期：准确假设，优化资源分配

---

#### 4.2.4 应急条件下如何用有限的监测数据校准模型

**校准策略：**

1. **优先校准关键参数：**
   - 大气：风速、稳定度
   - 河流：流速、衰减系数
   - 地下水：渗透系数、方向

2. **使用实时监测数据：**
   - 在关键位置布点
   - 高频监测（如每小时）
   - 反馈调整模型参数

3. **贝叶斯更新方法：**
   - 先验知识（模型预测）
   - 新观测数据
   - 后验预测（更新结果）

**实用技巧：**

1. **以实测浓度为基准，反推有效源强**
2. **使用多点浓度比，反推扩散参数**
3. **结合气象/水文实时数据，动态调整模型**

### 4.3 实操案例

#### 4.3.1 以涟水为例，模拟苯系物泄漏后的污染团运移过程

**案例背景：**

- 地点：江苏省涟水县某化工企业
- 事故：储罐泄漏，约1吨苯（C₆H₆）流入涟水
- 河流参数：
  - 流量Q = 50 m³/s
  - 流速u = 0.5 m/s
  - 河宽B = 50 m
  - 水深h = 2 m
  - 衰减系数k = 0.2 d⁻¹（苯的挥发+生物降解）

**模拟目标：**
- 预测污染团到达下游取水口（距离10km）的时间
- 估算峰值浓度
- 提出应急措施建议

---

#### 4.3.2 计算到达下游取水口的时间、峰值浓度

**步骤1：计算运移时间**

```
t = L / (u × α)
```

假设α = 1.2（峰值速度系数）：

```
t = 10000 m / (0.5 m/s × 1.2) = 16667 s ≈ 4.6 h
```

**结论：** 污染团约4.6小时后到达取水口。

---

**步骤2：计算峰值浓度**

**完全混合浓度（假设瞬时完全混合）：**

泄漏量M = 1000 kg = 10⁹ mg

河水流量Q = 50 m³/s = 5×10⁷ mL/s

假设污染团长度L_plume = 1000 m：

污染团体积V = B × h × L_plume = 50 × 2 × 1000 = 10⁵ m³ = 10¹¹ mL

峰值浓度C_peak：

```
C_peak ≈ M / V = 10⁹ mg / 10¹¹ mL = 0.01 mg/L = 10 μg/L
```

**考虑衰减：**

到达取水口时，已衰减4.6小时 ≈ 0.19 d

```
C(t) = C_peak × exp(-k × t) = 10 × exp(-0.2 × 0.19) ≈ 10 × 0.962 ≈ 9.6 μg/L
```

**结论：** 峰值浓度约9.6 μg/L，低于饮用水标准（10 μg/L，GB 5749-2006）。

---

**步骤3：应急措施建议**

1. **立即通知取水口管理单位，做好应急准备**
2. **在污染团到达前1小时，停止取水**
3. **污染团通过后，监测水质，确认达标后恢复取水**
4. **在泄漏点下游设置活性炭吸附坝，降低峰值浓度**
5. **持续监测至少24小时，确保无二次峰值**
