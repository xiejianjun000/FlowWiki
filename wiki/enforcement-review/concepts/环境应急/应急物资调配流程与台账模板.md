# 应急物资调配流程与台账模板

> 适用于环境应急事件中的物资调度管理。全流程涵盖调拨命令、装车、运输、交接、回执闭环管理。

---

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│ 调拨命令 │ → │ 装车出库 │ → │ 运输配送 │ → │ 现场交接 │ → │ 回执归档 │
│ (1)     │   │ (2)     │   │ (3)     │   │ (4)     │   │ (5)     │
└─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘
     ↓             ↓             ↓             ↓             ↓
  指挥中心     仓库管理      运输调度     现场协调员    后勤保障组
  签发调令    清点装车       GPS跟踪     签收确认     存档备查
```

## 二、各环节详细流程

### 2.1 环节一：调拨命令

**触发条件：** 应急指挥部发布物资调拨指令

**操作流程：**

```
1. 指挥中心填写《应急物资调拨单》（见台账模板）
2. 指挥长签发 → 传真/系统发送至储备库
3. 储备库确认收到，回复预计出库时间
4. 如需跨区域调拨，同步上报上级应急管理部门
```

**时间要求：** 从接收到调令到装车准备完成 ≤ 15分钟（平时储备库常态备勤）

### 2.2 环节二：装车出库

**操作流程：**

```
1. 仓库管理员持《调拨单》核对物资品名、规格、数量
2. 扫描/手工登记每件物资的批次号和有效期
3. 按"重不压轻、大不压小、先急后缓"原则装车
4. 装车完成 → 双方（仓库管理员+运输押运员）签字确认
5. 生成《出库单》（一式三联：库留/随车/交指挥中心）
6. 拍照存档：装车前、装车后、车牌照
```

**注意事项：**
- 易碎品单独包装，标注"轻拿轻放"
- 化学品与食品严格隔离装载
- 危险品车辆需有警示标识

### 2.3 环节三：运输配送

**操作流程：**

```
1. 出发前简报：行驶路线、预计到达时间、注意事项
2. 启用GPS跟踪（实时发回车辆位置）
3. 每30分钟向指挥中心报告一次位置和路况
4. 如遇交通堵塞，报告指挥中心协调交警放行
5. 如车辆故障，就近换车或请求就近库点补发
6. 到达前15分钟通知现场接货人准备
```

**时间估算：**

| 运输类型 | 参考速度 | 30km内 | 100km | 300km |
|---------|---------|--------|-------|-------|
| 普通货车 | 40~60 km/h | 30~45min | 1.5~2.5h | 5~7h |
| 危险品专车 | 30~50 km/h | 36~60min | 2~3h | 6~10h |
| 应急绿色通道 | 50~70 km/h | 25~35min | 1~1.5h | 4~5h |

### 2.4 环节四：现场交接

**操作流程：**

```
1. 车辆到达 → 现场协调员核验封条/铅封完好
2. 逐件清点：品名 + 规格 + 数量 + 外观完好
3. 如发现破损、短缺、过期等问题：
   a) 现场拍照取证
   b) 在《交接单》上注明差异
   c) 紧急联系储备库补救
4. 双方（运输押运员 + 现场接收人）签字确认
5. 物资暂存现场临时库或直接分发至作业组
```

**交接确认要素：**

| 要素 | 说明 |
|------|------|
| 数量核验 | 清点后与《调拨单》逐项比对 |
| 质量核验 | 检查包装完好、无受潮/变形/过期 |
| 规格核验 | 确认型号、规格与需求一致 |
| 时效核验 | 物资时限是否符合应急需求 |

### 2.5 环节五：回执归档

**操作流程：**

```
1. 现场协调员填写《物资回执单》（见台账模板）
2. 回执单拍照上传至应急指挥系统
3. 纸质回执随物资返回车辆带回或快递至指挥中心
4. 指挥中心归档（电子+纸质双备份）
5. 更新库存台账（出库扣减）
6. 如需紧急补货，立即启动新一轮调拨
```

## 四、入库/出库/盘点/报废标准操作

### 4.1 入库流程

| 步骤 | 操作 | 责任人 |
|------|------|-------|
| 1 | 到货验收：核验采购单与实物一致 | 采购员 |
| 2 | 质量检验：抽检（≥10%）外观/功能/有效期 | 质检验收员 |
| 3 | 实物入库：分类上架，贴二维码/标签 | 仓库管理员 |
| 4 | 系统入库：录入品名/规格/数量/批次/有效期 | 仓库管理员 |
| 5 | 归档：采购单+验收单+入库单 装订存档 | 档案管理员 |

### 4.2 出库流程

| 步骤 | 操作 | 责任人 |
|------|------|-------|
| 1 | 接收调令：确认调拨单有效性 | 仓库管理员 |
| 2 | 按单拣货：FIFO原则取货 | 仓库管理员 |
| 3 | 清点核验：双人复核出库数量 | 仓库管理员+复核员 |
| 4 | 扫描出库：系统扣减库存 | 仓库管理员 |
| 5 | 装车发运：拍照+封条+押运 | 运输组 |

### 4.3 盘点流程

| 频次 | 盘点类型 | 方法 | 时间要求 |
|------|---------|------|---------|
| 月 | 月度盘点 | 抽盘高值/高频物资（A类） | 月末3天内 |
| 季 | 季度盘点 | 全品类盘点（A+B类） | 季末7天内 |
| 年 | 年度大盘点 | 全面盘点（所有品类） | 12月1-15日 |
| 应急 | 应急后盘点 | 事件结束后全面盘库 | 事件结束后24h内 |

**盘点公式：**
```
盘点差异率 = |盘点数量 - 账面数量| / 账面数量 × 100%
允许差异率：A类物资 ≤ 0.5%，B类物资 ≤ 1%，C类物资 ≤ 2%
超出范围 → 启动差异调查程序
```

### 4.4 报废流程

**报废条件：**
1. 超过有效期的物资
2. 运输/存储中损坏且无法修复
3. 标准更新后原物资不再适用
4. 应急使用后剩余的一次性物资（已拆封）

**处置方式：**

| 物资类型 | 处置方式 | 法规依据 |
|---------|---------|---------|
| 过期化学品 | 委托危废资质单位处置 | 《危废名录》 |
| 过期滤毒罐 | 按危废处置 | 《危废名录》HW49 |
| 损坏防护服 | 普通固废 | — |
| 使用后吸油毡 | 按危废处置（含油） | 《危废名录》HW08 |
| 过期药品 | 销毁或退回供应商 | 《药品管理法》 |

## 五、破损/过期物资处置流程

```
破损/过期物资发现
        ↓
  ┌─ 临时隔离存放（挂红色"待处置"标识牌）
  │
  ├─ 填写《物资报废申请单》
  │     ↓
  │  仓库管理员+质检员联合审核
  │     ↓
  ├─ 审核通过 → 仓库主管批准
  │     ↓
  ├─ 区分处置路径：
  │     ├─ 可退回供应商 → 联系供应商退货
  │     ├─ 可翻新修复 → 送修后重新检验入库
  │     ├─ 普通固废 → 按垃圾分类标准处置
  │     └─ 危险废物 → 联系资质单位转运（附联单）
  │     ↓
  └─ 系统更新：扣减库存 + 归档处置记录
        ↓
  季度汇总报应急管理局备案
```

> **关键控制点：** 过期物资严禁私自处置，破损化学品必须按危废管理，所有处置均需形成《危废转移联单》存档备查。
