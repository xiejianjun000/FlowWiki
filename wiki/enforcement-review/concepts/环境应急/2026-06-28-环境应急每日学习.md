## 一、法规政策要点

### （一）湖南省重大新政：《湖南省应急物资管理暂行办法》

- **文件编号：** 湘政办发〔2025〕41号
- **发布日期：** 2025年10月23日（省政府办公厅印发），2025年10月30日公开
- **有效期：** 2年（自发布之日起施行）
- **发文单位：** 湖南省人民政府办公厅
- **适用层级：** 省、市、县、乡镇各级

**核心制度设计：**

#### 1. 储备格局（第五条）
> **政府实物储备为主 + 企业协议/产能储备辅助 + 社会储备补充**
> 政府实物储备规模原则上不低于所需物资的50%

- 省、市、县三级按规定共储共用
- 乡镇（街道）、重点村（社区）按需配备

#### 2. 经费保障（第六条）
- 各级财政部门将物资采购、储备、维护、调运等经费纳入财政预算
- 保管运维费用按实际成本安排

#### 3. 需求与采购（第七至十条）
- 每年科学编制下一年度购置需求计划
- 紧急情况下可按紧急采购规定组织采购
- 鼓励采购高精尖、首台（套）重大技术装备
- 采购文件需及时归档

#### 4. 储备管理（第十一至十七条）
- 高风险地区应达到二级应急响应储备标准
- 统筹现有仓库资源，优先利用粮食和物资储备部门可用库容
- 承储单位须：专人负责、专账记载、挂牌明示
- 坚持"用旧储新、先进先出"原则
- 定期维护保养，随时处于备战状态
- 报废需按国有资产管理规定执行

#### 5. 调用机制（第十八至二十三条）
- **原则：** 先用本级储备，不足时向上一级申请
- **紧急调用：** 欠手续的须15个工作日内补齐
- **调拨指令：** 由应急和安全生产委员会办公室或上级行业主管部门下达
- **绿色通道：** 高速公路经营管理单位对经批准的应急车辆减免通行费
- **费用承担："谁调用、谁承担"**
  - 调运费用（运输、搬运装卸、过路费、押运人员补助等）由申请调用单位承担
  - 回收清洗、打包、维保、检测等费用由申请调用单位或接收使用单位承担
- **紧急征用：** 应急处置期间可依法紧急征用，事后及时返还或补偿

#### 6. 信息化管理（第二十四至二十六条）
- 省应急委员会办公室建设湖南省应急物资管理平台
- 承储单位须及时将出入库、检查盘点等信息录入平台
- 平台账户设专人管理，承储单位为数据维护第一责任人

#### 7. 法律责任（第二十七、二十八条）
- 骗取、截留、挤占、挪用财政资金 → 依法查处
- 私自转让、租借、挪用或故意损毁物资 → 追责
- 玩忽职守、滥用职权、徇私舞弊 → 依法依规处分，涉嫌犯罪移送司法

### （二）国家层面：GB 30077-2023 全面升级

- **标准名称：** 《危险化学品单位应急救援物资配备要求》
- **原标准：** GB 30077-2013
- **新标准：** GB 30077-2023（强制性国家标准）
- **实施日期：** 2024年9月1日

**主要技术变化：**

| 变化项 | 内容 |
|--------|------|
| 作业场所配备 | 修改和补充了部分物资种类和性能要求 |
| 应急救援队伍配备 | 增加了物资种类，更新了配备标准 |
| 附录体系 | 新增附录A（单位类别划分）、附录B（第一类配备要求）、附录C（第二类配备要求） |
| 适用范围 | 适用于危险化学品生产和贮存单位；使用、经营、运输和处置废弃单位参照执行 |

**作业场所必备物资清单（表1）：**
- 正压式空气呼吸器（≥2套）
- 化学防护服（≥2套，有腐蚀性液体场所）
- 过滤式防毒面具（1个/人，按当班人数）
- 气体浓度检测仪（≥2台）
- 防爆手电筒（1个/人）
- 防爆对讲机（≥2台）
- 急救箱/急救包（≥1包）
- 吸附材料、洗消设施（根据介质性质）

**应急救援队伍个体防护装备（表2）：**
- 消防头盔（1顶/人，备份比4:1）
- 二级化学防护服装（1套/人）
- 一级化学防护服装（1套/10人，至少2套）
- 灭火防护服（1套/人，备份比3:1）
- 防化手套（2副/人）、防化靴（1双/人）

**沿江河湖海单位额外要求（8.2条）：**
- 配齐水上灭火抢险救援、水上泄漏物处置和防汛排涝物资

### （四）储备定额计算方法（通用标准）

**计算公式：** `Q = N × f × d × k`

| 符号 | 含义 | 典型取值 |
|------|------|---------|
| Q | 储备定额 | — |
| N | 基准用户数（应急人数/保护区域人口） | — |
| f | 人均消耗系数 | 见下表 |
| d | 应急持续天数 | 通常3~7天 |
| k | 安全系数 | 通常1.2~1.5 |

**常见物资消耗系数（f值）：**

| 物资 | f值 | 说明 |
|------|:---:|------|
| 防毒面具滤毒罐 | 1.0个/人/天 | 高毒环境4h更换 |
| 化学防护服 | 0.5套/人/天 | 一次性使用 |
| 吸油毡 | 5~20 kg/m² | 视油膜厚度 |
| 消油剂 | 1:20~1:30 | 与油品重量比 |

## 三、娄底市环境应急物资储备现状

### （一）娄底市环境应急物资储备库

- **揭牌日期：** 2022年12月13日
- **建设模式：** 政企合作（娄底市生态环境局 + 湖南湘中博一检测技术有限公司）
- **位置：** 湖南湘中博一检测技术有限公司仓库
- **选址原则：** 结合区域环境风险特征，"最快时间、最短距离"运抵
- **储备规模：** 首批20类应急物资
  - 活性炭
  - 防毒面具
  - 强酸碱洗消器
  - 其他17类物资

### （二）储备库管理要求（采购需求）

| 管理类别 | 具体要求 |
|---------|---------|
| 物资管理 | 每月清点，专项管理，凭证手续齐全 |
| 台账制度 | 使用记录清单、每月清点记录单 |
| 巡查制度 | 日常巡视+安全检查 |
| 报告制度 | 发现损坏、缺失、失效及时上报 |
| 季度汇报 | 每季度向生态环境局汇报台账 |
| 年度检查 | 每年检查，提出报废更新清单 |
| 专库专人 | 建立专库专人负责制度 |

### （三）改进建议

娄底市储备库目前物资品种偏少（仅20类），相比环境应急物资九大类体系：
- **已覆盖：** 个体防护（防毒面具）、围堵控制（活性炭）、洗消（强酸碱洗消器）
- **需补充：** 环境监测设备、围油栏/吸油毡（水污染事件）、收集储运装备、应急通讯、医疗急救物资

建议参照GB 30077-2023和《湖南省应急物资管理暂行办法》，逐步扩增储备品类。

## 四、新增知识点

### 1. 《湖南省应急物资管理暂行办法》是省级应急物资管理的顶层制度

- **创新点①：** 明确"政府实物储备≥50%"的底限要求
- **创新点②：** 建立"应急和安全生产委员会办公室牵头、多部门联动"的协调机制
- **创新点③：** "谁调用、谁承担"费用原则，权责清晰
- **创新点④：** 全省统一的信息化管理平台
- **有效期仅2年（2025.10~2027.10），说明是暂行办法，到期可能更新

### 2. GB 30077-2023与GB 30077-2013的主要区别

| 维度 | 2013版 | 2023版 |
|------|--------|--------|
| 核心技术 | 作业场所+队伍配备 | 新增附录A/B/C，细化分类 |
| 物资品种 | 基础配备 | 增加新型应急设备 |
| 单位分类 | 简单划分 | 按附录A规范划分一、二类 |
| 沿江单位 | 一般要求 | 专门条款（8.2条）强化 |

### 3. 省市县应急物资储备库全覆盖（十四五成果）

- 2025年9月应急管理部宣布覆盖完成
- 中央储备较十三五末增长39.6%
- 建立联动调拨机制和快速通行渠道

### 4. 基层应急物资储备管理要点（2026年5月新指南）

> 源自近期发布的基层应急物资储备清单与管理指南

**管理四要点：**
- 存放环境：干燥、通风、避光
- 定期检查：查保质期、压力状态、药品完整性
- 物资轮换：临期物资优先使用
- 台账管理：种类、数量、入库时间、保质期，账物相符

## 五、实用操作建议

### 1. 应急物资储备清单自查表（面向娄底市应急工作）

建议定期对照以下清单核查储备状况：

```
□ 个体防护：防毒面具（全面罩+半面罩）、化学防护服（A/B级）、防化手套、护目镜
□ 气体监测：有毒气体检测仪、PID检测仪、可燃气体检测仪
□ 水质监测：便携式水质多参数仪（pH/DO/电导率）
□ 围堵控制：围油栏、吸油毡、活性炭、中和剂（碱/酸）、吸附沙
□ 收集储运：集污袋（吨袋）、危废收集桶（200L）、防爆潜水泵
□ 应急通讯：卫星电话、防爆对讲机
□ 医疗急救：解毒剂（有机磷/氰化物等）、急救包、洗眼液
□ 后勤保障：移动发电机（防爆）、应急照明灯
□ 辐射应急（如有辖区放射源）：辐射防护服、个人剂量计
```

### 2. 物资管理台账"四个一致"检查法

```
名称一致：实物名称 ↔ 标签名称 ↔ 台账名称 ↔ 系统名称
规格一致：实物规格 ↔ 标签规格 ↔ 台账规格 ↔ 采购规格
数量一致：实物数量 ↔ 标签数量 ↔ 台账数量 ↔ 系统数量
状态一致：有效期内 ↔ 外观完好 ↔ 功能正常 ↔ 标签清晰
```

### 3. "黄金1小时"物资调度清单（适用于中等规模应急）

| 批次 | 时间窗 | 重点物资 |
|------|:-----:|---------|
| 第1批 | 0~30min | 防护用品+检测设备+急救物资 |
| 第2批 | 30~60min | 围堵材料+吸附材料+中和剂 |
| 第3批 | 1~3h | 大型设备+后勤补给 |

### 4. 应急物资储备库建设选址建议

参照《救灾物资储备库建设标准》和各省规范，选址应满足：
- 交通便利，靠近主干道/高速入口
- 地势高燥，不受洪水威胁
- 远离危险品生产/储存区域
- 供电、供水、通信有保障
- 面积达标：县级储备库建议≥1000m²

## 八、学习心得

今天系统学习了环境应急物资储备与管理规范，核心收获：

1. **制度先行：** 湖南省在2025年10月出台了《应急物资管理暂行办法》（湘政办发〔2025〕41号），这是省级应急物资管理的纲领性文件，明确政府实物储备≥50%、信息化平台、费用承担等关键制度。

2. **标准升级：** GB 30077-2023《危险化学品单位应急救援物资配备要求》作为强制性国家标准已于2024年9月全面实施，意味着所有危化品单位的物资配备必须按新标准执行，不容忽视。

3. **本地实况：** 娄底市环境应急物资储备库（湖南湘中博一检测）已有20类基础物资，但对照九大类体系仍有较大扩充空间，特别是在环境监测设备和围堵控制材料方面。

4. **管理体系化：** 物资储备不是简单的"买一堆东西放仓库"，而是从需求计划→采购→入库→保管→轮换→调拨→使用→回收→报废的全链条闭环管理。
