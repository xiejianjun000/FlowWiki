# 常见放射源识别卡

> 适用对象：应急处置人员、现场监测人员、值守人员
> 
> 重点提示：娄底地区虽无核电站，但存在工业探伤、医疗放射源、测井作业等应用场景，
> 
> 处置人员必须掌握常见放射源的外观特征与识别要点

---

## 放射源分类总览

### 按危险等级分类（IAEA分类体系）

```
Ⅰ类（极高危险）
  ├── 可造成永久性损伤
  ├── 典型：Co-60辐照源（>100 TBq）
  └── 未屏蔽状态下接触数分钟可致死

Ⅱ类（高危险）
  ├── 可造成永久性损伤
  ├── 典型：Ir-192工业探伤源
  └── 短时接触可造成严重损伤

Ⅲ类（中等危险）
  ├── 可能造成永久性损伤
  ├── 典型：Co-60治疗源
  └── 长时间接触可能造成损伤

Ⅳ类（低危险）
  ├── 通常不造成永久性损伤
  ├── 典型：Ir-192低活度源
  └── 长时间接触需医学观察

Ⅴ类（极低危险）
  ├── 不可能造成永久性损伤
  ├── 典型：Am-241烟雾探测器
  └── 日常接触无健康影响
```

### 按射线类型分类

| 射线类型 | 主要来源核素 | 屏蔽要求 | 外照射风险 |
|---------|------------|---------|-----------|
| α射线 | Am-241、Ra-226 | 皮肤防护即可 | 极低 |
| β射线 | Sr-90、Pm-147 | 有机玻璃 | 中等 |
| γ射线 | Co-60、Cs-137、Ir-192 | 铅或混凝土 | 高 |
| α+γ | Am-241（次要γ） | 复合防护 | 中等 |

## 识别卡一：钴-60（Co-60）

### 基本信息

| 项目 | 内容 |
|-----|------|
| 核素符号 | ⁶⁰Co |
| 原子序数 | 27 |
| 半衰期 | 5.27年 |
| 衰变类型 | β⁻衰变 → ⁶⁰Ni（激发态）→ γ发射 |
| 主要γ能量 | 1.17 MeV（88%）、1.33 MeV（100%） |
| 比活度 | 44 TBq/g（非常高） |
| 生产方式 | ⁵⁹Co在反应堆中子活化 |

### 外观特征

**典型外形**：
- 形状：圆柱状（pellet颗粒源）、板状（板源）、球状（胶囊源）
- 尺寸：颗粒源直径1-5mm，板源可达数十厘米
- 颜色：金属银灰色，抛光表面
- 外壳：通常为不锈钢或哈斯特合金密封源壳

**特殊标识**：
- 源体上刻印编号（如"Co-60-001"）
- 源壳标有活度、日期、核素信息
- 高活度源有专用储源罐（铅罐或贫化铀罐）

**储存容器**：
- 运输罐：铅屏蔽，壁厚≥5cm，配备锁具
- 储存井：井式储存，水或铅屏蔽
- 辐照装置：混凝土屏蔽室，自动化控制

### 典型活度范围

| 应用类型 | 活度范围 | 危险等级 |
|---------|---------|---------|
| 实验室用 | 100 MBq - 10 GBq | Ⅲ-Ⅳ类 |
| 医疗远距离治疗 | 100 GBq - 1 TBq | Ⅰ-Ⅱ类 |
| 工业辐照装置 | 1 - 100 PBq | Ⅰ类 |
| 钻-60测井（历史） | 1 - 10 GBq | Ⅲ类 |

### 危害特性

**γ射线能量特点**：
- 能量较高，穿透力强
- 在人体组织中衰减较慢
- 对全身均有影响

**典型剂量率估算**：
```
未屏蔽Co-60源
活度1 TBq → 约1米处 ~10 mSv/h
活度1 PBq → 约1米处 ~10 Sv/h（致死剂量率）
```

**生物效应**：
- 短时高剂量暴露：急性放射病
- 长期低剂量暴露：癌症风险增加
- 局部高剂量：组织损伤、功能障碍

### 识别要领

**现场识别要点**：

```
一看：金属银灰色小型密封源体
二查：刻印的Co-60标识、活度标牌
三测：γ谱仪显示1.17 MeV和1.33 MeV双峰
四估：剂量率异常升高
```

**γ能谱特征峰**：
- 峰位：1.17 MeV、1.33 MeV（特征双峰）
- 峰形清晰，无明显干扰峰
- 可用于快速确认Co-60

**与其他核素区分**：
| 核素 | 特征峰 | 与Co-60区分 |
|-----|-------|------------|
| Cs-137 | 0.662 MeV | 峰位不同 |
| Ir-192 | 多峰（0.3-0.6 MeV） | 能量差异明显 |
| Na-24 | 1.37 MeV、2.75 MeV | 半衰期短（15小时） |

### 应急处置要点

1. **不接近**：未确认前保持距离≥15米
2. **先监测**：使用剂量率仪确定剂量水平
3. **戴防护**：穿戴铅防护围裙、手套
4. **快封控**：使用长柄工具远距离操作
5. **速报告**：立即上报，启动应急预案

## 识别卡二：铯-137（Cs-137）

### 基本信息

| 项目 | 内容 |
|-----|------|
| 核素符号 | ¹³⁷Cs |
| 原子序数 | 55 |
| 半衰期 | 30.07年 |
| 衰变类型 | β⁻衰变 → ¹³⁷mBa → γ发射 |
| 主要γ能量 | 0.662 MeV |
| 比活度 | 3.2 TBq/g |
| 化学形态 | 氯化铯（CsCl） |

### 外观特征

**典型外形**：
- 形状：圆柱形颗粒源、陶瓷源芯
- 尺寸：颗粒源直径2-10mm
- 颜色：灰白色粉末（氯化铯）或陶瓷状
- 外壳：不锈钢双层密封源壳

**储存容器**：
- 铅罐：壁厚2-5cm，配锁具
- 运输罐：符合IAEA规定
- 储存井：铅或贫化铀屏蔽

**特殊注意**：
- CsCl易溶于水
- 一旦源壳破损，污染物易扩散
- 需特别防止水源污染

### 典型活度范围

| 应用类型 | 活度范围 | 危险等级 |
|---------|---------|---------|
| 实验室校准 | 1 MBq - 1 GBq | Ⅳ-Ⅴ类 |
| 工业测厚 | 100 MBq - 10 GBq | Ⅲ-Ⅳ类 |
| 医疗后装治疗 | 10 - 100 GBq | Ⅱ-Ⅲ类 |
| 辐照装置 | 1 - 100 TBq | Ⅰ-Ⅱ类 |

### 危害特性

**γ射线特点**：
- 能量中等（0.662 MeV）
- 穿透力较好
- 屏蔽相对容易（1cm铅可减弱99%）

**典型剂量率**：
```
未屏蔽Cs-137源
活度1 GBq → 约1米处 ~0.08 mSv/h
活度1 TBq → 约1米处 ~80 mSv/h
```

**特殊风险-化学毒性**：
- CsCl可溶，误食风险大
- 环境污染后处理困难
- 需防止扬尘和液体扩散

### 识别要领

**现场识别要点**：

```
一看：小型密封源体，标牌注明Cs-137
二查：剂量率异常（相对自然本底）
三测：γ谱仪显示0.662 MeV单峰（特征峰）
四防：检查是否有水源污染风险
```

**γ能谱特征**：
- 主峰：0.662 MeV
- 峰位清晰，无其他高能峰
- 可用NaI谱仪快速识别

**应急处置特别注意**：
- 防止水源污染
- 避免扬尘扩散
- 撤离污染区域人员
- 检测食品和饮水

## 识别卡三：铱-192（Ir-192）

### 基本信息

| 项目 | 内容 |
|-----|------|
| 核素符号 | ¹⁹²Ir |
| 原子序数 | 77 |
| 半衰期 | 73.83天 |
| 衰变类型 | β⁻衰变，多种γ发射 |
| 主要γ能量 | 0.31-0.61 MeV（多峰）|
| 比活度 | 约340 TBq/g（高）|
| 化学形态 | 金属铱丝、铱片 |

### 外观特征

**典型外形**：
- 形状：细丝状、丝绕源、颗粒状
- 尺寸：丝源直径0.1-0.5mm，长度可达数米
- 颜色：金属银白色
- 外壳：不锈钢双封密封源壳

**储存容器**：
- 源罐：铅或钨合金屏蔽
- 运输容器：贫化铀屏蔽（壁厚≥2cm）
- 分装容器：便携式铅罐

**特殊标识**：
- 源体刻印"Ir-192"及活度
- 颜色代码：无（黑灰色金属）
- 形状多样，需结合活度标识判断

### 典型活度范围

| 应用类型 | 活度范围 | 危险等级 |
|---------|---------|---------|
| 工业γ探伤 | 1 - 5 TBq | Ⅰ-Ⅱ类 |
| 医疗后装治疗 | 100 GBq - 1 TBq | Ⅱ类 |
| 实验室 | 1 MBq - 10 GBq | Ⅲ-Ⅳ类 |

### 危害特性

**γ射线特点**：
- 能量范围广（0.3-0.6 MeV）
- 平均能量约0.38 MeV
- 屏蔽相对容易

**半衰期短的特点**：
- 活度衰减快（需定期更换）
- 意外暴露时，随时间推移危害降低
- 但需考虑衰变产物

**典型剂量率**：
```
未屏蔽Ir-192源
活度1 TBq → 约1米处 ~4-6 mSv/h
```

**工业探伤事故特点**：
- 活度高（1-5 TBq）
- 现场操作频繁
- 源丢失事故多发
- 是最常见的放射源事故类型

### 识别要领

**现场识别要点**：

```
一看：细丝状或颗粒状小型金属源
二查：活度标牌（工业探伤通常1-5 TBq）
三测：γ谱仪显示多峰（0.31、0.47、0.60 MeV）
四核：计算暴露时间评估剂量（半衰期73天）
```

**γ能谱特征**：
- 多峰分布（特征）
- 主峰：0.47 MeV、0.60 MeV
- 与Cs-137（单峰）区分

**与其他γ源区分**：
| 核素 | 峰特征 | 半衰期 | 区分要点 |
|-----|-------|-------|---------|
| Ir-192 | 多峰 | 73天 | 短半衰期 |
| Co-60 | 双峰（高能）| 5.3年 | 高能峰（1.17/1.33 MeV）|
| Cs-137 | 单峰 | 30年 | 0.662 MeV |

**工业探伤现场要点**：
- 确认是否为探伤作业单位
- 检查设备是否正常归源
- 测量源罐内活度是否正常

## 识别卡四：镅-241（Am-241）

### 基本信息

| 项目 | 内容 |
|-----|------|
| 核素符号 | ²⁴¹Am |
| 原子序数 | 95 |
| 半衰期 | 432.2年 |
| 衰变类型 | α衰变（100%）|
| 主要α能量 | 5.49 MeV（85%）、5.44 MeV（13%）|
| 次要γ能量 | 59.5 keV（36%）|
| 比活度 | 0.13 TBq/g（较低）|
| 化学形态 | 氧化镅（AmO₂）|

### 外观特征

**典型外形**：
- 形状：圆片状、颗粒状、粉末状
- 尺寸：烟雾探测器内源片约5-20mm直径
- 颜色：银灰色金属氧化物
- 外壳：小型密封源壳（烟雾探测器内）

**主要应用**：
| 应用 | 典型活度 | 形式 |
|-----|---------|-----|
| 烟雾探测器 | 30-80 kBq（极低）| 源片 |
| 测井作业 | 1-10 GBq | 密封源 |
| 医疗 | 1-100 MBq | 密封源 |

### 危害特性

**α射线特点**：
- 能量高但射程极短
- 一张纸即可阻挡
- **外照射风险极低**
- **内照射风险极高**（误食、吸入）

**γ射线特点**：
- 能量低（59.5 keV）
- 穿透力弱
- 可用NaI谱仪检测

**典型剂量率**：
```
Am-241烟雾探测器（80 kBq）
距5cm处 ~0.01 µSv/h（极低）
```

**内照射风险**：
- 烟雾探测器源片破损后粉末扩散
- 吸入或误食α核素危害极大
- α粒子在组织内射程仅几十微米，能量集中

### 识别要领

**现场识别要点**：

```
一看：小型银色金属片或颗粒（烟雾探测器内）
二查：产品标签"Nr-241 Am"或电离室标识
三测：γ谱仪显示59.5 keV特征峰
四判：活度极低，通常无外照射风险
```

**γ能谱特征**：
- 唯一可测γ峰：59.5 keV
- 峰位低（需低能探测器）
- 特征明显

**与其他核素区分**：
| 核素 | 峰特征 | 危险类型 |
|-----|-------|---------|
| Am-241 | 59.5 keV单峰 | α为主（内照射）|
| Cs-137 | 0.662 MeV | γ（外照射）|
| Co-60 | 双高能峰 | γ（外照射）|

**内照射处置要点**：
- 烟雾探测器破损：通风、收集残片、检测表面污染
- 活度较低，一般无需疏散
- 误服：立即就医，收集呕吐物送检

## 识别卡五：镭-226（Ra-226）

### 基本信息

| 项目 | 内容 |
|-----|------|
| 核素符号 | ²²⁶Ra |
| 原子序数 | 88 |
| 半衰期 | 1600年 |
| 衰变类型 | α衰变系（铀系）|
| 主要α能量 | 4.78 MeV（94%）、4.60 MeV |
| 主要γ能量 | 186 keV、多种（子体产生）|
| 比活度 | 0.36 TBq/g |

### 背景说明

**历史应用**：
- 夜光表盘（早期）
- 医疗（现已淘汰）
- 科学研究（标准源）

**现状**：
- 新产生的Ra-226源极少
- 现有源多为历史遗留
- 多为封存或退役状态
- **但泄露事故仍有发生**

### 外观特征

**典型外形**：
- 形状：圆柱状、针状、粉末状
- 尺寸：小型密封源，数mm至cm级
- 颜色：硫酸镭为白色粉末，溴化镭为晶体
- 外观：早期源可能标记"Ra"字样

**历史遗留源特点**：
- 容器可能老化、腐蚀
- 标识可能模糊
- 需特别警惕

### 危害特性

**射线特点**：
- α射线为主（外照射风险低）
- γ射线来自子体（226Rn、214Bi等）
- 子体放射性复杂

**半衰期长的影响**：
- 活度变化缓慢
- 持续危害时间长
- 处置后仍需长期监测

**内照射风险**：
- 镭与钙同族
- 可沉积于骨骼
- 长期内照射导致骨肿瘤

### 识别要领

**现场识别要点**：

```
一看：老旧密封源，可能有"Ra"标识
二查：生产日期（多为历史遗留）
三测：γ谱仪显示铀系特征（多种γ峰）
四判：优先考虑封存，避免直接接触
```

**γ能谱特征**：
- 铀系复杂γ谱
- 主峰：186 keV、350 keV、609 keV等
- 需与Am-241（单峰）区分

**应急处置要点**：
- 优先保持距离
- 禁止直接接触
- 使用长柄工具操作
- 必要时疏散人员

## 识别卡六：其他常见放射源速查

### 钋-210（Po-210）

| 项目 | 内容 |
|-----|------|
| 半衰期 | 138.4天 |
| 射线类型 | α（99.98%）|
| 典型应用 | 静电消除器、抗静电刷 |
| 活度范围 | kBq-GBq |
| 识别要点 | α源，无γ，测井式探测器检测 |
| 特殊注意 | 剧毒，误服无解药 |

### 锶-90（Sr-90）

| 项目 | 内容 |
|-----|------|
| 半衰期 | 28.8年 |
| 射线类型 | β⁻（子体Y-90）|
| 典型应用 | 核电池、心脏起搏器（历史）|
| 活度范围 | Bq-TBq |
| 识别要点 | β源，低能γ（子体），需塑料屏蔽 |
| 特殊注意 | β源外照射需有机玻璃防护 |

### 钷-147（Pm-147）

| 项目 | 内容 |
|-----|------|
| 半衰期 | 2.6年 |
| 射线类型 | β⁻ |
| 典型应用 | 夜光漆（替代Ra-226）、荧光涂料 |
| 活度范围 | MBq-GBq |
| 识别要点 | 低能β，需薄塑料屏蔽 |
| 特殊注意 | 通常活度较低，风险可控 |

## 放射源现场识别流程

### 标准化识别流程

```
┌─────────────────────────────────────────────┐
│           放射源现场识别流程                  │
├─────────────────────────────────────────────┤
│                                             │
│  步骤1：初步观察                             │
│  ├─ 观察现场环境（工业探伤/医疗/科研）        │
│  ├─ 查找放射源标识标牌                       │
│  └─ 判断放射源可能类型                       │
│                                             │
│  步骤2：剂量监测                             │
│  ├─ 开启剂量率仪（量程选择）                 │
│  ├─ 测量各方向剂量率                         │
│  └─ 评估剂量水平                             │
│                                             │
│  步骤3：能谱分析                             │
│  ├─ 开启γ谱仪（NaI或HPGe）                  │
│  ├─ 获取能谱曲线                            │
│  └─ 识别特征峰位                             │
│                                             │
│  步骤4：核素确认                             │
│  ├─ 对照特征峰表                             │
│  ├─ 排除干扰核素                             │
│  └─ 确定核素种类                             │
│                                             │
│  步骤5：活度估算                             │
│  ├─ 已知距离测量剂量率                       │
│  ├─ 考虑衰减和几何因素                       │
│  └─ 估算源活度                               │
```

## 附录：放射源事故警示案例

### 案例一：Ir-192探伤源丢失

**事故经过**：某年某月，探伤作业后未确认源是否归位即离开，数小时后现场剂量率异常。

**关键教训**：
- 探伤作业必须执行"出源-作业-归源"三确认
- 现场必须配备便携式剂量率仪
- 发现异常立即启动搜寻程序

### 案例二：Cs-137源破损污染

**事故经过**：Cs-137测厚源壳破损，CsCl粉末扩散，污染地面和衣物。

**关键教训**：
- 可溶放射性物质破损后污染范围广
- 禁止直接接触破损源
- 需专业队伍进行去污

### 案例三：Am-241烟雾探测器处理不当

**事故经过**：居民发现旧烟雾探测器内源片，将其砸碎丢弃，导致粉末扩散。

**关键教训**：
- 公众无需恐慌Am-241源
- 活度极低，外照射风险可忽略
- 破损后通风处理即可，无需疏散
