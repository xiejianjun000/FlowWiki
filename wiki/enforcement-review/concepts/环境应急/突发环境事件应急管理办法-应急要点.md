# 《突发环境事件应急管理办法》应急要点

> 施行日期：2015年6月5日
> 发布机关：环境保护部
> 部令号：第34号

---

## 一、核心地位

《突发环境事件应急管理办法》是环境应急管理领域**最核心、最直接**的部门规章，是各级生态环境部门和企业开展环境应急管理工作的主要依据。

---

## 二、适用范围

**第二条：** 本办法适用于以下突发环境事件的应急管理工作：

1. **大气污染事件** - 有毒有害气体泄漏、火灾烟气、爆炸烟尘等
2. **水体污染事件** - 化学品泄漏、废水事故排放、尾矿库泄漏等
3. **土壤污染事件** - 危险废物倾倒、化学品泄漏污染土壤等
4. **辐射污染事件** - 放射源丢失、辐射事故等
5. **其他突发环境事件** - 噪声、振动、光污染等

---

## 三、核心制度体系

### （一）应急预案制度

#### 1. 预案编制主体

| 主体类型 | 预案类型 | 编制要求 |
|---------|---------|---------|
| **政府部门** | 突发环境事件应急预案 | 县级以上生态环境部门编制 |
| **工业园区** | 突发环境事件应急预案 | 园区管理机构编制 |
| **企业事业单位** | 突发环境事件应急预案 | 风险源单位编制 |

#### 2. 预案内容（第十三条）

应急预案应当包括以下内容：

1. **总则** - 编制目的、依据、适用范围、工作原则
2. **组织指挥体系** - 应急组织机构及职责
3. **预防与预警机制** - 风险防控、监测预警
4. **应急处置** - 分级响应程序、处置措施
5. **应急保障** - 队伍、物资、装备、技术保障
6. **后期处置** - 调查评估、恢复重建
7. **附则** - 术语解释、预案管理

#### 3. 预案备案（第十四条）

| 备案主体 | 备案机关 | 备案时限 |
|---------|---------|---------|
| 县级以上政府预案 | 上一级生态环境部门 | 发布后20个工作日内 |
| 企业事业单位预案 | 所在地县级生态环境部门 | 发布后20个工作日内 |
| 跨区域企业预案 | 各相关区域生态环境部门 | 发布后20个工作日内 |

### （二）风险评估制度

#### 1. 风险评估要求（第十五条）

企业事业单位应当按照以下要求开展突发环境事件风险评估：

- **识别风险源** - 生产装置、储运设施、危险废物等
- **分析风险程度** - 按照HJ 941-2018标准分级
- **确定风险等级** - 一般、较大、重大、特大
- **编制评估报告** - 作为预案编制依据

#### 2. 风险分级标准（HJ 941-2018）

| 风险等级 | 判定标准 |
|---------|---------|
| **一般风险** | 涉及风险物质数量≤临界量10%，且周边无敏感目标 |
| **较大风险** | 涉及风险物质数量≤临界量30%，或周边有敏感目标 |
| **重大风险** | 涉及风险物质数量≤临界量100%，且周边有敏感目标 |
| **特大风险** | 涉及风险物质数量>临界量，或发生过突发环境事件 |

### （三）隐患排查制度

#### 1. 排查内容（第十六条）

企业事业单位应当建立隐患排查治理制度，重点排查：

| 排查类别 | 具体内容 |
|---------|---------|
| **设施设备** | 生产装置、储罐、管道、阀门、安全设施等 |
| **管理制度** | 操作规程、应急预案、培训演练记录等 |
| **应急准备** | 应急物资、应急队伍、应急设施等 |
| **周边环境** | 敏感目标分布、应急通道、应急水源等 |

#### 2. 隐患治理

- 建立隐患台账
- 明确整改责任人
- 限定整改时限
- 跟踪整改进度
- 验收整改效果

### （四）应急演练制度

#### 1. 演练频次（第十七条）

| 演练类型 | 频次要求 |
|---------|---------|
| **综合应急演练** | 每年至少1次 |
| **专项应急演练** | 每半年至少1次 |
| **现场处置演练** | 每季度至少1次 |

#### 2. 演练内容

- 事故报警与信息报送
- 人员疏散与救援
- 污染控制与处置
- 应急监测
- 舆情应对

## 四、应急响应要求

### （一）信息报告

#### 1. 报告时限

| 报告阶段 | 时限要求 | 报告对象 |
|---------|---------|---------|
| **初报** | 发现后1小时内 | 同级政府和上级生态环境部门 |
| **续报** | 每24小时报告一次 | 同级政府和上级生态环境部门 |
| **终报** | 应急响应终止后10个工作日内 | 同级政府和上级生态环境部门 |

#### 2. 报告内容

| 报告阶段 | 内容要求 |
|---------|---------|
| **初报** | 事件发生时间、地点、类型、原因、影响范围、已采取的措施、人员伤亡情况 |
| **续报** | 事件进展、污染动态、处置措施效果、存在的困难和问题 |
| **终报** | 事件调查结论、处置措施、损失评估、经验教训、整改措施 |

### （二）应急监测

#### 1. 监测启动

突发环境事件发生后，生态环境部门应当：

1. 立即启动应急监测预案
2. 组织监测人员赶赴现场
3. 制定监测方案
4. 开展应急监测

#### 2. 监测方案内容

- 监测因子选择
- 监测点位布设
- 监测频次确定
- 监测方法选择
- 质量保证措施

#### 3. 监测报告

- 监测结果
- 污染趋势分析
- 预警建议

### （三）应急处置

#### 1. 处置原则

- **先控制后处置** - 先控制污染源，再处置污染物
- **先重点后一般** - 优先保护敏感目标和人群
- **先应急后恢复** - 先应急响应，后恢复重建

#### 2. 处置措施

| 污染类型 | 处置措施 |
|---------|---------|
| **大气污染** | 疏散人群、喷淋稀释、活性炭吸附、点火焚烧 |
| **水体污染** | 筑坝拦截、活性炭吸附、化学中和、投加絮凝剂 |
| **土壤污染** | 隔离围堵、土壤挖掘、固化稳定化、焚烧处置 |
| **固废污染** | 围堵拦截、分类收集、安全处置 |

## 五、企业主体责任

### （一）企业应当建立的制度

| 制度名称 | 主要内容 |
|---------|---------|
| 应急预案管理制度 | 编制、评审、备案、修订 |
| 风险评估制度 | 风险识别、评估、分级 |
| 隐患排查制度 | 日常排查、专项排查、整改治理 |
| 应急演练制度 | 演练计划、组织实施、评估总结 |
| 应急值守制度 | 24小时值班、信息报告 |
| 应急物资管理制度 | 储备、调拨、更新 |

### （二）企业应当配备的资源

| 资源类型 | 具体内容 |
|---------|---------|
| **应急队伍** | 应急指挥、抢险救援、应急监测、后勤保障 |
| **应急物资** | 围油栏、吸油毡、活性炭、中和剂、絮凝剂、防护用品 |
| **应急装备** | 应急车辆、监测仪器、通讯设备、照明设备 |
| **应急设施** | 事故应急池、应急阀门、应急通道 |

## 六、政府监管职责

### （一）生态环境部门职责

1. 制定本行政区域突发环境事件应急预案
2. 组织开展环境风险评估
3. 建立环境应急物资储备库
4. 组织应急演练和培训
5. 开展突发环境事件应急处置
6. 组织事件调查和损害评估

### （二）监督检查

生态环境部门应当对以下内容进行监督检查：

- 预案编制备案情况
- 风险评估开展情况
- 隐患排查治理情况
- 应急演练开展情况
- 应急物资储备情况
- 应急队伍建设情况

---

## 七、法律责任

### （一）违法情形

| 违法行为 | 处罚措施 |
|---------|---------|
| 未按规定编制应急预案 | 责令改正，处1-3万元罚款 |
| 未按规定备案应急预案 | 责令改正，处1-3万元罚款 |
| 未按规定开展应急演练 | 责令改正，处1-3万元罚款 |
| 未按规定开展风险评估 | 责令改正，处1-3万元罚款 |
| 未按规定开展隐患排查 | 责令改正，处1-3万元罚款 |
| 迟报、谎报、瞒报、漏报事件信息 | 责令改正，处1-3万元罚款 |

### （二）责任追究

- 对直接负责的主管人员依法给予处分
- 构成犯罪的，依法追究刑事责任

## 八、实务要点

### （一）应急预案编制流程

```
1. 成立编制工作组
   ↓
2. 开展风险评估
   ↓
3. 开展应急资源调查
   ↓
4. 编制应急预案
   ↓
5. 组织评审
   ↓
6. 签署发布
   ↓
7. 备案
   ↓
8. 实施
```

        ▼
