# 辐射应急监测与处置流程

> 适用标准：HJ 1157-2021《辐射事故应急监测技术规范》
> 
> 适用对象：辐射监测技术人员、现场处置人员、应急指挥人员
> 
> 重点提示：本流程适用于辐射事故的监测与处置，非日常环境辐射监测

---

## 一、应急监测启动条件

### 1.1 触发条件分类

**Ⅰ级触发（必须立即启动）**：
```
├─ 公众人员异常受照
├─ 放射源丢失或失窃
├─ 放射源破损导致环境污染
├─ 辐射剂量率超过管理限值10倍
└─ 核与辐射恐怖事件
```

**Ⅱ级触发（应启动监测）**：
```
├─ 发现不明放射源
├─ 辐射剂量率超过本底3倍
├─ 辐射相关报警信号
├─ 辐射设施异常事件
└─ 举报投诉疑似辐射问题
```

**Ⅲ级触发（可启动监测）**：
```
├─ 辐射设施正常运行但有异常
├─ 辐射剂量率略高于本底
├─ 辐射防护设施故障
└─ 辐射工作人员异常受照（轻微）
```

### 1.2 启动程序

```
应急监测启动流程

事件发生
    │
    ▼
初步核实（15分钟内）
├─ 确认事件性质
├─ 评估剂量率水平
├─ 初步判断影响范围
└─ 确定监测级别
    │
    ├─── Ⅰ级 → 立即上报 + 全面监测
    ├─── Ⅱ级 → 上报 + 重点监测
    └─── Ⅲ级 → 备案 + 针对性监测
```

### 1.3 报告要求

**Ⅰ级事件**：
- 30分钟内口头报告生态环境部门
- 2小时内书面报告
- 持续续报

**Ⅱ级事件**：
- 1小时内口头报告
- 4小时内书面报告
- 每日续报

**Ⅲ级事件**：
- 24小时内备案
- 事件结束后7日内报告

## 二、监测设备配置

### 2.1 设备分类与用途

| 设备类型 | 测量参数 | 主要用途 | 典型设备 |
|---------|---------|---------|---------|
| 剂量率仪 | 环境剂量率 | 快速筛查、定界 | FH40G、451B |
| α/β/γ表面污染仪 | 表面污染水平 | 人员/物品污染检测 |FJ-2207、FJ-2607 |
| γ谱仪 | 能谱分布 | 核素识别、定性分析 | NaI谱仪、HPGe |
| 个人剂量报警仪 | 个人累积剂量 | 作业人员监测 | AT2145、PD-712i |
| 热释光剂量计 | 历史剂量 | 事后剂量评估 | LiF热释光片 |
| 全身计数器 | 体内放射性 | 内照射评估 | 全身计数器 |

### 2.2 设备选用原则

**快速响应包（必备）**：
```
便携式设备包：
├─ 剂量率仪（1台）
│   ├─ 量程：0.01 µSv/h - 10 mSv/h
│   └─ 能量响应：50 keV - 3 MeV
├─ 表面污染仪（1台）
│   └─ α/β/γ兼容
├─ 个人剂量报警仪（若干）
│   └─ 阈值可调
├─ 防护装备
│   ├─ 铅防护围裙
│   ├─ 铅手套
│   └─ 防护面罩
└─ 记录工具
    ├─ 记录本
    ├─ 相机/手机
    └─ GPS定位仪
```

**专业监测包（支援到达后）**：
```
专业设备：
├─ γ谱仪（NaI或HPGe）
├─ 高量程剂量率仪
├─ 中子监测仪（必要时）
├─ 采样设备
│   ├─ 空气采样器
│   ├─ 水采样器
│   └─ 土壤采样器
└─ 定位制图设备
    └─ GPS + 地图绘制工具
```

### 2.3 设备校准与维护

**校准要求**：
- 年度校准（计量检定）
- 使用前检查（功能正常、电池充足）
- 对比校准（可疑时用标准源验证）

**日常维护**：
- 定期开机自检
- 电池管理（充足电量）
- 传感器清洁
- 存储保护（防震、防潮）

### 2.4 设备操作要点

**剂量率仪操作**：

```
操作步骤：
1. 开机预热（按说明书要求）
2. 选择量程（自动或手动）
3. 能量补偿设置（根据测量目的）
4. 测量读数（稳定后记录）
5. 记录位置、时间
6. 必要时拍照留证

读数要点：
├─ 观察数值是否稳定
├─ 注意量程指示
├─ 记录异常波动
└─ 关注报警提示
```

**γ谱仪操作**：

```
操作步骤：
1. 开机预热（通常5-10分钟）
2. 能量校准（如有必要）
3. 设置测量时间
4. 背景测量（测量前）
5. 样品/现场测量
6. 保存谱数据
7. 谱分析（特征峰识别）

分析要点：
├─ 寻找特征峰
├─ 核对核素数据库
├─ 判断源核素
└─ 评估活度
```

## 三、监测点位布设

### 3.1 布设原则

**优先原则**：
```
布设优先级
├─ 1. 事故中心点
├─ 2. 下风向（主导）
├─ 3. 敏感目标（学校、医院、居民区）
├─ 4. 边界
├─ 5. 防护设施位置
└─ 6. 参考对照点
```

**风向原则**：
- 以事故点为中心
- 重点布设下风向
- 扇形布点或网格布点
- 根据风向变化调整

**敏感目标优先**：
- 优先覆盖人员密集区
- 覆盖饮用水源
- 覆盖食品生产区
- 覆盖学校、医院等

### 3.2 布设密度参考

| 区域类型 | 监测点间距 | 监测点数量（参考）|
|---------|-----------|-----------------|
| 事故中心区 | 10-20米 | >10个 |
| 近场区（<100米）| 20-50米 | >10个 |
| 中场区（100-500米）| 50-100米 | >5个 |
| 远场区（>500米）| 100-500米 | 根据需要 |

**网格布点法**：
```
网格法适用场景：事故范围较大、需全面评估

布设方法：
├─ 以事故点为原点建立坐标系
├─ 按间距划分网格
├─ 每个网格至少1个监测点
├─ 加密高风险区域
└─ 覆盖所有敏感目标

示例：100×100米范围，50米间距
├─ 需5×5=25个网格
└─ 至少25个监测点
```

## 四、监测方法与流程

### 4.1 现场测量流程

**标准化测量程序**：

```
现场测量流程
│
├─ 步骤1：准备阶段
│   ├─ 领取设备、检查状态
│   ├─ 记录设备信息
│   └─ 记录背景点位置
│
├─ 步骤2：背景测量
│   ├─ 选择对照点
│   ├─ 测量背景剂量率
│   └─ 记录背景值
│
├─ 步骤3：现场测量
│   ├─ 进入监测区域
│   ├─ 按计划布点测量
│   ├─ 记录各点数据
│   └─ 记录异常情况
│
├─ 步骤4：数据处理
│   ├─ 扣除背景值
│   ├─ 绘制等剂量率线
│   ├─ 标注异常区域
│   └─ 初步分析
│
└─ 步骤5：报告编制
    ├─ 整理监测数据
    ├─ 绘制现场图
    ├─ 编写监测报告
    └─ 提交审核
```

### 4.2 放射源搜寻方法

**方法一：网格搜索法**

```
适用场景：已知大概范围，需精确定位

操作步骤：
1. 将可疑区域划分为网格
2. 网格间距根据活度确定
   - 高活度源（mCi级）：5-10米
   - 中活度源（µCi级）：2-5米
   - 低活度源（nCi级）：1-2米
3. 按网格逐点测量
4. 记录每点剂量率
5. 绘制等剂量率图
6. 定位最高点

注意：源不在剂量率最高点正上方
      需结合方向确定
```

**方法二：背向屏蔽法**

```
适用场景：定位方向已确定，需确定距离

操作步骤：
1. 确定辐射来向（使用方向探测器）
2. 沿辐射来向移动
3. 记录剂量率变化
4. 剂量率先增后减的拐点即源所在平面
5. 结合距离估算定位

原理：剂量率随距离变化
      接近源时增加
      经过源后开始下降
```

**方法三：梯度搜索法**

```
适用场景：快速定位大致范围

操作步骤：
1. 从外围开始测量
2. 沿梯度上升方向移动
3. 直到剂量率达到峰值
4. 结合背向屏蔽确定位置

简化操作：
- 边移动边观察读数
- 始终沿剂量增加方向
- 找到最高点
```

**方法四：立体定位法**

```
适用场景：需要三维定位

操作步骤：
1. 在多个位置测量
2. 记录各点位置坐标和剂量率
3. 建立剂量-距离模型
4. 计算源位置
5. 验证定位结果

数学方法：
- 点源剂量率公式反演
- 最小二乘拟合
- 迭代优化
```

### 4.3 表面污染监测

**监测对象**：
- 人员（皮肤、衣物）
- 地面
- 设备设施
- 车辆

**监测方法**：

```
表面污染测量程序
│
├─ 1. 选择设备
│   └─ α/β/γ表面污染仪
│
├─ 2. 设备设置
│   ├─ 选择核素（Am-241、Co-60等）
│   ├─ 设定报警阈值
│   └─ 了解探测效率
│
├─ 3. 测量操作
│   ├─ 探测器贴近表面
│   ├─ 缓慢移动（2-5cm/s）
│   ├─ 重叠扫描覆盖全面
│   └─ 记录异常位置
│
└─ 4. 结果记录
    ├─ 记录各点计数率
    ├─ 扣除本底
    ├─ 计算污染水平（Bq/cm²）
    └─ 标记污染区域
```

**表面污染判断标准**：

| 表面类型 | 控制水平 | 行动水平 |
|---------|---------|---------|
| 地面 | 0.8 Bq/cm² | 4 Bq/cm² |
| 设备 | 0.4 Bq/cm² | 4 Bq/cm² |
| 皮肤 | 0.4 Bq/cm² | 4 Bq/cm² |
| 衣物 | 0.4 Bq/cm² | 4 Bq/cm² |

### 4.4 空气监测与采样

**空气监测**：

```
气溶胶监测（必要时）
├─ 使用：空气采样器
├─ 采样头：滤膜（玻璃纤维/聚丙烯）
├─ 流量：10-50 L/min
├─ 时间：连续或定时
└─ 分析：放射性核素分析

氡及子体监测（必要时）
├─ 使用：氡监测仪
├─ 方法：主动采样或被动累积
└─ 核素：Ra-226子体

惰性气体监测（核设施事故）
├─ 使用：高灵敏度γ谱仪
└─ 目标：Xe-133、Xe-135等
```

```
    ├─ 人员搜索（衣物/随身物品）
```

```
收贮条件确认：

├─ 放射源状态评估

├─ 收贮条件确认
```

**收贮操作**：

```
收贮作业程序：
│
├─ 1. 远距离确认
│   └─ 在安全距离使用长柄工具确认
│
├─ 2. 远距离搬运
│   ├─ 使用长柄工具
│   ├─ 沿最低剂量路径
│   └─ 保持铅罐口朝上
│
├─ 3. 放入铅罐
│   ├─ 将放射源送入铅罐
│   ├─ 确认源在罐内
│   └─ 封闭铅罐
│
├─ 4. 表面检测
│   ├─ 表面污染检测
│   ├─ 剂量率检测
│   └─ 记录检测结果
│
├─ 5. 标识记录
│   ├─ 铅罐编号
│   ├─ 核素、活度
│   ├─ 收贮时间
│   └─ 操作人员
│
└─ 6. 转运交接
    ├─ 临时储存
    ├─ 联系收贮单位
    └─ 办理交接手续
```

**收贮注意事项**：

```
安全注意事项：
│
├─ 操作距离
│   └─ 尽可能远距离操作
│
├─ 操作时间
│   └─ 尽可能缩短
│
├─ 屏蔽保护
│   ├─ 使用铅罐屏蔽
│   └─ 铅手套、围裙
│
├─ 防止跌落
│   ├─ 工具牢固

│   └─ 备用接应

├─ 防止破损
```

```
洗消分类：

├─ 人员洗消

│   ├─ 处置人员
│   └─ 其他相关人员
│
├─ 物品洗消
│   ├─ 防护装备
│   ├─ 作业工具
│   └─ 监测设备
│
├─ 场地洗消
│   ├─ 地面
│   ├─ 墙壁
│   └─ 设备设施
│
└─ 车辆洗消
    ├─ 作业车辆
    └─ 转运车辆
```

**人员洗消**：

```
人员洗消程序：
│
├─ 1. 污染检测
│   ├─ 使用表面污染仪
│   ├─ 检测全身
│   ├─ 重点部位（手、足、面部）
│   └─ 记录污染位置和水平
│
├─ 2. 分类洗消
│   ├─ 低水平污染：一般清洗
│   ├─ 中水平污染：加强清洗
│   └─ 高水平污染：隔离→专用洗消
│
├─ 3. 洗消方法
│   ├─ 清水冲洗
│   ├─ 肥皂/洗涤剂
│   ├─ 专用去污剂（根据核素）
│   └─ 反复清洗
│
├─ 4. 效果检测
│   ├─ 洗消后检测
│   ├─ 对比洗消前
│   ├─ 达到控制水平以下
│   └─ 否则继续洗消
│
└─ 5. 洗消记录
    ├─ 人员信息
    ├─ 污染水平
    ├─ 洗消过程
    └─ 洗消结果
```

**物品/场地洗消**：

```
物体表面洗消方法：
│
├─ 机械去污
│   ├─ 擦拭
│   ├─ 冲洗
│   ├─ 真空吸尘
│   └─ 适用于大部分情况
│
├─ 化学去污
│   ├─ 酸碱清洗
│   ├─ 络合剂
│   ├─ 专用去污剂
│   └─ 需考虑材料兼容性
│
├─ 其他方法
│   ├─ 高压水枪（场地）
│   ├─ 蒸汽清洗
│   └─ 刮削/打磨（严重污染）
│
└─ 废物处理
    ├─ 收集废液
    ├─ 收集污染固体
    └─ 作为放射性废物处置
```

**洗消效果判定**：

| 类型 | 洗消后控制水平 | 备注 |
|-----|--------------|------|
| 人员皮肤 | <0.4 Bq/cm² | 接近本底 |
| 防护装备 | <4 Bq/cm² | 可复用或暂存 |
| 地面/墙面 | <4 Bq/cm² | 可有限使用 |
| 设备设施 | <4 Bq/cm² | 可正常使用 |
