# 生产经营单位生产安全事故应急预案编制导则

**标准编号**: GB/T 29639-2020（代替GB/T 29639-2013）  
**发布机关**: 国家市场监督管理总局、国家标准化管理委员会  
**发布日期**: 2020年9月29日  
**施行日期**: 2021年4月1日  
**归口单位**: 全国安全生产标准化技术委员会（SAC/TC288）  
**来源**: https://banshi.beijing.gov.cn/pubtask/download/472c8571-0604-4dc0-b128-c05d124042af.pdf

---

## 1. 范围

本标准给出了生产经营单位生产安全事故应急预案的编制程序、体系构成和综合应急预案、专项应急预案、现场处置方案的主要内容以及附件信息。

适用于生产经营单位生产安全事故应急预案编制工作，核电厂、其他社会组织和单位的应急预案编制可参照执行。

## 2. 应急预案编制程序（8个步骤）

| 步骤 | 内容 |
|------|------|
| 1. 成立编制工作组 | 以单位有关负责人为组长，相关部门人员参加，邀请相关救援队伍及周边企业、社区代表 |
| 2. 资料收集 | 法律法规、技术标准、地质地形环境、气象水文交通、功能区划分、工艺流程、历史事故等 |
| 3. 风险评估 | 辨识危险有害因素，分析事故类别、可能性、危害后果和影响范围，评估风险等级 |
| 4. 应急资源调查 | 本单位可调用的应急队伍/装备/物资/场所，周边可请求援助的应急资源 |
| 5. 应急预案编制 | 遵循以人为本、依法依规、符合实际、注重实效的原则，以应急处置为核心 |
| 6. 桌面推演 | 按照应急预案，模拟突发事件进行推演，检验预案 |
| 7. 应急预案评审 | 内部评审和外部评审相结合，评审预案内容的适用性 |
| 8. 批准实施 | 由生产经营单位主要负责人签发实施 |

## 3. 应急预案体系构成

### 3.1 综合应急预案

从总体上阐述事故的应急方针、政策，包括：
- 总则（编制目的、编制依据、适用范围、应急预案体系、应急工作原则）
- 应急组织机构及职责
- 应急响应（响应分级、响应程序、处置措施）
- 后期处置
- 应急保障

### 3.2 专项应急预案

针对具体事故类型制定的应急预案，包括：
- 适用范围
- 应急组织机构及职责
- 响应启动
- 处置措施
- 应急保障

### 3.3 现场处置方案

针对具体的场所、装置或设施制定的应急处置措施，包括：
- 事故风险描述
- 应急工作职责
- 应急处置（应急处置程序、现场应急处置措施）
- 注意事项

## 4. 综合应急预案主要内容

| 章节 | 内容要点 |
|------|----------|
| 总则 | 编制目的、编制依据、适用范围、应急预案体系、应急工作原则 |
| 应急组织机构及职责 | 应急组织形式及组成单位或人员（可用结构图表示），各工作小组工作任务及职责 |
| 应急响应 | 信息报告（24小时应急值守电话、信息接收与通报、上报、传递）、预警、响应分级、响应程序、处置措施、应急解除 |
| 信息公开 | 向新闻媒体、社会公众通报的部门、负责人和程序 |
| 后期处置 | 污染物处理、生产秩序恢复、医疗救治、人员安置、善后赔偿、应急救援评估 |
| 保障措施 | 通信与信息保障、应急队伍保障、物资装备保障、其他保障（经费/交通/治安/技术/医疗/后勤） |
| 应急预案管理 | 培训、演练、修订（定期评审）、备案、实施 |

## 5. 附件信息

- 生产经营单位概况
- 风险评估的结果
- 预案体系与衔接
- 应急物资装备的名录或清单
- 有关应急部门、机构或人员的联系方式
- 规范化格式文本（应急信息接报、处理、上报等）
- 关键的路线、标识和图纸（警报系统分布、重要防护目标、指挥位置及救援路线、疏散路线、平面布置图等）
- 有关协议或备忘录

## 6. 2020版主要修订内容（对比2013版）

- 修改了应急预案编制程序（将应急能力评估修改为应急资源调查）
- 细化了应急预案评审内容
- 修改综合应急预案要素，去掉编制目的，将风险评估结果放入附件
- 修改专项应急预案要素，增加适用范围，去掉事故风险分析
- 补充了应急预案附件组成

## 关联标准：GB/T XXXX 突发事件应急预案编制导则（征求意见稿）

该标准将取代GB/T 29639，分为10个部分：
- 第1部分：通则
- 第4部分：生产经营单位突发事件应急预案编制导则

**新变化**：
- 适用对象从"生产安全事故"扩展到"突发事件"（含自然灾害、事故灾难等）
- 增加应急预案情景构建方法
- 细化应急资源调查和风险评估要求
