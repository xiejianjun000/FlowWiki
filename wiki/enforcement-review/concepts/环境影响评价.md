# 环境影响评价

## 一句话解释

环境影响评价（EIA）是指对规划和建设项目实施后可能造成的环境影响进行分析、预测和评估，提出预防或者减轻不良环境影响的对策和措施，进行跟踪监测的方法与制度。该制度是中国环境管理中"预防为主"方针的核心体现，通过在决策早期阶段评估环境风险，从源头上避免或减轻不良环境影响。

## 定义与法律依据

环境影响评价（EIA）是指对规划和建设项目实施后可能造成的环境影响进行分析、预测和评估，提出预防或者减轻不良环境影响的对策和措施，进行跟踪监测的方法与制度。该制度是中国环境管理中"预防为主"方针的核心体现，通过在决策早期阶段评估环境风险，从源头上避免或减轻不良环境影响。

**[[sources/laws/eco_import/环境影响评价法.md|环境影响评价法]]** §2（定义）、§16（分类管理）：

> 国家根据建设项目对环境的影响程度，对建设项目的环境影响评价实行分类管理。建设单位应当按照下列规定组织编制环境影响报告书、环境影响报告表或者填报环境影响登记表：（一）可能造成重大环境影响的，应当编制环境影响报告书，对产生的环境影响进行全面评价；（二）可能造成轻度环境影响的，应当编制环境影响报告表；（三）对环境影响很小、不需要进行环境影响评价的，应当填报环境影响登记表。

## 核心内容

| 类别 | 适用情形 | 编制要求 | 审批方式 |
|------|----------|----------|----------|
| 环境影响报告书 | 可能造成重大环境影响 | 全面评价 | 审批（60日） |
| 环境影响报告表 | 可能造成轻度环境影响 | 分析或专项评价 | 审批（30日） |
| 环境影响登记表 | 环境影响很小 | 填报 | 备案管理 |

1. **规划环评**：国务院有关部门和设区的市级以上政府编制土地利用规划和专项规划须进行环评
2. **公众参与**：重大影响项目须征求有关单位、专家和公众意见
3. **"未批先建"禁止**：环评文件未批准不得开工建设，违者处总投资额1%-5%罚款
4. **质量终身追责**：环评报告质量问题，建设单位处50万-200万元，编制单位处收费3-5倍
5. **跟踪检查**：项目投产后主管部门须跟踪检查，发现严重问题追责

```
项目立项 → 委托/自行编制环评文件 → 公众参与（重大影响） → 报批 → 审批 → 建设施工 → 配套环保设施"三同时"验收 → 投产运行 → 跟踪检查
```

## 企业合规要点

- 企业应根据自身行业特点，建立健全与本概念相关的内部管理制度。
- 定期开展合规自查，确保操作过程符合法律法规及许可证要求。
- 保留完整台账、监测记录和佐证材料，便于监管核查与审计。

## 常见误区

- 误区：认为相关合规要求只适用于大型企业。实际上，中小企业同样负有法定环境保护义务。
- 误区：认为只要没有行政处罚记录就合规。合规管理不仅关注结果，也关注过程控制和持续改进。
