# 环境影响评价技术导则 大气环境详解

## 一、标准基本信息

- **标准号**：HJ 2.2-2018
- **标准名称**：环境影响评价技术导则 大气环境
- **替代标准**：HJ 2.2-2008
- **实施日期**：2018年12月1日
- **归口部门**：生态环境部

## 二、总则

### 2.1 适用范围

本标准适用于：
- 新建、改建、扩建项目大气环境影响评价
- 大气环境影响后评价
- 大气环境影响评价文件编制

### 2.2 评价因子筛选

#### 2.2.1 基本因子

- SO₂、NO₂、PM₁₀、PM₂.₅、CO、O₃
- 依据《环境空气质量标准》(GB 3095-2012)

#### 2.2.2 其他因子

- 项目排放的特征污染物
- TSP、铅、苯并[a]芘
- VOCs相关物种

### 2.3 评价标准

- 一类区执行GB 3095-2012一级标准
- 二类区执行GB 3095-2012二级标准
- 三类区执行GB 3095-2012二级标准
- 特征污染物参照TJ 36-79居住区大气中有害物质最高容许浓度

## 三、评价工作等级与范围

### 3.1 评价工作等级

#### 3.1.1 计算方法

通过估算模式计算各污染物的最大占标率Pmax：

```
Pimax = Ci / C₀i × 100%
```

其中：
- Ci：估算模式预测的最大1h地面浓度
- C₀i：环境空气质量标准1h平均浓度限值

#### 3.1.2 分级判据

| 评价等级 | Pmax范围 |
|----------|----------|
| 一级 | Pmax ≥ 10% |
| 二级 | 1% ≤ Pmax < 10% |
| 三级 | Pmax < 1% |

### 3.2 评价范围

| 评价等级 | 评价范围 |
|----------|----------|
| 一级 | 以排放源为中心，边长5km矩形区域 |
| 二级 | 以排放源为中心，边长5km矩形区域 |
| 三级 | 以排放源为中心，边长2km矩形区域 |

特殊情况下，可根据排放高度、地形条件适当扩大或缩小。

## 四、污染源调查

### 4.1 调查内容

#### 4.1.1 建设项目污染源

- 排气筒参数：高度、内径、出口温度、出口流速
- 排放参数：排放浓度、排放量、排放速率
- 排放工况：连续/间歇、年排放小时数
- 排放因子：颗粒物、SO₂、NOx、VOCs等

#### 4.1.2 现有污染源

- 评价范围内在建、已建项目污染源
- 排放参数、排放工况

#### 4.1.3 区域污染源

- 评价范围内区域污染源统计
- 评价范围内主要交通道路
- 区域内的民用源

### 4.2 排放数据来源

1. **实测法**：在线监测数据
2. **物料衡算法**：基于物料守恒
3. **产污系数法**：参照行业产污系数手册
4. **实验法**：实验测试
5. **类比法**：参照同类项目

## 五、气象观测与调查

### 5.1 气象资料来源

#### 5.1.1 常规气象资料

- 气象台站近5年连续1年逐时气象数据
- 风速、风向、温度、云量、气压、相对湿度

#### 5.1.2 补充观测

- 评价等级一级且无气象台站资料时
- 复杂地形区域
- 观测期不少于1年

### 5.2 气象数据处理

#### 5.2.1 风频玫瑰图

- 全年、各季风频玫瑰图
- 静风频率

#### 5.2.2 联合频率

- 风速、风向、稳定度联合频率表

#### 5.2.3 大气稳定度

- P-T分类法
- 各稳定度频率分布

### 5.3 高空气象数据

- 混合层高度
- 逆温层特征
- 探空数据

## 六、环境空气质量现状调查与评价

### 6.1 现状监测

#### 6.1.1 监测点位布设

| 项目特征 | 点位数量 |
|----------|----------|
| 一级评价 | ≥6个 |
| 二级评价 | ≥4个 |
| 三级评价 | ≥2个 |

布设原则：
- 主导风向下风向加密
- 主要敏感目标布点
- 厂界外布设监控点

#### 6.1.2 监测因子

- 常规污染物：PM₁₀、PM₂.₅、SO₂、NO₂、CO、O₃
- 项目特征污染物
- 必要时增加VOCs

#### 6.1.3 监测频次

| 污染物 | 频次 |
|--------|------|
| SO₂、NO₂、CO、O₃ | 1h平均、8h平均、24h平均 |
| PM₁₀、PM₂.₅、TSP | 24h平均 |
| 特征污染物 | 按相关标准规定 |

监测期：7天连续监测，至少一期监测。

### 6.2 现状评价

#### 6.2.1 单因子指数法

```
Ii = Ci / Si
```

其中：
- Ci：污染物i的浓度
- Si：污染物i的评价标准

Ii > 1 表示超标。

#### 6.2.2 最大占标率

```
Pmax = max(Ci / Si) × 100%
```

#### 6.2.3 超标率

```
超标率 = 超标数据个数 / 总数据个数 × 100%
```

## 七、气象预测模式

### 7.1 推荐模式

#### 7.1.1 AERMOD模式

- 稳态高斯烟羽模式
- 适用于简单地形、复杂地形
- 推荐用于一、二级评价

#### 7.1.2 ADMS模式

- 高斯烟羽模式
- 考虑边界层湍流结构
- 适用于城市、工业区

#### 7.1.3 CALPUFF模式

- 非稳态拉格朗日烟团模式
- 适用于远距离输送、复杂风场
- 推荐用于海岸线、复杂地形

#### 7.1.4 估算模式AERSCREEN

- 简化估算模式
- 适用于三级评价
- 用于评价等级判定

### 7.2 模式参数

#### 7.2.1 地形数据

- DEM数字高程数据
- 分辨率30m、90m

#### 7.2.2 土地利用

- 土地利用分类
- 地表粗糙度
- 反照率
- 鲍文比

#### 7.2.3 地表参数

- 季节变化
- 昼夜变化

### 7.3 模式预测

#### 7.3.1 预测情景

- 正常排放
- 非正常排放

#### 7.3.2 预测时段

- 1h平均浓度
- 日平均浓度
- 年平均浓度

#### 7.3.3 预测内容

- 浓度场分布
- 等值线图
- 敏感目标浓度贡献值
- 区域最大浓度

### 7.4 预测结果表达

- 网格浓度分布图
- 等值线图
- 敏感目标浓度统计表
- 浓度叠加分析

## 八、环境影响评价

### 8.1 评价内容

#### 8.1.1 浓度贡献值

- 新增污染源贡献值
- 区域削减源削减值
- 评价范围内其他在建、拟建项目贡献值

#### 8.1.2 浓度叠加值

- 现状浓度 + 新增污染源贡献值
- 现状浓度 + 新增污染源贡献值 + 评价范围内其他在建、拟建项目贡献值

### 8.2 评价判据

#### 8.2.1 一级、二级评价

- 新增污染源正常排放短期浓度贡献值：环境质量浓度标准的**90%以内**
- 新增污染源正常排放年均浓度贡献值：环境质量浓度标准的**30%以内**

#### 8.2.2 三级评价

- 不进行预测，定性分析

### 8.3 区域削减要求

- 区域削减源应在本项目投产前完成
- 削减量应大于等于本项目新增排放量
- 削减量不得重复使用

## 九、环境保护措施

### 9.1 大气污染防治措施

#### 9.1.1 源头控制

- 选用清洁生产工艺
- 选用低硫、低灰分燃料
- 优化能源结构

#### 9.1.2 末端治理

- 颗粒物：袋式除尘器、电除尘器
- SO₂：石灰石-石膏湿法、氨法脱硫
- NOx：SCR、SNCR脱硝
- VOCs：RTO、RCO、活性炭吸附

### 9.2 措施论证

- 技术可行性论证
- 经济合理性论证
- 达标可靠性论证
- 二次污染分析

## 十、监测计划

### 10.1 施工期监测

- 施工场地扬尘监测
- 施工机械废气监测

### 10.2 运营期监测

#### 10.2.1 排放源监测

- 在线监测：颗粒物、SO₂、NOx
- 手工监测：特征污染物

#### 10.2.2 环境质量监测

- 厂界无组织监测
- 敏感目标监测

## 十一、对企业环保合规工作的启示

1. **评价等级判定的关键**：估算模式预测最大占标率，准确确定评价等级
2. **气象资料质量**：5年连续1年逐时气象数据，确保代表性
3. **现状监测数据可靠**：监测点位、频次、因子应符合规范
4. **预测模式选择合理**：根据地形、气象条件选择适宜模式
5. **浓度贡献值控制**：新增污染源贡献值不应超标，且不能挤占环境容量
6. **区域削减落实**：新建项目需配套区域削减方案，且在本项目投产前完成
7. **环境保护措施可行**：技术可行、经济合理、达标可靠
8. **环境风险防范**：事故排放情景预测、应急措施到位
9. **监测计划完善**：在线监测、手工监测、环境质量监测全覆盖
10. **公示与公众参与**：依法开展公示与公众参与，信息公开

## 十二、相关法规依据

- 《中华人民共和国大气污染防治法》（2018年修订）
- 《大气污染防治行动计划》
- 《建设项目环境影响报告书（表）编制监督管理办法》
- 《关于做好环境影响评价制度与排污许可制衔接工作的通知》

## 十三、违法处罚依据

### 13.1 大气污染防治法第99条

超过大气污染物排放标准排放大气污染物的，处**10万元以上100万元以下罚款**。

### 13.2 大气污染防治法第108条

未采取措施防止扬尘污染的，处**1万元以上10万元以下罚款**。

### 13.3 环评法第31条

未依法进行环境影响评价的建设项目，擅自开工建设的，处建设项目总投资额**1%以上5%以下的罚款**。
