## 任务6：ALOHA扩散模拟软件深度学习

### 6.1 ALOHA软件概述

**ALOHA**（Areal Locations of Hazardous Atmospheres，有害大气空中定位软件）是由美国环保署（EPA）化学制品突发事件和预备办公室（CEPPO）和美国国家海洋和大气管理局（NOAA）响应和恢复办公室共同开发的专业 hazard modeling 程序，是CAMEO软件套件中的核心危害建模工具。

#### 6.1.1 核心功能
ALOHA能够模拟以下四类事故后果：

| 事故类型 | 具体情形 | 输出参数 |
|---------|---------|---------|
| **毒气扩散** | 有毒气体/蒸气云泄漏后在大气中的扩散 | 浓度等值线、影响范围、敏感点浓度时变曲线 |
| **池火** | 液体燃料在地面形成液池后燃烧 | 热辐射强度等值线（kW/m²）、死亡/重伤/轻伤半径 |
| **BLEVE**（沸腾液体扩展蒸气爆炸） | 受压储罐在火灾环境下破裂，液体瞬间气化爆炸 | 火球半径、热辐射通量、冲击波超压 |
| **蒸气云爆炸**（VCE） | 泄漏的可燃气体/液体蒸气与空气混合形成可燃云，遇点火源发生爆炸 | 爆炸超压等值线（kPa）、建筑物破坏半径 |

#### 6.1.2 内置事故情景矩阵

| 泄漏源类型 | 中毒情景 | 火灾情景 | 爆炸情景 |
|-----------|---------|---------|---------|
| 直接泄漏（点源） | 毒气云 | 闪火区 | 蒸气云爆炸 |
| 液池蒸发 | 毒气云 | 池火 | 蒸气云爆炸 |
| 储罐（加压） | 毒气云 | 喷射火/闪火 | BLEVE/火球 |
| 气体管道 | 毒气云 | 喷射火 | 蒸气云爆炸 |

### 6.2 输入参数详解

#### 6.2.1 地理位置参数（Site Data → Location）
- **经纬度**：十进制格式，如娄底市约 N27.7°, E112.0°
- **海拔高度**：影响空气密度和扩散参数，娄底约200m
- **地点名称**：自定义标识

#### 6.2.2 建筑类型（Building Type）
| 类型 | 适用场景 | 注意事项 |
|-----|---------|---------|
| Single Story（单层） | 平房、传达室等 | 室外扩散，无遮挡 |
| Multi-Story（多层） | 楼房 | 需考虑建筑物尾流效应 |
| Enclosed Space（密闭空间） | 车间、仓库内泄漏 | 需设置室内体积，计算室内浓度 accumulation |
| Open Country（开阔乡村） | 无周围建筑物的敞开空间 | 默认选择 |
| Urban（城市） | 城市环境 | 地表粗糙度更高 |

#### 6.2.3 日期时间设置
- 用于确定太阳高度角，从而影响大气稳定度分类
- 建议按实际事故发生时间设置，或按最不利气象条件设置

#### 6.2.4 化学品选择（Setup → Chemical）
- **纯化学品数据库**：ALOHA内置近1000种常见危化品，直接搜索选择（如CHLORINE、AMMONIA、HYDROGEN SULFIDE）
- **自定义化学品**：当数据库中没有时，可手动输入：分子量、正常沸点、蒸气压曲线（Antoine参数）、Flash Point等
- **混合物**：可选择多种纯物质按百分比混合

#### 6.2.5 大气条件参数（Atmospheric）
| 参数 | 说明 | 典型值 |
|-----|------|-------|
| 风速 | 距地面参考高度处的风速 | 1.5m/s（一级风）~ 10m/s（五级风） |
| 风向 | 来风方向 | N/S/E/W |
| 测量高度 | 风速测量高度，默认10m或3m | 3m或10m |
| 地表类型 | 决定地表粗糙度长度z₀ | Open country（农村）0.03~0.1m；Urban（城市）0.5~1.0m |
| 云层覆盖率 | 0~10分之十分制 | 0（晴）~10（全阴） |
| 气温 | 环境温度 | 夏季35℃/冬季0℃等 |
| 逆温层 | 是否存在接地逆温或抬升逆温 | No inversion（无逆温，默认）|
| 相对湿度 | 影响蒸气压和可见光折射 | 50%（典型）|

**大气稳定度等级**（Pasquill-Gifford分类）：
- A：极不稳定（强日晒，大风）
- B：不稳定
- C：微不稳定
- D：中性（阴天或大风）
- E：微稳定
- F：稳定（夜间辐射逆温）

ALOHA可根据输入的云量、风速、日照条件自动判定稳定度等级，也可手动指定。

#### 6.2.6 泄漏源参数（Source）
**容器类型选择**：
- ** Tank**（储罐）：卧式/立式，设置直径、长度/高度、充装量（质量或液位）
- ** Pipe**（管道）：设置管道直径、压力、泄漏孔径
- ** Pool**（液池）：设置液池面积、液体深度
- **Pressurized Tank**（受压储罐）：用于BLEVE模拟

**关键泄漏参数**：
- 泄漏孔径（5cm/10cm/30cm或自定义）
- 泄漏方向（水平/垂直向上/垂直向下）
- 液体过热度（superheat）——影响闪蒸比例
- 喷射速度（受压容器泄漏）

#### 6.2.7 计算选项（Calculation Options）
- **高斯扩散模型**（Gaussian Plume/Slab）：适用于中性浮力气体，是最常用的模型
- **重气体扩散模型**（Heavy Gas Dispersion，DEGADIS）：适用于密度大于空气的气体（如氯气、液化石油气），模拟初始重气下沉和后续转变为中性浮力的过程
- **蒸气云爆炸模型**：需要设置点火延迟时间、可燃云尺寸
- **池火模型**：需要设置液池直径、燃烧速率
- **BLEVE模型**：自动计算火球直径、持续时间、热辐射通量

### 6.3 输出解读——威胁区域图与浓度等值线

#### 6.3.1 威胁区域的颜色编码含义

ALOHA生成的威胁区域图中，不同颜色对应不同的浓度阈值或危害程度：

| 颜色 | 含义 | 对应浓度基准（以毒气扩散为例） |
|-----|------|--------------------------|
| **红色区域** | 立即威胁生命和健康区域（IDLH区域），或致死区域 | IDLH浓度，或AEGL-3/ERPG-3/TEEL-3（1小时内造成死亡或不可逆伤害的浓度） |
| **橙色区域** | 严重伤害区域（不可耐受，必须撤离） | AEGL-2/ERPG-2/TEEL-2（1小时内造成不可逆伤害或严重健康影响的浓度） |
| **黄色区域** |  noticeable健康影响区域（可耐受短时间，建议防护） | AEGL-1/ERPG-1/TEEL-1（1小时内引起明显不适但无持久性伤害的浓度） |
| **绿色区域** | 无明显健康影响区域 | 低于AEGL-1 |

**关键浓度标准解释**：
- **AEGL**（Acute Exposure Guideline Levels）：美国EPA发布的急性暴露指导浓度，分AEGL-1/2/3三级
- **ERPG**（Emergency Response Planning Guidelines）：美国AIHA发布，ERPG-1（轻度症状）、ERPG-2（不可逆伤害）、ERPG-3（危及生命）
- **TEEL**（Temporary Emergency Exposure Limits）：美国DOE发布的临时应急暴露限值
- **IDLH**（Immediately Dangerous to Life and Health）：NIOSH定义的立即危及生命和健康浓度

#### 6.3.2 浓度等值线输出
- **等值线图**：显示不同浓度阈值对应的地理边界
- **浓度时变曲线**：可查询某敏感点（如学校、医院）处的浓度随时间变化
- **室内外浓度对比**：ALOHA可计算建筑物内外浓度差异（由于渗透和通风）

#### 6.3.3 热辐射与爆炸输出解读
- **池火/火球热辐射**：输出不同热辐射强度（kW/m²）对应的距离
  - 37.5 kW/m²：1分钟内造成一度烧伤
  - 12.5 kW/m²：1分钟内造成疼痛（需立即撤离）
  - 4.0 kW/m²：可耐受8秒以上
- **蒸气云爆炸超压**：输出不同超压值（kPa）对应的距离
  - 70 kPa：大多数建筑物严重损坏
  - 20 kPa：房屋轻度损坏，玻璃破碎
  - 7 kPa：玻璃破裂

### 6.4 与MARPLOT配合在地图上显示

**MARPLOT**是CAMEO套件中的地图绘制模块，与ALOHA无缝集成：

1. **工作流程**：
   - 在ALOHA中完成事故模拟
   - 点击"Show in MARPLOT"按钮
   - ALOHA将威胁区域边界导出为GIS格式
   - MARPLOT在背景地图上叠加显示威胁区域、敏感点（学校、医院、居民区）、道路、水体等

2. **与Google Earth集成**：
   - ALOHA支持将模拟结果导出为KML格式
   - 可在Google Earth中查看高分辨率卫星影像上的威胁区域
   - 便于与现场实际地形对照，识别可能的地形阻挡效应

3. **实战应用**：
   - 应急指挥"挂图作战"：将ALOHA模拟结果打印或投屏，标注疏散范围
   - 与"一河一策一图"成果叠加：在河流污染事件中，结合沿岸敏感目标图层

### 6.5 五种典型场景的参数设置思路

#### 场景a：氯气管道泄漏（液态/气态）

**情景设定**：液氯储罐出口管道法兰泄漏，孔径25mm，液氯喷出后部分气化

**参数设置**：
```
化学品：CHLORINE（CAS 7782-50-5）
容器类型：Pressurized Tank（液氯储罐，临界温度144℃）
泄漏孔径：25 mm（部分破裂）
环境温度：25℃
风速：3 m/s（二级风）
稳定度：D（中性）
地表类型：Open country
建筑类型：Open country
```

**注意要点**：
- 液氯泄漏后发生**闪蒸**（约20~30%瞬时气化），剩余以液滴形式扩散并形成氯气云
- ALOHA自动计算闪蒸比例
- 氯气密度约为空气的2.5倍，属重气体，应选择**DEGADIS重气模型**
- 输出重点关注：AEGL-2（16 ppm，约60mg/m³）影响范围

#### 场景b：汽油储罐池火

**情景设定**：汽油储存罐区，储罐破裂，汽油流出形成液池，遇点火源发生池火

**参数设置**：
```
化学品：GASOLINE（混合物，可用OCTANE或HEPTANE近似）
泄漏类型：Pool fire
液池直径：50 m（根据泄漏量估算）
燃烧速率：约0.04 kg/(m²·s)（汽油典型值）
风速：2 m/s
```

**注意要点**：
- 池火主要危害为**热辐射**，而非中毒
- ALOHA计算不同热辐射强度（kW/m²）的距离
- 需要考虑周围建筑物对热辐射的遮挡（shadowing effect）
- 稳定度对池火模拟影响较小，主要关注风速（影响火焰倾斜角度）

#### 场景c：液氨钢瓶泄漏

**情景设定**：液氨钢瓶（400L，充装量200kg）阀门损坏，液氨喷射泄漏

**参数设置**：
```
化学品：AMMONIA（CAS 7664-41-7）
容器类型：Pressurized Tank（设定为钢瓶尺寸）
泄漏孔径：10 mm（阀门裂缝）
环境温度：20℃
```

**注意要点**：
- 液氨泄漏后迅速气化，形成低温蒸气云（氨气云显白色，因空气中水分冷凝）
- 氨气（分子量17）比空气轻，属**上浮气体**，用高斯模型即可
- 但低温氨气云初始密度大，初期可用重气模型更精确
- ALOHA可同时输出：**毒气扩散区** + **闪火区**（氨气爆炸极限15~28%，LEL较高）+ **喷射火区**

#### 场景d：甲苯蒸气云爆炸

**情景设定**：甲苯储罐区，甲苯泄漏后蒸发形成蒸气云，遇明火发生蒸气云爆炸（VCE）

**参数设置**：
```
化学品：TOLUENE（CAS 108-88-3）
泄漏类型：Vapor Cloud Explosion
液池面积：100 m²（估算）
点火延迟时间：300 s（5分钟，典型值）
爆炸效率：通常取3~10%（TNT当量法）
```

**注意要点**：
- 甲苯蒸气与空气混合形成可燃云，爆炸极限1.2~7.1%LEL~UEL
- VCE模拟需要设定**点火概率**和**点火延迟时间**
- ALOHA输出爆炸超压等值线（kPa）
- 注意区分：**蒸气云爆炸**（VCE，超压危害）与**闪火**（Flash Fire，燃烧危害但不产生显著超压）

#### 场景e：硫化氢井喷

**情景设定**：油气井钻井过程中发生井喷，含硫化氢的天然气大量释放

**参数设置**：
```
化学品：HYDROGEN SULFIDE（CAS 7783-06-4）
泄漏类型：Continuous release（持续泄漏）
泄漏速率：100 kg/s（井喷典型值）
泄漏高度：10 m（井口高度）
风速：5 m/s
```

**注意要点**：
- 硫化氢IDLH = 100 ppm（142 mg/m³），极低！
- H₂S浓度 > 1000 ppm（~1400 mg/m³）时，数秒内致人猝死（"电击型"死亡）
- ALOHA输出：AEGL-3区域（致死）可能达数公里
- 需特别关注**风向**：硫化氢云向下风向传播，需立即疏散下风向居民

### 6.6 ALOHA的局限性和注意事项

#### 6.6.1 模型局限性
1. **地形处理简单**：ALOHA假设平坦地形，不能精确处理复杂山地、建筑物群的阻挡效应
2. **不考虑化学反应**：如泄漏物与水反应产生二次污染物（如三氯化磷遇水产生氯化氢）
3. **不包含颗粒物扩散**：如烟尘、粉尘的沉降和传输
4. **稳态气象假设**：假设风速、稳定度在模拟时段内不变，实际天气是动态变化的
5. **重气模型适用范围**：DEGADIS模型适用于平坦地形，对复杂地形准确性下降

#### 6.6.2 使用注意事项
1. **输入参数敏感性**：风速对结果影响极大（风速翻倍，浓度减半），应尽量使用实测气象数据
2. **保守性设定**：应急决策时应采用保守假设（如最小风速、最不稳定大气条件）
3. **结果验证**：模拟结果应与类似事故案例对比验证，不能盲目信任模型输出
4. **版本更新**：EPA定期更新ALOHA化学品数据库和模型算法，应使用最新版本
5. **专业培训**：ALOHA是专业工具，未经培训人员使用可能产生严重误导

#### 6.6.3 与其他软件的对比
| 软件 | 优势 | 局限 |
|-----|------|------|
| ALOHA | 免费、易用、化学品数据库丰富 | 地形处理简单 |
| PHAST | 专业级、可处理复杂地形和化学反应 | 昂贵、学习曲线陡 |
| FLACS | CFD级精度、可处理复杂几何 | 计算量大、需高性能计算机 |
| CALPUFF | 长距离传输、非稳态气象 | 不适用于瞬时泄漏 |

## 任务7：7类突发环境事件污染物去除技术速查表

### 7.1 技术分类框架

突发环境事件污染物去除技术按介质分为三大类：
- **水污染物去除技术**
- **大气污染物去除技术**
- **土壤污染物去除技术**

每类技术下按物理、化学、生物方法细分。

---

### 7.2 水体污染物去除技术速查表

#### 7.2.1 沉淀法（化学沉淀）

**原理**：向废水中投加化学药剂（碱、硫化物、碳酸盐等），使溶解态重金属离子生成难溶性沉淀物，通过重力沉降分离。

| 适用污染物 | 沉淀剂 | 最佳pH范围 | 去除率 | 优点 | 局限 |
|-----------|-------|-----------|-------|-----|------|
| 铬（Cr³⁺） | NaOH/Ca(OH)₂ | 7~9 | 95~99% | 成本低，操作简单 | Cr⁶⁺需先还原为Cr³⁺ |
| 铜（Cu²⁺） | NaOH | 7~8 | 90~99% | 石灰法最经济 | pH>9时Cu(OH)₂可能重新溶解 |
| 铅（Pb²⁺） | NaOH/Ca(OH)₂ | 8~9 | 95~99% | 也可采用碳酸盐沉淀 | 铅沉淀最佳pH较窄 |
| 锌（Zn²⁺） | NaOH | 9~10 | 90~98% | 也可硫化物沉淀 | pH>10.5时Zn(OH)₂溶解 |
| 镉（Cd²⁺） | NaOH | 10~11 | 95~99% | 硫化镉溶解度更低 | 强碱性操作，腐蚀性强 |
| 镍（Ni²⁺） | NaOH | 9~10 | 90~97% | 石灰法可行 | pH控制要求高 |
| 汞（Hg²⁺） | Na₂S（硫化物） | 8~9 | 99%以上 | 硫化汞溶解度极低 | 残渣需安全处置 |
| 砷（AsⅢ/AsⅤ） | 铁盐+石灰（共沉淀） | 7~9 | 90~99% | 铁砷共沉淀效果好 | AsⅢ需先氧化为AsⅤ |
| 锑（Sb³⁺/Sb⁵⁺） | 铁盐混凝沉淀 | 6~8 | 85~95% | 与砷类似 | 去除率略低于砷 |

**分段沉淀策略**（多种重金属共存时）：
1. pH 7~8：Cr³⁺、Cu²⁺、Pb²⁺沉淀
2. pH 8~9：Zn²⁺、Cd²⁺沉淀
3. pH 9~10：Ni²⁺沉淀
4. pH 10~11：残留Cd²⁺深度去除

**效果**：设备简单，运行成本低；**用时**：沉淀时间1~4小时；**成本**：★☆☆☆☆（最低）

#### 7.2.2 混凝絮凝法

**原理**：投加混凝剂（铝盐、铁盐、有机高分子絮凝剂），通过电荷中和、吸附架桥作用，使胶体颗粒和细小悬浮物聚集成大颗粒而沉降。

| 混凝剂 | 适用污染物 | 投加量 | 去除率 | 优点 | 局限 |
|-------|-----------|-------|-------|-----|------|
| 聚合氯化铝（PAC） | 浊度、胶体、部分重金属 | 10~50 mg/L | 70~90% | 适应pH宽（5~9） | 产生铝污泥 |
| 聚合硫酸铁（PFS） | 浊度、砷、磷 | 10~60 mg/L | 80~95% | 沉降速度快 | 出水色度高 |
| PAM（聚丙烯酰胺） | 助凝剂，配合铝/铁盐使用 | 0.5~2 mg/L | 提高20~30% | 大幅改善污泥沉降性 | 需严格控制投加量 |

**效果**：★★★★☆；**用时**：混凝反应15~30分钟 + 沉淀1~2小时；**成本**：★★☆☆☆

#### 7.2.3 化学氧化法

| 氧化剂 | 适用污染物 | 原理 | 去除率 | 优点 | 局限 |
|-------|-----------|------|-------|-----|------|
| 高锰酸钾（KMnO₄） | 砷（Ⅲ）、铁（Ⅱ）、锰（Ⅱ）、有机物 | 强氧化，Mn⁷⁺→Mn⁴⁺ | AsⅢ→AsⅤ >95% | 副产物MnO₂可助凝 | 残留MnO₂需过滤 |
| 臭氧（O₃） | 有机物、色度、氰化物、Fe/Mn | 强氧化，无二次污染 | COD去除30~60% | 无残留，杀菌消毒 | 设备投资高 |
| Fenton试剂（H₂O₂+Fe²⁺） | 难降解有机物、农药、染料 | 产生·OH自由基（强氧化） | COD去除50~80% | 反应快，设备简单 | 产生大量铁泥 |
| 过氧化氢氧化 | 氰化物、硫化物 | H₂O₂直接氧化 | CN⁻去除>99% | 反应产物为水，清洁 | 对高浓度氰化物需加热 |
| 次氯酸钠/液氯 | 氰化物、有机物、脱色 | 氯氧化 | CN⁻去除>99% | 成本低，效果好 | 可能产生氯代有机物（AOX） |

**Fenton氧化最佳实践**：
- pH：3~4（酸性条件）
- H₂O₂：Fe²⁺摩尔比 = 3~10:1
- 反应时间：30~60分钟
- 后续需中和（调pH至7~8）并沉淀铁泥

**效果**：★★★★★；**用时**：氧化反应15~60分钟；**成本**：★★★☆☆

#### 7.2.4 化学还原法

| 还原剂 | 适用污染物 | 原理 | 去除效果 |
|-------|-----------|------|---------|
| 硫酸亚铁（FeSO₄） | 六价铬（Cr⁶⁺） | Cr⁶⁺ + 3Fe²⁺ → Cr³⁺ + 3Fe³⁺，随后Cr³⁺沉淀 | Cr⁶⁺→Cr³⁺ >99% |
| 亚硫酸钠（Na₂SO₃） | Cr⁶⁺、余氯 | 还原作用 | Cr⁶⁺去除>99% |
| 硫化钠（Na₂S） | 重金属、Cr⁶⁺ | 还原+沉淀双重作用 | 多重效果 |
| 零价铁（ZVI） | 氯代有机物、Cr⁶⁺、硝酸盐 | 还原脱氯/还原沉淀 | 慢速但持久 |

**Cr⁶⁺还原最佳条件**：
- pH：2~3（酸性）
- 还原剂：NaHSO₃或FeSO₄
- 反应时间：15~30分钟
- 后续调pH至7~8沉淀Cr³⁺

#### 7.2.5 吸附法

| 吸附剂 | 适用污染物 | 吸附容量 | 优点 | 局限 |
|-------|-----------|---------|-----|------|
| 颗粒活性炭（GAC） | 有机物、部分重金属、色度 | 0.1~0.5 kg/kg | 再生性能好 | 对重金属吸附容量低 |
| 粉末活性炭（PAC） | 同上，但一次性使用 | 0.05~0.3 kg/kg | 投加灵活，不需专用设备 | 污泥量大 |
| 沸石（Zeolite） | 氨氮、重金属（Pb、Cd、Cu） | 0.01~0.2 kg/kg | 对氨氮特效，天然沸石廉价 | 选择性较强 |
| 活性氧化铝 | 砷、氟、磷 | 0.01~0.05 kg/kg | 对砷特效 | 吸附容量有限 |
| 生物炭 | 重金属、有机物 | 0.05~0.3 kg/kg | 原料廉价（秸秆、木屑） | 质量不稳定 |
| 重金属捕集剂（DTCR） | Cu、Pb、Cd、Ni、Hg等 | 0.1~10 kg/kg | 适用pH宽（4~12），去除率极高 | 药剂成本较高 |

**活性炭吸附设计参数**：
- 空床接触时间（EBCT）：10~30分钟
- 吸附等温线：Langmuir或Freundlich模型
- 再生：热再生（400~800℃）或化学再生

**效果**：★★★★☆；**用时**：吸附平衡数分钟~数小时；**成本**：★★★☆☆（活性炭较贵）

#### 7.2.6 离子交换法

**原理**：利用离子交换树脂的功能基团（如-SO₃H、-COOH、-NR₃OH）与水中离子发生交换反应，从而去除污染物。

| 树脂类型 | 适用污染物 | 交换容量 | 优点 | 局限 |
|---------|-----------|---------|-----|------|
| 强酸性阳离子树脂（SAC） | 重金属阳离子（Cu²⁺、Pb²⁺、Cd²⁺、Ni²⁺等） | 1~3 eq/L | 交换容量高，再生容易 | 对Na⁺、Ca²⁺也交换（竞争性） |
| 弱酸性阳离子树脂（WAC） | 重金属（选择性更高） | 2~4 eq/L | 对H⁺选择性高，易再生 | 适用pH较窄 |
| 强碱性阴离子树脂（SBA） | 铬酸根（CrO₄²⁻）、砷酸根（AsO₄³⁻）、硝酸根 | 1~1.5 eq/L | 适用pH宽 | 有机物污染后需再生 |
| 螯合树脂 | 特定重金属（Cu、Ni、Co选择性强） | 0.5~2 eq/L | 选择性极高 | 价格昂贵 |

**效果**：★★★★★（深度处理）；**用时**：接触时间5~30分钟；**成本**：★★★★☆

#### 7.2.7 膜分离技术

| 膜类型 | 截留分子量/孔径 | 适用污染物 | 操作压力 | 优点 | 局限 |
|-------|---------------|-----------|---------|-----|------|
| 微滤（MF） | 0.1~10 μm | 悬浮物、细菌 | 0.1~0.2 MPa | 通量大，能耗低 | 不能去除溶解性污染物 |
| 超滤（UF） | 0.01~0.1 μm（1~100 kDa） | 胶体、大分子有机物、病毒 | 0.2~0.5 MPa | 无相变，节能 | 对小分子有机物/离子无效 |
| 纳滤（NF） | 0.001~0.01 μm（200~1000 Da） | 二价离子（Ca²⁺、Mg²⁺、SO₄²⁻）、有机物 | 0.5~1.5 MPa | 对二价离子选择性高 | 膜污染 |
| 反渗透（RO） | <0.001 μm（<200 Da） | 几乎所有溶解性物质 | 2~7 MPa | 脱盐率>99% | 能耗高，浓水处置 |
| 电渗析（ED） | 离子选择性 | 盐分、重金属离子 | 1~3 V/cm | 适用于高盐废水 | 对非离子有机物无效 |

**膜污染控制**：
- 预处理：混凝/过滤去除悬浮物
- 反冲洗：定期反向冲洗
- 化学清洗：酸洗（除垢）+碱洗（除有机物）

**效果**：★★★★★；**用时**：连续运行；**成本**：★★★★★（高）

#### 7.2.8 气提法/空气吹脱法

**原理**：将空气通入废水，使水中挥发性污染物（如苯、甲苯、氯仿、硫化氢、氨）转移到气相中，从而去除。

**适用污染物**：挥发性有机物（VOCs）、氨氮、硫化氢
**设计参数**：气液比（G/L）= 10~100:1，填料塔或开放池
**效果**：对苯系物去除率80~99%；**成本**：★★☆☆☆

### 7.4 土壤污染物去除技术速查表

#### 7.4.1 固化/稳定化技术（Solidification/Stabilization）

**原理**：向污染土壤中添加固化剂（水泥、石灰、粉煤灰等），通过物理包裹和化学键合作用，将污染物固定，降低其迁移性和生物可利用性。

| 固化剂 | 适用污染物 | 效果 | 成本 |
|-------|-----------|------|------|
| 水泥 | 重金属（Pb、Cd、Cr、Cu等） | 浸出浓度降低90~99% | ★★☆☆☆ |
| 石灰 | 重金属、酸性土壤 | pH升高，金属沉淀 | ★☆☆☆☆ |
| 粉煤灰+水泥 | 重金属 | 协同效应，强度更高 | ★★☆☆☆ |
| 专用稳定化药剂（如重金属螯合剂） | 多种重金属 | 浸出浓度极低 | ★★★☆☆ |

**效果**：★★★☆☆（不能去除，只能固定）；**用时**：养护7~28天；**成本**：★★☆☆☆

#### 7.4.2 土壤淋洗法

**原理**：用淋洗液（水、酸、螯合剂、表面活性剂等）冲洗污染土壤，通过溶解、络合、迁移作用将污染物从土壤固相转移到液相，然后处理淋洗废水。

| 淋洗剂 | 适用污染物 | 去除率 | 优点 | 局限 |
|-------|-----------|-------|-----|------|
| 清水 | 可溶性盐类 | 30~60% | 无二次污染 | 对重金属效果差 |
| 柠檬酸/草酸 | 重金属 | 50~80% | 可生物降解 | 成本较高 |
| EDTA（螯合剂） | 多种重金属 | 70~95% | 去除率高 | EDTA难降解，可能二次污染 |
| 表面活性剂 | 有机污染物（油类、PAHs） | 60~90% | 对有机物特效 | 需处理含表面活性剂废水 |
| 酸（HCl、HNO₃） | 重金属 | 80~95% | 去除率高 | 破坏土壤结构，需中和 |

**效果**：★★★★☆；**用时**：淋洗1~3天；**成本**：★★★☆☆

#### 7.4.3 热脱附技术（Thermal Desorption）

**原理**：加热污染土壤至足够高的温度（100~350℃），使污染物挥发，然后收集气相并处理。

| 温度范围 | 适用污染物 | 去除率 |
|---------|-----------|-------|
| 100~200℃（低温热脱附） | 汽油、苯、甲苯、二甲苯等轻组分VOCs | 95~99% |
| 200~350℃（中温热脱附） | 重油、PAHs、农药 | 90~99% |
| >350℃（高温热脱附/焚烧） | 几乎所有有机物 | >99.9% |

**效果**：★★★★★；**用时**：处理时间数小时~数天；**成本**：★★★★☆（高能耗）

#### 7.4.4 生物修复技术

| 类型 | 适用污染物 | 修复周期 | 去除率 |
|-----|-----------|---------|-------|
| 生物通风（Biosparging） | 汽油、柴油等轻组分VOCs | 6~18个月 | 70~95% |
| 生物堆（Biopile） | 石油烃、PAHs | 3~12个月 | 60~90% |
| 植物修复（Phytoremediation） | 重金属、放射性核素、部分有机物 | 2~5年 | 30~80% |
| 微生物强化修复（Bioaugmentation） | 特定有机物（如MTBE、氯代烃） | 6~24个月 | 70~99% |

**效果**：★★★☆☆；**用时**：长达数月~数年；**成本**：★☆☆☆☆（最经济）

### 7.5 7类突发环境事件场景与推荐技术组合

#### 场景1：化学品泄漏（水体）
**典型污染物**：重金属、有机溶剂、酸碱
**推荐技术组合**：
1. 先拦截（围堰、拦污坝）→ 2. 中和/沉淀（调节pH + 投加沉淀剂）→ 3. 混凝絮凝 → 4. 吸附（活性炭）→ 5. 如有有机物，考虑Fenton氧化

#### 场景2：火灾次生污染（消防废水）
**典型污染物**：多环芳烃（PAHs）、重金属（来自燃烧产物）、消防药剂残留
**推荐技术组合**：
1. 收集消防废水（不能直排）→ 2. 混凝沉淀（去除颗粒物/PAHs）→ 3. 活性炭吸附 → 4. 如有需要，Fenton氧化深度处理

#### 场景3：爆炸次生污染
**典型污染物**：爆炸产物（NOx、SO₂等酸性气体溶于水形成酸性废水）、碎片中的重金属
**推荐技术组合**：
1. 碱液中和对酸性废水 → 2. 沉淀去除重金属 → 3. 如有氰化物（来自炸药），次氯酸钠氧化

#### 场景4：废水偷排（需应急处理）
**典型污染物**：不定，需快速鉴定
**推荐技术组合**：
1. 快速检测确定污染物种类 → 2. 活性炭吸附（广谱）→ 3. 根据鉴定结果选择专项技术

#### 场景5：尾矿库泄漏
**典型污染物**：高浓度重金属（尾矿特征）、悬浮物
**推荐技术组合**：
1. 构建临时拦污坝 → 2. 自然沉淀（大颗粒先沉）→ 3. 投加絮凝剂（PAM）→ 4. 硫化物或氢氧化物沉淀去除重金属 → 5. 出水砂滤或活性炭精处理

#### 场景6：交通次生污染（如交通事故导致危化品泄漏入河）
**典型污染物**：不定（取决于运输货物）
**推荐技术组合**：
1. 立即拦截（筑坝、投加围油栏（油类））→ 2. 确定泄漏物种类 → 3. 投加相应处理药剂（如氯系灭火剂用于硫化物？不正确——需具体判断）

#### 场景7：核与辐射事件
**典型污染物**：放射性核素（Cs-137、Sr-90、I-131等）
**推荐技术组合**：
1. **不是化学处理**，而是**物理拦截和吸附** → 2. 投加改性粘土（如膨润土，对Cs特效）→ 3. 沸石吸附（对Sr、Cs）→ 4. 沉淀（如投加银离子沉淀I-131为AgI）→ 5. 土壤固定（防止扩散）

#### 8.1.2 逐条解读

**第一条**（立法目的和依据）
> 为了规范突发环境事件信息报告工作，提高环境保护主管部门应对突发环境事件的能力，依据《中华人民共和国突发事件应对法》、《国家突发公共事件总体应急预案》、《国家突发环境事件应急预案》及相关法律法规的规定，制定本办法。

**第二条**（适用范围和事件分级）
> 本办法适用于环境保护主管部门对突发环境事件的信息报告。
> 突发环境事件分为特别重大（Ⅰ级）、重大（Ⅱ级）、较大（Ⅲ级）和一般（Ⅳ级）四级。
> 核与辐射突发环境事件的信息报告按照核安全有关法律法规执行。

**第三条**（**核心条款：报告时限与程序**）——信息报告起算点确认
> 突发环境事件发生地设区的市级或者县级人民政府环境保护主管部门在**发现或者得知**突发环境事件信息后，应当立即进行核实，对突发环境事件的性质和类别做出初步认定。

**关键解读：起算时点是"发现或得知"，而非"确认"或"接报"**
- "发现"：指环保部门通过巡查、监测等手段主动发现
- "得知"：指通过举报、其他部门通报、媒体报道等途径获知
- **不是"确认"之后才开始计算时限**，而是"发现或得知"后即刻起算
- 这意味着：环保部门获知信息后，必须**立即核实**，同时开始计算报告时限

**报告时限要求**：
- **一般（Ⅳ级）/较大（Ⅲ级）**：**4小时内**向本级人民政府和上一级环保主管部门报告
- **重大（Ⅱ级）/特别重大（Ⅰ级）**：**2小时内**向本级人民政府和省级环保主管部门报告，**同时上报环境保护部**；省级环保主管部门核实后**1小时内**报告环境保护部

**第四条**（**一时无法判明等级时的升级报告**）
> 发生下列一时无法判明等级的突发环境事件，应当按照重大（II级）或者特别重大（I级）突发环境事件的报告程序上报：

**（一）对饮用水水源保护区造成或者可能造成影响的**——水源保护是最高优先级
**（二）涉及居民聚居区、学校、医院等敏感区域和敏感人群的**
**（三）涉及重金属或者类金属污染的**——重金属污染危害持久，须升级报告
**（四）有可能产生跨省或者跨国影响的**
**（五）因环境污染引发群体性事件，或者社会影响较大的**
**（六）地方人民政府环境保护主管部门认为有必要报告的其他突发环境事件**

**第五条**（上级部门主动获知信息的处理）
> 上级人民政府环境保护主管部门先于下级人民政府环境保护主管部门获悉突发环境事件信息的，可以要求下级人民政府环境保护主管部门核实并报告相应信息。

**第六条**（报告渠道）
> 向环境保护部报告突发环境事件有关信息的，应当报告总值班室，同时报告环境保护部环境应急指挥领导小组办公室。

**第七条**（向国务院报告）
> 环境保护部在接到下级重大（II级）或者特别重大（I级）突发环境事件信息后，应当及时向国务院总值班室和中共中央办公厅秘书局报告。

**第八条**（**跨区域通报——"双通道"机制的重要组成部分**）
> 突发环境事件已经或者可能涉及相邻行政区域的，事件发生地环境保护主管部门应当及时通报相邻区域同级人民政府环境保护主管部门，并向本级人民政府提出向相邻区域人民政府通报的建议。

**关键解读**：这就是"**双通道**"机制的法定依据之一：
- **纵向通道**：事件发生地→上级环保部门→更上级（直至生态环境部）
- **横向通道**：事件发生地环保部门→相邻区域同级环保部门（通报）

**第九条**（电话报告与书面报告的关系）
> 上级人民政府环境保护主管部门接到下级人民政府环境保护主管部门以电话形式报告的突发环境事件信息后，应当如实、准确做好记录，**并要求下级人民政府环境保护主管部门及时报告书面信息**。

**注意**：电话报告后**必须补充书面报告**，不能仅以电话报告为最终报告。

**第十条**（信息档案和定期报告）
> 县级以上人民政府环境保护主管部门应当建立突发环境事件信息档案，并按照有关规定向上一级人民政府环境保护主管部门报送本行政区域突发环境事件的月度、季度、半年度和年度报告以及统计情况。

**第十一条**（保密要求）
> 报告涉及国家秘密的突发环境事件信息，应当遵守国家有关保密的规定。

**第十二条**（报告分类定义）
> 突发环境事件的报告分为**初报**、**续报**和**处理结果报告**。
> - **初报**在发现或者得知突发环境事件后**首次上报**
> - **续报**在查清有关基本情况、事件发展情况后**随时上报**
> - **处理结果报告**在突发环境事件**处理完毕后上报**

**第十三条**（报告内容要求）

**初报内容**：
- 发生时间、地点
- 信息来源
- 事件起因和性质
- 基本过程
- 主要污染物和数量
- 监测数据
- 人员受害情况
- 饮用水水源地等环境敏感点受影响情况
- 事件发展趋势
- 处置情况
- 拟采取的措施以及下一步工作建议
- **并提供可能受到突发环境事件影响的环境敏感点的分布示意图**

**续报内容**：在初报基础上，报告有关处置进展情况

**处理结果报告内容**：在初报和续报基础上，报告：
- 处理措施、过程和结果
- 潜在或间接危害以及损失
- 社会影响
- 处理后的遗留问题
- 责任追究等详细情况

**第十四条**（报告形式）
> 突发环境事件信息应当采用**传真、网络、邮寄和面呈等方式书面报告**；情况紧急时，初报可通过**电话报告**，但应当及时补充书面报告。

**书面报告必备要素**：
- 报告单位
- 报告签发人
- 联系人及联系方式
- 地图、图片以及相关的多媒体资料（尽可能提供）

**第十五条**（法律责任）
> 在突发环境事件信息报告工作中**迟报、谎报、瞒报、漏报**有关突发环境事件信息的：
> - 给予**通报批评**
> - 造成后果的，对直接负责的主管人员和其他直接责任人员**依法依纪给予处分**
> - 构成犯罪的，**移送司法机关依法追究刑事责任**

**第十六条**（解释权）
> 本办法由环境保护部解释。

**第十七条**（施行日期）
> 自2011年5月1日起施行。

### 8.2 "双通道"报告机制的具体操作

#### 8.2.1 双通道的定义

**双通道**是指突发环境事件信息报告的两个并行渠道：

| 通道 | 方向 | 法律依据 | 时限要求 |
|-----|------|---------|---------|
| **纵向通道**（上下级报告） | 事件发生地环保部门 → 本级政府 + 上级环保部门 | 17号令第三条 | 2小时/4小时 |
| **横向通道**（跨区域通报） | 事件发生地环保部门 → 相邻区域同级环保部门 | 17号令第八条 | 及时通报（无明确时限，但应立即） |

#### 8.2.2 省级3小时双通道要求

**湖南省的实践**（以娄底为例）：
- 国家17号令要求：重大/特别重大事件，**2小时内**报告
- 湖南省额外要求： some contexts mention "3小时双通道"——这是指**向省级政府和生态环境部同时报告**的"双通道"，而非跨行政区域的横向通报

**"3小时双通道"的具体含义**（部分省份的实践）：
- 重大事件发生后，须在**3小时内**同时完成两个报告：
  1. 向省级人民政府报告
  2. 向生态环境部报告（通过省级环保部门转报或直接报告）
- 这是**比国家17号令更严格**的要求（国家要求2小时报告省级，省级1小时内报告生态环境部，合计3小时）

#### 8.2.3 无法判明等级时的报告要求（17号令第四条）

当事件等级一时无法判明时，**必须按照重大（Ⅱ级）或特别重大（Ⅰ级）的报告程序上报**，即：
- **2小时内**报告本级政府和省级环保部门
- **同时上报环境保护部**
- 这相当于"**就高不就低**"原则，确保不漏报重大风险

**适用情形**（17号令第四条列出的6种）：
1. 影响饮用水水源保护区
2. 涉及居民聚居区、学校、医院等敏感区
3. 涉及重金属或类金属污染
4. 可能跨省或跨国影响
5. 引发群体性事件或社会影响较大
6. 环保部门认为有必要报告的其他情形

---

### 8.3 与省级3小时双通道要求对比分析

| 项目 | 国家17号令要求 | 部分省份（如湖南）的更严要求 |
|-----|--------------|--------------------------|
| 重大/特别重大事件报告时限 | 2小时内报告省级，省级1小时内报告生态环境部（**合计3小时**） | 要求**3小时内同时完成**双通道报告 |
| 一般/较大事件报告时限 | 4小时内报告 | 部分省份缩短为2小时 |
| 跨区域通报 | 要求"及时通报"，无明确时限 | 要求**立即通报**，最好不超过1小时 |
| 书面报告补充 | 电话报告后及时补充书面 | 电话报告后**1小时内**书面报告 |

**关键结论**：
- 国家17号令是**最低要求**，各省可制定更严格的规定
- "双通道"在国家层面指**纵向+横向**；在省级实践中也可能指**同时报告政府和上级部门**
- 实际操作中，应遵循"**就高不就低、就严不就宽**"原则

### 9.4 污染团运移时间计算方法

#### 9.4.1 基本公式

**污染团运移时间（T）** = 距离（L）÷ 流速（V）

**流速（V）计算方法**：
- 曼宁公式：V = (1/n) × R^(2/3) × S^(1/2)
  - n：河道糙率（混凝土衬砌河道约0.015，天然河道0.03~0.05）
  - R：水力半径（m）
  - S：河道底坡（m/m）

#### 9.4.2 实际修正系数

| 影响因素 | 修正系数 | 说明 |
|---------|---------|------|
| 河道弯曲度 | 1.1~1.3 | 实际流程 > 直线距离 |
| 支流汇入 | 0.8~1.2 | 支流汇入可能改变流速 |
| 河道障碍物（堰、坝） | +30%~+100% | 障碍物减缓流速 |
| 流量变化（洪水/枯水） | 0.3~3.0 | 流量大则流速快 |
| 温度（影响化学反应） | - | 不涉及运移时间 |

**经验公式（快速估算）**：
- T（小时）≈ L（km）÷ [V（m/s）× 3.6]
- 例如：孙水河上距离50 km，流速0.5 m/s，则T ≈ 50 ÷ (0.5×3.6) ≈ **27.8小时**

#### 9.4.3 应急决策中的应用

**黄金时间窗口** = 污染团到达敏感目标（如取水口）前的剩余时间
- 若剩余时间 > 6小时：可调动大型设备，筑坝拦截
- 若剩余时间 2~6小时：投加药剂（絮凝剂、活性炭）
- 若剩余时间 < 2小时：紧急停止取水，启动备用水源

### 9.5 典型处置方案

#### 9.5.1 拦污截污
- **构筑临时拦污坝**：用沙袋、土工膜在狭窄河段筑坝
- **投加絮凝剂**：在污染物进入主河道前，在支流或上游投加PAC/PAM，使污染物沉淀
- **投加活性炭**：在取水口上游投加粉末活性炭，吸附有机物

#### 9.5.2 分流引流
- **利用分流堰**：将污染河水引入支流或滞洪区
- **利用引水式电站**：将上游清水引入发电渠道，绕过污染段

#### 9.5.3 调蓄降污
- **水库调度**：上游水库放水稀释（需权衡：放水可能加速污染物向下游传输）
- **闸坝调控**：关闭闸坝，将污染物截留在可控区段，再进行处理

**成果**：成功将污染物控制在局部河段，保障了渌水下游河段水质和饮水安全

#### 9.7.2 对娄底（湘黔边界）的启示

娄底市西部（新化县、冷水江市）与**贵州省铜仁市**接壤，资水上游可能涉及跨湘黔界污染传输。建议：
1. 建立湘黔资水流域应急联动机制
2. 定期联合演练
3. 共享水文、水质、风险源信息

### 10.1 无机酸类

#### ① 硫酸（Sulfuric Acid）
- **CAS号**：7664-93-9
- **分子式**：H₂SO₄
- **分子量**：98.08
- **外观与气味**：无色至淡黄色油状液体，无嗅（工业品有刺激性气味）
- **密度**：1.84 g/cm³（98%硫酸，与水比较：>1，沉于水底）
- **熔点**：10.5℃
- **沸点**：330℃（分解）
- **闪点**：不燃
- **自燃点**：不燃
- **爆炸极限**：不燃（助燃）
- **蒸气压**：0.13 kPa（145.8℃）
- **水溶性**：完全混溶（放热剧烈）
- **IDLH**：10 mg/m³（以H₂SO₄雾计）
- **PEL/STEL/TLV-TWA**：
  - OSHA PEL-TWA：1 mg/m³
  - ACGIH TLV-TWA：1 mg/m³（以SO₄²⁻计）
- **LC₅₀/LD₅₀**：
  - 口服LD₅₀（大鼠）：2140 mg/kg（浓H₂SO₄）
- **主要危险类别**：腐蚀性（第8类），强氧化性（与有机物接触可致燃烧）
- **不相容物质**：碱类、碱金属、水（稀释时必须将酸加入水中，严禁将水加入浓酸）、还原剂、易燃物
- **泄漏应急处置**：
  - 小量泄漏：用砂土、干燥石灰或苏打灰混合，然后用大量水冲洗
  - 大量泄漏：构筑围堤，用石灰中和后收集处理
  - **严禁将水直接喷入浓H₂SO₄**（可能沸溅）
- **灭火剂选择**：不可燃，但需用水冷却容器；周围火灾用泡沫、干粉、CO₂

#### ② 盐酸（Hydrochloric Acid）
- **CAS号**：7647-01-0（HCl气体）；盐酸是HCl水溶液
- **分子式**：HCl
- **分子量**：36.46
- **外观与气味**：无色或微黄色液体，有刺激性酸味
- **密度**：约1.2 g/cm³（37% HCl）
- **熔点**：-35℃（37% HCl）
- **沸点**：57℃（37% HCl，共沸）
- **闪点**：不燃
- **蒸气压**：21.3 kPa（21.1℃，37% HCl）
- **水溶性**：完全混溶（HCl气体极易溶于水）
- **IDLH**：50 ppm（HCl气体）
- **PEL/STEL/TLV-TWA**：
  - OSHA PEL-TWA：5 ppm（7 mg/m³）
  - ACGIH TLV-TWA：2 ppm（时间加权平均）
  - STEL：5 ppm
- **LC₅₀**：约3124 ppm（大鼠，1小时）
- **主要危险类别**：腐蚀性（第8类）
- **不相容物质**：碱类、活泼金属（产生H₂）、氧化剂
- **泄漏应急处置**：用碱（石灰、苏打灰）中和，大量水冲洗
- **灭火剂选择**：不燃，周围火灾用适合灭火剂

#### ③ 硝酸（Nitric Acid）
- **CAS号**：7697-37-2（HNO₃）
- **分子式**：HNO₃
- **分子量**：63.01
- **外观与气味**：无色至淡黄色液体，有刺激性酸味，见光易分解变黄（生成NO₂）
- **密度**：1.51 g/cm³（68% HNO₃）
- **熔点**：-42℃（68% HNO₃）
- **沸点**：122℃（68% HNO₃，部分分解）
- **闪点**：不燃（但助燃）
- **蒸气压**：6.4 kPa（20℃，浓HNO₃易挥发NO₂）
- **水溶性**：完全混溶
- **IDLH**：25 ppm（HNO₃雾）
- **PEL/STEL/TLV-TWA**：
  - OSHA PEL-TWA：2 ppm（5 mg/m³）[C（ ceiling限值）]
  - ACGIH TLV-TWA：0.5 ppm
- **LC₅₀**：1260 mg/m³（大鼠，1小时）
- **主要危险类别**：氧化性腐蚀性液体（第8类+氧化剂）
- **不相容物质**：有机物（可引发燃烧）、还原剂、金属粉末（可引发爆炸）
- **泄漏应急处置**：用大量水冲洗，用碱（石灰）中和；**注意：浓HNO₃与有机物接触可起火**
- **灭火剂选择**：不燃（助燃），周围火灾用水、泡沫、干粉、CO₂

### 10.3 有毒气体类

#### ⑤ 氯气（Chlorine）
- **CAS号**：7782-50-5
- **分子式**：Cl₂
- **分子量**：70.90
- **外观与气味**：黄绿色气体，有强烈刺激性气味（漂白水味）
- **密度**：3.21 kg/m³（气体，空气=1.29，比空气重约2.5倍）
- **熔点**：-101℃
- **沸点**：-34℃
- **闪点**：不燃（助燃）
- **蒸气压**：677 kPa（20℃）
- **水溶性**：可溶（1体积水溶解约2体积Cl₂），生成HClO/HCl
- **IDLH**：10 ppm（中国标准29 mg/m³；美国NIOSH IDLH = 10 ppm）
- **PEL/STEL/TLV-TWA**：
  - OSHA PEL-TWA：1 ppm（3 mg/m³）
  - ACGIH TLV-TWA：0.5 ppm
  - STEL：1 ppm
- **LC₅₀**：293 ppm（大鼠，1小时）
- **主要危险类别**：毒性气体（第2.3类）+ 氧化性（第5.1类）
- **不相容物质**：氢气（可爆炸）、氨气（产生氯化铵烟雾）、易燃物
- **泄漏应急处置**：
  - 疏散下风向人员（Cl₂比空气重，沿地面扩散）
  - 用喷雾水枪稀释（产生次氯酸和盐酸，但可降低浓度）
  - 应急人员佩戴正压自给式呼吸器（SCBA）和A级防护服
  - 用碱液（NaOH或Na₂CO₃溶液）喷淋吸收
- **灭火剂选择**：不燃（助燃），周围火灾先切断氯源，然后用水、泡沫等灭火

**ERPG/AEGL参考**：
- ERPG-1：0.5 ppm（1小时）
- ERPG-2：3 ppm（1小时）
- ERPG-3：20 ppm（1小时）

#### ⑥ 氨气/液氨（Ammonia）
- **CAS号**：7664-41-7
- **分子式**：NH₃
- **分子量**：17.03
- **外观与气味**：无色气体，有强烈刺激性气味（厕所味/腥味）
- **密度**：0.73 kg/m³（气体，比空气轻）
- **熔点**：-78℃（升华）
- **沸点**：-33℃
- **闪点**：气体，易燃
- **爆炸极限**：15~28% vol（LEL~UEL，范围宽，但LEL较高）
- **蒸气压**：857 kPa（20℃，液氨）
- **水溶性**：极易溶（1:700体积比），生成NH₄OH
- **IDLH**：300 ppm
- **PEL/STEL/TLV-TWA**：
  - OSHA PEL-TWA：50 ppm（35 mg/m³）
  - ACGIH TLV-TWA：25 ppm
  - STEL：35 ppm
- **LC₅₀**：2000 ppm（大鼠，1小时）—— 氨的LC₅₀相对较高，但低浓度即有强烈刺激性
- **主要危险类别**：毒性气体（第2.3类）+ 易燃气体（第2.1类）
- **不相容物质**：氯气（产生氯化铵，剧烈反应）、酸类（中和放热）、铜（应力腐蚀）
- **泄漏应急处置**：
  - 液氨泄漏：喷水雾稀释，产生铵水后收集处理
  - 氨气云：疏散下风向人员（NH₃比空气轻，向上扩散，但低温氨云初期密度大）
  - 用稀酸（如稀硫酸）喷淋吸收
- **灭火剂选择**：大量水（冷却容器）、干粉、CO₂；**注意**：氨火可以用大量水扑灭（氨极易溶于水）

#### ⑦ 硫化氢（Hydrogen Sulfide）
- **CAS号**：7783-06-4
- **分子式**：H₂S
- **分子量**：34.08
- **外观与气味**：无色气体，低浓度时有臭鸡蛋味，高浓度时嗅觉麻痹（**闻不到**）
- **密度**：1.54 kg/m³（气体，比空气重约20%）
- **熔点**：-82℃
- **沸点**：-60℃
- **闪点**：气体，易燃
- **爆炸极限**：4.3~46% vol（LEL~UEL）
- **蒸气压**：2026 kPa（20℃，液化）
- **水溶性**：微溶（1:4体积比），溶于水生成弱酸H₂S
- **IDLH**：100 ppm（142 mg/m³）—— **极低！**
- **PEL/STEL/TLV-TWA**：
  - OSHA PEL-TWA：20 ppm（28 mg/m³）[Ceiling：50 ppm]
  - ACGIH TLV-TWA：1 ppm（10 mg/m³）[注意：ACGIH标准非常严格]
  - STEL：5 ppm（中国GBZ2.1）
- **LC₅₀**：~600 ppm（大鼠，1小时）—— 但人类在>1000 ppm下暴露数秒即可猝死
- **主要危险类别**：毒性气体（第2.3类）+ 易燃气体（第2.1类）
- **不相容物质**：强氧化剂（可引发爆炸）
- **泄漏应急处置**：
  - **极度危险**：H₂S是"电击型"窒息性气体，高浓度下数秒致死
  - 应急人员必须佩戴SCBA，且至少2人同行
  - 用喷雾水枪稀释（H₂S微溶于水）
  - 用次氯酸钠溶液或过氧化氢溶液喷淋氧化处理
- **灭火剂选择**：切断气源后，用干粉、CO₂、水灭火

**特别注意**：
- H₂S浓度 > 100 ppm时，嗅觉神经迅速麻痹，受害者"闻不到"——这是H₂S最危险的特性之一
- "电击型死亡"：> 1000 ppm时，呼吸1~2次即意识丧失，数分钟内死亡

#### ⑧ 氰化氢（Hydrogen Cyanide）
- **CAS号**：74-90-8
- **分子式**：HCN
- **分子量**：27.03
- **外观与气味**：无色气体或液体，有淡淡的苦杏仁味（**约40~60%的人无法闻到苦杏仁味**，因遗传差异）
- **密度**：0.94 kg/m³（气体，略轻于空气）
- **熔点**：-14℃（液体）
- **沸点**：26℃
- **闪点**：-18℃（极易燃）
- **爆炸极限**：5.6~40% vol
- **蒸气压**：81 kPa（20℃）
- **水溶性**：无限混溶
- **IDLH**：50 ppm（HCN气体）
- **PEL/STEL/TLV-TWA**：
  - OSHA PEL-TWA：10 ppm（11 mg/m³）[Ceiling：10 ppm]
  - ACGIH TLV-TWA：4.7 ppm（5 mg/m³）
- **LC₅₀**：~500 ppm（大鼠，1小时）
- **主要危险类别**：毒性气体（第2.3类）+ 极易燃气体（第2.1类）
- **不相容物质**：强酸（产生HCN气体）、强氧化剂
- **泄漏应急处置**：
  - 剧毒且易燃，须立即疏散
  - 用次氯酸钠或过氧化氢溶液处理（氧化为低毒氰酸盐）
  - 解毒剂：亚硝酸异戊酯（吸入）、硫代硫酸钠（静脉注射）
- **灭火剂选择**：干粉、CO₂、泡沫；用水冷却容器

#### ⑮ 柴油（Diesel Fuel）
- **CAS号**：68476-34-6（混合物）

- **密度**：0.82~0.86 g/cm³

- **沸点**：170~390℃
- **闪点**：>55℃（较安全，但不容忽视）
- **爆炸极限**：0.6~7.5% vol（柴油蒸气，需加热才能产生足够蒸气）
- **水溶性**：不溶
- **IDLH**：无明确规定（按烃类处理）
- **PEL/STEL/TLV-TWA**：无专门标准
- **主要危险类别**：易燃液体（第3类，闪点较高）
- **不相容物质**：强氧化剂
- **泄漏应急处置**：与汽油类似，但柴油粘度高，较难处理；用吸油棉、砂土吸收
- **灭火剂选择**：泡沫、干粉、CO₂、水雾

### 10.5 压缩气体/液化气体

#### ⑯ 天然气/甲烷（Methane）
- **CAS号**：74-82-8
- **分子式**：CH₄
- **分子量**：16.04
- **外观与气味**：无色无味气体（商用天然气添加硫醇类臭剂以便泄漏 detection）
- **密度**：0.72 kg/m³（气体，比空气轻）
- **熔点**：-182℃
- **沸点**：-162℃（液化天然气LNG）
- **闪点**：气体，易燃
- **爆炸极限**：5.0~15% vol
- **蒸气压**：不可液化（常温）
- **水溶性**：微溶
- **IDLH**：无（主要危害是窒息和爆炸，而非毒性）
- **PEL/STEL/TLV-TWA**：无专门毒性标准（按可燃气体处理）
- **主要危险类别**：易燃气体（第2.1类），高压气体
- **不相容物质**：强氧化剂（助燃）
- **泄漏应急处置**：
  - 切断气源
  - 疏散人员
  - 禁止一切火源
  - 用喷雾水枪稀释（CH₄比空气轻，会向上扩散）
- **灭火剂选择**：切断气源后，用干粉、CO₂；如无法切断气源，允许可控燃烧（防止气体积聚）

#### ⑰ 液化石油气（LPG）
- **CAS号**：68476-85-7（混合物，主要成分：丙烷+丁烷）
- **主要成分**：丙烷（C₃H₈）、丁烷（C₄H₁₀）
- **分子量**：约44~58（平均）
- **外观与气味**：无色气体（液化后为无色液体），有添加臭剂（硫醇）
- **密度**：1.55~2.0 kg/m³（气相，比空气重！——这是LPG比天然气更危险的原因之一）
- **熔点**：-188℃（丙烷）/-138℃（丁烷）
- **沸点**：-42℃（丙烷）/-0.5℃（丁烷）
- **闪点**：气体，极易燃
- **爆炸极限**：丙烷 2.1~9.5%；丁烷 1.8~8.4%
- **蒸气压**：约800~1200 kPa（20℃，LPG钢瓶压力）
- **水溶性**：微溶
- **IDLH**：无专门标准（按易燃气体处理）
- **主要危险类别**：易燃气体（第2.1类），高压液化气体
- **不相容物质**：强氧化剂
- **泄漏应急处置**：
  - **严禁一切火源**（包括静电）
  - LPG蒸气比空气重，会在低洼处积聚
  - 疏散下风向和下坡向人员
  - 用喷雾水枪稀释（但不能像NH₃那样有效溶解）
  - 如可能，将钢瓶移至安全地点
- **灭火剂选择**：干粉、CO₂；如钢瓶泄漏无法制止，允许受控燃烧

### 10.6 其他有机危化品（摘要格式）

#### ⑫ 苯（Benzene）
- CAS：71-43-2｜分子量：78.11｜密度：0.88｜沸点：80℃｜闪点：-11℃｜爆炸极限：1.2~8.6%｜IDLH：500 ppm｜TLV-TWA：0.5 ppm（**致癌物**）｜水溶性：微溶｜主要危险：易燃+致癌｜灭火剂：泡沫、干粉、CO₂

#### ⑬ 甲醛（Formaldehyde）
- CAS：50-00-0｜分子量：30.03｜沸点：-19℃（气体，通常37%水溶液即福尔马林）｜闪点：50℃（溶液）｜IDLH：20 ppm｜TLV-TWA：0.1 ppm（**致癌物**）｜主要危险：毒性+易燃｜灭火剂：水、泡沫、干粉、CO₂

#### ⑱ 丙烯腈（Acrylonitrile）
- CAS：107-13-1｜分子量：53.06｜沸点：77℃｜闪点：-1℃｜爆炸极限：3.0~17%｜IDLH：100 ppm｜TLV-TWA：2 ppm（皮肤吸收）｜主要危险：易燃+剧毒+致癌｜不相容：强酸、强碱（产生HCN）

#### ⑲ 苯胺（Aniline）
- CAS：62-53-3｜分子量：93.13｜沸点：184℃｜闪点：70℃｜IDLH：100 ppm｜TLV-TWA：5 ppm（可经皮肤吸收）｜主要危险：毒性（高铁血红蛋白血症）｜灭火剂：水雾、泡沫、干粉、CO₂

#### ⑳ 苯酚（Phenol）
- CAS：108-95-2｜分子量：94.11｜沸点：182℃｜闪点：79℃｜IDLH：250 ppm｜TLV-TWA：5 ppm（皮肤吸收）｜主要危险：腐蚀性+毒性｜灭火剂：水雾、泡沫、干粉、CO₂

#### ㉑ 二硫化碳（Carbon Disulfide）
- CAS：75-15-0｜分子量：76.14｜沸点：46℃｜闪点：-30℃（极易燃）｜爆炸极限：1.3~50%（极宽）｜IDLH：500 ppm｜TLV-TWA：1 ppm｜主要危险：极易燃+剧毒｜灭火剂：水雾、泡沫（严禁用CO₂——CS₂与CO₂可能反应）

#### ㉒ 环氧乙烷（Ethylene Oxide）
- CAS：75-21-8｜分子量：44.05｜沸点：10.7℃（需加压储存）｜闪点：-20℃｜爆炸极限：3.0~100%（**极度危险——与空气混合几乎全程可燃**）｜IDLH：800 ppm｜TLV-TWA：1 ppm（致癌）｜主要危险：极易燃+爆炸+致癌+有毒｜灭火剂：切断气源，用水冷却容器

#### ㉓ 氟化氢（Hydrogen Fluoride）
- CAS：7664-39-3｜分子量：20.01｜沸点：19.5℃（液体，或气体）｜IDLH：30 ppm（**极高毒性**）｜TLV-TWA：0.5 ppm｜主要危险：剧毒+腐蚀性｜泄漏处置：用石灰（Ca(OH)₂）或碳酸钠中和｜灭火剂：不可燃（但助燃）

#### ㉔ 光气（Phosgene）
- CAS：75-44-5｜分子量：98.98｜沸点：8.2℃（气体）｜IDLH：2 ppm（**极高毒性——"双肺毒气"**）｜TLV-TWA：0.02 ppm（0.08 mg/m³）｜主要危险：剧毒（肺水肿）｜历史：一战化学武器｜灭火剂：不燃（但本身不可燃）

#### ㉕ 三氯化磷（Phosphorus Trichloride）
- CAS：7719-12-2｜分子量：137.33｜沸点：76℃｜遇水剧烈反应生成HCl和亚磷酸｜主要危险：腐蚀性+遇水产生有毒气体｜泄漏处置：用干燥砂土覆盖，用碱液中和（严禁用水——会剧烈反应产生HCl）

### 10.7 重点监管的危险化学品（摘要）

#### ㉖ 黄磷（White Phosphorus）
- CAS：7723-14-0｜分子量：123.90｜沸点：281℃｜**自燃点：30℃**（在空气中自燃！）｜必须储存在水中｜主要危险：自燃+剧毒（经口LD₅₀约3 mg/kg）｜灭火：必须用大量水（保持湿润），用湿砂覆盖，严禁用干粉（可能助燃）

#### ㉗ 锑（三氧化二锑，Antimony Trioxide）
- CAS：1309-64-4｜分子量：291.52｜主要用途：阻燃剂原料｜**健康危害**：可疑致癌物（IARC 2B类）｜可溶性锑化合物有毒｜去除技术：铁盐混凝沉淀（pH 6~8），去除率70~90%

#### ㉘ 砷（三氧化二砷，Arsenic Trioxide）
- CAS：1327-53-3｜分子量：197.84｜**剧毒**（砒霜！）｜LD₅₀：约14 mg/kg（口服，人）｜水溶性：微溶（AS₂O₃可溶，生成亚砷酸）｜去除技术：铁盐共沉淀（pH 7~9），最佳pH 8~9，去除率>95%

#### ㉙ 铬酸酐（Chromium Trioxide）
- CAS：1333-82-0｜分子量：99.99｜Cr⁶⁺化合物，**剧毒+致癌**｜LD₅₀：约80 mg/kg（口服，CrO₃）｜去除技术：先还原（NaHSO₃或FeSO₄，pH 2~3）为Cr³⁺，然后沉淀（pH 7~9）

#### ㉚ 氰化钠（Sodium Cyanide）
- CAS：143-33-9｜分子量：49.01｜**剧毒**（CN⁻离子）｜LD₅₀：约6.4 mg/kg（口服，人）｜水溶性：极易溶｜遇酸产生HCN气体｜去除技术：碱式氯化法（次氯酸钠氧化CN⁻为CNO⁻，然后进一步氧化为CO₂+N₂）或硫化物沉淀法

### B. 常见危化品应急处置要点速查

| 化学品 | 首要措施 | 禁忌 |
|-------|---------|------|
| 硫酸 | 用碱中和，大量水冲洗（**酸入水**） | 严禁水入酸 |
| 盐酸 | 用碱中和，通风（排气HCl气体） | - |
| 硝酸 | 用碱中和，防止接触有机物 | 严禁与有机物接触 |
| 氢氧化钠 | 用稀酸中和，大量水冲洗 | 避免接触铝 |
| 氯气 | 疏散下风向，碱液吸收 | - |
| 氨气 | 疏散，水雾稀释，酸液吸收 | - |
| 硫化氢 | **立即撤离**（SCBA必备），氧化处理 | 严禁单人作业 |
| 氰化氢 | 立即撤离，次氯酸钠处理，解毒剂 | - |
| 汽油/柴油 | 围油栏，泡沫覆盖，吸油棉 | 严禁用水直射 |
| LPG/天然气 | 切断气源，禁止火源 | 严禁盲目灭火（可能致积聚爆炸） |
