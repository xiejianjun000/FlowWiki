# VOCs

## 一句话解释

VOCs（Volatile Organic Compounds，挥发性有机物）是指参与大气光化学反应的有机化合物，或者根据规定确定的有机化合物。主要包括非甲烷总烃、苯系物（苯、甲苯、二甲苯）、醇类、酮类、酯类等。VOCs是大气污染防治的重点管控对象，既是臭氧和PM2.5的前体物，又可能对人体健康造成危害。

## 定义与法律依据

## 核心内容

| 标准编号 | 标准名称 | 主要内容 |
|----------|----------|----------|
| GB 37822 | 挥发性有机物无组织排放控制标准 | 厂界和企业边界无组织排放控制 |
| GB 16297 | 大气污染物综合排放标准 | 有组织排放浓度和速率限值 |
| GB 3095 | 环境空气质量标准 | 臭氧前体物控制（非直接限值） |
| GB 31571 | 石油化学工业污染物排放标准 | 石化行业VOCs排放限值 |
| GB 37824 | 涂料、油墨及胶粘剂工业大气污染物排放标准 | 涂料行业VOCs排放限值 |

| 行业 | 排放环节 | 特征污染物 |
|------|----------|-----------|
| 工业涂装 | 喷漆、烘干、流平 | 苯系物、非甲烷总烃 |
| 石油化工 | 储罐、装载、管道泄漏 | 苯系物、烷烃 |
| 印刷 | 印刷、烘干 | 苯系物、醇类 |
| 制鞋 | 胶粘剂使用 | 苯、甲苯、二甲苯 |
| 电子制造 | 清洗、涂覆 | 醇类、酮类 |
| 包装印刷 | 印刷、复合 | 苯系物、酯类 |

- **密闭收集**：产生含VOCs废气的生产和服务活动应在密闭空间或设备中进行（大气法§45）
- **台账管理**：工业涂装企业须记录原料、辅料使用量、VOCs含量、废弃量、去向
- **低VOCs原料替代**：鼓励使用低毒、低挥发性有机溶剂
- **油气回收**：储油储气库、加油加气站须安装油气回收装置
- **泄漏检测与修复**：石化等行业须开展泄漏检测与修复

- **活性炭吸附**：适用于低浓度VOCs废气
- **蓄热式热氧化（RTO）**：适用于中高浓度废气
- **催化燃烧（CO）**：适用于中低浓度废气
- **冷凝回收**：适用于高浓度有回收价值的VOCs
- **生物净化**：适用于低浓度、水溶性好的VOCs

## 企业合规要点

- 企业应根据自身行业特点，建立健全与本概念相关的内部管理制度。
- 定期开展合规自查，确保操作过程符合法律法规及许可证要求。
- 保留完整台账、监测记录和佐证材料，便于监管核查与审计。

[[sources/laws/eco_import/大气污染防治法.md|大气污染防治法]]（补充关联）

## 常见误区

- 误区：认为相关合规要求只适用于大型企业。实际上，中小企业同样负有法定环境保护义务。
- 误区：认为只要没有行政处罚记录就合规。合规管理不仅关注结果，也关注过程控制和持续改进。
