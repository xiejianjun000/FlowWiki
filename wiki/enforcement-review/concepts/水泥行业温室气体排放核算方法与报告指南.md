# 水泥行业温室气体排放核算方法与报告指南

**文件编号**：CETS—AG—02.01—V01—2024
**发布单位**：生态环境部
**实施日期**：2024年1月1日
**适用范围**：全国碳排放权交易市场水泥行业重点排放单位

---

## 一、适用范围

本指南适用于纳入全国碳排放权交易市场的水泥行业重点排放单位的温室气体排放核算与报告工作。

### 1.1 适用主体

- 水泥熟料生产企业
- 水泥粉磨站企业（购入熟料进行粉磨）
- 水泥制品生产企业（如混凝土搅拌站，部分适用）
- 拥有水泥窑协同处置设施的企业

### 1.2 不适用范围

- 纯石灰石开采企业
- 纯石膏板生产企业
- 砖瓦生产企业（另行执行建材行业指南）

---

## 二、核算边界

### 2.1 组织边界

水泥企业应核算其拥有或控制的所有生产设施的温室气体排放。

- **拥有**：企业具有所有权的生产设施
- **控制**：企业具有运营控制权的生产设施

### 2.2 运行边界

核算边界应包括水泥生产的直接排放和间接排放。

#### 2.2.1 直接排放（范围1）

1. **化石燃料燃烧排放**：窑头窑尾锅炉、烘干机、余热发电锅炉等燃烧设备化石燃料燃烧产生的CO₂排放
2. **工业生产过程排放**：
   - 碳酸盐分解排放（石灰石、白云石等原料分解）
   - 熟料煅烧过程中的燃料燃烧排放（已计入燃烧排放）
   - 生料中有机碳氧化排放
   - 水泥窑协同处置废物产生的排放
3. **逸散排放**：设备密封点泄漏等产生的CH₄排放（占比很小，可忽略）

#### 2.2.2 间接排放（范围2）

1. **购入使用电力排放**：企业购入的电力产生的CO₂排放
2. **购入使用蒸汽排放**：企业购入的蒸汽产生的CO₂排放（如适用）

### 2.3 生产工序边界

水泥生产主要工序包括：

| 工序 | 主要排放源 | 说明 |
|------|-----------|------|
| 原料准备 | 破碎机、烘干机燃料燃烧 | 原料破碎、烘干 |
| 生料制备 | 生料磨、烘干机 | 生料粉磨、烘干 |
| 熟料煅烧 | 预热器、分解炉、回转窑、冷却机 | 碳酸盐分解、燃料燃烧 |
| 水泥粉磨 | 水泥磨、烘干机 | 熟料+石膏+混合材粉磨 |
| 包装发运 | 包装机、装车机 | 水泥包装、发运 |
| 余热发电 | 余热锅炉、汽轮机 | 利用余热发电，抵扣间接排放 |

## 三、核算方法

### 3.1 总体方法

水泥行业温室气体排放核算采用**排放因子法**与**物料平衡法**相结合的方法。

### 3.2 核算公式

```
E_total = E_combustion + E_process + E_indirect - E_waste_heat
```

其中：
- `E_total`：温室气体排放总量，单位：吨CO₂当量（tCO₂e）
- `E_combustion`：化石燃料燃烧排放量，单位：tCO₂
- `E_process`：工业生产过程排放量，单位：tCO₂
- `E_indirect`：间接排放量，单位：tCO₂
- `E_waste_heat`：余热发电量抵扣的间接排放量，单位：tCO₂

### 3.3 化石燃料燃烧排放核算

#### 3.3.1 方法一：元素碳含量法（推荐）

```
E_combustion = Σ (FC_i × C_ar,i × OF_i × 44/12)
```

其中：
- `FC_i`：第i种化石燃料的消耗量，单位：吨（t）或万立方米（10⁴Nm³）
- `C_ar,i`：第i种化石燃料的收到基元素碳含量，单位：吨碳/吨燃料（tC/t）
- `OF_i`：第i种化石燃料的碳氧化率，单位：%
- `44/12`：碳转化为二氧化碳的系数

#### 3.3.2 方法二：低位发热量法

```
E_combustion = Σ (FC_i × NCV_i × EF_i × OF_i × 44/12)
```

其中：
- `NCV_i`：第i种化石燃料的收到基低位发热量，单位：GJ/t或GJ/10⁴Nm³
- `EF_i`：第i种化石燃料的单位热值含碳量，单位：tC/GJ

### 3.4 工业生产过程排放核算

#### 3.4.1 碳酸盐分解排放

方法一：熟料产量法（推荐）

```
E_carbonate = P_clinker × EF_clinker
```

其中：
- `P_clinker`：熟料产量，单位：t
- `EF_clinker`：熟料排放因子，单位：tCO₂/t熟料

方法二：原料消耗量法

```
E_carbonate = Σ (M_raw,i × EF_raw,i)
```

其中：
- `M_raw,i`：第i种碳酸盐原料消耗量，单位：t
- `EF_raw,i`：第i种原料的CO₂排放因子，单位：tCO₂/t

#### 3.4.2 生料中有机碳氧化排放

```
E_organic = M_raw × C_organic × OF_organic × 44/12
```

其中：
- `M_raw`：生料消耗量，单位：t
- `C_organic`：生料中有机碳含量，单位：tC/t
- `OF_organic`：有机碳氧化率，单位：%

#### 3.4.3 水泥窑协同处置废物排放

```
E_waste = M_waste × EF_waste
```

其中：
- `M_waste`：协同处置废物量，单位：t
- `EF_waste`：废物排放因子，单位：tCO₂/t

### 3.5 间接排放核算

```
E_indirect = (AD_electricity - AD_waste_heat) × EF_electricity
```

其中：
- `AD_electricity`：购入使用电量，单位：MWh
- `AD_waste_heat`：余热发电量，单位：MWh
- `EF_electricity`：电力排放因子，单位：tCO₂/MWh

## 四、温室气体种类

本指南核算的温室气体包括：

| 序号 | 温室气体种类 | 化学分子式 | 全球增温潜势（GWP） | 主要来源 |
|------|-------------|-----------|---------------------|----------|
| 1 | 二氧化碳 | CO₂ | 1 | 化石燃料燃烧、碳酸盐分解、间接排放 |
| 2 | 甲烷 | CH₄ | 28 | 逸散排放（占比很小，可忽略） |
| 3 | 氧化亚氮 | N₂O | 265 | 化石燃料燃烧（少量） |

**说明**：水泥行业以CO₂排放为主，占总排放量的99%以上。其中碳酸盐分解排放约占60-70%，燃料燃烧排放约占25-35%，间接排放约占5-10%。

## 五、排放源分类

### 5.1 直接排放源

#### 5.1.1 化石燃料燃烧排放

| 排放源 | 燃料类型 | 燃烧设备 |
|--------|---------|----------|
| 窑头燃烧 | 煤粉、煤矸石、石油焦、天然气等 | 回转窑窑头燃烧器 |
| 分解炉燃烧 | 煤粉、煤矸石、石油焦、天然气等 | 分解炉燃烧器 |
| 烘干机燃烧 | 煤粉、重油、天然气、高炉煤气等 | 原料烘干机、煤磨烘干机 |
| 锅炉燃烧 | 煤炭、天然气、重油等 | 采暖锅炉、备用锅炉 |
| 发电锅炉 | 余热 | 余热锅炉（不产生额外排放） |
| 点火启动 | 柴油、重油、天然气 | 点火燃烧器 |

#### 5.1.2 工业生产过程排放

| 排放源 | 排放原因 | 温室气体 | 占比 |
|--------|---------|----------|------|
| 碳酸盐分解 | 石灰石等原料高温分解 | CO₂ | 约60-70% |
| 有机碳氧化 | 生料中有机碳燃烧氧化 | CO₂ | 约1-3% |
| 协同处置废物 | 废物中可燃成分燃烧 | CO₂ | 视处置量而定 |

#### 5.1.3 逸散排放

| 排放源 | 排放原因 | 温室气体 | 占比 |
|--------|---------|----------|------|
| 设备泄漏 | 阀门、法兰等密封点 | CH₄ | <0.1%，可忽略 |

### 5.2 间接排放源

| 排放源 | 说明 | 占比 |
|--------|------|------|
| 购入使用电力 | 企业从电网购入的电力 | 约5-10% |
| 余热发电抵扣 | 企业自发自用电量 | 抵扣间接排放 |
| 购入使用蒸汽 | 企业从外部购入的蒸汽 | 较少 |

## 六、活动水平数据要求

### 6.1 化石燃料消耗量

#### 6.1.1 数据来源

- 优先采用**计量数据**：入窑煤粉计量、燃料油计量、天然气计量等
- 次选采用**台账数据**：燃料采购台账、燃料消耗台账
- 缺省采用**财务数据**：燃料采购发票、财务凭证

#### 6.1.2 计量要求

| 燃料类型 | 计量器具 | 精度要求 | 检定周期 |
|---------|---------|----------|----------|
| 煤粉（入窑） | 煤粉计量秤 | ±1.0% | 每年至少1次 |
| 原煤（入厂） | 地磅、皮带秤 | ±0.5% | 每年至少1次 |
| 燃料油 | 流量计、地磅 | ±0.5% | 每年至少1次 |
| 天然气、煤气 | 气体流量计 | ±1.0% | 每年至少1次 |
| 石油焦 | 地磅、皮带秤 | ±0.5% | 每年至少1次 |
| 替代燃料 | 地磅、估算 | ±5.0% | 每月记录 |

#### 6.1.3 数据频次

- 每日记录燃料消耗量
- 每月汇总燃料消耗数据
- 每年进行燃料盘点

### 6.2 燃料元素分析数据

#### 6.2.1 元素碳含量

- 每批次燃料至少检测1次
- 煤粉每月至少检测1次
- 可采用入窑煤粉在线监测数据

#### 6.2.2 低位发热量

- 每批次燃料至少检测1次
- 原煤每月至少检测1次
- 可采用煤质在线监测数据

### 6.3 熟料产量

#### 6.3.1 计量要求

- 优先采用**直接计量**：熟料地磅、熟料秤
- 次选采用**物料平衡**：生料消耗量×料耗
- 缺省采用**水泥产量推算**：水泥产量×熟料配比

#### 6.3.2 数据频次

- 每日记录熟料产量
- 每月进行物料平衡核算
- 每年进行盘点调整

### 6.4 原料消耗量

| 原料类型 | 计量要求 | 数据频次 |
|---------|---------|----------|
| 石灰石 | 地磅/皮带秤，精度±0.5% | 每日记录 |
| 黏土/页岩 | 地磅/皮带秤，精度±0.5% | 每日记录 |
| 铁粉/硫酸渣 | 地磅/皮带秤，精度±1.0% | 每日记录 |
| 砂岩 | 地磅/皮带秤，精度±0.5% | 每日记录 |
| 粉煤灰 | 地磅/冲板流量计，精度±1.0% | 每日记录 |
| 矿渣 | 地磅/皮带秤，精度±0.5% | 每日记录 |
| 石膏 | 地磅，精度±1.0% | 每日记录 |

### 6.5 生料成分分析

- 每班次至少检测1次生料化学成分
- 检测项目：烧失量、CaO、SiO₂、Al₂O₃、Fe₂O₃等
- 计算熟料率值（KH、SM、IM）

### 6.6 购入电力和余热发电数据

- 以电网企业电费结算单为准
- 按月统计购入电量和自发自用电量
- 区分外购电和余热发电
- 安装电能计量装置，精度±1.0%

## 七、排放因子选取

### 7.1 排放因子选取原则

1. **优先实测**：企业具备实测条件的，应采用实测排放因子
2. **行业缺省**：无法实测的，采用生态环境部发布的行业缺省值
3. **国家标准**：可参考GB/T 32151系列国家标准中的缺省值

### 7.2 熟料排放因子

| 熟料类型 | 排放因子（tCO₂/t熟料） | 数据来源 |
|---------|-----------------------|----------|
| 硅酸盐水泥熟料 | 0.860 | 生态环境部缺省值 |
| 普通硅酸盐水泥熟料 | 0.850 | 生态环境部缺省值 |
| 矿渣硅酸盐水泥熟料 | 0.840 | 生态环境部缺省值 |

**说明**：优先采用企业实测的熟料排放因子，实测方法见附录。

### 7.3 原料碳酸盐排放因子

| 原料名称 | 主要成分 | CO₂排放因子（tCO₂/t） | 数据来源 |
|---------|---------|---------------------|----------|
| 石灰石 | CaCO₃ | 0.440 | 理论计算值（纯品） |
| 白云石 | CaMg(CO₃)₂ | 0.477 | 理论计算值（纯品） |
| 菱镁石 | MgCO₃ | 0.522 | 理论计算值（纯品） |

**说明**：实际排放因子需乘以原料中碳酸盐的纯度。

### 7.4 化石燃料排放因子

参考电力行业排放因子表。

### 7.5 电力排放因子

采用国家温室气体排放因子数据库发布的最新电力排放因子。

## 八、数据质量管理

### 8.1 数据质量控制计划（DQCP）

企业应制定并实施数据质量控制计划，包括：

- 数据质量管理组织机构及职责
- 数据监测计划（含监测点位、监测频次、监测方法）
- 数据记录和存档要求
- 数据审核机制（三级审核）
- 人员培训要求
- 仪器设备检定校准计划

### 8.2 关键参数分类

#### 8.2.1 企业层级关键参数

1. 化石燃料消耗量
2. 熟料产量
3. 石灰石原料消耗量
4. 购入电量
5. 余热发电量

#### 8.2.2 工序层级关键参数

1. 入窑煤粉消耗量
2. 生料消耗量
3. 熟料化学成分
4. 生料化学成分

### 8.3 数据质量等级

| 数据质量等级 | 活动数据要求 | 排放因子要求 | 适用情况 |
|-------------|-------------|-------------|----------|
| Ⅰ级 | 连续计量，每日记录 | 实测（每批次检测） | 重点排放单位推荐 |
| Ⅱ级 | 定期计量，每周记录 | 实测（每月检测） | 一般排放单位 |
| Ⅲ级 | 台账记录，每月汇总 | 行业缺省值 | 小规模排放单位 |

### 8.4 数据内部审核

- 班组级：每班次数据自查
- 车间级：每日数据审核
- 公司级：每月数据质量审核
- 年度：全面数据质量审核
- 保留审核记录和整改报告

### 8.5 信息化存证

- 重点排放单位应按月上传月度数据
- 上传内容包括：燃料消耗、熟料产量、电量等
- 数据应与原始凭证一致
- 保留电子凭证和纸质凭证

### 8.6 不确定性控制

- 定期开展排放量不确定性分析
- 识别主要不确定性来源
- 采取措施降低不确定性
- 报告不确定性范围

## 九、报告内容和格式要求

- 企业基本情况（名称、统一社会信用代码、地址、法定代表人等）

### 9.6 报告格式

报告应采用生态环境部统一制定的报告格式，包括：

- 封面

### 附录B：核算公式汇总

```
1. 排放总量
E_total = E_combustion + E_process + E_indirect - E_waste_heat

2. 化石燃料燃烧排放（元素碳法）
E_combustion = Σ (FC_i × C_ar,i × OF_i × 44/12)

3. 碳酸盐分解排放（熟料产量法）
E_carbonate = P_clinker × EF_clinker

4. 碳酸盐分解排放（原料消耗法）
E_carbonate = Σ (M_raw,i × EF_raw,i)

5. 有机碳氧化排放
E_organic = M_raw × C_organic × OF_organic × 44/12

6. 购入电力间接排放
E_indirect = AD_electricity × EF_electricity

7. 余热发电抵扣
E_waste_heat = AD_waste_heat × EF_electricity

8. 吨熟料碳排放强度
EI_clinker = E_total / P_clinker

9. 吨水泥碳排放强度
EI_cement = E_total / P_cement
```

### 附录C：熟料排放因子实测方法

#### C.1 熟料排放因子计算

```
EF_clinker = (C_carbonate + C_organic) / P_clinker × 44/12
```

其中：
- `C_carbonate`：碳酸盐分解释放的碳量，单位：tC
- `C_organic`：有机碳氧化释放的碳量，单位：tC
- `P_clinker`：熟料产量，单位：t

#### C.2 碳酸盐碳量计算

采用物料平衡法：

```
C_carbonate = (M_raw × LOI_raw - M_clinker × LOI_clinker) × C_CO2 / CO2_ratio
```

其中：
- `M_raw`：生料消耗量，单位：t
- `LOI_raw`：生料烧失量，单位：%
- `M_clinker`：熟料产量，单位：t
- `LOI_clinker`：熟料烧失量，单位：%
- `C_CO2`：CO₂中碳的比例，约27.3%（12/44）
