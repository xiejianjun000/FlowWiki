# 环境影响评价制度体系

## 概述

环境影响评价（EIA）是一项全球性环境管理制度，中国自1979年正式建立该制度，经过近五十年的发展，已形成由法律、行政法规、部门规章、技术导则构成的完整体系。EIA是生态环境管理中最核心的源头预防工具。

## 制度演进历程

| 阶段 | 时期 | 标志性事件 |
|------|------|-----------|
| 引入和确立 | 1973-1979 | 1979年《环境保护法（试行）》确立制度 |
| 规范和建设 | 1979-1989 | 各项配套规章出台，资质管理建立 |
| 强化和完善 | 1990-2002 | 《建设项目环境保护管理条例》 |
| 提高和拓展 | 2003-2015 | 《环境影响评价法》施行，扩展到规划环评 |
| 改革和优化 | 2016至今 | 取消资质管理，"三线一单"体系 |

## 法律法规体系结构

```
宪法（环境保护条款）
  └── 环境保护综合法（《环境保护法》）
       ├── 环境影响评价法（专门法）
       ├── 污染防治单行法（水、大气、土壤等）
       ├── 行政法规（《建设项目环境保护管理条例》）
       ├── 部门规章（管理办法、名录）
       ├── 技术导则（总纲、各要素导则）
       └── 环境标准（质量标
```
## 五大制度特点

### 1. 法律强制性
- 以《环境保护法》和《环境影响评价法》为法律依据
- 有明确的法律责任体系（规划编制机关、审批机关、建设单位、评价机构等）

### 2. 纳入基本建设程序
- 中国独有管理模式
- 环评审批前置——未获批准不得开工建设

### 3. 分类管理
- 报告书（重大影响）→ 报告表（轻度影响）→ 登记表（很小影响）
- 50大类192项（2017版分类管理名录）

### 4. 分级审批
- 中央、省、市、县四级审批
- 核设施、跨省项目等由环保部审批

### 5. 环评工程师职业资格制度
- 2004年建立，全国统一考试
- 11个专业类别
- 继续教育制度（年均16学时）

## 与相关制度的联动

- **与排污许可**：环评确定的许可排放量是排污许可证的核心内容
- **与总量控制**：项目总量指标来源于区域总量控制目标
- **与排污权交易**：环评核定的排放指标在排污权市场流通
- **与环保验收**：竣工验收检验环评措施的落实情况
- **与"三线一单"**：生态保护红线、环境质量底线、资源利用上线、环境准入负面清单

## 2017年改革要点

1. 取消环评单位资质管理
2. 登记表由审批制改为备案制
3. 竣工验收由环保部门验收改为建设单位自主验收
4. 简化审批程序，强化事中事后监管
5. 加大处罚力度，强化信息公开和公众参与
