# 温室气体排放管理

## 概览

温室气体排放管理是指对温室气体（GHG）排放进行系统化的核算、报告、核查（MRV）和减排管理的制度体系。它是应对气候变化的基础性工作，也是碳排放权交易市场、碳达峰碳中和目标考核的数据支撑。

中国已建立以《碳排放权交易管理暂行条例》（国务院令第775号）为核心，以碳排放核算标准、报告指南、核查规范为配套的MRV制度体系。2026年碳达峰碳中和综合评价考核制度的建立，进一步强化了温室气体排放管理的刚性约束。

## 核心内容

### 温室气体种类

《京都议定书》管控的七种温室气体：

| 温室气体 | 分子式 | 全球增温潜势（GWP） | 主要来源 |
|---------|--------|-------------------|---------|
| 二氧化碳 | CO₂ | 1 | 化石燃料燃烧、工业过程 |
| 甲烷 | CH₄ | 28 | 农业、废弃物处理、化石能源开采 |
| 氧化亚氮 | N₂O | 265 | 农业土壤管理、化工生产 |
| 氢氟碳化物 | HFCs | 12-14,800 | 制冷剂、泡沫发泡 |
| 全氟化碳 | PFCs | 7,390-12,200 | 铝冶炼、半导体制造 |
| 六氟化硫 | SF₆ | 23,500 | 电力设备绝缘 |
| 三氟化氮 | NF₃ | 17,200 | 半导体制造 |

### MRV体系

MRV（Monitoring/Measurable, Reporting, Verification）是温室气体排放管理的核心框架：

```
核算（Monitoring）
     └── 排放源识别、活动数据收集、排放因子确定
          ↓
报告（Reporting）
     └── 排放报告编制、数据质量控制、信息公开
          ↓
核查（Verification）
     └── 第三方核查、数据真实性验证、核查报告出具
          ↓
履约（Compliance）
     └── 配额清缴、碳市场交易、监督管理
```

### 碳排放核算方法

| 方法学 | 说明 | 适用范围 |
|--------|------|---------|
| 排放因子法 | 活动数据 × 排放因子 | 宏观层面、企业层面 |
| 物料平衡法 | 输入-输出碳平衡计算 | 工业过程排放 |
| 实测法 | 直接测量排放浓度和流量 | 重点排放源（火电等） |

### 碳排放核算标准体系

| 标准/指南 | 范围 | 发布机构 |
|-----------|------|---------|
| ISO 14064-1 | 组织层面GHG清单量化 | ISO |
| ISO 14064-2 | 减排项目GHG量化 | ISO |
| ISO 14067 | 产品碳足迹 | ISO |
| IPCC指南（2006/2019修订） | 国家温室气体清单编制 | IPCC |
| 企业温室气体排放核算方法与报告指南 | 行业级核算 | 生态环境部 |
| 产品碳足迹核算标准 | 产品级碳足迹 | 生态环境部 |

### 温室气体排放报告制度

根据《碳排放权交易管理暂行条例》：

- **重点排放单位义务**（第11条）：制定数据质量控制方案，核算温室气体排放量，编制年度排放报告并公开
- **核查制度**（第12条）：省级生态环境主管部门委托技术服务机构核查
- **清缴制度**（第14条）：重点排放单位按时足额清缴碳排放配额
- **处罚机制**（第21-26条）：未按规定清缴的，处未清缴配额市场均价5-10倍罚款

### 温室气体排放数据质量管控

2025-2026年，数据质量管控持续强化：

- 碳排放数据质量监督帮扶
- 碳排放报告与核查技术规范更新
- 重点行业数据质量评价指标体系
- 企业碳排放数据质量管理能力提升

### 碳达峰碳中和综合评价考核

2026年建立（2026-06-22-MEE-碳达峰碳中和综合评价考核办法_AM）：

- **考核对象**：各省（自治区、直辖市）
- **核心指标**：碳排放强度、能源结构、行业减排、生态碳汇
- **考核方式**：年度评价 + 中期评估 + 五年考核
- **结果运用**：纳入高质量发展综合绩效评价

### 省级温室气体清单编制指南更新

2026年1月，生态环境部办公厅印发《省级温室气体清单编制指南（2025年版）》（环办气候〔2026〕1号），以2011年《省级温室气体清单编制指南（试行）》为基础进行系统修订，提升了省级温室气体清单编制的科学性、规范性和可操作性。该指南为各省（自治区、直辖市）编制温室气体清单提供了统一的技术规范，支撑省级碳排放双控考核和碳达峰碳中和综合评价。

### 碳排放权交易与MRV的衔接

全国碳市场的运行依赖MRV体系提供的排放数据：

- **配额分配**：基于历史排放数据确定配额
- **交易清缴**：排放报告数据是清缴依据
- **市场监管**：数据质量的真实性直接影响碳市场公信力
- **行业扩容**：2026年钢铁、水泥、铝冶炼纳入碳市场，相关行业的核算指南同步扩展
