# 环境影响评价

## 定义

环境影响评价（Environmental Impact Assessment, EIA），是指对规划和建设项目实施后可能造成的环境影响进行分析、预测和评估，提出预防或者减轻不良环境影响的对策和措施，进行跟踪监测的方法与制度。

## 法律依据

- 生态环境法典第一编第五章"生态环境影响评价"（当前核心依据）
- [[sources/laws/eco_import/环境影响评价法.md|环境影响评价法]]（配套单行法）
- 环境保护法第19条（环评的母法依据）
- [[sources/laws/eco_import/生态环境法律体系概览.md|生态环境法律体系概览]]

## 两大环评体系

### 规划环境影响评价

| 规划类型 | 评价要求 | 责任主体 |
|---------|---------|---------|
| 土地利用规划 | 编写环境影响篇章或说明 | 规划编制机关 |
| 区域、流域、海域开发利用规划 | 编写环境影响篇章或说明 | 规划编制机关 |
| 工业、农业、能源、水利、交通等专项规划 | 编制环境影响报告书 | 规划编制机关 |

### 建设项目环境影响评价

根据项目对环境的影响程度实行分类管理：

| 环评类别 | 适用项目 | 要求 |
|---------|---------|------|
| **环境影响报告书** | 可能造成重大环境影响的 | 进行全面、详细的评价 |
| **环境影响报告表** | 可能造成轻度环境影响的 | 进行专项评价 |
| **环境影响登记表** | 环境影响很小的 | 仅需填报登记表 |

## 环评的基本程序

```
┌──────────────────┐
│ 1. 环评文件编制    │ ← 建设单位委托环评机构
└────────┬─────────┘
         ↓
┌──────────────────┐
│ 2. 公众参与        │ ← 报告书须征求意见，必要时听证
└────────┬─────────┘
         ↓
┌──────────────────┐
│ 3. 环评审批        │ ← 生态环境部门审批（分级审批）
└────────┬─────────┘
         ↓
┌──────────────────┐
│ 4. "三同时"落实    │ ← 环保设施与主体工程三同时
└────────┬─────────┘
         ↓
┌──────────────────┐
│ 5. 竣工环保验收    │ ← 验收合格方可投产
└────────┬─────────┘
         ↓
┌──────────────────┐
│ 6. 排污许可衔接    │ ← 持证排污
└──────────────────┘
```

## 环评与相关制度的关系

### 环评 → 排污许可
环评是排污许可的前置程序。环评文件批复中明确的污染物排放种类、浓度、排放量等信息，是排污许可证载明内容的主要来源。

### 环评 → 三同时
环评文件提出污染防治要求，"三同时"制度保证这些要求在设计和建设阶段得到落实。

### 环评 → 环境保护税
环评中预测的污染物排放量是税务部门核定环保税排污量的参考依据之一。

## 违法后果

| 违法行为 | 处罚标准 |
|---------|---------|
| 未批先建（项目） | 责令停止建设，处总投资额1%-5%罚款，可责令恢复原状 |
| 环评文件弄虚作假 | 对环评机构处所收费用1-3倍罚款，吊销资质 |
| 规划未做环评 | 对责任人给予处分 |

## 关联概念

- 排污许可 → 环评后续的核心制度
- 三同时 → 环评要求的具体落实
- 生态保护红线 → 环评中的"底线"约束
- 环境保护税 → 环境影响的经济调节

## 最新发展（2024—2026年）

### 生态环境分区管控与环评衔接

- 生态环境分区管控管理暂行规定（2024年7月）——"三线一单"成为环评审批前置依据
- 衔接机制：生态保护红线、环境质量底线、资源利用上线作为环评审批的前提条件

### 入河排污口监督管理

- 部令第35号：入河排污口监督管理办法（2024年11月）
- 规范入河排污口的设置审批和监督管理，与环评制度衔接

### 环评改革试点

- "大数据+监管"模式查处建设项目环境违法行为

## 改革趋势（2026年）

- 纳入 生态环境法典后，环评制度与其他制度的衔接更加规范
- 环评审批流程持续"放管服"改革
- 规划环评的约束力逐步增强
- 环评与排污许可的"无缝衔接"持续推进
- 环评领域的信用监管体系逐步建立
