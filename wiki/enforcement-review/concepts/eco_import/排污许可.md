# 排污许可

## 定义

排污许可是指生态环境主管部门根据排污单位的申请和承诺，依法对排污单位排放污染物的种类、浓度、排放量、排放方式等作出许可决定的监督管理制度。排污许可证是企业事业单位在生产运营期排放污染物的**法律依据**。

## 法律依据

### 法典层面的依据

- 生态环境法典第一编第五章（环境影响评价）与第二编第一分编第二章"排污许可管理"
- 法典确立了排污许可作为污染防治**核心管理制度**的地位
- 所有排放污染物的排污单位须依法取得排污许可证

### 单行法层面的依据

| 法律 | 主要规定 |
|------|---------|
| 环境保护法第45条 | 国家依照法律规定实行排污许可管理制度 |
| [[sources/laws/eco_import/大气污染防治法.md|大气污染防治法]]第19条 | 排放工业废气或有毒有害大气污染物的企业须取得排污许可 |
| [[sources/laws/eco_import/水污染防治法.md|水污染防治法]]第20条 | 直接或间接向水体排放工业废水和医疗污水须取得排污许可 |
| [[sources/laws/eco_import/固体废物污染环境防治法.md|固体废物污染环境防治法]]第30条 | 产生工业固废的单位须取得排污许可 |
| [[sources/laws/eco_import/海洋环境保护法.md|海洋环境保护法]]第26条 | 向海域排放陆源污染物的单位须取得排污许可 |

## 核心要点

### 1. "一证式"管理

排污许可证整合了环境影响评价、污染物排放标准、总量控制等多重制度要求，实现"一证式"综合管理。许可证载明：
- 排放污染物的种类、浓度和排放量
- 排放口位置和数量
- 排放方式、排放去向
- 自行监测要求
- 环境管理台账记录要求
- 执行报告提交要求

### 2. 分类分级管理

| 管理类别 | 适用对象 | 管理要求 |
|---------|---------|---------|
| 重点管理 | 污染物产生量、排放量大的企业 | 详细申领、在线监测、定期报告 |
| 简化管理 | 污染物产生量、排放量中等的企业 | 简化申领流程 |
| 登记管理 | 污染物产生量、排放量很小的企业 | 仅需登记备案，无需申领许可证 |

### 3. 许可证的执行与监管

- 排污单位须按照许可证规定的污染物种类、浓度和排放量进行排放
- 须开展自行监测并保存监测记录
- 须按期间生态环境部门提交执行报告
- 违反许可证规定的排污行为将受到行政处罚

### 4. 与环评的衔接

- 环评批复是申领排污许可证的前置条件
- 排污许可证载明的要求来源于环评文件
- 建设项目竣工环保验收须与排污许可衔接

## 违法后果

| 违法行为 | 处罚标准 |
|---------|---------|
| 无证排污 | 责令改正或限制生产、停产整治，处10万元-100万元罚款；情节严重责令停业、关闭 |
| 超浓度、超总量排污 | 处10万元-100万元罚款；情节严重责令停业、关闭 |
| 未按规定提交执行报告 | 处2万元-20万元罚款 |
| 未开展自行监测 | 处2万元-10万元罚款 |

## 制度升级：2024年《排污许可管理办法》（部令第32号）

2024年4月，生态环境部发布修订后的《排污许可管理办法》（部令第32号），自2024年7月1日起施行。主要升级要点：

### 综合许可范围扩展
管控范围从大气、水污染物扩展至**工业固体废物、工业噪声**，实现多要素综合许可管理（第6条），推动"一证式"管理真正覆盖固定污染源的主要环境要素。

### 数据应用强化
- 执行报告中的实际排放量可作为生态环境统计、总量考核、污染源排放清单编制的依据（第9条）
- 排污许可证明确作为**排污权的确认凭证和排污权交易的管理载体**（第9条）

### 质量管理机制
建立排污许可证质量审核机制，定期开展质量核查（第42条），排污许可执法检查纳入生态环境执法年度计划（第40条），强化证后监管。

### 与原试行办法的关系
该办法同时废止了2018年《排污许可管理办法（试行）》（环境保护部令第48号），是排污许可制度从"试行"走向"正式"的标志性法规升级。

## 当前发展（2026年）

- 排污许可已全面纳入 生态环境法典，制度法律层级得到提升
- 全国固定污染源排污许可全覆盖
- 排污许可与环评、监测、执法实现全链条联动
- 数据化管理水平持续提升
