# 暴露参数

## 定义

暴露参数（Exposure Parameters）是描述人体与环境污染物接触行为的量化指标，包括呼吸速率、饮水量、食物摄入量、皮肤接触面积、体重、活动时间模式等。暴露参数是环境健康风险评估中暴露评估环节的核心基础数据，其准确性直接影响风险评估结果的可信度。

## 暴露参数的类别

### 基本参数

| 参数类别 | 典型参数 | 影响因素 |
|---------|---------|---------|
| 呼吸参数 | 呼吸速率（m³/天） | 年龄、活动强度 |
| 饮水参数 | 饮水量（L/天） | 年龄、气候、活动 |
| 食物摄入 | 各类食物摄入量（g/天） | 年龄、饮食习惯、地区 |
| 皮肤接触 | 体表面积（m²）、皮肤暴露比例 | 年龄、季节、着装 |
| 体重 | 体重（kg） | 年龄、性别 |
| 活动时间 | 室内外活动时间（h/天） | 年龄、职业、生活方式 |

### 特殊参数

- 土壤摄入量（g/天）—— 主要关注儿童，因儿童有手-口行为
- 母乳摄入量（L/天）—— 婴儿特定暴露途径
- 沐浴时间和水温 —— 皮肤接触暴露
- 房屋渗透系数 —— 室内外空气污染物交换

## 标准体系

中国的暴露参数调查已建立系列技术标准：

| 标准名称 | 年份 | 内容 |
|---------|------|------|
| 《暴露参数调查技术规范》 | 2017 | 暴露参数调查的总体技术方法 |
| 《暴露参数调查基本数据集》 | 2019 | 暴露参数的数据标准与格式规范 |
| 《儿童土壤摄入量调查技术规范 示踪元素法》 | 2017 | 儿童土壤摄入量的专用调查方法 |

## 暴露参数的应用

环境健康风险评估中，暴露剂量计算的一般公式：

```
ADD = (C × IR × EF × ED) / (BW × AT)

其中：
ADD = 日均暴露剂量（mg/kg·day）
C   = 污染物浓度（mg/L 或 mg/m³）
IR  = 摄入/呼吸速率（L/day 或 m³/day）
EF  = 暴露频率（days/year）
ED  = 暴露持续时间（years）
BW  = 体重（kg）
AT  = 平均时间（days）
```

**关键暴露参数（示例值）**：

| 参数 | 成人 | 儿童 |
|------|------|------|
| 呼吸速率 | 15-20 m³/天 | 5-10 m³/天 |
| 饮水量 | 2 L/天 | 1 L/天 |
| 体重参考值 | 60-70 kg | 15-30 kg（依年龄） |
| 土壤摄入量 | 50 mg/天 | 100-200 mg/天 |

## 暴露参数调查方法

### 横断面调查

在特定时间点对目标人群的暴露行为进行调查，获取代表性暴露参数。

### 示踪元素法（儿童土壤摄入量）

- 通过测定粪便中不可消化示踪元素（如铝、钛、酸不溶灰分）的含量
- 反推儿童土壤摄入量
- 避免问卷调查的回忆偏差

### 问卷调查

- 活动模式日志
- 食物频率问卷
- 时间-活动模式调查

## 国际比较

- **美国**：EPA发布《暴露因子手册》（Exposure Factors Handbook），定期更新
- **中国**：《中国人群暴露参数手册》已发布，填补了国内数据空白，推动本土化风险评估
- 中国暴露参数与欧美人群存在显著差异（体型、饮食结构、活动模式等），需要本土数据支持
