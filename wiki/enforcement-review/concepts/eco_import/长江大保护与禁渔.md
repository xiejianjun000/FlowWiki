# 长江大保护与禁渔

## 概述

长江流域重点水域禁捕（长江十年禁渔）是党中央、国务院为全局计、为子孙谋的重要决策。自2021年1月1日实施禁渔以来，退捕渔民安置保障有力，禁捕水域管理秩序平稳，水生生物资源恢复向好。2024年3月国务院办公厅发布《关于坚定不移推进长江十年禁渔工作的意见》（国办发〔2024〕12号），进一步巩固禁渔成果。

## 工作推进机制

坚持"中央统筹、部门协同、省负总责、市县抓落实"的工作机制。农业农村部牵头，协调机制成员单位共同推进，纳入地方政府绩效考核和河湖长制考核。

## 持续做好安置保障

- **动态精准监测**：退捕渔民就业状况、收入、养老保险动态跟踪
- **就业帮扶**：职业培训、单位吸纳补贴、创业担保贷款、公益性岗位兜底
- **养老保险**：应保尽保、缴费补贴及时足额到位

## 执法监管体系

| 措施 | 内容 |
|------|------|
| 执法协作 | 渔政、公安、市场监管、交通、水利跨部门联合执法 |
| 高压严管 | 严查"电毒炸"、"绝户网"、非法销售渔获物 |
| 船舶管理 | 清理"三无"船舶，加强农民自用船舶管理 |
| 违规垂钓 | 划定禁钓区，备案制度，有奖举报 |
| 能力建设 | 船艇、无人机、视频监控等现代化执法装备 |

## 生态修复行动

### 珍稀濒危物种保护

| 物种 | 保护措施 |
|------|---------|
| 中华鲟 | 产卵场修复、人工保种、增殖放流、野外种群重建 |
| 长江鲟 | 生境修复、生态调度、自然繁殖试验 |
| 长江江豚 | 就地保护、迁地保护、人工繁育、应急救助 |

### 重要栖息地修复

- 划定水生生物重要栖息地名录
- 涉渔工程严格环评，落实补偿措施
- 过鱼设施、生态调度、灌江纳苗、江湖连通
- 长江上游珍稀特有鱼类国家级自然保护区建设

### 资源调查监测

- 健全监测调查网络
- 水生生物完整性指数评价
- 监测数据作为地方政府履职考核依据

### 外来物种防治

- 外来物种常态化监测和预警
- 防逃隔离设施建设
- 全链条防控预案
- 严禁向天然开放水域放流外来物种
