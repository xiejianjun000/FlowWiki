# 环境保护税

## 定义

环境保护税是国家对直接向环境排放应税污染物的企业事业单位和其他生产经营者征收的一种特定目的税。它是我国绿色税收体系的核心税种，通过经济手段调节排污行为。

## 法律依据

- [[sources/laws/eco_import/环境保护税法.md|环境保护税法]]（2018年1月1日起施行）
- 生态环境法典第四编"绿色低碳发展"

## 核心机制

### 1. 纳税人
直接向环境排放应税污染物的企业事业单位和其他生产经营者。

### 2. 应税污染物

| 类别 | 具体污染物 |
|------|-----------|
| 大气污染物 | SO₂、NOx、烟尘、VOCs等44项 |
| 水污染物 | COD、氨氮、总磷、重金属等 |
| 固体废物 | 煤矸石、尾矿、危险废物、冶炼渣等 |
| 工业噪声 | 按超标分贝数征收 |

### 3. 税额标准

| 污染物 | 税额 |
|--------|------|
| 大气污染物 | 每污染当量1.2元-12元（地方可上浮） |
| 水污染物 | 每污染当量1.4元-14元（地方可上浮） |
| 危险废物 | 1000元/吨 |
| 工业噪声 | 月分贝超标，350元-11200元/月 |

### 4. 减免政策

- 排放浓度低于标准30% → 减按75%征收
- 排放浓度低于标准50% → 减按50%征收
- 畜禽养殖废弃物综合利用 → 免征
- 城镇污水、生活垃圾集中处理场所达标排放 → 免征

## 与其他制度的关系

### 费改税的历史意义
- 2018年之前：征收"排污费"（行政事业性收费）
- 2018年之后：改为"环境保护税"（法定税种）
- **税收法定原则**的体现
- 法律刚性更强
- 全部作为地方收入，激励地方政府积极性

### 与排污许可的联动
- 排污许可证中载明的排放数据是环保税计税的重要依据
- 企业自行监测数据用于申报环保税

### 与污染物排放标准的关系
- 排放浓度是否达标直接影响税率优惠
- 低于标准浓度 → 减税；超标排放 → 全额缴纳 + 行政处罚

## 2026年动态

### 环保税申报五大避坑要点

2026年企业环保税申报需关注（2026-06-22-企业环保税申报-2026年五大避坑技巧_AM）：
1. 排放数据与排污许可证的一致性
2. 减免政策适用的条件审核
3. 在线监测数据的完整性
4. 跨区域转移排放的税务处理
5. 新纳入行业（钢铁/水泥/铝冶炼）的碳市场与环保税衔接

### 法规更新

随着生态环境法典施行，环境保护税相关配套制度正在调整，包括应税污染物范围的动态管理和与碳市场的协同机制。

## 发展趋势

- 征税范围逐步扩大（VOCs等已纳入）
- 税率动态调整机制
- 税务与生态环境部门的信息共享持续优化
- 绿色税收体系（环保税+资源税+耕地占用税+车船税）逐步完善
- 环保税与碳市场的协同机制正在建立
