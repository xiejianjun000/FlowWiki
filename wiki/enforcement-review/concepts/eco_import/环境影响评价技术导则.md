# 环境影响评价技术导则

## 概览

环境影响评价技术导则（简称"环评导则"）是指导环境影响评价工作的技术规范，是环评制度科学化、规范化运行的技术支撑。环评导则体系由生态环境部组织制定，属于国家生态环境标准体系的组成部分，涵盖了建设项目环评和规划环评两大类，按要素和行业形成多层次、全覆盖的技术指导体系。

环评导则依据《环境影响评价法》和《建设项目环境保护管理条例》制定，具有强制性技术标准效力。环评机构和环评技术人员在编制环评文件时必须严格遵循导则要求。

## 核心内容

### 导则体系结构

环评导则体系分为三个层次：

```
第一层：总纲导则
     └── 指导环评工作的总体框架和方法论
          ↓
第二层：要素导则
     └── 各环境要素的预测评价技术规范
          ↓
第三层：专项/行业导则
     └── 特定行业或专题的技术规范
```

### 导则与标准的关系

环评导则在生态环境标准体系中的位置：

```
生态环境标准体系
├── 生态环境质量标准（环境空气、地表水、土壤等）
├── 污染物排放标准（行业排放限值）
├── 生态环境监测标准
├── 生态环境管理技术规范
│   ├── 环境影响评价技术导则  ← 本概念
│   ├── 排污许可技术规范
│   └── 竣工验收技术规范
└── 生态环境基础标准
```

### 导则核心内容要素

以 HJ 2.1 总纲为例，环评导则主要规定：

1. **评价工作程序**：准备阶段、正式工作阶段、报告编制阶段
2. **评价等级划分**：根据项目特征和环境敏感性确定一级、二级、三级评价
3. **评价范围确定**：依据导则规定的距离和面积指标
4. **现状调查与评价**：自然环境现状、环境质量现状、污染源调查
5. **环境影响预测**：采用导则推荐的预测模型和方法
6. **环境风险评价**：识别风险源、预测后果、制定应急预案
7. **环境保护措施**：污染防治措施、生态保护措施、环境管理计划
8. **公众参与**：信息公开、公众意见调查和反馈

### 导则的更新与维护

- 生态环境部负责制修订环评导则
- 根据环境管理需求和科技进步定期更新
- 导则修订伴随环评制度改革同步推进
- 重点方向：碳排放评价纳入环评、模型软件升级、简化优化

### 导则的强制性

环评导则是强制性技术标准：

- 环评文件必须严格遵循现行导则要求
- 导则中规定的预测模型和参数具有唯一权威性
- 环评文件评审以导则合规性为基本审查标准
- 导则更新后，新受理项目按新版导则执行
