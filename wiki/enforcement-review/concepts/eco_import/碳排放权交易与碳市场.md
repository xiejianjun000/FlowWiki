# 碳排放权交易与碳市场

## 概述

全国碳排放权交易市场是利用市场机制控制和减少温室气体排放、推动绿色低碳发展的重大制度创新。其法律基础为2024年国务院令第775号《碳排放权交易管理暂行条例》，该条例于2024年5月1日起施行。

## 法律框架

### 《碳排放权交易管理暂行条例》（国务院令第775号）

**核心制度设计**：

1. **覆盖范围**（第6条）：碳排放权交易覆盖的温室气体种类和行业范围由国务院生态环境主管部门会同有关部门确定，报国务院批准后实施。交易产品包括碳排放配额和经国务院批准的其他现货交易产品。

2. **配额管理**（第9条）：碳排放配额实行免费分配，并根据国家有关要求逐步推行免费和有偿相结合的分配方式。

3. **重点排放单位管理**（第11条）：制定温室气体排放数据质量控制方案，统计核算温室气体排放量，编制年度排放报告，向社会公开。

4. **核查与清缴**（第12-14条）：省级生态环境主管部门核查排放报告，重点排放单位需按时足额清缴碳排放配额。

5. **处罚机制**（第21-26条）：严格的法律责任，未按规定清缴配额的，处未清缴配额市场均价5-10倍罚款。

## CCER（国家核证自愿减排量）

| 方法学名称 | 领域 | 发布日期 |

| 滨海盐沼植被修复 | 海洋碳汇 | 2025-12-03 |
| 海草床植被修复 | 海洋碳汇 | 2025-12-03 |
| 规模化猪场粪污沼气回收利用 | 农业 | 2025-12-18 |
| 农业废弃物集中处理工程 | 农业 | 2025-12-18 |

## 碳市场扩容路线

根据《2024-2025年节能降碳行动方案》及碳市场系列解读：

1. **行业扩容**：从电力行业逐步扩展至建材（水泥）、钢铁、有色金属、石化化工等行业
2. **产品扩容**：从碳排放配额扩展至CCER等自愿减排产品
3. **方式扩容**：从免费分配向免费+有偿分配并存过渡
4. **国际对接**：深化碳市场国际交流合作，推动全球气候治理体系构建

## 2026年重要进展

### 碳市场行业扩容

2026年，钢铁、水泥、铝冶炼三大行业正式纳入全国碳市场（（新闻动态链接）），使全国碳市场覆盖从发电行业扩展至四大行业，合计覆盖全国约65%的碳排放量：

| 行业 | 纳入年份 | 碳排放占比 | 关键要求 |
|------|----------|-----------|---------|
| 发电行业 | 2021年 | ~40% | 首个履约周期完成 |
| 钢铁 | 2026年 | ~15% | 2026年6月底前完成配额核定 |
| 水泥 | 2026年 | ~10% | 7月1日起启动履约 |
| 铝冶炼 | 2026年 | ~5% | 强化数据质量管理 |

### 碳价走势

2026年6月全国碳市场收盘价约**81元/吨**（（新闻动态链接））：
- 较2021年启动时48元/吨上涨约69%
- 与欧盟EUA（约70欧元/吨，约540元/吨）价差约6.7倍
- 行业扩容后预计碳价有进一步上行空间

### 碳足迹管理体系建设

2026年全国低碳日（6月17日），生态环境部发布《产品碳足迹管理体系建设进展报告(2026)》（（新闻动态链接）），系统展示碳足迹工作实践成果，为与EU CBAM对接做准备。

### 碳达峰碳中和综合评价考核

中共中央办公厅、国务院办公厅印发《碳达峰碳中和综合评价考核办法》（2026年2月26日中央政治局常委会审议通过，（新闻动态链接）），建立"指标化+可操作化+闭环监督"考核体系。

### 上海碳普惠一周年

上海碳普惠上线一周年（（新闻动态链接））：
- 45万人参与
- 累计减排33万吨
- 公众参与碳市场的新路径探索
