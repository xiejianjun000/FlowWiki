# 美丽中国建设

## 概述

美丽中国建设是中国共产党第十八次全国代表大会提出的生态文明建设目标，强调将生态文明建设融入经济、政治、文化、社会建设各方面和全过程。2024—2025年，生态环境部牵头推出了一系列政策文件和行动方案，推动美丽中国建设从顶层设计进入具体实施阶段。

## 政策体系（2025年集中发布）

### 总体框架

1. **2025-01-14 关于印发《美丽城市建设实施方案》的通知**（2025年1月发布）
   - 以城市为基本单元推进美丽中国建设
   - 统筹城市生态环境保护与高质量发展

2. **2025-01-15 国务院办公厅转发生态环境部《关于建设美丽中国先行区的实施意见》**（2025年1月发布）
   - 选择重点区域先行先试，形成可复制可推广的经验
   - 国务院办公厅转发，体现跨部门协调力度

### 三大区域行动方案（2025年12月集中发布）

3. **2025-12-25 关于印发《京津冀美丽中国先行区建设行动方案》《长三角美丽中国先行区建设行动方案》《粤港澳大湾区美丽中国先行区建设行动方案》的通知**
   - 由生态环境部等七部门联合印发
   - 聚焦京津冀协同发展中的生态环境共保联治

4. **2025-12-25 关于印发《京津冀美丽中国先行区建设行动方案》《长三角美丽中国先行区建设行动方案》《粤港澳大湾区美丽中国先行区建设行动方案》的通知**
   - 突出长三角区域生态环境一体化治理
   - 推动绿色低碳高质量发展

5. **2025-12-25 关于印发《京津冀美丽中国先行区建设行动方案》《长三角美丽中国先行区建设行动方案》《粤港澳大湾区美丽中国先行区建设行动方案》的通知**
   - 结合粤港澳大湾区跨境环境治理需求
   - 探索"一国两制"框架下的区域环境治理新模式

## 配套支撑政策

- **绿色金融支持**：2024-10-13 中国人民银行、生态环境部、金融监管总局、中国证监会联合印发《关于发挥绿色金融作用 服务美丽中国建设的意见》（2024年10月，四部门联合印发）
- **减污降碳协同**：减污降碳协同增效系列案例（2023年）
- **区域战略协同**：区域重大战略生态环境保护系列专题（2022年）

## 政策演进脉络

美丽中国建设经历了从概念到规划再到具体实施方案的逐步落地过程：

- **2012年**：党的十八大首提"美丽中国"，纳入"五位一体"总体布局
- **2018年**：宪法修正案将生态文明写入宪法
- **2022年**：党的二十大对推进美丽中国建设作出系统部署；区域重大战略生态环境保护系列专题发布
- **2024年**：各部门联合发文，绿色金融支持美丽中国建设；高水平保护促进中部地区崛起
- **2025年1月**：美丽城市建设实施方案、美丽中国先行区实施意见发布——进入具体实施阶段
- **2025年12月**：三大区域行动方案发布——美丽中国先行区分区域推进

## 2026年新进展

### 持续深入推进污染防治攻坚

2026年生态环境部部署六大核心战役（（新闻动态链接））：

| 战役 | 重点领域 |
|------|----------|
| 蓝天保卫战 | PM2.5、臭氧、NOx协同控制 |
| 碧水保卫战 | 重点流域、近岸海域综合治理 |
| 净土保卫战 | 土壤污染源头管控 |
| 固体废物污染防治 | 危险废物排除清单（2026版） |
| 噪声污染防治 | 城市声环境功能区管理 |
| 应对气候变化 | 碳排放强度持续下降 |

### 生态环境监测法制化

《生态环境监测条例》于2026年1月1日起正式施行（（新闻动态链接）），为美丽中国建设提供监测数据真实性保障。

### 中央环保督察深化

第三轮第六批中央生态环保督察完成进驻（7省/兵团，受理群众举报34,896件），督察覆盖面持续扩大、问责力度不断强化（（新闻动态链接））。

### 法规清理贯彻法典

2026年7月，生态环境部启动大规模规章和规范性文件清理（拟废止17部规章、修改11部规章），以贯彻新施行的《生态环境法典》，维护法治统一（（新闻动态链接））。
