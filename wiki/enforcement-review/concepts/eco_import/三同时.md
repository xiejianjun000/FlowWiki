# 三同时

## 定义

"三同时"是指建设项目中防治污染的设施，应当与主体工程**同时设计、同时施工、同时投产使用**的环境管理基本制度。这是中国环境管理中的一项原创性制度。

## 法律依据

| 法律 | 条款 | 主要内容 |
|------|------|---------|
| 生态环境法典 | 总则相关条款 | 防治污染设施与主体工程三同时 |
| 环境保护法 | 第41条 | 三同时制度的母法依据 |
| [[sources/laws/eco_import/环境影响评价法.md|环境影响评价法]] | 相关条款 | 环评文件中的污染防治要求须在建设中落实 |

## 三同时的具体含义

| 阶段 | 要求 | 说明 |
|------|------|------|
| **同时设计** | 防治污染的设施应当与主体工程同时进行设计 | 环评文件中的环保要求在设计中体现，设计图纸须包含环保设施 |
| **同时施工** | 防治污染的设施应当与主体工程同时施工 | 环保设施建设进度不得落后于主体工程 |
| **同时投产使用** | 防治污染的设施应当与主体工程同时投入生产或使用 | 先验收环保设施，验收合格后方可正式投产 |

## 三同时与相关制度的关系

```
环评 ──→ 提出污染防治要求
  │
  ├──→ 三同时 ──→ 设计阶段落实
  │      │       ──→ 施工阶段落实
  │      │       ──→ 验收阶段把关
  │      │
  │      └──→ 竣工环保验收 → 方可投产
  │
  └──→ 排污许可 ──→ 持证运行（运营期管理）
```

### 在环评制度中的定位
- 环评文件提出污染防治要求和措施
- 三同时制度保证这些要求在建设和试运行阶段得到落实
- 三同时是连接环评和排污许可的关键环节

### 在排污许可制度中的定位
- 三同时验收通过后，企业方可正式投产运行
- 正式运行后纳入排污许可管理

## 违法后果

- **违反三同时规定**：防治污染的设施未建成、未经验收或验收不合格即投入生产使用
- **处罚**：责令停止生产使用，处20万元-100万元罚款；情节严重责令关闭
- **对直接责任人**：处5万元-20万元罚款

## 关联概念

- 环境影响评价 → 三同时的上游制度
- 排污许可 → 三同时的下游制度
- [[sources/laws/eco_import/生态环境法律体系概览.md|生态环境法律体系概览]] → 制度在法律体系中的定位

## 制度历史

三同时制度起源于1973年全国第一次环境保护会议，1979年《环境保护法（试行）》首次确立，是中国环境管理历史最悠久的制度之一，现已被 生态环境法典 全面吸收。

## 改革趋势（2026年）

- 竣工环保验收已由审批制改为建设单位自主验收
- 三同时与排污许可的衔接更加紧密
- 事中事后监管加强，验收信息须公开
