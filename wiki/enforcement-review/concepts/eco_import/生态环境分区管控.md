# 生态环境分区管控

## 概述

生态环境分区管控是以保障生态功能和改善环境质量为目标，实施分区域差异化精准管控的环境管理制度。2024年3月，中共中央办公厅、国务院办公厅印发《关于加强生态环境分区管控的意见》（简称"分区管控意见"），将其定位为"提升生态环境治理现代化水平的重要举措"，从国家层面系统部署。

## 制度框架

### "三线一单"核心架构

| 要素 | 说明 |
|------|------|
| **生态保护红线** | 生态功能极重要、生态环境极敏感脆弱区域的"生命线" |
| **环境质量底线** | 大气、水、土壤等环境质量目标要求 |
| **资源利用上线** | 水资源、土地资源、能源等开发利用的管控要求 |
| **生态环境准入清单** | 以管控单元为单位的差别化准入要求（"一单元一策略"） |

### 三类管控单元

| 单元类型 | 划定原则 | 管理要求 |
|---------|---------|---------|
| **优先保护单元** | 以生态保护红线为基础，划定生态功能重要区域 | 加强生态系统保护和功能维护 |
| **重点管控单元** | 环境污染重、生态破坏严重、环境风险高的区域 | 强化污染物排放管控和环境风险防控 |
| **一般管控单元** | 优先保护和重点管控以外的区域 | 保持生态环境质量基本稳定 |

## 制度建设目标

| 阶段 | 目标 |
|------|------|
| 到2025年 | 生态环境分区管控制度基本建立，全域覆盖、精准科学的管控体系初步形成 |
| 到2035年 | 体系健全、机制顺畅、运行高效的管控制度全面建立 |

## 分区管控方案制定

实行"国家指导、省级统筹、市级落地"的分级编制发布机制：
1. 省级、市级生态环境分区管控方案由同级政府组织编制
2. 与国土空间规划"一张图"系统衔接
3. 报上一级生态环境主管部门备案后发布实施
4. 原则上每5年定期调整，结合国民经济和社会发展规划、国土空间规划评估

## 促进高质量发展

### 服务国家重大战略

- **长江经济带**：全流域按单元精细化分区管控，加强沿江重化工业水污染防治
- **黄河流域**：上中下游差异化分区管控，优化能源化工和新能源产业布局
- **京津冀、长三角、粤港澳**：分区管控在产业、能源和交通运输结构调整中的应用

### 促进绿色低碳发展

- 落实高耗能、高排放、低水平项目管理政策
- 引导重化工业向环境容量大的地区转移
- 推动传统产业绿色低碳转型升级和清洁生产改造
- 衔接准入清单，优化优先保护单元管理，支持生态产品价值实现

## 高水平生态环境保护

- **维护生态安全格局**：生态保护红线、生物多样性保护、气候变化适应
- **推动环境质量改善**：流域分区管控、近岸海域陆海统筹、大气分区分类管控、土壤分类管理
- **强化政策协同**：与国土空间规划衔接、减污降碳协同试点、与环境影响评价/排污许可/执法监管联动

## 监督考核

- 纳入**中央和省级生态环境保护督察**
- 纳入**污染防治攻坚战成效考核**
- 考核结果作为**领导班子和领导干部综合考核评价**的重要参考
- 利用大数据、卫星遥感、无人机等技术手段动态监控

## 制度配套：生态环境分区管控管理暂行规定（2024）

2024年7月，生态环境部印发《生态环境分区管控管理暂行规定》（环环评〔2024〕41号），作为落实中办国办意见的操作性规章：

| 内容 | 规定要点 |
|------|---------|
| **方案编制** | 省级、市级分区管控方案由同级政府组织编制，与国土空间规划"一张图"衔接 |
| **发布程序** | 报上一级生态环境主管部门备案后发布实施 |
| **调整周期** | 原则上每5年定期调整 |
| **三类单元** | 优先保护单元（加强生态功能维护）、重点管控单元（强化排放管控）、一般管控单元（保持稳定） |

该规定建立了分区管控从方案编制、审批发布、实施落实到监督考核的全流程管理制度，为全国统一的分区管控体系提供了制度保障。
