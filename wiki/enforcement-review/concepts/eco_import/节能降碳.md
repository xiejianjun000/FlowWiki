# 节能降碳

## 概述

节能降碳是积极稳妥推进碳达峰碳中和、全面推进美丽中国建设、促进经济社会发展全面绿色转型的重要举措。2024年国务院发布《2024-2025年节能降碳行动方案》（国发〔2024〕12号），系统部署节能降碳十大重点任务。

## 2024-2025年节能降碳目标

| 指标 | 2024年目标 | 2025年目标 |
|------|-----------|-----------|
| 单位GDP能源消耗降低 | 2.5%左右 | - |
| 单位GDP二氧化碳排放降低 | 3.9%左右 | - |
| 规模以上工业单位增加值能耗降低 | 3.5%左右 | - |
| 非化石能源消费占比 | 18.9%左右 | 20%左右 |
| 节能降碳改造年节能量 | 约5000万吨标准煤 | 约5000万吨标准煤 |
| 节能降碳改造年减排二氧化碳 | 约1.3亿吨 | 约1.3亿吨 |

## 十大重点任务

### 1. 化石能源消费减量替代
- 严格合理控制煤炭消费，煤电"三改联动"（节能、灵活性、供热）
- 大气污染防治重点区域散煤基本清零
- 合理调控石油消费，加快非常规油气资源开发

### 2. 非化石能源消费提升
- 大型风电光伏基地（沙戈荒）建设
- 海上风电、分布式新能源、水电、核电、生物质能、氢能
- 2025年非化石能源发电量占比39%，抽水蓄能6200万千瓦

### 3-6. 重点行业节能降碳

| 行业 | 2025年底目标 | 改造节能/减排量 |
|------|-------------|----------------|
| **钢铁** | 电炉钢占比15%，废钢利用3亿吨，80%产能超低排放 | 2000万吨标煤/5300万吨CO2 |
| **石化化工** | 炼油能力控制在10亿吨以内 | 4000万吨标煤/1.1亿吨CO2 |
| **有色金属** | 电解铝可再生能源使用比例25%+，再生金属占比24%+ | 500万吨标煤/1300万吨CO2 |
| **建材** | 水泥熟料产能控制在18亿吨，50%产能超低排放 | 1000万吨标煤/2600万吨CO2 |

### 7. 建筑节能降碳
- 新建建筑全面执行绿色建筑标准
- 建筑光伏一体化、存量建筑节能改造
- 2025年屋顶光伏覆盖率力争50%，既有改造面积2亿平方米+
- 参考：《加快推动建筑领域节能降碳工作方案》（国办函〔2024〕20号）

### 8. 交通运输节能降碳
- 新能源汽车推广、公共领域车辆电动化
- 大宗货物"公转铁"、"公转水"
- 2025年交通运输CO2强度较2020年降低5%

### 9. 公共机构节能降碳
- 单位建筑面积能耗降低5%，碳排放降低7%

### 10. 用能产品设备节能降碳
- 工业锅炉、电机、变压器、制冷设备等更新换代
- 废旧产品设备循环利用

## 管理机制创新

### 碳排放双控转型

从"能耗双控"向"碳排放双控"转变，落实原料用能和非化石能源不纳入能源消耗总量和强度调控。

### 固定资产投资项目管控

- 节能审查与环评审批联动
- 碳排放评价纳入节能审查
- 坚决遏制高耗能、高排放、低水平项目盲目上马
- 重大项目节能审查权限动态调整机制

### 市场化机制

| 机制 | 进展 |
|------|------|
| 全国碳市场 | 有偿分配引入，覆盖范围扩大（含建材、钢铁等） |
| CCER自愿减排市场 | 方法学体系扩展至十余个领域 |
| 绿证交易 | 2024年底实现核发全覆盖 |
| 用能权交易 | 支持跨省交易 |

## 设备更新与节能降碳的协同

《推动大规模设备更新和消费品以旧换新行动方案》（国发〔2024〕7号）与节能降碳行动方案协同推进，围绕节能降碳、超低排放等方向推动设备更新和技术改造，到2027年重点行业主要用能设备能效基本达到节能水平。

## 2026年重要进展

### 碳达峰碳中和综合评价考核

2026年2月26日，中央政治局常委会审议通过《碳达峰碳中和综合评价考核办法》（（新闻动态链接）），建立系统化、指标化、可操作化的闭环监督机制。重点考核内容包括：
- **碳排放强度**（非绝对量）
- 能源结构调整
- 重点行业减排
- 生态系统碳汇
- 政策体系与能力建设

### 碳排放双控转型加速

从"能耗双控"向"碳排放双控"转变持续深化，2026年碳市场行业扩容至钢铁/水泥/铝冶炼，覆盖全国约65%碳排放（（新闻动态链接））。

### AI能耗对节能降碳的新挑战

AI算力扩张带来数据中心电力需求激增（详见 synthesis/topics/AI在生态环境领域的应用趋势#二、AI-能源消耗与环境影响）：
- PJM容量价格因数据中心需求暴涨9.3倍（IEEFA）
- 中国"东数西算"工程体现前瞻布局
- 绿色算力、低碳数据中心成为新课题
