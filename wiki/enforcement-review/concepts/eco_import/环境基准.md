# 环境基准

## 定义

环境基准（Environmental Benchmark/Criteria）是指环境中污染物对人体健康或生态系统不产生不良或有害影响的最大剂量、浓度或水平。环境基准是**纯科学**概念，它反映污染物暴露与效应的客观关系，不涉及经济技术可行性考量，区别于含有管理决策因素的"环境标准"。

## 环境基准与环境标准的区别

| 对比维度 | 环境基准 | 环境标准 |
|---------|---------|---------|
| 性质 | 科学依据 | 管理工具 |
| 确定依据 | 剂量-效应关系 | 基准 + 经济技术可行性 |
| 强制性 | 无（科学参考） | 有（法律法规强制执行） |
| 修订周期 | 随科学认知更新 | 随管理和技术发展更新 |

## 中国环境基准体系

### 类型划分

| 基准类型 | 保护对象 | 现状 |
|---------|---------|------|
| 淡水水生生物水质基准 | 淡水水生生物 | 已发布镉、氨氮、苯酚、锌 |
| 海洋生物水质基准 | 海洋生物 | 2022年发布推导指南，2026年发布首个基准（镉） |
| 湖泊营养物基准 | 湖泊生态系统 | 中东部湖区已发布，云贵/东南湖区在征求意见 |
| 人体健康水质基准 | 人体健康 | 研究推进中 |
| 土壤环境基准 | 土壤生态/人体健康 | 研究推进中 |

### 基准推导方法

中国已建立规范化的基准推导技术方法：

**淡水生物水质基准推导（HJ 831—2022）**：
1. 收集筛选毒性数据
2. 计算物种敏感度分布（SSD）
3. 推导基准最大浓度（CMC）和基准连续浓度（CCC）
4. 专家判断与审定

**海洋生物水质基准推导（HJ 1260—2022，试行）**：
- 在淡水推导方法基础上，考虑海洋生态系统特征
- 涵盖咸水生物毒性数据要求

### 数据标准化（2025年）

2025年发布的16项《水生生物水质基准推导基本数据集》标准，实现了基准推导数据的全面标准化，涵盖：

- 数据格式和元数据规范
- 毒性数据质量评价
- 数据共享和交换标准

## 基准在水环境管理中的应用

```
环境基准 ← 科学依据
    ↓
环境质量标准 ← 管理目标
    ↓
污染物排放标准 ← 控制手段
    ↓
排污许可 ← 执行工具
```

## 国际比较

- **美国**：EPA制定水质基准（Criteria），各州据此制定水质标准（Standards），体系最为成熟
- **欧盟**：环境质量基准（EQS）作为水框架指令的组成部分，强调生态保护
- **中国**：2019年正式启动基准体系建设，已覆盖淡水、海洋、湖泊等多种水环境类型
