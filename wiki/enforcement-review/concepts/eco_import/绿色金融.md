# 绿色金融

## 概览

绿色金融是指为支持环境改善、应对气候变化和资源节约高效利用的经济活动所提供的金融服务。它是生态文明建设的重要支撑，通过金融杠杆引导资金流向绿色低碳领域，推动经济社会绿色转型。

中国已构建以绿色信贷、绿色债券、ESG投资、碳金融为支柱的绿色金融体系，并建立了绿色金融改革创新试验区。中国人民银行、生态环境部、金融监管总局等多部门协同推进绿色金融标准体系建设。

## 核心内容

### 绿色金融体系框架

```
绿色金融体系
├── 绿色信贷 — 银行信贷向绿色项目倾斜
├── 绿色债券 — 募集资金专项用于绿色项目
├── 绿色保险 — 环境污染责任保险等
├── 绿色基金 — 政府引导基金、ESG基金
├── ESG投资 — 环境、社会和治理因素纳入投资决策
└── 碳金融 — 碳配额交易、CCER、碳期货等
```

### 绿色信贷

- **定义**：银行业金融机构为支持绿色、低碳、循环经济而提供的信贷服务
- **监管要求**：绿色信贷统计制度、绿色信贷业绩评价
- **重点投向**：节能环保、清洁能源、绿色交通、绿色建筑、生态保护等
- **成效**：中国绿色信贷规模全球最大，二十多家主要银行绿色信贷余额超30万亿元

### 绿色债券

- **定义**：募集资金专门用于绿色产业项目的有价证券
- **标准**：《绿色债券支持项目目录（2021年版）》统一了国内绿色债券标准
- **品种**：绿色金融债、绿色企业债、绿色公司债、绿色债务融资工具、绿色资产支持证券
- **创新**：碳中和债券、蓝色债券、转型债券、可持续发展挂钩债券

### ESG投资

ESG（环境、社会和治理）是衡量企业可持续发展绩效的三大维度：

| 维度 | 主要内容 |
|------|---------|
| **E（环境）** | 碳排放、资源消耗、污染防治、生物多样性影响 |
| **S（社会）** | 员工权益、社区关系、产品安全、数据隐私 |
| **G（治理）** | 董事会结构、股东权利、信息披露、商业道德 |

**发展动态**：

- 沪深北三大交易所2024年发布可持续发展报告指引，部分上市公司强制披露
- 财政部2024年发布《企业可持续披露准则——基本准则（征求意见稿）》
- 中国ESG评级体系逐步完善
- 国际可持续准则理事会（ISSB）准则IFRS S1、S2的采纳

### 碳金融

碳金融是以碳排放权为核心的金融产品和服务：

| 产品类型 | 说明 | 发展现状 |
|---------|------|---------|
| 碳排放配额交易 | 全国碳市场配额现货交易 | 2025年交易活跃，覆盖行业扩大 |
| CCER交易 | 国家核证自愿减排量 | 2025年方法学扩展至十余领域 |
| 碳配额质押融资 | 以碳配额为质押物的信贷 | 多省开展试点 |
| 碳远期/碳期货 | 碳配额远期合约交易 | 广州期货交易所推进碳期货 |
| 碳保险 | 碳资产价值保障、碳信用保险 | 创新产品逐步涌现 |

详见 碳排放权交易与碳市场。

### 绿色金融改革创新试验区

- **六省九地**：浙江（湖州、衢州）、广东（广州）、贵州（贵安新区）、江西（赣江新区）、甘肃（兰州新区）、新疆（哈密、克拉玛依、昌吉）
- **特色**：各试验区聚焦差异化创新（绿色建筑、绿色农业、绿色矿业等）
- **升级**：2023-2024年试验区扩容和深化方案持续推进

### 绿色金融标准体系

| 标准类型 | 标准名称/编号 |
|---------|-------------|
| 绿色信贷标准 | 绿色信贷指引、绿色信贷统计制度 |
| 绿色债券标准 | 绿色债券支持项目目录（2021年版） |
| ESG披露标准 | 上市公司可持续发展报告指引 |
| 环境信息披露 | 金融机构环境信息披露指南 |
| 碳核算标准 | 金融机构碳核算指南 |

### 绿色金融与碳市场的协同

- **碳配额资产化**：碳配额可作为抵质押品获得绿色信贷
- **CCER价值实现**：CCER为绿色项目提供额外收益来源
- **绿色债券与碳减排挂钩**：可持续发展挂钩债券绑定碳减排目标
- **ESG与碳管理的融合**：企业碳排放数据是ESG评级的关键指标
