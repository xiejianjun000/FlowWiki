# 畜禽养殖污染防治规范汇编

## 一、总则

### 1.1 立法目的

- 防治畜禽养殖污染
- 保护和改善环境
- 促进畜牧业可持续发展
- 保障畜禽产品安全

### 1.2 立法依据

- 《中华人民共和国环境保护法》
- 《中华人民共和国畜牧法》
- 《中华人民共和国动物防疫法》
- 《畜禽规模养殖污染防治条例》（国务院令第643号）
- 《中华人民共和国水污染防治法》
- 《中华人民共和国大气污染防治法》
- 《中华人民共和国固体废物污染环境防治法》

### 1.3 适用范围

- 适用于畜禽规模养殖场、养殖小区
- 适用于养殖专业户
- 适用于畜禽养殖污染防治设施建设、运行
- 适用于畜禽粪污资源化利用

## 二、规模养殖分级

### 2.1 规模等级

#### 生猪

| 规模等级 | 年出栏量（头） |
|---------|--------------|
| 大型 | ≥ 50000 |
| 中型 | 5000-50000 |
| 小型 | 500-5000 |
- 散养户 < 500

#### 奶牛

| 规模等级 | 存栏量（头） |
|---------|------------|
| 大型 | ≥ 1000 |
| 中型 | 100-1000 |
| 小型 | 20-100 |

#### 肉牛

| 规模等级 | 年出栏量（头） |
|---------|--------------|
| 大型 | ≥ 1000 |
| 中型 | 100-1000 |
| 小型 | 10-100 |

#### 蛋鸡

| 规模等级 | 存栏量（只） |
|---------|------------|
| 大型 | ≥ 100000 |
| 中型 | 10000-100000 |
| 小型 | 1000-10000 |

#### 肉鸡

| 规模等级 | 年出栏量（只） |
|---------|--------------|
| 大型 | ≥ 100000 |
| 中型 | 10000-100000 |
| 小型 | 1000-10000 |

### 2.2 管理要求

- 规模以上养殖场必须办理排污许可证
- 规模以下养殖专业户进行登记备案

## 三、禁养区管理

### 3.1 禁养区划定

#### 禁养区范围

1. 饮用水水源一级保护区
2. 自然保护区的核心区和缓冲区
3. 风景名胜区核心景区
4. 城镇居民区、文化教育科学研究区等人口集中区域
5. 法律法规规定的其他禁止养殖的区域

### 3.2 限养区划定

#### 限养区范围

1. 饮用水水源二级保护区
2. 自然保护区实验区
3. 风景名胜区非核心景区
4. 城镇规划区周边 1 km 范围
5. 主要交通干线两侧 500 m 范围
6. 法律法规规定的其他限制养殖的区域

### 3.3 适养区管理

- 适养区可以新建、扩建规模养殖场
- 必须符合环保要求
- 必须配套粪污处理设施

## 四、畜禽养殖污染物排放标准

### 4.1 GB 18596-2001 畜禽养殖业污染物排放标准

#### 废水排放限值

| 项目 | 集约化畜禽养殖场（mg/L） | 集约化畜禽养殖区（mg/L） |
|------|---------------------|---------------------|
| 五日生化需氧量（BOD₅） | 150 | 200 |
| 化学需氧量（COD） | 400 | 500 |
| 悬浮物（SS） | 200 | 250 |
| 氨氮 | 80 | 80 |
| 总磷（以P计） | 8.0 | 8.0 |
| 粪大肠菌群数 | 10000 个/L | 10000 个/L |
| 蛔虫卵 | 2.0 个/L | 2.0 个/L |

#### 废渣无害化标准

| 项目 | 限值 |
|------|------|
| 蛔虫卵 | 死亡率 ≥ 95% |
| 粪大肠菌群数 | ≤ 10⁵ 个/kg |

#### 恶臭污染物排放标准

| 项目 | 限值 |
|------|------|
| 臭气浓度（无量纲） | 70 |

### 4.2 行业特征排放标准

#### GB 18596-2001 集约化畜禽养殖业恶臭污染物排放限值

| 项目 | 单位 | 限值 |
|------|------|------|
| 恶臭 | 臭气浓度 | 70 |
| NH₃ | mg/m³ | 1.5 |
| H₂S | mg/m³ | 0.06 |

## 五、畜禽粪污资源化利用

### 5.1 资源化利用方式

#### 肥料化利用

##### 固体粪便

- 好氧堆肥
- 厌氧发酵
- 干燥制粒

##### 液体粪污

- 沼气工程
- 沼液还田
- 厌氧发酵

#### 能源化利用

- 沼气发电
- 沼气供暖
- 沼气做饭
- 生物天然气

#### 饲料化利用

- 鸡粪饲料化
- 蚯蚓养殖
- 黑水虻养殖

#### 基料化利用

- 食用菌基料
- 有机肥原料

### 5.2 资源化利用要求

#### 还田利用要求

1. **土地匹配**：与农田面积匹配
2. **处理达标**：粪污经无害化处理
3. **运输规范**：密封运输，避免渗漏
4. **施用规范**：避免雨季施用，避免地表径流

#### 还田标准

| 作物 | 粪肥施用量（t/亩·年） |
|------|-------------------|
| 玉米 | 2-3 |
| 小麦 | 2-3 |
| 水稻 | 1-2 |
| 蔬菜 | 1-2 |
| 果树 | 3-5 |
| 牧草 | 3-5 |

### 5.3 主要处理技术

#### 好氧堆肥

##### 工艺流程

1. 调节碳氮比至 25:1-30:1
2. 调节含水率至 50%-60%
3. 加入菌种
4. 发酵温度 55-65℃
5. 翻堆通风
6. 发酵周期 15-30 天
7. 后熟 30 天

##### 质量指标

| 指标 | 要求 |
|------|------|
| 含水率 | ≤ 30% |
| 有机质 | ≥ 30% |
| 总养分（N+P₂O₅+K₂O） | ≥ 4% |
| pH | 5.5-8.5 |
| 蛔虫卵死亡率 | ≥ 95% |
| 粪大肠菌群数 | ≤ 100 个/g |
| 重金属（Pb） | ≤ 50 mg/kg |
| 重金属（Cd） | ≤ 3 mg/kg |
| 重金属（Hg） | ≤ 2 mg/kg |
| 重金属（As） | ≤ 15 mg/kg |
| 重金属（Cr） | ≤ 150 mg/kg |

#### 沼气工程

##### 工艺流程

1. 预处理：格栅、固液分离
2. 厌氧发酵：CSTR、UASB 等
3. 沼气利用：发电、供暖
4. 沼液沼渣：还田利用

##### 设计参数

| 参数 | 数值 |
|------|------|
| 发酵温度 | 中温 35-38℃；高温 50-55℃ |
| 料液浓度 | 6%-10% |
| 停留时间 | 中温 20-30 天；高温 10-15 天 |
| 容积产气率 | 中温 0.8-1.5 m³/m³·d；高温 1.5-3.0 m³/m³·d |

## 六、养殖污染防治设施

### 6.1 设施类型

#### 粪污收集设施

| 设施 | 适用场景 |
|------|---------|
| 漏缝地板 | 猪舍、鸡舍 |
| 刮粪板 | 猪舍、鸡舍 |
| 传送带 | 鸡舍 |
| 水冲粪 | 猪舍（已淘汰） |
| 干清粪 | 各种养殖场 |

#### 粪污贮存设施

| 设施 | 适用场景 |
|------|---------|
| 粪污贮存池 | 液体粪污 |
| 堆粪场 | 固体粪便 |
| 沼气池 | 厌氧发酵 |

#### 粪污处理设施

| 设施 | 适用场景 |
|------|---------|
| 堆肥设备 | 固体粪便 |
| 沼气工程 | 液体粪污 |
- 固液分离设备
| 污水处理设备 | 养殖废水 |

### 6.2 设施建设要求

#### 粪污贮存池

1. 容积：≥ 3 个月的粪污产生量
2. 防渗：HDPE 防渗膜
3. 防雨：加盖封闭
4. 防臭：加盖密闭

#### 堆肥场

1. 面积：满足堆肥需求
2. 防雨：加盖封闭
3. 防渗：混凝土防渗
4. 通风：通风系统

#### 沼气工程

1. 容积：满足发酵要求
2. 防渗：搪瓷钢板、混凝土
3. 保温：保温层
4. 安全：沼气利用安全设施

### 6.3 雨污分流

#### 分流要求

- 雨水、污水分开收集
- 雨水直接排放
- 污水进入处理系统

#### 实施措施

1. 雨水沟：明沟或暗管
2. 污水沟：暗管
3. 雨水井：收集雨水
4. 污水井：收集污水

## 七、恶臭污染防治

### 7.1 恶臭来源

| 来源 | 主要恶臭物质 |
|------|------------|
| 畜舍 | NH₃、H₂S、VOCs |
| 粪污贮存 | NH₃、H₂S、VOCs |
| 堆肥 | NH₃、VOCs |
| 沼气工程 | H₂S、NH₃ |

### 7.2 恶臭控制措施

#### 源头控制

1. 选用低臭饲料
2. 添加除臭剂
3. 及时清粪
4. 控制饲养密度

#### 过程控制

1. 集中通风
2. 生物除臭
3. 化学除臭
4. 物理除臭

#### 末端治理

1. 生物滤池
2. 化学洗涤
3. 活性炭吸附
4. 等离子体

## 八、动物疫病防控与环境保护

### 8.1 病死畜禽处置

#### 处置方式

| 方式 | 适用场景 |
|------|---------|
| 焚烧 | 重大疫病 |
- 化制
| 深埋 | 一般病死畜禽
| 堆肥 | 一般病死畜禽 |

#### 处置要求

1. 病死畜禽应及时处置
2. 处置前应消毒
3. 处置过程避免污染
4. 建立处置记录

### 8.2 兽药使用管理

#### 兽药使用要求

1. 按规定使用兽药
2. 严格执行休药期
3. 不得使用禁用兽药
4. 建立兽药使用记录

#### 兽药包装废弃物处置

- 按危险废物管理
- 委托有资质单位处置
- 建立回收台账

## 十一、对企业环保合规工作的启示

1. **依法选址**：不在禁养区建设养殖场
2. **配套污染防治设施**：按规模配套粪污处理设施
3. **规范运行设施**：保证设施正常运行
4. **资源化利用**：粪污资源化利用，实现零排放
5. **建立台账**：建立粪污资源化利用台账
6. **妥善处置病死畜禽**：按规定处置病死畜禽
7. **依法使用兽药**：按规定使用兽药，建立使用记录
8. **开展监测**：定期开展污染物监测
9. **配合监管**：配合生态环境、农业农村部门监管
10. **完善档案**：完整保存污染防治档案
