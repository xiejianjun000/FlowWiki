# 环境影响评价技术导则 总纲详解

## 一、标准基本信息

- **标准号**：HJ 2.1-2016
- **标准名称**：建设项目环境影响评价技术导则 总纲
- **替代标准**：HJ/T 2.1-2011
- **实施日期**：2017年1月1日
- **归口部门**：生态环境部

## 二、总则

### 2.1 适用范围

本标准适用于：
- 建设项目环境影响评价
- 环境影响后评价
- 环境影响评价文件的编制与审查

### 2.2 评价原则

1. **依法评价**：严格执行环保法律法规、标准、政策
2. **科学评价**：客观、公开、公正
3. **突出重点**：关注主要环境影响和主要保护目标
4. **等级恰当**：评价工作等级与工程特征、环境特征相适应
5. **数据可靠**：数据来源真实、有效
6. **结论明确**：评价结论明确、可信

### 2.3 评价工作程序

```
研究有关文件 → 进行工程分析 → 评价工作分级
        ↓
确定评价范围、内容、标准
        ↓
环境现状调查、监测与评价
        ↓
环境影响预测与评价
        ↓
环保措施及其技术经济论证
        ↓
环境管理与监测计划
        ↓
环境影响评价结论
```

## 三、工程分析

### 3.1 工程分析基本原则

1. 工程分析应全过程、全时段
2. 涵盖施工期、运营期、退役期
3. 明确污染源源强及排放参数

### 3.2 工程分析内容

#### 3.2.1 项目基本情况

- 项目名称、建设地点
- 建设性质（新建、改建、扩建）
- 建设规模及主要内容
- 总投资及环保投资
- 占地面积及土地利用
- 职工人数及工作制度

#### 3.2.2 工艺流程

- 工艺流程图
- 主要原辅材料
- 主要能源消耗
- 水量平衡图
- 物料平衡图

#### 3.2.3 污染源源强核算

| 污染源类型 | 核算内容 |
|------------|----------|
| 废气 | 排放浓度、排放量、排放参数 |
| 废水 | 排放浓度、排放量 |
| 噪声 | 源强、声压级、频谱特性 |
| 固体废物 | 种类、产生量、利用处置方式 |
| 地下水 | 入渗量、入渗速率 |
| 生态 | 占地范围、植被破坏、土石方量 |
| 环境风险 | 风险源、风险物质、最大可信事故 |

### 3.3 污染源源强核算方法

1. **实测法**：同类项目实测数据
2. **物料衡算法**：基于物料守恒
3. **产污系数法**：参照行业产污系数手册
4. **实验法**：实验测试
5. **类比法**：参照同类项目

### 3.4 全时段分析

#### 3.4.1 施工期

- 施工机械排放
- 施工废水、生活污水
- 建筑垃圾、生活垃圾
- 噪声、扬尘
- 生态扰动

#### 3.4.2 运营期

- 主要污染源
- 排放参数
- 环境影响

#### 3.4.3 服务期满后（退役期）

- 拆除过程污染
- 残留污染物
- 土壤、地下水污染修复
- 生态恢复

## 四、环境质量现状评价

### 4.1 环境功能区划

明确评价区域各环境要素功能区划：
- 大气环境功能区（一类区、二类区、三类区）
- 地表水环境功能区（Ⅰ类至Ⅴ类）
- 地下水环境功能区
- 声环境功能区（0类至4类）
- 生态功能区

### 4.2 环境质量现状调查

#### 4.2.1 调查范围

按各专项导则确定：
- 大气：以排放源为中心，1-5km范围
- 地表水：上下游、湖库全库区
- 地下水：场地及周边
- 声环境：厂界外200m范围
- 生态：项目占地及周边1km

#### 4.2.2 调查因子

| 环境要素 | 调查因子 |
|----------|----------|
| 大气 | SO₂、NO₂、PM₁₀、PM₂.₅、CO、O₃、TSP及特征污染物 |
| 地表水 | pH、COD、BOD、NH₃-N、TP、TN及特征污染物 |
| 地下水 | pH、总硬度、硫酸盐、氯化物等及特征污染物 |
| 声环境 | 等效连续A声级 |
| 生态 | 植被、土壤、动物、生物多样性 |

#### 4.2.3 监测要求

- 监测点位布设原则
- 监测频次
- 监测方法标准
- 质量保证

## 五、环境影响预测与评价

### 5.1 预测基本原则

- 预测因子与评价因子一致
- 预测时段包括施工期、运营期
- 预测情景：正常排放、非正常排放
- 预测范围与评价范围一致

### 5.2 预测方法

1. **数学模式法**：常规方法
2. **物理模型法**：复杂地形、特殊流场
3. **类比调查法**：参照同类项目
4. **专业判断法**：定性分析

### 5.3 预测内容

| 环境要素 | 预测内容 |
|----------|----------|
| 大气 | 1h平均、日平均、年平均浓度 |
| 地表水 | 水质浓度场分布 |
| 地下水 | 污染物迁移范围、浓度 |
| 声环境 | 等效声级分布 |
| 生态 | 植被破坏、生物多样性影响 |
| 环境风险 | 事故影响范围、持续时间 |

### 5.4 评价标准

- 大气：环境空气质量标准（GB 3095-2012）二级
- 地表水：地表水环境质量标准（GB 3838-2002）相应类别
- 地下水：地下水质量标准（GB/T 14848-2017）相应类别
- 声环境：声环境质量标准（GB 3096-2008）相应类别
- 生态：根据生态功能区划确定

## 六、环境保护措施

### 6.1 措施分类

1. **预防措施**：从源头减少污染
2. **治理措施**：末端治理
3. **回收利用措施**：资源化
4. **生态保护措施**：植被恢复、水土保持
5. **环境风险防范措施**：应急预案、监测预警

### 6.2 措施论证内容

- 措施的技术可行性
- 措施的经济合理性
- 措施的达标可靠性
- 措施的运行管理要求

### 6.3 环保投资估算

- 环保设施投资
- 环保设施运行费用
- 环保投资占项目总投资比例

## 七、环境管理与监测计划

### 7.1 环境管理

1. 环境管理机构设置
2. 环境管理制度
3. 环境管理人员职责
4. 环境管理台账

### 7.2 环境监测计划

#### 7.2.1 排污口监测

| 排放源 | 监测因子 | 监测频次 |
|--------|----------|----------|
| 废气排放口 | 主要污染物 | 每月1次 |
| 废水排放口 | 主要污染物 | 每周1次 |
| 厂界噪声 | 等效声级 | 每季度1次 |
| 厂界无组织 | 主要污染物 | 每季度1次 |

#### 7.2.2 环境质量监测

- 监测点位
- 监测因子
- 监测频次

### 7.3 环境风险事故应急预案

- 应急组织机构
- 应急设施
- 应急程序
- 应急培训与演练

## 八、环境影响评价结论

### 8.1 评价结论内容

1. 项目建设必要性、可行性
2. 项目主要环境影响
3. 环境保护措施可行性
4. 项目环境可行性结论
5. 项目实施的条件、要求

### 8.2 评价结论要求

- 结论明确、具体
- 数据可信、来源可靠
- 突出重点、抓住关键
- 建议、对策具有可操作性

## 九、专项评价工作等级

### 9.1 大气环境评价工作等级

依据HJ 2.2-2018确定：

| 评价等级 | 判定条件 |
|----------|----------|
| 一级 | Pmax ≥ 10% |
| 二级 | 1% ≤ Pmax < 10% |
| 三级 | Pmax < 1% |

Pmax为污染物最大占标率。

### 9.2 地表水评价工作等级

依据HJ 2.3-2018确定：

| 评价等级 | 判定条件 |
|----------|----------|
| 一级 | 排水量大、影响显著 |
| 二级 | 排水量中等、影响一般 |
| 三级 | 排水量小、影响轻微 |

### 9.3 地下水评价工作等级

依据HJ 610-2016确定：

| 评价等级 | 判定条件 |
|----------|----------|
| 一级 | 项目类别I类、环境敏感 |
| 二级 | 项目类别II类、环境一般敏感 |
| 三级 | 项目类别III类、环境不敏感 |

### 9.4 声环境评价工作等级

依据HJ 2.4-2021确定：

| 评价等级 | 判定条件 |
|----------|----------|
| 一级 | 4类区或 noise ≥ 5dB(A) |
| 二级 | 2-3类区或 noise ≥ 3dB(A) |
| 三级 | 1类区或 noise < 3dB(A) |

### 9.5 生态影响评价工作等级

依据HJ 19-2022确定：

| 评价等级 | 判定条件 |
|----------|----------|
| 一级 | 影响范围大、生态敏感 |
| 二级 | 影响范围中等、生态一般敏感 |
| 三级 | 影响范围小、生态不敏感 |

## 十、对企业环保合规工作的启示

1. **环评报告应全面**：覆盖施工期、运营期、退役期全过程，避免漏项
2. **源强核算依据充分**：采用实测、物料衡算、产污系数等方法，确保源强数据可信
3. **现状监测数据可靠**：监测点位、频次、方法应符合规范要求
4. **预测模式选择合理**：根据地形、气象、水文等条件选择适宜模式
5. **环保措施可行**：技术可行、经济合理、达标可靠
6. **应急措施健全**：环境风险防范措施到位
7. **公众参与到位**：依法开展公众参与，信息公开
8. **跟踪监测到位**：落实环境管理与监测计划
9. **专项评价等级恰当**：避免过度评价或评价不足
10. **跨专项协调一致**：各专项评价结论应相互协调，避免矛盾

## 十一、相关法规依据

- 《中华人民共和国环境影响评价法》（2018年修订）
- 《建设项目环境保护管理条例》（国务院第682号令）
- 《建设项目环境影响报告书（表）编制监督管理办法》
- 《关于进一步加强环境影响评价违法案件查办工作的通知》

## 十二、违法处罚依据

### 12.1 环评法第31条

未依法进行环境影响评价的建设项目，擅自开工建设的，由县级以上生态环境主管部门责令停止建设，根据违法情节和危害后果，处建设项目总投资额**1%以上5%以下的罚款**，并可以责令恢复原状。

### 12.2 环评法第32条

环境影响评价文件存在弄虚作假的，处**50万元以上200万元以下的罚款**；情节严重的，撤销其资质证书。

### 12.3 环评法第33条

未落实环评报告书（表）及审批意见要求的建设项目，由县级以上生态环境主管部门责令限期改正，处**20万元以上100万元以下的罚款**。
