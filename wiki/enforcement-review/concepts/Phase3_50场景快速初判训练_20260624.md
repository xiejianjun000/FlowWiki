# Phase 3A——50个场景快速初判训练题库

> **训练目标**：模拟指挥长接到报告后30秒内完成快速初判
> 
> **难度分布**：简单（20个）| 中等（20个）| 困难（10个）
> 
> **类型分布**：化学品泄漏（8）| 火灾次生（7）| 爆炸次生（7）| 废水偷排（7）| 尾矿库泄漏（7）| 交通次生（7）| 核与辐射（7）


---

## 使用说明

1. 每个场景单独展示，训练者看到"接报信息"后，30秒内完成初判
2. 初判要素：**事件类型、涉及物质、等级判断、报告时限、前三件事**
3. 完成后对照"参考答案与易错点"进行复盘
4. 易错点部分是训练核心，务必仔细研读

2. 物质：98%硫酸（第8类腐蚀品，UN1830）

### 场景04 [难度：中等] [类型：化学品泄漏]

**接报信息：**
- 时间：2025年9月3日 16:30
- 地点：某氰化钠生产企业仓库
- 报告人：企业安环部经理
- 事件简述：仓库发生火灾，起火点靠近氰化钠包装储存区。仓库内存有氰化钠约5吨（50kg/桶，共100桶）。消防正在扑救，但担心消防废水可能携带氰化钠外溢。企业已停止向雨水排口排水。最近地表水体距仓库约200米。

**【训练者作答区】**
1. 事件类型：________
2. 可能涉及物质：________
3. 初步等级判断：□特别重大 □重大 □较大 □一般 □无法判明
4. 信息报告时限：初报最迟______小时内
5. 立即部署的前3件事：________

**参考答案与易错点：**

1. 类型：火灾次生剧毒化学品泄漏
2. 物质：氰化钠（第6.1类剧毒固体，UN1689）+ 火灾可能产生的氰化氢气体（HCN）
3. 等级：**☑重大**
   - 依据：5吨氰化钠属大量剧毒物质，火灾可能导致HCN气体释放，消防废水若外溢将造成严重水污染，且氰化物属"特别管控危险化学品"。
4. 时限：**1小时**内初报
5. 前三件事：
   - 立即要求消防调整灭火策略，禁止使用直流水柱冲击氰化钠储存区
   - 在仓库周边设置围堰和收集池，拦截所有消防废水，禁止外排
   - 通知200米内地表水体管理部门，预置活性炭和次氯酸钠（氰化物解毒剂）应急物资
6. 易错点提醒：
   - 氰化钠遇水可水解产生氰化氢（HCN）气体，剧毒，处置人员必须佩戴正压呼吸器
   - 灭火时优先用干粉、沙土，慎重用水
   - 氰化物废水处置需用次氯酸钠氧化破氰，不能直接排放

**【训练者作答区】**
1. 事件类型：________
2. 可能涉及物质：________
3. 初步等级判断：□特别重大 □重大 □较大 □一般 □无法判明
4. 信息报告时限：初报最迟______小时内

**参考答案与易错点：**

   - 联系公安部门和生态环境部门（辐射监管），调查倾倒责任和来源
6. 易错点提醒：
   - "荧光"不一定等于放射性（某些化学物质也有荧光）
   - 但若确实是放射性废物，可能含铀、钍、镭等天然放射性物质或Cs-137等人工放射性核素
   - 非法倾倒放射性废物是犯罪行为，需公安介入

# 附录：快速初判要点总结

## 一、等级判断核心依据

| 等级 | 关键特征 |
|------|----------|
| 特别重大 | 大量剧毒/易燃易爆物质泄漏、跨省界影响、饮用水源污染、大量人员伤亡 |
| 重大 | 较大规模泄漏、涉及敏感目标（居民区/水源/生态保护区）、信息不明需按高等级上报 |
| 较大 | 中等规模泄漏、影响范围有限、物质性质相对明确 |
| 一般 | 小规模泄漏或无泄漏（险性事件）、影响范围小、无敏感目标 |
| 无法判明 | 信息严重不足、物质不明、可能影响重大→按重大上报 |

## 二、30秒初判顺序

1. **听**：接报信息中获取关键要素（地点、物质、泄漏量、敏感目标、气象）
2. **判类型**：化学品泄漏/火灾次生/爆炸次生/废水偷排/尾矿库/交通次生/核与辐射
3. **判物质**：根据场景信息推断可能的化学物质或污染物
4. **判等级**：根据上述核心依据快速判断
5. **报时限**：特别重大/重大→1小时；较大→4小时；一般→24小时
6. **部署事**：前三件事围绕"控制源头、保护敏感目标、预警通知"

## 三、常见易错点汇总

1. **硫酸 vs 盐酸**：硫酸禁止直接用水冲洗；盐酸可适量用水稀释
2. **氯气比空气重**：需重点监测低洼处和地下空间
3. **液氨/液化气泄漏**：比空气重，沿地面扩散，易进入地下空间
4. **PVC/含氯材料燃烧**：产生HCl，需用碱性物质中和/吸收
5. **氰化物**：遇水或高温产生HCN（氰化氢）气体，剧毒，需正压呼吸器
6. **尾矿库"干滩长度"**：变短是溃坝前兆，需立即核查
7. **放射源"三叶标志"**：识别放射性警告的关键视觉线索
8. **夜间/无风气象**：最严重的扩散条件，气体易聚集

## 四、信息报告时限速查

| 事件等级 | 初报时限 |
|----------|----------|
| 特别重大、重大 | 1小时内 |
| 较大 | 4小时内 |
| 一般 | 24小时内 |
