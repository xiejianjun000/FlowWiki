# 民航行业温室气体排放核算方法与报告指南

**文件编号**：GB/T 32151.6-2015
**发布单位**：国家市场监督管理总局、国家标准化管理委员会
**实施日期**：2016年6月1日
**适用范围**：民用航空企业温室气体排放核算与报告

---

## 一、适用范围

本指南适用于民用航空运输企业的温室气体排放核算与报告工作。

### 1.1 适用主体

- 公共航空运输企业（航空公司）
- 通用航空企业
- 机场管理机构（部分适用）
- 航空油料供应企业（部分适用）

### 1.2 不适用范围

- 纯航空维修企业
- 纯航空货运代理企业
- 军用航空企业

---

## 二、核算边界

### 2.1 组织边界

民航企业应核算其拥有或控制的所有航空器和地面设施的温室气体排放。

- **拥有**：企业具有所有权的航空器和设施
- **控制**：企业具有运营控制权的航空器和设施

### 2.2 运行边界

核算边界应包括航空运营的直接排放和间接排放。

#### 2.2.1 直接排放（范围1）

1. **航空燃油燃烧排放**：航空器飞行过程中航空燃油燃烧产生的CO₂排放
2. **地面燃油燃烧排放**：地面保障设备、车辆等燃烧化石燃料产生的排放
3. **辅助动力装置（APU）排放**：飞机APU燃油燃烧排放
4. **逸散排放**：制冷剂泄漏、灭火器使用等产生的含氟气体排放

#### 2.2.2 间接排放（范围2）

1. **购入使用电力排放**：机场设施、办公楼等购入电力产生的排放
2. **购入使用热力排放**：购入蒸汽、热水等热力产生的排放

### 2.3 飞行阶段边界

| 飞行阶段 | 排放特点 | 核算说明 |
|---------|---------|----------|
| 起飞爬升 | 燃油消耗大，排放强度高 | 计入LTO循环和巡航 |
| 巡航 | 飞行时间长，排放总量大 | 单独核算 |
| 下降进近 | 燃油消耗较小 | 计入LTO循环 |
| 着陆滑行 | 燃油消耗较小 | 计入LTO循环 |
| 地面等待 | 使用APU或地面电源 | 单独核算 |

### 2.4 LTO循环定义

LTO（起飞-着陆）循环包括以下阶段：

- 起飞（0-1000米）：约0.7分钟
- 爬升（1000-3000米）：约2.2分钟
- 进近（3000-0米）：约4.0分钟
- 滑行/地面等待：约26.0分钟

**说明**：LTO循环主要用于机场当地空气质量核算，也适用于碳排放核算。

## 三、核算方法

### 3.1 总体方法

民航行业温室气体排放核算采用**排放因子法**（燃油消耗量×排放因子）为主。

### 3.2 核算公式

```
E_total = E_flight + E_APU + E_ground + E_fugitive + E_indirect
```

其中：
- `E_total`：温室气体排放总量，单位：吨CO₂当量（tCO₂e）
- `E_flight`：航空燃油燃烧排放量，单位：tCO₂
- `E_APU`：辅助动力装置排放量，单位：tCO₂
- `E_ground`：地面设施排放量，单位：tCO₂e
- `E_fugitive`：逸散排放量，单位：tCO₂e
- `E_indirect`：间接排放量，单位：tCO₂

### 3.3 航空燃油燃烧排放核算

#### 3.3.1 方法一：燃油消耗量法（推荐）

```
E_flight = Σ (FC_ij × EF_i)
```

其中：
- `FC_ij`：第i种燃油在第j次飞行中的消耗量，单位：t
- `EF_i`：第i种燃油的CO₂排放因子，单位：tCO₂/t

#### 3.3.2 方法二：燃油销售量法

```
E_flight = Σ (FS_i × EF_i) × (1 - K)
```

其中：
- `FS_i`：第i种燃油的销售量（加注重），单位：t
- `K`：燃油储备系数（未燃烧的燃油比例）

#### 3.3.3 方法三：飞行距离法（缺省）

```
E_flight = Σ (D_j × EF_flight,j)
```

其中：
- `D_j`：第j次飞行的距离，单位：公里
- `EF_flight,j`：第j种机型的单位距离排放因子，单位：tCO₂/km

### 3.4 APU排放核算

```
E_APU = Σ (T_APU,j × FC_APU,j × EF)
```

其中：
- `T_APU,j`：第j架飞机APU使用时间，单位：小时
- `FC_APU,j`：第j架飞机APU燃油消耗率，单位：t/h
- `EF`：燃油排放因子，单位：tCO₂/t

### 3.5 地面设施排放核算

```
E_ground = E_ground_vehicle + E_ground_equipment + E_ground_boiler
```

其中：
- `E_ground_vehicle`：地面车辆燃油燃烧排放
- `E_ground_equipment`：地面设备燃油燃烧排放
- `E_ground_boiler`：锅炉等燃烧设备排放

### 3.6 逸散排放核算

#### 3.6.1 制冷剂泄漏排放

```
E_refrigerant = Σ (M_ref,i × GWP_i)
```

其中：
- `M_ref,i`：第i种制冷剂的泄漏量，单位：t
- `GWP_i`：第i种制冷剂的全球增温潜势

#### 3.6.2 灭火器使用排放

```
E_fire_extinguisher = Σ (N_j × M_j × GWP_j)
```

其中：
- `N_j`：第j种灭火器使用数量，单位：具
- `M_j`：第j种灭火器的装药量，单位：t/具
- `GWP_j`：第j种灭火剂的全球增温潜势

### 3.7 间接排放核算

```
E_indirect = AD_electricity × EF_electricity + AD_heat × EF_heat
```

## 四、温室气体种类

本指南核算的温室气体包括：

| 序号 | 温室气体种类 | 化学分子式 | 全球增温潜势（GWP） | 主要来源 |
|------|-------------|-----------|---------------------|----------|
| 1 | 二氧化碳 | CO₂ | 1 | 航空燃油燃烧、地面设施燃烧、间接排放 |
| 2 | 甲烷 | CH₄ | 28 | 燃油燃烧（少量） |
| 3 | 氧化亚氮 | N₂O | 265 | 燃油燃烧（少量） |
| 4 | 氢氟碳化物 | HFCs | 124-14800 | 制冷剂、灭火剂 |
| 5 | 全氟碳化物 | PFCs | 7390-12200 | 灭火剂（少量） |

**说明**：民航行业以CO₂排放为主，占总排放量的99%以上。HFCs等含氟气体排放量小但GWP值高，也需核算。

## 五、排放源分类

### 5.1 直接排放源

#### 5.1.1 航空燃油燃烧排放

| 排放源 | 燃油类型 | 排放设备 | 占比 |
|--------|---------|----------|------|
| 主发动机燃烧 | 航空煤油（Jet A-1） | 涡扇、涡喷发动机 | 约90% |
| APU燃烧 | 航空煤油 | 辅助动力装置 | 约3-5% |
| 地面设备 | 柴油、汽油、航空煤油 | 牵引车、电源车、气源车等 | 约2-3% |

#### 5.1.2 地面设施燃烧排放

| 排放源 | 燃料类型 | 燃烧设备 |
|--------|---------|----------|
| 锅炉燃烧 | 天然气、重油 | 采暖锅炉、热水锅炉 |
| 车辆燃烧 | 汽油、柴油 | 公务车、货运车、摆渡车 |
| 备用电源 | 柴油 | 柴油发电机 |

#### 5.1.3 逸散排放

| 排放源 | 排放原因 | 温室气体 |
|--------|---------|----------|
| 制冷剂泄漏 | 空调、冷藏设备泄漏 | HFCs |
| 灭火剂释放 | 灭火器使用、系统释放 | HFCs、PFCs |
| 燃油蒸发 | 油箱呼吸、加油作业 | VOCs（非温室气体为主） |

### 5.2 间接排放源

| 排放源 | 说明 | 占比 |
|--------|------|------|
| 购入使用电力 | 办公楼、候机楼、机库等用电 | 约3-5% |
| 购入使用热力 | 采暖、热水等热力消耗 | 较少 |

### 5.3 特殊排放源

| 排放源 | 说明 | 核算要求 |
|--------|------|----------|
| 高空凝结尾迹 | 飞机高空飞行产生的凝结尾迹 | 暂不核算，科学研究阶段 |
| 卷云诱导 | 飞机对卷云的影响 | 暂不核算，科学研究阶段 |
| 生物燃油 | 使用可持续航空燃料（SAF） | 按生命周期核算减排量 |

## 六、活动水平数据要求

### 6.1 航空燃油消耗量

#### 6.1.1 数据来源

- 优先采用**飞行数据**：飞行计划、飞行数据记录器（FDR）
- 次选采用**加油数据**：加油单、航油结算单
- 缺省采用**运营数据**：飞行里程、机型参数估算

#### 6.1.2 数据要求

| 数据项 | 计量单位 | 精度要求 | 数据频次 |
|--------|---------|----------|----------|
| 燃油加注重 | 吨（t） | ±0.5% | 每次飞行 |
| 燃油消耗量 | 吨（t） | ±1.0% | 每次飞行 |
| 燃油密度 | kg/m³ | ±0.5% | 每批次 |
| 飞行距离 | 公里（km） | ±0.1% | 每次飞行 |
| 飞行时间 | 小时（h） | ±0.1% | 每次飞行 |

#### 6.1.3 燃油类型

主要航空燃油类型：

| 燃油类型 | 适用发动机 | 排放因子 |
|---------|-----------|---------|
| 航空煤油（Jet A-1） | 涡扇、涡喷发动机 | 3.16 tCO₂/t |
| 航空汽油（Avgas） | 活塞发动机 | 3.08 tCO₂/t |
| 生物燃油（SAF） | 涡扇发动机 | 生命周期核算 |
| 柴油 | 地面设备 | 3.10 tCO₂/t |
| 汽油 | 地面车辆 | 3.04 tCO₂/t |

- 机型、机号、发动机型号

- 业载（旅客、货物、邮件）

### 6.3 APU运行数据

- APU使用时间（小时）
- APU燃油消耗率

### 6.4 地面设施数据

#### 6.4.1 地面车辆

- 车辆数量、类型
- 燃油消耗量
- 行驶里程
- 年运营天数

#### 6.4.2 地面设备

- 设备数量、类型
- 燃油消耗量
- 使用时间
- 年运行小时

### 6.5 逸散排放数据

- 制冷剂种类和充注量

- 灭火器种类和数量
- 灭火剂使用记录

### 6.6 购入电力和热力数据

- 以供电/供热企业结算单为准
- 按月统计购入量
- 区分不同用途和区域

1. **优先实测**：企业具备实测条件的，应采用实测排放因子
2. **行业缺省**：无法实测的，采用行业缺省值

## 八、数据质量管理

### 8.1 数据质量控制计划（DQCP）

企业应制定并实施数据质量控制计划，包括：

- 数据质量管理组织机构及职责
- 数据监测计划
- 数据记录和存档要求
- 数据审核机制（三级审核）
- 人员培训要求
- 仪器设备检定校准计划

### 8.2 数据质量等级

| 数据质量等级 | 活动数据要求 | 排放因子要求 | 适用情况 |
|-------------|-------------|-------------|----------|
| Ⅰ级 | 每次飞行精确计量 | 实测/制造商数据 | 大型航空公司推荐 |
| Ⅱ级 | 每日/每周汇总 | 行业缺省值（分机型） | 中型航空公司 |
| Ⅲ级 | 每月汇总统计 | 行业平均缺省值 | 小型航空公司 |

### 8.3 航空燃油数据管理

- 加油单应完整保存
- 燃油密度应定期检测
- 燃油消耗量应与飞行数据核对
- 月度燃油盘点应准确

### 8.4 数据内部审核

- 飞行数据每日审核
- 燃油消耗每周核对
- 月度数据质量审核
- 年度全面数据质量审核
- 保留审核记录和整改报告

## 九、报告内容和格式要求

### 9.1 报告主体信息

- 企业基本情况（名称、统一社会信用代码、地址、法定代表人等）

- 航线网络（国内/国际、主要航线）

- 数据质量控制计划执行情况

#### 9.2.1 排放总量

- 温室气体排放总量（tCO₂e）
- 直接排放量（tCO₂e）
- 间接排放量（tCO₂）
- 其中：国际航线排放量（单独列示）

#### 9.2.2 分排放源排放量

- 航空燃油燃烧排放量（分国内/国际、分机型）
- APU排放量
- 地面设施排放量
- 逸散排放量
- 购入使用电力排放量
- 购入使用热力排放量

### 9.3 活动数据

- 航空燃油消耗量（分类型、分国内/国际）
- 飞行小时、飞行架次、飞行距离
- 可用座公里（ASK）、收入客公里（RPK）
- 可用吨公里（ATK）、收入吨公里（RTK）
- APU使用时间
- 地面车辆/设备燃油消耗量
- 购入电量/热力

### 9.4 排放因子数据

- 各燃油排放因子及来源
- 各机型排放因子及来源

- 其他排放因子及来源

### 9.5 效率指标

- 吨公里油耗（kg/100tkm）
- 客公里油耗（kg/100pkm）
- 吨公里碳排放（kgCO₂/100tkm）
- 碳强度改进率

### 9.6 支撑材料

- 数据质量控制计划
- 燃油消耗统计报表
- 飞行运行统计报表
- 电费/热力费结算单
- 其他证明材料

### 9.7 报告格式

报告应采用统一报告格式，包括：

- 封面
- 目录
- 正文（按上述内容组织）
- 附表（数据表格）
- 附图（机队构成、航线网络图等）
- 附件（证明材料）

```
1. 排放总量
E_total = E_flight + E_APU + E_ground + E_fugitive + E_indirect

2. 航空燃油燃烧排放
E_flight = Σ (FC_ij × EF_i)

3. APU排放
E_APU = Σ (T_APU,j × FC_APU,j × EF)

4. 地面设施排放
E_ground = E_ground_vehicle + E_ground_equipment + E_ground_boiler

5. 制冷剂泄漏逸散排放
E_refrigerant = Σ (M_ref,i × GWP_i)

6. 购入电力间接排放
E_indirect_electricity = AD_electricity × EF_electricity

7. 单位周转量碳排放
EI_ATK = E_total / ATK_total
（ATK：可用吨公里）

8. 单位客公里碳排放
EI_RPK = E_total / RPK_total
（RPK：收入客公里）
```
