## 二、储备定额计算方法

### 2.1 通用公式

```
Q = N × f × d × k
```

| 符号 | 含义 | 说明 |
|------|------|------|
| Q | 储备定额 | 应储备的数量 |
| N | 基准用户数 | 如应急人员数、保护区域人口 |
| f | 人均消耗系数 | 参照表2.2 |
| d | 应急持续天数 | 通常取 3~7天 |
| k | 安全系数 | 通常 1.2~1.5 |

### 2.2 常见物资消耗系数（f值）

| 物资类别 | f值 | 说明 |
|---------|-----|------|
| 防毒面具滤毒罐 | 1.0个/人/天 | 高毒环境4h更换 |
| 化学防护服 | 0.5套/人/天 | 一次性使用 |
| 丁基手套 | 1.0双/人/天 | 一次性使用 |
| 吸油毡 | 5~20 kg/㎡ | 视油膜厚度而定 |
| 围油栏 | 3~5 m/100m²水面 | 围油线长=π(D+100) |
| 消油剂 | 1:20~1:30 | 与油品重量比 |
| 活性炭 | 0.1~0.5 kg/m³水 | 视污染物浓度 |
| 生石灰 | 2~5 kg/m³水 | 酸性废水中和 |
| 急救药品 | 0.5份/人 | 按受伤比例30%估算 |

### 2.3 案例：县级环境应急储备库定额计算

**背景：** 某县需建设应急物资储备库，服务区域人口50万，应急队伍50人。

#### 个体防护类计算

| 物资 | N | f | d | k | Q | 单位 |
|------|---|---|---|---|---|----|
| 全面罩防毒面具 | 50人 | 1.0 | 5 | 1.3 | 65 | 个 |
| A型滤毒罐 | 65个 | 1.0/天 | 5 | 1.3 | 325 | 个 |
| B型滤毒罐 | 65个 | 1.0/天 | 5 | 1.3 | 325 | 个 |
| A级化学防护服 | 20人 | 0.5 | 5 | 1.3 | 13 | 套 |
| B级化学防护服 | 50人 | 0.5 | 5 | 1.3 | 33 | 套 |
| 丁基手套 | 50人 | 1.0 | 5 | 1.3 | 325 | 双 |
| 防化护目镜 | 50人 | 0.3 | 5 | 1.3 | 16 | 副 |

## 三、保质期与轮换周期

### 3.1 各类物资保质期

| 物资类别 | 保质期（年） | 轮换周期 | 轮换方式 |
|---------|------------|---------|---------|
| 防毒面具（橡胶） | 3~5 | 3年 | 到期报废更新 |
| 滤毒罐（未开封） | 3 | 2年半 | 到期前统一换新 |
| 化学防护服（未开封） | 5 | 4年 | 到期前换新 |
| 吸油毡（密封） | 5 | 4年 | 到期前换新 |
| 消油剂（密封） | 3 | 2年半 | 到期前换新 |
| 活性炭（密封） | 3 | 2年半 | 到期前换新 |
| 氢氧化钠（密封） | 2 | 1年半 | 到期前换新 |
| 围油栏（未展开） | 8 | 6年 | 每年抽检10% |
| 气体检测仪 | 5 | 每年校准 | 每年送检标定 |
| 药品类 | 1~3 | 按有效期 | 临期6个月预警 |
| 防护手套（密封） | 3 | 2年半 | 到期前换新 |

### 3.2 轮换管理机制

```
┌─────────────────────────────────────────────────────┐
│                    轮换管理流程                       │
│                                                      │
│  入库登记 → 标注有效期 → 定期盘点 → 临期预警        │
│              ↓（有效期≤6个月）                        │
│          优先使用or轮换出库 → 补充采购 → 归档        │
└─────────────────────────────────────────────────────┘
```

**关键规则：**
1. **FIFO原则**：先入库的先出库，临期物资优先使用
2. **临期预警**：有效期≤6个月标记为黄色，≤3个月标记为红色
3. **报废处置**：过期物资按《危险废物管理条例》处置
4. **台账管理**：每次轮换均需记录在《物资轮换台账》中

## 五、储备模式

| 储备模式 | 说明 | 建议比例 |
|---------|------|---------|
| 实物储备 | 库存实际存放 | 60% |
| 协议储备 | 与供应商签订应急供货协议 | 25% |
| 生产能力储备 | 生产企业保留产能，紧急时转产 | 15% |

> **建议：** 实物储备保证前24小时响应量，协议储备保证后续补充。
