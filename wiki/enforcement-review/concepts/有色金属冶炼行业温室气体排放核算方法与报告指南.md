# 有色金属冶炼行业温室气体排放核算方法与报告指南

**文件编号**：CETS—AG—04.01—V01—2024（铝冶炼）/ GB/T 32151.14-2015（其他有色金属）
**发布单位**：生态环境部 / 国家市场监督管理总局
**实施日期**：2024年1月1日
**适用范围**：全国碳排放权交易市场有色金属冶炼行业重点排放单位

---

## 一、适用范围

本指南适用于有色金属冶炼行业企业的温室气体排放核算与报告工作。

### 1.1 适用主体

- 铝冶炼企业（电解铝、氧化铝）
- 铜冶炼企业（火法炼铜、湿法炼铜）
- 铅锌冶炼企业
- 镁冶炼企业
- 镍钴冶炼企业
- 锡锑汞冶炼企业
- 贵金属冶炼企业（金、银、铂族金属）
- 稀有稀土金属冶炼企业
- 有色金属压延加工企业（部分适用）

### 1.2 不适用范围

- 有色金属矿采选企业（矿山部分）
- 纯有色金属加工企业（无冶炼工序）
- 再生有色金属企业（可参照执行）

---

## 二、核算边界

### 2.1 组织边界

有色金属冶炼企业应核算其拥有或控制的所有生产设施的温室气体排放。

- **拥有**：企业具有所有权的生产设施
- **控制**：企业具有运营控制权的生产设施

### 2.2 运行边界

核算边界应包括有色金属冶炼的直接排放和间接排放。

#### 2.2.1 直接排放（范围1）

1. **化石燃料燃烧排放**：锅炉、冶炼炉、回转窑、干燥窑等燃烧设备化石燃料燃烧产生的CO₂排放
2. **工业生产过程排放**：
   - 阳极消耗排放（电解铝）
   - 碳酸盐分解排放（氧化铝、镁冶炼等）
   - 冶金过程反应排放
   - PFCs排放（电解铝阳极效应）
3. **逸散排放**：设备密封点泄漏、废水处理等产生的CH₄排放

#### 2.2.2 间接排放（范围2）

1. **购入使用电力排放**：企业购入的电力产生的CO₂排放
2. **购入使用蒸汽排放**：企业购入的蒸汽产生的CO₂排放（如适用）

**重要说明**：电解铝企业电力消耗占比大，间接排放是重要组成部分。

### 2.3 典型工序边界（以电解铝为例）

| 工序 | 主要排放源 | 温室气体 |
|------|-----------|----------|
| 氧化铝生产 | 石灰窑、熟料窑、燃烧锅炉、碳酸盐分解 | CO₂ |
| 电解铝 | 阳极消耗、阳极效应、电解槽散热 | CO₂、PFCs |
| 炭素生产 | 煅烧炉、焙烧炉、成型、沥青熔化 | CO₂ |
| 自备电厂 | 锅炉、汽轮机 | CO₂ |
| 公辅设施 | 锅炉、运输设备 | CO₂ |

## 三、核算方法

### 3.1 总体方法

有色金属冶炼行业温室气体排放核算采用**排放因子法**与**物料平衡法**相结合的方法。

### 3.2 核算公式

```
E_total = E_combustion + E_process + E_fugitive + E_indirect
```

其中：
- `E_total`：温室气体排放总量，单位：吨CO₂当量（tCO₂e）
- `E_combustion`：化石燃料燃烧排放量，单位：tCO₂
- `E_process`：工业生产过程排放量，单位：tCO₂e
- `E_fugitive`：逸散排放量，单位：tCO₂e
- `E_indirect`：间接排放量，单位：tCO₂

### 3.3 化石燃料燃烧排放核算

```
E_combustion = Σ (FC_i × NCV_i × EF_i × OF_i × 44/12)
```

### 3.4 工业生产过程排放核算

#### 3.4.1 电解铝阳极消耗排放

```
E_anode = M_anode × EF_anode
```

其中：
- `M_anode`：阳极炭块消耗量，单位：t
- `EF_anode`：阳极排放因子，单位：tCO₂/t

#### 3.4.2 电解铝阳极效应PFCs排放

方法一：阳极效应系数法

```
E_PFCs = Σ (AEF_j × t_j × EF_j × GWP_j)
```

其中：
- `AEF_j`：第j种槽型的阳极效应系数，单位：次/槽·天
- `t_j`：第j种槽型的运行槽数×天数，单位：槽·天
- `EF_j`：第j种槽型的每次阳极效应排放因子，单位：tCF₄/次
- `GWP_j`：PFCs的全球增温潜势

方法二：浓度监测法

```
E_PFCs = Q_gas × C_PFCs × GWP_PFCs × 10^-6
```

#### 3.4.3 氧化铝碳酸盐分解排放

```
E_alumina_carbonate = M_limestone × EF_limestone
```

#### 3.4.4 铜冶炼过程排放

```
E_copper = P_copper × EF_copper
```

其中：
- `P_copper`：阴极铜产量，单位：t
- `EF_copper`：铜冶炼排放因子，单位：tCO₂/t

#### 3.4.5 铅锌冶炼过程排放

```
E_lead_zinc = Σ (P_i × EF_i)
```

### 3.5 间接排放核算

```
E_indirect = AD_electricity × EF_electricity + AD_steam × EF_steam
```

**电解铝特别说明**：电解铝企业电力消耗占总排放的60-80%，应重点关注。

## 四、温室气体种类

本指南核算的温室气体包括：

| 序号 | 温室气体种类 | 化学分子式 | 全球增温潜势（GWP） | 主要来源 |
|------|-------------|-----------|---------------------|----------|
| 1 | 二氧化碳 | CO₂ | 1 | 化石燃料燃烧、阳极消耗、碳酸盐分解、间接排放 |
| 2 | 四氟化碳 | CF₄ | 6630 | 电解铝阳极效应 |
| 3 | 六氟乙烷 | C₂F₆ | 11100 | 电解铝阳极效应 |
| 4 | 六氟化硫 | SF₆ | 23500 | 镁冶炼、电气设备（少量） |
| 5 | 甲烷 | CH₄ | 28 | 逸散排放、废水处理 |
| 6 | 氧化亚氮 | N₂O | 265 | 化石燃料燃烧（少量） |

**说明**：
- 电解铝行业：PFCs（CF₄、C₂F₆）是重要的温室气体排放源，占总排放的10-20%（以CO₂当量计）
- 其他有色金属：以CO₂排放为主，占95%以上

## 五、排放源分类

### 5.1 直接排放源

#### 5.1.1 化石燃料燃烧排放

| 排放源 | 燃料类型 | 燃烧设备 | 典型行业 |
|--------|---------|----------|----------|
| 冶炼炉 | 煤炭、重油、天然气 | 鼓风炉、反射炉、电炉 | 铜、铅、锌冶炼 |
| 回转窑 | 煤炭、煤粉、重油 | 氧化铝熟料窑、炭素煅烧窑 | 氧化铝、炭素 |
| 焙烧炉 | 天然气、重油、煤气 | 流态化焙烧炉、沸腾炉 | 氧化铝、镁冶炼 |
| 干燥窑 | 烟气、蒸汽 | 矿浆干燥、精矿干燥 | 各行业 |
| 锅炉 | 煤炭、天然气、重油 | 电站锅炉、工业锅炉 | 各行业 |
| 熔化炉 | 天然气、重油 | 保温炉、熔化炉 | 铝加工、铜加工 |

#### 5.1.2 工业生产过程排放

| 排放源 | 排放原因 | 温室气体 | 典型行业 |
|--------|---------|----------|----------|
| 阳极消耗 | 阳极炭块氧化燃烧 | CO₂ | 电解铝 |
| 阳极效应 | 电解质与阳极反应 | CF₄、C₂F₆ | 电解铝 |
| 碳酸盐分解 | 石灰石、白云石分解 | CO₂ | 氧化铝、镁冶炼 |
| 硫化矿氧化 | 硫化精矿焙烧 | SO₂（非温室气体）、CO₂ | 铜、铅、锌冶炼 |
| 还原剂消耗 | 焦炭、煤粉、天然气 | CO₂ | 多种冶炼 |
| 电极消耗 | 石墨电极氧化 | CO₂ | 电炉冶炼 |
| 镁保护气 | SF₆泄漏 | SF₆ | 镁冶炼 |

#### 5.1.3 逸散排放

| 排放源 | 排放原因 | 温室气体 |
|--------|---------|----------|
| 设备泄漏 | 阀门、法兰、泵等密封点 | CH₄、VOCs |
| 废水处理 | 厌氧降解 | CH₄ |
| 储罐呼吸 | 电解液、化学品 | VOCs |

### 5.2 间接排放源

| 排放源 | 说明 | 占比（电解铝） |
|--------|------|---------------|
| 购入使用电力 | 企业从电网购入的电力 | 60-80% |
| 购入使用蒸汽 | 企业从外部购入的蒸汽 | 较少 |
| 自备电厂 | 企业自备电厂发电 | 计入直接排放 |

## 八、数据质量管理

### 8.1 数据质量控制计划（DQCP）

企业应制定并实施数据质量控制计划，包括：

- 数据质量管理组织机构及职责
- 数据监测计划（含监测点位、监测频次、监测方法）
- 数据记录和存档要求
- 数据审核机制（三级审核）
- 人员培训要求
- 仪器设备检定校准计划

### 8.2 数据质量等级

| 数据质量等级 | 活动数据要求 | 排放因子要求 | 适用情况 |
|-------------|-------------|-------------|----------|
| Ⅰ级 | 连续计量，每日记录 | 实测（连续监测/每批次检测） | 重点排放单位推荐 |
| Ⅱ级 | 定期计量，每周记录 | 实测（每月检测） | 一般排放单位 |
| Ⅲ级 | 台账记录，每月汇总 | 行业缺省值 | 小规模排放单位 |

### 8.3 电解铝数据管理特殊要求

- 阳极效应数据应逐槽记录
- 电解质成分应定期检测
- PFCs排放应优先采用浓度监测法
- 电力消耗应单独计量电解工序

### 8.4 数据内部审核

- 班组级：每日数据自查
- 车间级：每周数据审核
- 公司级：每月数据质量审核
- 年度：全面数据质量审核
- 保留审核记录和整改报告

### 附录B：核算公式汇总

```
1. 排放总量
E_total = E_combustion + E_process + E_fugitive + E_indirect

2. 化石燃料燃烧排放
E_combustion = Σ (FC_i × NCV_i × EF_i × OF_i × 44/12)

3. 电解铝阳极消耗排放
E_anode = M_anode × EF_anode

4. 电解铝阳极效应PFCs排放（系数法）
E_PFCs = Σ (AEF_j × t_j × EF_j × GWP_j)

5. 氧化铝碳酸盐分解排放
E_alumina_carbonate = M_limestone × EF_limestone

6. 购入电力间接排放
E_indirect_electricity = AD_electricity × EF_electricity

7. 吨铝碳排放强度
EI_aluminum = E_total / P_aluminum

8. 单位产品碳排放强度
EI_product = E_total / P_product
```
