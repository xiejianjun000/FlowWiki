## 一、适用范围扩展

### 原办法 vs 修订版

| 类别 | 原办法 | 修订版 |
|------|--------|--------|
| 政府预案 | ✓ | ✓ |
| 企业预案 | ✓ | ✓ |
| 工业园区预案 | ✗ | ✓ **新增** |
| 饮用水水源地预案 | ✗ | ✓ **新增** |
| 临时预案 | ✗ | ✓ **新增** |

### 四大类预案定义

1. **政府及部门环境应急预案**
   - 编制主体：县级以上生态环境主管部门
   - 适用范围：本行政区域内突发环境事件应对

2. **工业园区环境应急预案**
   - 编制主体：工业园区管理机构
   - 适用范围：园区内突发环境事件应对
   - **意义：** 强化园区一体化应急管理

3. **企事业单位环境应急预案**
   - 编制主体：企事业单位
   - 分类管理：
     - 较大及以上风险：严格要求
     - 一般风险：简化程序
     - Q<1：豁免管理

4. **临时环境应急预案**
   - 编制主体：大型活动主办单位
   - 适用场景：
     - 可能造成严重环境影响的工程建设
     - 影视拍摄
     - 文化体育等群众性集会活动

## 二、Q值豁免管理机制

### 什么是Q值？
- **Q值定义：** 环境风险物质与临界量的比值
- **计算公式：** Q = Σ(风险物质储存量 / 临界量)
- **临界量来源：** 《企业突发环境事件风险分级方法》

### 豁免条件

| Q值范围 | 风险等级 | 预案管理要求 |
|---------|----------|--------------|
| Q < 1 | 一般风险（低） | **可豁免**编制应急预案 |
| 1 ≤ Q < 10 | 一般风险 | 需编制，可简化程序 |
| 10 ≤ Q < 100 | 较大风险 | 需编制，严格管理 |
| Q ≥ 100 | 重大风险 | 需编制，重点监管 |

### 豁免管理实操

**申请流程：**
1. 企业自行计算Q值
2. 准备证明材料（风险物质清单、储存量、MSDS等）
3. 报属地生态环境部门备案
4. 领取豁免证明

**豁免不等于免责：**
- 仍需开展风险评估
- 仍需采取风险防控措施
- 仍需排查治理隐患
- 发生事件时仍需启动应急响应

## 三、专业人员资格要求

### 适用对象
**较大及以上环境风险企事业单位**（Q ≥ 10）

### 资格要求
应急预案编制人员中，**至少1名**需具备以下资格之一：
1. **注册环保工程师执业资格证书**
2. **环境影响评价师执业资格证书**

### 目的与意义
1. **提升预案质量：** 专业人员熟悉法规标准，能编制可操作的预案
2. **落实主体责任：** 企业需配备专业人员进行环境风险管理
3. **对标国际：** 借鉴发达国家经验，提高环境应急管理水平

### 实操问题解答

**Q1：小微企业无专业人员怎么办？**
- 可委托第三方机构编制预案（第三方机构人员需具备资格）
- 可联合园区内其他企业共同委托

**Q2：原有预案无专业人员签字是否有效？**
- 修订版实施后，新编制/修订预案需满足要求
- 原有预案在有效期内仍可继续使用
- 预案修订时需补充专业人员参与

**Q3：如何核实专业人员资格？**
- 查看执业资格证书原件
- 登录相关网站查询（注册环保工程师、环评师查询系统）
- 留存资格证书复印件作为备案材料

## 四、预案评审与备案时限

### 时间表（关键节点）

```
外部评审完成
    ↓
90个工作日内签署实施  ← 新增要求
    ↓
20个工作日（企业）/ 30个工作日（政府）内备案
```

### 详细要求

| 节点 | 时限 | 责任主体 | 备注 |
|------|------|----------|------|
| 外部评审完成 | - | 企事业单位/政府部门 | 较大及以上风险需专家评审 |
| 签署实施 | 评审后90个工作日内 | 预案责任主体 | **新增**，避免久拖不签 |
| 备案（企业） | 签署后20个工作日内 | 企事业单位 | 报属地生态环境部门 |
| 备案（政府） | 签署后30个工作日内 | 政府部门 | 报上级生态环境部门 |

### 备案材料清单

**企业预案备案：**
1. 环境应急预案备案表
2. 环境应急预案及编制说明
3. 环境风险评估报告
4. 环境应急资源调查报告
5. 评审意见及采纳情况说明
6. 专业人员资格证明材料（较大及以上风险）

**政府预案备案：**
1. 环境应急预案备案表
2. 环境应急预案及编制说明
3. 评审意见及采纳情况说明

## 五、预案修订管理

### 修订周期
- **原则：** 每3年至少修订一次
- **依据：** 预案实施情况、法律法规变化、风险变化等

### 强制修订情形（6种）

1. **法律法规发生变化**
   - 例：《突发环境事件应急管理办法》修订
   - 例：新的环保标准发布

2. **应急组织指挥体系或职责调整**
   - 例：机构改革，部门职责调整
   - 例：企业组织架构变化

3. **环境风险发生重大变化**
   - 例：新建项目，增加风险物质
   - 例：工艺变更，风险等级提高

4. **重要应急资源发生重大变化**
   - 例：应急队伍解散
   - 例：应急装备报废，无补充

5. **预案演练或实际应对中发现问题**
   - 例：演练中暴露预案不可操作
   - 例：实际事件中预案未能有效指导处置

6. **其他需要修订的情形**
   - 兜底条款，由生态环境部门认定

### 修订流程
```
触发修订条件 → 组织修订（需专业人员参与） → 评审（必要时） → 
签署实施 → 重新备案 → 旧版预案废止
```

## 六、监督管理与法律责任

### 监督管理措施

1. **建立台账**
   - 预案编制台账
   - 预案备案台账
   - 预案修订台账
   - 预案演练台账

2. **定期检查**
   - 纳入生态环境执法内容
   - 检查预案编制、备案、修订、演练等情况

3. **信息公开**
   - 备案企业名单向社会公布
   - 企业公开预案信息（涉及保密的除外）

### 法律责任

**企业违法行为：**
1. 未编制应急预案
2. 未按时备案
3. 未按时修订
4. 未组织演练
5. 预案内容严重失实

**法律后果：**
- 依据《突发环境事件应急管理办法》处罚
- 罚款金额：1万元以上3万元以下
- 责令改正，拒不改正的可停产整治

## 七、与国家要求的对比

| 项目 | 国家要求 | 湖南省要求 | 湖南省特点 |
|------|----------|------------|------------|
| 专业人员 | 无硬性要求 | 较大及以上风险需至少1名专业人员 | **更严格** |
| Q值豁免 | 无明确规定 | Q<1可豁免 | **创新** |
| 备案时限 | 发布后20个工作日内 | 签署实施后20/30个工作日内 | 增加签署环节 |
| 修订周期 | 未明确规定 | 每3年至少修订一次 | **更具体** |
| 工业园区预案 | 鼓励编制 | 纳入管理范围 | **更全面** |

## 八、实操 Checklist

### 企业预案管理自查表

**□ 编制阶段**
- [ ] 是否开展风险评估（Q值计算）
- [ ] Q值是否<1（可豁免）
- [ ] 较大及以上风险是否邀请专业人员参与
- [ ] 预案内容是否结合企业实际
- [ ] 是否组织专家评审（较大及以上风险）

**□ 签署与备案阶段**
- [ ] 评审后90个工作日内是否签署实施
- [ ] 签署后20个工作日内是否完成备案
- [ ] 备案材料是否齐全
- [ ] 是否公开预案信息（涉及保密的除外）

**□ 实施与修订阶段**
- [ ] 是否每年组织演练
- [ ] 是否每3年修订一次
- [ ] 是否触发强制修订情形
- [ ] 修订后是否重新备案

**□ 监督管理**
- [ ] 是否建立预案管理台账
- [ ] 应急资源是否定期核查
- [ ] 是否配合生态环境部门检查

## 九、常见问题解答

**Q1：Q<1的企业完全不需要做任何环境应急工作吗？**
- **答：** 不是。豁免的是"编制应急预案"，但仍需：
  - 开展风险评估
  - 采取风险防控措施
  - 排查治理隐患
  - 配备基本应急资源

**Q2：专业人员必须是本企业在职员工吗？**
- **答：** 不一定。可以是：
  - 本企业在职员工
  - 委托的第三方机构人员
  - 但需在预案编制说明中明确其参与的工作内容

**Q3：预案签署实施后，发现错误怎么办？**
- **答：** 如果是轻微错误，可发布补充说明；如果是重大问题，需启动修订程序。

**Q4：备案后，企业名称变更怎么办？**
- **答：** 需在变更后20个工作日内向原备案部门申请变更备案。

**Q5：园区预案与企业预案的关系？**
- **答：** 
  - 园区预案是"面"上预案，侧重园区整体应急
  - 企业预案是"点"上预案，侧重企业自身应急
  - 两者需衔接，企业预案需符合园区预案要求
