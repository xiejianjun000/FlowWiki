# 制药企业突发环境事件应急预案模板

## 应急预案编制说明

本预案依据《突发环境事件应急预案管理办法》《企业事业单位突发环境事件应急预案编制导则》（HJ 941-2018）、《制药工业大气污染物排放标准》（GB 37823-2019）、《提取类制药工业水污染物排放标准》（GB 21905-2008）等法规标准，结合制药企业特点编制。

---

## 第一章 总则

### 1.1 编制目的
- 规范制药企业突发环境事件应急处置程序
- 提高应急处置能力，最大程度减少环境污染损害
- 防止化学原料、有机溶剂、危废等泄漏造成环境污染
- 防止抗生素菌渣、危险废物泄漏造成生态风险
- 保护周边生态环境和公众健康安全

### 1.2 编制依据
- 《中华人民共和国环境保护法》
- 《中华人民共和国突发事件应对法》
- 《中华人民共和国安全生产法》
- 《中华人民共和国水污染防治法》
- 《中华人民共和国大气污染防治法》
- 《中华人民共和国固体废物污染环境防治法》
- 《中华人民共和国药品管理法》
- 《突发环境事件应急预案管理办法》
- 《企业事业单位突发环境事件应急预案编制导则》（HJ 941-2018）
- 《建设项目环境风险评价技术导则》（HJ 169-2018）
- 《危险化学品安全管理条例》
- 《制药工业大气污染物排放标准》（GB 37823-2019）
- 《提取类制药工业水污染物排放标准》（GB 21905-2008）
- 《化学合成类制药工业水污染物排放标准》（GB 21904-2008）
- 《发酵类制药工业水污染物排放标准》（GB 21903-2008）
- 《生物工程类制药工业水污染物排放标准》（GB 21907-2008）

### 1.3 适用范围
本预案适用于本企业原料药生产、制剂生产过程中发生的可能造成环境污染的突发事件。

### 1.4 应急预案体系
- 综合应急预案（本预案）
- 专项应急预案（溶剂泄漏、菌渣泄漏、废气事故排放等）
- 现场处置方案（各车间、罐区等岗位应急处置措施）

### 1.5 工作原则
- 以人为本，安全第一
- 预防为主，平战结合
- 统一领导，分级负责
- 快速反应，协同应对
- 依法规范，科学处置

## 第七章 应急响应

### 7.1 响应分级
- **Ⅰ级响应**（特别重大）：大量溶剂泄漏引发火灾、菌渣大量泄漏
- **Ⅱ级响应**（重大）：溶剂泄漏、废气事故排放、废水事故排放
- **Ⅲ级响应**（较大）：局部泄漏、设施故障
- **Ⅳ级响应**（一般）：轻微泄漏、隐患

### 7.2 响应程序
1. 发现事件 → 报告值班人员
2. 值班人员初步判断 → 报告应急指挥部
3. 启动应急响应 → 通知各应急小组
4. 现场处置 → 监测评估
5. 事态控制 → 终止响应

### 7.3 信息报告与通报
#### 7.3.1 内部报告
- 报告时限：立即（不超过15分钟）
- 报告对象：应急指挥部

#### 7.3.2 外部报告
- 报告时限：1小时内
- 报告对象：当地生态环境部门
- 报告内容：企业信息、事件概况、物质种类、影响范围、已采取措施

### 7.4 现场处置措施

#### 7.4.1 溶剂泄漏处置
1. **人员防护**：穿戴防毒面具、防化服、防静电服
2. **切断源**：关闭阀门、堵漏、转移未破损容器
3. **火源控制**：切断电源、禁止明火、消除静电
4. **隔离警戒**：泄漏点周围50-100米警戒
5. **泄漏控制**：
   - 用砂土围堵，防止流入下水道
   - 用泵抽吸转移
   - 用吸附材料吸附残留
6. **废物处置**：收集物按危废处置
7. **监测**：监测可燃气体浓度、TVOC

#### 7.4.2 火灾爆炸处置
1. **报警**：拨打119
2. **疏散**：疏散周边人员至上风向
3. **初期处置**：
   - 关闭防火门，切断电源
   - 使用合适灭火器（泡沫、干粉、CO2）
   - 抗溶性泡沫用于醇类、酮类火灾
4. **防止污染扩散**：
   - 收集消防废水
   - 防止流入排水系统和水体
5. **监测**：监测大气VOCs、水质

#### 7.4.3 菌渣泄漏处置
1. **人员防护**：穿戴防护服、防毒面具、橡胶手套
2. **隔离警戒**：泄漏点周围30米警戒
3. **泄漏控制**：用工具收集，防止扩散
4. **污染清理**：
   - 清理受污染土壤
   - 受污染土壤按危废处置
   - 泄漏区域消毒处理
5. **监测**：监测土壤、水体
6. **报告**：按危废泄漏报告生态环境部门

#### 7.4.4 废气事故排放处置
1. **立即减排**：降低生产负荷或停车
2. **排查故障**：检查废气处理设施故障原因
   - 活性炭失效 → 切换备用吸附床
   - RTO故障 → 检查燃烧系统、温度
   - 系统停电 → 启动备用电源
3. **应急处理**：修复设施，调整工艺
4. **监测**：加密监测VOCs排放浓度
5. **记录**：记录事故时间、气量、浓度

#### 7.4.5 废水事故排放处置
1. **立即切断**：关闭排放口阀门
2. **切换应急池**：将废水引入事故应急池
3. **排查故障**：检查废水处理设施故障原因
4. **应急处理**：投加药剂、调整工艺
5. **监测**：监测排放口污染物浓度

#### 7.4.6 危废泄漏处置
1. **隔离警戒**：泄漏点周围30米警戒
2. **人员防护**：穿戴防护服、防毒面具
3. **泄漏控制**：用砂土围堵，收集至密封容器
4. **污染清理**：清理污染土壤，按危废处置
5. **监测**：监测土壤、地下水

### 7.5 现场监测
- 大气：VOCs、可燃气体、特征污染物
- 水体：COD、氨氮、特征污染物、溶剂残留
- 监测点位：泄漏点、厂界、敏感目标
- 监测频次：初始每30分钟，趋于稳定后每2小时

### 7.6 安全防护
- 应急人员防护：正压式呼吸器、防化服、防毒面具、防静电服
- 疏散路线：沿上风向撤离
- 安全距离：火灾≥500m，泄漏≥100m

### 7.7 应急终止
- 终止条件：污染源消除、环境监测达标、现场清理完毕
- 终止决定：总指挥决定
- 终止程序：通知各小组 → 现场清理 → 总结评估
