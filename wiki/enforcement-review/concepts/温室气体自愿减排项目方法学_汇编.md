## 三、术语和定义

### 3.1 温室气体自愿减排项目 Chinese Certified Emission Reduction project, CCER project

对我国境内可再生能源、林业碳汇、甲烷利用等项目的温室气体减排效果进行量化核证，并在国家温室气体自愿减排交易注册登记系统中登记的温室气体减排量。

### 3.2 方法学 methodology

用于确定项目基准线、论证额外性、计算减排量、制定监测计划等的方法指南。

### 3.3 基准线 baseline

在没有该项目活动的情况下，最可能发生的温室气体排放情景。

### 3.4 额外性 additionality

项目活动所产生的减排量相对于基准线是额外的，即这种项目活动在没有外来的CCER支持下，存在诸如财务、技术、融资、认知、政策和机制等方面的障碍，不太可能正常实施。

### 3.5 项目边界 project boundary

项目活动的地理范围和排放源/温室气体类型范围。

### 3.6 泄漏 leakage

由于项目活动的实施，导致项目边界外的温室气体排放增加的情况。

### 3.7 计入期 crediting period

项目活动产生的减排量可计入的时间期限。

### 3.8 监测 monitoring

为确定项目的温室气体减排量，对项目活动参数进行系统测量和记录的过程。

### 3.9 审定 validation

由独立的审定机构对项目设计文件进行审查，确认项目符合方法学和相关程序要求的过程。

### 3.10 核查 verification

由独立的核查机构对项目产生的减排量进行审查和核实的过程。

### 3.11 减排量 emission reductions

在特定时间段内，项目边界内基准线排放量减去项目排放量，再减去泄漏排放量后的差值。

## 四、方法学基本框架

### 4.1 方法学的基本要素

每个方法学应包含以下基本要素：

1. **适用条件**：方法学适用的项目类型、技术、规模、区域等条件
2. **基准线情景识别**：确定没有项目活动时最可能的情景
3. **基准线排放计算**：基准线情景下的温室气体排放量
4. **项目排放计算**：项目活动实施后的温室气体排放量
5. **泄漏计算**：项目边界外的排放增加量
6. **减排量计算**：减排量=基准线排放-项目排放-泄漏
7. **额外性论证**：证明项目活动具有额外性
8. **监测要求**：需监测的参数、方法、频率、精度
9. **数据质量管理**：数据质量保证和控制措施
10. **计入期**：减排量计入的时间期限及延期条件

### 4.2 方法学的类型

| 类型 | 说明 | 示例 |
|-----|------|------|
| 类型一 | 大型项目方法学 | 装机容量≥15MW的可再生能源项目 |
| 类型二 | 小型项目方法学 | 装机容量<15MW的可再生能源项目 |
| 类型三 | 农林项目方法学 | 造林、森林经营等林业碳汇项目 |

### 4.3 方法学选择原则

项目业主应选择合适的方法学，遵循以下原则：

1. **适用性**：方法学的适用条件与项目特点相符
2. **保守性**：当存在多种方法选择时，选择更保守的方法
3. **透明性**：方法应用过程透明，可被第三方验证
4. **可操作性**：监测参数可测量，数据可获得
5. **成本效益**：在保证质量的前提下，考虑实施成本

## 五、主要领域方法学

### 5.1 可再生能源领域

#### 5.1.1 并网太阳能光伏发电项目方法学

**方法学编号：CM-001-V02**

**适用条件：**
- 项目类型：并网太阳能光伏发电项目
- 装机容量：不限（小型项目<15MW可简化）
- 接入电网：与公共电网连接
- 技术类型：光伏电池板，包括晶硅、薄膜等

**不适用条件：**
- 离网光伏发电项目
- 聚光太阳能光伏发电项目
- 光伏与建筑一体化发电项目（BIPV）
- 光热发电项目

**基准线情景：**
项目所发电量由项目所在区域电网中最可能的替代电源提供。

**基准线排放计算：**

```
BE_y = EG_y × EF_grid,y
```

其中：
- `BE_y`：第y年基准线排放量，单位：tCO₂e
- `EG_y`：第y年项目上网电量，单位：MWh
- `EF_grid,y`：第y年项目所在区域电网排放因子，单位：tCO₂/MWh

**项目排放计算：**

```
PE_y = Σ (M_i × EF_i) + OMF_y
```

其中：
- `PE_y`：第y年项目排放量，单位：tCO₂e
- `M_i`：第i种材料消耗量，单位：根据材料类型确定
- `EF_i`：第i种材料的排放因子
- `OMF_y`：第y年运行维护排放，单位：tCO₂e

**注**：光伏项目运行期排放极少，可忽略不计。

**泄漏：**
- 小型光伏发电项目泄漏忽略不计
- 大型项目根据实际情况评估

**计入期：**
- 固定计入期：10年
- 可更新计入期：3×7年（共21年）

**监测参数：**

| 参数 | 监测方法 | 监测频率 | 数据来源 |
|-----|---------|---------|---------|
| 上网电量 | 电能表计量 | 连续/月度 | 关口电表 |
| 自用电量 | 电能表计量 | 月度 | 自用电表 |
| 电网排放因子 | 年度发布 | 年度 | 生态环境部 |
| 运行维护 | 台账记录 | 年度 | 运维记录 |

### 5.2 甲烷回收利用领域

#### 5.2.1 煤矿瓦斯利用项目方法学

**方法学编号：CM-005-V02**

**适用条件：**
- 项目类型：煤矿瓦斯（煤层气）收集利用
- 利用方式：发电、供热、民用、化工等
- 瓦斯来源：抽采瓦斯、通风瓦斯

**基准线情景：**
- 情景一：瓦斯直接排放到大气
- 情景二：部分利用，其余排放
- 情景三：煤炭开采利用（视具体情况）

**减排量计算：**

```
ER_y = BE_CH4,y - PE_CH4,y - Leakage_y
```

其中：
- `BE_CH4,y`：基准线甲烷排放量，单位：tCO₂e
- `PE_CH4,y`：项目后甲烷排放量，单位：tCO₂e
- `Leakage_y`：泄漏量，单位：tCO₂e

**基准线排放：**

```
BE_CH4,y = Q_gas,y × C_CH4 × GWP_CH4
```

其中：
- `Q_gas,y`：年瓦斯排放量，单位：m³
- `C_CH4`：瓦斯中甲烷浓度，单位：%
- `GWP_CH4`：甲烷GWP值，取28

**监测参数：**
- 瓦斯抽采量
- 瓦斯浓度
- 利用量
- 排放量
- 利用方式及效率

#### 5.2.2 垃圾填埋气回收利用项目方法学

**方法学编号：CM-006-V02**

**适用条件：**
- 项目类型：垃圾填埋场填埋气收集利用
- 利用方式：发电、供热、火炬焚烧等
- 填埋场类型：生活垃圾卫生填埋场

**基准线情景：**
- 情景一：填埋气直接排放
- 情景二：部分收集焚烧
- 情景三：自然排放

**减排量计算：**

```
ER_y = (Q_LFG,y × C_CH4 × GWP_CH4) × (1 - EF_flare) - PE_y
```

其中：
- `Q_LFG,y`：年填埋气产生量，单位：m³
- `C_CH4`：甲烷浓度，单位：%
- `EF_flare`：火炬燃烧效率（通常取0.9）
- `PE_y`：项目排放量

**填埋气产生量估算方法：**

```
Q_CH4 = MSW × L₀ × (1 - e^(-kt))
```

其中：
- `MSW`：垃圾填埋量，单位：吨/年
- `L₀`：单位垃圾产甲烷潜势，缺省值0.10 tCH₄/t
- `k`：产甲烷速率常数，缺省值0.05 /年
- `t`：填埋时间，单位：年

**计入期：**
- 固定计入期：10年
- 可更新计入期：可延长至填埋场稳定后20年

### 5.3 林业碳汇领域

#### 5.3.1 碳汇造林项目方法学

**方法学编号：CM-008-V02**

**适用条件：**
- 项目类型：人工造林
- 土地类型：造林前为无林地
- 造林时间：2005年2月16日之后
- 项目地点：全国范围内

**不适用条件：**
- 天然林保护、自然恢复项目
- 经济林（水果、橡胶等）
- 竹林造林

**碳库选择：**

| 碳库 | 是否计入 | 说明 |
|-----|---------|------|
| 地上生物量 | 是 | 树木地上部分 |
| 地下生物量 | 是 | 树木根系 |
| 枯死木 | 可选 | 枯立木、倒木 |
| 枯落物 | 可选 | 枯枝落叶 |
| 土壤有机碳 | 可选 | 0-30cm土层 |

**碳汇量计算：**

```
ΔC_total = ΔC_above + ΔC_below + ΔC_deadwood + ΔC_litter + ΔC_soil
```

其中：
- `ΔC_total`：总碳汇量，单位：tCO₂e
- `ΔC_above`：地上生物量碳储量变化
- `ΔC_below`：地下生物量碳储量变化
- `ΔC_deadwood`：枯死木碳储量变化（可选）
- `ΔC_litter`：枯落物碳储量变化（可选）
- `ΔC_soil`：土壤有机碳储量变化（可选）

**生物量测量方法：**

1. **样地法**（默认方法）
   - 设置永久样地
   - 每木检尺测量胸径、树高
   - 使用生物量模型计算

2. **生物量模型**
   ```
   W = a × (DBH)^b
   ```
   其中：
   - `W`：单株生物量，单位：kg
   - `DBH`：胸径，单位：cm
   - `a, b`：树种参数

**计入期：**
- 最短20年，最长60年
- 可申请延期

**监测频率：**
- 每5年进行一次全面监测
- 每年进行年度核查

## 六、额外性论证

### 6.1 额外性的基本概念

额外性是指项目活动所产生的减排量相对于基准线是额外的，即这种项目活动在没有CCER收益的情况下，存在各种障碍，不太可能正常实施。

### 6.2 额外性论证步骤

#### 步骤一：识别拟议的项目活动

明确项目活动的类型、技术、规模、地点等基本信息。

#### 步骤二：识别基准线情景

确定在没有该项目活动的情况下，最可能发生的情景。

#### 步骤三：投资分析

论证项目在财务上不具备吸引力：

**方法一：简单成本分析**
- 比较项目投资与常规投资的成本差异
- 计算增量成本

**方法二：投资回报分析**
- 计算项目内部收益率（IRR）
- 与基准收益率比较
- 证明项目IRR低于基准收益率

**方法三：投资差距分析**
- 计算实现基准收益率所需的减排收益
- 证明没有减排收益项目不可行

**基准收益率参考值：**

| 项目类型 | 基准收益率（税后） |
|---------|------------------|
| 可再生能源 | 8%~10% |
| 工业节能 | 10%~12% |
| 林业碳汇 | 6%~8% |
| 甲烷利用 | 10%~12% |

#### 步骤四：障碍分析

论证项目面临的主要障碍：

1. **投资障碍**
   - 初始投资高，资金不足
   - 融资困难，融资成本高
   - 投资回报期长

2. **技术障碍**
   - 技术不成熟，风险高
   - 缺乏技术人才
   - 设备供应不足

3. **政策障碍**
   - 缺乏政策支持
   - 审批程序复杂
   - 法规不明确

4. **认知障碍**
   - 对技术不了解
   - 对效益不确定
   - 缺乏成功案例

5. **机制障碍**
   - 市场机制不完善
   - 缺乏激励政策
   - 交易成本高

#### 步骤五：普遍性分析

论证项目活动在类似情况下不是普遍实施的：

- 行业普及率低
- 同类项目数量少
- 技术应用不广泛
- 市场渗透率低

#### 步骤六：结论

综合以上分析，得出项目是否具有额外性的结论。

### 6.3 额外性论证简化方法

对于小型项目和特定类型项目，可采用简化方法：

| 项目类型 | 简化条件 |
|---------|---------|
| 小型可再生能源 | 装机<15MW，自动满足额外性 |
| 低收入地区项目 | 位于国家确定的贫困县 |
| 国家鼓励类项目 | 列入国家鼓励类产业目录 |
- **注**：简化方法仍需提供必要的说明和证据。

## 七、监测要求

### 7.1 监测计划

项目设计文件中应包含详细的监测计划，内容包括：

1. **监测参数清单**
   - 参数名称
   - 参数定义
   - 单位
   - 监测频率
   - 监测方法
   - 数据来源
   - 精度要求

2. **监测设备清单**
   - 设备名称
   - 型号规格
   - 安装位置
   - 校准/检定要求

3. **数据管理程序**
   - 数据采集
   - 数据记录
   - 数据审核
   - 数据保存
   - 数据保密

4. **质量管理程序**
   - 质量保证措施
   - 质量控制措施
   - 不确定度评估

### 7.2 监测参数分类

| 类别 | 说明 | 示例 |
|-----|------|------|
| 关键参数 | 对减排量影响大，需精确监测 | 发电量、燃料消耗量、瓦斯浓度 |
| 重要参数 | 对减排量有一定影响 | 运行时间、负荷率 |
| 一般参数 | 对减排量影响小 | 环境温度、设备型号 |

### 7.3 监测精度要求

| 参数类型 | 精度要求 | 仪表准确度等级 |
|---------|---------|--------------|
| 电度量 | ±0.5% | 0.5级及以上 |
| 流量（气体） | ±2.0% | 2.0级及以上 |
| 流量（液体） | ±1.0% | 1.0级及以上 |
| 温度 | ±0.5℃ | - |
| 压力 | ±1.0% | - |
| 浓度 | ±5.0% | - |

### 7.4 数据记录与保存

**记录要求：**
- 原始数据应及时记录
- 记录应清晰、完整、可追溯
- 修改应有标注和签字
- 电子数据应有备份

**保存期限：**
- 至少保存至计入期结束后2年
- 纸质记录和电子记录同时保存
- 保存地点应安全、防潮、防火

## 八、减排量计算通用公式

### 8.1 基本公式

```
ER_y = BE_y - PE_y - Leakage_y
```

其中：
- `ER_y`：第y年减排量，单位：tCO₂e
- `BE_y`：第y年基准线排放量，单位：tCO₂e
- `PE_y`：第y年项目排放量，单位：tCO₂e
- `Leakage_y`：第y年泄漏量，单位：tCO₂e

### 8.2 基准线排放计算

根据项目类型选择不同的基准线排放计算方法：

**类型一：能源替代类**
```
BE_y = Activity_baseline × EF_baseline
```

**类型二：减排技术类**
```
BE_y = Activity_project × EF_baseline
```

**类型三：碳汇类**
```
BE_y = C_baseline, t+1 - C_baseline, t
```

### 8.3 项目排放计算

```
PE_y = Σ (Activity_i × EF_i)
```

其中：
- `Activity_i`：第i种活动数据
- `EF_i`：第i种活动的排放因子

### 8.4 泄漏计算

项目泄漏应根据项目类型具体评估：

| 项目类型 | 主要泄漏源 | 处理方式 |
|---------|-----------|---------|
| 可再生能源 | 设备制造排放 | 一般忽略 |
| 工业节能 | 材料生产、运输 | 计入项目排放 |
| 林业碳汇 | 采伐转移、市场效应 | 评估后确定 |
| 甲烷利用 | 管道泄漏 | 计入项目排放 |

## 九、计入期

### 9.1 计入期类型

| 类型 | 时长 | 适用项目 | 延期次数 |
|-----|------|---------|---------|
| 固定计入期 | 10年 | 大多数项目 | 不可延期 |
| 可更新计入期 | 3×7年=21年 | 长期项目 | 可更新2次 |
| 林业项目计入期 | 20-60年 | 林业碳汇项目 | 可申请延期 |

### 9.2 计入期开始时间

计入期开始时间应满足以下条件：
- 项目已开始实施
- 项目产生了实际减排量
- 不早于项目审定日期
- 不早于2005年2月16日

### 9.3 计入期延期

可更新计入期的项目申请延期时，应满足：
- 项目仍在正常运行
- 减排效果持续存在
- 方法学仍然适用
- 经过重新审定

## 十、审定与核查

### 10.1 审定

**审定目的：**
确认项目设计符合方法学和相关程序要求。

**审定内容：**
1. 项目设计文件（PDD）完整性
2. 方法学适用性
3. 基准线情景合理性
4. 额外性论证充分性
5. 监测计划可行性
6. 减排量计算正确性

**审定结论：**
- 同意注册
- 需修改后同意
- 不同意注册

### 10.2 核查

**核查目的：**
核实项目产生的实际减排量。

**核查内容：**
1. 监测数据的真实性、准确性
2. 项目运行是否符合设计
3. 减排量计算是否正确
4. 方法学应用是否正确

**核查频率：**
- 每年至少核查一次
- 可连续多年一次性核查

**核查结论：**
- 核证减排量
- 部分核证
- 不予核证
