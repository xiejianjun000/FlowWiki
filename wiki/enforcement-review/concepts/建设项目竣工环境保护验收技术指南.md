# 建设项目竣工环境保护验收技术指南

## 一、总则

### 1.1 适用范围

- 适用于指导建设项目竣工环境保护验收工作
- 适用于编制环境影响报告书（表）的建设项目
- 适用于建设单位组织验收及相关技术服务机构提供技术支持

### 1.2 主要目的

- 规范建设项目竣工环境保护验收工作
- 提高验收工作的科学性、规范性
- 保障环境保护设施与主体工程同时投入运行

## 二、验收工作流程

### 2.1 主要流程

```text
1. 项目竣工准备 → 2. 成立验收工作组 → 3. 编制验收方案
↓
4. 验收监测 → 5. 编制验收报告 → 6. 验收工作组审议
↓
7. 形成验收意见 → 8. 公开验收信息 → 9. 报送主管部门
```

### 2.2 关键时间节点

| 节点 | 时间要求 |
|------|---------|
| 项目竣工 | 主体工程及环保设施完工 |
| 验收准备 | 项目竣工后 1 个月内 |
| 验收监测 | 项目竣工后 3 个月内 |
| 验收完成 | 项目竣工后 6 个月内 |
| 信息报送 | 验收完成后 30 日内 |

## 三、验收前准备

### 3.1 项目竣工确认

#### 主体工程

1. 主要生产装置建成并具备运行条件
2. 配套公用工程建成
3. 工程竣工验收合格

#### 环境保护设施

1. 废气治理设施建成并具备运行条件
2. 废水治理设施建成并具备运行条件
3. 固体废物处置设施建成
4. 噪声防治措施落实
5. 风险防范措施落实
6. 生态保护措施落实

### 3.2 验收工作组组建

#### 工作组成员

- 建设单位代表（组长）
- 设计单位代表
- 施工单位代表
- 监理单位代表
- 监测机构代表
- 咨询机构代表（如委托）
- 专家（视情况）

#### 工作组职责

1. 组织验收工作
2. 审查验收资料
3. 现场检查环境保护设施
4. 审议验收监测报告
5. 形成验收意见

### 3.3 资料准备

#### 必备资料清单

1. **环境影响评价文件**：报告书/表
2. **环境影响评价批复文件**：批复函
3. **设计文件**：环境保护设施设计文件
4. **施工文件**：施工方案、施工记录
5. **监理文件**：监理报告、监理日志
6. **试运行记录**：试运行报告
7. **环境保护设施清单**：设施名称、规格、数量
8. **环境管理制度**：环境管理体系文件
9. **应急预案**：突发环境事件应急预案
10. **其他资料**：相关许可证、合格证等

### 4.2 工况要求

#### 工况负荷要求

| 项目类型 | 工况负荷要求 |
|---------|------------|
| 一般工业项目 | ≥ 75% |
| 化工项目 | ≥ 75% |
| 电力项目 | ≥ 75% |
| 污水处理厂 | ≥ 50% |
| 垃圾焚烧厂 | ≥ 75% |
| 道路工程 | 通过车流量 ≥ 设计流量的 50% |

#### 工况无法满足的处理

1. 说明原因
2. 在低工况下监测
3. 推算满负荷下的排放情况
4. 后续验收监测补做

## 五、验收监测

### 5.1 监测点位布设

#### 废气监测点位

1. **有组织排放**：各排气筒设置监测点
2. **无组织排放**：厂界外 10m 范围内设置监测点
3. **参考点**：在污染源上风向设置参考点

#### 废水监测点位

1. **总排口**：废水总排放口
2. **车间排放口**：含第一类污染物的车间排放口
3. **雨水排放口**：雨水排放口（必要时）

#### 噪声监测点位

1. **厂界噪声**：厂界外 1m 处
2. **敏感点噪声**：周边敏感点
3. **噪声源**：主要噪声源

#### 固体废物监测

1. 危险废物鉴别
2. 浸出毒性监测

### 5.2 监测项目确定

#### 通用监测项目

| 类别 | 监测项目 |
|------|---------|
| 废气 | 颗粒物、SO₂、NOx、VOCs |
| 废水 | pH、COD、BOD₅、SS、氨氮、总磷 |
| 噪声 | 厂界噪声 |
| 固废 | 浸出毒性、危险特性 |

#### 行业特征监测项目

| 行业 | 特征监测项目 |
|------|------------|
| 火电 | 烟尘、汞、烟气黑度 |
| 钢铁 | 颗粒物、氟化物 |
| 化工 | VOCs、特征有机物 |
| 电镀 | 六价铬、总铬、氰化物 |
| 造纸 | AOX、色度 |
| 印染 | 色度、硫化物 |
| 制药 | 残留药物、抗生素 |
| 食品加工 | 动植物油、大肠菌群 |

### 5.3 监测频次

| 监测对象 | 监测频次 |
|---------|---------|
| 废气 | 连续 2 天，每天 4 次 |
| 废水 | 连续 2 天，每天 4 次 |
| 噪声 | 连续 2 天，每天昼夜各 1 次 |
| 固废 | 1 次取样 |

### 5.4 监测方法

- 采用国家标准、行业标准方法
- 监测仪器应经过检定/校准
- 监测人员应持证上岗

### 5.5 质量保证

#### 现场质量保证

1. 监测前仪器校准
2. 平行样采集（不少于 10%）
3. 现场空白样
4. 全程空白样

#### 实验室质量保证

1. 实验室资质认证
2. 标准样品分析
3. 加标回收率分析
4. 实验室间比对

## 八、验收意见

### 8.1 验收合格条件

#### 必须同时满足

1. 环境保护设施按环评文件及批复要求建成
2. 环境保护设施运行正常
3. 污染物排放符合排放标准
4. 主要污染物排放总量符合总量控制指标
5. 生态保护措施得到落实
6. 环境管理措施得到落实
7. 验收资料完整、真实
8. 无其他严重环境问题

### 8.2 验收意见格式

```markdown
# [项目名称]竣工环境保护验收意见

## 1 验收组织
验收工作组由[建设单位]组织成立，成员包括[成员名单]。

## 2 验收过程
验收工作组于 YYYY-MM-DD 至 YYYY-MM-DD 开展验收工作。

## 3 验收内容
3.1 环境保护设施建设情况
3.2 验收监测情况
3.3 环境管理情况

## 4 验收结论
经验收工作组审议，[项目名称]竣工环境保护验收合格/不合格。

## 5 验收意见
（验收工作组的意见）

## 6 签字
验收工作组成员签字：
日期：
```

## 十一、特殊项目验收

### 11.1 涉密项目

- 按保密规定执行
- 验收资料按涉密文件管理
- 信息公开按保密规定

### 11.2 跨区域项目

- 由涉及区域的共同上级生态环境主管部门协调
- 各地分别报送

### 11.3 改扩建项目

- 与原有项目同时验收
- 总量控制按整体计算

## 十三、对企业环保合规工作的启示

1. **按时组织验收**：项目竣工后 6 个月内组织验收
2. **如实开展监测**：委托有资质的监测机构开展监测
3. **如实编制报告**：如实编制验收报告，不得弄虚作假
4. **及时公开信息**：按规定公开验收信息
5. **报送信息**：按时向生态环境主管部门报送验收信息
6. **整改问题**：发现的问题及时整改
7. **完善档案**：完整保存验收相关档案
8. **避免未验先投**：未验收前不得投入正式生产
9. **配合监督检查**：配合生态环境部门的监督检查
10. **建立长效机制**：建立环境保护设施运行管理长效机制
