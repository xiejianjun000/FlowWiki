# 钢铁行业温室气体排放核算方法与报告指南

**文件编号**：CETS—AG—03.01—V01—2024
**发布单位**：生态环境部
**实施日期**：2024年1月1日
**适用范围**：全国碳排放权交易市场钢铁行业重点排放单位

---

## 一、适用范围

本指南适用于纳入全国碳排放权交易市场的钢铁行业重点排放单位的温室气体排放核算与报告工作。

### 1.1 适用主体

- 长流程钢铁联合企业（含焦化、烧结、球团、炼铁、炼钢、轧钢等完整工序）
- 短流程钢铁企业（以电炉炼钢为主）
- 独立焦化企业
- 独立炼铁企业
- 独立炼钢企业

### 1.2 不适用范围

- 铁合金生产企业
- 碳素制品生产企业
- 耐火材料生产企业
- 纯钢铁加工企业（无冶炼工序）

---

## 二、核算边界

### 2.1 组织边界

钢铁企业应核算其拥有或控制的所有生产设施的温室气体排放。

- **拥有**：企业具有所有权的生产设施
- **控制**：企业具有运营控制权的生产设施

### 2.2 运行边界

核算边界应包括钢铁生产的直接排放和间接排放。

#### 2.2.1 直接排放（范围1）

1. **化石燃料燃烧排放**：各工序化石燃料燃烧产生的CO₂排放
2. **工业生产过程排放**：
   - 碳酸盐分解排放（石灰石、白云石等）
   - 电极消耗排放
   - 还原剂消耗排放
   - 其他工艺过程排放
3. **逸散排放**：设备密封点泄漏、废水处理等产生的CH₄排放

#### 2.2.2 间接排放（范围2）

1. **购入使用电力排放**：企业购入的电力产生的CO₂排放
2. **购入使用蒸汽排放**：企业购入的蒸汽产生的CO₂排放
3. **购入使用热力排放**：企业购入的热力产生的CO₂排放

### 2.3 工序边界

钢铁生产主要工序包括：

| 工序 | 主要排放源 |
|------|-----------|
| 焦化 | 炼焦用煤燃烧、焦炉煤气燃烧、焦化过程 |
| 烧结 | 固体燃料燃烧、点火燃料燃烧、碳酸盐分解 |
| 球团 | 固体燃料燃烧、焙烧燃料燃烧 |
| 炼铁 | 焦炭燃烧、煤粉燃烧、熔剂分解 |
| 转炉炼钢 | 铁水物理热、氧气燃烧、熔剂分解、电极消耗 |
| 电炉炼钢 | 电极消耗、辅料分解 |
| 轧钢 | 加热炉燃料燃烧 |
| 公辅设施 | 锅炉燃烧、火炬燃烧 |

## 三、核算方法

### 3.1 总体方法

钢铁行业温室气体排放核算采用**物料平衡法**为主，**排放因子法**为辅的方法。

### 3.2 核算公式

```
E_total = E_combustion + E_process + E_fugitive + E_indirect - E_output
```

其中：
- `E_total`：温室气体排放总量，单位：吨CO₂当量（tCO₂e）
- `E_combustion`：化石燃料燃烧排放量，单位：tCO₂
- `E_process`：工业生产过程排放量，单位：tCO₂
- `E_fugitive`：逸散排放量，单位：tCO₂e
- `E_indirect`：间接排放量，单位：tCO₂
- `E_output`：含碳产品输出折算排放量，单位：tCO₂

### 3.3 化石燃料燃烧排放核算

采用物料平衡法，核算公式：

```
E_combustion = Σ (C_input,i - C_output,i) × 44/12
```

其中：
- `C_input,i`：第i种输入含碳物料的碳量，单位：tC
- `C_output,i`：第i种输出含碳物料的碳量，单位：tC
- `44/12`：碳转化为二氧化碳的系数

### 3.4 工业生产过程排放核算

#### 3.4.1 碳酸盐分解排放

```
E_carbonate = Σ (M_i × EF_i)
```

其中：
- `M_i`：第i种碳酸盐原料消耗量，单位：t
- `EF_i`：第i种碳酸盐的CO₂排放因子，单位：tCO₂/t

#### 3.4.2 电极消耗排放

```
E_electrode = M_electrode × EF_electrode
```

其中：
- `M_electrode`：电极消耗量，单位：t
- `EF_electrode`：电极排放因子，单位：tCO₂/t

### 3.5 含碳产品输出扣除

```
E_output = Σ (M_product,i × C_product,i) × 44/12
```

其中：
- `M_product,i`：第i种含碳产品产量，单位：t
- `C_product,i`：第i种产品的含碳量，单位：tC/t

### 3.6 间接排放核算

```
E_indirect = AD_electricity × EF_electricity + AD_steam × EF_steam
```

其中：
- `AD_electricity`：购入使用电量，单位：MWh
- `EF_electricity`：电力排放因子，单位：tCO₂/MWh
- `AD_steam`：购入使用蒸汽量，单位：t
- `EF_steam`：蒸汽排放因子，单位：tCO₂/t

## 四、温室气体种类

本指南核算的温室气体包括：

| 序号 | 温室气体种类 | 化学分子式 | 全球增温潜势（GWP） | 核算来源 |
|------|-------------|-----------|---------------------|----------|
| 1 | 二氧化碳 | CO₂ | 1 | 化石燃料燃烧、工业生产过程、间接排放 |
| 2 | 甲烷 | CH₄ | 28 | 逸散排放、焦化过程 |
| 3 | 氧化亚氮 | N₂O | 265 | 化石燃料燃烧（少量） |

**说明**：钢铁行业以CO₂排放为主，占总排放量的95%以上。CH₄主要来自焦化过程和逸散排放，N₂O排放量很小。

## 五、排放源分类

### 5.1 直接排放源

#### 5.1.1 化石燃料燃烧排放

| 工序 | 排放源 | 燃料类型 |
|------|--------|---------|
| 焦化 | 焦炉加热 | 焦炉煤气、高炉煤气、混合煤气 |
| 烧结 | 点火炉、保温炉 | 焦炉煤气、高炉煤气、混合煤气、天然气 |
| 球团 | 焙烧炉、回转窑 | 焦炉煤气、高炉煤气、煤粉 |
| 炼铁 | 热风炉、锅炉房 | 高炉煤气、焦炉煤气、混合煤气、煤粉 |
| 炼钢 | 转炉煤气回收系统、烘烤装置 | 转炉煤气、焦炉煤气 |
| 轧钢 | 加热炉、热处理炉 | 焦炉煤气、高炉煤气、混合煤气、天然气、重油 |
| 公辅 | 锅炉、火炬 | 各种煤气、天然气、重油 |

#### 5.1.2 工业生产过程排放

| 排放源 | 排放原因 | 温室气体 | 主要工序 |
|--------|---------|----------|----------|
| 碳酸盐分解 | 石灰石、白云石分解 | CO₂ | 烧结、炼铁、炼钢 |
| 电极消耗 | 石墨电极氧化 | CO₂ | 电炉炼钢 |
| 焦炭反应 | 焦炭参与还原反应 | CO₂ | 炼铁 |
| 脱硫过程 | 石灰石分解 | CO₂ | 烧结、球团 |

#### 5.1.3 逸散排放

| 排放源 | 排放原因 | 温室气体 |
|--------|---------|----------|
| 设备泄漏 | 阀门、法兰、泵等密封点泄漏 | CH₄、VOCs |
| 焦化过程 | 炼焦过程中产生的焦炉煤气逃逸 | CH₄ |
| 废水处理 | 厌氧处理产生的沼气 | CH₄ |

### 5.2 间接排放源

| 排放源 | 说明 |
|--------|------|
| 购入使用电力 | 企业从电网购入的电力 |
| 购入使用蒸汽 | 企业从外部购入的蒸汽 |
| 购入使用热力 | 企业从外部购入的热力 |

## 六、活动水平数据要求

### 6.1 含碳物料消耗量

#### 6.1.1 数据来源

- 优先采用**计量数据**：皮带秤、地磅、流量计等
- 次选采用**台账数据**：生产报表、物料平衡表
- 缺省采用**财务数据**：采购发票、财务凭证

#### 6.1.2 主要含碳物料

| 物料类型 | 计量要求 | 数据频次 |
|---------|---------|----------|
| 煤炭（炼焦煤、动力煤） | 地磅/皮带秤，精度±0.5% | 每日记录 |
| 焦炭 | 地磅/皮带秤，精度±0.5% | 每日记录 |
| 煤粉 | 流量计/称重，精度±1.0% | 每日记录 |
| 重油、柴油 | 流量计，精度±0.5% | 每日记录 |
| 天然气、煤气 | 气体流量计，精度±1.0% | 每日记录 |
| 电极 | 地磅/台账，精度±1.0% | 每月记录 |
| 含碳废料 | 地磅/估算，精度±5.0% | 每月记录 |

### 6.2 含碳物料碳含量

#### 6.2.1 检测要求

- 煤炭：每批次检测1次，每月至少1次
- 焦炭：每批次检测1次，每月至少1次
- 煤粉：每月检测1次
- 其他含碳物料：每季度检测1次

#### 6.2.2 检测项目

- 收到基元素碳含量（C_ar）
- 空气干燥基元素碳含量（C_ad）
- 干燥无灰基元素碳含量（C_daf）
- 工业分析（水分、灰分、挥发分、固定碳）

## 七、排放因子选取

### 7.1 排放因子选取原则

1. **优先实测**：企业具备实测条件的，应采用实测排放因子
2. **行业缺省**：无法实测的，采用生态环境部发布的行业缺省值
3. **国家标准**：可参考GB/T 32151系列国家标准中的缺省值

## 八、数据质量管理

### 8.1 数据质量控制计划（DQCP）

企业应制定并实施数据质量控制计划，包括：

- 数据质量管理组织机构及职责
- 数据监测计划（含监测点位、监测频次、监测方法）
- 数据记录和存档要求
- 数据审核机制（三级审核）
- 人员培训要求
- 仪器设备检定校准计划

### 8.2 关键参数分类

#### 8.2.1 企业层级关键参数

1. 化石燃料消耗量
2. 碳酸盐原料消耗量
3. 电极及其他含碳原料消耗量
4. 含碳产品输出量
5. 粗钢产量

#### 8.2.2 工序层级关键参数

1. 烧结工序化石燃料消耗量
2. 炼铁工序化石燃料消耗量
3. 各工序产品产量

### 8.3 数据质量等级

| 数据质量等级 | 活动数据要求 | 排放因子要求 | 适用情况 |
|-------------|-------------|-------------|----------|
| Ⅰ级 | 连续计量，每日记录 | 实测（每批次检测） | 重点排放单位推荐 |
| Ⅱ级 | 定期计量，每周记录 | 实测（每月检测） | 一般排放单位 |
| Ⅲ级 | 台账记录，每月汇总 | 行业缺省值 | 小规模排放单位 |

### 8.4 数据内部审核

- 班组级：每日数据自查
- 车间级：每周数据审核
- 公司级：每月数据质量审核
- 年度：全面数据质量审核
- 保留审核记录和整改报告

### 8.5 信息化存证

- 重点排放单位应按月上传月度数据
- 上传内容包括：主要物料消耗、产品产量、能源消耗等
- 数据应与原始凭证一致
- 保留电子凭证和纸质凭证

### 8.6 不确定性控制

- 定期开展排放量不确定性分析
- 识别主要不确定性来源
- 采取措施降低不确定性
- 报告不确定性范围

### 附录B：核算公式汇总

```
1. 排放总量
E_total = E_combustion + E_process + E_fugitive + E_indirect - E_output

2. 化石燃料燃烧排放（物料平衡法）
E_combustion = Σ (C_input,i - C_output,i) × 44/12

3. 碳酸盐分解排放
E_carbonate = Σ (M_i × EF_i)

4. 电极消耗排放
E_electrode = M_electrode × EF_electrode

5. 含碳产品输出扣除
E_output = Σ (M_product,i × C_product,i) × 44/12

6. 购入电力间接排放
E_indirect_electricity = AD_electricity × EF_electricity

7. 购入蒸汽间接排放
E_indirect_steam = AD_steam × EF_steam

8. 吨钢碳排放强度
EI_steel = E_total / P_steel
（P_steel为粗钢产量）
```
