# 危险废物处置企业突发环境事件应急预案模板

## 应急预案编制说明

本预案依据《突发环境事件应急预案管理办法》《企业事业单位突发环境事件应急预案编制导则》（HJ 941-2018）、《危险废物经营许可证管理办法》等法规标准，结合危废处置企业特点编制。

---

## 第一章 总则

### 1.1 编制目的
- 规范危险废物处置企业突发环境事件应急处置程序
- 提高应急处置能力，最大程度减少环境污染损害
- 防止危废处置过程中二次污染
- 保护周边生态环境和公众健康安全

### 1.2 编制依据
- 《中华人民共和国环境保护法》
- 《中华人民共和国突发事件应对法》
- 《中华人民共和国固体废物污染环境防治法》
- 《中华人民共和国大气污染防治法》
- 《中华人民共和国水污染防治法》
- 《中华人民共和国土壤污染防治法》
- 《突发环境事件应急预案管理办法》（国办发〔2014〕101号）
- 《突发环境事件应急管理办法》（环境保护部令第34号）
- 《企业事业单位突发环境事件应急预案编制导则》（HJ 941-2018）
- 《建设项目环境风险评价技术导则》（HJ 169-2018）
- 《危险废物经营许可证管理办法》
- 《危险废物转移管理办法》
- 《危险废物贮存污染控制标准》（GB 18597-2023）
- 《危险废物焚烧污染控制标准》（GB 18484-2020）
- 《危险废物填埋污染控制标准》（GB 18598-2019）

### 1.3 适用范围
本预案适用于本企业危废接收、贮存、处置（焚烧/物化/填埋等）过程中发生的可能造成环境污染的突发事件。

### 1.4 应急预案体系
- 综合应急预案（本预案）
- 专项应急预案（危废泄漏、火灾爆炸、烟气事故排放、渗滤液泄漏等）
- 现场处置方案（各岗位应急处置措施）

### 1.5 工作原则
- 以人为本，安全第一
- 预防为主，平战结合
- 统一领导，分级负责
- 快速反应，协同应对
- 依法规范，科学处置
- 全过程管控，防止二次污染

#### 2.4.2 焚烧处置工艺

#### 2.4.4 填埋处置工艺
- 危废预处理 → 稳定化/固化 → 检测 → 填埋 → 覆盖

### 3.3 风险类型
1. **危废泄漏**：暂存、运输、处置过程中危废泄漏污染土壤、水体
2. **火灾爆炸**：易燃危废或化学品发生火灾爆炸
3. **烟气事故排放**：焚烧系统或烟气净化设施故障导致烟气超标排放
4. **渗滤液泄漏**：填埋场防渗层破损或渗滤液调节池泄漏污染地下水
5. **废水事故排放**：废水处理设施故障导致超标废水排放
6. **危废运输事故**：危废运输过程中交通事故导致泄漏

## 第六章 预防与预警

### 6.1 风险防控措施

#### 6.1.1 危废接收与贮存防控
- 严格危废接收检验制度
- 分类贮存，标识清晰
- 暂存间设置防渗、防漏、防火、通风、气体收集设施
- 暂存间设置视频监控和气体报警
- 定期检查暂存危废状态

#### 6.1.2 焚烧系统防控
- 焚烧炉运行参数实时监控（温度、停留时间、氧含量）
- 烟气在线监测系统
- 备用电源保障
- 烟气净化系统冗余设计
- 布袋除尘器压差报警

#### 6.1.3 填埋场防控
- 防渗系统定期检测
- 渗滤液收集系统监控
- 地下水监测井定期监测
- 填埋场雨污分流

#### 6.1.4 运输防控
- 使用符合资质的运输车辆
- 配备GPS定位系统
- 运输路线规划
- 配备应急处理物资

### 6.2 监测预警
- 暂存间VOCs、可燃气体监测报警
- 焚烧烟气在线监测
- 渗滤液液位监测
- 地下水监测井定期监测
- 填埋场沉降监测
- 气象监测

### 6.3 预警分级与发布

## 第七章 应急响应

### 7.1 响应分级
- **Ⅰ级响应**（特别重大）：危废暂存间火灾、焚烧系统重大故障、大量危废泄漏
- **Ⅱ级响应**（重大）：局部危废泄漏、烟气事故排放
- **Ⅲ级响应**（较大）：设施故障、局部泄漏
- **Ⅳ级响应**（一般）：轻微泄漏、隐患

### 7.2 响应程序
1. 发现事件 → 报告值班人员
2. 值班人员初步判断 → 报告应急指挥部
3. 启动应急响应 → 通知各应急小组
4. 现场处置 → 监测评估
5. 事态控制 → 终止响应

### 7.3 信息报告与通报
#### 7.3.1 内部报告
- 报告时限：立即（不超过15分钟）
- 报告对象：应急指挥部
- 报告内容：事件时间、地点、类型、规模、初步原因

#### 7.3.2 外部报告
- 报告时限：1小时内
- 报告对象：当地生态环境部门
- 报告内容：企业信息、事件概况、危废类别、污染物种类、影响范围、已采取措施

### 7.4 现场处置措施

#### 7.4.1 危废泄漏处置
1. **人员防护**：穿戴防毒面具、防护服、耐酸碱手套
2. **隔离警戒**：泄漏点周围50-100米警戒
3. **切断源**：关闭阀门、转移未破损包装、堵漏
4. **泄漏控制**：
   - 液态危废：用干砂土、吸附材料围堵，收集至专用容器
   - 固态危废：用工具收集，防止扩散
   - 酸碱性危废：用相应中和剂处理
5. **污染清理**：清理受污染土壤，按危废处置
6. **监测**：监测土壤、地下水、大气
7. **废物处置**：收集的污染物按危废分类处置

#### 7.4.2 火灾爆炸处置
1. **报警**：拨打119
2. **疏散**：疏散周边人员至上风向
3. **初期处置**：
   - 关闭防火门，切断电源
   - 使用合适灭火器（注意：危废火灾需专业消防）
   - 启动消防系统
4. **防止污染扩散**：
   - 收集消防废水（防止进入排水系统）
   - 监测大气污染物（VOCs、重金属、二噁英）
5. **人员洗消**：对接触人员进行洗消
6. **监测**：监测厂界及敏感目标大气

#### 7.4.3 焚烧烟气事故排放处置
1. **立即减排**：降低焚烧负荷或停炉
2. **排查故障**：检查烟气净化系统故障原因
   - 布袋破损 → 切换备用室，更换布袋
   - 脱酸失效 → 检查药剂投加系统，补充药剂
   - 系统停电 → 启动备用电源
3. **应急处理**：调整工艺参数，修复故障
4. **监测**：加密监测烟气排放浓度
5. **记录**：记录事故时间、烟气量、浓度

#### 7.4.4 渗滤液泄漏处置
1. **立即切断**：停止向泄漏区域填埋
2. **排查漏点**：检查防渗层、管道、调节池
3. **应急处理**：
   - 防渗层破损 → 局部修复
   - 管道泄漏 → 修复管道
   - 调节池泄漏 → 转移渗滤液
4. **监测**：加密地下水监测井监测
5. **污染评估**：评估土壤、地下水污染范围
6. **修复**：必要时开展土壤地下水修复

#### 7.4.5 废水事故排放处置
1. **立即切断**：关闭排放口阀门
2. **切换应急池**：将废水引入事故应急池
3. **排查故障**：检查废水处理设施故障原因
4. **应急处理**：投加药剂、调整工艺
5. **监测**：监测排放口污染物浓度

#### 7.4.6 危废运输事故处置
1. **报警**：拨打110、119
2. **现场警戒**：设置警戒区
3. **人员防护**：穿戴防护装备
4. **泄漏控制**：用砂土、吸附材料围堵
5. **收集清理**：收集泄漏物，按危废处置
6. **污染监测**：监测土壤、水体

### 7.5 现场监测
- 大气：VOCs、重金属、二噁英、烟气参数
- 水体：pH、COD、重金属、氨氮、SS
- 土壤：重金属、有机物
- 地下水：重金属、有机物
- 监测点位：泄漏点、厂界、敏感目标
- 监测频次：初始每30分钟，趋于稳定后每2小时

### 7.6 安全防护
- 应急人员防护：正压式呼吸器、防化服、防毒面具、防护手套
- 疏散路线：沿上风向撤离
- 安全距离：火灾≥500m，危废泄漏≥100m

### 7.7 应急终止
- 终止条件：污染源消除、环境监测达标、现场清理完毕
- 终止决定：总指挥决定
- 终止程序：通知各小组 → 现场清理 → 总结评估

### 附录4：各类危废应急处置方法

#### 有机溶剂废物（HW06）
- **特性**：易燃、毒性
- **泄漏处理**：
  - 穿戴防毒面具、防化服
  - 切断火源
  - 用砂土围堵，收集至密封容器
  - 用活性炭吸附残留
  - 收集物按危废处置
- **禁忌**：禁止接触明火、氧化剂
- **急救**：移至空气新鲜处，皮肤接触用清水冲洗

#### 废矿物油（HW08）
- **特性**：易燃、毒性
- **泄漏处理**：
  - 切断火源
  - 用砂土围堵，收集
  - 用吸油材料吸附
  - 收集物按危废处置
- **禁忌**：禁止接触明火、强氧化剂

#### 精蒸馏残渣（HW11）
- **特性**：易燃、毒性、可能含有多环芳烃
- **泄漏处理**：
  - 穿戴防毒面具、防化服
  - 切断火源
  - 用砂土围堵，收集
  - 收集物按危废处置

#### 表面处理废物（HW17）
- **特性**：含重金属、酸碱
- **泄漏处理**：
  - 穿戴耐酸碱防护服、防毒面具
  - 用砂土围堵，收集
  - 用石灰中和酸性废物
  - 收集物按危废处置

#### 废酸（HW34）/废碱（HW35）
- **特性**：强腐蚀性
- **泄漏处理**：
  - 穿戴耐酸碱防护服
  - 用砂土围堵
  - 酸性废物用石灰/氢氧化钠中和
  - 碱性废物用弱酸中和
  - 收集物按危废处置
- **禁忌**：废酸和废碱禁止混合
