# 碳达峰碳中和目标企业碳排放核算指南

**文件编号**：CETS—DN—01.01—V01—2024
**发布单位**：生态环境部、国务院国资委
**实施日期**：2024年6月1日

---

## 一、范围

本指南规定了设定碳达峰碳中和目标的企业（以下简称"双碳目标企业"）开展碳排放核算的总体要求、核算边界、核算方法、数据质量管理、目标设定与跟踪评估等内容。

本指南适用于：
- 设定了碳达峰、碳中和目标的企业
- 开展碳中和认证的企业
- 编制企业碳中和报告的机构
- 自愿开展碳管理的企业

本指南覆盖的温室气体包括：
- 范围1：直接排放
- 范围2：外购能源间接排放
- 范围3：其他间接排放（价值链排放）

## 三、术语和定义

### 3.1 碳达峰 carbon peaking

企业的二氧化碳排放量达到历史最高值，然后经历平台期进入持续下降的过程。

### 3.2 碳中和 carbon neutrality

企业在规定期限内，通过自身减排和碳移除等方式，抵消其产生的温室气体排放量，实现净零排放。

### 3.3 范围3排放 scope 3 emissions

除范围2排放之外的所有间接排放，发生在企业价值链的上下游。

### 3.4 价值链 value chain

企业产品或服务从原材料获取到最终处置的全生命周期中，所有直接和间接的活动。

### 3.5 科学碳目标 science-based target, SBT

与气候科学一致的减排目标，即与将全球变暖控制在工业化前水平以上2℃以内、并努力追求1.5℃的目标相一致。

### 3.6 基准年 base year

用于比较和跟踪排放变化的基准年份。

### 3.7 排放清单 emission inventory

企业在一定时间内的温室气体排放量及其构成的详细记录。

### 3.8 减排措施 abatement measure

为减少温室气体排放而采取的技术、管理或政策措施。

### 3.9 碳移除 carbon removal

通过技术手段或生态方式从大气中清除二氧化碳的活动。

### 3.10 碳抵消 carbon offset

通过购买碳信用或实施减排项目，抵消自身不可避免的排放。

### 3.11 净零排放 net zero emissions

通过深度减排和碳移除，使剩余排放量等于碳移除量，实现净排放为零。

## 四、总体要求

### 4.1 核算原则

双碳目标企业的碳排放核算应遵循以下原则：

1. **相关性**
   - 核算方法与企业特点相适应
   - 数据能够真实反映企业排放情况
   - 满足目标设定和跟踪评估的需要

2. **完整性**
   - 覆盖所有运营边界内的排放源
   - 覆盖范围1、范围2和范围3排放
   - 覆盖所有相关温室气体种类

3. **一致性**
   - 核算方法在不同年度保持一致
   - 数据来源和口径保持一致
   - 确保不同时期数据可比

4. **透明性**
   - 核算方法、数据来源公开透明
   - 假设条件清晰说明
   - 排放数据可验证

5. **准确性**
   - 尽可能减少不确定性
   - 采用最高质量的数据
   - 定期优化核算方法

6. **保守性**
   - 数据不确定时采用保守估计
   - 不高估减排成效
   - 不低估排放量

### 4.2 核算边界确定

#### 4.2.1 组织边界

双碳目标企业应采用控制权法确定组织边界，覆盖：

| 层级 | 内容 | 要求 |
|-----|------|------|
| 一级 | 总部及所有子公司 | 100%纳入 |
| 二级 | 分公司、分厂 | 100%纳入 |
| 三级 | 合营、联营企业 | 按控制权比例纳入 |
| 四级 | 供应链上下游 | 范围3核算 |

**组织边界调整：**
- 并购：并购完成后纳入
- 剥离：剥离完成后剔除
- 重组：按新架构调整
- 边界变更需重新计算基准年排放

#### 4.2.2 运行边界

双碳目标企业应核算三个范围的排放：

```
                   企业温室气体排放
                       │
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
     范围1          范围2          范围3
   直接排放      外购能源排放    价值链排放
    │              │              │
    ├─固定燃烧      ├─电力          ├─上游：原材料
    ├─移动燃烧      ├─蒸汽          │      运输
    ├─工艺过程      ├─热力          │      采购
    └─逸散排放      └─冷力          ├─下游：产品使用
                                    │      产品运输
                                    │      废弃处理
                                    └─其他：差旅
                                            投资
                                            外包
```

**范围3核算要求：**
- 碳中和目标企业必须核算范围3排放
- 碳达峰目标企业鼓励核算范围3排放
- 范围3应至少覆盖对总排放贡献≥1%的类别
- 范围3排放占比<5%的，可简要说明

#### 4.2.3 时间边界

- 核算周期：日历年（1月1日至12月31日）
- 基准年：设定目标前的代表性年份
- 目标年：碳达峰年、碳中和年

**基准年选择原则：**
- 数据完整、质量可靠
- 具有代表性（正常生产年份）
- 距目标设定不超过5年
- 可选择单一基准年或滚动基准年

### 4.3 核算机构与人员

1. **机构设置**
   - 设立碳中和管理部门
   - 明确职责分工
   - 配备专职人员

2. **人员要求**
   - 经过专业培训
   - 掌握核算方法
   - 了解行业特点

3. **能力建设**
   - 定期培训
   - 经验交流
   - 外部咨询（必要时）

## 五、核算方法

### 5.1 范围1：直接排放核算

#### 5.1.1 固定燃烧排放

**计算公式：**
```
E_固定燃烧 = Σ (FC_i × C_ar,i × OF_i × 44/12)
```

其中：
- `FC_i`：第i种化石燃料消耗量，t或10⁴Nm³
- `C_ar,i`：第i种燃料收到基碳含量，tC/t或tC/10⁴Nm³
- `OF_i`：第i种燃料的碳氧化率，%
- `44/12`：碳转化为CO₂的系数

**数据要求：**
- 燃料消耗量：企业计量数据
- 元素碳含量：优先实测，缺省值次之
- 碳氧化率：按指南取值

#### 5.1.2 移动燃烧排放

**计算公式：**
```
E_移动燃烧 = Σ (FC_j × EF_j)
```

其中：
- `FC_j`：第j种燃料消耗量
- `EF_j`：第j种燃料的排放因子

**核算范围：**
- 企业自有车辆
- 企业租赁车辆（运营控制权）
- 厂内工程机械
- 铁路专用线机车
- 码头船舶（如有）

#### 5.1.3 工艺过程排放

根据行业特点，采用物料衡算法或排放因子法：

**物料衡算法：**
```
E_工艺 = Σ (投入物料含碳量 - 产品含碳量 - 废物含碳量) × 44/12
```

**排放因子法：**
```
E_工艺 = Σ (产品产量 × EF_产品)
```

#### 5.1.4 逸散排放

**主要类型：**
1. 气体燃料泄漏
2. 制冷剂泄漏
3. 灭火器泄漏
4. 废水处理CH₄排放
5. 固体废物处理CH₄排放

**核算方法：**
```
E_逸散 = Σ (排放源数量 × EF_逸散)
```

或采用实测法：
```
E_逸散 = 泄漏量 × GWP
```

### 5.2 范围2：间接排放核算

#### 5.2.1 外购电力排放

**计算公式：**
```
E_电力 = EC × EF_电力
```

其中：
- `EC`：外购电力消耗量，MWh
- `EF_电力`：电力排放因子，tCO₂/MWh

**排放因子选择：**

| 因子类型 | 说明 | 适用场景 |
|---------|------|---------|
| 区域电网平均因子 | 生态环境部发布 | 大部分企业 |
| 省级电网因子 | 省级生态环境部门发布 | 有省级因子的地区 |
| 市场化电力因子 | 绿电、绿证对应零排放 | 购买绿电的企业 |
| 位置边际因子 | 反映特定电网位置 | 自愿报告 |

**双计算法：**
- 鼓励采用"基于地点"和"基于市场"双计算法
- 明确披露两种方法的结果
- 目标跟踪应保持方法一致

#### 5.2.2 外购蒸汽/热力/冷力排放

**计算公式：**
```
E_蒸汽 = HS × EF_蒸汽
```

其中：
- `HS`：外购蒸汽/热力/冷力量，GJ
- `EF_蒸汽`：排放因子，tCO₂/GJ

**排放因子确定：**
- 优先采用供应方的实际排放数据
- 无法获取时采用缺省值

### 5.3 范围3：价值链排放核算

#### 5.3.1 范围3排放类别

GHG Protocol定义的15类范围3排放：

| 类别 | 上游/下游 | 说明 |
|-----|----------|------|
| 1. 采购的商品和服务 | 上游 | 原材料、零部件、外包服务 |
| 2. 资本货物 | 上游 | 设备、厂房、基础设施 |
| 3. 燃料和能源相关活动 | 上游 | 范围1、2之外的燃料能源 |
| 4. 上游运输和配送 | 上游 | 原材料运输 |
| 5. 上游运营产生的废物 | 上游 | 生产过程废物处理 |
| 6. 商务旅行 | 上游 | 员工出差 |
| 7. 员工通勤 | 上游 | 员工上下班 |
| 8. 上游租赁资产 | 上游 | 租赁的办公/生产场所 |
| 9. 下游运输和配送 | 下游 | 产品运输给客户 |
| 10. 加工的已售产品 | 下游 | 客户继续加工 |
| 11. 已售产品的使用 | 下游 | 产品使用阶段 |
| 12. 已售产品的报废处理 | 下游 | 产品废弃处理 |
| 13. 下游租赁资产 | 下游 | 出租给客户的资产 |
| 14. 特许经营 | 下游 | 加盟店、特许经营店 |
| 15. 投资 | 下游 | 股权投资、债权投资 |

#### 5.3.2 范围3核算方法

**方法一：供应商具体法（首选）**
- 使用供应商提供的实际排放数据
- 数据质量最高
- 适用于主要供应商

**方法二：基于支出的法**
- 使用行业平均排放强度×支出金额
- 适用于数据缺乏的类别
- 排放因子：kgCO₂e/元

**方法三：平均数据法**
- 使用行业平均排放因子×活动数据
- 适用于有活动数据的类别
- 如运输：吨公里×排放因子

#### 5.3.3 主要类别核算方法

**1. 采购的商品和服务**

```
E_采购 = Σ (采购量_i × EF_i)
```

或
```
E_采购 = Σ (支出金额_i × EF_支出,i)
```

**2. 上游运输和配送**

```
E_运输 = Σ (运输量_i × 运输距离_i × EF_i)
```

其中：
- 运输量：吨（t）或立方米（m³）
- 运输距离：公里（km）
- 排放因子：kgCO₂e/(t·km)

**3. 已售产品的使用**

```
E_使用 = Σ (产品数量_i × 使用寿命_i × 年使用量_i × EF_i)
```

**4. 已售产品的报废处理**

```
E_报废 = Σ (产品数量_i × 单重_i × 处理方式占比_i × EF_i)
```

**5. 商务旅行**

```
E_差旅 = Σ (出行人次_i × 距离_i × EF_i)
```

| 出行方式 | 排放因子参考 | 单位 |
|---------|------------|------|
| 飞机（短途） | 0.25 | kgCO₂e/客公里 |
| 飞机（长途） | 0.18 | kgCO₂e/客公里 |
| 火车 | 0.04 | kgCO₂e/客公里 |
| 汽车（单人） | 0.20 | kgCO₂e/客公里 |

**6. 员工通勤**

```
E_通勤 = 员工数 × 通勤距离 × 通勤天数 × 排放因子
```

#### 5.3.4 范围3数据质量分级

| 数据质量等级 | 数据来源 | 说明 |
|-------------|---------|------|
| 一级 | 供应商具体数据 | 质量最高 |
| 二级 | 行业平均数据 | 质量较高 |
| 三级 | 区域平均数据 | 质量一般 |
| 四级 | 估算数据 | 质量较低 |

**要求：**
- 主要排放类别应达到二级及以上
- 鼓励逐步提高一级数据比例
- 明确披露数据质量

### 5.4 碳清除核算

#### 5.4.1 生物碳汇

**类型：**
- 企业自有森林
- 企业营造林
- 草原碳汇
- 农田碳汇

**核算方法：**
```
ΔC_生物 = C_t2 - C_t1
```

其中：
- `ΔC_生物`：碳汇量，tCO₂e
- `C_t1`：期初碳储量，tCO₂e
- `C_t2`：期末碳储量，tCO₂e

#### 5.4.2 技术碳移除

**类型：**
- 直接空气碳捕集与封存（DACCS）
- 生物能源碳捕集与封存（BECCS）
- 矿化固碳
- 其他负排放技术

**核算方法：**
```
E_移除 = CO₂封存或固化量
```

#### 5.4.3 碳汇计量要求

- 监测频率：至少每年1次
- 计量方法：符合相关标准
- 第三方核查：鼓励开展
- 计入规则：企业可控范围内

### 5.5 排放量汇总

**总排放量：**
```
E_总 = E_范围1 + E_范围2 + E_范围3
```

**净排放量：**
```
E_净 = E_总 - E_碳移除 - E_抵消
```

**说明：**
- 碳达峰核算不扣减碳汇和抵消
- 碳中和核算可扣减合格的碳汇和抵消
- 应分别披露总排放和净排放

## 六、数据质量管理

### 6.1 数据质量要求

双碳目标企业应建立高质量的数据管理体系：

| 数据类别 | 精度要求 | 完整性要求 | 来源优先级 |
|---------|---------|-----------|-----------|
| 范围1活动数据 | ±5%以内 | 100%覆盖 | 企业实测 > 台账 > 统计 > 估算 |
| 范围1排放因子 | ±10%以内 | - | 实测 > 行业平均 > IPCC缺省 |
| 范围2活动数据 | ±2%以内 | 100%覆盖 | 结算单 > 内部计量 |
| 范围2排放因子 | - | - | 官方发布 > 研究数据 |
| 范围3活动数据 | ±20%以内 | ≥80%类别 | 供应商数据 > 行业平均 > 估算 |
| 范围3排放因子 | ±30%以内 | - | 行业数据 > 区域数据 > 估算 |

### 6.2 数据管理制度

1. **数据采集制度**
   - 明确数据采集责任人
   - 规定数据采集频率
   - 建立数据审核流程

2. **数据存储制度**
   - 建立排放数据库
   - 纸质档案和电子档案
   - 保存期限≥10年

3. **数据审核制度**
   - 多级审核机制
   - 定期数据质量检查
   - 异常数据调查

### 6.3 不确定性管理

1. **不确定性来源识别**
   - 活动数据不确定性
   - 排放因子不确定性
   - 方法学不确定性
   - 数据缺失不确定性

2. **不确定性评估方法**
   - 定性分级评估
   - 定量误差传播
   - 关键类别重点评估

3. **质量改进措施**
   - 提高实测数据比例
   - 完善计量体系
   - 建立供应商数据收集机制
   - 定期更新排放因子

## 七、碳达峰目标设定与核算

### 7.1 达峰目标设定

#### 7.1.1 目标类型

| 目标类型 | 说明 | 适用场景 |
|---------|------|---------|
| 绝对排放达峰 | 排放总量达到峰值后下降 | 大多数企业 |
| 强度达峰 | 单位产值/产品排放达到峰值 | 高速增长期企业 |
| 达峰后下降率 | 达峰后每年下降X% | 已接近峰值的企业 |

#### 7.1.2 目标设定要求

1. **基准年选择**
   - 数据完整、质量可靠
   - 具有代表性
   - 距目标设定不超过5年

2. **达峰年份**
   - 不晚于2030年
   - 鼓励提前达峰
   - 高排放行业争取更早

3. **目标幅度**
   - 达峰后年下降率≥2%
   - 鼓励更高下降率
   - 分阶段设定目标

### 7.2 达峰核算与跟踪

#### 7.2.1 达峰判定标准

满足以下条件可判定为达峰：
1. 排放量连续3年下降
2. 下降具有确定性（非因外部因素）
3. 未来趋势将持续下降
4. 经过第三方核查确认

#### 7.2.2 排放跟踪

**年度跟踪内容：**
- 总排放量及变化
- 分范围排放量
- 分业务板块排放量
- 单位产值/产品排放量
- 主要排放源变化

**同比变化分析：**
```
变化率 = (本年排放 - 上年排放) / 上年排放 × 100%
```

**变化原因分析：**
- 产量变化影响
- 结构调整影响
- 技术进步影响
- 能源结构影响
- 其他因素影响

### 7.3 减排措施核算

#### 7.3.1 减排措施分类

| 类别 | 具体措施 | 减排潜力 |
|-----|---------|---------|
| 能源结构优化 | 煤改气、煤改电、可再生能源 | 大 |
| 能效提升 | 节能改造、高效设备 | 中-大 |
| 工艺改进 | 工艺优化、新技术应用 | 中-大 |
| 原料替代 | 低碳原料、循环利用 | 中 |
| 碳捕集利用与封存 | CCUS技术 | 大（长期） |
| 管理节能 | 管理优化、行为节能 | 小-中 |
| 碳汇增加 | 造林、森林经营 | 中-大 |

#### 7.3.2 减排量计算

**项目级减排量：**
```
ER_项目 = E_基准线 - E_项目 - E_泄漏
```

**企业级减排量汇总：**
- 避免重复计算
- 考虑叠加效应
- 保守估算

## 八、碳中和目标设定与核算

### 8.1 碳中和目标设定

#### 8.1.1 目标类型

| 目标类型 | 范围 | 说明 |
|---------|------|------|
| 运营碳中和 | 范围1+范围2 | 基础目标 |
| 全价值链碳中和 | 范围1+范围2+范围3 | 完整目标 |
| 产品碳中和 | 产品生命周期 | 产品层面 |

#### 8.1.2 目标设定要求

1. **目标年份**
   - 不晚于2060年
   - 鼓励提前实现
   - 分阶段推进

2. **减排深度**
   - 运营碳中和：范围1+2减排≥90%
   - 全价值链碳中和：总排放减排≥90%
   - 剩余排放通过碳移除/抵消

3. **抵消原则**
   - 优先自身减排
   - 剩余排放才能抵消
   - 抵消项目应符合标准
   - 优先选择碳移除

### 8.2 碳中和核算

#### 8.2.1 碳中和核算公式

```
净排放 = 总排放 - 碳移除 - 合格抵消
```

**碳中和判定：** 净排放 ≤ 0

#### 8.2.2 减排优先级

碳中和实现路径应遵循以下优先级：

```
优先级1：避免排放 Avoid
    ↓
优先级2：减少排放 Reduce
    ↓
优先级3：替代排放 Substitute
    ↓
优先级4：碳移除 Remove
    ↓
优先级5：碳抵消 Offset（最后手段）
```

#### 8.2.3 合格抵消项目要求

可用于抵消的碳信用应满足：
1. 真实：确实产生了减排
2. 额外：没有碳信用收入项目不会实施
3. 可测量：减排量可测量、可核查
4. 永久：减排效果具有持久性
5. 不重复：没有被多次计算和交易
6. 第三方核查：经过独立第三方核查

**优先使用的碳信用类型：**
- 林业碳汇CCER
- 可再生能源CCER
- 甲烷利用CCER
- 碳移除项目
- 符合国际标准的碳信用

### 8.3 碳中和声明

#### 8.3.1 声明原则

- 真实准确，不夸大
- 透明披露方法和数据
- 不误导消费者和公众
- 有充分的证据支持

#### 8.3.2 声明内容

碳中和声明应包含：
1. 声明主体
2. 声明范围（组织/产品）
3. 声明时间
4. 覆盖的排放范围
5. 核算方法和标准
6. 减排措施和成效
7. 碳移除/抵消情况
8. 第三方核查情况

#### 8.3.3 禁止行为

- 虚假声明
- 夸大碳中和程度
- 隐藏重要信息
- 只谈抵消不谈减排
- 使用不合格的抵消项目

## 附录B（资料性附录） 科学碳目标（SBTi）设定方法

### B.1 目标设置方法

1. **绝对收缩法**
   - 适用于大多数企业
   - 设定绝对排放下降目标

2. **强度法**
   - 适用于快速增长企业
   - 设定单位产值/产品排放下降目标

3. **部门法**
   - 适用于特定行业
   - 按行业脱碳路径设定

### B.2 1.5℃目标要求

- 范围1+2：每年减排≥4.2%
- 范围3：2030年减排≥30%（2019基准）
- 2050年实现净零排放
