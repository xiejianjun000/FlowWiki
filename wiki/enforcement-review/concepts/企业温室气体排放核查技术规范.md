# 企业温室气体排放核查技术规范

**文件编号**：HJ 1225-2024
**发布单位**：生态环境部
**实施日期**：2024年9月1日
**代替标准**：HJ 1225-2021

---

## 一、适用范围

本标准规定了企业温室气体排放核查的技术要求，包括核查程序、核查内容、核查方法、核查结论、核查报告等。

本标准适用于纳入全国碳排放权交易市场的重点排放单位的温室气体排放核查工作。

本标准也适用于：
- 地方碳排放权交易市场企业的排放核查
- 自愿开展温室气体排放核查的企业
- 企业温室气体排放清单审核

### 1.1 核查对象

企业温室气体排放报告，包括：
- 企业基本信息
- 核算边界
- 排放源识别
- 活动数据
- 排放因子
- 排放量计算
- 数据质量管理

### 1.2 核查范围

核查范围应与企业报告的核算边界一致：

| 边界类型 | 说明 |
|---------|------|
| 组织边界 | 企业拥有或控制的所有生产设施 |
| 运行边界 | 范围1直接排放、范围2间接排放 |
| 时间边界 | 报告年度（1月1日至12月31日） |
| 温室气体 | CO₂、CH₄、N₂O等（按行业指南要求） |

## 三、术语和定义

### 3.1 核查 verification

核查机构根据约定的核查准则，对企业温室气体排放声明进行系统、独立的评价，以确定其与核查准则符合程度的过程。

### 3.2 核查准则 verification criteria

核查所依据的标准、法规、指南和方法学。

### 3.3 核查机构 verification body

具备相应资质，独立开展温室气体排放核查的第三方机构。

### 3.4 核查员 verifier

具备相应能力，从事温室气体排放核查的专业人员。

### 3.5 技术专家 technical expert

在特定行业或技术领域具有专业知识和经验，为核查提供技术支持的人员。

### 3.6 客观证据 objective evidence

建立在观察、测量或试验基础上的，可被验证的关于事实的信息。

### 3.7 不符合 nonconformity

未能满足某一规定要求。

### 3.8 重大不符合 major nonconformity

可能导致排放报告严重失实的系统性、区域性或关键性错误。

### 3.9 一般不符合 minor nonconformity

对排放报告准确性影响较小的孤立性、程序性问题。

### 3.10 观察项 observation

尚未构成不符合，但存在潜在风险或需改进的事项。

### 3.11 重要性 materiality

影响排放报告使用者决策的错报或漏报的严重程度。

### 3.12 合理保证 reasonable assurance

核查机构对排放报告在所有重大方面符合核查准则提供高水平但非绝对的保证。

## 四、核查基本原则

### 4.1 独立性原则

- 核查机构应独立于被核查企业
- 核查人员与被核查企业无利益关系
- 不受任何可能影响核查公正性的外部压力
- 保持客观公正的立场

### 4.2 基于证据原则

- 核查结论应基于充分、适当的客观证据
- 证据应可追溯、可验证
- 证据收集方法应科学、规范

### 4.3 应有的职业审慎原则

- 保持谨慎态度和专业判断
- 关注可能存在的重大错报风险
- 勤勉尽责，不放过可疑点

### 4.4 重要性原则

- 合理确定重要性水平
- 重点关注重大事项
- 对重大错报风险保持警觉

### 4.5 保密原则

- 对核查过程中获取的商业秘密保密
- 未经授权不得披露相关信息
- 按规定使用和保存核查资料

### 4.6 透明性原则

- 核查过程和方法应透明
- 核查结论应有充分的说明
- 核查报告内容应完整、清晰

## 五、核查程序

### 5.1 核查准备阶段

#### 5.1.1 签订委托合同

核查机构与委托方签订核查服务合同，明确：
- 核查目的和范围
- 核查准则
- 双方权利与义务
- 保密条款
- 服务费用
- 争议解决方式

#### 5.1.2 组建核查组

核查机构应组建满足能力要求的核查组：

| 岗位 | 数量 | 能力要求 |
|-----|------|---------|
| 核查组组长 | 1名 | 5年以上核查经验，高级职称，主持过10个以上项目 |
| 专业核查员 | ≥2名 | 相关专业背景，经培训考核合格，参与过5个以上项目 |
| 行业技术专家 | 按需 | 10年以上行业工作经验，熟悉行业工艺和技术 |

**独立性要求：**
- 核查组成员近3年内未为被核查企业提供过碳排放咨询服务
- 与被核查企业无股权、雇佣等关系
- 不存在其他可能影响独立性的情形

#### 5.1.3 资料收集与文件评审

**企业应提交的资料：**

| 类别 | 具体资料 | 用途 |
|-----|---------|------|
| 基本信息 | 营业执照、组织机构代码证 | 核实企业身份 |
| 排放报告 | 温室气体排放报告及附件 | 核查对象 |
| 能源数据 | 能源消费统计表、购售凭证 | 核查活动数据 |
| 检测报告 | 燃料元素分析、工业分析报告 | 核查排放因子 |
| 计量资料 | 计量器具台账、检定证书 | 核查数据可靠性 |
| 生产数据 | 生产报表、产量统计 | 交叉验证 |
| 其他 | 工艺流程图、设施清单 | 边界核查 |

**文件评审内容：**
1. 报告完整性审查
2. 方法合规性审查
3. 数据逻辑初筛
4. 识别重点核查领域
5. 评估资料充分性

#### 5.1.4 制定核查计划

核查组制定详细的核查计划：

| 项目 | 内容 |
|-----|------|
| 核查目的 | 核实排放报告的真实性、准确性、完整性 |
| 核查范围 | 组织边界、运行边界、时间边界 |
| 核查准则 | 行业核算指南、相关法规标准 |
| 重要性水平 | 通常为排放总量的±5% |
| 核查方法 | 文件评审、现场勘查、凭证核对等 |
| 人员分工 | 各成员职责和分工 |
| 时间安排 | 现场核查日期和日程 |
| 重点领域 | 高风险排放源、关键数据 |

#### 5.1.5 下发核查通知

提前5个工作日通知企业：
- 核查时间安排
- 现场核查日程
- 需准备的资料清单
- 配合人员要求
- 其他注意事项

### 5.2 现场核查阶段

#### 5.2.1 首次会议

**时间**：现场核查第一天上午，约60分钟

**参会人员**：
- 核查组全体成员
- 企业分管领导
- 碳排放管理部门负责人
- 能源、生产、质量、财务等相关部门负责人

**会议议程**：
1. 核查组介绍核查目的、范围、程序、方法
2. 介绍核查组成员及独立性声明
3. 企业介绍基本情况及碳排放核算工作
4. 确认核查计划和日程
5. 明确企业配合人员及联系方式
6. 签署保密协议和公正性声明

#### 5.2.2 现场勘查

**勘查目的**：
- 核实核算边界
- 了解生产工艺
- 确认排放源
- 检查计量设施

**勘查内容**：

| 勘查对象 | 勘查要点 |
|---------|---------|
| 生产装置 | 主要生产设施、工艺路线、生产能力 |
| 燃烧设施 | 锅炉、窑炉、加热炉等型号、台数、燃料类型 |
| 计量设施 | 能源计量点位、计量器具类型、安装位置 |
| 燃料系统 | 燃料储存、输送、计量方式 |
| 环保设施 | 脱硫、脱硝、除尘等设施 |
| 其他设施 | 备用发电机、移动源等 |

**勘查方法**：
- 实地察看
- 拍照记录
- 现场询问
- 核对清单

#### 5.2.3 数据核查

**1. 燃料消耗量核查**

核查方法：
- 核对购入凭证（发票、过磅单、运输单）
- 核对库存台账（期初、期末盘点记录）
- 核对消耗记录（锅炉运行日志、给煤/给油记录）
- 验证消耗量计算公式：消耗量 = 期初库存 + 本期购入 - 期末库存 - 外售量
- 抽查计量器具及检定证书

核查要点：
- 购入量与凭证是否一致
- 库存量盘点是否规范
- 消耗量计算是否正确
- 不同燃料是否分类统计
- 燃料消耗与产量是否匹配

**2. 燃料元素碳含量核查**

核查方法：
- 检查检测报告真实性（CMA/CNAS标志、检测机构资质）
- 核对检测频率（每月不少于1次，每批次必测）
- 核对检测方法（是否符合GB/T 476、GB/T 212等标准）
- 检查加权平均计算过程
- 对比分析检测数据的合理性（与历史数据、行业均值对比）

核查要点：
- 检测报告是否真实有效
- 检测频次是否满足要求
- 元素碳含量取值是否正确
- 加权平均计算是否准确
- 是否存在故意选用低值的情况

**3. 电力消耗量核查**

核查方法：
- 核对电网企业电费结算单和发票
- 核对企业内部电表抄表记录
- 核实自备电厂发电量和自用电量
- 核实转供电量及扣除情况
- 分析单位产品电耗的合理性

核查要点：
- 外购电量是否以结算电量为准
- 自备电厂是否单独核算
- 转供电量是否正确扣除
- 线损、变损处理是否正确

**4. 蒸汽/热力消耗量核查**

核查方法：
- 核对热力供应企业的结算凭证
- 核对企业蒸汽流量计记录
- 核实蒸汽参数（压力、温度、焓值）
- 检查计量装置检定情况

#### 5.2.4 核算过程核查

**1. 核算边界核查**

- 组织边界是否完整（所有设施是否纳入）
- 运行边界是否完整（排放源是否遗漏）
- 是否存在应纳入未纳入的设施
- 是否存在不应纳入而纳入的设施
- 边界变更是否有合理理由

**2. 核算方法核查**

- 方法选择是否符合行业指南
- 方法应用是否正确
- 方法变更是否合理
- 是否存在方法选用不当

**3. 排放因子核查**

- 排放因子来源是否可靠
- 排放因子取值是否正确
- 缺省值使用是否合规
- 实测数据是否符合标准

**4. 计算过程核查**

- 计算公式是否正确
- 单位换算是否正确
- 计算结果是否正确
- 汇总是否准确

#### 5.2.5 人员访谈

**访谈对象及内容：**

| 访谈对象 | 访谈内容 | 目的 |
|---------|---------|------|
| 企业管理层 | 碳排放管理体系、重视程度 | 了解管理水平 |
| 碳排放管理员 | 核算工作组织、数据来源、方法选择 | 核实核算过程 |
| 能源管理人员 | 能源计量、统计、消耗情况 | 核实能源数据 |
| 质检人员 | 燃料检测、质量控制情况 | 核实检测数据 |
| 生产管理人员 | 生产工艺、产量、运行情况 | 交叉验证 |
| 财务人员 | 能源采购、结算凭证 | 核实购入数据 |

**访谈要求：**
- 做好访谈记录
- 关键信息需确认
- 与其他证据相互印证
- 关注不一致的信息

#### 5.2.6 不符合项确认

核查组对发现的问题进行分类确认：

| 类型 | 判定标准 | 处理方式 |
|-----|---------|---------|
| 重大不符合 | 导致排放量偏差>5%；数据造假；方法严重错误 | 必须整改，重新核算 |
| 一般不符合 | 导致排放量偏差2%~5%；程序不规范 | 视情况调整或改进 |
| 观察项 | 存在潜在风险；可改进事项 | 提出建议，不影响结论 |

不符合项应与企业沟通确认，做到：
- 事实清楚
- 证据充分
- 定性准确
- 双方确认

#### 5.2.7 末次会议

**时间**：现场核查最后一天下午，约60分钟

**参会人员**：同首次会议

**会议议程**：
1. 核查组总结核查工作开展情况
2. 通报核查发现及不符合项
3. 说明初步核查结论
4. 企业陈述意见
5. 明确整改要求和时限
6. 感谢企业配合

### 5.3 核查报告阶段

#### 5.3.1 整改验证

对存在不符合项的，企业应在规定时间内整改：

**整改流程：**
1. 核查组下达不符合项通知书
2. 企业分析原因，制定整改方案
3. 企业实施整改
4. 企业提交整改报告及证据材料
5. 核查组验证整改效果
6. 验证有效后关闭不符合项

**整改期限：**
- 重大不符合：一般不超过30天
- 一般不符合：一般不超过15天

#### 5.3.2 编制核查报告

核查组根据核查结果编制正式核查报告。

#### 5.3.3 内部审核

核查机构进行内部审核：
- 一级审核：核查组组长审核
- 二级审核：技术负责人审核
- 三级审核：机构负责人批准

#### 5.3.4 提交报告

核查机构向委托方提交正式核查报告：
- 纸质报告（加盖公章，骑缝章）
- 电子报告（PDF格式）
- 报告份数按合同约定

## 六、核查内容与方法

### 6.1 核算边界核查

#### 6.1.1 组织边界

**核查要点：**
1. 企业法人资格是否明确
2. 是否采用控制权法/股权比例法
3. 分公司、子公司是否正确处理
4. 租赁、承包设施是否正确处理
5. 所有生产设施是否全部纳入

**核查方法：**
- 审查营业执照、组织机构代码证
- 审查组织架构图
- 审查固定资产清单
- 审查租赁、承包合同
- 现场核实设施数量和位置

#### 6.1.2 运行边界

**核查要点：**
1. 范围1排放源是否完整
   - 固定燃烧排放源
   - 移动燃烧排放源
   - 工艺过程排放源
   - 逸散排放源
2. 范围2排放是否完整
   - 外购电力
   - 外购蒸汽/热力
3. 是否存在遗漏或重复

**核查方法：**
- 审查排放源清单
- 对照工艺流程图识别
- 现场勘查确认
- 与同行业对比分析

### 6.2 活动数据核查

#### 6.2.1 燃料消耗量

**核查方法：**

| 方法 | 操作要点 | 证据类型 |
|-----|---------|---------|
| 凭证核对法 | 核对发票、过磅单、结算单 | 原始凭证 |
| 台账核对法 | 核对出入库台账、库存记录 | 统计台账 |
| 仪表核对法 | 核对计量仪表记录 | 仪表数据 |
| 趋势分析法 | 分析月度、年度变化趋势 | 时间序列 |
| 交叉验证法 | 与产量、产值等对比 | 关联数据 |

**抽样要求：**
- 购入凭证抽查比例≥10%，且不少于12份
- 库存记录抽查≥3个月
- 计量记录抽查≥6个月

#### 6.2.2 电力/热力消耗量

**核查要点：**
1. 外购电力是否以电网结算为准
2. 自备电厂是否正确核算
3. 转供电量是否扣除
4. 蒸汽/热力计量是否准确

**核查方法：**
- 审查结算单和发票
- 审查自备电厂运行记录
- 审查转供电协议和记录
- 检查计量装置检定证书

### 6.3 排放因子核查

#### 6.3.1 元素碳含量

**核查要点：**
1. 检测方法是否符合标准
2. 检测机构是否具备资质
3. 检测频率是否满足要求
4. 数据取值是否正确
5. 加权平均计算是否准确

**核查方法：**
- 检查检测报告（CMA/CNAS标志）
- 检查检测机构资质证书
- 核对检测报告数量（每月至少1份）
- 复算加权平均值
- 与历史数据、行业数据对比

#### 6.3.2 低位发热量

**核查要点：**
1. 检测方法是否符合GB/T 213
2. 高位/低位发热量换算是否正确
3. 与元素分析结果是否匹配

#### 6.3.3 碳氧化率

**核查要点：**
1. 是否按指南规定取值
2. 特殊设备取值是否有依据

#### 6.3.4 电力排放因子

**核查要点：**
1. 是否采用正确的区域电网因子
2. 是否采用最新版本的因子

### 6.4 计算过程核查

#### 6.4.1 计算公式核查

**核查方法：**
- 对照行业指南核对公式
- 检查系数（如44/12）是否正确
- 检查单位换算是否正确
- 独立复算关键排放源

#### 6.4.2 计算准确性核查

**复算要求：**
- 主要排放源100%复算
- 一般排放源抽查≥30%
- 合计数100%验算
- CO₂当量计算100%复算

### 6.5 数据质量管理核查

**核查要点：**
1. 是否建立数据管理制度
2. 计量器具是否定期检定
3. 数据记录是否完整可追溯
4. 是否有内部审核机制
5. 人员是否经过培训

**核查方法：**
- 审查制度文件
- 审查计量检定证书
- 抽查数据记录
- 询问相关人员
- 检查培训记录

## 七、重要性与风险评估

### 7.1 重要性水平

**重要性水平确定：**

| 企业排放规模 | 重要性阈值（相对值） | 说明 |
|-------------|-------------------|------|
| ≥1000万tCO₂e | ±3% | 超大型排放企业 |
| 100万~1000万tCO₂e | ±5% | 大型排放企业 |
| 10万~100万tCO₂e | ±5% | 中型排放企业 |
| <10万tCO₂e | ±10% | 小型排放企业 |

**重要性应用原则：**
- 超过重要性水平的错报为重大错报
- 接近重要性水平的应追加核查程序
- 多项小额错报应汇总考虑

### 7.2 风险评估

#### 7.2.1 风险识别

| 风险领域 | 风险因素 | 风险等级 |
|---------|---------|---------|
| 燃料消耗量 | 少报消耗、虚报库存、数据造假 | 高 |
| 燃料含碳量 | 使用低值、检测造假 | 高 |
| 工艺排放 | 低估排放量、方法不当 | 中高 |
| 核算边界 | 遗漏高排放设施 | 中高 |
| 外购电力 | 少报用电量 | 中 |
| 数据质量 | 记录不全、计量不准 | 中 |

#### 7.2.2 风险应对

**高风险领域应对措施：**
- 增加核查时间和资源
- 提高抽样比例
- 采用多种核查方法
- 增加核查人员
- 安排专家参与

## 八、核查结论

### 8.1 核查结论类型

#### 8.1.1 无保留结论

**适用条件：**
- 排放报告符合核查准则
- 未发现重大不符合
- 核查范围未受限制
- 证据充分、适当

**标准表述：**
"我们认为，XX公司20XX年度温室气体排放报告符合《XX行业温室气体排放核算方法与报告指南》的规定，在所有重大方面真实、准确、完整地反映了该公司20XX年度的温室气体排放情况。"

#### 8.1.2 保留结论

**适用条件：**
- 存在个别重大不符合，但整体影响有限
- 核查范围受到局部限制
- 部分数据存在不确定性

**标准表述：**
"除XX事项的影响外，我们认为，XX公司20XX年度温室气体排放报告符合《XX行业温室气体排放核算方法与报告指南》的规定，在所有重大方面真实、准确、完整地反映了该公司20XX年度的温室气体排放情况。"

#### 8.1.3 否定结论

**适用条件：**
- 存在多个重大不符合
- 排放报告严重失实
- 企业不配合核查
- 证据严重不足

**标准表述：**
"我们认为，由于存在XX等重大问题，XX公司20XX年度温室气体排放报告不符合《XX行业温室气体排放核算方法与报告指南》的规定，未能真实、准确、完整地反映该公司20XX年度的温室气体排放情况。"

#### 8.1.4 无法表示结论

**适用条件：**
- 核查范围受到严重限制
- 无法获取充分、适当的证据
- 企业严重不配合

**标准表述：**
"由于XX原因，我们无法获取充分、适当的核查证据，因此无法对XX公司20XX年度温室气体排放报告发表结论。"
