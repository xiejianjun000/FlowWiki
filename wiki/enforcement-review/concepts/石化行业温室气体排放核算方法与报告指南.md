# 石化行业温室气体排放核算方法与报告指南

**文件编号**：GB/T 32151.15-2015
**发布单位**：国家市场监督管理总局、国家标准化管理委员会
**实施日期**：2016年6月1日
**适用范围**：石油化工生产企业温室气体排放核算与报告

---

## 一、适用范围

本指南适用于石油化工生产企业的温室气体排放核算与报告工作。

### 1.1 适用主体

- 原油加工企业（炼油厂）
- 石油化工联合企业
- 乙烯生产企业
- 合成树脂生产企业
- 合成橡胶生产企业
- 合成纤维原料生产企业
- 其他石油化工产品生产企业

### 1.2 不适用范围

- 石油天然气开采企业（另行执行油气开采指南）
- 纯成品油销售企业
- 纯化工产品贸易企业
- 纯仓储物流企业

---

## 二、核算边界

### 2.1 组织边界

石化企业应核算其拥有或控制的所有生产设施的温室气体排放。

- **拥有**：企业具有所有权的生产设施
- **控制**：企业具有运营控制权的生产设施

### 2.2 运行边界

核算边界应包括石化生产的直接排放和间接排放。

#### 2.2.1 直接排放（范围1）

1. **化石燃料燃烧排放**：加热炉、锅炉、裂解炉、焚烧炉等燃烧设备化石燃料燃烧产生的CO₂排放
2. **工业生产过程排放**：
   - 催化裂化催化剂再生排放
   - 制氢过程排放
   - 脱硫过程排放
   - 其他化学反应过程排放
3. **逸散排放**：
   - 设备密封点泄漏
   - 储罐呼吸排放
   - 废水处理排放
   - 火炬燃烧排放
   - 制冷剂泄漏

#### 2.2.2 间接排放（范围2）

1. **购入使用电力排放**：企业购入的电力产生的CO₂排放
2. **购入使用蒸汽排放**：企业购入的蒸汽产生的CO₂排放（如适用）

### 2.3 生产装置边界

典型石化生产装置包括：

| 装置类型 | 主要产品 | 主要排放源 |
|---------|---------|-----------|
| 常减压蒸馏 | 石脑油、煤油、柴油、蜡油、渣油 | 加热炉燃料燃烧 |
| 催化裂化 | 汽油、柴油、液化气 | 催化剂再生、加热炉 |
| 催化重整 | 高辛烷值汽油、芳烃 | 加热炉、催化剂再生 |
| 加氢裂化 | 轻油、中间馏分 | 加热炉、氢气消耗 |
| 延迟焦化 | 焦化气、汽柴油、石油焦 | 加热炉、焦炭燃烧 |
| 乙烯装置 | 乙烯、丙烯、丁二烯、芳烃 | 裂解炉、锅炉 |
| 合成树脂 | 聚乙烯、聚丙烯、聚苯乙烯 | 聚合反应、辅助锅炉 |
| 合成橡胶 | 顺丁橡胶、丁苯橡胶 | 聚合反应、凝聚干燥 |
| 制氢装置 | 氢气 | 转化炉、CO变换 |
| 硫磺回收 | 硫磺 | 克劳斯反应炉 |
| 污水处理场 | 净化水 | 厌氧处理沼气 |

## 三、核算方法

### 3.1 总体方法

石化行业温室气体排放核算采用**排放因子法**与**物料平衡法**相结合的方法。

### 3.2 核算公式

```
E_total = E_combustion + E_process + E_fugitive + E_indirect
```

其中：
- `E_total`：温室气体排放总量，单位：吨CO₂当量（tCO₂e）
- `E_combustion`：化石燃料燃烧排放量，单位：tCO₂
- `E_process`：工业生产过程排放量，单位：tCO₂
- `E_fugitive`：逸散排放量，单位：tCO₂e
- `E_indirect`：间接排放量，单位：tCO₂

### 3.3 化石燃料燃烧排放核算

```
E_combustion = Σ (FC_i × NCV_i × EF_i × OF_i × 44/12)
```

其中：
- `FC_i`：第i种化石燃料的消耗量，单位：t或10⁴Nm³
- `NCV_i`：第i种化石燃料的低位发热量，单位：GJ/t或GJ/10⁴Nm³
- `EF_i`：第i种化石燃料的单位热值含碳量，单位：tC/GJ
- `OF_i`：第i种化石燃料的碳氧化率，单位：%

### 3.4 工业生产过程排放核算

#### 3.4.1 催化裂化催化剂再生排放

方法一：烧焦量法

```
E_FCC = C_burned × 44/12
```

其中：
- `C_burned`：催化剂再生烧焦量，单位：tC
- `44/12`：碳转化为二氧化碳的系数

方法二：烟气分析法

```
E_FCC = V_flue_gas × C_CO2 × 44/22.4 × 10^-6
```

#### 3.4.2 制氢过程排放

```
E_H2 = P_H2 × EF_H2
```

其中：
- `P_H2`：氢气产量，单位：t
- `EF_H2`：制氢排放因子，单位：tCO₂/tH₂

#### 3.4.3 硫磺回收排放

```
E_sulfur = P_sulfur × EF_sulfur
```

#### 3.4.4 其他过程排放

```
E_other_process = Σ (P_i × EF_i)
```

### 3.5 逸散排放核算

#### 3.5.1 设备泄漏排放

方法一：检测法（LDAR）

```
F_leak = Σ (N_j × EF_j)
```

其中：
- `N_j`：第j类密封点数量，单位：个
- `EF_j`：第j类密封点排放因子，单位：kg/个/年

方法二：估算法（排放系数法）

```
F_leak = Σ (throughput_j × EF_throughput,j)
```

#### 3.5.2 储罐呼吸排放

```
F_storage = Σ (V_i × EF_storage,i)
```

其中：
- `V_i`：第i种物料储存量，单位：t
- `EF_storage,i`：第i种物料储罐排放因子，单位：tCO₂e/t

#### 3.5.3 废水处理排放

```
F_wastewater = (COD_in - COD_out - COD_sludge) × EF_CH4 × GWP_CH4
```

#### 3.5.4 火炬燃烧排放

```
F_flare = Σ (V_flare,i × EF_flare,i)
```

其中：
- `V_flare,i`：第i种放空气体的量，单位：t或10⁴Nm³
- `EF_flare,i`：第i种放空气体的排放因子，单位：tCO₂/t

#### 3.5.5 制冷剂泄漏排放

```
F_refrigerant = Σ (M_ref,i × GWP_i)
```

### 3.6 间接排放核算

```
E_indirect = AD_electricity × EF_electricity + AD_steam × EF_steam
```

## 四、温室气体种类

本指南核算的温室气体包括：

| 序号 | 温室气体种类 | 化学分子式 | 全球增温潜势（GWP） | 主要来源 |
|------|-------------|-----------|---------------------|----------|
| 1 | 二氧化碳 | CO₂ | 1 | 化石燃料燃烧、工艺过程、间接排放 |
| 2 | 甲烷 | CH₄ | 28 | 逸散排放、废水处理、火炬不完全燃烧 |
| 3 | 氧化亚氮 | N₂O | 265 | 化石燃料燃烧（少量） |
| 4 | 氢氟碳化物 | HFCs | 124-14800 | 制冷剂、发泡剂 |

**说明**：石化行业以CO₂排放为主，同时存在大量逸散排放（设备泄漏、储罐呼吸、废水处理等），其中CH₄是重要的逸散温室气体。

## 五、排放源分类

### 5.1 直接排放源

#### 5.1.1 化石燃料燃烧排放

| 排放源 | 燃料类型 | 燃烧设备 | 占比 |
|--------|---------|----------|------|
| 加热炉/裂解炉 | 燃料气、燃料油、煤炭 | 管式加热炉、裂解炉 | 约40-50% |
| 锅炉 | 燃料气、煤炭、重油 | 电站锅炉、工业锅炉 | 约20-30% |
| 焚烧炉 | 辅助燃料+废气废液 | 废气焚烧炉、废液焚烧炉 | 约5-10% |
| 火炬 | 放空气体 | 高架火炬、地面火炬 | 约2-5% |
| 自备电厂 | 煤炭、燃料气 | 发电机组 | 约10-20% |

#### 5.1.2 工业生产过程排放

| 排放源 | 排放原因 | 温室气体 | 占比 |
|--------|---------|----------|------|
| 催化裂化再生 | 催化剂烧焦 | CO₂ | 约5-15% |
| 制氢过程 | 烃类转化 | CO₂ | 约3-8% |
| 硫磺回收 | 克劳斯反应 | CO₂（少量） | 约1-2% |
| 其他工艺 | 多种化学反应 | CO₂ | 约2-5% |

#### 5.1.3 逸散排放

| 排放源 | 排放原因 | 温室气体 | 占比 |
|--------|---------|----------|------|
| 设备泄漏 | 阀门、法兰、泵、压缩机等密封点 | CH₄、VOCs | 约5-15% |
| 储罐呼吸 | 温度、压力变化 | VOCs、CH₄ | 约3-8% |
| 废水处理 | 厌氧降解 | CH₄ | 约1-3% |
| 制冷剂泄漏 | 制冷设备 | HFCs | 约0.5-2% |
| 装卸逸散 | 装卸车/船 | VOCs | 约1-2% |

### 5.2 间接排放源

| 排放源 | 说明 | 占比 |
|--------|------|------|
| 购入使用电力 | 企业从电网购入的电力 | 约5-15% |
| 购入使用蒸汽 | 企业从外部购入的蒸汽 | 较少 |
| 自备电厂 | 企业自备电厂发电 | 计入直接排放 |

## 六、活动水平数据要求

### 6.1 化石燃料消耗量

#### 6.1.1 数据来源

- 优先采用**计量数据**：流量计、地磅、皮带秤等
- 次选采用**台账数据**：生产报表、燃料消耗台账
- 缺省采用**财务数据**：采购发票、财务凭证

#### 6.1.2 计量要求

| 燃料类型 | 计量器具 | 精度要求 | 检定周期 |
|---------|---------|----------|----------|
| 燃料气（炼厂气、天然气） | 气体流量计 | ±1.0% | 每年至少1次 |
| 燃料油（重油、渣油） | 流量计、地磅 | ±0.5% | 每年至少1次 |
| 煤炭 | 地磅、皮带秤 | ±0.5% | 每年至少1次 |
| 柴油、汽油 | 流量计、地磅 | ±0.5% | 每年至少1次 |
| 液化石油气 | 地磅、流量计 | ±1.0% | 每年至少1次 |

## 七、排放因子选取

### 7.1 排放因子选取原则

1. **优先实测**：企业具备实测条件的，应采用实测排放因子
2. **行业缺省**：无法实测的，采用行业缺省值
3. **国家标准**：可参考GB/T 32151系列国家标准中的缺省值

## 八、数据质量管理

### 8.1 数据质量控制计划（DQCP）

企业应制定并实施数据质量控制计划，包括：

- 数据质量管理组织机构及职责
- 数据监测计划（含监测点位、监测频次、监测方法）
- 数据记录和存档要求
- 数据审核机制（三级审核）
- 人员培训要求
- 仪器设备检定校准计划

### 8.2 LDAR数据管理

- 建立密封点台账
- 定期开展泄漏检测
- 及时修复泄漏点
- 完整保存检测记录
- 建立LDAR信息管理系统

### 8.3 数据质量等级

| 数据质量等级 | 活动数据要求 | 排放因子要求 | 适用情况 |
|-------------|-------------|-------------|----------|
| Ⅰ级 | 连续计量，每日记录 | 实测/LDAR检测 | 大型石化企业推荐 |
| Ⅱ级 | 定期计量，每周记录 | 行业缺省值（分装置） | 中型石化企业 |
| Ⅲ级 | 台账记录，每月汇总 | 行业平均缺省值 | 小型石化企业 |

### 8.4 数据内部审核

- 装置级：每日数据自查
- 厂部级：每周数据审核
- 公司级：每月数据质量审核
- 年度：全面数据质量审核
- 保留审核记录和整改报告

## 九、报告内容和格式要求

### 9.1 报告主体信息

- 企业基本情况（名称、统一社会信用代码、地址、法定代表人等）
- 生产设施基本情况（装置组成、加工能力、主要产品等）
- 核算边界说明（组织边界、运行边界、装置边界）
- 数据质量控制计划执行情况

### 9.2 排放数据

#### 9.2.1 排放总量

- 温室气体排放总量（tCO₂e）
- 直接排放量（tCO₂e）
- 间接排放量（tCO₂）
- 其中：逸散排放量（tCO₂e，单独列示）

#### 9.2.2 分排放源排放量

- 化石燃料燃烧排放量（分装置、分燃料类型）

### 附录B：核算公式汇总

```
1. 排放总量
E_total = E_combustion + E_process + E_fugitive + E_indirect

2. 化石燃料燃烧排放
E_combustion = Σ (FC_i × NCV_i × EF_i × OF_i × 44/12)

3. 催化裂化再生排放
E_FCC = C_burned × 44/12

4. 设备泄漏逸散排放（平均因子法）
F_leak = Σ (N_j × EF_j)

5. 储罐呼吸逸散排放
F_storage = Σ (V_i × EF_storage,i)

6. 废水处理逸散排放
F_wastewater = (COD_in - COD_out - COD_sludge) × EF_CH4 × GWP_CH4

7. 购入电力间接排放
E_indirect_electricity = AD_electricity × EF_electricity

8. 单位原油加工碳排放强度
EI_crude = E_total / P_crude

9. 单位产品碳排放强度
EI_product = E_total / P_product
```
