# 化工行业温室气体排放核算方法与报告指南

**文件编号**：GB/T 32151.10-2015
**发布单位**：国家市场监督管理总局、国家标准化管理委员会
**实施日期**：2016年6月1日
**适用范围**：化工生产企业温室气体排放核算与报告

---

## 一、适用范围

本指南适用于化工生产企业的温室气体排放核算与报告工作。

### 1.1 适用主体

- 基础化学原料制造企业（酸、碱、盐、化肥、有机原料等）
- 肥料制造企业（氮肥、磷肥、钾肥、复混肥等）
- 农药制造企业
- 涂料、油墨、颜料及类似产品制造企业
- 合成材料制造企业（塑料、合成橡胶、合成纤维等）
- 专用化学品制造企业
- 日用化学品制造企业

### 1.2 不适用范围

- 石油化工企业（另行执行石化行业指南）
- 生物化工企业（部分适用）
- 纯化学品加工、混配企业

---

## 二、核算边界

### 2.1 组织边界

化工企业应核算其拥有或控制的所有生产设施的温室气体排放。

- **拥有**：企业具有所有权的生产设施
- **控制**：企业具有运营控制权的生产设施

### 2.2 运行边界

核算边界应包括化工生产的直接排放和间接排放。

#### 2.2.1 直接排放（范围1）

1. **化石燃料燃烧排放**：锅炉、加热炉、焚烧炉等燃烧设备化石燃料燃烧产生的排放
2. **工业生产过程排放**：
   - 化学反应过程排放（如合成氨、硝酸、电石等生产过程）
   - 碳酸盐使用排放
   - 电极消耗排放
   - 催化剂再生排放
3. **逸散排放**：
   - 设备密封点泄漏
   - 储罐呼吸排放
   - 废水处理排放
   - 火炬燃烧排放

#### 2.2.2 间接排放（范围2）

1. **购入使用电力排放**
2. **购入使用蒸汽排放**
3. **购入使用热力排放**

### 2.3 生产装置边界

典型化工生产装置包括：

| 装置类型 | 主要产品 | 主要排放源 |
|---------|---------|-----------|
| 合成氨装置 | 合成氨、尿素 | 化石燃料燃烧、变换反应、原料脱碳 |
| 硝酸装置 | 硝酸 | 氧化反应、N₂O排放 |
| 烧碱装置 | 烧碱、氯气 | 电解过程、化石燃料燃烧 |
| 纯碱装置 | 纯碱 | 碳酸盐分解、煅烧反应 |
| 电石装置 | 电石 | 电弧炉、原料煅烧 |
| 甲醇装置 | 甲醇 | 原料转化、合成反应 |
| 乙烯装置 | 乙烯、丙烯 | 裂解炉、锅炉 |
| 合成树脂装置 | 聚乙烯、聚丙烯 | 聚合反应、催化剂 |
| 合成橡胶装置 | 合成橡胶 | 聚合反应、凝聚干燥 |

## 三、核算方法

### 3.1 总体方法

化工行业温室气体排放核算采用**排放因子法**与**物料平衡法**相结合的方法。

### 3.2 核算公式

```
E_total = E_combustion + E_process + E_fugitive + E_indirect
```

其中：
- `E_total`：温室气体排放总量，单位：吨CO₂当量（tCO₂e）
- `E_combustion`：化石燃料燃烧排放量，单位：tCO₂
- `E_process`：工业生产过程排放量，单位：tCO₂e
- `E_fugitive`：逸散排放量，单位：tCO₂e
- `E_indirect`：间接排放量，单位：tCO₂

### 3.3 化石燃料燃烧排放核算

```
E_combustion = Σ (FC_i × NCV_i × EF_i × OF_i × 44/12)
```

其中：
- `FC_i`：第i种化石燃料的消耗量，单位：t或10⁴Nm³
- `NCV_i`：第i种化石燃料的低位发热量，单位：GJ/t或GJ/10⁴Nm³
- `EF_i`：第i种化石燃料的单位热值含碳量，单位：tC/GJ
- `OF_i`：第i种化石燃料的碳氧化率，单位：%

### 3.4 工业生产过程排放核算

#### 3.4.1 合成氨过程排放

```
E_ammonia = P_ammonia × EF_ammonia
```

其中：
- `P_ammonia`：合成氨产量，单位：t
- `EF_ammonia`：合成氨排放因子，单位：tCO₂/tNH₃

#### 3.4.2 硝酸生产N₂O排放

```
E_nitric_acid = P_nitric_acid × EF_N2O × GWP_N2O
```

其中：
- `P_nitric_acid`：硝酸产量（100%HNO₃），单位：t
- `EF_N2O`：硝酸生产N₂O排放因子，单位：tN₂O/t
- `GWP_N2O`：N₂O全球增温潜势，取265

#### 3.4.3 电石生产过程排放

```
E_calcium_carbide = P_carbide × EF_carbide
```

其中：
- `P_carbide`：电石产量（折发气量300L/kg），单位：t
- `EF_carbide`：电石排放因子，单位：tCO₂/t

#### 3.4.4 纯碱生产过程排放

```
E_soda_ash = P_soda_ash × EF_soda_ash
```

其中：
- `P_soda_ash`：纯碱产量，单位：t
- `EF_soda_ash`：纯碱排放因子，单位：tCO₂/t

### 3.5 逸散排放核算

#### 3.5.1 设备泄漏排放

采用核算公式法或检测法：

```
F_leak = Σ (N_j × EF_j)
```

其中：
- `N_j`：第j类密封点数量，单位：个
- `EF_j`：第j类密封点排放因子，单位：kg/个/年

#### 3.5.2 储罐呼吸排放

```
F_storage = Σ (V_i × EF_storage,i)
```

其中：
- `V_i`：第i种物料储存量，单位：t
- `EF_storage,i`：第i种物料储罐排放因子，单位：tCO₂e/t

#### 3.5.3 废水处理排放

```
F_wastewater = Q_wastewater × EF_wastewater
```

其中：
- `Q_wastewater`：废水处理量，单位：t
- `EF_wastewater`：废水处理排放因子，单位：tCO₂e/t

### 3.6 间接排放核算

```
E_indirect = AD_electricity × EF_electricity + AD_steam × EF_steam
```

## 四、温室气体种类

本指南核算的温室气体包括：

| 序号 | 温室气体种类 | 化学分子式 | 全球增温潜势（GWP） | 主要来源 |
|------|-------------|-----------|---------------------|----------|
| 1 | 二氧化碳 | CO₂ | 1 | 化石燃料燃烧、工业生产过程 |
| 2 | 甲烷 | CH₄ | 28 | 逸散排放、废水处理、火炬 |
| 3 | 氧化亚氮 | N₂O | 265 | 硝酸生产、己二酸生产 |
| 4 | 氢氟碳化物 | HFCs | 124-14800 | 制冷剂、发泡剂 |
| 5 | 全氟碳化物 | PFCs | 7390-12200 | 电解铝（不属化工）、半导体 |
| 6 | 六氟化硫 | SF₆ | 23500 | 电气设备、镁冶炼 |

**说明**：化工行业以CO₂排放为主，同时存在N₂O（硝酸、己二酸生产）、CH₄（逸散）和含氟气体（制冷剂）排放。

## 八、数据质量管理

### 8.1 数据质量控制计划（DQCP）

企业应制定并实施数据质量控制计划，包括：

- 数据质量管理组织机构及职责
- 数据监测计划（含监测点位、监测频次、监测方法）
- 数据记录和存档要求
- 数据审核机制（三级审核）
- 人员培训要求
- 仪器设备检定校准计划

### 8.2 数据质量等级

| 数据质量等级 | 活动数据要求 | 排放因子要求 | 适用情况 |
|-------------|-------------|-------------|----------|
| Ⅰ级 | 连续计量，每日记录 | 实测（每批次检测） | 重点排放单位推荐 |
| Ⅱ级 | 定期计量，每周记录 | 实测（每月检测） | 一般排放单位 |
| Ⅲ级 | 台账记录，每月汇总 | 行业缺省值 | 小规模排放单位 |

### 8.3 数据内部审核

- 班组级：每日数据自查
- 车间级：每周数据审核
- 公司级：每月数据质量审核
- 年度：全面数据质量审核
- 保留审核记录和整改报告

### 8.4 不确定性控制

- 定期开展排放量不确定性分析
- 识别主要不确定性来源
- 采取措施降低不确定性
- 报告不确定性范围

## 九、报告内容和格式要求

### 9.1 报告主体信息

- 企业基本情况（名称、统一社会信用代码、地址、法定代表人等）
- 生产设施基本情况（装置组成、产能、主要产品等）
- 核算边界说明（组织边界、运行边界、装置边界）
- 数据质量控制计划执行情况

### 9.2 排放数据

#### 9.2.1 排放总量

- 温室气体排放总量（tCO₂e）
- 直接排放量（tCO₂e）
- 间接排放量（tCO₂）

#### 9.2.2 分排放源排放量

- 化石燃料燃烧排放量（分装置、分燃料类型）
- 工业生产过程排放量（分工艺、分气体种类）
- 逸散排放量（分类型）
- 购入使用电力排放量
- 购入使用蒸汽/热力排放量

### 9.3 活动数据

- 化石燃料消耗量（分类型）
- 产品产量（分类型）
- 原材料消耗量（分类型）
- 逸散排放相关数据
- 购入电量/蒸汽量

### 9.4 排放因子数据

- 各燃料排放因子及来源
- 各工艺过程排放因子及来源
- 逸散排放因子及来源
- 电力排放因子及来源

### 9.5 支撑材料

- 数据质量控制计划
- 监测设备检定校准证书
- 物料检测报告
- 电费/蒸汽费结算单
- 物料平衡表
- 其他证明材料

### 9.6 报告格式

报告应采用统一报告格式，包括：

- 封面
- 目录
- 正文（按上述内容组织）
- 附表（数据表格）
- 附图（工艺流程图、监测点位图等）
- 附件（证明材料）

### 附录B：核算公式汇总

```
1. 排放总量
E_total = E_combustion + E_process + E_fugitive + E_indirect

2. 化石燃料燃烧排放
E_combustion = Σ (FC_i × NCV_i × EF_i × OF_i × 44/12)

3. 工业生产过程排放
E_process = Σ (P_j × EF_process,j × GWP_j)

4. 设备泄漏逸散排放
F_leak = Σ (N_j × EF_j)

5. 储罐呼吸逸散排放
F_storage = Σ (V_i × EF_storage,i)

6. 废水处理逸散排放
F_wastewater = Q_wastewater × EF_wastewater

7. 购入电力间接排放
E_indirect_electricity = AD_electricity × EF_electricity

8. 单位产品碳排放强度
EI_product = E_total / P_product
```
