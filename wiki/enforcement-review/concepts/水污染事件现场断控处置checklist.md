# 水污染事件现场断控处置 Checklist（断·控·治·测）

**适用场景**：突发水污染事件（生产/储存/运输/处置危险化学品或危险废物引发，或自然灾害次生），重点适配娄底市资江、涟水、孙水河、青丰河、涟溪河等流域工矿（涉锑）企业环境风险。  
**核心理念**：以空间换时间（找空间 → 定方案 → 抓演练）；三级防控（一级不出厂区、二级不出公共应急空间、三级不出园区）。  
**配套规范**：HJ 589-2021《突发环境事件应急监测技术规范》。  
**用法**：接报后按"断→控→治→测→保"顺序处置，每完成一项打☑；本卡与《一河（园）一策一图》空间清单配合使用。

---

## 0. 接报与启动（0–30分钟）

- [ ] 核实：事发位置、污染源/污染物、泄漏量、入水方式（雨水/污水/直接入河）、受影响水体
- [ ] 第一时间启动预案，向县级以上生态环境部门报告（较大及以上：30分钟内电话、60分钟内书面）
- [ ] 通知下游水厂、可能受影响取水口、沿岸居民；研判是否需停取用水
- [ ] 调集污染处置组、应急监测组、应急保障组到位（娄底市8工作组对标对接）
- [ ] 判定事件级别，必要时启动Ⅳ级及以上响应

---

## 1. 断（断源·源头控制）— 越快越好，先于一切围堵

**目标：切断或减少污染物进入水体。**

- [ ] **关闸**：关闭企业雨水排口闸阀、污水排口闸阀（远程/现场），切换井切至事故应急池
- [ ] **收容**：装置区围堰、罐区防火堤收容泄漏物，防止漫流
- [ ] **堵漏**：封堵漏点；交通泄漏用围堤/挖沟槽收容至安全地点（吸油毡、防油栅）
- [ ] **限排/停产**：关停、限排相关排放企业与产污工序
- [ ] **物料转移**：可安全转移物料的，优先转移避免事故扩大（三级防控导则优先项）
- [ ] **一级防控确认**：事故废水是否已被控制在企业事故应急池/初期雨水池内（不出厂区？）

> 娄底涉锑要点：锡矿山企业雨水入河闸阀"平时可远程、急时可关闭"；青丰河、涟溪河入河口闸控第一时间关闭。

---

## 2. 控（控扩散·拦截与暂存）— 把污染团"关住"

**目标：利用应急空间拦住、存住污染团，防止下泄至饮用水源地/敏感点。**

- [ ] **筑坝拦截**：在溢点上游50m、下游100m等临时筑坝点修土坝/设气囊，拦截高浓度废水
- [ ] **闸坝调度**：调度河流闸坝、水库分段拦蓄，控制清水、隔离污染团（河道可作临时应急池）
- [ ] **回抽转输**：雨水管网回抽装置 + 临时管线，将事故废水转输至园区/公共事故应急池（双通道优先）
- [ ] **导流引流**：利用坑塘、水库、明渠将污染水引至临时储存空间
- [ ] **二级/三级防控确认**：一级不足时启用园区公共应急空间（二级）；仍不足时闸坝/临时坝拦在园区内（三级）
- [ ] **空间清单核对**：对照《一河（园）一策一图》空间清单，确认已启用的闸坝/水库/坑塘/筑坝点坐标与容量

> 娄底要点：资江干流"找空间"——闸坝、水库调蓄、河道分段拦蓄，严防污染团下泄至新化水厂断面；上下游（娄底—邵阳—益阳）联动通报。

---

## 3. 治（削减·污染处置）— 降浓度、削峰值

**目标：在拦截空间内或旁路对污染水进行削减处置。**

- [ ] **投加**：依污染物投加混凝剂（铁盐/铝盐）、吸附剂（活性炭/沸石）、氧化剂（次氯/双氧）等
  - 涉锑：**铁盐/铝盐混凝沉淀捕集锑离子（沉淀降锑）**，配合 PAM 助凝
- [ ] **吸附**：水面油类/有机溶剂用吸油毡、活性炭；打捞漂浮污染物
- [ ] **絮凝沉淀**：在应急池/拦蓄河段投药沉淀，泥渣妥善收集处置（防二次污染）
- [ ] **旁路治理**：引污染水至旁建处理设施（如**涟溪河旁路治理工程**）处理后回河
- [ ] **稀释**：通过加大泄流/水库调水稀释（⚠ 须与沉淀降锑同步，避免仅下移污染团）
- [ ] **处置泥渣/吸附物**：作为危废规范收集、转运、处置，留痕建档

> 娄底三段式处置链（已验证）：沉淀降锑 + 水利调度（泄流/调蓄）+ 备用水源切换（新化二水厂）。枯水期"加大泄流"必配"沉淀降锑"。

---

## 4. 测（应急监测）— 依 HJ 589-2021

**目标：掌握污染态势，支撑断/控/治决策与事件终止判定。**

- [ ] **布点**（HJ 589-2021）：事发地上游设**对照断面**；下游设**控制断面/削减断面**；饮用水源地等**敏感点断面**必布
- [ ] **频次**：初期加密（连续/小时级），随态势稳定逐步降低；跟踪污染前锋与范围
- [ ] **快筛**：便携重金属仪/试纸/无人船/小微水质站定性半定量筛查特征污染物（锑等）
- [ ] **确证**：快筛异常即用实验室方法定量确证
- [ ] **敏感点盯防**：新化水厂、月光潭等饮用水源地断面重点加密；超标即启动供水保障
- [ ] **底泥反释警惕**：上游来水骤减+高温高光照时，持续监测底泥反释导致的浓度反弹（2022坪口教训）
- [ ] **上报与终止**：按规范上报监测数据；污染团消除、敏感点稳定达标后方可终止监测

---

## 5. 保（饮用水与公众）— 守住底线

- [ ] 超标或超标风险时：通知水厂调整工艺/强化净化，必要时**停取、启用备用水源**（新化二水厂）
- [ ] 水源现有工艺不能控制时：建议停止供水、启动临时供水，媒体通告居民禁饮
- [ ] 受影响人群：医疗救治、预防性服药、必要时疏散；送供水水质检测与容器消毒
- [ ] 信息发布：由新闻宣传组统一发布，避免恐慌

---

## 附：娄底资江锑污染处置"三必做"

1. **雨季/枯水季必维持常态化应急机制**（锑浓度波动高发期）
2. **沉淀降锑 + 水利调度必同步**（单纯稀释只是下移污染团）
3. **上下游联防联控必启动**（娄底—邵阳—益阳信息通报、资源共享）
