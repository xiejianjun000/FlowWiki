# 第三方监测机构造假典型案例汇编

**来源**: 生态环境部、最高人民法院、各省生态环境厅公布的典型案例  
**说明**: 以下为2022-2026年查处的典型第三方机构弄虚作假案件摘要

---

## 一、生态环境部公布典型案例

### 案例1：广东国环检测技术股份有限公司造假案（2023年公布）

**查处时间**：2021年  
**查处机关**：广东省中山市生态环境局  
**违法行为**：80份监测报告存在未开展采样分析直接出具监测数据、故意不真实记录原始数据、纸质与电子记录不一致、用替代样品进行分析等  
**涉及范围**：45家排污单位  
**涉案金额**：66.49万元  
**处理结果**：公司犯提供虚假证明文件罪，罚金20万元；总经理等5人分别被判1年2个月至1年9个月不等有期徒刑并处罚金  

### 案例2：河北从瑞环保科技有限公司造假案（2024年公布）

**查处时间**：2023年12月-2024年1月  
**查处机关**：石家庄市生态环境局、公安局  
**违法行为**：2022-2023年期间在石家庄、邯郸、保定等地9次因出具虚假监测报告被处罚。符合"二年内因提供虚假证明文件受过二次行政处罚，又提供虚假证明文件"的刑事追究情形  
**处理结果**：2024年1月移送公安机关，6月5名涉案嫌疑人移送检察院审查起诉  

### 案例3：厦门凯力信检测技术有限公司造假案（2024年公布）

**查处时间**：2024年3月  
**查处机关**：厦门市生态环境局  
**违法行为**：修改实验室分析数据、使用虚假谱图、缩短采样时长、篡改采样原始记录、伪造时间等。2022年1月至2024年3月，向5个地市75家排污单位出具虚假监测报告205份  
**涉案金额**：银行回执53万余元（初步判断符合"违法所得三十万元以上的"刑事追究条件）  
**处理结果**：2024年7月移送公安机关立案侦查  

### 案例4：重庆中涵环保技术研究院有限公司造假案（2024年公布）

**查处时间**：2023年10月  
**查处机关**：重庆市江津区生态环境局  
**违法行为**：2023年7月出具的两份监测报告使用完全相同现场采样图片，当月排污单位实际未生产，编造虚假监测数据，伪造监测采样时间和负责人签字  
**处理结果**：对公司罚款13.1666万元，对主要负责人罚款2.9125万元（"双罚"）  

### 案例5：启东市全通机动车检测有限公司造假案（2024年公布）

**查处时间**：2024年4月  
**查处机关**：南通市启东生态环境局  
**违法行为**：检测线检测取样管安装三通阀，连接管路延伸至车间墙外。机动车无法通过尾气检测时，将合格车辆尾气接入分析仪代替检测  
**处理结果**：没收违法所得480元，罚款17.5万元  

### 案例6：某检测公司、石某涛等提供虚假证明文件案（2024年最高人民法院典型案例）

**违法行为**：2021年3月至2023年10月，出具环境监测虚假报告222份，涉及陕西省5地市44家委托单位  
**违法所得**：76万余元  
**处理结果**：构成提供虚假证明文件罪，属情节严重情形

## 二、福建省生态环境厅公布典型案例

### 案例7：福建省大潭检测有限公司"先监测后采样"案（2023年公布）

**违法行为**：检测报告中地下水、地表水铜和锌的检测分析时间为2022年11月13日，而水质采样记录时间为2022年11月14日，分析时间早于采样时间  
**处理结果**：没收违法所得，罚款5.17万元，三年内禁止参与政府购买服务，直接责任人员三年内不得从事监测服务活动  

### 案例8：福建省本讯环境检测有限公司伪造采样记录案（2022年公布）

**违法行为**：编造烟尘在线监测设施校验监测的原始采样记录，实际采样时长与报告记载不符  
**处理结果**：依法处罚并移送市场监管部门处理

## 三、厦门市生态环境局公布2026年典型案例

### 案例9：篡改仪器时间、无组织废气未采样造假案

**查处时间**：2024年7月  
**违法行为**：3份建设项目验收检测报告涉及的非甲烷总烃样品超过保存期限，实验室分析人员通过变更电脑系统时间人为改变仪器分析时间；2份报告中无组织颗粒物未实际采样，通过伪造样品上交实验室分析  
**处理结果**：没收违法所得2.9万元，罚款5.1875万元，三年内禁止参与政府购买服务，直接责任人员三年内不得从事监测服务活动  

### 案例10：缩减采样时长、虚报采样频次造假案

**违法行为**：监测报告原始记录表中载明的采样时长和频次与企业视频监控不一致，实际采样频次和时长远低于规范要求（如30分钟×3频次变为12分钟×1频次）  
**处理结果**：依法处罚

## 四、造假常见手段总结

| 类别 | 具体手段 |
|------|----------|
| 未采造假 | 未开展采样分析直接出具监测数据；用替代样品进行分析 |
| 记录造假 | 纸质原始记录与电子存储记录不一致；编造原始采样记录；伪造采样时间 |
| 仪器造假 | 修改实验室分析数据；使用虚假谱图；变更电脑系统时间 |
| 程序造假 | 缩短采样时长；虚报采样频次；先出数据后采样（分析时间早于采样时间） |
| 硬件造假 | 加装三通阀替换样品；破坏/擅自改动监测设备参数 |
| 报告造假 | 报告副本与正本不一致；不同企业使用完全相同的数据和图片 |

## 五、法律责任体系

| 违法行为 | 法律后果 |
|----------|----------|
| 出具不实检验检测报告 | 限期改正，处3万元罚款 |
| 出具虚假检验检测报告 | 限期改正，处10万元罚款 |
| 监测数据弄虚作假 | 10万-100万元罚款；情节严重责令停产停业 |
| 提供虚假证明文件罪 | 有期徒刑+罚金（违法所得30万以上或受过两次处罚后再犯） |
| 连带责任 | 在环境服务活动中弄虚作假，对造成污染负有责任的，承担连带责任（《环境保护法》第65条） |
| 从业禁止 | 列入不良记录名单，禁止参与政府购买服务；直接责任人员禁止从事监测服务活动 |
