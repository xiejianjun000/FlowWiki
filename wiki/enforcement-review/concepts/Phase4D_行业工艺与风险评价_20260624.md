## 专题1：化工行业典型工艺流程与产污节点

### 1.1 涉氯工艺

#### 1.1.1 液氯使用/储存工艺流程

**工艺流程概述**：
```
液氯槽车 → 液氯储罐(0.05-0.65MPa) → 气化器(40-45℃热水加热) 
→ 缓冲罐 → 氯化反应釜 → 尾气处理(碱液吸收)
```

**关键工艺参数**：
- 液氯储罐压力：0.05-0.65 MPa
- 气化温度：40-45℃（使用热水循环加热，严禁蒸汽/明火直接加热）
- 槽车与储罐压差：0.15-0.20 MPa

**关键风险节点**：

| 风险节点 | 主要风险 | 典型事故场景 |
|---------|---------|-------------|
| 液氯储罐 | 超压、腐蚀、材料老化 | 储罐超压破裂、焊缝泄漏 |
| 管道系统 | 腐蚀、法兰密封失效 | 管道破裂、法兰泄漏 |
| 阀门 | 密封失效、误操作 | 阀门泄漏、误开误关 |
| 气化器 | NCl₃积累、超温超压 | 三氯化氮爆炸、气化器破裂 |
| 缓冲罐 | NCl₃积聚 | 定期排污不及时导致爆炸 |
| 反应釜 | 反应失控、倒灌 | 物料倒灌至液氯系统引发爆炸 |

**典型事故场景分析**：

1. **液氯管道破裂**
   - 源强：取决于管道直径、压力、破裂形式
   - 扩散特性：重质气体（密度约为空气的2.5倍）
   - 应急措施：紧急切断、水幕稀释、反向抽吸

2. **安全阀起跳**
   - 原因：储罐超压、环境温度过高
   - 后果：氯气直排大气
   - 预防：设置安全阀排放管引至吸收装置

3. **储罐超压**
   - 原因：充装过量、温度升高、异物进入
   - 预防：严格控制充装系数（≤85%）、设置超压报警

**三氯化氮（NCl₃）风险**：
- 来源：液氯生产过程中氨及有机胺类杂质与氯反应
- 危害：受热、撞击易爆炸
- 控制措施：
  - 定期排污（气化器、缓冲罐设排污口）
  - 控制液氯中NCl₃含量<50 ppm
  - 避免液氯完全气化

#### 1.1.2 氯碱工业（电解食盐水）

**工艺原理**：
```
2NaCl + 2H₂O → 2NaOH + Cl₂↑ + H₂↑
```

**三种工艺方法对比**：

| 工艺方法 | 隔膜法 | 离子膜法 | 水银法（已淘汰） |
|---------|--------|---------|----------------|
| 烧碱浓度 | 10-11% | 32-33% | 45-50% |
| NaCl含量（50%碱液）| 1.0-1.2% | <0.005% | 0.005% |
| 总能耗（kW·h/t） | 3260 | 2645 | 3205 |
| 主要风险 | 隔膜破损、氯气外溢 | 离子膜破损、氢气泄漏 | 汞污染 |

**产污节点**：
1. **氯气吸收塔**：尾气处理产生次氯酸钠废液
2. **次氯酸钠储罐**：老化分解产生氯酸盐
3. **含氯废水**：设备清洗、泄漏应急处理废水

**典型事故类型**：

1. **氯气外溢**
   - 原因：电解槽密封失效、氯气管道破裂
   - 特点：密度大，沿地面扩散
   - 应急：设置氯气吸收装置，碱液喷淋

2. **隔膜/离子膜破损**
   - 原因：
     - 盐水质量不合格（Ca²⁺、Mg²⁺、SO₄²⁻超标）
     - 膜老化、机械损伤
   - 后果：
     - Cl₂进入阴极室与H₂混合（爆炸风险）
     - H₂进入阳极室与Cl₂混合（氯中含氢超标）
   - 预防：严格控制盐水质量

**盐水质量控制标准**（待核实具体数值）：
- Ca²⁺ + Mg²⁺：< 2 mg/L
- SO₄²⁺：< 5 g/L
- Fe³⁺：< 0.5 mg/L

### 1.2 涉氨工艺

#### 1.2.1 液氨储存与制冷系统

**液氨储罐类型**：

| 类型 | 适用规模 | 特点 | 典型容量 |
|-----|---------|------|---------|
| 球罐 | 大型储备 | 受力均匀、占地面积小 | 500-5000 m³ |
| 卧罐 | 中小型 | 制造简单、便于运输 | 10-200 m³ |
| 立罐 | 小型 | 占地面积小 | <100 m³ |

**制冷系统氨循环原理**：
```
压缩机 → 冷凝器（放热）→ 节流阀 → 蒸发器（吸热制冷）
    ↑                                        ↓
    ←←←←←←←←← 氨气回流 ←←←←←←←←←←←←←←←←←←←
```

**关键风险节点**：

| 风险部位 | 主要风险 | 典型事故 |
|---------|---------|---------|
| 管道系统 | 腐蚀、振动疲劳 | 管道破裂、法兰泄漏 |
| 阀门 | 密封失效、冰堵 | 阀门泄漏、冻伤 |
| 安全阀 | 起跳后不复位 | 持续泄漏 |
| 冷凝器 | 腐蚀穿孔 | 水侧进入氨系统 |
| 蒸发器 | 结霜过厚、融霜冲击 | 管道破裂 |
| 压缩机 | 轴封泄漏、液击 | 氨气泄漏、设备损坏 |

**典型事故场景**：

1. **管道破裂泄漏**
   - 原因：腐蚀、振动、低温脆性断裂
   - 源强估算：
     - 小孔泄漏（孔径≤10mm）：Q = Cd·A·√(2ρΔP)
     - 完全破裂：储罐存量快速释放
   - 扩散特性：
     - 密度0.6（轻质气体，上升扩散）
     - 爆炸极限：16-25%（最易引燃浓度17%）
     - 自燃点：651℃

2. **安全阀失效泄漏**
   - 原因：脏物阻碍密封、弹簧失效
   - 特点：高空排放，检查易疏忽
   - 预防：定期检验、设置备用安全阀

3. **融霜管道破裂**
   - 原因：融霜时压差过大、液锤冲击
   - 预防：控制融霜速度、设置缓冲装置

**氨的理化特性**：
- 分子式：NH₃
- 分子量：17.03
- 沸点：-33.35℃
- 密度（气态）：0.6（相对空气）
- 爆炸极限：16-25%
- 自燃点：651.11℃
- 嗅觉阈值：1.5 ppm
- TLV-TWA：25 ppm
- TLV-STEL：35 ppm
- IDLH：500 ppm

#### 1.2.2 合成氨工业（哈勃法）

**工艺原理**：
```
N₂ + 3H₂ ⇌ 2NH₃
条件：高压（30 MPa）、高温（450-550℃）、铁触媒
```

**工艺流程**：
```
天然气/煤制氢 → 变换 → 脱碳 → 精制 → 压缩(30MPa) 
→ 合成塔(450-550℃) → 冷却分离 → 液氨储罐
```

**产污节点**：
- 变换气：CO₂废气
- 脱碳液：废液
- 合成尾气：驰放气（含NH₃、H₂、CH₄）
- 冷却水：含氨废水

**主要风险**：
1. 高压系统泄漏
2. 氢气爆炸
3. 氨中毒
4. 触媒中毒（含氧、硫化合物）

### 1.3 涉苯系物工艺

#### 1.3.1 苯/甲苯/二甲苯储存和使用

**理化特性**：

| 物质 | 分子式 | 密度(g/cm³) | 水溶性 | 挥发性 | 闪点(℃) |
|-----|--------|------------|--------|--------|---------|
| 苯 | C₆H₆ | 0.88 | 微溶(1.8g/L) | 易挥发 | -11 |
| 甲苯 | C₇H₈ | 0.87 | 不溶 | 易挥发 | 4 |
| 二甲苯 | C₈H₁₀ | 0.86 | 不溶 | 易挥发 | 25-30 |

**浮顶罐排水系统风险**（"兰州4·11"案例）：

**事故概况**（2014年4月11日，兰州）：
- 事件：自来水苯含量超标
- 峰值：出厂水苯含量最高达200 µg/L（国标：10 µg/L）
- 影响：兰州市区停水，市民抢水
- 原因：兰州石化历史泄漏（1987年渣油罐爆炸、2002年管道开裂）导致地下含油污水渗入自流沟

**浮顶罐风险机理**：
```
浮顶罐 → 浮顶积水 → 排水管 → 地下水/土壤
                    ↓
                阀门密封失效
                    ↓
                苯类物质泄漏
```

**风险控制措施**：
1. 浮顶罐设置双道密封
2. 排水管设置油水分离器
3. 定期检测排水水质
4. 设置围堰、防渗设施
5. 建立地下水监测井

**苯的理化特性对应急处置的影响**：

| 特性 | 应急处置影响 |
|-----|-------------|
| 密度0.88<水 | 漂浮在水面上，形成液膜 |
| 微溶于水 | 水中溶解度低，主要在水面上挥发 |
| 易挥发 | 大气扩散快，需快速疏散 |
| BTEX特性 | 苯系物综合污染，需全面检测 |

**应急处置要点**：
- **水上泄漏**：使用围油栏、吸附材料、撇油器
- **大气扩散**：疏散下风向人员，喷雾稀释
- **土壤污染**：开挖、换土、土壤修复
- **地下水污染**：抽提处理、原位修复

#### 1.3.2 农药生产工艺（有机磷农药）

**典型产品**：乐果、敌敌畏、甲胺磷、对硫磷

**有机磷农药合成工艺**（以乐果为例）：
```
五硫化二磷 + 甲醇 → 甲基硫化物
          ↓
    甲基硫化物 + 一甲胺 → 乐果
```

**产污环节**：

| 工序 | 废气 | 废水 | 固废 |
|-----|------|------|------|
| 硫化反应 | H₂S、CH₃SH | 硫化废水 | 硫化渣 |
| 酯化反应 | 溶剂挥发 | 含磷废水 | 废催化剂 |
| 缩合反应 | 胺类废气 | 含胺废水 | 过滤残渣 |
| 精制过程 | 溶剂废气 | 洗涤废水 | 废活性炭 |
| 后处理 | 粉尘 | 冲洗废水 | 废包装 |

**典型事故类型**：

1. **中间体泄漏**
   - 五硫化二磷：遇水分解产生H₂S
   - 甲基硫化物：毒性大，易燃
   - 应急：隔离泄漏区，佩戴正压式空气呼吸器

2. **反应失控**
   - 原因：冷却失效、投料过快
   - 后果：温度失控→压力升高→爆炸
   - 预防：设置紧急冷却、泄压装置

3. **硫化氢中毒**
   - 来源：硫化反应、废水处理
   - 特点：嗅觉疲劳、快速致死
   - 预防：H₂S检测报警、强制通风

### 1.4 涉氰工艺

#### 1.4.1 氰化钠使用（黄金提炼/电镀）

**氰化提金工艺**：

**基本原理**：
```
4Au + 8NaCN + O₂ + 2H₂O → 4Na[Au(CN)₂] + 4NaOH
```

**工艺流程**：
```
金矿破碎磨细 → 氰化浸出(NaCN溶液,pH>10) → 固液分离 
→ 锌粉置换/炭吸附 → 金泥熔炼 → 成品金
         ↓
    贫液返回/废水处理
```

**关键工艺参数**：
- NaCN浓度：0.01-0.05%
- pH值：10-11（防止HCN逸散）
- 浸出时间：24-72小时
- 温度：常温

**氰化物废水的氧化处理（碱性氯化法）**：

**反应原理**：
```
第一阶段（不完全氧化）：
CN⁻ + OCl⁻ + H₂O → CNO⁻ + Cl⁻ + H₂O

第二阶段（完全氧化）：
CNO⁻ + 3Cl₂ + 2OH⁻ → 2CO₂↑ + N₂↑ + 6Cl⁻ + H₂O
```

**工艺条件**：
- 第一阶段：pH 10-11，反应时间10-15 min
- 第二阶段：pH 8-9，反应时间10-30 min
- 氧化剂：次氯酸钠、液氯、漂白粉

**关键风险：pH<9时剧毒HCN气体逸散**

**HCN的特性**：
- 剧毒，致死剂量：50-100 mg
- 沸点：25.7℃
- 爆炸极限：5.6-40%
- MAC：0.3 mg/m³
- HCN在pH下的分布：
  - pH=7：HCN占99%
  - pH=9：HCN占约30%
  - pH=11：HCN占<1%

**风险控制措施**：
1. **pH控制**：
   - 浸出过程pH>10
   - 废水处理pH 8-11
   - 设置pH在线监测报警

2. **HCN监测**：
   - 作业区设置HCN检测报警仪
   - 定点监测+移动监测

3. **应急处理**：
   - 泄漏时立即加碱调pH>10
   - 使用次氯酸钠氧化
   - 禁止酸性物质接触氰化物

4. **个人防护**：
   - 正压式空气呼吸器
   - 防氰化物滤毒罐
   - 防护服、护目镜

## 专题2：有色金属冶金工艺流程——娄底锑特色

### 2.1 锑（Sb）冶炼工艺

#### 2.1.1 火法炼锑（挥发焙烧+还原熔炼）

**工艺原理**：

**第一步：挥发焙烧**
```
2Sb₂S₃ + 9O₂ → 2Sb₂O₃ + 6SO₂↑
Sb₂S₃ + 5O₂ → Sb₂O₄ + 3SO₂↑
```

**第二步：还原熔炼**
```
Sb₂O₃ + 3C → 2Sb + 3CO↑
Sb₂O₄ + 4C → 2Sb + 4CO↑
```

**工艺流程**：
```
锑矿(辉锑矿Sb₂S₃) → 破碎筛分 → 挥发焙烧(赫氏炉/直井炉/回转窑) 
→ 氧化锑(Sb₂O₃) → 还原熔炼(反射炉) → 粗锑(96-97%Sb)
         ↓                              ↓
    SO₂烟气 → 制酸/脱硫           精炼除杂 → 精锑
                                        ↓
                                    砷碱渣（危险废物）
```

**主要设备**：
- 焙烧设备：赫氏炉、直井炉、回转窑
- 熔炼设备：反射炉、鼓风炉
- 精炼设备：反射炉、短鼓回转炉

**产污节点详细分析**：

| 污染类型 | 产污节点 | 主要成分 | 处置方式 |
|---------|---------|---------|---------|
| 含锑烟尘 | 焙烧、熔炼烟气 | Sb、As、Pb、Zn | 布袋除尘器回收 |
| SO₂烟气 | 焙烧过程 | SO₂ | 制酸或脱硫 |
| 砷碱渣 | 精炼除砷 | Na₂CO₃(53%)、As(34%)、Sb(11%) | 无害化处理（冷水江16万吨累计） |
| 冶炼废水 | 湿法除尘、冷却 | Sb、As、Pb、Cd | 中和沉淀、膜处理 |

**砷碱渣——冷水江最大环境隐患**：

**来源**：锑火法精炼除砷过程
- 粗锑加热至800-850℃
- 加入纯碱(Na₂CO₃)或烧碱(NaOH)
- 吹入空气氧化除砷
- 产出砷碱渣浮于锑液表面

**成分**：
- 纯碱：53%
- 砷及其化合物：34%
- 锑及其化合物：11%
- 三氧化二砷（As₂O₃，俗称"砒霜"）：易溶于水、剧毒

**危害**：
- As₂O₃易溶于水，污染地下水、土壤
- 剧毒，经口致死量100-200 mg
- 冷水江累计堆存量约16万吨

**无害化处理技术**（冷水江锑都环保公司）：
- 工艺：中性中温连续盐析工艺
- 原理：破碎磨矿 → 低温浸出 → 连续盐析 → 砷碱高效分离
- 产物：
  - 碳酸氢钠（可销售）
  - 单质砷（可外销）
  - 还原渣（可制耐火材料）

#### 2.1.2 湿法炼锑

**工艺原理**：
```
碱性浸出：Sb₂S₃ + 6NaOH → 2Na₃SbS₃ + 3H₂O
电积：Na₃SbS₃ → Sb + 3Na₂S
```

**工艺流程**：
```
锑精矿 → 碱性浸出(NaOH/Na₂S) → 浸出液净化 
→ 电积 → 阴极锑 → 熔铸
    ↓
浸出渣（含铅、锌、硫）
```

**产污**：
- 浸出渣：含铅、锌、硫等
- 含锑废水：需中和沉淀处理
- 副产物Na₂S：可回用或销售

**优缺点对比**：

| 对比项 | 火法炼锑 | 湿法炼锑 |
|-------|---------|---------|
| 占比 | 95%以上 | <5% |
| 优点 | 工艺成熟、处理量大 | 金属回收率高、可综合利用硫 |
| 缺点 | SO₂污染、砷碱渣产生 | 碱耗大、电耗高、成本高 |
| 适用 | 高品位矿、大规模生产 | 复杂矿、低品位矿 |

### 2.2 锑矿尾矿库特殊风险

**锑的伴生元素**：
- **砷（As）**：高砷锑矿含砷可达1-5%
- 铅（Pb）
- 锌（Zn）
- 金（Au）：伴生金矿
- 钨（W）：部分矿区伴生

**尾矿中锑的存在形态**：
- Sb₂S₃（辉锑矿）
- Sb₂O₃（氧化锑）
- Sb(V)氧化物、锑酸盐
- 吸附态、络合态

**锑在环境中的迁移特性**：
- 氧化条件下：Sb(III) → Sb(V)，溶解度增加
- 还原条件下：Sb(V) → Sb(III)，易沉淀
- pH影响：酸性条件迁移性强
- 有机质影响：络合作用增加迁移性

**尾矿库渗滤液特征污染指标**：
- 锑（Sb）：0.5-50 mg/L
- 砷（As）：0.1-10 mg/L
- 铅（Pb）、锌（Zn）、镉（Cd）
- 硫酸盐（SO₄²⁻）
- pH：3-9（酸化尾矿库pH可降至3以下）

### 2.3 铅锌冶炼工艺

#### 2.3.1 铅冶炼

**工艺方法**：
1. **烧结-鼓风炉熔炼**（传统工艺）
2. **ISA法**（氧气底吹熔炼）
3. **基夫赛特法**（闪速熔炼）
4. **QSL法**（氧气底吹连续炼铅）

**烧结-鼓风炉工艺流程**：
```
铅精矿 → 配料 → 烧结焙烧 → 破碎 → 鼓风炉熔炼 
→ 粗铅 → 精炼 → 精铅
    ↓           ↓        ↓
 烧结烟气     炉渣     烟尘
 (SO₂)      (含Zn)    (回收)
```

**产污**：
- **含铅烟气**：烧结、熔炼过程，主要含Pb、Zn、Cd
- **冶炼废渣**：鼓风炉渣（含Zn、Pb）、烟化炉渣
- **含铅废水**：冷却、冲洗、烟气净化废水

#### 2.3.2 锌冶炼

**工艺方法**：
1. **湿法炼锌**（主流，占80%以上）
2. **火法炼锌**（竖罐蒸馏、电热法）

**湿法炼锌工艺流程**：
```
锌精矿 → 焙烧 → 浸出(稀硫酸) → 净化 → 电积 
→ 阴极锌 → 熔铸 → 锌锭
    ↓       ↓        ↓
 焙烧烟气 浸出渣   废电解液
 (SO₂)  (含Pb、Cd、As)
```

**浸出渣处理**：
- 回转窑挥发：回收Pb、Zn
- 威尔兹法：生产氧化锌
- 热酸浸出：回收有价金属

**产污**：
- **浸出渣**：含Pb、Cd、As、Cu等重金属
- **酸雾**：电积过程产生
- **废水**：酸性废水、重金属废水

## 专题3：环境风险评价技术

### 3.1 毒性终点浓度体系

#### 3.1.1 AEGL（Acute Exposure Guideline Levels）

**制定机构**：美国EPA/NRC（国家研究委员会）

**特点**：
- 目前最权威的急性暴露标准
- 3个级别 × 5个暴露时段
- 基于科学的毒理学数据

**AEGL级别定义**：

| 级别 | 定义 | 终点效应 |
|-----|------|---------|
| AEGL-1 | 短暂不适、可逆效应阈值 | 轻度刺激、恶心、头痛 |
| AEGL-2 | 不可逆或严重效应阈值 | 长期健康损害、功能丧失 |
| AEGL-3 | 致死效应阈值 | LC₀₁或LC₀₅（1%或5%死亡率） |

**5个暴露时段**：
- 10 min
- 30 min
- 60 min
- 4 hr
- 8 hr

**编制方法学**：
```
动物实验数据 → 统计分析(LC₅₀、BMCL等) → 人体等效浓度 
→ 不确定性系数调整 → AEGL值
```

**不确定性系数**：
- 种属差异：10倍
- 个体差异：10倍
- 数据质量：1-10倍
- 总不确定性系数：1-100倍

#### 3.1.2 ERPG（Emergency Response Planning Guidelines）

**制定机构**：AIHA（美国工业卫生协会）

**特点**：
- 3个级别 × 1小时暴露
- 专为应急响应设计
- 基于专家判断

**ERPG级别定义**：

| 级别 | 定义 | 暴露后果 |
|-----|------|---------|
| ERPG-1 | 短暂不适阈值 | 感觉到明显异味、刺激，但不影响健康 |
| ERPG-2 | 不可逆损伤阈值 | 可能导致不可逆健康损害，影响逃生 |
| ERPG-3 | 生命威胁阈值 | 暴露1小时可能危及生命 |

#### 3.1.3 TEEL（Temporary Emergency Exposure Limits）

**制定机构**：美国DOE（能源部）

**用途**：当AEGL/ERPG不存在时的替代值

**制定方法**：
- 基于毒理学结构估算
- 利用现有毒性数据外推
- 保守估计，优先使用AEGL/ERPG

#### 3.1.4 AEGL vs ERPG对比

| 对比项 | AEGL | ERPG |
|-------|------|------|
| 制定机构 | EPA/NRC | AIHA |
| 暴露时段 | 5个(10min-8hr) | 1个(1hr) |
| 科学基础 | 毒理学实验+统计分析 | 专家判断+文献评估 |
| 适用场景 | 全面风险评估 | 应急响应规划 |
| 权威性 | 更高 | 较高 |
| 覆盖物质 | 约300种 | 约150种 |

### 3.3 个人风险与社会风险

#### 3.3.1 个人风险等值线图的概念

**定义**：
个人风险是指因危险化学品重大危险源各种潜在的火灾、爆炸、有毒气体泄漏事故造成区域内某一固定位置人员的个体死亡概率，即单位时间内（通常为年）的个体死亡率。

**表示方法**：个人风险等值线图

**特点**：
- 以危险源为中心
- 不同风险等级用不同等值线表示
- 如：10⁻⁵、10⁻⁶、10⁻⁷等值线
- 考虑所有可能事故场景及其概率

**计算方法**：
```
IR = Σᵢ Pᵢ × Lᵢ
其中：
IR - 个人风险（年）
Pᵢ - 第i种事故场景的发生概率
Lᵢ - 第i种事故场景导致的个人死亡概率
```

#### 3.3.2 可接受风险标准（中国）

**文件依据**：《危险化学品生产、储存装置个人可接受风险标准和社会可接受风险标准(试行)》（安监总公告2014年第13号）

**中国个人可接受风险标准值**：

| 防护目标类型 | 新建装置（每年） | 在役装置（每年） |
|-------------|----------------|----------------|
| **低密度人员场所**（人数<30人） | ≤1×10⁻⁵ | ≤3×10⁻⁵ |

| **公众聚集类高密度场所**（30人≤人数<100人）<br>办公场所、商场、饭店、娱乐场所等 | ≤3×10⁻⁶ | ≤1×10⁻⁵ |
| **高敏感场所**<br>学校、医院、幼儿园、养老院、监狱等 | ≤3×10⁻⁷ | ≤3×10⁻⁶ |
| **重要目标**<br>军事禁区、军事管理区、文物保护单位等 | ≤3×10⁻⁷ | ≤3×10⁻⁶ |

#### 3.3.3 社会风险F-N曲线

**定义**：
社会风险是指能够引起大于等于N人死亡的事故累积频率(F)，即单位时间内（通常为年）的死亡人数。

**表示方法**：F-N曲线（累积频率-死亡人数曲线）

**F-N曲线特点**：
- 横轴：死亡人数N（对数坐标）
- 纵轴：累积频率F（对数坐标）
- 双对数坐标系
- 曲线越靠右下，风险越低

**中国可接受社会风险标准**：

```
F-N曲线划分三个区域：

不可接受区（F > F_max）
    ↓
尽可能降低区（ALARP区，F_min < F < F_max）
    ↓
可接受区（F < F_min）

其中：
F_max = 10⁻³/年（N=1时）
F_min = 10⁻⁵/年（N=1时）
曲线斜率：-1（风险中性）或-2（风险厌恶）
```

**ALARP原则**（As Low As Reasonably Practicable）：
- 风险尽可能低
- 考虑技术可行性
- 考虑经济合理性
- 成本效益分析

## 专题4：事故后果模拟

### 4.1 泄漏场景定量分析

#### 4.1.1 储罐完全破裂 vs 小孔泄漏

**源强差异**：

| 泄漏类型 | 泄漏速率 | 持续时间 | 扩散范围 | 典型场景 |
|---------|---------|---------|---------|---------|
| 完全破裂 | 极高（瞬时） | 短（分钟级） | 大 | 地震、撞击、爆炸破坏 |
| 小孔泄漏 | 较低（持续） | 长（小时级） | 中 | 腐蚀穿孔、法兰泄漏 |

**小孔泄漏速率计算**（液体）：
```
Q = Cd × A × √(2ρΔP)

其中：
Q - 泄漏速率，kg/s
Cd - 泄漏系数（0.6-0.9，取决于孔形状）
A - 泄漏面积，m²
ρ - 液体密度，kg/m³
ΔP - 内外压差，Pa
```

**气体泄漏速率计算**（临界流）：
```
Q = Cd × A × P × √[γM/(RgT) × (2/(γ+1))^((γ+1)/(γ-1))]

其中：
P - 容器压力，Pa
γ - 绝热指数
M - 摩尔质量，kg/mol
Rg - 气体常数
T - 温度，K
```

#### 4.1.2 连续泄漏 vs 瞬时泄漏

**扩散特性差异**：

| 类型 | 特点 | 扩散模式 | 适用模型 |
|-----|------|---------|---------|
| 连续泄漏 | 持续释放、源强稳定 | 烟羽扩散 | 高斯烟羽模型 |
| 瞬时泄漏 | 短时释放、源强高 | 烟团扩散 | 高斯烟团模型 |
| 半瞬时泄漏 | 介于两者之间 | 混合模式 | 分段计算 |

#### 4.1.3 液池蒸发速率模型

**蒸发速率计算**：
```
Q = K × A × (P_s - P_a) × M / (R × T)

其中：
Q - 蒸发速率，kg/s
K - 传质系数，m/s
A - 液池面积，m²
P_s - 饱和蒸汽压，Pa
P_a - 环境中物质分压，Pa
M - 摩尔质量，kg/mol
R - 气体常数
T - 温度，K
```

**传质系数K的影响因素**：
- 风速
- 大气稳定度
- 液池温度
- 物质性质

### 4.2 火灾后果

#### 4.2.1 喷射火

**热辐射通量计算**：
```
q = τ × E × F

其中：
q - 目标接收的热辐射通量，kW/m²
τ - 大气透射率
E - 火焰表面辐射能量，kW/m²
F - 视角系数
```

**视角系数F的计算**：
- 取决于火焰形状、尺寸
- 目标与火焰的相对位置
- 可查图或公式计算

**热辐射伤害准则**：

| 热辐射通量(kW/m²) | 暴露时间(s) | 伤害程度 |
|------------------|------------|---------|
| < 1.6 | 长时间 | 可接受，无明显不适 |
| 1.6-4.0 | 30 | 轻度烧伤 |
| 4.0-10.0 | 30 | 二级烧伤 |
| > 10.0 | 30 | 重度烧伤，可能死亡 |
| 25.0 | 长时间 | 木材引燃 |

#### 4.2.2 池火

**火焰高度（Thomas公式）**：
```
H/L = 42 × [m_f/(ρ_a√(gL))]^0.61

其中：
H - 火焰高度，m
L - 液池直径，m
m_f - 燃烧速率，kg/(m²·s)
ρ_a - 空气密度，kg/m³
g - 重力加速度
```

**表面热辐射能量**：
- 碳氢化合物：100-200 kW/m²
- 液化气：150-300 kW/m²

#### 4.2.3 火球（BLEVE）

**火球尺寸**：
```
D = 5.8 × M^0.333
t = 0.45 × M^0.333

其中：
D - 火球直径，m
t - 火球持续时间，s
M - 参与燃烧的物质质量，kg
```

**热辐射计算**：
```
q = τ × E × F × cos(θ)

其中：
E - 火球表面辐射能量（通常200-350 kW/m²）
θ - 视线与目标表面法线的夹角
```

### 4.3 爆炸后果

#### 4.3.1 蒸气云爆炸（VCE）

**TNT当量法**：
```
W_TNT = η × W_f × Q_f / Q_TNT

其中：
W_TNT - TNT当量，kg
η - TNT当量系数（0.02-0.149，常用0.04）
W_f - 参与爆炸的燃料质量，kg
Q_f - 燃料燃烧热，kJ/kg
Q_TNT - TNT爆热（4120-4690 kJ/kg，取4500）
```

**超压-距离关系**：
```
ΔP_s/P_0 = f(Z)

其中：
ΔP_s - 冲击波峰值超压，Pa
P_0 - 环境压力（101325 Pa）
Z - 无量纲距离，Z = R/(W_TNT)^(1/3)
R - 距离，m
```

**超压伤害准则**：

| 超压(MPa) | 损伤程度 |
|----------|---------|
| 0.02-0.03 | 轻微挫伤 |
| 0.03-0.05 | 中等损伤：听觉器官损伤、内脏轻度出血、骨折等 |
| 0.05-0.10 | 严重：内脏严重损伤，可引起死亡 |
| > 0.10 | 严重：可能大部分死亡 |

**死亡/重伤/轻伤半径计算准则**：
- **死亡半径**：肺出血死亡概率50%，ΔP ≈ 0.1 MPa
- **重伤半径**：耳膜破裂概率50%，ΔP = 0.044 MPa
- **轻伤半径**：耳膜破裂概率1%，ΔP = 0.017 MPa

#### 4.3.2 BLEVE

**破坏形式**：
- 主要：热辐射
- 次要：冲击波超压
- 再次：碎片抛射

**火球尺寸**：见4.2.3节

#### 4.3.3 物理爆炸（压力容器破裂）

**能量释放计算**：
```
E = P × V × [ln(P/P_a) + (γ-1)/γ × (1 - (P_a/P)^((γ-1)/γ))]

其中：
E - 爆炸能量，J
P - 容器压力，Pa
V - 容器体积，m³
P_a - 环境压力，Pa
γ - 绝热指数
```

### 4.4 有毒物质扩散（与Phase 4C衔接）

#### 4.4.1 致死区/受伤区/反应区的划分

**基于AEGL的分区方法**：

| 区域 | 浓度标准 | 对应AEGL | 后果 |
|-----|---------|---------|------|
| 致死区 | C > AEGL-3 | AEGL-3/1h | 可能导致死亡 |
| 重伤区 | AEGL-3 > C > AEGL-2 | AEGL-2/1h | 不可逆健康损害 |
| 轻伤区 | AEGL-2 > C > AEGL-1 | AEGL-1/1h | 可逆性不适 |
| 反应区 | AEGL-1 > C > ERPG-1 | ERPG-1 | 轻微不适、异味 |
| 安全区 | C < ERPG-1 | - | 无明显影响 |

**应急疏散距离确定**：
1. 根据泄漏量、物质性质计算扩散范围
2. 以AEGL-3确定疏散边界
3. 以AEGL-2确定警戒边界
4. 考虑风向、地形、人口分布调整

#### 4.4.2 扩散模型选择

| 泄漏类型 | 大气稳定度 | 模型选择 |
|---------|-----------|---------|
| 连续泄漏 | 稳定/中性 | 高斯烟羽模型 |
| 瞬时泄漏 | 各种 | 高斯烟团模型 |
| 重质气体 | 各种 | SLAB、DEGADIS、ALOHA |
| 复杂地形 | 各种 | CFD模型（FLUENT、PHAST） |
