# 国家危险废物名录（2025年修订版）

## 一、修订背景

### 1.1 修订历程

| 版本 | 发布时间 | 主要内容 |
|------|---------|---------|
| 首版 | 1998年 | 47类危险废物 |
| 2008年版 | 2008年6月6日 | 49类498种危险废物 |
| 2016年版 | 2016年6月14日 | 46大类479种，引入豁免清单 |
| 2021年版 | 2020年11月25日 | 46大类467种，新增10种豁免 |
| **2025年版** | **2025年发布** | **调整名录结构，新增豁免情形** |

### 1.2 修订依据

- 《中华人民共和国固体废物污染环境防治法》（2020年修订）
- 《危险废物鉴别标准》（GB 5085系列）
- 《危险废物鉴别技术规范》（HJ 298-2019）

### 1.3 修订原则

1. **科学性**：基于危险特性鉴定结果调整名录
2. **合理性**：考虑环境风险与经济成本平衡
3. **可操作性**：便于企业识别和管理
4. **动态调整**：建立常态化评估机制

## 二、危险废物定义与特性

### 2.1 定义

根据《固体废物污染环境防治法》第一百二十四条规定：

> 危险废物，是指列入国家危险废物名录或者根据国家规定的危险废物鉴别标准和鉴别方法认定的，具有危险特性的固体废物。

### 2.2 危险特性

| 特性 | 简称 | 判定标准 |
|------|------|---------|
| 腐蚀性 | C | pH ≥ 12.5 或 ≤ 2.0；或在 55.7℃ 下腐蚀钢材速率 ≥ 6.35 mm/a |
| 急性毒性 | H | 经口 LD₅₀ ≤ 200 mg/kg；经皮 LD₅₀ ≤ 1000 mg/kg；吸入 LC₅₀ ≤ 10 mg/L |
| 浸出毒性 | T | 按规定方法浸出，浸出液中任何一种危害成分浓度超过限值 |
| 反应性 | R | 具爆炸性、易燃性、与水或酸反应产生有毒气体等 |
| 易燃性 | I | 闪点 < 60℃ 的液态废弃物 |
| 感染性 | In | 含致病微生物，能传播疾病 |
| 毒性物质 | T | 含有列入名录的有毒物质，且含量超过规定限值 |

## 三、危险废物名录分类体系

### 3.1 名录结构

2025年版名录按行业来源与废物类型相结合方式分类：

- **工业行业**：46大类行业来源
- **环境治理行业**：废水处理、废气治理、固废处理等
- **社会源**：医疗废物、实验室废物、家庭源危险废物

## 四、危险废物豁免管理清单

### 4.1 豁免原则

- 在一定条件下，部分危险废物可以按照一般工业固体废物管理
- 豁免不改变废物的危险特性，仅豁免其特定环节的管理要求
- 豁免清单根据风险变化动态调整

## 五、危险废物管理要点

### 5.1 危险废物识别

- 查阅《国家危险废物名录》
- 委托有资质机构进行危险特性鉴别
- 与环评文件中的废物类别对照

### 5.2 危险废物贮存

#### 贮存设施要求

- 按 GB 18597-2023 危险废物贮存污染控制标准建设
- 贮存场所防渗、防漏、防雨
- 分类分区贮存，禁止混存
- 设置危险废物标识

#### 贮存时限

- 一年以内（特殊情况可申请延长至2年）
- 贮存超过时限的，应报生态环境主管部门批准

### 5.3 危险废物转移

#### 转移联单制度

- 通过国家危险废物信息管理系统填报电子联单
- 转移前报移出地生态环境主管部门备案
- 跨省转移需经移入地省级生态环境主管部门同意

#### 转移包装要求

- 包装容器符合危险货物运输包装要求
- 容器外部设置危险废物标识
- 易反应废物分开包装

### 5.4 危险废物处置

#### 处置方式

- 综合利用（资源化）
- 焚烧处置
- 安全填埋
- 物化处理
- 生物处理

#### 处置单位资质

- 必须持有《危险废物经营许可证》
- 严格按许可证规定的类别、规模、方式经营
- 定期向生态环境主管部门报告

## 六、违法处罚依据

### 6.1 《固体废物污染环境防治法》第八章 法律责任

| 违法行为 | 法律依据 | 罚款金额 |
|---------|---------|---------|
| 不按规定设置危险废物识别标志 | 第一百一十二条 | 10-100 万元 |
| 不按规定申报登记危险废物 | 第一百一十二条 | 10-100 万元 |
| 擅自倾倒、堆放危险废物 | 第一百一十二条 | 处所需处置费用 3-5 倍罚款，20-200 万元 |
| 将危险废物提供或委托给无经营许可证单位 | 第一百一十二条 | 处所需处置费用 3-5 倍罚款，20-200 万元 |
| 未按规定填写转移联单 | 第一百一十二条 | 10-100 万元 |
| 未制定危险废物意外事故防范措施和应急预案 | 第一百一十二条 | 10-100 万元 |
| 危险废物经营单位不按规定经营 | 第一百一十四条 | 50-300 万元，吊销经营许可证 |

### 6.2 刑事责任

#### 《刑法》第三百三十八条 污染环境罪

非法排放、倾倒、处置危险废物三吨以上的，处三年以下有期徒刑或者拘役，并处或者单处罚金；后果特别严重的，处三年以上七年以下有期徒刑，并处罚金。

#### 《刑法》第三百三十九条 非法处置进口的固体废物罪

违反国家规定，将境外的固体废物进境倾倒、堆放、处置的，处五年以下有期徒刑或者拘役，并处罚金。

## 八、对企业环保合规工作的启示

1. **准确识别危险废物**：企业应准确识别本单位产生的危险废物类别与代码
2. **建立管理台账**：详细记录危险废物的产生、贮存、转移、利用、处置情况
3. **依法申报登记**：通过国家危险废物信息管理系统申报登记
4. **规范贮存设施**：建设符合标准的危险废物贮存场所
5. **落实转移联单**：严格执行危险废物转移电子联单制度
6. **委托合规单位**：仅委托持有经营许可证的单位处置
7. **制定应急预案**：建立危险废物意外事故防范措施和应急预案
8. **定期培训**：对从业人员进行危险废物管理培训
