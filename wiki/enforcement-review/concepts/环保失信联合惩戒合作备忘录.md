# 关于对环境保护领域失信生产经营单位及其有关人员开展联合惩戒的合作备忘录

## 一、总则

### 1.1 制定目的

- 贯彻落实《中华人民共和国环境保护法》
- 落实《国务院关于建立完善守信联合激励和失信联合惩戒制度加快推进社会诚信建设的指导意见》
- 推进环境保护领域社会信用体系建设
- 强化对环境保护领域失信行为的惩戒

### 1.2 制定依据

- 《中华人民共和国环境保护法》
- 《中华人民共和国大气污染防治法》
- 《中华人民共和国水污染防治法》
- 《中华人民共和国土壤污染防治法》
- 《中华人民共和国固体废物污染环境防治法》
- 《社会信用体系建设规划纲要（2014-2020年）》

### 1.3 适用范围

- 适用于环境保护领域存在严重失信行为的生产经营单位及其有关人员
- 适用于签署本备忘录的相关部门实施联合惩戒

## 二、联合惩戒对象

### 2.1 失信主体

#### 严重失信生产经营单位

符合下列情形之一的生产经营单位：

1. 因严重环境违法行为被吊销排污许可证的
2. 因环境违法行为被责令停产整顿的
3. 因环境犯罪被追究刑事责任的
4. 发生重大及以上突发环境事件的
5. 拒不执行行政处罚决定的
6. 通过暗管、渗井、渗坑、灌注或者篡改、伪造监测数据，或者不按照规定运行防治污染设施等逃避监管的方式违法排放污染物的
7. 非法排放、倾倒、处置危险废物三吨以上的
8. 违反环境影响评价制度，未批先建且拒不停止建设的
9. 违反"三同时"制度，环境保护设施未建成、未经验收或者验收不合格，主体工程正式投入生产或者使用的
10. 在环境信用评价中被评为"环保不良企业"的

#### 严重失信人员

1. 失信生产经营单位的法定代表人
2. 失信生产经营单位的主要负责人
3. 失信生产经营单位的直接负责的主管人员
4. 失信生产经营单位的其他直接责任人员
5. 环评工程师、环境监测人员等专业人员有严重违法行为的

### 2.2 失信行为认定

#### 认定主体

- 生态环境部门
- 司法机关
- 其他相关监管部门

#### 认定程序

1. 调查取证
2. 听证（视情况）
3. 决定
4. 公告
5. 移送相关部门

#### 认定证据

- 行政处罚决定书
- 司法判决书
- 行政强制决定书
- 监测报告
- 现场检查笔录

## 三、联合惩戒措施

### 3.1 限制或者禁止生产经营活动

#### 限制许可

1. **限制取得或者吊销排污许可证**
2. **限制取得环评批复**
3. **限制取得经营许可证**
4. **限制取得安全生产许可证**
5. **限制取得食品生产许可证**

#### 限制市场准入

1. **限制参与政府采购**
2. **限制参与政府招投标**
3. **限制参与特许经营**
4. **限制参与 PPP 项目**
5. **限制参与政府购买服务**

#### 限制融资

1. **限制银行贷款**
2. **限制发行债券**
3. **限制上市融资**
4. **限制增发新股**
5. **限制融资担保**

#### 限制生产经营

1. **限制扩大生产规模**
2. **限制新建项目**
3. **限制技术改造**
4. **限制设备进口**
5. **暂停享受税收优惠**

### 3.2 加大监管力度

#### 加强日常监管

1. **加大现场检查频次**：从每年 2 次增加到每年 6 次
2. **加大监测频次**：从每季度 1 次增加到每月 1 次
3. **重点监管**：纳入重点监管名单

#### 加强专项检查

1. **开展专项执法检查**
2. **开展专项监测**
3. **开展专项整治**

### 3.3 限制或者禁止享受优惠政策

#### 限制财政补贴

1. **暂停环保专项资金申请资格**
2. **暂停节能专项资金申请资格**
3. **暂停清洁生产专项资金申请资格**
4. **暂停科技创新专项资金申请资格**

#### 限制税收优惠

1. **暂停享受环境保护税优惠**
2. **暂停享受资源综合利用税收优惠**
3. **暂停享受节能税收优惠**
4. **暂停享受增值税即征即退优惠**

#### 限制其他优惠

1. **暂停享受用电优惠**
2. **暂停享受用气优惠**
3. **暂停享受用水优惠**
4. **暂停享受土地使用优惠**

### 3.4 限制或者禁止评优评先

#### 限制荣誉称号

1. **限制取得环境保护荣誉称号**
2. **限制取得清洁生产企业称号**
3. **限制取得节能减排先进企业称号**
4. **限制取得质量奖**
5. **限制取得名牌产品称号**

#### 限制评奖评优

1. **限制申报科技奖励**
2. **限制申报科技进步奖**
3. **限制申报优秀企业**
4. **限制申报先进工作者**
5. **限制申报劳动模范**

### 3.5 限制或者禁止担任特定职务

#### 限制担任企业职务

1. **限制担任企业法定代表人**
2. **限制担任企业董事**
3. **限制担任企业监事**
4. **限制担任企业高级管理人员**

#### 限制担任社会职务

1. **限制担任人大代表**
2. **限制担任政协委员**
3. **限制担任行业协会职务**
4. **限制担任社会组织职务**

### 3.6 限制或者禁止出境

- 对严重失信人员，必要时可以限制出境

### 3.7 加大刑事打击力度

- 公安机关依法立案侦查
- 检察机关依法提起公诉
- 人民法院依法从重处罚

## 四、联合惩戒实施

### 4.1 惩戒措施落实主体

#### 实施部门

| 惩戒措施 | 实施部门 |
|---------|---------|
| 限制取得或者吊销排污许可证 | 生态环境部门 |
| 限制取得环评批复 | 生态环境部门 |
| 限制取得经营许可证 | 行业主管部门 |
| 限制取得安全生产许可证 | 应急管理部门 |
| 限制取得食品生产许可证 | 市场监管部门 |
| 限制参与政府采购 | 财政部门 |
| 限制参与政府招投标 | 招投标监督部门 |
| 限制参与特许经营 | 财政部门、行业主管部门 |
| 限制银行贷款 | 银保监部门、人民银行 |
| 限制发行债券 | 证监部门、人民银行、发改部门 |
| 限制上市融资 | 证监部门 |
| 暂停享受环保专项资金 | 财政部门、生态环境部门 |
| 暂停享受税收优惠 | 税务部门 |
| 限制取得荣誉称号 | 相关部门 |
| 限制担任企业职务 | 市场监管部门 |
| 限制担任人大代表、政协委员 | 人大、政协 |
| 限制出境 | 公安机关 |
| 加大刑事打击力度 | 公安、检察、法院 |

### 4.2 惩戒信息共享

#### 信息共享平台

- 全国信用信息共享平台
- 国家企业信用信息公示系统
- 中国执行信息公开网
- 中国裁判文书网

#### 信息共享内容

1. 失信主体基本信息
2. 失信行为认定信息
3. 惩戒措施信息
4. 惩戒措施落实情况

### 4.3 惩戒期限

#### 一般惩戒期限

- 一般失信行为：**1-3 年**
- 严重失信行为：**3-5 年**
- 特别严重失信行为：**5 年以上**

#### 惩戒解除条件

1. 整改完成并经验收合格
2. 赔偿完毕
3. 处罚执行完毕
4. 惩戒期限届满
5. 经原认定部门核实，失信行为已纠正

### 4.4 惩戒措施解除程序

1. 失信主体提出申请
2. 原认定部门核实
3. 公示解除信息
4. 通知相关部门解除惩戒

## 五、信用修复

### 5.1 信用修复条件

#### 申请条件

1. 失信行为已纠正
2. 不良影响已消除
3. 惩戒期限已满 6 个月
4. 期间无新的失信行为
5. 主动履行法定义务

#### 不予修复的情形

1. 因环境犯罪被追究刑事责任的
2. 发生重大及以上突发环境事件的
3. 多次发生环境违法行为的
4. 拒不履行法定义务的
5. 严重失信行为未纠正的

### 5.2 信用修复程序

#### 申请

- 失信主体向原认定部门提出信用修复申请
- 申请材料：申请书、整改报告、第三方评估报告等

#### 受理

- 原认定部门应当在 **15 个工作日内** 决定是否受理

#### 审查

- 原认定部门应当在 **30 个工作日内** 完成审查
- 必要时可组织专家评审

#### 决定

- 同意修复的，发布修复公告
- 不同意修复的，书面告知理由

#### 公示

- 修复结果公示 **15 个工作日**
- 公示期满无异议的，解除惩戒措施

## 六、信息公开与监督

### 6.1 信息公开

#### 主动公开

- 失信主体名单
- 失信行为
- 惩戒措施
- 惩戒期限
- 解除信息

#### 公开渠道

- 全国信用信息共享平台
- 国家企业信用信息公示系统
- 中国环境报
- 当地主流媒体
- 生态环境部门网站

### 6.2 公众监督

#### 公众查询

- 公众可通过全国信用信息共享平台查询失信主体名单
- 可查询失信行为、惩戒措施、惩戒期限等信息

#### 公众举报

- 公众可举报失信主体继续违法行为
- 可举报失信主体规避惩戒行为

## 七、典型案例

### 7.1 江苏某化工企业联合惩戒案

- **失信行为**：通过暗管偷排废水
- **联合惩戒**：吊销排污许可证、停产整顿、限制贷款、限制上市融资
- **效果**：企业承担 1.6 亿元环境修复费用

### 7.2 山东某钢铁企业联合惩戒案

- **失信行为**：篡改监测数据
- **联合惩戒**：吊销排污许可证、停产整顿、限制政府采购、限制政府招投标
- **效果**：企业承担 8000 万元环境修复费用

### 7.3 河北某制药企业联合惩戒案

- **失信行为**：未批先建、未验先投
- **联合惩戒**：限制环评审批、限制贷款、限制财政补贴
- **效果**：企业承担 5000 万元整改费用

## 九、对企业环保合规工作的启示

1. **重视信用建设**：企业应重视环境信用建设，避免失信行为
2. **及时整改**：发现失信行为及时整改，争取减轻惩戒
3. **履行义务**：主动履行法定义务，避免加重惩戒
4. **加强管理**：加强内部环境管理，避免环境违法行为
5. **完善档案**：完善环境管理档案，作为信用修复的证据
6. **申请修复**：符合条件的，及时申请信用修复
7. **关注变化**：关注相关法律法规的变化，及时调整经营策略
8. **防范风险**：投保环境污染责任保险，转移风险
