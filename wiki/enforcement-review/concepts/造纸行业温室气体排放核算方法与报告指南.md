# 造纸行业温室气体排放核算方法与报告指南

**文件编号**：GB/T 32151.26-2024
**发布单位**：国家市场监督管理总局、国家标准化管理委员会
**实施日期**：2024年10月1日
**适用范围**：造纸和纸制品生产企业温室气体排放核算与报告

---

## 一、适用范围

本指南适用于造纸和纸制品生产企业的温室气体排放核算与报告工作。

### 1.1 适用主体

- 制浆企业（木浆、竹浆、蔗渣浆、废纸浆、草浆等）
- 造纸企业（文化用纸、包装用纸、生活用纸、特种纸等）
- 制浆造纸联合企业
- 纸制品制造企业（纸箱、纸盒、纸管等，部分适用）

### 1.2 不适用范围

- 纯木材采伐企业
- 纯废纸回收企业
- 纸浆贸易企业

---

## 二、核算边界

### 2.1 组织边界

造纸企业应核算其拥有或控制的所有生产设施的温室气体排放。

- **拥有**：企业具有所有权的生产设施
- **控制**：企业具有运营控制权的生产设施

### 2.2 运行边界

核算边界应包括造纸生产的直接排放和间接排放。

#### 2.2.1 直接排放（范围1）

1. **化石燃料燃烧排放**：锅炉、碱回收炉、石灰窑、动力设备等燃烧设备化石燃料燃烧产生的CO₂排放
2. **工业生产过程排放**：
   - 石灰窑碳酸盐分解排放
   - 制浆过程中黑液燃烧排放（生物质碳排放，需注明）
   - 废水处理产生的CH₄排放
3. **逸散排放**：设备密封点泄漏、废水处理等产生的排放

#### 2.2.2 间接排放（范围2）

1. **购入使用电力排放**：企业购入的电力产生的CO₂排放
2. **购入使用蒸汽排放**：企业购入的蒸汽产生的CO₂排放（如适用）

### 2.3 生产工序边界

制浆造纸主要工序包括：

| 工序 | 主要排放源 | 说明 |
|------|-----------|------|
| 原料制备 | 剥皮、削片、筛选 | 原料准备 |
| 制浆 | 蒸煮、洗涤、筛选、漂白 | 化学浆/机械浆/废纸浆 |
| 碱回收 | 蒸发、燃烧、苛化 | 黑液回收、石灰再生 |
| 造纸 | 打浆、抄纸、压光、卷取 | 纸张成形 |
| 涂布/加工 | 涂布、压光、复卷 | 纸加工 |
| 废水处理 | 预处理、生化处理、深度处理 | 废水处理 |
| 自备电厂 | 锅炉、汽轮机、发电机 | 能源供应 |
| 石灰窑 | 石灰石煅烧 | 石灰再生 |

## 三、核算方法

### 3.1 总体方法

造纸行业温室气体排放核算采用**排放因子法**为主，**物料平衡法**为辅的方法。

**重要说明**：制浆过程中生物质燃料（黑液、树皮、木屑等）燃烧产生的CO₂排放不计入企业排放总量，但应单独列示。

### 3.2 核算公式

```
E_total = E_combustion_fossil + E_process + E_fugitive + E_indirect
```

其中：
- `E_total`：温室气体排放总量（不含生物质碳排放），单位：吨CO₂当量（tCO₂e）
- `E_combustion_fossil`：化石燃料燃烧排放量，单位：tCO₂
- `E_process`：工业生产过程排放量，单位：tCO₂e
- `E_fugitive`：逸散排放量，单位：tCO₂e
- `E_indirect`：间接排放量，单位：tCO₂

**生物质碳排放单独列示**：
```
E_biomass = E_combustion_biomass
```

### 3.3 化石燃料燃烧排放核算

```
E_combustion_fossil = Σ (FC_i × NCV_i × EF_i × OF_i × 44/12)
```

其中：
- `FC_i`：第i种化石燃料的消耗量，单位：t或10⁴Nm³
- `NCV_i`：第i种化石燃料的低位发热量，单位：GJ/t或GJ/10⁴Nm³
- `EF_i`：第i种化石燃料的单位热值含碳量，单位：tC/GJ
- `OF_i`：第i种化石燃料的碳氧化率，单位：%

### 3.4 生物质燃料燃烧排放核算（单独列示）

```
E_combustion_biomass = Σ (M_bio,i × EF_bio,i)
```

其中：
- `M_bio,i`：第i种生物质燃料消耗量，单位：t（绝干）
- `EF_bio,i`：第i种生物质燃料的排放因子，单位：tCO₂/t（绝干）

**生物质燃料包括**：黑液、树皮、木屑、竹屑、蔗渣、秸秆、沼气等。

### 3.5 工业生产过程排放核算

#### 3.5.1 石灰窑碳酸盐分解排放

```
E_lime_kiln = M_limestone × EF_limestone
```

其中：
- `M_limestone`：石灰窑石灰石消耗量，单位：t
- `EF_limestone`：石灰石排放因子，单位：tCO₂/t

#### 3.5.2 废水处理CH₄排放

```
E_wastewater_CH4 = (COD_in - COD_out - COD_sludge) × EF_CH4 × GWP_CH4
```

其中：
- `COD_in`：进水中COD总量，单位：t
- `COD_out`：出水中COD总量，单位：t
- `COD_sludge`：污泥中COD总量，单位：t
- `EF_CH4`：CH₄排放因子，单位：kgCH₄/kgCOD
- `GWP_CH4`：CH₄全球增温潜势，取28

### 3.6 间接排放核算

```
E_indirect = AD_electricity × EF_electricity + AD_steam × EF_steam
```

## 四、温室气体种类

本指南核算的温室气体包括：

| 序号 | 温室气体种类 | 化学分子式 | 全球增温潜势（GWP） | 主要来源 |
|------|-------------|-----------|---------------------|----------|
| 1 | 二氧化碳 | CO₂ | 1 | 化石燃料燃烧、碳酸盐分解、间接排放 |
| 2 | 甲烷 | CH₄ | 28 | 废水处理、逸散排放 |
| 3 | 氧化亚氮 | N₂O | 265 | 化石燃料燃烧（少量） |

**补充说明**：生物质燃烧产生的CO₂不计入企业排放总量，但需单独报告。

## 五、排放源分类

### 5.1 直接排放源

#### 5.1.1 化石燃料燃烧排放

| 排放源 | 燃料类型 | 燃烧设备 |
|--------|---------|----------|
| 动力锅炉 | 煤炭、重油、天然气、树皮、木屑等 | 电站锅炉、工业锅炉 |
| 碱回收炉 | 黑液、重油、天然气等 | 碱回收炉 |
| 石灰窑 | 煤粉、重油、天然气等 | 石灰回转窑 |
| 烘干设备 | 蒸汽、热风、天然气 | 纸机干燥部、浆料烘干机 |
| 自备电厂 | 煤炭、天然气 | 发电机组 |
| 运输设备 | 柴油、汽油 | 叉车、运输车等 |

#### 5.1.2 工业生产过程排放

| 排放源 | 排放原因 | 温室气体 | 说明 |
|--------|---------|----------|------|
| 石灰窑 | 石灰石煅烧分解 | CO₂ | 苛化工序石灰再生 |
| 废水处理 | 厌氧降解产生甲烷 | CH₄ | 废水处理系统 |
| 黑液燃烧 | 木质素燃烧 | CO₂ | 生物质碳排放，单独列示 |
| 树皮/木屑燃烧 | 生物质燃烧 | CO₂ | 生物质碳排放，单独列示 |

#### 5.1.3 逸散排放

| 排放源 | 排放原因 | 温室气体 |
|--------|---------|----------|
| 设备泄漏 | 阀门、法兰、泵等密封点 | CH₄、VOCs |
| 废水处理 | 沼气泄漏 | CH₄ |
| 储罐呼吸 | 黑液、化学品储罐 | VOCs |

### 5.2 间接排放源

| 排放源 | 说明 | 占比 |
|--------|------|------|
| 购入使用电力 | 企业从电网购入的电力 | 约20-40% |
| 购入使用蒸汽 | 企业从外部购入的蒸汽 | 较少 |
| 自备电厂 | 企业自备电厂发电 | 计入直接排放 |

### 5.3 生物质碳排放（单独列示）

| 排放源 | 说明 | 是否计入总量 |
|--------|------|-------------|
| 黑液燃烧 | 碱回收炉黑液燃烧 | 否，单独列示 |
| 树皮/木屑燃烧 | 树皮、木屑等造纸废弃物燃烧 | 否，单独列示 |
| 沼气燃烧 | 废水处理产生的沼气燃烧 | 否，单独列示 |
| 秸秆燃烧 | 农业废弃物燃烧 | 否，单独列示 |

## 六、活动水平数据要求

### 6.1 化石燃料消耗量

#### 6.1.1 数据来源

- 优先采用**计量数据**：皮带秤、地磅、流量计等
- 次选采用**台账数据**：燃料采购台账、燃料消耗台账
- 缺省采用**财务数据**：燃料采购发票、财务凭证

| 燃料类型 | 计量器具 | 精度要求 | 检定周期 |

## 七、排放因子选取

### 7.1 排放因子选取原则

1. **优先实测**：企业具备实测条件的，应采用实测排放因子
2. **行业缺省**：无法实测的，采用行业缺省值
3. **国家标准**：可参考GB/T 32151系列国家标准中的缺省值

### 7.2 化石燃料排放因子

参考电力行业排放因子表。

### 7.3 生物质燃料排放因子

## 八、数据质量管理

### 8.1 数据质量控制计划（DQCP）

企业应制定并实施数据质量控制计划，包括：

- 数据质量管理组织机构及职责
- 数据监测计划（含监测点位、监测频次、监测方法）
- 数据记录和存档要求
- 数据审核机制（三级审核）
- 人员培训要求
- 仪器设备检定校准计划

### 8.2 数据质量等级

| 数据质量等级 | 活动数据要求 | 排放因子要求 | 适用情况 |
|-------------|-------------|-------------|----------|
| Ⅰ级 | 连续计量，每日记录 | 实测（每批次检测） | 重点排放单位推荐 |
| Ⅱ级 | 定期计量，每周记录 | 实测（每月检测） | 一般排放单位 |
| Ⅲ级 | 台账记录，每月汇总 | 行业缺省值 | 小规模排放单位 |

### 8.3 数据内部审核

- 班组级：每日数据自查
- 车间级：每周数据审核
- 公司级：每月数据质量审核
- 年度：全面数据质量审核
- 保留审核记录和整改报告

### 8.4 生物质数据管理

- 生物质燃料消耗量应单独计量
- 生物质燃料与化石燃料应分账记录
- 生物质燃料水分和热值应定期检测
- 生物质碳排放应单独列示，不得混入化石燃料排放

## 九、报告内容和格式要求

### 9.1 报告主体信息

- 企业基本情况（名称、统一社会信用代码、地址、法定代表人等）
- 生产设施基本情况（生产线数量、产能、主要产品等）
- 核算边界说明（组织边界、运行边界、工序边界）
- 数据质量控制计划执行情况

### 9.2 排放数据

#### 9.2.1 排放总量

- 温室气体排放总量（tCO₂e，不含生物质碳）
- 直接排放量（tCO₂e）
- 间接排放量（tCO₂）
- 生物质碳排放量（tCO₂，单独列示）

#### 9.2.2 分排放源排放量

- 化石燃料燃烧排放量（分燃料类型、分工序）
- 工业生产过程排放量（碳酸盐分解、废水处理等）
- 逸散排放量
- 购入使用电力排放量
- 购入使用蒸汽排放量
- 生物质碳排放量（单独列示）

### 9.3 活动数据

- 化石燃料消耗量（分类型）
- 生物质燃料消耗量（分类型，绝干量）
- 产品产量（分类型）
- 原材料消耗量（分类型）
- 废水处理相关数据
- 购入电量/蒸汽量
- 自备电厂发电量

### 9.4 排放因子数据

- 各燃料排放因子及来源
- 生物质燃料排放因子及来源
- 各工艺过程排放因子及来源
- 电力排放因子及来源

### 9.5 支撑材料

- 数据质量控制计划
- 监测设备检定校准证书
- 燃料检测报告
- 产品产量证明材料
- 电费/蒸汽费结算单
- 废水处理监测报告
- 其他证明材料

### 9.6 报告格式

报告应采用统一报告格式，包括：

- 封面
- 目录
- 正文（按上述内容组织）
- 附表（数据表格）
- 附图（工艺流程图、监测点位图等）
- 附件（证明材料）

### 附录B：核算公式汇总

```
1. 排放总量（不含生物质碳）
E_total = E_combustion_fossil + E_process + E_fugitive + E_indirect

2. 生物质碳排放（单独列示）
E_biomass = E_combustion_biomass

3. 化石燃料燃烧排放
E_combustion_fossil = Σ (FC_i × NCV_i × EF_i × OF_i × 44/12)

4. 生物质燃料燃烧排放
E_combustion_biomass = Σ (M_bio,i × EF_bio,i)

5. 石灰窑碳酸盐分解排放
E_lime_kiln = M_limestone × EF_limestone

6. 废水处理CH₄排放
E_wastewater_CH4 = (COD_in - COD_out - COD_sludge) × EF_CH4 × GWP_CH4

7. 购入电力间接排放
E_indirect_electricity = AD_electricity × EF_electricity

8. 吨纸碳排放强度
EI_paper = E_total / P_paper

9. 吨浆碳排放强度
EI_pulp = E_total / P_pulp
```
