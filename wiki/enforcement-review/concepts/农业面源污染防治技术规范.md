# 农业面源污染防治技术规范

## 一、总则

### 1.1 立法目的

- 防治农业面源污染
- 保护和改善农业生态环境
- 保障农产品质量安全
- 推进农业绿色发展

### 1.2 立法依据

- 《中华人民共和国环境保护法》
- 《中华人民共和国水污染防治法》
- 《中华人民共和国土壤污染防治法》
- 《中华人民共和国农业法》
- 《中华人民共和国农产品质量安全法》
- 《中华人民共和国乡村振兴促进法》

### 1.3 适用范围

- 适用于农田化肥、农药施用
- 适用于农作物秸秆综合利用
- 适用于农田残膜回收利用
- 适用于农村生活污水治理
- 适用于水产养殖尾水治理

## 二、农业面源污染来源

### 2.1 主要污染源

#### 化肥污染

| 污染类型 | 主要污染物 |
|---------|----------|
| 氮肥 | 硝酸盐氮、氨氮、亚硝酸盐氮 |
| 磷肥 | 总磷 |
| 复合肥 | 总氮、总磷 |
| 有机肥 | COD、氨氮、总磷 |

#### 农药污染

| 农药类型 | 主要污染物 |
|---------|----------|
| 杀虫剂 | 有机磷、有机氯、菊酯类 |
| 杀菌剂 | 三唑类、苯并咪唑类 |
| 除草剂 | 草甘膦、阿特拉津、2,4-D |
| 植物生长调节剂 | 多效唑、乙烯利 |

#### 秸秆污染

- 焚烧产生的颗粒物、CO、VOCs
- 堆放产生的渗滤液
- 直接还田产生的甲烷

#### 农膜污染

- 残留塑料膜对土壤的污染
- 微塑料污染
- 重金属污染（含催化剂）

#### 畜禽养殖污染

- 粪便产生的 COD、氨氮、总磷
- 尿液产生的 COD、氨氮
- 臭气产生的 H₂S、NH₃

#### 水产养殖污染

- 饵料残渣
- 排泄物
- 渔药残留

### 2.2 主要污染物

| 污染物类别 | 主要指标 |
|----------|---------|
| 营养盐 | 总氮、氨氮、硝酸盐氮、总磷 |
| 有机物 | COD、BOD₅、TOC |
| 农药类 | 阿特拉津、草甘膦、滴滴涕、六六六 |
| 重金属 | 镉、铅、汞、砷、铬 |
| 微塑料 | 数量、质量 |
| 大气污染物 | NH₃、N₂O、CH₄ |

## 三、化肥污染防治

### 3.1 化肥施用管理

#### 化肥减量增效

| 措施 | 减量效果 |
|------|---------|
| 测土配方施肥 | 节肥 10%-20% |
| 有机肥替代 | 节肥 30%-50% |
| 缓控释肥 | 节肥 20%-30% |
| 水肥一体化 | 节肥 30%-50% |
| 机械深施 | 节肥 10%-20% |

#### 化肥使用限值

| 作物 | 单位面积化肥使用量（kg/亩） |
|------|------------------------|
| 水稻 | ≤ 25 |
| 小麦 | ≤ 25 |
| 玉米 | ≤ 25 |
| 棉花 | ≤ 30 |
| 蔬菜 | ≤ 40 |
| 果树 | ≤ 50 |

### 3.2 测土配方施肥

#### 实施要求

1. 开展土壤测试
2. 制定配方方案
3. 推广配方肥料
4. 跟踪效果

#### 配方方案

| 作物 | N : P₂O₅ : K₂O |
|------|---------------|
| 水稻 | 1 : 0.4 : 0.6 |
| 小麦 | 1 : 0.5 : 0.5 |
| 玉米 | 1 : 0.4 : 0.6 |
| 棉花 | 1 : 0.5 : 0.7 |
| 蔬菜 | 1 : 0.4 : 1.0 |
| 果树 | 1 : 0.5 : 1.0 |

### 3.3 有机肥替代

#### 替代比例

| 作物 | 有机肥替代比例 |
|------|-------------|
| 水稻 | 20%-30% |
| 小麦 | 20%-30% |
| 玉米 | 20%-30% |
| 蔬菜 | 30%-50% |
| 果树 | 30%-50% |

#### 有机肥要求

- 符合 NY 525-2012 有机肥料标准
- 重金属含量符合限值
- 粪大肠菌群数 ≤ 100 个/g
- 蛔虫卵死亡率 ≥ 95%

## 四、农药污染防治

### 4.1 农药减量控害

#### 减量措施

| 措施 | 减量效果 |
|------|---------|
| 绿色防控 | 节药 20%-30% |
| 统防统治 | 节药 10%-20% |
| 精准施药 | 节药 20%-30% |
| 生物农药 | 替代 30%-50% |

#### 禁限用农药

##### 禁用农药（部分）

- 六六六、滴滴涕
- 甲胺磷、对硫磷、甲基对硫磷
- 克百威、涕灭威
- 三氯杀螨醇、氯丹

##### 限制使用农药（部分）

- 阿维菌素（限制在果树上使用）
- 毒死蜱（限制在蔬菜上使用）

### 4.2 绿色防控技术

#### 农业防治

- 选用抗性品种
- 合理轮作
- 适时播种
- 健身栽培

#### 物理防治

- 杀虫灯诱杀
- 色板诱杀
- 食饵诱杀
- 防虫网阻隔

#### 生物防治

- 释放天敌
- 使用生物农药
- 性信息素迷向
- 捕食性昆虫

#### 生态控制

- 间作套种
- 增加生物多样性
- 生态调控

### 4.3 农药包装废弃物回收

#### 回收要求

- 建立农药包装废弃物回收体系
- 设立回收点
- 实行押金回收制度

#### 处置要求

- 不可再利用的农药包装废弃物按危险废物管理
- 委托有资质的单位处置
- 建立回收台账

## 六、农膜污染防治

### 6.1 农膜使用要求

#### 推广可降解农膜

- 生物降解农膜
- 光降解农膜
- 光-生物双降解农膜

#### 推广薄型农膜

- 使用厚度 ≥ 0.01 mm 的农膜
- 提高回收率

### 6.2 农膜回收

#### 回收要求

- 当季农膜回收率 ≥ 80%
- 残膜量 ≤ 5 kg/亩

#### 回收方式

- 人工捡拾
- 机械回收
- 机械化收膜

### 6.3 残膜处理

#### 再利用

- 再生塑料颗粒
- 塑料制品

#### 无害化处置

- 焚烧处置
- 卫生填埋

## 七、农村生活污水治理

### 7.1 排放要求

#### 排放标准

按 GB 18918-2002 城镇污水处理厂污染物排放标准或地方标准执行。

#### 主要限值

| 排放去向 | COD（mg/L） | 氨氮（mg/L） | 总磷（mg/L） |
|---------|-----------|-------------|-------------|
| 直接排入水体 | ≤ 50 | ≤ 5 | ≤ 0.5 |
| 排入城镇下水道 | ≤ 120 | ≤ 25 | ≤ 5 |
| 用于农田灌溉 | ≤ 100 | ≤ 15 | ≤ 5 |

### 7.2 处理方式

#### 集中处理

- 适用于人口密集的村庄
- 处理规模：≥ 50 m³/d
- 工艺：A/O、A²/O、SBR、MBR

#### 分散处理

- 适用于人口分散的村庄
- 处理规模：5-50 m³/d
- 工艺：人工湿地、稳定塘、沼气池

#### 庭院处理

- 适用于分散农户
- 处理规模：≤ 5 m³/d
- 工艺：化粪池、小型人工湿地

### 7.3 处理工艺选择

#### 处理工艺选择依据

1. 村庄规模
2. 人口密度
3. 排水方式
4. 排放去向
5. 经济条件

#### 主要工艺

##### 人工湿地

- 优点：投资少、运行费用低、管理方便
- 缺点：占地面积大、受气候影响
- 适用：南方地区

##### 稳定塘

- 优点：投资少、运行费用低
- 缺点：占地面积大、有臭气
- 适用：地势低洼地区

##### 沼气池

- 优点：能源回收、肥源
- 缺点：管理复杂
- 适用：畜禽养殖密集区

##### 一体化设备

- 优点：占地面积小、出水水质好
- 缺点：投资大、运行费用高
- 适用：经济条件好的村庄

## 八、水产养殖尾水治理

### 8.1 排放要求

#### 排放标准

按 SC/T 9103-2007 淡水池塘养殖水排放要求或地方标准执行。

#### 主要限值

| 项目 | 一级标准 | 二级标准 |
|------|---------|---------|
| SS（mg/L） | ≤ 50 | ≤ 100 |
| pH | 6.5-8.5 | 6.0-9.0 |
| COD（mg/L） | ≤ 20 | ≤ 30 |
| 总氮（mg/L） | ≤ 2.0 | ≤ 3.0 |
| 总磷（mg/L） | ≤ 0.4 | ≤ 0.8 |
| 非离子氨（mg/L） | ≤ 0.02 | ≤ 0.10 |

### 8.2 处理工艺

#### 物理处理

- 沉淀池
- 过滤池
- 气浮池

#### 化学处理

- 投加絮凝剂
- 投加消毒剂

#### 生物处理

- 生物滤池
- 人工湿地
- 综合生物塘

#### 综合处理

- 三池两坝（沉淀池、曝气池、生物滤池 + 上下坝）
- 三池三坝（增加一道过滤坝）

## 九、监测要求

### 9.1 监测项目

#### 土壤监测

| 项目 | 监测频次 |
|------|---------|
| pH、有机质 | 每年 1 次 |
| 全氮、全磷 | 每年 1 次 |
| 碱解氮、速效磷、速效钾 | 每年 1 次 |
| 重金属 | 每 3 年 1 次 |
| 农药残留 | 每 3 年 1 次 |

#### 水质监测

| 项目 | 监测频次 |
|------|---------|
| pH、COD、氨氮、总磷、总氮 | 每月 1 次 |
| 农药残留 | 每季度 1 次 |
| 重金属 | 每年 1 次 |

### 9.2 监测点位

#### 农田监测点

- 每千亩布设 1 个监测点
- 主要监测土壤、地表径流

#### 养殖场监测点

- 每个规模养殖场布设 1-2 个监测点
- 主要监测废水、地下水

## 十二、对企业环保合规工作的启示

1. **合理使用农业投入品**：科学施肥、用药
2. **建立农业投入品台账**：记录化肥、农药使用情况
3. **推广绿色技术**：采用测土配方、绿色防控等技术
4. **资源化利用**：秸秆、农膜、畜禽粪污资源化利用
5. **依法处置农药包装**：按规定回收农药包装废弃物
6. **加强监测**：定期开展土壤、水质监测
7. **配合监管**：配合农业、生态环境部门监管
8. **完善档案**：完整保存农业投入品使用记录
