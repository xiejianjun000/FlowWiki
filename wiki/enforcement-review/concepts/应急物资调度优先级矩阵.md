# 应急物资调度优先级矩阵

> 用于快速判断在不同类型环境应急事件中，应优先调拨哪些物资，合理分配运输资源。

---

| 水污染 | 下游取水口风险 | 围堵+监测第一 → 处理物资紧跟 → 备用水源 |
| 交通事故 | 伤员+化学品双重 | 医疗第一 → 防护 → 围堵泄漏 |

## 三、物资调配时间估算

### 3.1 准备工作时间

| 步骤 | 平时（工作日白天） | 夜间/节假日 | 说明 |
|------|:----------------:|:----------:|------|
| 接收调令→开始装车 | 5~10分钟 | 15~30分钟 | 值班响应 |
| 清点装车（50箱以内） | 15~20分钟 | 20~30分钟 | 双人操作 |
| 清点装车（50~200箱） | 30~45分钟 | 40~60分钟 | — |
| 装车完成→发车 | 5分钟 | 5分钟 | 签单+封车 |
| **合计准备时间** | **25~80分钟** | **40~125分钟** | — |

### 3.2 总响应时间表

**计算公式：** `T_total = T_prepare + T_transport + T_unload`

| 事件距离 | 白天响应 | 夜间响应 | 备注 |
|---------|:--------:|:--------:|------|
| 同城区（≤10km） | 30~45分钟 | 45~70分钟 | 最优场景 |
| 近郊（10~30km） | 45~70分钟 | 60~100分钟 | — |
| 县域（30~100km） | 70~150分钟 | 100~180分钟 | 含高速 |
| 跨市（100~300km） | 2~5小时 | 3~7小时 | 需协调 |

### 3.3 特殊情况加时

| 特殊情况 | 加时 | 应对 |
|---------|:----:|------|
| 恶劣天气（暴雨/大雾） | +30%~50% | 提前关注气象预警 |
| 交通管制/封路 | +不固定 | 申请应急绿色通道 |
| 夜间操作 | +20~40分钟 | 加强照明和人员配置 |
| 大型物资（需吊装） | +30~60分钟 | 提前预约吊车 |
| 多批次组织 | +批次间隔15~30分钟 | 多车辆同时装车 |

## 四、现场物资消耗快速估算公式

### 4.1 通用公式

```
消耗总量 = 作业人数 × 单位消耗率 × 作业时间 × 环境系数
```

### 4.2 分项消耗估算

#### 个体防护类

| 物资 | 消耗公式 | 示例 |
|------|---------|------|
| 防毒面具滤毒罐 | 0.5个/人/4h（高毒环境） | 30人×6h→1个/人→30个 |
| 化学防护服 | 1套/人/8h（一次使用） | 30人→30套 |
| 丁基手套 | 2双/人/8h | 30人→60双 |
| 护目镜 | 1副/人/事件 | 30人→30副（可复用） |

#### 围堵控制类

| 物资 | 消耗公式 | 示例 |
|------|---------|------|
| 吸油毡 | 油量(kg)×100×吸附率(0.3~0.8) | 100kg油→5,000~10,000kg吸油毡 |
| 消油剂 | 油量(kg)×(1/20~1/30) | 100kg油→3~5L |
| 围油栏 | π×(D+100)×1.5（D=围控直径m） | 50m直径→约700m |
| 活性炭（吸附） | 水量(m³)×污染物浓度(mg/L)×吸附比(0.05~0.2)/1000 | 1000m³×50mg/L×0.1/1000=5,000kg |
| 石灰（中和） | 水量(m³)×(pH差)×0.5 | 100m³×(6→7)×0.5=50kg |

#### 水处理类

| 处理方式 | 消耗公式 | 说明 |
|---------|---------|------|
| 混凝沉淀 | PAC: 20~50mg/L × 水量(m³)/1000 (kg) | 需现场快速搅拌混合 |
|    | PAM: 1~5mg/L × 水量(m³)/1000 (kg) | 助凝剂，用量为PAC的1/10 |
| 中和处理 | Ca(OH)₂: 1.5kg/m³·pH单位 | pH从2→7，1m³需7.5kg |
|    | HCl(35%): 3L/m³·pH单位 | pH从12→7，1m³需15L |
| 活性炭吸附 | 粉末活性炭: 50~200mg/L | 直接投加 |
|    | 颗粒活性炭: 接触时间≥20min | 需要过滤装置 |

#### 医疗急救类

| 物资 | 消耗估算 | 说明 |
|------|---------|------|
| 急救包 | 现场人数×15~20% | 按受伤比例预估 |
| 烧伤敷料 | 受伤人数×3套 | 烧伤按10%估算 |
| 洗眼液 | 5L/核心作业组 | 除污染备用 |
| 解毒剂 | 按事件类型 | 参考化学物中毒剂量 |

### 4.3 快速速算口诀

```
化危泄漏先护身，面具防服不能省
油品入水围为先，吸油毡要按吨算
毒气扩散测风向，滤毒罐要看毒型
水遇污染活性炭，石灰中和按方算
交通事故双重险，救人为先防扩散
夜间作业灯要亮，通讯备电不能断
消耗估算三七开，备多不亏是用心
```

> **口诀解读：**
> - "消耗估算三七开" → 理论值的1.3倍（额外考虑30%富余量+操作损耗）
> - "备多不亏" → 应急物资宁可备而不用，不可用时无备

## 五、调度决策参考指南

### 5.1 首批调拨原则

1. **安全物资先行**：个人防护设备必须随第一批出发
2. **围堵物资紧跟**：控制污染扩散是第一优先级的行动
3. **监测物资同步**：实时数据是决策的基础
4. **运输能力优化**：每次车辆满载，分批到达

### 5.2 应急响应"黄金1小时"物资清单

> 适用于中等规模环境应急事件（如20~50人救援队）

| 批次 | 时间窗 | 车辆数 | 重点物资 |
|------|-------|--------|---------|
| 第1批 | 0~30min | 1~2辆 | 防护+检测+急救 |
| 第2批 | 30~60min | 2~3辆 | 围堵+吸附+中和 |
| 第3批 | 1~3h | 按需增派 | 大型设备+后勤补给 |

### 5.3 调拨决策树

```
事件发生
   ↓
确定事件类型 → 查矩阵优先级
   ↓
评估威胁范围 → 确定物资数量级
   ↓
确认现有库存 → 实物储备够？→ 是 → 立即调拨
                           ↓ 否
                    启动协议储备/申请跨区域调拨
   ↓
确定运输方式 → 距离+路况+天气 → 安排车辆
   ↓
发送物资 → GPS跟踪 → 现场交接
```

---

> **附注：** 本矩阵中的优先级和数量均为一般性参考值。实际应急中应根据：
> - 事件具体规模（泄漏量、影响面积）
> - 气象条件（风向、风速、温度、雨晴）
> - 地理环境（市区/郊区/水域/山地）
> - 实际到达现场后的事态发展
>
> 进行动态调整。建议每次应急后复盘更新矩阵参数。
