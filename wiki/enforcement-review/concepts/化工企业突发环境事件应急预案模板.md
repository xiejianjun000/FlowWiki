## 应急预案编制说明

### 一、编制背景

为贯彻落实《中华人民共和国环境保护法》《中华人民共和国突发事件应对法》《突发环境事件应急管理办法》《突发环境事件应急预案管理办法》等法律法规要求，规范企业突发环境事件应急管理工作，有效预防、及时控制和消除突发环境事件的危害，保障公众生命健康和环境安全，促进企业可持续发展，特编制本预案。

### 二、编制过程

本预案编制工作于____年____月启动，由企业环保管理部门牵头，生产、安全、设备、技术等部门共同参与。编制过程包括：

1. 资料收集与现状调研
2. 环境风险源识别与风险分析
3. 环境风险受体识别与评估
4. 应急能力评估
5. 预案编制与内部评审
6. 专家评审与修订
7. 企业内部发布与备案

### 三、预案定位

本预案是企业突发环境事件应急管理工作的总体指导性文件，是企业应急预案体系的重要组成部分。本预案与企业安全生产应急预案、消防应急预案等相互衔接，共同构成企业应急管理体系。

### 四、预案备案

本预案经企业主要负责人批准发布后，报所在地生态环境主管部门备案。

### 1.3 适用范围

本预案适用于本企业厂区范围内，因生产安全事故、设备故障、人为因素、自然灾害等引发的突发环境事件的预防、预警、应急处置和后期处置工作。

本预案适用的突发环境事件类型包括：

1. 危险化学品泄漏、火灾、爆炸引发的大气、水、土壤环境污染事件
2. 危险废物泄漏、流失引发的环境污染事件
3. 废水、废气非正常排放引发的环境污染事件
4. 雨污水管网、污水处理设施故障引发的水环境污染事件
5. 其他突发环境事件

### 1.5 工作原则

1. **以人为本，安全第一**：把保障人民群众生命健康和财产安全作为应急工作的出发点和落脚点，最大程度地减少突发环境事件造成的人员伤亡和危害。

2. **预防为主，防治结合**：坚持预防与应急相结合，常态与非常态相结合，做好风险防范、监测预警、应急准备等日常工作。

3. **统一领导，分级负责**：在企业应急指挥部的统一领导下，各部门按照职责分工，各司其职，密切配合，共同做好突发环境事件应急处置工作。

4. **快速响应，科学处置**：建立快速反应机制，确保信息及时、准确传递，应急资源迅速调度，采用科学的应急处置技术和方法，提高应急处置水平。

5. **依靠科学，依法规范**：充分发挥专家和专业技术人员的作用，实行科学民主决策，依法规范应急管理和应急响应程序。

6. **政企联动，社会协同**：加强与地方政府、相关部门及周边企业的协作，建立应急联动机制，形成应急合力。

### 3.3 风险类型

#### 3.3.1 泄漏事故

1. **液体泄漏**：危险化学品储罐、管道、反应釜等设施发生物料泄漏，可能引发水体、土壤污染。
2. **气体泄漏**：有毒有害气体泄漏，可能引发大气环境污染，对周边人群健康造成危害。
3. **固废泄漏**：危险废物在储存、转移过程中发生泄漏、流失，可能造成土壤、水体污染。

#### 3.3.2 火灾事故

危险化学品泄漏后遇火源引发火灾，燃烧产生的烟气可能造成大气环境污染，消防废水可能造成水环境污染。

#### 3.3.3 爆炸事故

危险化学品泄漏后与空气形成爆炸性混合物，遇火源引发爆炸，造成设备损坏、人员伤亡，并可能引发次生环境污染。

#### 3.3.4 非正常排放

1. **废水非正常排放**：污水处理设施故障、生产异常等导致废水超标排放。
2. **废气非正常排放**：废气处理设施故障、开停车、检修等导致废气超标排放。

## 第六章 预防与预警

### 6.1 风险防控措施

#### 6.1.1 危险化学品储存风险防控

1. 储罐区设置围堰、防火堤，防止泄漏物料扩散
2. 储罐设置液位、温度、压力监测报警装置
3. 储罐区设置可燃/有毒气体检测报警装置
4. 定期对储罐进行检测检验，及时消除安全隐患
5. 危险化学品分区分类储存，符合规范要求
6. 建立危险化学品出入库管理制度

#### 6.1.2 生产过程风险防控

1. 生产装置设置安全联锁、紧急停车系统
2. 关键工艺参数设置报警装置
3. 定期对设备设施进行维护保养
4. 严格执行操作规程，杜绝违章作业
5. 加强职工安全教育培训，提高安全意识
6. 定期开展隐患排查治理

#### 6.1.3 管道输送风险防控

1. 定期对管道进行巡检和检测
2. 管道设置明显标识和警示标志
3. 管道穿越道路、沟渠等采取防护措施
4. 定期对管道阀门、法兰进行检查维护
5. 建立管道档案，做好运行记录

#### 6.1.4 水污染风险防控

1. 建设事故废水收集系统，设置事故池
2. 雨水排口设置切断阀，防止事故废水外排
3. 污水处理站设置备用设备，确保稳定运行
4. 定期对污水管网进行检查维护
5. 设置在线监测设备，实时监控排放情况

#### 6.1.5 大气污染风险防控

1. 废气处理设施定期维护，确保正常运行
2. 设置废气在线监测设备，实时监控排放情况
3. 储罐区设置油气回收装置
4. 加强无组织排放管控
5. 制定非正常排放应对措施

#### 6.1.6 危险废物风险防控

1. 危险废物分类收集、分区储存
2. 危废暂存间做好防渗、防雨、防扬散措施
3. 危险废物及时委托有资质单位处置
4. 严格执行危险废物转移联单制度
5. 定期对危废暂存间进行检查

### 6.2 监测预警

#### 6.2.1 监测体系

企业建立覆盖全厂的环境监测体系，包括：

1. 大气环境监测
   - 厂界无组织排放监测
   - 废气排放口在线监测
   - 可燃/有毒气体检测报警
2. 水环境监测
   - 废水排放口在线监测
   - 雨水排口监测
   - 地下水监测
3. 土壤环境监测
   - 重点区域土壤监测
   - 地下水监测井监测

1. 自动监测：在线监测设备24小时连续监测
2. 人工监测：定期开展手工监测
3. 日常巡检：现场巡查检查
4. 视频监控：重点区域视频监控

#### 6.2.3 预警信息来源

1. 企业监测系统异常数据
2. 设备设施故障报警
3. 生产运行异常信息
4. 隐患排查发现的问题
5. 自然灾害预警信息
6. 周边企业事故信息
7. 其他渠道获取的预警信息

### 6.3 预警分级与发布

#### 6.3.1 预警分级

根据突发环境事件可能造成的危害程度、发展态势，将预警分为四级，依次为：

| 预警级别 | 颜色标识 | 可能的危害程度 |
|----------|----------|---------------|
| 一级预警 | 红色 | 可能发生特别重大突发环境事件 |
| 二级预警 | 橙色 | 可能发生重大突发环境事件 |
| 三级预警 | 黄色 | 可能发生较大突发环境事件 |
| 四级预警 | 蓝色 | 可能发生一般突发环境事件 |

#### 6.3.2 预警发布

1. 预警发布主体：应急指挥部办公室
2. 预警发布方式：
   - 企业内部广播
   - 内部通讯系统
   - 电话通知
   - 短信通知
   - 现场通知
3. 预警发布内容：
   - 预警级别
   - 预警事项
   - 可能影响范围
   - 预警起始时间
   - 应采取的防范措施
   - 发布单位和时间

#### 6.3.3 预警调整与解除

1. 根据事态发展变化，及时调整预警级别
2. 当风险消除后，及时解除预警
3. 预警调整和解除由应急指挥部决定，指挥部办公室发布

### 6.4 预警措施

#### 6.4.1 四级（蓝色）预警措施

1. 加强环境监测，增加监测频次
2. 加强现场巡查，及时发现隐患
3. 通知相关岗位人员做好应急准备
4. 检查应急物资，确保完好可用

2. 应急救援队伍进入现场
3. 启动应急响应准备
4. 实施交通管制
5. 组织人员疏散转移
6. 向地方政府报告

#### 6.4.4 一级（红色）预警措施

4. 请求外部应急支援
5. 配合政府开展应急处置
6. 做好信息发布和舆情应对

## 第七章 应急响应

### 7.1 响应分级

根据突发环境事件的严重程度、影响范围，将应急响应分为四级：

| 响应级别 | 事件等级 | 启动条件 | 响应主体 |
|----------|----------|----------|----------|
| Ⅰ级响应 | 特别重大 | 发生或可能发生特别重大突发环境事件 | 报请上级政府启动 |
| Ⅱ级响应 | 重大 | 发生或可能发生重大突发环境事件 | 报请地方政府启动 |
| Ⅲ级响应 | 较大 | 发生或可能发生较大突发环境事件 | 企业应急指挥部启动 |
| Ⅳ级响应 | 一般 | 发生或可能发生一般突发环境事件 | 部门负责人启动 |

### 7.2 响应程序

#### 7.2.1 信息接报

1. 应急指挥部办公室负责接收突发环境事件信息
2. 接报后立即核实事件基本情况
3. 记录事件发生时间、地点、原因、污染物种类、数量、影响范围等信息

#### 7.2.2 信息研判

1. 应急指挥部办公室组织对事件信息进行研判
2. 分析事件发展趋势和可能造成的危害
3. 提出启动响应级别建议

#### 7.2.3 响应启动

1. 应急指挥部根据研判结果，决定启动相应级别应急响应
2. 发布启动应急响应命令
3. 通知各应急救援队伍和相关部门

#### 7.2.4 应急处置

1. 各应急救援队伍按照职责分工开展应急处置工作
2. 采取有效措施控制污染源，防止污染扩散
3. 开展环境监测，及时掌握污染状况
4. 组织人员疏散转移，保障人员安全

#### 7.2.5 响应升级

当事件超出企业处置能力或事态进一步扩大时，及时向上级报告，请求升级响应。

#### 7.2.6 响应终止

当事件得到有效控制，满足终止条件时，由应急指挥部决定终止应急响应。

### 7.3 信息报告与通报

#### 7.3.1 内部报告

1. 突发环境事件发生后，现场人员立即向部门负责人报告
2. 部门负责人立即向应急指挥部办公室报告
3. 应急指挥部办公室立即向应急指挥部报告
4. 紧急情况下，可越级上报

#### 7.3.2 外部报告

1. 发生较大及以上突发环境事件后，企业应当在1小时内向所在地生态环境主管部门和相关部门报告
2. 报告内容包括：
   - 事件发生的时间、地点、原因
   - 污染物种类、数量、性质
   - 影响范围和程度
   - 已采取的应急措施
   - 事件发展趋势预测
   - 需要协调支援的事项
3. 及时续报事件处置进展情况
4. 事件处置结束后，提交总结报告

#### 7.3.3 信息通报

1. 及时向周边企业和居民通报事件情况
2. 向可能受到影响的下游地区通报情况
3. 通报内容应真实、准确、及时
4. 做好公众沟通和解释工作

### 7.4 现场处置措施

#### 7.4.1 危险化学品泄漏处置

**一般处置原则**：
- 立即撤离无关人员，设置警戒区域
- 切断火源，禁止明火
- 应急人员做好个人防护
- 采取措施控制泄漏源
- 收集泄漏物料，防止扩散

**液体泄漏处置**：
1. 立即停止相关作业，关闭阀门
2. 用围堰、沙袋等围堵，防止液体扩散
3. 用防爆泵将泄漏物料转移至备用容器
4. 少量泄漏用吸附材料吸附处理
5. 防止泄漏物进入雨水管网、水体
6. 对泄漏区域进行监测

**气体泄漏处置**：
1. 立即停止相关作业，关闭阀门
2. 迅速撤离泄漏污染区人员至上风向
3. 应急人员佩戴正压式空气呼吸器
4. 加强通风，促进气体扩散
5. 喷雾状水稀释、溶解
6. 对泄漏区域进行气体浓度监测

#### 7.4.2 火灾事故处置

1. 立即报警，启动消防系统
2. 组织人员疏散，设置警戒区域
3. 切断物料供应，关闭相关阀门
4. 根据物料性质选择合适的灭火剂
5. 防止消防废水外排，收集至事故池
6. 对燃烧烟气进行监测
7. 防止次生环境污染

#### 7.4.3 爆炸事故处置

1. 立即撤离现场人员，设置警戒区域
2. 查明是否有二次爆炸危险
3. 对受伤人员进行急救
4. 控制火源，防止引发连锁爆炸
5. 清理现场，收集泄漏物料
6. 开展环境监测

#### 7.4.4 水污染事故处置

1. 立即停止废水排放
2. 关闭雨水排口切断阀
3. 将事故废水引入事故池
4. 开启污水处理站应急处理设施
5. 加强水质监测
6. 防止污染扩散
7. 必要时通知下游采取防范措施

#### 7.4.5 大气污染事故处置

1. 立即停止废气排放
2. 组织人员向上风向疏散
3. 加强废气处理设施运行
4. 喷雾降尘，促进污染物沉降
5. 加强大气环境监测
6. 必要时通知周边单位和居民采取防护措施

#### 7.4.6 危险废物泄漏处置

1. 立即停止危险废物作业
2. 设置警戒区域，禁止无关人员进入
3. 应急人员做好个人防护
4. 收集泄漏的危险废物
5. 对污染区域进行清理处置
6. 防止污染土壤和地下水
7. 做好记录，委托专业机构处置

### 7.5 现场监测

#### 7.5.1 监测方案

根据事故类型和影响范围，制定应急监测方案，确定：

1. 监测项目
2. 监测点位
3. 监测频次
4. 监测方法
5. 监测人员及设备

#### 7.5.2 大气环境监测

1. 监测点位：事故点、厂界、下风向敏感目标
2. 监测项目：特征污染物、可燃气体、有毒有害气体
3. 监测频次：事故初期每15-30分钟一次，后期根据情况调整

#### 7.5.3 水环境监测

1. 监测点位：事故池、污水处理站进出口、雨水排口、周边水体
2. 监测项目：pH、COD、特征污染物
3. 监测频次：事故初期每30分钟-1小时一次，后期根据情况调整

#### 7.5.4 土壤环境监测

1. 监测点位：泄漏点周边
2. 监测项目：特征污染物
3. 监测频次：根据需要确定

#### 7.5.5 监测报告

1. 监测数据及时报告应急指挥部
2. 编制应急监测报告
3. 为应急决策提供依据

### 7.6 安全防护

#### 7.6.1 应急人员防护

1. 根据事故类型和危害程度，配备相应的防护装备
2. 进入污染区域必须佩戴个人防护用品
3. 设置安全警戒区域，禁止无关人员进入
4. 应急人员实行轮换作业，避免长时间暴露
5. 对应急人员进行健康监护

#### 7.6.2 公众防护

1. 根据事故影响范围，及时组织人员疏散转移
2. 告知公众正确的防护方法
3. 为疏散人员提供临时安置场所
4. 为受影响人员提供医疗服务
5. 做好受影响人员的心理疏导

### 7.7 应急终止

#### 7.7.1 应急终止条件

满足下列全部条件，可终止应急响应：

1. 事件现场得到有效控制，事件条件已经消除
2. 污染物浓度降至规定限值以内
3. 事件造成的危害已经被彻底消除，无继发可能
4. 采取了必要的防护措施，保护公众免受再次危害
5. 专业机构评估认为事件风险已得到有效控制

#### 7.7.2 应急终止程序

1. 现场处置组提出终止应急响应建议
2. 监测预警组提供监测数据支持
3. 应急指挥部组织评估，决定终止应急响应
4. 发布应急终止命令
5. 通知各应急救援队伍撤离
6. 通知周边单位和居民应急终止

#### 7.7.3 应急终止后工作

1. 开展事故调查分析
2. 开展环境损害评估
3. 开展污染治理和生态修复
4. 对应急处置工作进行总结评估
5. 修订完善应急预案

## 第十二章 附则

### 12.1 预案管理

#### 12.1.1 预案编制与备案

本预案由企业安全环保部负责编制，经企业主要负责人批准后发布实施，并报所在地生态环境主管部门备案。

#### 12.1.2 预案修订

有下列情形之一的，应当及时修订应急预案：

1. 依据的法律、法规、规章、标准发生变化的
2. 企业生产工艺和技术发生变化的
3. 企业环境风险源发生变化的
4. 应急组织指挥体系或职责发生调整的
5. 应急资源发生重大变化的
6. 预案演练或应急处置中发现问题需要修订的
7. 其他需要修订的情形

应急预案每三年至少修订一次。

#### 12.1.3 预案培训与演练

定期开展应急预案培训和演练，确保相关人员熟悉预案内容，掌握应急处置技能。

### 12.2 名词术语

1. **突发环境事件**：指由于污染物排放或自然灾害、生产安全事故等因素，导致污染物或放射性物质等有毒有害物质进入大气、水体、土壤等环境介质，突然造成或可能造成环境质量下降，危及公众身体健康和财产安全，或造成生态环境破坏，或造成重大社会影响，需要采取紧急措施予以应对的事件。

2. **环境风险源**：指可能导致突发环境事件的污染源，以及生产、贮存、经营、使用、运输危险物质或产生、收集、利用、处置危险废物的场所、设备和装置。

3. **环境风险受体**：指可能受突发环境事件影响的人员、财产、环境敏感区等。

4. **应急响应**：指针对突发环境事件采取的紧急措施和行动。

5. **应急预案**：指针对可能发生的突发环境事件，为迅速、有序地开展应急行动而预先制定的工作方案。

### 12.3 制定与解释

本预案由企业安全环保部负责解释。

### 12.4 实施日期
