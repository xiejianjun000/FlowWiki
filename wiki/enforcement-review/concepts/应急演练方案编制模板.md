# 应急演练方案编制模板

## 模板概述

应急演练方案是组织应急演练的核心文件，是演练成功实施的基础。本模板全面涵盖应急演练方案的各项要素，提供标准化的编制框架和完整的场景脚本示例。模板适用于桌面推演、功能演练和全面演练三类演练形式的方案编制。

本模板为生态环境领域应急演练量身定制，特别考虑化学品泄漏、重金属污染（如锑污染）等典型环境应急场景的演练需求。

### 第二章 场景设置

#### 2.1 事故设定原则

演练场景设定应遵循以下原则：

1. **针对性**：基于本单位或本区域的实际环境风险特征
2. **合理性**：场景在技术可能性范围内，不脱离实际
3. **安全性**：模拟过程不产生真实危害
4. **教育性**：场景应能暴露问题和薄弱环节
5. **可控性**：演练进程可以通过情景控制进行调节
6. **层次性**：场景应具备逐步升级的特性
7. **真实性**：贴近真实事故的发展规律

#### 2.2 场景要素表

| 要素 | 内容 | 编制说明 |
|------|------|---------|
| 事故类型 | | 化学品泄漏、火灾爆炸次生环境污染、尾矿库泄漏、锑污染、油品泄漏、危险废物倾倒等 |
| 发生时间 | | 具体到年月日时分，考虑季节和时段因素（夜间、节假日更具挑战） |
| 发生地点 | | 明确的地理位置、周边水系、保护目标 |
| 事故源头 | | 泄漏源类型、规模、压力、温度等参数 |
| 污染物 | | 污染物名称、物化性质、毒性、扩散特性 |
| 泄漏/释放量 | | 定量估算，区分瞬时泄漏和持续泄漏 |
| 受影响介质 | | 水体/土壤/大气/多介质耦合 |
| 影响范围 | | 初始影响范围、扩散预估范围 |
| 受影响敏感目标 | | 水源地、居民区、生态保护区、学校医院等 |
| 气象条件 | | 风向、风速、气温、湿度、气压、稳定度 |
| 水文条件 | | 河流流量、流速、水深、断面参数 |
| 次生灾害风险 | | 火灾、爆炸、有毒气体扩散等 |
| 环境敏感程度 | | 按HJ 589-2021分级标准 |

| 响应启动单位 | 县级 / 市级 / 省级 / 国家级 |

#### 3.3 各岗位职责详述

**总指挥职责：**
1. 批准演练总体方案和关键文件
2. 宣布演练开始和终止
3. 根据演练进程做出重大决策
4. 批准应急响应升级和降级
5. 批准信息发布内容
6. 引导演练复盘和总结

**副总指挥职责：**
1. 具体组织协调各参演单位
2. 指导各工作组按方案推进
3. 在总指挥缺席时代行其职权
4. 审核演练评估报告
5. 跟踪改进措施落实情况

**综合协调组职责：**
1. 制定演练工作方案
2. 协调参演单位和人员
3. 组织演练前协调会议
4. 保障指挥通信畅通
5. 整理演练资料和档案

**情景控制组职责：**
1. 编制情景脚本和注入计划
2. 按计划向参演人员注入情景信息
3. 根据演练实际进展灵活调整情景
4. 控制演练节奏和进度
5. 确保情景信息不被提前泄露

**观摩评估组职责：**
1. 制定评估标准和评分表
2. 全程观察记录各参演单位的响应表现
3. 对关键节点进行独立评估打分
4. 编写评估报告
5. 提出改进建议

**安全保障组职责：**
1. 编制演练安全方案
2. 演练前安全检查（场地、装备、交通）
3. 演练过程中全程安全监控
4. 配备现场医疗保障人员
5. 制定应急预案和撤离方案
6. 处理演练中的突发安全情况

**现场处置组职责：**
1. 按照预案执行现场抢险处置
2. 建立围控和收集设施
3. 执行污染物控制和清理
4. 保护周边环境敏感目标
5. 配合应急监测组进行现场操作

**应急监测组职责：**
1. 编制应急监测方案
2. 执行现场布点和采样
3. 使用快速检测设备进行现场分析
4. 建立监测数据分析链
5. 编制监测简报和报告
6. 提出处置技术支持建议

**后勤保障组职责：**
1. 保障演练所需物资装备到位
2. 安排演练车辆和交通
3. 保障参演人员食宿
4. 管理演练物资出入库
5. 演练后物资归位管理

**信息宣传组职责：**
1. 编制信息发布预案
2. 拟写新闻通稿
3. 对接新闻媒体
4. 模拟舆情监控和应对
5. 演练影像资料记录
6. 统一信息出口管理

#### 4.2 演练实施流程

（标准演练实施流程，时间轴以T表示）

**第一阶段：事发与接报（T+00:00 - T+00:20）**

T+00:00 — 情景控制组向应急值班室发出初始报警
- 报警内容：(按情景脚本注入)
- 记录重点：报警时间、报警人信息、事故事件描述、事故地点

T+00:05 — 值班人员完成接报记录，初步判断事故等级
- 填写《突发环境事件信息接报记录表》
- 通知带班领导和应急管理部门负责人
- 将事故信息上报指挥中心

T+00:10 — 应急管理部门负责人初步研判
- 调取事故地点周边环境资料（水系、敏感目标、气象水文数据）
- 评估初步事故等级
- 决定是否启动应急响应

T+00:15 — 启动应急响应
- 通知应急指挥中心成员
- 通知应急监测队伍
- 通知现场处置队伍
- 通知后勤保障部门
- 开始《应急响应启动工作记录》

T+00:20 — 应急队伍集结
- 人员到点到位情况核查
- 装备装车情况核查
- 个人防护装备配备情况检查
- 出发前安全交底

**第二阶段：应急响应（T+00:20 - T+01:00）**

T+00:20 — 成立现场应急指挥部
- 指挥部人员到位
- 通讯系统建立
- 与上级应急指挥中心建立联系
- 确定指挥协调机制

T+00:25 — 信息研判与方案制定
- 汇总初步事故信息
- 调取事故地点GIS信息
- 分析污染物扩散趋势
- 制定初步处置方案
- 制定应急监测方案

T+00:30 — 先期处置力量到达现场
- 先遣组现场勘查
- 确认事故态势
- 评估人员安全状况
- 建立现场安全区域

T+00:40 — 现场处置展开
- 建立围堰/围栏控制泄漏物扩散
- 启动污染物收集系统
- 设置安全警戒区域
- 疏散受威胁区域人员

T+00:50 — 应急监测展开
- 按照监测方案布设监测点位
- 现场快速检测
- 送样至实验室分析
- 建立监测数据传送链路

**第三阶段：事态升级与深度处置（T+01:00 - T+02:30）**

T+01:00 — 首次事态研判通报
- 汇总监测数据
- 研判污染扩散趋势
- 评估对敏感目标的影响
- 做出决策：是否升级响应级别

T+01:15 — 如需升级响应
- 向上级请求支援
- 增调应急物资和装备
- 启动跨区域联动机制
- 通知受影响区域下游单位

T+01:30 — 深度处置
- 重点保护源和敏感目标的防护措施
- 污染物的源头控制与削减
- 污染物的收集与转运
- 次生灾害的防范

T+01:45 — 信息发布与舆情管理
- 编制新闻通稿
- 信息上报上级部门
- 回应社会关切
- 发布预警信息

T+02:00 — 第二次事态研判（中期评估）
- 持续监测数据分析
- 评估处置效果
- 研判后续趋势
- 调整处置方案

#### 场景名称：锑矿尾矿库泄漏引发涟水锑污染事件应急演练

##### 一、场景基本信息

| 要素 | 设定内容 |
|------|---------|

| 事故等级 | 重大（Ⅱ级）环境事件 |
| 模拟时间 | 2026年7月10日（周四）21:30（深夜，暴雨过后） |
| 模拟地点 | ××锑业有限公司尾矿库（位于涟水上游约30公里处） |
| 周围环境 | 尾矿库位于山谷中，下游连接涟水支流，最终汇入涟水干流 |
| 气象条件 | 暴雨过后，阴天，气温24℃，东北风2级，湿度85% |
| 水文条件 | 涟水干流流量约180m³/s（汛期）；支流流量约12m³/s |

##### 二、事故起因设定

受连续强降雨影响，××锑业有限公司尾矿库（四等库）副坝发生局部渗漏。由于巡查人员发现不及时，渗漏持续发展约6小时后形成约3米宽的溃口，含有高浓度锑的尾矿浆随渗水外泄，经冲沟流入涟水支流，进而汇入涟水干流。初步估算泄漏尾矿浆约5000立方米，对下游饮用水安全构成严重威胁。

##### 三、关键参数

- 尾矿库库容：120万m³
- 尾矿渣成分：主要含锑（Sb），少量砷（As）、铅（Pb）
- 尾矿浆中锑浓度：约15-30mg/L
- 泄漏总量：约5000m³尾矿浆（含锑约75-150kg）
- 外泄路径：尾矿库→冲沟（约2km）→涟水支流（约8km）→涟水干流
- 下游敏感目标：距事故点下游约35公里处为某市饮用水水源地取水口（服务人口约30万）
- 下游36小时将到达取水口（水流速度约0.5m/s）
- 锑超标浓度预估（到达取水口时）：约0.010-0.030mg/L（饮用水标准0.005mg/L）

## 第三部分：方案编制注意事项

### 一、方案编制的常见问题

1. **目的过于空泛**：使用"提高应急能力""加强协调能力"等空泛表述，缺乏可量化指标
2. **场景设计缺乏针对性**：套用通用模板，不结合本区域实际风险特征
3. **流程过于简化**：缺少足够的情景注入和决策节点，演练变成走过场
4. **角色分配不明确**：职责描述模糊，出现"相关单位""有关部门"等模糊表述
5. **评估标准缺乏操作性**：评分标准定性化严重，无法客观评分
6. **安全方案缺位**：完全忽视安全风险评估，或安全方案过于笼统
7. **保障措施不落实**：只列项目不列预算，或预算不切实际
8. **缺乏可追溯性**：演练关键环节无记录安排

### 二、方案编制的成功关键

1. **场景驱动**：好的场景是成功演练的一半，场景设计应真实、合理、有层次
2. **角色明确**：每个参与人员清楚自己"在什么时间做什么事"
3. **节奏合理**：张弛有度，既有紧张环节也有缓冲时间
4. **问题导向**：聚焦于发现和改进问题，而非单纯展示能力
5. **评估前置**：在方案阶段就明确评估标准和具体指标
6. **安全第一**：安全方案应作为附件专章纳入方案
7. **预案对接**：演练方案应与实际应急预案对接，不留偏差
