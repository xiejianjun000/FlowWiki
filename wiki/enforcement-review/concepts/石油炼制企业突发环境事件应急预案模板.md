# 石油炼制企业突发环境事件应急预案模板

## 应急预案编制说明

本预案依据《突发环境事件应急预案管理办法》《企业事业单位突发环境事件应急预案编制导则》（HJ 941-2018）、《石油炼制工业污染物排放标准》（GB 31570-2015）等法规标准，结合石油炼制企业特点编制。

---

## 第一章 总则

### 1.1 编制目的
- 规范石油炼制企业突发环境事件应急处置程序
- 提高应急处置能力，最大程度减少环境污染损害
- 防止原油、成品油及化学品泄漏造成环境污染
- 保护周边生态环境和公众健康安全

### 1.2 编制依据
- 《中华人民共和国环境保护法》
- 《中华人民共和国突发事件应对法》
- 《中华人民共和国安全生产法》
- 《中华人民共和国水污染防治法》
- 《中华人民共和国大气污染防治法》
- 《中华人民共和国固体废物污染环境防治法》
- 《中华人民共和国土壤污染防治法》
- 《海洋环境保护法》
- 《突发环境事件应急预案管理办法》
- 《企业事业单位突发环境事件应急预案编制导则》（HJ 941-2018）
- 《建设项目环境风险评价技术导则》（HJ 169-2018）
- 《危险化学品安全管理条例》
- 《石油炼制工业污染物排放标准》（GB 31570-2015）
- 《石油化学工业污染物排放标准》（GB 31571-2015）

### 1.3 适用范围
本预案适用于本企业原油接收、储存、炼制、成品油出厂等过程中发生的可能造成环境污染的突发事件。

### 1.4 应急预案体系
- 综合应急预案（本预案）
- 专项应急预案（原油泄漏、成品油泄漏、火灾爆炸、废气事故排放等）
- 现场处置方案（各装置、罐区、码头等岗位应急处置措施）

### 1.5 工作原则
- 以人为本，安全第一
- 预防为主，平战结合
- 统一领导，分级负责
- 快速反应，协同应对
- 依法规范，科学处置
- 全过程管控，防止次生污染

### 3.3 风险类型
1. **原油/成品油泄漏**：储罐、管道、装卸过程泄漏污染土壤、水体（海洋）
2. **火灾爆炸**：油品蒸气遇火源发生火灾爆炸
3. **有毒气体泄漏**：硫化氢、氨等有毒气体泄漏造成人员中毒
4. **废气事故排放**：装置故障或火炬燃烧不完全导致废气超标
5. **废水事故排放**：废水处理设施故障导致超标废水排放
6. **危废泄漏**：危废暂存、处置过程泄漏

## 第七章 应急响应

### 7.1 响应分级
- **Ⅰ级响应**（特别重大）：储罐区火灾爆炸、大量油品泄漏入水体、装置重大事故
- **Ⅱ级响应**（重大）：油品泄漏、有毒气体泄漏、装置故障
- **Ⅲ级响应**（较大）：局部泄漏、设施故障
- **Ⅳ级响应**（一般）：轻微泄漏、隐患

### 7.2 响应程序
1. 发现事件 → 报告中控室/值班人员
2. 中控室初步判断 → 报告应急指挥部
3. 启动应急响应 → 通知各应急小组
4. 现场处置 → 监测评估
5. 事态控制 → 终止响应

### 7.3 信息报告与通报
#### 7.3.1 内部报告
- 报告时限：立即（不超过5分钟）
- 报告对象：应急指挥部
- 报告内容：事件时间、地点、类型、规模、初步原因

#### 7.3.2 外部报告
- 报告时限：1小时内
- 报告对象：当地生态环境部门、应急管理部门
- 涉水事件还需报告海事部门
- 报告内容：企业信息、事件概况、油品种类和数量、泄漏量、影响范围、已采取措施

### 7.4 现场处置措施

#### 7.4.1 原油/成品油泄漏处置
1. **人员防护**：穿戴防毒面具、防化服、防静电服
2. **切断源**：关闭阀门、停泵、堵漏
3. **火源控制**：切断周边电源、禁止明火、消除静电
4. **隔离警戒**：
   - 小量泄漏：警戒30m
   - 大量泄漏：警戒100m以上
5. **泄漏控制**：
   - 用砂土围堵，防止流入下水道、水体
   - 用泡沫覆盖减少蒸发
   - 用泵抽吸转移
6. **清理**：用吸附材料收集，残液用砂土吸收
7. **废物处置**：收集的污染物按危废处置
8. **监测**：监测可燃气体浓度、TVOC、水质

#### 7.4.2 油品火灾处置
1. **报警**：拨打119
2. **疏散**：疏散周边人员至上风向
3. **冷却降温**：用消防水冷却着火罐和相邻罐
4. **泡沫灭火**：使用抗溶性泡沫灭火
5. **防止扩散**：
   - 筑围堰收集消防废水
   - 防止油品和废水流入水体
   - 关闭雨水排放口
6. **监测**：监测大气SO2、NOx、VOCs、水质

#### 7.4.3 硫化氢泄漏处置
1. **人员防护**：穿戴正压式呼吸器、防化服
2. **隔离警戒**：泄漏点周围500m警戒
3. **疏散**：疏散下风向人员
4. **切断源**：关闭阀门、隔离泄漏源
5. **稀释**：用喷雾水稀释泄漏气体
6. **监测**：监测H2S浓度，确认安全后方可进入
7. **急救**：中毒人员立即移至空气新鲜处，立即送医

#### 7.4.4 装置事故废气排放处置
1. **紧急停车**：启动装置紧急停车程序
2. **物料转移**：将系统物料转移至安全位置
3. **火炬处理**：将可燃气体引入火炬燃烧
4. **排查故障**：检查废气处理设施故障原因
5. **应急处理**：修复设施，调整工艺
6. **监测**：监测烟气排放浓度、厂界污染物

#### 7.4.5 废水事故排放处置
1. **立即切断**：关闭排放口阀门
2. **切换应急池**：将废水引入事故应急水池
3. **排查故障**：检查废水处理设施故障原因
4. **应急处理**：投加药剂、调整工艺
5. **监测**：监测排放口污染物浓度

#### 7.4.6 水域油品污染处置
1. **报警**：立即报告海事部门、生态环境部门
2. **控制源头**：切断泄漏源
3. **水面围控**：
   - 布设围油栏
   - 控制油膜扩散
4. **水面回收**：
   - 用收油机回收浮油
   - 用吸油材料吸附
5. ** shoreline保护**：保护敏感岸线
6. **监测**：监测水质石油类浓度

### 7.5 现场监测
- 大气：可燃气体、H2S、VOCs、SO2、NOx
- 水体：石油类、COD、挥发酚
- 监测点位：泄漏点、厂界、敏感目标、水体
- 监测频次：初始每15分钟，趋于稳定后每2小时
- 监测方法：便携式仪器、在线监测、实验室分析

### 7.6 安全防护
- 应急人员防护：正压式呼吸器、防化服、防静电服
- 疏散路线：沿上风向撤离
- 安全距离：
  - 油品火灾≥1000m
  - H2S泄漏≥500m
  - 其他泄漏≥100m

### 7.7 应急终止
- 终止条件：污染源消除、环境监测达标、现场清理完毕
- 终止决定：总指挥决定
- 终止程序：通知各小组 → 现场清理 → 总结评估

### 附录4：常用油品/化学品应急处置方法

#### 原油
- **特性**：易燃、毒性（含H2S、VOCs）
- **泄漏处理**：
  - 切断火源
  - 用砂土围堵，防止流入下水道、水体
  - 用泡沫覆盖减少蒸发
  - 用泵抽吸转移
- **禁忌**：禁止接触明火、强氧化剂
- **急救**：移至空气新鲜处，皮肤接触用肥皂水冲洗

#### 汽油
- **特性**：易燃易爆
- **泄漏处理**：
  - 切断火源
  - 用砂土围堵
  - 用泡沫覆盖
  - 收集至密封容器
- **禁忌**：禁止接触明火

#### 硫化氢（H2S）
- **特性**：剧毒、易燃
- **泄漏处理**：
  - 穿戴正压式呼吸器
  - 隔离泄漏区500m
  - 用喷雾水稀释
  - 通风
- **急救**：立即移至空气新鲜处，立即送医，吸氧

#### 苯
- **特性**：易燃、致癌
- **泄漏处理**：
  - 切断火源
  - 穿戴防毒面具、防化服
  - 用砂土围堵
  - 用活性炭吸附
- **急救**：移至空气新鲜处，皮肤接触用清水冲洗
