# 企业温室气体排放核算与报告要求 总则

**文件编号**：GB/T 32150-2024
**发布单位**：国家市场监督管理总局、国家标准化管理委员会
**实施日期**：2024年7月1日
**代替标准**：GB/T 32150-2015

---

## 一、范围

本标准规定了企业温室气体排放核算与报告的术语和定义、核算原则、核算边界、核算方法、数据质量管理、报告内容和格式等通用要求。

本标准适用于企业温室气体排放的核算与报告，包括直接排放和间接排放。

本标准不适用于：
- 生物质燃烧产生的温室气体排放（另行规定）
- 土地利用、土地利用变化和林业（LULUCF）相关的温室气体排放与清除
- 产品全生命周期温室气体排放核算（参见GB/T 24067）

## 三、术语和定义

### 3.1 温室气体 greenhouse gas, GHG

大气中吸收和重新放出红外辐射的自然和人为的气态成分，包括二氧化碳（CO₂）、甲烷（CH₄）、氧化亚氮（N₂O）、氢氟碳化物（HFCs）、全氟化碳（PFCs）、六氟化硫（SF₆）和三氟化氮（NF₃）。

### 3.2 温室气体排放 greenhouse gas emission

将温室气体释放到大气中的过程。

### 3.3 直接排放 direct emission

来自报告企业拥有或控制的排放源的温室气体排放，也称为范围1排放。

### 3.4 间接排放 indirect emission

报告企业活动引起的，但发生在其他企业拥有或控制的排放源的温室气体排放。

### 3.5 范围1排放 scope 1 emission

见直接排放（3.3）。

### 3.6 范围2排放 scope 2 emission

报告企业外购电力、蒸汽、热力或冷力产生的温室气体排放。

### 3.7 范围3排放 scope 3 emission

除范围2排放之外的所有间接排放，是报告企业活动的结果，但发生在非报告企业拥有或控制的排放源。

### 3.8 温室气体排放因子 greenhouse gas emission factor

将活动数据与温室气体排放量相关联的系数。

### 3.9 活动数据 activity data

导致温室气体排放或清除的人类活动水平的度量值。

### 3.10 全球变暖潜势 global warming potential, GWP

将单位质量的某种温室气体在给定时间段内辐射强迫的影响与等量二氧化碳辐射强迫影响相关联的系数。

### 3.11 二氧化碳当量 carbon dioxide equivalent, CO₂e

在辐射强迫上与某种温室气体质量相当的二氧化碳的质量。

### 3.12 氧化率 oxidation factor, OF

燃料燃烧过程中被氧化的碳的比例，以质量分数表示。

### 3.13 碳含量 carbon content

单位燃料或物料中含有的碳的质量。

## 四、核算原则

企业进行温室气体排放核算与报告，应遵循以下原则：

### 4.1 相关性

选择的核算方法、排放因子和数据应与企业的温室气体排放源相适应，能够真实反映企业的温室气体排放情况。

### 4.2 完整性

核算应覆盖报告边界内所有的温室气体排放源和排放类型，不得遗漏。

### 4.3 一致性

核算方法和数据来源在不同报告期应保持一致，以确保排放数据的可比性。

### 4.4 准确性

核算结果应尽可能准确，减少不确定性，避免系统性偏差。

### 4.5 透明性

核算过程和数据应可核查，相关假设、方法和数据来源应予以披露。

### 4.6 成本效益

在保证核算质量的前提下，应考虑核算成本与核算结果准确性之间的平衡。

## 五、核算边界

### 5.1 组织边界

企业应确定其温室气体排放核算的组织边界，即哪些业务单元、设施或活动纳入核算范围。

组织边界的确定应采用以下方法之一：

#### 5.1.1 股权比例法

按照企业在各业务单元中拥有的股权比例，核算对应的温室气体排放。

#### 5.1.2 控制权法

核算企业拥有控制权的所有业务单元的温室气体排放。控制权包括：
- 财务控制权：企业能够决定该业务单元的财务和经营政策
- 运营控制权：企业有权决定该业务单元的运营政策

**注**：推荐采用控制权法确定组织边界。

### 5.2 运行边界

运行边界包括企业的直接排放（范围1）和间接排放（范围2和范围3）。

#### 5.2.1 范围1：直接排放

1. **固定燃烧排放**：固定燃烧设备（如锅炉、熔炉、加热炉、燃气轮机等）燃烧化石燃料产生的排放
2. **移动燃烧排放**：企业拥有或控制的移动源（如车辆、船舶、飞机等）燃烧化石燃料产生的排放
3. **工艺过程排放**：工业生产过程中发生的物理或化学反应产生的排放
4. **逸散排放**：设备密封不严、系统泄漏、废物处理等产生的无组织排放

#### 5.2.2 范围2：外购能源间接排放

1. **外购电力排放**：企业外购电力产生的排放
2. **外购蒸汽排放**：企业外购蒸汽产生的排放
3. **外购热力排放**：企业外购热力产生的排放
4. **外购冷力排放**：企业外购冷力产生的排放

#### 5.2.3 范围3：其他间接排放（可选报告）

1. 上游排放：原材料开采、生产和运输排放
2. 下游排放：产品使用、废弃处理排放
3. 员工差旅、通勤排放
4. 租赁资产排放
5. 外包服务排放
6. 投资排放等

### 5.3 时间边界

核算周期应为完整的日历年（1月1日至12月31日），或企业的财务年度。首次核算可采用不少于6个月的时间段。

## 六、核算方法

### 6.1 核算方法选择

企业应根据排放源特点、数据可得性和核算精度要求，选择合适的核算方法：

| 方法层级 | 方法类型 | 精度 | 适用场景 |
|---------|---------|------|---------|
| 方法一 | 实测法 | 高 | 有连续监测系统（CEMS）或定期检测数据 |
| 方法二 | 物料平衡法 | 中高 | 有完整的物料计量数据 |
| 方法三 | 排放因子法 | 中 | 有活动数据和可靠的排放因子 |
| 方法四 | 估算法 | 低 | 数据缺乏的小型排放源 |

**注**：应优先选用精度高的方法，不同排放源可采用不同方法。

### 6.2 通用核算公式

#### 6.2.1 单种温室气体排放量

```
E_GHG = AD × EF
```

其中：
- `E_GHG`：某类温室气体排放量，单位：吨（t）
- `AD`：活动数据，单位根据排放源类型确定
- `EF`：排放因子，单位根据排放源类型确定

#### 6.2.2 二氧化碳当量排放量

```
E_CO₂e = Σ (E_GHG,i × GWP_i)
```

其中：
- `E_CO₂e`：二氧化碳当量排放量，单位：吨CO₂当量（tCO₂e）
- `E_GHG,i`：第i种温室气体的排放量，单位：吨（t）
- `GWP_i`：第i种温室气体的全球变暖潜值（100年时间尺度）

### 6.3 全球变暖潜值（GWP）

采用IPCC第六次评估报告（AR6）公布的100年时间尺度GWP值：

| 温室气体 | 化学式 | GWP（100年） |
|---------|-------|-------------|
| 二氧化碳 | CO₂ | 1 |
| 甲烷 | CH₄ | 28 |
| 氧化亚氮 | N₂O | 265 |
| 氢氟碳化物 | HFCs | 124-14 800 |
| 全氟化碳 | PFCs | 7 390-12 200 |
| 六氟化硫 | SF₆ | 23 500 |
| 三氟化氮 | NF₃ | 16 100 |

### 6.4 主要排放源核算方法

#### 6.4.1 固定燃烧排放

**方法一：元素碳含量法（推荐）**

```
E_燃烧 = Σ (FC_i × C_ar,i × OF_i × 44/12)
```

其中：
- `FC_i`：第i种化石燃料的消耗量，单位：吨（t）或万标立方米（10⁴Nm³）
- `C_ar,i`：第i种化石燃料的收到基元素碳含量，单位：吨碳/吨燃料（tC/t）或吨碳/万标立方米（tC/10⁴Nm³）
- `OF_i`：第i种化石燃料的碳氧化率，单位：%
- `44/12`：碳转化为二氧化碳的系数

**方法二：低位发热量法**

```
E_燃烧 = Σ (FC_i × NCV_i × EF_i)
```

其中：
- `NCV_i`：第i种化石燃料的低位发热量，单位：吉焦/吨（GJ/t）或吉焦/万标立方米（GJ/10⁴Nm³）
- `EF_i`：第i种化石燃料的单位热值含碳量，单位：吨碳/吉焦（tC/GJ）

#### 6.4.2 移动燃烧排放

```
E_移动 = Σ (FC_j × EF_j)
```

其中：
- `FC_j`：第j种移动源燃料消耗量，单位：吨（t）或升（L）
- `EF_j`：第j种移动源燃料的排放因子，单位：吨CO₂/吨燃料（tCO₂/t）或吨CO₂/升（tCO₂/L）

#### 6.4.3 工艺过程排放

根据不同行业工艺特点选择核算方法，典型方法包括：

**物料平衡法：**
```
E_工艺 = Σ (物料投入量 × 含碳量 - 产品含碳量 - 废物含碳量) × 44/12
```

**排放因子法：**
```
E_工艺 = Σ (产品产量 × EF_产品)
```

#### 6.4.4 逸散排放

```
E_逸散 = Σ (排放源数量 × EF_逸散,i)
```

其中：
- `EF_逸散,i`：第i类逸散排放源的排放因子

#### 6.4.5 外购电力排放

```
E_电力 = EC × EF_电力
```

其中：
- `EC`：外购电力消耗量，单位：兆瓦时（MWh）
- `EF_电力`：电力排放因子，单位：吨CO₂/兆瓦时（tCO₂/MWh）

#### 6.4.6 外购蒸汽/热力排放

```
E_蒸汽 = HS × EF_蒸汽
```

其中：
- `HS`：外购蒸汽/热力消耗量，单位：吉焦（GJ）
- `EF_蒸汽`：蒸汽/热力排放因子，单位：吨CO₂/吉焦（tCO₂/GJ）

## 七、数据质量管理

### 7.1 数据来源分类

| 数据类型 | 优先级 | 来源说明 |
|---------|-------|---------|
| 一级数据 | 最高 | 企业实测数据（CEMS、实验室检测、计量仪表等） |
| 二级数据 | 高 | 企业台账记录、生产报表、购售合同等 |
| 三级数据 | 中 | 行业平均数据、供应商数据、工程测算数据 |
| 四级数据 | 低 | IPCC默认值、国家/地区发布的排放因子 |

### 7.2 数据质量要求

#### 7.2.1 准确性

- 计量器具应符合国家计量法规要求，定期检定/校准
- 检测方法应符合相关国家标准或行业标准
- 数据记录应真实、完整、可追溯

#### 7.2.2 完整性

- 核算边界内所有排放源的数据应齐全
- 缺失数据应有合理的替代方案和说明
- 数据记录应保存不少于5年

#### 7.2.3 一致性

- 核算方法在不同报告期应保持一致
- 数据来源和计算方法应保持一致
- 如发生方法变更，应予以说明并量化影响

#### 7.2.4 可验证性

- 数据应有原始记录支持
- 计算过程可重复、可验证
- 关键参数和假设应清晰披露

### 7.3 不确定性评估

企业应识别主要排放源和关键参数的不确定性来源，采用定性或定量方法评估不确定性：

**不确定性来源包括：**
- 测量误差
- 采样偏差
- 排放因子代表性
- 假设条件
- 数据缺失

**不确定性等级划分：**

| 不确定性等级 | 相对不确定度范围 | 说明 |
|-------------|----------------|------|
| 低 | ≤±10% | 数据质量高，方法成熟 |
| 中 | ±10%~±30% | 数据质量较好，有一定不确定性 |
| 高 | >±30% | 数据质量较差，不确定性较大 |

### 7.4 数据质量控制措施

1. 建立温室气体数据管理制度和台账
2. 配备专业的核算人员并定期培训
3. 建立数据内部审核机制
4. 定期校准计量设备
5. 保存原始记录和计算过程文件
6. 对缺失数据采用保守估计并记录说明

## 八、报告内容和格式

### 8.1 报告基本信息

企业温室气体排放报告应至少包括以下内容：

#### 8.1.1 报告主体信息

- 企业名称、统一社会信用代码、法定代表人
- 注册地址、生产经营地址
- 所属行业、主要产品
- 报告联系人及联系方式

#### 8.1.2 报告说明

- 报告周期
- 核算边界说明（组织边界、运行边界）
- 核算方法说明
- 排放因子来源说明
- 与上一年度的变化说明（如适用）

### 8.2 排放数据

#### 8.2.1 排放总量

- 温室气体排放总量（tCO₂e）
- 范围1排放量（tCO₂e）
- 范围2排放量（tCO₂e）
- 范围3排放量（如有，tCO₂e）

#### 8.2.2 分排放源排放量

按排放源类别详细列出排放量，包括：
- 固定燃烧排放（分燃料类型）
- 移动燃烧排放（分燃料类型）
- 工艺过程排放（分工艺类型）
- 逸散排放（分排放源类型）
- 外购电力排放
- 外购蒸汽/热力排放

#### 8.2.3 分温室气体排放量

列出每种温室气体的排放量及CO₂当量：
- CO₂排放量
- CH₄排放量及CO₂当量
- N₂O排放量及CO₂当量
- HFCs排放量及CO₂当量
- PFCs排放量及CO₂当量
- SF₆排放量及CO₂当量

| 外购电力 | XXX | MWh | XXX | tCO₂/MWh | 区域电网 |

### 8.4 补充信息

- 数据质量评估
- 不确定性分析
