**文件编号**：CETS—AG—00.01—V02—2024
**发布单位**：生态环境部
**实施日期**：2024年3月1日
**代替版本**：V01—2022

## 一、适用范围

本指南规定了工业企业温室气体排放核算与报告的通用方法、技术要求和报告格式。

本指南适用于化工、建材、钢铁、有色、造纸、电力、航空等行业以外的工业企业温室气体排放核算与报告工作。已发布行业核算指南的，优先执行行业指南。

### 1.1 适用主体

- 年综合能源消费量1万吨标准煤及以上的工业企业
- 纳入全国或地方碳排放权交易市场的工业企业
- 自愿开展温室气体排放核算的工业企业

### 1.2 核算的温室气体种类

本指南核算的温室气体包括：
- 二氧化碳（CO₂）
- 甲烷（CH₄）
- 氧化亚氮（N₂O）

### 1.3 不适用范围

- 土地利用、土地利用变化和林业（LULUCF）活动的排放与清除
- 产品碳足迹核算
- 生物质燃烧产生的CO₂排放（单独统计，不计入排放总量）

## 三、术语和定义

### 3.1 工业企业 industrial enterprise

从事工业生产经营活动的经济实体。

### 3.2 标准煤 standard coal equivalent, SCE

热值为29307 kJ/kg（即7000 kcal/kg）的能源计量单位。

### 3.3 低位发热量 net calorific value, NCV

燃料完全燃烧，其燃烧产物中的水蒸气仍以气态存在时，单位数量燃料所释放的热量。

### 3.4 收到基 as received basis, ar

以收到状态的燃料为基准，即包含水分和灰分的燃料。

### 3.5 排放因子 emission factor

单位活动水平对应的温室气体排放量。

### 3.6 物料平衡 material balance

根据质量守恒定律，对生产过程中的物料投入和产出进行平衡核算的方法。

### 3.7 活动数据 activity data

导致温室气体排放的生产或消费活动水平的量化数据，如燃料消耗量、产品产量等。

### 3.8 碳氧化率 carbon oxidation rate, OF

燃料燃烧过程中被氧化成二氧化碳的碳占总碳的比例，以质量分数表示。

## 四、核算边界

### 4.1 组织边界

工业企业应以企业法人或视同法人单位为核算主体，核算其拥有或控制的所有生产设施的温室气体排放。

采用**控制权法**确定组织边界：
- **运营控制权**：企业有权决定该设施的运营政策
- **财务控制权**：企业能够决定该设施的财务和经营政策

同一企业的多个生产设施（含分厂、分公司）应合并核算。

### 4.2 运行边界

运行边界包括直接排放（范围1）和间接排放（范围2）。

#### 4.2.1 范围1：直接排放

1. **固定燃烧排放**
   - 锅炉、窑炉、加热炉、热处理炉等固定燃烧设备燃烧化石燃料产生的CO₂排放
   - 备用发电机燃烧化石燃料产生的CO₂排放

2. **移动燃烧排放**
   - 企业拥有或控制的载货汽车、通勤车辆、叉车、工程机械等移动源燃烧化石燃料产生的CO₂排放
   - 厂内铁路机车、船舶等移动源排放

3. **工艺过程排放**
   - 工业生产过程中的物理或化学反应产生的CO₂、CH₄、N₂O排放
   - 碳酸盐分解、熔铸、电解等过程排放
   - 特定工艺过程的逸散排放

4. **逸散排放**
   - 气体燃料输送、储存过程中的泄漏排放
   - 制冷剂、灭火剂等含氟气体泄漏排放
   - 废水和固体废物处理产生的CH₄排放

#### 4.2.2 范围2：间接排放

1. **外购电力排放**
   - 企业外购电力产生的CO₂排放

2. **外购蒸汽排放**
   - 企业外购蒸汽/热水产生的CO₂排放

3. **外购热力排放**
   - 企业外购热力产生的CO₂排放（若与蒸汽分开计量）

### 4.3 设施边界

工业企业温室气体排放核算应覆盖以下设施：

| 设施类别 | 主要设施 | 排放类型 |
|---------|---------|---------|
| 生产系统 | 生产装置、窑炉、反应釜、生产线等 | 燃烧排放、工艺排放 |
| 辅助生产系统 | 锅炉房、空压站、制冷站、循环水系统等 | 燃烧排放、电力间接排放 |
| 附属生产系统 | 办公建筑、科研楼、食堂、宿舍等 | 燃烧排放、电力间接排放 |
| 移动源 | 厂内车辆、工程机械等 | 移动燃烧排放 |
| 环保设施 | 脱硫脱硝、污水处理、危废处理等 | 工艺排放、逸散排放 |

### 4.4 时间边界

- 核算周期为完整的日历年（1月1日至12月31日）
- 新投产企业可按实际生产天数核算
- 停产、减产企业应按实际运行天数核算，并在报告中说明

## 五、核算方法

### 5.1 核算总公式

```
E_total = E_scope1 + E_scope2
```

其中：
- `E_total`：温室气体排放总量，单位：吨CO₂当量（tCO₂e）
- `E_scope1`：范围1直接排放量，单位：tCO₂e
- `E_scope2`：范围2间接排放量，单位：tCO₂e

范围1排放计算公式：
```
E_scope1 = E_燃烧 + E_工艺 + E_移动 + E_逸散
```

范围2排放计算公式：
```
E_scope2 = E_电力 + E_蒸汽
```

### 5.2 固定燃烧排放核算

#### 5.2.1 计算方法

**方法一：元素碳含量法（推荐，精确度高）**

```
E_燃烧 = Σ (FC_i × C_ar,i × OF_i × 44/12)
```

其中：
- `FC_i`：第i种化石燃料的消耗量，单位：吨（t）或万标立方米（10⁴Nm³）
- `C_ar,i`：第i种化石燃料的收到基元素碳含量，单位：tC/t或tC/10⁴Nm³
- `OF_i`：第i种化石燃料的碳氧化率，单位：%
- `44/12`：碳转化为二氧化碳的系数（CO₂/C分子量比）

**方法二：低位发热量法**

```
E_燃烧 = Σ (FC_i × NCV_i × EF_单位热值,i)
```

其中：
- `NCV_i`：第i种化石燃料的低位发热量，单位：GJ/t或GJ/10⁴Nm³
- `EF_单位热值,i`：第i种化石燃料的单位热值CO₂排放因子，单位：tCO₂/GJ

#### 5.2.2 燃料消耗量确定

燃料消耗量应优先采用企业计量数据，按以下优先级确定：

| 优先级 | 数据来源 | 要求 |
|-------|---------|------|
| 1 | 企业能源计量台账 | 符合GB 17167要求 |
| 2 | 燃料购入结算单/发票 | 按购入量扣除库存量变化 |
| 3 | 生产报表统计数据 | 应有相关记录支持 |
| 4 | 估算数据 | 需说明估算方法和依据 |

**消耗量计算公式：**
```
燃料消耗量 = 期初库存量 + 本期购入量 - 期末库存量 - 外售量
```

#### 5.2.3 元素碳含量确定

收到基元素碳含量按以下优先级确定：

| 优先级 | 数据来源 | 检测频率要求 |
|-------|---------|-------------|
| 1 | 企业每批次实测值 | 每批次燃料检测1次 |
| 2 | 每月实测平均值 | 每月不少于1次检测 |
| 3 | 供应商提供的检测报告 | 每季度不少于1次 |
| 4 | 行业/地方发布的平均缺省值 | 按指南附录取值 |

#### 5.2.4 碳氧化率缺省值

| 燃料类型 | 碳氧化率（%） | 适用条件 |
|---------|--------------|---------|
| 煤炭 | 93 | 一般工业锅炉 |
| 焦炭 | 93 | 工业窑炉 |
| 原油及石油制品 | 98 | 各类燃烧设备 |
| 天然气 | 99 | 燃气锅炉/窑炉 |
| 液化石油气 | 98 | 燃气设备 |
| 其他气体燃料 | 99 | 燃气设备 |

### 5.3 移动燃烧排放核算

```
E_移动 = Σ (FC_j × EF_j)
```

其中：
- `FC_j`：第j种移动源燃料消耗量，单位：吨（t）或升（L）
- `EF_j`：第j种移动源燃料的CO₂排放因子，单位：tCO₂/t或tCO₂/L

#### 移动源燃料消耗量确定方法

| 移动源类型 | 推荐方法 | 数据来源 |
|-----------|---------|---------|
| 厂内机动车 | 加油量法 | 车辆加油台账/油卡记录 |
| 自有车辆 | 里程法/加油量法 | 行驶里程×油耗率 |
| 工程机械 | 油耗法 | 燃料消耗台账 |
| 铁路机车 | 燃料消耗量 | 燃料台账 |

#### 移动源排放因子参考值

| 燃料类型 | 排放因子 | 单位 |
|---------|---------|------|
| 汽油 | 2.925 | tCO₂/t |
| 柴油 | 3.096 | tCO₂/t |
| 液化石油气 | 2.950 | tCO₂/t |
| 天然气 | 2.162 | tCO₂/10³m³ |

### 5.4 工艺过程排放核算

工艺过程排放因行业和工艺差异较大，企业应根据自身工艺特点选择合适的核算方法。

#### 5.4.1 方法一：物料平衡法

适用于有完整物料计量数据的生产过程：

```
E_工艺 = Σ [ (投入物料含碳量 - 产出产品含碳量 - 废物含碳量 - 回收碳量) × 44/12 ]
```

**适用场景：**
- 碳酸盐分解过程（水泥、石灰、玻璃等）
- 金属冶炼过程（钢铁、有色等）
- 化工生产过程

#### 5.4.2 方法二：排放因子法

适用于缺乏详细物料数据的生产过程：

```
E_工艺 = Σ (产品产量 × EF_产品)
```

**适用场景：**
- 产量数据可靠但物料计量不全
- 工艺排放与产品产量直接相关

#### 5.4.3 常见工艺过程排放因子参考

| 工艺过程 | 排放因子 | 单位 | 温室气体 |
|---------|---------|------|---------|
| 水泥熟料生产 | 0.538 | tCO₂/t熟料 | CO₂ |
| 石灰生产 | 0.785 | tCO₂/t石灰 | CO₂ |
| 玻璃生产 | 0.25 | tCO₂/t玻璃 | CO₂ |
| 合成氨生产 | 1.5 | tCO₂/t氨 | CO₂ |
| 硝酸生产 | 8.5 | kgN₂O/t硝酸 | N₂O |
| 己二酸生产 | 30 | kgN₂O/t己二酸 | N₂O |
| 铝电解生产 | 0.8 | kgCF₄/t铝 | PFCs |

### 5.5 逸散排放核算

#### 5.5.1 化石燃料逸散排放

```
E_逸散_燃料 = Σ (年周转量 × EF_逸散,i)
```

| 燃料类型 | 排放因子 | 单位 |
|---------|---------|------|
| 天然气输送 | 0.004 | tCH₄/t |
| 液化石油气储存 | 0.002 | tCH₄/t |

#### 5.5.2 废水处理CH₄排放

```
E_CH₄_废水 = (OC × B₀ × MCF - R) × GWP_CH₄
```

其中：
- `OC`：废水中有机物总量，单位：吨COD/年
- `B₀`：最大产甲烷潜势，缺省值0.25 kgCH₄/kgCOD
- `MCF`：甲烷修正系数（根据处理方式确定）
- `R`：回收的甲烷量，单位：tCH₄/年
- `GWP_CH₄`：甲烷GWP值，取28

#### 5.5.3 固体废物处理CH₄排放

```
E_CH₄_固废 = MSW × L₀ × MCF × (1 - OX) × (1 - R)
```

其中：
- `MSW`：固体废物产生量，单位：吨/年
- `L₀`：垃圾填埋场单位废物甲烷产生潜势，缺省值0.10 tCH₄/t
- `MCF`：甲烷修正系数
- `OX`：氧化因子，缺省值0.1
- `R`：甲烷回收比例

### 5.6 间接排放核算

#### 5.6.1 外购电力排放

```
E_电力 = EC × EF_电力
```

其中：
- `EC`：企业外购电力消耗量，单位：兆瓦时（MWh）
- `EF_电力`：电力CO₂排放因子，单位：tCO₂/MWh

**电力排放因子取值：**
- 优先采用企业所在区域电网的年度平均排放因子
- 可采用生态环境部发布的全国碳市场电力排放因子
- 省级电网有独立公布排放因子的，可采用省级排放因子

#### 5.6.2 外购蒸汽/热力排放

```
E_蒸汽 = HS × EF_蒸汽
```

其中：
- `HS`：外购蒸汽/热力消耗量，单位：吉焦（GJ）
- `EF_蒸汽`：蒸汽/热力排放因子，单位：tCO₂/GJ

**蒸汽排放因子确定：**
- 有热力供应企业排放数据的，按实际排放核算
- 无法获取实际数据的，采用缺省值0.11 tCO₂/GJ

## 六、数据质量管理

### 6.1 数据分类及优先级

| 数据类别 | 一级（优先） | 二级 | 三级 | 四级 |
|---------|------------|------|------|------|
| 活动数据 | 计量实测 | 台账记录 | 统计报表 | 估算值 |
| 排放因子 | 企业实测 | 供应商提供 | 行业平均 | IPCC缺省 |

### 6.2 关键数据质量要求

#### 6.2.1 燃料消耗量数据

- 计量器具配备应符合GB 17167要求
- 一级能源计量器具配备率≥95%
- 二级能源计量器具配备率≥90%
- 数据记录保存不少于5年

#### 6.2.2 燃料元素碳含量检测

- 检测方法应符合GB/T 212、GB/T 476等标准要求
- 每批次燃料应进行元素分析
- 检测机构应具有CMA或CNAS资质
- 检测报告应包含收到基碳含量、氢含量、低位发热量等参数

#### 6.2.3 电力消耗量数据

- 以电网企业结算电量为准
- 自备电厂应单独计量
- 转供电量应扣除

### 6.3 数据缺失处理

数据缺失时，应按以下原则处理：

1. **短期缺失（≤1个月）**：采用同类型同期数据平均值
2. **中期缺失（1-3个月）**：采用年度平均值并保守估计
3. **长期缺失（>3个月）**：采用缺省值并在报告中说明
4. **关键数据缺失**：应在报告中明确披露不确定性等级

### 6.4 不确定性评估

#### 6.4.1 不确定性来源识别

| 类别 | 不确定性来源 | 影响程度 |
|-----|------------|---------|
| 活动数据 | 计量误差、读数偏差、记录错误 | 中-高 |
| 排放因子 | 燃料品质差异、检测误差、代表性不足 | 中 |
| 方法选择 | 方法假设、模型简化 | 低-中 |
| 数据缺失 | 替代数据偏差、估计不准 | 中-高 |

#### 6.4.2 整体不确定性评估

企业应对排放总量进行整体不确定性评估，可采用以下方法：
- 专家判断法（定性）
- 误差传播法（定量）
- 蒙特卡洛模拟法（定量，精确）

**不确定性等级划分：**

| 等级 | 相对不确定度 | 数据质量评价 |
|-----|-------------|-------------|
| 低 | ≤±10% | 良好 |
| 中 | ±10%~±30% | 一般 |
| 高 | >±30% | 较差，需改进 |

### 6.5 质量保证与质量控制（QA/QC）

企业应建立温室气体排放数据质量管理体系：

1. **组织保证**：指定责任部门和人员
2. **制度保证**：制定数据管理办法
3. **流程控制**：建立数据采集-审核-上报流程
4. **记录管理**：完整保存原始记录和计算过程
5. **定期核查**：每年至少开展1次内部核查
6. **人员培训**：相关人员接受专业培训

## 七、报告内容和格式

### 7.1 报告基本内容

工业企业温室气体排放报告应包括以下内容：

#### 7.1.1 报告主体基本信息
- 企业名称、统一社会信用代码
- 法定代表人、联系人及联系方式
- 注册地址、生产地址
- 所属行业、主要产品及产能
- 报告年度、报告编制日期

#### 7.1.2 核算边界说明
- 组织边界及确定方法
- 运行边界及排放源识别
- 纳入核算的设施清单
- 核算边界变更说明（如有）

#### 7.1.3 核算方法说明
- 各排放源采用的核算方法
- 排放因子选择及来源说明
- 关键假设及说明
