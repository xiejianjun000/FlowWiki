## 一、预案体系与事件分级

### 1.1 突发环境事件定义
由于污染物排放或自然灾害、生产安全事故等因素，导致污染物或放射性物质等有毒有害物质进入大气、水体、土壤等环境介质，突然造成或可能造成环境质量下降，危及公众身体健康和财产安全，或造成生态环境破坏，或造成重大社会影响，需要采取紧急措施予以应对的事件。

### 1.2 事件分级标准

| 级别 | 名称 | 伤亡/经济损失 | 副省级城市 | 地级市 |
|------|------|---------------|------------|--------|
| Ⅰ级 | 特别重大 | 30人以上死亡或100人以上中毒；直接经济损失1亿元以上 | 集中式饮用水水源地取水中断 | - |
| Ⅱ级 | 重大 | 10-30人死亡或50-100人中毒；直接经济损失2000万-1亿元 | 重点流域干流取水中断 | 集中式饮用水水源地取水中断 |
| Ⅲ级 | 较大 | 3-10人死亡或10-50人中毒；直接经济损失500-2000万元 | - | 重点流域取水中断 |
| Ⅳ级 | 一般 | 3人以下死亡或10人以下中毒；直接经济损失500万元以下 | - | - |

**注：** 娄底市为地级市，适用地级市标准。

### 1.3 不适用范围
- 辐射污染事件：按《娄底市辐射事故应急预案》执行
- 重污染天气：按《娄底市重污染天气应急预案》执行

## 二、组织指挥体系与职责

### 2.1 应急组织指挥机构

```
娄底市突发环境事件应急指挥部
          ↓
      总指挥（市政府分管副市长）
          ↓
      副总指挥（市政府副秘书长、市生态环境局局长）
          ↓
  ┌───────┼───────┬───────┬───────┐
  ↓       ↓       ↓       ↓       ↓
市生态环境局 市应急管理局 市公安局 市卫健委 市消防救援支队
（牵头单位） （协调）    （治安） （救治） （处置）
```

### 2.2 主要部门职责

| 部门 | 主要职责 |
|------|----------|
| **市生态环境局** | 牵头处置，开展应急监测，提出处置建议 |
| **市应急管理局** | 综合协调，启动市级应急响应 |
| **市公安局** | 治安管控，交通管制，人员疏散 |
| **市卫健委** | 医疗救治，卫生防疫 |
| **市消防救援支队** | 现场抢险，危险源控制 |
| **市气象局** | 提供气象数据，预警会商 |
| **市水利局** | 水资源调度，饮用水水源保护 |
| **市住建局** | 城镇污水处理，供水保障 |
| **市交通运输局** | 运输保障，交通疏导 |
| **市财政局** | 经费保障 |

### 2.3 专家组
- **组成：** 环境监测、应急处置、化学化工、水利、气象、法律等领域专家
- **职责：** 提供技术咨询，参与风险评估，提出处置建议

## 三、预防与预警机制

### 3.1 监测与风险分析

**监测网络：**
- 国控、省控、市控环境监测站点
- 企业自行监测数据
- 饮用水水源地监测
- 重点风险源在线监测

**风险分析内容：**
1. 风险源识别（企业、园区、敏感目标）
2. 风险物质种类、数量、分布
3. 可能受影响的水体、大气、土壤
4. 可能受影响的敏感目标（居民区、学校、医院等）

### 3.2 预警分级

| 级别 | 名称 | 颜色 | 启动条件 |
|------|------|------|----------|
| Ⅰ级 | 特别重大 | 红色 | 可能发生特别重大突发环境事件 |
| Ⅱ级 | 重大 | 橙色 | 可能发生重大突发环境事件 |
| Ⅲ级 | 较大 | 黄色 | 可能发生较大突发环境事件 |
| Ⅳ级 | 一般 | 蓝色 | 可能发生一般突发环境事件 |

### 3.3 预警发布与解除

**发布程序：**
1. 生态环境部门提出预警建议
2. 应急指挥部批准后发布
3. 通过广播、电视、短信、微信等渠道发布

**解除程序：**
1. 风险已消除或可控
2. 生态环境部门提出建议
3. 应急指挥部批准后解除

### 3.4 信息报告时限（重点！）

| 事件等级 | 报告时限 | 报告对象 |
|----------|----------|----------|
| **一般事件** | **3小时内** | 本级党委、政府 + 上一级生态环境部门 |
| **较大事件** | **30分钟内电话报告，60分钟内书面报告** | 省生态环境厅 + 本级党委、政府 |
| **重大/特别重大事件** | **30分钟内电话报告，60分钟内书面报告** | 省生态环境厅 + 生态环境部 + 本级党委、政府 |

**特殊情况升级报告：**
涉及以下情形，按高等级程序上报：
- 饮用水水源地
- 敏感人群（学校、医院、居民区）
- 重金属污染
- 跨界影响

**报告内容：**
1. 事件发生时间、地点
2. 事件类型、起因
3. 污染物种类、数量
4. 已造成的危害和潜在危害
5. 已采取的处置措施
6. 需要支援的事项

## 四、应急响应

### 4.1 响应分级

**分级原则：** 与事件分级对应

| 事件等级 | 响应等级 | 启动主体 |
|----------|----------|----------|
| 特别重大（Ⅰ级） | Ⅰ级响应 | 市级政府 + 请求省级支援 |
| 重大（Ⅱ级） | Ⅱ级响应 | 市级政府 |
| 较大（Ⅲ级） | Ⅲ级响应 | 市级政府 |
| 一般（Ⅳ级） | Ⅳ级响应 | 县市区政府 |

### 4.2 响应程序

```
事件发生后
    ↓
第一时间处置（企业/属地）
    ↓
信息报告（时限要求如上）
    ↓
启动相应级别响应
    ↓
成立现场指挥部
    ↓
开展应急处置
    ↓
应急监测
    ↓
信息公开
    ↓
响应终止
```

### 4.3 响应措施

**Ⅰ级、Ⅱ级响应措施：**
1. **切断污染源**
   - 关闭阀门、封堵管道
   - 构筑围堰、投放药剂
   - 转移危险品

2. **人员转移安置**
   - 疏散受影响群众
   - 设置安置点
   - 提供生活必需品

3. **应急监测**
   - 确定监测方案（点位、频次、项目）
   - 实时出具监测数据
   - 预测污染扩散趋势

4. **医学救援**
   - 救治中毒人员
   - 开展卫生防疫
   - 提供心理援助

5. **应急保障**
   - 调集应急队伍、物资、装备
   - 保障通信、交通
   - 提供经费支持

6. **维护社会稳定**
   - 治安管控
   - 交通管制
   - 谣言管控

7. **信息发布**
   - 召开新闻发布会
   - 及时发布事件进展
   - 回应社会关切

### 4.4 响应终止条件

1. 事件已得到有效控制
2. 污染源已切断
3. 次生、衍生事件风险已消除
4. 环境指标已恢复正常
5. 受影响群众已得到妥善安置

## 五、后期工作

### 5.1 损害评估
- **评估内容：** 环境污染程度、生态破坏程度、经济损失、社会影响
- **评估主体：** 生态环境部门牵头，相关部门参与
- **评估时限：** 响应终止后30个工作日内完成

### 5.2 善后处置
- 环境修复（水体、土壤、大气）
- 生态恢复（植被、湿地）
- 赔偿善后（受影响群众、企业）
- 保险理赔

### 5.3 总结评估
- **总结内容：** 事件经过、处置过程、经验教训、改进建议
- **总结时限：** 响应终止后40个工作日内完成
- **上报对象：** 本级政府 + 上一级生态环境部门

## 六、应急保障

### 6.1 队伍保障
- **专业队伍：** 生态环境部门应急监测队伍、消防救援队伍、危险化学品救援队伍
- **社会队伍：** 企业专兼职应急队伍、第三方机构应急队伍
- **专家队伍：** 环境应急专家库

### 6.2 物资与资金保障
- **物资储备：** 应急监测仪器、防护装备、处置药剂、应急车辆
- **储备方式：** 政府储备 + 企业代储 + 社会储备
- **经费保障：** 纳入财政预算，专款专用

### 6.3 通信、交通与运输保障
- **通信保障：** 应急通信网络、卫星电话、对讲机
- **交通保障：** 应急通道、交通管制、运输车辆
- **运输保障：** 危险品运输车辆、应急物资运输

### 6.4 技术保障
- **监测技术：** 便携式监测仪器、在线监测设备、实验室检测
- **处置技术：** 污染治理技术库、处置方案库
- **信息化系统：** 环境应急指挥平台、风险源数据库

### 6.5 机制保障
- **联动机制：** 部门联动、区域联动、军地联动
- **演练机制：** 定期演练、实战演练
- **培训机制：** 应急培训、资格认证

## 七、监督管理

### 7.1 预案演练要求
- **市级：** 每年至少组织1次应急演练
- **县市区：** 每年至少组织1次应急演练
- **企业：** 每年至少组织1次应急演练
- **演练类型：** 桌面推演、功能演练、全面演练

### 7.2 奖励与责任追究

**奖励情形：**
1. 出色完成应急处置任务
2. 避免或减轻事件损失
3. 应急工作中有重大创新
4. 提供重要线索或建议

**责任追究情形：**
1. 未按规定报告事件
2. 迟报、谎报、瞒报事件
3. 处置不当导致事态扩大
4. 不服从统一指挥调度
5. 挪用、贪污应急资金物资

## 八、娄底市特色与重点

### 8.1 重点风险源
根据娄底市产业特点，重点防范：
1. **重金属污染：** 锡矿山、冷水江等地锑、铅、锌等采矿冶炼企业
2. **危险废物：** 医药、化工企业产生的危险废物
3. **危险化学品：** 加油站、化工企业的油料、化学品
4. **尾矿库：** 矿山企业的尾矿库（汛期重点防范）
5. **饮用水水源地：** 全市乡镇及以上集中式饮用水水源地

### 8.2 重点敏感目标
1. **饮用水水源地：**
   - 娄底市第二自来水厂（涟水河）
   - 各县市区饮用水水源地

2. **人口密集区：**
   - 娄星区城区
   - 冷水江市城区
   - 涟源市城区
   - 双峰县城区
   - 新化县城区

3. **生态敏感区：**
   - 自然保护区
   - 湿地公园
   - 森林公园

### 8.3 区域联动
- **省内联动：** 与邵阳、益阳、怀化等相邻市州建立联动机制
- **跨界事件：** 涟水河、资江等跨界河流污染事件协同处置

## 九、实操 Checklist

### 9.1 企业突发环境事件应对流程

```
事件发生
    ↓
1. 立即启动企业预案（1小时内）
    ↓
2. 切断污染源（关闭阀门、停止生产）
    ↓
3. 疏散人员（厂区内 + 可能受影响的周边群众）
    ↓
4. 第一时间报告（属地生态环境部门 + 应急管理部门）
    ↓
5. 开展先期处置（构筑围堰、投放药剂、控制泄漏）
    ↓
6. 配合政府处置（提供技术资料、协助监测、提供物资）
    ↓
7. 事件终止后开展损害评估、环境修复
```

### 9.2 信息报告模板

**电话报告（30分钟内）：**
```
"报告，这里是XX企业，今天X时X分，在我公司XX车间发生XX泄漏事件，
泄漏量约XX吨，已影响XX，目前已有X人中毒，我们正在采取XX措施，请指示。"
```

**书面报告（60分钟内）：**
```
1. 事件基本情况（时间、地点、类型、起因）
2. 已造成的危害（人员伤亡、污染范围、经济损失）
3. 已采取的处置措施
4. 需要政府协调的事项
5. 联系人及电话
```

## 十一、2025版官网原文补充（2026-07-11更新）

> 以下内容摘自娄政发〔2025〕2号官网原文，为本次核对补全的关键机制。

### 11.1 现场指挥部与 8 个工作组
根据应急处置需要，现场指挥部按战线和属地原则组成 **8 个应急工作组**：

| 序号 | 工作组 | 牵头单位 | 配合单位 | 主要职责 |
|------|--------|----------|----------|----------|
| 1 | 综合协调组 | 市生态环境局 | 市应急管理局等 | 信息报送、传达上级指示、协调各组 |
| 2 | **污染处置组** | 市生态环境局 | 自然资源、应急管理、公安、交通、水利、林业、消防救援、武警、属地政府 | 切断污染源、分析污染途径、防扩散、消除/减轻污染、确定个人防护、警戒区与交通管制、疏散转移 |
| 3 | 应急监测组 | 市生态环境局 | 自然资源、水利、水文、气象 | 布点监测、确认扩散范围与强度，支撑决策 |
| 4 | 应急保障组 | 市应急局 | 生态环境、工信、财政、交通、发改、公安、民政、商务 | 转移安置、物资储备调拨配送、生活必需品保障 |
| 5 | 医学救援组 | 市卫健委 | 市场监管、民政 | 伤病员救治、应急心理援助、健康保护建议 |
| 6 | 新闻宣传组 | 市委宣传部 | 生态环境、应急管理、网信、文旅 | 权威发布、舆情引导、**严禁现场摄影摄像资料上网炒作** |
| 7 | 社会稳定组 | 市公安局 | 工信、生态环境、城管、武警、军分区 | 治安管控、打击谣言、矛盾化解、市场监管 |
| 8 | 专家组 | 市生态环境局 | 应急管理、水利、自然资源、气象 | 性质研判、趋势预测、方案评估、修复建议 |

### 11.2 “三库”保障要求
市预案1.4工作原则明确要求建立健全 **专家库、风险源库、应急物资库（三库）**，做好队伍、经费、装备、通讯、交通、运输及技术保障。

### 11.3 信息报告红线（依据环境保护部令第17号）
- **一般/较大（Ⅳ/Ⅲ级）：** 发现或得知后 **4小时内** 向本级政府 + 上一级环保部门报告。
- **重大/特别重大（Ⅱ/Ⅰ级）：** **2小时内** 向本级政府 + 省级环保部门报告，同时报生态环境部；省级核实后 **1小时内** 报生态环境部。
- **一律按重大/特别重大（2小时）程序上报的情形（第17号第四条）：** ①影响饮用水水源保护区；②涉及居民区/学校/医院等敏感人群；③**涉及重金属或类金属污染**；④可能跨省/跨国影响；⑤引发群体性事件或社会影响较大；⑥环保部门认为有必要报告的其他情形。
- **对娄底的实操含义：** 辖区内任何**涉锑（重金属）**异常，无论初判等级，**一律触发2小时上报程序**（含报生态环境部路径）。本文档第三章 3.4 表中的“3小时/30分钟电话”应理解为更严的地方初报节点要求，但**涉重金属事件不得按一般事件4小时报送**，须执行2小时红线。

### 11.4 与湖南省预案衔接
娄底市预案为市政府专项预案，与《湖南省突发环境事件应急预案》（湘政办发〔2018〕2号）及省级管理办法（湘环发〔2024〕49号）相衔接；企业/园区预案须符合湖南省预案管理办法修订版要求（Q<1豁免、专业人员编制、90工作日签署+20/30工作日备案等）。
