# 辐射应急基础术语与单位速查

> 适用对象：应急管理人员、现场处置人员、值守人员
> 
> 重点提示：本文件为基础速查手册，建议与《辐射应急监测与处置流程》配套使用

---

## 一、基础概念辨析

### 1.1 放射性（Radioactivity）

**定义**：不稳定原子核自发地释放能量和粒子，转变为更稳定状态的过程。

**核心特征**：
- 原子核自发放出α粒子、β粒子或γ射线的现象
- 释放的能量以辐射形式表现出来
- 是自然现象，也可人工产生

**与大众理解的差异**：
- 放射性 ≠ 核武器
- 放射性 ≠ 核电站
- 放射性物质在医疗、工业、农业、科研领域广泛存在

**常见应用场景**：
| 应用领域 | 典型放射源 | 用途 |
|---------|-----------|------|
| 医疗灭菌 | Co-60、Cs-137 | 医疗器械消毒 |
| 工业探伤 | Ir-192、Co-60 | 焊缝检测 |
| 烟雾探测 | Am-241 | 离子感烟探测器 |
| 测井作业 | Am-241、Cs-137 | 地质勘探 |
| 食品辐照 | Co-60 | 杀虫保鲜 |

### 1.2 电离辐射（Ionizing Radiation）

**定义**：具有足够能量使物质发生电离的辐射。

**可产生电离的辐射类型**：

```
电离辐射家族
├── 带电粒子辐射
│   ├── α粒子（氦-4原子核，+2电荷）
│   ├── β粒子（电子，-1电荷）
│   ├── β+粒子（正电子，+1电荷）
│   └── 质子辐射
├── 不带电粒子辐射
│   ├── γ射线（原子核退激）
│   ├── X射线（原子内层电子跃迁）
│   └── 中子辐射
└── 复合辐射
    └── 宇宙射线（混合粒子流）
```

**电离能力对比**：
- α粒子：电离能力最强，穿透能力最弱（一张纸可阻挡）
- β粒子：电离能力中等，穿透能力中等（铝板可阻挡）
- γ/X射线：电离能力较弱，穿透能力最强（需要铅或混凝土屏蔽）
- 中子：穿透力强，需要特殊材料屏蔽（水、聚乙烯）

### 1.3 非电离辐射（Non-Ionizing Radiation）

**定义**：能量不足以使物质原子或分子电离的辐射。

**典型来源**：
| 类型 | 频率范围 | 常见来源 |
|-----|---------|---------|
| 极低频 | 0-300 Hz | 电力线路、家用电器 |
| 射频 | 300 Hz-300 GHz | 手机基站、WiFi、广播 |
| 红外线 | 300 GHz-400 THz | 热成像、遥控器 |
| 可见光 | 400-790 THz | 太阳光、灯光 |
| 紫外线 | 790 THz-30 PHz | 阳光 |

**重要提示**：
- **非电离辐射不属于辐射应急范畴**
- 本知识库所称"辐射"均指电离辐射
- 接到"辐射泄漏"报警时，首先确认是否为放射性物质事故

## 二、单位体系详解

### 2.1 吸收剂量（Absorbed Dose）

**单位：戈瑞（Gray, Gy）**

**定义**：单位质量物质吸收的电离辐射能量。

**计算公式**：
```
1 Gy = 1 J/kg
```

**Gy与旧单位rad的换算**：
```
1 Gy = 100 rad
1 rad = 0.01 Gy
```

**实际应用**：
- 主要用于描述介质吸收的能量
- 用于评估设备损伤、物质加热效应
- 在医学上用于肿瘤放疗剂量计算

**典型数值参考**：
| 场景 | 典型剂量 |
|-----|---------|
| 胸部CT单次 | 5-7 mGy |
| 腹部CT单次 | 10-20 mGy |
| 钡餐检查 | 7 mGy |
| 常规X光片 | 0.1-1 mGy |

### 2.2 当量剂量（Equivalent Dose）

**单位：希沃特（Sievert, Sv）**

**定义**：考虑辐射类型加权后的吸收剂量，反映对生物组织的影响程度。

**加权系数**：
| 辐射类型 | 组织加权系数 |
|---------|------------|
| X射线、γ射线、电子 | 1 |
| 质子 | 2 |
| α粒子、重离子 | 20 |
| 中子 | 5-20（依能量而异） |

**计算公式**：
```
H = Q × D
```
其中：
- H = 当量剂量（Sv）
- Q = 辐射权重因子
- D = 吸收剂量（Gy）

**Sv与旧单位rem的换算**：
```
1 Sv = 100 rem
1 rem = 10 mSv
```

### 2.3 有效剂量（Effective Dose）

**单位：希沃特（Sv）**

**定义**：考虑组织权重因子后的全身当量剂量，用于评估随机性健康效应风险。

**主要组织权重因子**：
| 组织/器官 | 权重因子 |
|----------|---------|
| 性腺 | 0.08 |
| 骨髓、结肠、肺、胃 | 0.12 |
| 膀胱、食道、肝、甲状腺 | 0.04 |
| 骨表面、脑、唾液腺、皮肤 | 0.01 |
| 其余组织（取最大值） | 0.12 |

**全身有效剂量 = Σ(组织当量剂量 × 组织权重因子)**

### 2.4 活度（Activity）

**单位：贝克勒尔（Bequerel, Bq）**

**定义**：单位时间内原子核衰变的数目。

**换算关系**：
```
1 Bq = 1 次衰变/秒
1 Ci（居里）= 3.7 × 10^10 Bq
1 mCi = 3.7 × 10^7 Bq = 37 MBq
1 µCi = 3.7 × 10^4 Bq = 37 kBq
```

**常见放射源典型活度**：
| 放射源类型 | 典型活度范围 | 备注 |
|-----------|-------------|------|
| 烟雾报警器 | 30-80 kBq | Am-241，安全性高 |
| 医用Ir-192 | 100-400 GBq | 后装治疗 |
| 工业探伤Ir-192 | 1-5 TBq | 活度较高 |
| 辐照装置Co-60 | 1-100 PBq | 工业级高活度 |
| 测井Cs-137 | 1-10 GBq | 工业应用 |

### 2.5 剂量率（ dose rate）

**单位：Sv/h、mSv/h、µSv/h**

**定义**：单位时间内接收的剂量。

**快速换算表**：
```
1 Sv/h = 1000 mSv/h = 1,000,000 µSv/h
1 mSv/h = 1000 µSv/h
```

**现场快速估算**：
- 剂量率仪读数 × 暴露时间 = 预估剂量
- 例：100 µSv/h环境中暴露2小时 ≈ 0.2 mSv

### 3.3 吸收剂量与当量剂量换算（以γ射线为例）

```
吸收剂量 1 Gy ≈ 当量剂量 1 Sv（γ射线权重因子=1）
```

**重要提醒**：
- 对于γ射线，1 Gy吸收剂量 ≈ 1 Sv当量剂量
- 对于α射线，1 Gy吸收剂量 = 20 Sv当量剂量
- 不可混淆！同样的吸收剂量，不同辐射类型造成的生物效应差异巨大

### 4.4 天然本底监测意义

**建立基准线**：
- 了解本地天然本底水平是评估异常辐射事件的前提
- 娄底地区基准线：剂量率约0.08-0.12 µSv/h

**异常判断阈值**：
- 持续超过本底3倍：需关注排查
- 持续超过本底10倍：需启动应急监测
- 持续超过本底100倍：需启动应急响应

| 适用对象 | 器官/组织 | 剂量限值 |

| 群体 | 附加要求 |

| 预期剂量 | 建议行动 |
|---------|---------|

| ≥1 Gy（全身） | 医疗救治 |
| ≥10 Gy（局部） | 紧急处理 |

**行动水平（Action Levels）**：
| 类型 | 水平值 |
|-----|-------|
| 食品通用行动水平 | 放射性核素特定值 |
| 氡浓度行动水平 | 室内200-400 Bq/m³ |

### 5.3 剂量与健康效应对照

```
剂量区间与健康效应对照

< 100 mSv          无显著临床效应，癌症风险略微增加（线性无阈模型）
100-500 mSv        可能出现暂时性血象变化
500-1000 mSv       轻度急性放射病症状（恶心、乏力）
1-6 Gy             中度至重度急性放射病（造血系统损伤）
6-10 Gy            重度急性放射病（胃肠损伤为主）
> 10 Gy            极重度（存活困难，需最高级别医疗支持）
```

## 六、快速参考卡片

### 6.1 剂量速算公式

```
预估剂量（mSv）= 剂量率（µSv/h）× 暴露时间（h）÷ 1000
```

**实例**：
- 剂量率：200 µSv/h
- 暴露时间：30分钟（0.5小时）
- 预估剂量：200 × 0.5 ÷ 1000 = 0.1 mSv

### 6.2 屏蔽材料速查

| 辐射类型 | 推荐屏蔽材料 | 备注 |
|---------|-------------|------|
| α粒子 | 纸、衣服、皮肤 | 穿透力极弱，外照射风险低 |
| β粒子 | 铝板、塑料、有机玻璃 | 避免产生韧致辐射 |
| γ/X射线 | 铅、钨、混凝土 | 厚度依活度计算 |
| 中子 | 水、聚乙烯、硼砂/石蜡 | 先慢化再吸收 |

### 6.3 常用剂量率参考

| 场景 | 典型剂量率 |
|-----|----------|
| 自然本底 | 0.05-0.15 µSv/h |
| 飞行高度万米 | 3-8 µSv/h |
| 胸部X光检查后1米 | 0.1-1 µSv/h（短暂）|
| 放射源丢失现场 | 数十至数千µSv/h |
| 辐照装置误照 | 可能达到mSv/h级 |

### 6.4 关键数值记忆口诀

```
辐射数值记一记：
本底一年两个四（全球2.4 mSv/年）
公众限值一毫西（1 mSv/年）
```
