# DCS曲线取证指引——在线监测执法证据固定

## 一、DCS曲线在执法中的核心作用

DCS（分散控制系统）曲线是环境执法中**识别在线监测数据弄虚作假**的核心技术手段。执法人员和监管部门通过调取和分析企业DCS系统的历史曲线，结合CEMS数据，进行**工况关联分析**，实现对排污行为的**穿透式监管**。

核心逻辑：**"透过数据看工况、透过工况查合规"**

## 二、DCS曲线取证的典型应用场景

### 2.1 核验工况标记的真实性

当企业标记"停炉""启炉"时，执法人员通过DCS曲线核验：
- **停炉标记**：DCS曲线显示窑温下降、投料停止、氧含量升高
- **启炉标记**：DCS曲线显示温度上升、投料开始、氧含量下降
- 若DCS显示仍在投料但标记为"停炉"→ **涉嫌弄虚作假**

### 2.2 发现隐蔽的数据造假

自动监测数据造假按环节分三类，DCS分析对**第二类**尤为有效：

| 环节 | 造假手段 | DCS识别方法 |
|------|---------|------------|
| 采样/预处理 | 遮挡采样口、破坏管线 | 结合视频监控 |
| **仪器分析** | **修改参数、植入造假软件** | **DCS工况参数与排放数据逻辑一致性分析** |
| 数据传输 | 修改量程、破坏通讯 | 比对数采仪原始数据 |

### 2.3 案例：淄博穿透式监管案

某企业颗粒物数据异常 → 数据分析发现疑点 → 执法支队现场检查 → 调取**湿电除尘装置电压历史曲线**，发现异常时段曲线有明显波动 → 结合视频监控查明员工私自进入站房对烟尘仪断电 → **认定人为干扰在线设备、数据弄虚作假** → 移交公安机关。

## 三、取证操作规范

### 3.1 取证内容

| 证据类型 | 具体内容 |
|---------|---------|
| DCS历史曲线 | 启停炉时段、异常排放时段的前后1小时曲线 |
| 运行参数 | 温度、投料量、氧含量、电压、电流、pH值 |
| 排放数据 | CEMS同步数据（SO₂、NOx、颗粒物） |
| 操作日志 | DCS操作记录、报警记录 |
| 运维记录 | 校准记录、维护台账、故障处理记录 |

### 3.2 证据固定要求

根据《环境行政处罚办法》第36条和《环境行政处罚证据指南》，在线监测数据作为电子证据须满足：

1. **设备合规**：在线监测设备通过强制检定和适用性检测
2. **数据合规**：采集和传输符合技术规范
3. **站点合规**：监测站点设置符合要求
4. **完整性**：数据未被篡改，原始记录完整
5. **原始介质**：提供原始载体或按要求复制提取

### 3.3 证据链闭环（五环闭合）

```
现场笔录 → 拍照录像 → 书证调取 → 手工比对监测 → 询问笔录
  逐页签字   全景+近景   原始DCS数据   印证监测数据   固定主观故意
              +时间戳    +运维台账
```

## 四、"穿透式"监管趋势

### 4.1 新型监管模式

- 从"末端数据核查"向"全过程工况溯源"关口前移
- 融合**在线监测 + DCS + 分表计电 + 视频**等多源数据
- 构建"**数据筛查→综合分析→问题推送→现场核查→查处反馈**"闭环

### 4.2 AI智能取证

宁夏宁东正在研发**固定污染源异常数据AI智能分析核验系统**：
- 自动区分：设备故障、真实超标、人为造假三类异常
- 生成完整取证档案：监测曲线+视频录像+操作日志
- 满足环保执法取证规范
