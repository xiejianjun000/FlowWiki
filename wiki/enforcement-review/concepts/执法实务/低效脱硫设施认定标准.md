# 低效脱硫设施认定标准

## 一、政策背景

2023年11月，生态环境部发布《低效失效大气污染治理设施排查整治工作方案》，将低效脱硫设施排查列为重点工作。各省市（河南、许昌等）陆续出台实施方案，明确排查标准和整治时限。

**时间线**：
- 2024年9月：各省印发实施方案
- 2024年12月：完成重点企业排查
- 2025年9月：完成整治提升

## 二、低效脱硫设施的认定标准

### （一）淘汰类工艺

以下工艺被明确列为**低效脱硫工艺，应淘汰更新**：
- 水喷淋脱硫
- 电子束法脱硫
- 处理机制不明、无法通过脱硫剂或副产物进行污染物脱除效果核查评估的治理技术
- **禁止无反应容器直接在烟道中喷洒液态或气态脱硫剂**

### （二）关键设备缺失

湿法脱硫设施（含双碱法）必须安装以下关键组件，**缺失即认定为低效失效**：

| 必备组件 | 说明 |
|---------|------|
| 除雾器 | 防止烟气带水 |
| **pH计** | 脱硫塔、再生池均须设置 |
| 氧化风机 | 保证亚硫酸盐氧化 |
| 脱硫废液及副产物处理系统 | 副产物须有去向 |
| 浆液密度计 | 石灰/石灰石-石膏法必备 |
| **副产物氧化和提取设施** | ⚠️ **双碱法在浆液循环系统外必须设置** |
| 脱硫剂自动投加设备 | 与生产负荷、pH值、SO₂浓度联动 |

### （三）自动化控制要求

- 脱硫剂喷入量应与**生产负荷、浆液pH值、SO₂浓度**等关键参数联动
- 控制系统应实现脱硫剂投加量、脱硫浆液pH值的**自动调节控制**
- 人工手动加药且无实时监控记录的，视为控制不达标

### （四）运行维护问题

存在以下情形之一，可认定为运行性低效：
- 结垢、堵塞、腐蚀、泄漏
- 有色烟羽、烟气拖尾、"烟囱雨"
- 台账记录不全、不规范
- 关键参数未按技术规范或设计要求运行维护

## 三、双碱法的特殊认定

### 3.1 双碱法原理

双碱法（NaOH + Ca(OH)₂）通过钠碱吸收SO₂，再用钙碱再生，理论上可循环使用。核心流程：
1. 钠碱吸收SO₂ → Na₂SO₃/NaHSO₃
2. 钙碱再生 → CaSO₃沉淀 + NaOH再生
3. 副产物氧化 → CaSO₄（石膏）

### 3.2 双碱法常见违法模式

| 违法表现 | 具体情形 | 执法识别方法 |
|---------|---------|------------|
| **只用碱不加钙** | 只加片碱不加石灰，缺少钙碱再生环节 | 检查石灰仓库存、加药台账、pH值趋势 |
| **pH值失控** | 循环液呈酸性（pH＜7），脱硫能力丧失 | 调取pH计历史曲线 |
| **关键设备缺失** | 未配备副产物氧化和提取设施、再生池pH计 | 现场核查设备清单 |
| **台账造假** | 无加药记录、无药剂购买凭证 | 核对采购量与实际消耗量 |
| **自动控制缺失** | 人工手动加药，不能根据负荷调节 | 检查DCS控制逻辑 |

### 3.3 典型执法案例

**案例：湘潭市日鑫建材有限公司（2025年）**
- 仅采用片碱吸收脱硫，**没有再生反应过程及曝气氧化过程**
- 石灰加料池pH为中性，无石灰加料台账，现场未发现石灰药剂堆存
- **处罚**：罚款10万元，移送公安机关

**案例：内蒙古雄盛保温材料有限公司（2021年）**
- 未投加氧化钙，氧化钙添加池已板结
- SO₂排放浓度高达**3160mg/m³**，超标4.75倍
- **处罚**：罚款10万元，责任人行政拘留

## 四、法律依据

| 法条 | 内容 | 罚则 |
|------|------|------|
| 《大气污染防治法》第20条第2款 | 禁止通过不正常运行污染防治设施逃避监管 | — |
| 《大气污染防治法》第99条 | 违反上述规定 | **10万-100万元**，情节严重责令停业关闭 |
| 《环境保护法》第63条 | 不正常运行污染防治设施 | **移送公安，5-15日拘留** |

**执法认定要点**：
- "不正常运行"不仅指完全停运，还包括**"明开暗停""偷工减料""私设旁路""带病运行"**
- "不按照环评/验收报告的工艺要求运行"即可认定为不正常运行
