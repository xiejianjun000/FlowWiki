## 一、总体框架："以空间换时间"

**核心理念：** 通过企业、园区、流域三级空间设施（围堰→事故池→应急空间/河道路径），在污染物泄漏后、流向园区外之前，"以空间换时间"，将污水控制在园区边界范围内，避免进入外环境。

**整体架构图：**

```
泄漏发生
  ↓
┌─────────────────────────────────────────────────────┐
│  第一级防控（企业自身防控）                            │
│  装置区围堰 + 罐区围堰 + 企业事故应急池               │
│  → 防止泄漏扩散至厂外道路/管网                        │
└─────────────────────────────────────────────────────┘
  ↓（超越一级，进入公共区域）
┌─────────────────────────────────────────────────────┐
│  第二级防控（园区公共防控）                            │
│  园区公共应急池 + 企业间应急池连通 + 雨水管网闸控     │
│  → 控制在园区边界范围内                              │
└─────────────────────────────────────────────────────┘
  ↓（超越二级，威胁外环境）
┌─────────────────────────────────────────────────────┐
│  第三级防控（园区边界及周边空间防控）                  │
│  边界围堰/拦截坝 + 周边坑塘调蓄 + 河道闸坝           │
│  → 最后兜底，防止进入外环境受纳水体                   │
└─────────────────────────────────────────────────────┘
  ↓（超越三级，进入流域）
→ 流域级应急处置（加药捕集→拦截坝→稀释调度→供水保障）  ← 与7-19日学习技术链衔接
```

## 二、第一级防控：企业自身防控

### 2.1 装置区围堰

| 技术要素 | 技术要求 |
|----------|----------|
| 设置位置 | 生产装置区、罐组、泵区等潜在泄漏区域 |
| 围堰高度 | ≥泄漏液体最大积存高度（通常≥300mm） |
| 结构要求 | 防渗（防渗系数≤1×10⁻⁷ cm/s）、防腐、地面硬化 |
| 配套设施 | 清污切换阀门；围堰内设集水沟+集水井+抽吸泵 |
| 切换机制 | 正常：围堰内积水排入污水管网；事故：切换阀门，引导进入事故池 |

### 2.2 罐区围堰

| 技术要素 | 技术要求 |
|----------|----------|
| 地面硬化 | 罐区地面须硬化、防渗、防腐 |
| 围堰容积 | ≥最大储罐容积（单罐容积最大者） |
| 雨水阀管理 | 平时关闭（防止初期雨水进入污水系统）；收集后检测再决定排放去向 |
| 围堰维护 | 定期检查防渗层完整性、阀门启闭灵活性 |

### 2.3 企业事故应急池

| 技术要素 | 技术要求 |
|----------|----------|
| 有效容积 | ≥ max｛最大储罐容积，设计最大事故工况排水量｝ |
| 切换阀门 | 与雨水管网、污水管网联动；事故时自动/手动关闭雨水阀，打开事故池进水阀 |
| 防腐防渗 | 池体防渗；内部防腐处理（耐酸碱/耐有机溶剂） |
| 排水设施 | 事故池内设提升泵；处理达标后方可排放 |
| 备用电源 | 配套柴油发电机；确保停电时切换阀门和提升泵仍可运行 |
| 标识标牌 | 明显标识；禁止挪用 |

**娄底市重点企业核查要点（冷水江经开区涉锑/化工企业）：**
- 闪星锑业（锑冶炼）：焦锑酸钠/含锑废水事故池容积是否满足最大储罐容量？
- 其他化工企业：事故池是否与雨水管网实现有效切换？

### 2.4 排水管网清污分流

- 园区企业须实现**清污分流**（雨水/污水/事故水三套管网或切换阀门）
- 事故时雨水管网截断阀须能快速关闭（30秒内完成切换）

## 三、第二级防控：园区公共防控

### 3.1 园区公共应急池

| 技术要素 | 技术要求 |
|----------|----------|
| 功能定位 | 接纳园区内企业无法自行处置的事故废水；最后一道厂界防线 |
| 容积确定 | 满足园区最大风险源事故工况需求；通常取园区企业事故池容积之和的20%–30%作为应急余量（扬州经验） |
| 位置要求 | 设置于园区地势较低处；重力收集园区事故水 |
| 预处理 | 进入公共应急池前设格栅/隔油设施 |
| 排水管控 | 处理达标后通过园区污水管网进入污水处理厂；不得直接外排 |
| 标识标牌 | 明显标识；禁止挪用；周边设置围栏 |

### 3.2 企业间应急池连通

**扬州经验（推荐做法）：**

| 要素 | 具体做法 |
|------|----------|
| 连通方式 | 相邻企业间应急池通过管道+阀门连通 |
| 管道规格 | DN300–DN500；耐腐蚀材质（HDPE/玻璃钢） |
| 阀门设置 | 双向阀门；可就地/远程启闭 |
| 调度机制 | 园区指挥中心统一调度；应急预案中明确启用条件和程序 |
| 空间逻辑 | 企业A应急池满 → 打开连通阀 → 转入企业B应急池 |

**娄底适用性：** 在冷水江经开区闪星锑业与相邻涉锑企业间优先推动连通改造。

### 3.3 园区雨水管网闸控

| 技术要素 | 技术要求 |
|----------|----------|
| 设置位置 | 园区雨水管网末端（排放口前）+ 关键节点（跨越企业边界处） |
| 闸门类型 | 电动闸门（主）+ 手动闸门（备用） |
| 控制方式 | 园区指挥中心远程控制 + 现场手动控制 |
| 切换时间 | 紧急情况下30秒内完成关闭 |
| 状态监控 | 视频监控+液位监测+远程反馈 |

### 3.4 园区公共监测设施

| 设施类型 | 要求 |
|----------|------|
| 入河排口在线监测 | COD、pH、重金属（锑、镉等）等指标；5分钟频次数据上传 |
| 雨水排口监测 | 必要时加装简易在线监测（pH、电导率异常预警） |
| 视频监控 | 重点企业围堰/事故池/雨水闸门实时监控；联网园区指挥中心 |
| 预警系统 | 监测数据超阈值自动触发预警；短信通知园区值班人员 |

## 四、第三级防控：园区边界及周边空间防控

### 4.1 边界围堰/拦截坝

| 技术要素 | 技术要求 |
|----------|----------|
| 设置位置 | 园区边界（邻近河道/敏感水体侧） |
| 结构类型 | 土工膜围堰/混凝土矮墙/橡胶坝（可收纳式） |
| 功能 | 防止事故水漫出园区进入外环境受纳水体 |
| 拦截容量 | 须满足园区最大风险源事故水量（叠加二级应急池后仍有缺口部分） |

### 4.2 周边坑塘/调蓄空间

| 技术要素 | 技术要求 |
|----------|----------|
| 利用对象 | 园区周边自然坑塘、低洼地、鱼塘（经评估可用者） |
| 改造要求 | 防渗处理（必要时）；设置围堰；接入/引流水管 |
| 调蓄容量 | 作为三级防控的额外缓冲容量（叠加拦截坝容量） |
| 权属协调 | 需提前与周边村组/单位签订应急征用协议 |

### 4.3 河道拦截设施

| 技术要素 | 技术要求 |
|----------|----------|
| 设施类型 | 橡胶坝（可收纳式）+ 固定闸坝 |
| 设置位置 | 园区邻近河道（排放口下游适当距离） |
| 配合机制 | 与水利部门预先制定调度方案；事故时放下坝体拦截 |
| 预警联动 | 河道在线监测数据超阈值 → 自动触发拦截坝启用 |
| 泄洪安全 | 须预留泄洪通道；不能因拦截影响行洪安全（与水利部门联合论证） |

**娄底市涟溪河/青峰河现状（已有设施）：**
- 涟溪河已建成自动化应急加药设施（铁盐/活性炭投放系统）
- 青峰河相关设施（待核查）
- **现有加药设施可作为三级防控"处置端"**，但仍需配套足够的"空间端"（拦截容量）才能实现完整三级防控

### 4.4 受纳水体监控断面

| 断面类型 | 布设要求 |
|----------|----------|
| 入河排污口下游监控断面 | 紧邻排放口下游；锑/重金属等特征污染物在线监测 |
| 园区边界下游监控断面 | 园区边界下游500–1000m；综合指标监测 |
| 饮用水水源地上游预警断面 | 临近饮用水取水口上游500m；加密监测频次 |

## 五、"一园一策一图"内容框架

### 5.1 "一园"：园区基本情况

| 内容模块 | 具体要素 |
|----------|----------|
| 基本信息 | 园区名称、地址、批复面积、产业定位、园区规划环评批复情况 |
| 企业清单 | 入园企业名单、行业类别、环境风险等级、风险物质清单 |
| 风险源识别 | 重点风险源位置、风险物质种类与数量（Q值计算） |
| 应急资源 | 现有应急池/围堰/物资/队伍清单 |
| 能力评估 | 对照三级防控要求，评估现有设施差距 |
| 存在问题 | 一级/二级/三级防控设施缺口及原因分析 |

### 5.2 "一策"：三级防控体系建设方案

| 防控级别 | 建设内容 | 责任主体 | 完成时限 |
|----------|----------|----------|----------|
| 一级 | 园区内所有企业事故池+围堰建设达标 | 各企业 | 2026年12月 |
| 二级 | 园区公共应急池建设+企业间应急池连通改造 | 园区管委会 | 2027年6月 |
| 三级 | 边界拦截坝+雨水闸控升级+数字化监控平台 | 园区管委会+市水利局 | 2027年12月 |

**运维机制：**
- 园区管委会设专人对三级防控设施进行日常维护
- 每年开展至少一次功能性测试（蓄水试验、阀门启闭测试）
- 纳入园区年度环境应急能力评估

## 六、三级防控与"一河一策一图"的衔接

### 6.1 娄底市涟溪河衔接框架（示例）

```
【企业级：闪星锑业】
  含锑废水事故池（已建）
  → 一级防控：企业自身拦截
↓
【园区级：冷水江经开区】
  园区公共应急池（待核查/建设）
  → 二级防控：园区内集中拦截
↓
【边界级：涟溪河】
  涟溪河自动化加药设施（已建）+ 河岸拦截坝（待核查）
  → 三级防控：河道路径拦截+化学处置
↓
【流域级：资江/湘江】
  → 超出三级防控后，启动娄底市预案→省级联动
```

### 6.2 关键衔接节点

| 衔接点 | 设施 | 责任部门 |
|--------|------|----------|
| 企业→园区 | 雨水管网截断阀 | 企业+园区管委会 |
| 园区→河流 | 边界拦截坝 | 园区管委会+市水利局 |
| 河流→流域 | 监控断面预警 | 市生态环境局 |
