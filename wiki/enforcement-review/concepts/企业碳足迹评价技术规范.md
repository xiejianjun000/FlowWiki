# 企业碳足迹评价技术规范

**文件编号**：GB/T XXXXX-2024
**发布单位**：国家市场监督管理总局、国家标准化管理委员会
**实施日期**：2024年10月1日

---

## 一、范围

本标准规定了企业碳足迹评价的术语和定义、评价原则、评价范围、核算方法、数据质量管理、报告要求等内容。

本标准适用于：
- 产品层面的碳足迹评价
- 组织层面的碳足迹评价（可选）
- 项目层面的碳足迹评价（可选）

本标准主要针对产品碳足迹（Product Carbon Footprint, PCF），即产品全生命周期的温室气体排放。

## 三、术语和定义

### 3.1 碳足迹 carbon footprint

产品（或服务、组织、项目）在其全生命周期中产生的温室气体排放总量，以二氧化碳当量表示。

### 3.2 产品碳足迹 product carbon footprint, PCF

产品从原材料获取、生产、分销、使用到废弃处理（即从摇篮到坟墓）的整个生命周期中产生的温室气体排放总量。

### 3.3 生命周期 life cycle

产品系统从原材料获取到最终废弃的全部阶段，包括：
- 原材料获取阶段
- 生产制造阶段
- 分销运输阶段
- 使用阶段
- 废弃处理阶段

### 3.4 功能单位 functional unit

作为基准单位的产品性能量化表述，是生命周期评价的基准。

### 3.5 产品系统 product system

集合了为实现特定功能的物质流、能量流的各种单元过程的集合。

### 3.6 单元过程 unit process

产品系统中最基本的、可单独核算的操作步骤或过程。

### 3.7 系统边界 system boundary

为进行碳足迹核算而确定的单元过程和排放源的范围。

### 3.8 分配 allocation

当一个单元过程产出多种产品或服务时，将环境负荷在不同产品或服务之间进行分摊的过程。

### 3.9 基准流程 baseline flow

在功能相同或等效的前提下，与所研究产品系统进行比较的参考产品系统。

### 3.10 初级数据 primary data

通过现场测量、企业台账、直接调查等方式获得的特定过程的实际数据。

### 3.11 次级数据 secondary data

来自数据库、文献、行业平均等非特定来源的通用数据。

### 3.12 截断准则 cut-off criteria

用于判断哪些单元过程或物质流可以忽略不计的阈值标准。

## 四、评价原则

碳足迹评价应遵循以下原则：

### 4.1 生命周期视角

从产品全生命周期角度考虑所有阶段的排放，避免只关注单一阶段而忽略其他阶段。

### 4.2 相关性

选择的方法、数据和系统边界应与评价目的和功能单位相关。

### 4.3 完整性

评价应覆盖系统边界内所有相关的单元过程和排放源，不得遗漏重要的排放。

### 4.4 一致性

评价过程中采用的方法、假设、数据来源应保持一致，确保结果的可比性。

### 4.5 准确性

核算结果应尽可能准确，减少不确定性，避免系统性偏差。

### 4.6 透明性

评价方法、假设、数据来源、计算过程应清晰透明，便于第三方验证。

### 4.7 避免重复计算

在供应链和多产品过程中，应避免重复计算排放量。

### 4.8 科学严谨

采用科学的方法和可靠的数据，确保评价结果的科学性和可信度。

## 五、评价范围确定

### 5.1 评价目的

应明确碳足迹评价的目的，包括但不限于：
- 内部管理和减排决策
- 产品比较和标签
- 供应链管理
- 客户沟通
- 合规和报告
- 绿色采购

### 5.2 功能单位

#### 5.2.1 功能单位定义

功能单位是碳足迹核算的基准，应：
- 明确量化产品的功能
- 可测量、可验证
- 具有代表性
- 便于比较

#### 5.2.2 常见功能单位示例

| 产品类型 | 功能单位示例 |
|---------|-------------|
| 食品饮料 | 1kg产品 / 1L产品 / 每份 |
| 电子产品 | 1台产品 / 使用1年 |
| 建材 | 1m³ / 1t / 1m² |
| 服装 | 1件 / 1kg面料 |
| 包装材料 | 1个包装 / 1m²材料 |
| 服务 | 1人次 / 1次服务 |

**示例：**
- 1瓶500ml瓶装饮用水
- 1kWh光伏发电量
- 1km汽车运输服务

### 5.3 产品系统描述

应详细描述产品系统，包括：
1. 产品名称、型号、规格
2. 主要功能和用途
3. 产品性能参数
4. 使用寿命
5. 生产工艺流程
6. 供应链概况

### 5.4 系统边界

#### 5.4.1 生命周期阶段

产品碳足迹系统边界应包括以下阶段：

```
原材料获取 → 生产制造 → 分销运输 → 使用阶段 → 废弃处理
    │            │          │          │          │
    ▼            ▼          ▼          ▼          ▼
  原料开采   生产加工   仓储物流   产品使用   回收/填埋
  能源生产   能源消耗   运输排放   维护保养   焚烧/降解
  运输       废水废气   包装材料   能源消耗   残余物
```

**各阶段说明：**

| 阶段 | 主要活动 | 主要排放源 |
|-----|---------|-----------|
| 原材料获取 | 原材料开采、加工、运输 | 能源消耗、工艺排放、运输排放 |
| 生产制造 | 产品加工、组装、测试 | 能源消耗、工艺排放、废弃物 |
| 分销运输 | 仓储、运输、批发、零售 | 运输排放、仓储能耗、包装 |
| 使用阶段 | 产品使用、维护、保养 | 能源消耗、耗材、维修 |
| 废弃处理 | 收集、运输、处理 | 运输排放、处理过程排放 |

#### 5.4.2 系统边界类型

| 类型 | 范围 | 适用场景 |
|-----|------|---------|
| 从摇篮到大门 | 原材料获取到产品出厂 | B2B产品、中间产品 |
| 从摇篮到坟墓 | 全生命周期 | 终端产品、消费品 |
| 从大门到大门 | 企业内部生产过程 | 企业内部管理 |
| 从摇篮到使用 | 原材料到使用阶段 | 耐用产品 |

**推荐：** 终端消费品采用"从摇篮到坟墓"，中间产品采用"从摇篮到大门"。

#### 5.4.3 截断准则

对于排放量很小的过程或物质，可以忽略不计，但需满足：

| 截断级别 | 阈值 | 说明 |
|---------|------|------|
| 质量截断 | <1%质量占比 | 质量占比<1%的物料 |
| 环境影响截断 | <1%总排放 | 排放贡献<1%的过程 |

**要求：**
- 被截断的过程总贡献不超过5%
- 截断准则应明确说明
- 重要环境影响的物质即使量小也应纳入

### 5.5 温室气体种类

应核算以下温室气体：
- 二氧化碳（CO₂）
- 甲烷（CH₄）
- 氧化亚氮（N₂O）
- 氢氟碳化物（HFCs）
- 全氟化碳（PFCs）
- 六氟化硫（SF₆）
- 三氟化氮（NF₃）

**注：** 数据缺乏时，至少应核算CO₂、CH₄、N₂O三种主要温室气体。

### 5.6 GWP值选择

- 优先采用IPCC第六次评估报告（AR6）的100年GWP值
- 也可采用IPCC第五次评估报告（AR5）值，但需说明
- 应保持时间范围一致（100年或20年）

## 六、核算方法

### 6.1 核算总公式

产品碳足迹计算公式：

```
PCF = Σ (AD_i × EF_i) × GWP_i / FU
```

其中：
- `PCF`：单位功能单位产品碳足迹，单位：kgCO₂e/功能单位
- `AD_i`：第i个单元过程的活动数据
- `EF_i`：第i个单元过程的排放因子
- `GWP_i`：第i种温室气体的全球变暖潜值
- `FU`：功能单位数量

### 6.2 各阶段核算方法

#### 6.2.1 原材料获取阶段

**核算内容：**
1. 原材料开采和加工
2. 原材料运输到工厂
3. 能源生产（上游排放）

**核算方法：**
```
E_原材料 = Σ (M_i × EF_M,i) + Σ (T_i × EF_T,i)
```

其中：
- `M_i`：第i种原材料用量，kg
- `EF_M,i`：第i种原材料的排放因子，kgCO₂e/kg
- `T_i`：第i种原材料的运输量·距离，t·km
- `EF_T,i`：运输排放因子，kgCO₂e/(t·km)

**数据来源优先级：**
1. 供应商提供的具体数据（首选）
2. 行业平均数据
3. 生命周期数据库
4. 文献和研究报告

#### 6.2.2 生产制造阶段

**核算内容：**
1. 能源消耗（电力、蒸汽、燃料）
2. 工艺过程排放
3. 辅助材料消耗
4. 废弃物处理
5. 厂房设备分摊

**核算方法：**
```
E_生产 = E_能源 + E_工艺 + E_辅助 + E_废物 + E_分摊
```

**能源消耗排放：**
```
E_能源 = Σ (EC_j × EF_E,j)
```

其中：
- `EC_j`：第j种能源消耗量
- `EF_E,j`：第j种能源的排放因子

**工艺过程排放：**
根据具体工艺采用物料衡算法或排放因子法。

**生产阶段的特殊性：**
- 多产品生产时需进行分配
- 副产品和废弃物需合理处理
- 能耗分摊应科学合理

#### 6.2.3 分销运输阶段

**核算内容：**
1. 成品仓储
2. 产品运输（工厂→仓库→零售商→消费者）
3. 零售环节
4. 包装材料

**核算方法：**
```
E_分销 = E_仓储 + E_运输 + E_零售 + E_包装
```

**运输排放：**
```
E_运输 = Σ (D_k × M_k × EF_T,k)
```

其中：
- `D_k`：第k段运输距离，km
- `M_k`：运输质量，t
- `EF_T,k`：运输方式排放因子，kgCO₂e/(t·km)

#### 6.2.4 使用阶段

**核算内容：**
1. 使用过程的能源消耗
2. 使用过程的耗材
3. 维护保养
4. 使用寿命

**核算方法：**
```
E_使用 = (E_年使用 × 使用寿命) - E_节约（如有）
```

**关键参数：**
- 年使用强度
- 产品使用寿命
- 使用能效
- 用户行为模式

**注意事项：**
- 使用阶段排放占比可能很大
- 用户行为差异大，需取典型值
- 使用寿命应基于统计或标准

#### 6.2.5 废弃处理阶段

**核算内容：**
1. 产品废弃收集
2. 运输到处理厂
3. 处理方式（填埋、焚烧、回收、堆肥等）
4. 回收替代效益（如有）

**核算方法：**
```
E_废弃 = E_收集运输 + E_处理 - E_回收替代
```

**处理方式排放因子：**

| 处理方式 | CO₂排放 | CH₄排放 | 说明 |
|---------|---------|---------|------|
| 填埋 | 少量 | 较多 | 厌氧分解产甲烷 |
| 焚烧 | 较多 | 很少 | 能量回收可抵扣 |
| 回收再利用 | 很少 | 很少 | 替代原生材料有减排效益 |
| 堆肥 | 少量 | 少量 | 有机垃圾 |
| 拆解回收 | 少量 | 很少 | 电子产品 |

### 6.3 分配方法

当一个单元过程产生多种产品时，需要进行分配。

#### 6.3.1 分配原则

1. **避免分配原则**
   - 划分为子过程
   - 扩展系统边界

2. **因果关系原则**
   - 按产生排放的原因分配

3. **优先级原则**
   - 物理参数分配优先（质量、体积、能量）
   - 经济价值分配次之

#### 6.3.2 分配方法

| 方法 | 适用条件 | 公式 |
|-----|---------|------|
| 质量分配 | 产品质量可度量，与排放相关 | 分配比例 = 产品质量/总质量 |
| 能量分配 | 产品能量含量可度量 | 分配比例 = 产品能量/总能量 |
| 经济分配 | 产品价值差异大 | 分配比例 = 产品价值/总价值 |
| 替代法 | 副产品有明确替代 | 系统扩展，扣除副产品替代排放 |

#### 6.3.3 多产品生产分配示例

某化工厂同时生产产品A和产品B：
- 总能耗：1000 MWh
- 产品A产量：800 t
- 产品B产量：200 t

**质量分配：**
- A分配比例 = 800 / (800+200) = 80%
- B分配比例 = 200 / (800+200) = 20%

## 七、数据质量管理

### 7.1 数据类型

#### 7.1.1 初级数据（实地数据）

**来源：**
- 企业实测数据
- 供应商具体数据
- 现场计量数据
- 生产台账记录

**特点：**
- 针对性强，与特定产品相关
- 数据质量高
- 获取成本较高
- 优先采用

#### 7.1.2 次级数据（背景数据）

**来源：**
- 生命周期数据库（Ecoinvent、GABI、中国CLCD等）
- 行业平均数据
- 文献和研究报告
- IPCC排放因子
- 国家/地区统计数据

**特点：**
- 通用性强
- 数据质量差异大
- 获取成本低
- 初级数据缺乏时使用

### 7.2 数据质量要求

#### 7.2.1 数据质量特性

| 特性 | 说明 | 评价指标 |
|-----|------|---------|
| 时间代表性 | 数据年份与评价年份的接近程度 | 数据年份差≤3年为优 |
| 地理代表性 | 数据来源地区与实际的匹配度 | 本地区>全国>地区>全球 |
| 技术代表性 | 数据反映的技术水平 | 先进/平均/落后 |
| 完整性 | 数据覆盖的过程和排放源 | 覆盖率≥95%为优 |
| 准确性 | 数据接近真实值的程度 | 误差<10%为优 |
| 一致性 | 数据采集方法的一致性 | 方法统一为优 |

#### 7.2.2 各阶段数据质量要求

| 生命周期阶段 | 初级数据占比要求（最低） | 数据质量要求 |
|-------------|----------------------|-------------|
| 生产制造 | ≥70% | 高 |
| 原材料获取 | ≥30% | 中高 |
| 分销运输 | ≥20% | 中 |
| 使用阶段 | ≥30% | 中（用户行为差异大） |
| 废弃处理 | ≥20% | 中 |

### 7.3 数据收集方法

#### 7.3.1 企业生产数据收集

**收集内容：**
- 能源消耗台账（电力、煤炭、天然气、蒸汽等）
- 原材料消耗统计
- 产品产量统计
- 废弃物产生和处理数据
- 运输数据

**数据来源：**
- 企业能源管理系统
- 财务和采购部门
- 生产报表
- 环保监测数据

#### 7.3.2 供应链数据收集

**收集方法：**
1. **直接向供应商收集**（首选）
   - 供应商问卷调查
   - 供应商碳足迹数据
   - 供应商认证

2. **数据库和文献**
   - 生命周期数据库
   - 行业报告
   - 学术文献

3. **工程估算**
   - 物料清单（BOM）
   - 工艺参数
   - 工程计算

### 7.4 数据库选择

常用的生命周期数据库：

| 数据库名称 | 发布机构 | 地域 | 特点 |
|-----------|---------|------|------|
| 中国生命周期基础数据库（CLCD） | 四川大学 | 中国 | 本土化数据，免费 |
| Ecoinvent | 瑞士 | 全球 | 最全面，国际通用 |
| GaBi | 德国Sphera公司 | 全球 | 制造业数据库强 |
| IDEA | 日本 | 日本/亚洲 | 亚洲数据 |
| US LCI Database | 美国NREL | 美国 | 北美数据 |
| ELCD | 欧盟 | 欧洲 | 欧洲数据 |

**选择原则：**
- 优先使用本土数据库
- 数据质量高的数据库
- 与评价对象匹配
- 公开透明、可追溯

### 7.5 不确定性评估

#### 7.5.1 不确定性来源

| 来源 | 说明 | 影响程度 |
|-----|------|---------|
| 活动数据 | 计量误差、统计误差 | 中-高 |
| 排放因子 | 数据代表性、测量误差 | 中-高 |
| 分配假设 | 分配方法选择 | 中 |
| 使用阶段假设 | 用户行为、使用寿命 | 高（使用阶段占比大时） |
| 模型选择 | 核算模型差异 | 低-中 |
| 数据缺失 | 缺少数据，使用替代值 | 中-高 |

#### 7.5.2 不确定性评估方法

1. **定性分级法**
   - 对每个过程的数据质量进行分级
   - 评估整体不确定性等级

2. **敏感性分析**
   - 分析关键参数变化对结果的影响
   - 识别影响最大的因素

3. **蒙特卡洛模拟**
   - 设定各参数的概率分布
   - 随机抽样计算结果分布
   - 给出置信区间

#### 7.5.3 不确定性等级

| 等级 | 不确定度范围 | 数据质量评价 |
|-----|-------------|-------------|
| 低 | ≤±10% | 高质量，结果可信 |
| 中 | ±10%~±30% | 中等质量，结果基本可信 |
| 高 | ±30%~±50% | 低质量，结果仅供参考 |
| 很高 | >±50% | 质量很差，需改进 |

## 十、碳足迹减排

### 10.1 减排优先级

按照生命周期各阶段的减排潜力和成本，确定减排优先级：

```
优先级1：使用阶段减排（如能效提升）
    ↓
优先级2：原材料替代（如低碳材料）
    ↓
优先级3：生产过程减排（如节能、新能源）
    ↓
优先级4：供应链优化（如运输优化）
    ↓
优先级5：末端治理（如碳捕集）
```

### 10.2 各阶段减排措施

#### 10.2.1 原材料阶段

- 选用低碳原材料
- 使用回收再生材料
- 减少材料用量（轻量化）
- 替代高碳材料

#### 10.2.2 生产阶段

- 提高能源效率
- 使用可再生能源
- 优化生产工艺
- 减少废弃物产生

#### 10.2.3 分销阶段

- 优化运输路线
- 提高运输装载率
- 使用低碳运输方式
- 减少包装材料

#### 10.2.4 使用阶段

- 提高产品能效
- 延长产品寿命
- 减少使用阶段排放
- 优化用户行为

#### 10.2.5 废弃阶段

- 提高回收利用率
- 延长产品生命周期
- 设计可回收产品
- 优化处理方式

## 附录A（资料性附录） 产品碳足迹核算工作流程

### A.1 工作步骤

1. **步骤一：确定评价目的和范围**
   - 明确评价目的
   - 确定功能单位
   - 划定系统边界
   - 选择核算标准

2. **步骤二：数据收集**
   - 绘制产品生命周期流程图
   - 列出单元过程清单
   - 收集活动数据
   - 选择排放因子

3. **步骤三：排放量计算**
   - 各阶段排放量计算
   - 汇总总排放量
   - 分配处理
   - 计算单位产品碳足迹

4. **步骤四：结果分析**
   - 排放贡献分析
   - 敏感性分析
   - 不确定性评估
   - 减排潜力识别

5. **步骤五：报告编制**
   - 撰写评价报告
   - 数据质量说明
   - 减排建议
   - 第三方核查（如需）
