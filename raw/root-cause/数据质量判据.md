# 数据质量判据集

## 六维评估框架
1. 完整性：数据缺失比例 < 5%
2. 准确性：数据误差在可接受范围内
3. 一致性：跨系统数据一致率 > 95%
4. 及时性：数据延迟 < 指定 SLA
5. 唯一性：重复数据比例 < 1%
6. 有效性：数据格式和值域合规率 > 99%

## 监控指标
- 空值率：每个字段的 NULL 比例
- 离群率：超出 3σ 范围的数据比例
- 漂移率：数据分布随时间的变化幅度
- 时效性：从数据产生到可用的延迟

## 判据来源
- DAMA DMBOK 数据管理知识体系
- ISO 8000 数据质量标准
